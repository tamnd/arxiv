Consider a counting query $f$, namely a function that, applied to a dataset $x$, returns the number of individuals in $x$ that satisfy a given property. A way to implement differential privacy \cite{Dwork:06:TCC} is to add geometrical noise to the result of $f$, so to obtain a probability distribution $P$ on integers of the form $P(z) = c \, e^{|z-f(x)|}$, where $c$ is a normalization factor. The resulting mechanism can  be interpreted as a probabilistic choice on protocols of the form $f(x), f(x) + 1, f(x) + 2, \ldots , f(x) - 1, f(x)-2, \ldots$, where the probability assigned to 
 $f(x) + n$ and to $f(x)-n$ decreases exponentially with $n$.

<!-- example-3: body_md -->
\label{exe:Crime}
Compression Ratio Info-leak Made Easy (CRIME) \cite{Rizzo:12:Ekoparty} is a
security exploit against secret web cookies over connections using the HTTPS and SPDY protocols and  data compression. 
The idea is that the attacker can inject some content $a$ in the communication of the secret $x$ from the target site to the server. The server then compresses and  encrypts the data, including both $a$ and $x$, and sends back the result. By observing the length of the result, the attacker can then infer information about $x$. 
To mitigate the leakage, one possible defense would consist in transmitting, along with $x$, also an encryption method $f$ selected randomly from a set $F$. Again, the resulting protocol can be seen as a composition, using probabilistic choice, of the protocols in the set $F$.

<!-- example-4: body_md -->
\label{ex:Timing}
Consider a password-checker, or any similar system in which the user authenticates himself
by entering a secret that is checked by the system. An adversary does not know the real secret,
of course, but a timing side-channel could reveal the \emph{part} (eg. which bit) of the secret in which the adversary's
input fails. By repeating the process with different inputs, the adversary might be able to
fully retrieve the secret. A possible counter measure is to make the side channel noisy,
by randomizing the order in which the secret's bit are checked against the user input.
This example is studied in detaul in Section~\ref{sec:password-example}.

<!-- theorem-1: body_md -->
\label{theo:vonneumann}
Let $\mathcal{X} \subset \mathbb{R}^m$ and $\mathcal{Y} \subset \mathbb{R}^n$ be compact convex sets,
and $\textit{U}: \mathcal{X}\times\mathcal{Y}\rightarrow\mathbb{R}$ be a continuous function such that
$\textit{U}(x, y)$ is a convex function in $x\in\mathcal{X}$ and a concave function in $y\in\mathcal{Y}$.
Then
\[
\min_{x\in\mathcal{X}} \max_{y\in\mathcal{Y}} \textit{U}(x, y) = \max_{y\in\mathcal{Y}} \min_{x\in\mathcal{X}} \textit{U}(x, y)
.
\]

<!-- prop-1: body_md -->
\label{prop:type-hidden-choice}
Given a family $\{C_{i}\}_{i \in \mathcal{I}}$ of 
channels of  type $\mathcal{X} \times \mathcal{Y} \rightarrow \mathbb{R}$, 
and a distribution $\mu$ on $\mathcal{I}$, 
the hidden choice 
${\osum_{i \leftarrow \mu}} C_{i}$ is 
a channel of type
$\mathcal{X} \times \mathcal{Y} \rightarrow \mathbb{R}$.

<!-- prop-2: body_md -->
\label{prop:type-visible-choice}
Given a family $\{C_{i}\}_{i \in \mathcal{I}}$ of 
compatible channels s.t. each $C_{i}$ has type 
$\mathcal{X} \times \mathcal{Y}_{i} \rightarrow \mathbb{R}$,
and a distribution $\mu$ on $\mathcal{I}$, 
the result of the visible choice 
${\bigsqcupdot_{i \leftarrow \mu}} C_{i}$ is a channel
of type 
$\mathcal{X} \times \left( \bigsqcup_{i \in \mathcal{I}} \mathcal{Y}_{i} \right) \rightarrow \mathbb{R}$.
<!-- end prop-2 -->
<!-- definition-1: body_md -->
\label{def:equivalence-channels}
Two compatible channels $C_{1}$ and $C_{2}$
with domain $\mathcal{X}$
are \emph{equivalent}, denoted by $C_{1} \approx C_{2}$,
if for every prior $\pi \in \mathbb{D}{\mathcal{X}}$ and every 
posterior vulnerability $\mathbb{V}$ we have
               
$
\mathbb{V}\left[\pi,C_{1}\right] = \mathbb{V}\left[\pi,C_{2}\right]
$.
<!-- end definition-1 -->
<!-- prop-3: body_md -->
\label{prop:idempotency}
Given a family $\{C_{i}\}_{i \in \mathcal{I}}$ of 
channels s.t. $C_{i} = C$ for all $i \in \mathcal{I}$,
and a distribution $\mu$ on $\mathcal{I}$, then:
                     
                      
      
(a) ${{\osum_{i \leftarrow \mu}}C_{i} = C}$; and
       
(b) ${{\bigsqcupdot_{i \leftarrow \mu}}C_{i} \approx C}$.

<!-- prop-4: body_md -->
\label{prop:reorganization-operators}
Given a family $\{C_{i j}\}_{i \in \mathcal{I}, j \in \mathcal{J}}$ of 
channels indexed by sets $\mathcal{I}$ and $\mathcal{J}$,
a distribution $\mu$ on $\mathcal{I}$, and
a distribution $\eta$ on $\mathcal{J}$:

\begin{enumerate}
\renewcommand{\alph{enumi})}{(\alph{enumi})}
\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item 
${{\osum_{i \leftarrow \mu}} \;{\osum_{j \leftarrow \eta}} C_{i j} = {\osum_{\substack{i \leftarrow \mu\\ j \leftarrow \eta}}} C_{i j}}$, if all $C_{i}$'s have the same type;\\      

\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item 
${{\bigsqcupdot_{i \leftarrow \mu}} \; {\bigsqcupdot_{j \leftarrow \eta}} C_{i j} \approx {\bigsqcupdot_{\substack{i \leftarrow \mu\\ j \leftarrow \eta}}} C_{i j}}$, if all $C_{i}$'s are compatible; and\\      

\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item \label{item:c}
${{\osum_{i \leftarrow \mu}} \; {\bigsqcupdot_{j \leftarrow \eta}} C_{i j} \approx {\bigsqcupdot_{j \leftarrow \eta}}\; {\osum_{i \leftarrow \mu}} C_{i j}}$, 
if, for each $i$, all $C_{i j}$'s have same type $\mathcal{X} \times \mathcal{Y}_{j}\rightarrow\mathbb{R}$.
\end{enumerate}

<!-- theorem-2: body_md -->
\label{theo:convex-V-q}
Let $\{C_{i}\}_{i \in \mathcal{I}}$ be a family of channels,
and $\mu$ be a distribution on $\mathcal{I}$.
Then, for every distribution $\pi$ on $\mathcal{X}$, and every
vulnerability $\mathbb{V}$:
\begin{enumerate}
\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item \label{enumerate:vg:h:convex}
posterior vulnerability is convex w.r.t. to hidden choice:
               
$
\mathbb{V}\left[\pi,{\osum_{i \leftarrow \mu}} C_{i}\right] \leq \sum_{i \in \mathcal{I}} \mu(i) \,\mathbb{V}\left[\pi,C_{i}\right]
$
             
if all $C_{i}$'s have the same type.

\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item \label{enumerate:vg:v:linear}
posterior vulnerability is linear w.r.t. to visible choice:
               
$
\mathbb{V}\left[\pi,{\bigsqcupdot_{i \leftarrow \mu}} C_{i}\right] = \sum_{i \in \mathcal{I}} \mu(i) \,\mathbb{V}\left[\pi,C_{i}\right]
$
             
if all $C_{i}$'s are compatible.
\end{enumerate}
<!-- end theorem-2 -->
<!-- proof-1: body_md -->
\begin{enumerate}

\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item Let us call $\mathcal{X} \times \mathcal{Y} \rightarrow \mathbb{R}$ the 
type of each channel $C_{i}$ in the family $\{C_{i}\}$.
Then:
\begin{align*}
\mathbb{V}\left[\pi,{\osum_{i \leftarrow \mu}} C_{i}\right] 
=&\, \mathbb{V}\left[\pi,\operatorname{\sum}_{i} \mu(i)C_{i}\right] & \text{(by definition of hidden choice)} \\ 
=&\, \sum_{y \in \mathcal{Y}} p(y) \cdot \mathbb{V}\left[\frac{\pi(\cdot) \sum_{i}\mu(i)C_{i}(\cdot,y) }{p(y)}\right]  & \text{(by definition of posterior $\mathbb{V}$)}\\ 
=&\, \sum_{y \in \mathcal{Y}} p(y) \cdot \mathbb{V}\left[\sum_{i}\mu(i)\frac{\pi(\cdot) C_{i}(\cdot,y) }{p(y)}\right]  & \text{}\\ 
\leq&\, \sum_{y \in \mathcal{Y}} p(y) \cdot \sum_{i} \mu(i) \mathbb{V}\left[\frac{\pi(\cdot) C_{i}(\cdot,y) }{p(y)}\right]  & \text{(by convexity of $\mathbb{V}$)}\\ 
=&\, \sum_{i} \mu(i) \sum_{y \in \mathcal{Y}} p(y) \mathbb{V}\left[\frac{\pi(\cdot) C_{i}(\cdot,y) }{p(y)}\right]  & \text{}\\
=&\, \sum_{i} \mu(i) \mathbb{V}\left[\pi,C_{i}\right]  & \text{}
\end{align*}
where $p(y) = \sum_{x\in\mathcal{X}} \pi(x) \sum_{i} \mu(i)C_{i}(x,y)$.
\\

\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item Let us call $\mathcal{X} \times \mathcal{Y}_{i} \rightarrow \mathbb{R}$ the 
type of each channel $C_{i}$ in the family $\{C_{i}\}$.
Then:
\begin{align*}
\mathbb{V}\left[\pi,{\bigsqcupdot_{i \leftarrow \mu}} C_{i}\right]
=&\, \mathbb{V}\left[\pi,\meddiamond_{i} \mu(i)C_{i}\right] & \text{(by definition of visible choice)} \\ 
=&\, \sum_{y \in \mathcal{Y}} p(y) \cdot \mathbb{V}\left[\frac{\pi(\cdot) \meddiamond_{i}\mu(i)C_{i}(\cdot,y) }{p(y)}\right]  & \text{(by definition of posterior $\mathbb{V}$)}\\ 
=&\, \sum_{y \in \mathcal{Y}} p(y) \cdot \mathbb{V}\left[\meddiamond_{i}\mu(i)\frac{\pi(\cdot) C_{i}(\cdot,y) }{p(y)}\right]  & \text{}\\ 
=&\, \sum_{y \in \mathcal{Y}} p(y) \cdot \sum_{i} \mu(i) \mathbb{V}\left[\frac{\pi(\cdot) C_{i}(\cdot,y) }{p(y)}\right]  & \text{(see (*) below)}\\ 
=&\, \sum_{i} \mu(i) \sum_{y \in \mathcal{Y}} p(y) \mathbb{V}\left[\frac{\pi(\cdot) C_{i}(\cdot,y) }{p(y)}\right]  & \text{}\\
=&\, \sum_{i} \mu(i) \mathbb{V}\left[\pi,C_{i}\right]  & \text{}
\end{align*}
where $p(y) = \sum_{x\in\mathcal{X}} \pi(x) \sum_{i} \mu(i)C_{i}(x,y)$, and 
step (*) holds because in the vulnerability of a concatenation of matrices
every column will contribute to the vulnerability in proportion to its weight
in the concatenation, and hence it is possible to break the vulnerability of a 
concatenated matrix as the weighted sum of the vulnerabilities of its sub-matrices.
\end{enumerate}

<!-- corollary-1: body_md -->
\label{cor:concave-convex-V}
Let $\{C_{i j}\}_{i \in \mathcal{I}, j \in \mathcal{J}}$ be a family of channels,
all with domain $\mathcal{X}$ and with the same type, and let $\pi\in \mathbb{D}\mathcal{X}$, and $\mathbb{V}$ be any vulnerability. 
Define
$\textit{U}: \mathbb{D}\mathcal{I}\times\mathbb{D}\mathcal{J}\rightarrow \mathbb{R}$ as follows:
               
$
\textit{U}(\mu, \eta) \ensuremath{\stackrel{\mathrm{def}}{=}} \mathbb{V}\left[\pi,{\osum_{i \leftarrow \mu}} \; {\bigsqcupdot_{j \leftarrow \eta}} \; C_{i j}\right]
$.
             
Then $\textit{U}$ is convex on $\mu$ and linear on $\eta$.
<!-- end corollary-1 -->
<!-- proof-2: body_md -->
To see that $U(\mu,\eta)$ is convex on $\mu$, note that:
\begin{align*}
U(\mu,\eta) 
=&\, \mathbb{V}\left[\pi,{\osum_{i \leftarrow \mu}} \; {\bigsqcupdot_{j \leftarrow \eta}} \; C_{i j}\right] & \text{(by definition)} \\
\leq&\, \sum_{i} \mu(i) \; \mathbb{V}\left[\pi,{\bigsqcupdot_{j \leftarrow \eta}} \; C_{i j}\right] & \text{(by Theorem~\ref{theo:convex-V-q})}
\end{align*}

To see that $U(\mu,\eta)$ is linear on $\eta$, note that:
\begin{align*}
U(\mu,\eta) 
=&\, \mathbb{V}\left[\pi,{\osum_{i \leftarrow \mu}} \; {\bigsqcupdot_{j \leftarrow \eta}} \; C_{i j}\right] & \text{(by definition)} \\
=&\, \mathbb{V}\left[\pi,{\bigsqcupdot_{j \leftarrow \eta}} \; {\osum_{i \leftarrow \mu}} \; C_{i j}\right] & \text{(by Prop.~\ref{prop:reorganization-operators})} \\
=&\, \sum_{j} \eta(j) \; \mathbb{V}\left[\pi,{\osum_{i \leftarrow \mu}} \; C_{i j}\right] & \text{(by Theorem.~\ref{theo:convex-V-q})}
\end{align*}
~

<!-- theorem-3: body_md -->
\label{theo:deterministic-strategies-II}
Consider a defender-first sequential game with visible choice, and attacker's strategies of type 
$\mathbb{D}(\mathcal{D}\,{\rightarrow}\,\mathcal{A})$. Let $d^*\ensuremath{\stackrel{\mathrm{def}}{=}} \operatornamewithlimits{argmin}_d \max_a \textit{u}(d,a)$ and let $\textit{s}_{\sf a}^*:\mathcal{D}\,{\rightarrow}\,\mathcal{A}$ be defined as $\textit{s}_{\sf a}^*(d)\ensuremath{\stackrel{\mathrm{def}}{=}}  \operatornamewithlimits{argmax}_{a} \textit{u}(d,a)$
(if there is more than one  $a$ that maximizes $\textit{u}(d,a)$, we select one of them arbitrarily). 
Then   
for every $\delta\in\mathbb{D}\mathcal{D}$ and ${\sigma_{\sf a}}\in\mathbb{D}(\mathcal{D}\,{\rightarrow}\,\mathcal{A})$ we have
$
\textit{U}(d^*,{\sigma_{\sf a}})\leq \textit{u}(d^*,\textit{s}_{\sf a}^*(d^*))\leq \textit{U}(\delta,\textit{s}_{\sf a}^*)
$.
<!-- end theorem-3 -->
<!-- proof-3: body_md -->
Let 
 $\delta$ and  ${\sigma_{\sf a}}$ be arbitrary elements of $\mathbb{D}\mathcal{D}$ and $\mathbb{D}(\mathcal{D}\,{\rightarrow}\,\mathcal{A})$, respectively. Then:
\begin{align*}
\textit{U}(d^*,{\sigma_{\sf a}})
=     & \;\; \sum_{\textit{s}_{\sf a}:\mathcal{D}\,{\rightarrow}\,\mathcal{A}} {\sigma_{\sf a}}(\textit{s}_{\sf a})\, \textit{u}(d^*, \textit{s}_{\sf a}(d^*))\\
\leq & \;\; \sum_{\textit{s}_{\sf a}:\mathcal{D}\,{\rightarrow}\,\mathcal{A}} {\sigma_{\sf a}}(\textit{s}_{\sf a})\, \textit{u}(d^*, \textit{s}_{\sf a}^*(d^*)) &\mbox{(by definition of $\textit{s}_{\sf a}^*$)}\\
= & \;\;  \textit{u}(d^*, \textit{s}_{\sf a}^*(d^*))&\mbox{(since ${\sigma_{\sf a}}$ is a distribution)}\\
= & \;\; \sum_{d\in\mathcal{D}} \delta(d)\,\textit{u}(d^*, \textit{s}_{\sf a}^*(d^*))  &\mbox{(since $\delta$ is a distribution)}\\
\leq & \;\; \sum_{d\in\mathcal{D}} \delta(d)\,\textit{u}(d, \textit{s}_{\sf a}^*(d))    &\mbox{(by definition of $d^*$)}\\
= & \;\; \textit{U}(\delta,\textit{s}_{\sf a}^*)
\end{align*}

<!-- theorem-4: body_md -->
\label{theo:deterministic-strategies-II-2}
Consider a defender-first sequential game with visible choice, and attacker's strategies of type 
$\mathcal{D} \rightarrow \mathbb{D}(\mathcal{A})$.
Let $d^*\ensuremath{\stackrel{\mathrm{def}}{=}} \operatornamewithlimits{argmin}_d \max_a \textit{u}(d,a)$ and let $\phi^*_{\sf a}:\mathcal{D} \rightarrow \mathbb{D}(\mathcal{A})$ be defined as $\phi^*_{\sf a}(d)(a)\ensuremath{\stackrel{\mathrm{def}}{=}} 1$ if $a= \operatornamewithlimits{argmax}_{a'} \textit{u}(d,a')$ (if there is more than one such $a$, we select one of them arbitrarily), and $\phi^*_{\sf a}(d)(a)\ensuremath{\stackrel{\mathrm{def}}{=}} 0$ otherwise. 
Then   
for every $\delta\in\mathbb{D}\mathcal{D}$ and ${\phi_{\sf a}}: \mathcal{D} \rightarrow \mathbb{D}(\mathcal{A})$ we have:
$
\textit{U}(d^*,{\phi_{\sf a}}(d^*))\leq \textit{U}(d^*,\phi^*_{\sf a}(d^*))\leq \textit{U}(\delta,\phi^*_{\sf a})
$.
<!-- end theorem-4 -->
<!-- proof-4: body_md -->
Let $a^*$ be the action selected by $\phi^*_{\sf a}(d^*)$, i.e.,  $\phi^*_{\sf a}(d^*)(a^*)\ensuremath{\stackrel{\mathrm{def}}{=}} 1$. Then $\textit{u}(d^*,a^*)= \max_{a} \textit{u}(d^*,a)$. Let
$\delta$ and  ${\phi_{\sf a}}$ be arbitrary elements of $\mathbb{D}\mathcal{D}$ and 
$\mathcal{D} \rightarrow \mathbb{D}(\mathcal{A})$, respectively. 
Then:
\begin{align*}
\textit{U}(d^*,{\phi_{\sf a}}(d^*))
=     & \;\; \sum_{a\in\mathcal{A}} {\phi_{\sf a}}(d^*)(a)\, \textit{u}(d^*, a)\\
\leq & \;\; \sum_{a\in\mathcal{A}}  {\phi_{\sf a}}(d^*)(a)\,\textit{u}(d^*, a^*) &\mbox{(since $\textit{u}(d^*,a^*)= \max_{a} \textit{u}(d^*,a)$)}\\
= & \;\;  \textit{u}(d^*, a^*)&\mbox{(since ${\phi_{\sf a}}(d^*)$ is a distribution)}\\
= & \;\;  \textit{U}(d^*,\phi^*_{\sf a}(d^*))&\mbox{(by definition of  $a^*$)}\\
= & \;\; \sum_{d\in\mathcal{D}} \delta(d)\,\textit{u}(d^*, \phi^*_{\sf a}(d^*))  &\mbox{(since $\delta$ is a distribution)}\\
\leq & \;\; \sum_{d\in\mathcal{D}} \delta(d)\,\textit{u}(d, \phi^*_{\sf a}(d))    &\mbox{(by definition of $d^*$ and of $\phi^*_{\sf a}$)}\\
= & \;\; \textit{U}(\delta,\phi^*_{\sf a})
\end{align*}

\label{theo:deterministic-strategies-III}

<!-- example-8: body_md -->
\label{exa:exempio}
Consider now the example of Section~\ref{sec:running-example} in the setting of Game IV.
For $\delta\in\mathbb{D}\mathcal{D}$ and $\alpha\in\mathbb{D}\mathcal{A}$, let $p=\delta(0)$ and $q=\alpha(0)$. 
The system can be represented by the channel 
$(C_{00}\;{{}_{p}{\mathlarger{\mathlarger{\oplus}}}}\; C_{10})\;{{}_{q}{\mathlarger{\mathlarger{\sqcupdot}}}}\;(C_{01}\;{{}_{p}{\mathlarger{\mathlarger{\oplus}}}}\; C_{11})$
represented below.
\begin{align*}
\begin{array}{|c|c|c|}
\hline
C_{00}  \;{{}_{p}{\mathlarger{\mathlarger{\oplus}}}}\; C_{10}& y=0 & y=1 \\ \hline
x=0    & p & \overline{p} \\
x=1    & 1 & 0 \\ \hline
\end{array}
\quad
\;{{}_{q}{\mathlarger{\mathlarger{\sqcupdot}}}}\;
\quad
\begin{array}{|c|c|c|}
\hline
C_{01}\;{{}_{p}{\mathlarger{\mathlarger{\oplus}}}}\; C_{11}& y=0 & y=1 \\ \hline
x=0    & \nicefrac{1}{3}+ \nicefrac{2}{3}\;p &   \nicefrac{2}{3}- \nicefrac{2}{3}\;p \\
x=1    & \nicefrac{2}{3}- \nicefrac{2}{3}\;p  & \nicefrac{1}{3}+ \nicefrac{2}{3}\,p \\ \hline
\end{array}
\end{align*}
\noindent For uniform $\pi$, we have
$\mathbb{V}\left[\pi, C_{00} \;{{}_{p}{\mathlarger{\mathlarger{\oplus}}}}\; C_{10}\right]{=}1-\nicefrac{1}{2}\,p$, 
while
$\mathbb{V}\left[\pi, C_{10}  \;{{}_{p}{\mathlarger{\mathlarger{\oplus}}}}\; C_{11}\right]$ is equal to
$
\nicefrac{2}{3}- \nicefrac{2}{3}\,p$ if $p\leq \nicefrac{1}{4}$,
and equal to 
$\nicefrac{1}{3}+ \nicefrac{2}{3}\,p$ 
if $p> \nicefrac{1}{4}$.
          
Hence the payoff, expressed in terms of $p$ and $q$, is
$\textit{U}(p,q) = q(1-\nicefrac{1}{2}\,p) + \overline{q} (\nicefrac{2}{3} - \nicefrac{2}{3}\,p)$
if $p\leq \nicefrac{1}{4}$, and 
$\textit{U}(p,q) = q(1-\nicefrac{1}{2}\,p) + \overline{q} (\nicefrac{1}{3} + \nicefrac{2}{3}\,p)$ 
if $p> \nicefrac{1}{4}$.
The Nash equilibrium can be computed by imposing that the partial derivatives of 
$\textit{U}(p,q)$ with respect to $p$ and $q$ are both $0$, which means that we are in a  saddle point.  
We have:
\[
\renewcommand{1}{1.7}
\frac{\partial \textit{U}(p,q)}{\partial q}=\left\{\begin{array}{ll}
		\frac{1}{3}+\frac{1}{6}\,p&, \text{ if } p\leq\frac{1}{4}\\
		\frac{2}{3}-\frac{7}{6}\,p&, \text{ if } p>\frac{1}{4}\\
		\end{array}
		\right.
\qquad
\frac{\partial \textit{U}(p,q)}{\partial p}=\left\{\begin{array}{ll}
		-\frac{2}{3}+\frac{1}{6}\,q&, \text{ if } p\leq\frac{1}{4}\\
		\frac{2}{3}-\frac{7}{6}\,q&, \text{ if }  p>\frac{1}{4}\\
		\end{array}
		\right.		
\renewcommand{1}{1}
\]		
We can see that the equations $\nicefrac{\partial \textit{U}(p,q)}{\partial q}=0$ and $\nicefrac{\partial \textit{U}(p,q)}{\partial p}=0$ do not have solutions in $[0,1]$ for $p\leq \nicefrac{1}{4}$, 
while for $p> \nicefrac{1}{4}$ they have solution $p^*=q^*=\nicefrac{4}{7}$.
The pair $(p^*, q^*)$ thus constitutes the Nash equilibrium, and the corresponding payoff is $\textit{U}(p^*,q^*) = \nicefrac{5}{7}$.

\label{Theo:deterministic solution Game VI}
Consider an attacker-first sequential game with hidden choice.
\begin{description}
\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\setlength{\itemsep}{\wideitemsep}\item[1. Mixed strategies -- type $\mathbb{D}(\mathcal{A}\,{\rightarrow}\,\mathcal{D})$.] Let

We show that $(\delta^*,\alpha)$ where $\delta^*$ is uniform and $\alpha$ is
	arbitrary, is a saddle point of $\textit{U}(\delta,\alpha)$.
	The proof will rely on two crucial \emph{symmetries} of the password checker, in combination
	with the use of a uniform prior.
	Note that, under uniform $\pi$, the Bayes-vulnerability of a channel $C$
	is proportional to the sum of the column maxima of $C$, namely
	$\mathbb{V}\left[\pi,C\right] = \frac{1}{|\mathcal{X}|}\sum_y\max_x C(x,y)$.
	Given a permutation $\sigma$ of $\mathcal{X}$, define $C^\sigma$ as $C$ with its
	rows permuted, namely $C^\sigma(x,y) = C(\sigma(x),y)$.
	Note that $C^\sigma$ can be written as $M_\sigma C$
	where $M_\sigma$ is a permutation matrix.
	Permuting the rows
	does not affect the column maxima, hence $\mathbb{V}\left[\pi,C\right] = \mathbb{V}\left[\pi,C^\sigma\right]$.

	For the attacker things are simple, since we can show that under a uniform
	$\pi$ all attacker strategies are equivalent, that is,
	\[
		\textit{U}(\alpha,\delta) = \textit{U}(\alpha',\delta)
		\quad\text{for all } \alpha,\alpha',\delta
		~.
	\]
	To show this, we use the first important symmetry of the password checker, which
	is due to the fact that the output of the
	algorithm only depends on whether $x_i \neq a_i$ is true or false for each bit.
	Hence, any modification on $a$ can be matched with a modification on $x$ that preserves the output,
	namely for all $a,a'$ there exists a permutation $\sigma$ of passwords
	such that $C_{da} = C_{da'}^\sigma$ for all $d$.
	Denote $C_{\delta a} = {\osum_{d \leftarrow \delta}} C_{d a}$,
	we have that
	\[
		C_{\delta a}
		= {\osum_{d \leftarrow \delta}} C_{d a}
		= {\osum_{d \leftarrow \delta}} M_\sigma C_{d a'}
		= M_\sigma {\osum_{d \leftarrow \delta}} C_{d a'}
		= C_{\delta a'}^\sigma
	\]
	From $\mathbb{V}\left[\pi,C_{\delta a}\right] = \mathbb{V}\left[\pi,C_{\delta a'}^\sigma\right]$ we have that
	$\textit{U}(a,\delta) = \textit{U}(a',\delta)$ for all
	pure strategies $a,a'$, 
	which implies $\textit{U}(\alpha,\delta) = \textit{U}(\alpha',\delta)$
	since $\textit{U}(\alpha,\delta)$ is linear on $\alpha$.
	So in the remaining of the proof we assume that the attacker plays the fixed pure strategy
	$a_0$, having the zero bitstring $0..0$ as the low input.

	For the defender, on the other hand, the situation is far from trivial:
	although all \emph{pure} strategies $d$ are still equivalent,
	$\textit{U}(\alpha,\delta)$ is \emph{only convex} on $\delta$ and as a consequence the
	payoff highly depends on $\delta$.
	Our goal is to show that
	\[
	\textit{U}(a_0,\delta)
	= \frac{1}{|\mathcal{X}|}\sum_y\max_x \sum_d \delta(d) C_{da_0}(x,y)
	\]
	is minimized on the uniform $\delta^*$. To do so, we show something stronger, namely
	that \emph{each addend} of the $y$-sum is \emph{simultaneously} minimized on the uniform
	$\delta^*$. Fix an arbitrary $y$, and let
	\[
	f(\delta)
	= \max_x \delta \cdot \psi_x
	\]
	where $\cdot$ is the dot product and $\psi_x\in\mathbb{R}^{|\mathcal{D}|}$ is the vector defined by
	$\psi_x(d) = C_{da_0}(x,y)$.
	Note that, since $C_{da_0}$ is deterministic, all elements of $\psi_x$ are either $0$
	or $1$. Intuitively, $\psi_x(d)= 1$ if $x$ produces the fixed output $y$ when the
	bit checking order is $d$.

	We need to show that $f(\delta)$ is minimized on $\delta^*$.
	However, $f$ seen as a function on the whole $\mathbb{R}^{|\mathcal{D}|}$ has no global
	minimum. In our case, though, $\delta$ is a probability distribution
	taking values in $\mathbb{D}\mathcal{D}\subset \mathbb{R}^{|\mathcal{D}|}$. That is, only $|\mathcal{D}|-1$ elements
	of $\delta$ are free, so we can reduce the dimension by one as follows: fix some $d_0\in\mathcal{D}$ and let
	$\tilde\delta,\tilde\psi_x\in\mathbb{R}^{|\mathcal{D}|-1}$ be the same as 
	$\delta,\psi_x$ with the element corresponding to $d_0$ removed.
	We have that $\delta(d_0) = 1-\sum_{d\neq d_0}\delta(d) = 1 - \tilde\delta\cdot\mathbf{1}$,
	where $\mathbf{1}$ is the ``ones'' vector, hence we can rewrite $f(\delta)$ as a function
	of $\tilde\delta$:
	\begin{align*}
		           
		   
		f(\tilde\delta)
		&= \max_x \tilde\delta \cdot \tilde\psi_x + \delta(d_0)\psi_x(d_0)
			\\
		&= \max_x \tilde\delta \cdot \tilde\psi_x
		+ (1 - \tilde\delta\cdot\mathbf{1})\psi_x(d_0) 
			\\
		&= \max_x \tilde\delta \cdot (\tilde\psi_x - \psi_x(d_0)\mathbf{1}) + \psi_x(d_0)
	\end{align*}
	So it is sufficient to show that $f(\tilde\delta)$ is minimized on $\tilde\delta^*$.

	In the following, we use the fundamental concept of
	\emph{subgradients} from convex analysis, which generalize gradients for
	non-differentiable functions. A vector $v$ is a subgradient of
	a possibly non-differentiable convex function
	$g:S\to\mathbb{R}$
	at $x_0\in S$ iff
	\[
		g(x) - g(x_0) \ge v \cdot (x - x_0)
		\qquad \text{for all } x\in	S
		~.
	\]
	It is well-known that $g$ has
	a global minimum on $x_0$ iff the $\mathbf{0}$ vector belongs to the set of
	subgradients of $g$ at $x_0$ (this generalizes the fact that differentiable convex
	functions have zero gradient on their global minimum). Recall also that $g(x) = x\cdot v + c$
	has a single subgradient $v$, while for $g(x)=\max_i g_i(x)$, any subgradient
	of $g_i$ for \emph{any branch $i$} giving the max, is also a subgradient of $g$.
	Finally, the set of subgradients is convex, so any convex combination of them
	is also a subgradient.

	Hence, the subgradients of $f(\tilde\delta)$ are $\tilde\psi_x -
	\psi_x(d_0)\mathbf{1}$, for any $x$ giving the maximum, as well as their
	convex combinations. Our goal is to show that on $\tilde\delta^*$ these
	include the zero vector.

	We finally arrive to the second important symmetry of the password checker.
	Let $\rho$ be a permutation of the set $\{1,\ldots,n\}$ of password bits.
	Such a permutation could be seen both as a permutation on $\mathcal{X}$
	(i.e. $\rho(x) = x_{\rho(1)}.. x_{\rho(n)}$; note that $\rho(x)$ has the same
	number of $0$s and $1$s as $x$), as well as a permutation on
	$\mathcal{D}$ (a bit checking order $d$ is \emph{itself} a permutation of bits,
	so we can set $\rho(d) = \rho\circ d$).
	Since all low bits of $a_0$ are the same,
	applying $\rho$ to both $x$ and $d$ does not change the outcome of the
	algorithm, that is $C_{da_0} = C_{\rho(d)a_0}^\rho$.

	Intuitively, if $d$ is selected uniformly, then the attacker cannot
	distinguish $x$ from $\rho(x)$ since they
	produce the same output with the same probability.
	More concretely, 
	let $x\sim x'$ denote that $x' = \rho(x)$ for some bit permutation $\rho$.
	Due to the aforementioned symmetry we have that 
	$\psi_x$ and $\psi_{x'}$ have the same number of $1$s which means that
	$\delta^*\cdot\psi_x = \delta^*\cdot\psi_{x'}$.
	Now, let $x^* \in \mathrm{argmax}_x \delta^*\cdot\psi_x$.
	We have that \emph{all} $x\sim x^*$ also give the $\max$, hence all vectors
	\begin{equation}\label{eq-password-1}
	\tilde\psi_x -
		\psi_x(d_0)\mathbf{1}
		\qquad x\sim x^*
	\end{equation}
	are subgradients of $f$ on $\tilde\delta^*$.
	Finally, for any $d,d'$ there is a bit permutation $\rho$ such that
	$d' = \rho(d)$. Since $\psi_x(d) = \psi_{\rho(x)}(\rho(d))$ we have
	that
	$
		(\sum_{x\sim x^*} \psi_x)(d) = k
	$
	(for some integer $k$) independently from $d$.
	Hence, letting $c = |\{x\ |\ x\sim x^*\}|$ and averaging all subgradients of
	\eqref{eq-password-1} we get that
	\[
		\frac{1}{c}
		\sum_{x\sim x^*} \big(\tilde\psi_x -
			\psi_x(d_0)\mathbf{1}\big)
		= \frac{1}{c}(k\mathbf{1} - k\mathbf{1})
		= \mathbf{0}
	\]
	is also a subgradient, which concludes the proof.
