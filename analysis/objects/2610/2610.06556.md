<!-- theorem-1: body_md -->
\label{thm:thm1}
The inequality $\operatorname{prod-dim}(\mathcal{N}[G])\leq \operatorname{reg}(\mathfrak{B}_e(G))$ holds for every graph $G$.
<!-- end theorem-1 -->
<!-- theorem-2: body_md -->
\label{thm:thm2}
The equalities $\operatorname{prod-dim}(\mathcal{N}[G])=\operatorname{reg}(\mathfrak{B}_e(G))=\alpha(G)$ hold provided that $G$ belongs to any of the following classes:
\begin{enumerate}
\item  K{\"{o}}nig-Egerv{\'{a}}ry graphs (include all bipartite graphs) (Theorem~\ref{thm:konig_exact}),
\item cographs (Theorem~\ref{thm:cograph_exact}),
\item co-chordal graphs (Theorem~\ref{thm:cochordal_exact}),
\item chordal graphs (Theorem~\ref{thm:chordal_exact}),
\item comparability graphs (Theorem~\ref{thm:comparability}).
\end{enumerate}

<!-- remark-1: body_md -->
In an earlier unpublished work~\citep{BC-prod}, B{\i}y{\i}ko{\u{g}}lu and the first author have claimed~\citep[Theorem $3.23$]{BC-prod} that the equality $\operatorname{prod-dim}(\mathcal{N}[G])=\Gamma(G)$ holds for every graph $G$, where $\Gamma(G)$ denotes the upper domination number of $G$.  However, the proof of their result was dependent on~\citep[Theorem $5.4$]{ha-russ}, which was later shown to be wrong (compare to~\citep[Remark $8$]{Civan2022}). In particular, the equality $\operatorname{prod-dim}(\mathcal{N}[G])=\Gamma(G)$ does not need to hold as demonstrated by means of many examples in the present work.

If $G$ is a graph without any isolated vertex, then $\alpha(G)=\Gamma(G)=\operatorname{IR}(G)$ if one of the following holds:
\begin{itemize}
\item[$(1)$] $G$ is a strongly perfect graph~\textnormal{\citep[Theorem $2$]{Cheston1994}},

\item[$(2)$] $\operatorname{IR}(G)+\gamma(G)=|G|$~\textnormal{\citep[Theorem $2$]{Cockayne1981}}.
\end{itemize}

\textnormal{\cite{DHS-boundpd}}\label{cor:induction-sc}
Let $G$ be a graph and let $v\in V$ be given. Then
\begin{equation*}
\operatorname{reg} (G)\leq \max\{\operatorname{reg}(G-v), \operatorname{reg}(G-N_G[v])+1\}.

<!-- theorem-4: body_md -->
\label{thm:ineqs} The inequalities
\begin{displaymath}
\alpha(G)\leq \Gamma(G)\leq \operatorname{prod-dim}(\mathcal{N}[G])\leq \operatorname{reg}(\mathfrak{B}_{\operatorname{red}}(G))\leq \operatorname{reg}(\mathfrak{B}_e(G))\leq \operatorname{cochord}(\mathfrak{B}_e(G))
\end{displaymath}
hold for every graph $G$.
<!-- end theorem-4 -->
<!-- proof-1: body_md -->
As we have already mentioned, the first inequality is satisfied by any graph. Moreover, observe that the equality $i(\mathcal{N}[G])=|G|-\Gamma(G)$ holds for every graph $G$. Therefore, we conclude that $\Gamma(G)=|G|-i(\mathcal{N}[G])\leq \operatorname{prod-dim}(\mathcal{N}[G])$ by Corollary~\ref{cor:helly}.
		
Taking the equality $\operatorname{prod-dim}(\mathcal{N}[G])=\operatorname{prod-dim}(\mathcal{N}_{\operatorname{red}}[G])$ into account, the third inequality can be easily derived from~\citep[Theorem $3$]{yusuf} together with Fact~\ref{fact:inci-bip} and Terai's duality~\citep{Terai}. The fourth is due to the fact that $\mathfrak{B}_{\operatorname{red}}(G)$ is an induced subgraph of $\mathfrak{B}_e(G)$, and the last one follows from Lemma~\ref{lem:cochord}.

<!-- proposition-1: body_md -->
\label{prop:im-double}
$\operatorname{im}(\mathfrak{B}_e(G))=\operatorname{IR}(G)$ for every graph $G$.
<!-- end proposition-1 -->
<!-- proof-2: body_md -->
Let $U=\{u_1,\ldots,u_k\}$ be an irredundant set of maximum size in $G$. 
Therefore, there exists a vertex $v_j\in N_G[u_j]-N_G[U-\{u_j\}]$ for each $1\leq j\leq k$. However, this implies that the set $M(U):=\{u_1v'_1,\ldots,u_kv'_k\}$ is an induced matching in $\mathfrak{B}_e(G)$ so that $\operatorname{im}(\mathfrak{B}_e(G))\geq \operatorname{IR}(G)$. Conversely, suppose that $M=\{x_1y'_1,\ldots,x_py'_p\}$ be an induced matching in $\mathfrak{B}_e(G)$. Notice first that the vertices in $X(M):=\{x_1,\ldots,x_p\}$ must all be distinct. Since $y_i\in N_G[x_i]-N_G[X(M)-\{x_i\}]\neq \emptyset$ for each $1\leq i\leq p$, the set $X(M)$ is an irredundant set in $G$. This proves that $\operatorname{IR}(G)\geq \operatorname{im}(\mathfrak{B}_e(G))$.

<!-- definition-2: body_md -->
Let $G=(V,E)$ be a graph. The \emph{conflict-graph} $\mathcal{C}(G)$ of $G$ is defined to be the graph on the set $\{(u,v)\colon u,v\in V\;\textnormal{and}\;u\in N_G[v]\}$ of ordered pairs such that $(u,v)$ and $(x,y)$ form an edge if and only if $u\notin N_G[y]$ and $x\notin N_G[v]$.
<!-- end definition-2 -->
<!-- proposition-2: body_md -->
\label{prop:chi-cochord}
$\chi(\overline{G})\leq \chi(\mathcal{C}(G))\leq \operatorname{cochord}(\mathfrak{B}_e(G))$ for every graph $G$.
<!-- end proposition-2 -->
<!-- proof-3: body_md -->
The map $v\to (v,v)$ is an isomorphism of $\overline{G}$ onto a subgraph of $\mathcal{C}(G)$ induced by diagonal pairs $(v,v)$ for $v\in V$. Thus, $\chi(\overline{G})\leq \chi(\mathcal{C}(G))$.

For the second inequality, let $\mathcal{R}=\{R_1,\ldots,R_k\}$ be a co-chordal covering of $\mathfrak{B}_e(G)$. If we define $\kappa\colon V(\mathcal{C}(G))\to [k]$ by $\kappa((x,y)):=\min \{j\colon xy'\in R_j\}$, we claim that $\kappa$ is a proper coloring of $\mathcal{C}(G)$; hence, $\chi(\mathcal{C}(G))\leq \operatorname{cochord}(\mathfrak{B}_e(G))$.

Suppose that $((u,v),(x,y))\in E(\mathcal{C}(G))$ is an edge. Then by the definition, we have that $uy',xv'\notin E(\mathfrak{B}_e(G))$. It then follows that cross-edges $uv'$ and $xy'$ witness an induced $2K_2$ in $\mathfrak{B}_e(G)$. Therefore, no subgraph from the family $\mathcal{R}$ can contain both edges $uv'$ and $xy'$ at the same time. In other words, $\kappa((u,v))\neq \kappa((x,y))$ as claimed.
<!-- end proof-3 -->
<!-- theorem-5: body_md -->
For every integer $k\geq 3$, there exists a graph $G_k$ with $\operatorname{reg}(\mathfrak{B}_e(G_k))\leq 3$ and $\operatorname{cochord}(\mathfrak{B}_e(G_k))\geq k$.
<!-- end theorem-5 -->
<!-- proof-4: body_md -->
Let $H_k$ be a graph with $\operatorname{girth}(H_k)\geq 5$ and $\chi(H_k)\geq k$, and set $G_k:=\overline{H_k}$. By Proposition~\ref{prop:chi-cochord}, we immediately deduce that $\operatorname{cochord}(\mathfrak{B}_e(G_k))\geq k$. Thus we are left to prove that $\operatorname{reg}(\mathfrak{B}_e(G_k))\leq 3$. 
		
Let $A,B\subseteq V(G_k)=V(H_k)$ be two arbitrary subsets, and consider the induced bipartite graph $Q:=\mathfrak{B}_e(G_k)[A\cup B']$, where $B':=\{b'\colon b\in B\}$. We note that $ab'\notin E(Q)$ if and only if $a\in N_{H_k}(b)$. We next define a simplicial complex over $A$ by 
\begin{displaymath}
\Gamma_{A,B}:=\{\sigma\subseteq A\colon \exists b\in B\;\textnormal{such that}\;ab'\notin E(Q)\;\textnormal{for every}\;a\in \sigma\}.
\end{displaymath} 
By \citep[Theorem $3.1$]{jonsson}, we conclude that $\operatorname{Ind}(Q)\simeq \Sigma(\Gamma_{A,B})$, where $\Sigma(-)$ denotes the (unreduced) suspension. 
		
Since $H_k$ is $C_4$-free, we have that $|A\cap N_{H_k}(b)\cap N_{H_k}(c)|\leq 1$ for any $b,c\in B$. This in particular implies that any two facets of $\Gamma_{A,B}$ intersect in at most one vertex. However, it then follows that $\widetilde{H}_i(\Gamma_{A,B})=0$ for every $i\geq 2$; hence, $\widetilde{H}_j(\operatorname{Ind}(Q))=0$ for every $j\geq 3$. This proves that $\operatorname{reg}(\mathfrak{B}_e(G_k))\leq 3$.

<!-- definition-3: body_md -->
Let $G=(V,E)$ be a graph. A matching $M$ in $G$ is called an \emph{independent matching} if there exists a vertex $x_e\in e$ for each edge $e\in M$ such that the set $X_M:=\{x_e\colon e\in M\}$ is an independent set in $G$. The \emph{independent matching number} $\operatorname{m}_i(G)$ is defined to be the maximum size of an independent matching in $G$.

<!-- theorem-7: body_md -->
\label{thm:dom-mi}
For every graph $G$ without any isolated vertex, the inequality $\gamma(G)\leq \operatorname{m}_i(G)$ holds.
<!-- end theorem-7 -->
<!-- proof-6: body_md -->
Let $G=(V,E)$ be a graph without any isolated vertex. Let $I\subseteq V$ be a maximal independent set of $G$. We construct a bipartite spanning subgraph $B$ of $G$ whose edge set consists precisely of all edges in $E$ that have one endpoint in $I$ and the other in $V\setminus I$.
		
First, we show that $B$ contains no isolated vertices. 
For any $v\in I$, since $G$ has no isolated vertices and $I$ is an independent set, all neighbors of $v$ must belong to $V \setminus I$. Thus, every edge incident to $v$ in $G$ is preserved in $B$, that is, $v$ is not isolated in $B$. 
For any $v\in V\setminus I$, since $I$ is a maximal independent set, $v$ must be adjacent to at least one vertex in $I$. This edge is included in $B$, so $v$ is not isolated in $B$ either.
		
Let $M$ be a maximum matching in the bipartite graph $B$, and let $m=|M|$. By K\"onig's Theorem, $B$ admits a minimum vertex cover $C$ such that $|C|=m$. 
		
We claim that $C$ is a dominating set of $G$. Let $x\in V\setminus C$. Because $B$ has no isolated vertices, the vertex $x$ is incident to at least one edge $e\in E(B)$. Since $C$ is a vertex cover of $B$, it must cover the edge $e$, i.e., the other endpoint of $e$ belongs to $C$. Therefore, $x$ is adjacent to a vertex in $C$. This makes $C$ a dominating set of $B$, and since $B$ is a subgraph of $G$, the set $C$ is also a dominating set of $G$. Consequently, we have that $\gamma(G)\leq |C|=m$.
		
Finally, we show that $M$ is an independent matching in $G$. By the construction of $B$, every edge $e\in M$ has exactly one endpoint in $I$. For each $e\in M$, let $x_e$ be that specific endpoint. The set of representatives $X_M=\{x_e\colon e\in M\}$ is a subset of $I$. Since $I$ is an independent set in $G$, the set $X_M$ is also independent. However, it implies that $M$ is an independent matching. Therefore, the independent matching number $m_i(G)$ must be at least the size of $M$; hence, $m\leq m_i(G)$.
		
As a result, we conclude that $\gamma(G)\leq m\leq m_i(G)$ as claimed.
<!-- end proof-6 -->

<!-- corollary-4: body_md -->
\label{cor:dom-vc}
If $G$ is a graph with $\gamma(G)=\tau(G)$, then $\operatorname{prod-dim}(\mathcal{N}[G])=\operatorname{reg}(\mathfrak{B}_e(G))=\operatorname{cochord}(\mathfrak{B}_e(G))=\alpha(G)$.

\end{displaymath}
from which the result follows.

<!-- definition-4: body_md -->

<!-- end definition-4 -->
<!-- theorem-8: body_md -->
\label{thm:konig_exact}
If $G$ is a K{\"{o}}nig-Egerv{\'{a}}ry graph, then $\operatorname{prod-dim}(\mathcal{N}[G])=\operatorname{reg}(\mathfrak{B}_e(G))=\operatorname{cochord}(\mathfrak{B}_e(G))=\alpha(G)$.
<!-- end theorem-8 -->
<!-- proof-8: body_md -->
Let $S\subseteq V$ be a maximum independent set. Since $G$ is a K{\"{o}}nig-Egerv{\'{a}}ry graph, there exists a maximum matching
$M$ with $V(M)=X\cup Y$ such that $X\subseteq S$ and $Y\subseteq V\setminus S$ by~\citep{levit-2013}. However, this implies that $\operatorname{m}_i(G)=\operatorname{m}(G)$, since $S$ is an independent set. In particular, we have that $\alpha(G)=|G|-\operatorname{m}_i(G)$. By Theorems~\ref{thm:ineqs} and~\ref{thm:cd-mi}, we conclude that
\begin{align*}

\end{align*}
This establishes equality throughout.

<!-- proof-9: body_md -->
Let $G$ be a cograph. We prove that the inequality $\operatorname{cochord}(\mathfrak{B}_e(G))\leq \alpha(G)$  holds for any cograph by using the recursive construction of cographs together with induction.\medskip
		
{\em Base case}: If $G=K_1$, then $\alpha(K_1)=1$. The extended double cover $\mathfrak{B}_e(K_1)$ is a single edge $vv'$, which is trivially co-chordal, providing $\operatorname{cochord}(\mathfrak{B}_e(K_1))=1\leq \alpha(K_1)$.\medskip
		
{\em Inductive step} $1$ (the disjoint union): Suppose $G=G_1\cup G_2$ for some cographs $G_1$ and $G_2$. The independence number satisfies $\alpha(G)=\alpha(G_1)+\alpha(G_2)$. Because no edge exists between $G_1$ and $G_2$, the graph $\mathfrak{B}_e(G)$ is the disjoint union of $\mathfrak{B}_e(G_1)$ and $\mathfrak{B}_e(G_2)$. Taking the union of their respective co-chordal covers produces a cover of size $\alpha(G_1)+\alpha(G_2)$.\medskip
		
{\em Inductive step} $2$ (the join operation): Suppose $G=G_1\ast G_2$ for some cographs $G_1$ and $G_2$. We know that $\alpha(G)=\max(\alpha(G_1), \alpha(G_2))$. Assume without loss of generality that $k=\alpha(G_1)\geq \alpha(G_2)$. If $k=1$, the graph $G$ is a complete graph and $\mathfrak{B}_e(G)\cong K_{n,n}$, which is $2K_2$-free. 
		
For $k\geq 2$, let $\{S_1,\dots,S_k\}$ and $\{T_1,\dots,T_{\alpha(G_2)}\}$ be co-chordal covers of $\mathfrak{B}_e(G_1)$ and $\mathfrak{B}_e(G_2)$ respectively. For each $j>\alpha(G_2)$, we set $T_j=\emptyset$. We partition the set of bipartite cross-edges $E_{\textnormal{cross}}$ of $\mathfrak{B}_e(G)$ directionally:
\begin{displaymath}
E_{G_1,G_2}=\{uv'\mid u \in V(G_1), v\in V(G_2)\}, \quad E_{G_2,G_1}=\{ vu'\mid v \in V(G_2), u\in V(G_1)\}.
\end{displaymath}

We next define $k$ subgraphs $U_1,\dots,U_k$ by setting $U_1:=S_1\cup T_1\cup E_{G_1,G_2}$, $U_2:=S_2\cup T_2\cup E_{G_2,G_1}$, and $U_i:= S_i\cup T_i\cup E_{G_1,G_2}$ for $i \geq 3$. 
		
We now show that each subgraph $U_i$ is co-chordal, i.e., no induced $2K_2$ can be sustained within any $U_i$. Let $e_1,e_2\in U_1$. Since $S_1$ and $T_1$ are $2K_2$ free, there are four possibilities of an induced copy of $2K_2$:
\begin{enumerate}
\item $e_1=uu_1^\prime \in S_1$ and $e_2=vv_1^\prime \in T_1$. In this case, we have $uv_1^\prime \in E_{G_1,G_2} \subseteq U_1$. Hence, $e_1, e_2$ can not induce $2K_2$.
			
\item $e_1=uu_1^\prime \in S_1$ and $e_2=u_2v^\prime \in E_{G_1,G_2}$. In this case, we have $uv^\prime \in E_{G_1,G_2} \subseteq U_1$. Hence, $e_1, e_2$ can not induce $2K_2$.
			
\item $e_1=vv_1^\prime \in T_1$ and $e_2=uv^\prime \in E_{G_1,G_2}$. In this case, we have $uv_1^\prime \in E_{G_1,G_2} \subseteq U_1$. Hence, $e_1, e_2$ can not induce $2K_2$.
			
\item $e_1=u_1v_1^\prime, e_2=u_2v_2^\prime \in E_{G_1,G_2}$. In this case, we have $u_1v_2^\prime \in E_{G_1,G_2} \subseteq U_1$. Hence, $e_1, e_2$ can not induce $2K_2$.
\end{enumerate}
A similar argument applies to show that $U_i$ is co-chordal for any $i\geq 2$. This in particular implies that $\operatorname{cochord}(\mathfrak{B}_e(G))\leq \alpha(G)$ by the induction.

As a result we conclude that 
\begin{align*}
\alpha(G)\leq \operatorname{prod-dim}(\mathcal{N}[G])\leq \operatorname{reg}(\mathfrak{B}_e(G))\leq \operatorname{cochord}(\mathfrak{B}_e(G))\leq \alpha(G)
\end{align*}
by Theorem~\ref{thm:ineqs}. This completes the proof.

<!-- theorem-11: body_md -->
\label{thm:chordal_exact}
For every chordal graph $G$, the equalities
\begin{displaymath}
\operatorname{prod-dim}(\mathcal{N}[G])=\operatorname{reg}(\mathfrak{B}_e(G))=\operatorname{cochord}(\mathfrak{B}_e(G))=\alpha(G)
\end{displaymath}
hold.
<!-- end theorem-11 -->
<!-- proof-12: body_md -->
Let $G=(V,E)$ be a chordal graph, and let $v_1<_{\textnormal{PEO}}v_2<_{\textnormal{PEO}}\dots<_{\textnormal{PEO}}v_n$ be a perfect elimination ordering of $G$. 
		
We construct a maximal independent set $I$ greedily along the $\textnormal{PEO}$ by iterating through the vertices from $v_1$ to $v_n$, and adding a vertex to $I$ if it is not adjacent to any previously selected vertex in $I$. Since $G$ is chordal, this greedy approach gives a maximum independent set, that is, $|I|=\alpha(G)=k$. 
Let $I=\{x_1,\dots,x_k\}$.
		
For every vertex $v\in V$, let $f(v)$ be the \textit{earliest} vertex in $I$ (with respect to the $\textnormal{PEO}$) that is in the closed neighborhood $N_G[v]$. Since $I$ is a maximal independent set, $N_G[v]\cap I\neq\emptyset$, making $f(v)$ well-defined for all vertices. 

We partition the vertex set $V$ into $k$ sets $Q_1,\dots,Q_k$, defined by 
$Q_i:=\{v\in V\colon f(v)=x_i\}$.\medskip 
		
{\em Claim} $1$: Every $Q_i$ is a clique in $G$.\medskip

{\em Proof of Claim} $1$: Let $u\in Q_i$. By the definition, $u\in N_G[x_i]$. Suppose, for a contradiction, that $u$ appears before $x_i$ in the $\textnormal{PEO}$ ($u<_{\textnormal{PEO}} x_i$). When the greedy algorithm processed $u$, it did not add $u$ to $I$ (since $u\neq x_i$). This implies $u$ was adjacent to some $x_j\in I$ that appeared before $u$. However, this means $x_j\in N_G[u]$ and $x_j<_{\textnormal{PEO}} u<_{\textnormal{PEO}} x_i$, which contradicts to $f(u)=x_i$. Therefore, every vertex $u\in Q_i$ must appear at or after $x_i$ in the $\textnormal{PEO}$. Since all vertices in $Q_i$ appear at or after $x_i$ and are adjacent to $x_i$, they form a subset of the closed forward neighborhood of $x_i$. By the fundamental property of a $\textnormal{PEO}$, the closed forward neighborhood of any vertex induces a clique. Thus, $Q_i$ is a clique as claimed.\medskip
		
{\em Claim} $2$: The graph $\mathfrak{B}_e(G)$ can be partitioned into $k$ co-chordal subgraphs.\medskip

{\em Proof of Claim} $2$: We partition the edges of $\mathfrak{B}_e(G)$ into $k$ subgraphs $S_1,\dots,S_k$ using the following assignment rules:
\begin{enumerate}
\item For any vertex $v \in V$, assign the edge $vv'$ to $S_{f(v)}$.
\item For any edge $uv \in E(G)$, exactly one of $u<_{\textnormal{PEO}} v$ or $v <_{\textnormal{PEO}} u$ holds. Assume $u<_{\textnormal{PEO}} v$. We assign both corresponding cross-edges, $uv'$ and $vu'$, to $S_{f(u)}$. 
\end{enumerate}
This partitions the edges of $\mathfrak{B}_e(G)$. We now prove that each $S_i$ is $2K_2$-free. 
		
Let $e_1=ab'$ and $e_2=cd'$ be any two edges in $S_i$. By our assignment rules, there exists a vertex $u_1\in \{a,b\}$ such that $u_1\in Q_i$ and $u_1 \leq_{\textnormal{PEO}} a,b$ (if $a=b$, then $u_1=a$). Similarly, there exists a vertex $u_2\in \{c,d\}$ such that $u_2\in Q_i$ and $u_2 \leq_{\textnormal{PEO}} c,d$. 
		
Since $Q_i$ is a clique, it follows that $u_1\in N_G[u_2]$. Without loss of generality, we may assume  that $u_1\leq_{\textnormal{PEO}} u_2$. 
By the definition of a $\textnormal{PEO}$, the closed forward neighborhood of $u_1$ forms a clique. Since $u_1\leq_{\textnormal{PEO}} a$ and $u_1\leq_{\textnormal{PEO}} b$ (and $u_1\in \{a,b\}$), both $a$ and $b$ belong to the closed forward neighborhood of $u_1$. Furthermore, since $u_1 \leq_{\textnormal{PEO}} u_2$ and $u_1\in N_G[u_2]$, the vertex $u_2$ also belongs to the closed forward neighborhood of $u_1$. 
		
Consequently, the set of vertices $\{a,b,u_2\}$ must induce a clique in $G$. Since $u_2\in \{c,d\}$, we have two cases to analyze.\medskip

{\em Case} $1$: $u_2=c$. Then the set $\{a,b,c\}$ is a clique so that $c\in N_G[b]$. By the definition of $\mathfrak{B}_e(G)$, we conclude that $cb'\in E(\mathfrak{B}_e(G))$.\medskip

{\em Case} $2$: $u_2=d$. Then the set $\{a,b,d\}$ is a clique so that $d \in N_G[a]$. Once again, by the definition of $\mathfrak{B}_e(G)$, we obtain that $ad'\in E(\mathfrak{B}_e(G))$.

In all possible cases, there exists an edge between $\{a,b'\}$ and $\{c,d'\}$ in $\mathfrak{B}_e(G)$. Therefore, $e_1$ and $e_2$ cannot form an induced $2K_2$. 
		
Since every $S_i$ is $2K_2$-free, the graph $\mathfrak{B}_e(G)$ is covered by $k=\alpha(G)$ co-chordal subgraphs, proving that $\operatorname{cochord}(\mathfrak{B}_e(G))\leq \alpha(G)$. This completes the proof by Theorem~\ref{thm:ineqs}.

<!-- theorem-12: body_md -->
\label{thm:comparability}
For every comparability graph $G$, the equalities
\begin{displaymath}
\operatorname{prod-dim}(\mathcal{N}[G])=\operatorname{reg}(\mathfrak{B}_e(G))=\operatorname{cochord}(\mathfrak{B}_e(G))=\alpha(G)
\end{displaymath}
hold.
<!-- end theorem-12 -->
<!-- proof-13: body_md -->
Let $P=(V,\leq)$ be a poset (partially ordered set) whose comparability graph is $G$. Since the independent sets of $G$ correspond to the anti-chains of $P$, 
the width of $P$ is $k=\alpha(G)$. Recall that the bipartite graph $\mathfrak{B}_e(G)$ has bipartition $V\cup V'$ such that
\begin{displaymath}
xy'\in E(\mathfrak{B}_e(G)) \quad\Longleftrightarrow\quad x\leq y\;\textnormal{or}\;y\leq x.
\end{displaymath}
By Dilworth's theorem, the associated poset $P$ can be partitioned $V=C_1\cup\cdots \cup C_k$ into $k$ chains of $P$. For each $i\in [k]$, we define
a spanning subgraph $H_i$ of $\mathfrak{B}_e(G)$ by
\begin{displaymath}
E(H_i)=\bigcup_{\substack{c\in C_i,\ x\in V\\ c\leq x}}\{cx',\ xc'\}.
\end{displaymath}
We claim first that these subgraphs cover $E(\mathfrak{B}_e(G))$. Indeed, for any edge
$xy'$, vertices $x$ and $y$ are comparable in $P$, say $x\leq y$. Then, if $x\in C_i$, we conclude that $xy'\in E(H_i)$. Furthermore, observe that $E(H_i)$ also contains the diagonal edge $xx'$ for every vertex $x\in V$.

We next claim that every $H_i$ is a co-chordal graph. Let $i\in [k]$ be given, and write $C=C_i$. Consider two vertex-disjoint edges of $H_i$.
There are three cases to separate.

\begin{enumerate}
\item The edges have the form $cx'$ and $dy'$, where $c,d\in C$, $c\leq x$, and $d\leq y$ in $P$. Since $C$ is a chain, after interchanging the edges if
necessary, we may assume $c\leq d$. Then, $c\leq d\leq y$ so that $cy'\in E(H_i)$.

\item The edges have the form $xc'$ and $yd'$, where $c,d\in C$, $c\leq x$, and $d\leq y$ in $P$. Once again, assume $c\leq d$. Then $c\leq d\leq y$, so
$yc'\in E(H_i)$.

\item The edges have the form $cx'$ and $yd'$, where $c,d\in C$, $c\leq x$, and $d\leq y$ in $P$. Since $c$ and $d$ lie in the same chain, either
$c\leq d$ or $d\leq c$. In either case, the definition of $H_i$ implies that $cd'\in E(H_i)$.
\end{enumerate}

Therefore, in every case, a cross-edge prevents the two edges from inducing a $2K_2$ in $H_i$ as claimed.
 
As a consequence, we obtain that
\begin{displaymath}
\operatorname{cochord}(\mathfrak{B}_e(G))\leq k=\alpha(G).
\end{displaymath}
Now, the result follows from Theorem~\ref{thm:ineqs}.

<!-- lemma-3: body_md -->
\label{lem:bisimplicial}
Let $B=(X,Y;E)$ be a bipartite graph. If $e=xy$ is a bisimplicial edge of $B$, then
\begin{displaymath}
\operatorname{reg}(B)=\max \{\operatorname{reg}(B-\{x,y\}), \operatorname{reg}(B-N_B[e])+1\}.
\end{displaymath}
<!-- end lemma-3 -->
<!-- proof-14: body_md -->
Since $e=xy$ is bisimplicial, we observe that
\begin{align*}
&\operatorname{Ind}(B)=(x\ast \operatorname{Ind}(B-N_B[x]))\cup (y\ast \operatorname{Ind}(B-N_B[y]))\\
&\textnormal{and}\\
&(x\ast \operatorname{Ind}(B-N_B[x]))\cap (y\ast \operatorname{Ind}(B-N_B[y]))=\operatorname{Ind}(B-N_B[e]),
\end{align*}
where $z\ast \Delta$ denotes the cone of a simplicial complex $\Delta$ with apex $z$. Indeed, let $S$ be an independent set in $B$. If $S$ contains $x$ or $y$, then it belongs to the corresponding cone complex. Otherwise, it can not intersect both $N_B(x)\setminus \{y\}$ and $N_B(y)\setminus \{x\}$, since $e=xy$ is bisimplicial. If it avoids $N_B(x)\setminus \{y\}$, then $S\cup \{y\}$ is an independent set in $B$. Similarly, if it avoids $N_B(y)\setminus \{x\}$, then $S\cup \{x\}$ is an independent set in $B$. This proves the union equality, and a similar argument applies to the intersection. 
		
Recall that $\operatorname{reg}(z\ast \Delta)=\operatorname{reg}(\Delta)$ for any simplicial complex $\Delta$. Since $\operatorname{Ind}(B-N_B[x])$ and $\operatorname{Ind}(B-N_B[y])$ are induced subcomplexes of $\operatorname{Ind}(B-\{x,y\})$, we conclude that
\begin{displaymath}
\max\{\operatorname{reg}(\operatorname{Ind}(B-N_B[x])),\operatorname{reg}(\operatorname{Ind}(B-N_B[y]))\}\leq \operatorname{reg}(\operatorname{Ind}(B-\{x,y\})).
\end{displaymath}
Therefore, by Proposition~\ref{prop:reg-union}, the following inequalities
\begin{align*}
\operatorname{reg}(B)&\leq \max\{\operatorname{reg}(B-N_B[x]), \operatorname{reg}(B-N_B[y]), \operatorname{reg}(B-N_B[e])+1\}\\
&\leq \max \{\operatorname{reg}(B-\{x,y\}), \operatorname{reg}(B-N_B[e])+1\}
\end{align*}
hold.	
		
For the converse, we note that if we write $R:=V((B-N_B[e]))\cup \{x,y\}$, then $B[R]\cong (B-N_B[e])\cup K_2$ is an induced subgraph of $B$; hence, $\operatorname{reg}(B[R])=\operatorname{reg}(B-N_B[e])+1\leq \operatorname{reg}(B)$. Similarly, since $B-\{x,y\}$ is also an induced subgraph of $B$, we obtain that 
\begin{displaymath}
\operatorname{reg}(B)\geq \max \{\operatorname{reg}(B-\{x,y\}), \operatorname{reg}(B-N_B[e])+1\},
\end{displaymath}
which completes the proof.

\alpha(G)=\Gamma(G)=\operatorname{IR}(G)=\operatorname{im}(\mathfrak{B}_e(G))\leq \operatorname{prod-dim}(\mathcal{N}[G])\leq \operatorname{reg}(\mathfrak{B}_e(G))
\end{displaymath}
hold for a chordal graph $G$ by Theorems~\ref{thm:dom-eq} and~\ref{thm:ineqs}. Now, let $v$ be a simplicial vertex of $G$. By Corollary~\ref{cor:simplicial} together with an induction, we conclude that
\begin{align*}
\operatorname{reg}(\mathfrak{B}_e(G))&=\max \{\operatorname{reg}(\mathfrak{B}_e(G-v)),\operatorname{reg}(\mathfrak{B}_e(G-N_G[v]))+1\},\\
&\leq \max \{\alpha(G-v),\alpha(G-N_G[v])+1\},\\
&\leq \alpha(G).
\end{align*}
