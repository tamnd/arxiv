<!-- theorem-1: body_md -->
\label{standard action}  Let $G$ be a nontrivial compact Lie group.  Then there is a based-free $G$-\ensuremath{\mathsf{AR}}\ action of $G$ on each Keller space.
<!-- end theorem-1 -->
<!-- proof-1: body_md -->
Since $G$ is a smooth manifold, it is homeomorphic to a finite
simplicial complex \cite{whitehead}.  The cone $C(G)$ is then homeomorphic to a finite contractible simplicial
complex.  Set $Q(G) = C(G)^{\infty}$.  By \cite{West70} $C(G)$ is a Hilbert cube factor and $Q(G)$ is a Hilbert
cube.  Let $G$ act by left translation on $C(G)$ and
$\alpha$ be the diagonal action on $Q(G)$.  It is immediate from the cone structure that $Q(G)$ is a $G$-\ensuremath{\mathsf{ANR}}.
<!-- end proof-1 -->
<!-- theorem-2: body_md -->
\label{point} Let $G$ be a nontrivial compact group.
If there is a nontrivial semifree $G$-action $\alpha$ of $G$
                               
on a compact
          
Q-manifold then $G$
acts based-freely on all Keller spaces with arbitrary fixed points; if $\alpha$ is a $G$-\ensuremath{\mathsf{ANR}}\ action, then $G$
acts based-freely on all Keller spaces with $G$-\ensuremath{\mathsf{AR}}\ actions.
<!-- end theorem-2 -->
<!-- proof-2: body_md -->
Let $\alpha$ denote a semifree action of $G$ on a compact $Q$-manifold $M$ with
fixed point set $A \neq M$.  If $A =\emptyset$ then the induced action on the cone $C(M)$ of $M$ is a based-free action on an \ensuremath{\mathsf{AR}}\ so as observed below the diagonal action on the Hilbert cube $C(M)^{\infty}$ is based-free.
If $A \neq \emptyset$ then the product action $\beta = \alpha \times {\ensuremath{{\mathop{\operator@font id}\nolimits}}_\mathbb{I}}
$ of $G$ on $M\times \mathbb{I}$ has fixed point
set $A \times \mathbb{I}$.  Therefore it induces a based-free action $\gamma$ on the quotient
space
$X = M \times \mathbb{I} /((A\times \mathbb{I}) \cup (M \times \{1\}))$.
 To see that $X$ is an \ensuremath{\mathsf{AR}}\ we first collapse $M\times \{1\}$ to a single point $v$, thus obtaining
 the cone $C(M)$. This cone is an \ensuremath{\mathsf{AR}}\ by \cite[5.4.2]{vm:book}, \cite[6.5.7]{Sakai13}.  Let
 $k:C(M)\to X$ collapse $C(A)$ to the image $\ast$ of
 $(A\times \mathbb{I}) \cup (M \times \{1\})$.  For a map $\phi:M\to \mathbb{I}$ such that
 $\phi^{-1}(1) = A$, the function $k(x,t) = (x,s)$ where $s = \min\{t,\phi(x)\}$ embeds $X$ in $C(M)$ as a retract so it is an \ensuremath{\mathsf{AR}}.

By Edwards' Theorem (see Section \ref{infdim}), $X\times Q \approx Q$, so by \cite[Theorem 6.2]{West70}, $X^{\infty}\approx Q$.

The diagonal action of $\gamma$ is based-free.  Since all Keller spaces are homeomorphic to
$Q$ and homogeneous, the result follows.
If $\alpha$ is a G-\ensuremath{\mathsf{ANR}}\ action, so is $\beta$ and then $\gamma$ is a $G$-\ensuremath{\mathsf{AR}}\ action (by the
same argument given above for $X$ and the trivial action) and so is its diagonal action.
<!-- end proof-2 -->
<!-- theorem-3: body_md -->
\label{derdestelling}
If the compact group $G$ acts based-freely on $Q$, there is a based-free action of $G$ on $Q$ arbitrarily close
to the trivial action.
<!-- end theorem-3 -->
<!-- proof-3: body_md -->
Our actions will be defined on $C(Q)$.

To begin with, factor $Q$ as $\mathbb{J}^n\times Q_n$. Fix a based-free action $\sigma_n$ of $G$ on
$Q_n$.  By homogeneity of $Q_n$, we may assume that $\mathop{\operator@font Fix}\nolimits(\sigma_n) = \{\overline 0\}$.
Define an action $\alpha_n :  G\times Q\to Q$ by $\alpha_n(g,(x,y)) = (x,\sigma_n(g,y))$.
Then $\mathop{\operator@font Fix}\nolimits(\alpha_n)$ is the Z-set  $J^n\times \{\overline 0\}$, and $\ensuremath{{\mathop{\operator@font disp}\nolimits}}(\alpha_n)\le 2^{-n}$. By a shrinking argument with attention to orbit sizes,
we will shrink for sufficiently large $n$, $\mathop{\operator@font Fix}\nolimits(\alpha_n)$ to a point. Our use of cones simplifies the technical
details of the construction.

So now let Let $0 < \varepsilon \le 1$, and fix $n_0$ with $2^{-n_0} < \frac{\varepsilon}{4}$. Consider the cone $C(Q)=Q\times_c [0,1]$. Define $\hat
\alpha_{n_0} :  G\times C(Q)\to C(Q)$ by $\hat\alpha_{n_0}(g,(x,t)) = (\alpha_{n_0}(g,x),t)$, and put
$F=\mathop{\operator@font Fix}\nolimits(\alpha_{n_0})$. Then
$\ensuremath{{\mathop{\operator@font disp}\nolimits}}(\hat\alpha_{n_0})=\ensuremath{{\mathop{\operator@font disp}\nolimits}}(\alpha_{n_0}) <
\frac{\varepsilon}{4}$, and $\mathop{\operator@font Fix}\nolimits(\hat\alpha_{n_0}) = F \times_c [0,1]$. Clearly, $\mathop{\operator@font Fix}\nolimits(\hat\alpha_{n_0})$ is a
Z-set in $C(Q)$. Indeed, $F \times [0,1{-}\frac{1}{n}]$ is a Z-set in $C(Q)$ for every $n$, \cite[7.2.5]
{vm:book}, and so is the vertex of the cone, hence $\mathop{\operator@font Fix}\nolimits(\hat\alpha_{n_0})$ is a  closed countable union of
Z-sets, thus a Z-set.

Consider the set $\hat F = F \times_c [\delta,1]$, where $0<\delta<\frac{1}{2}$ is so small that the
homeomorphism $F \times_c [0,1]\to F \times_c [\delta,1]=\hat F$ defined by $(x,t) \mapsto (x,(1{-}\delta) t{+}
\delta)$ can be extended to a homeomorphism $f$ of $C(Q)$ such that $\ensuremath{{\mathop{\operator@font disp}\nolimits}}(f) < \frac{\varepsilon}{8}$,
\cite[11.1]{chapman:lectures}. As in Section \ref{preliminaries}, let $\check f = \ensuremath{{\mathop{\operator@font id}\nolimits}}_G\times f$, and set $\beta = f\circ \hat\alpha_{n_0} \circ \check f^{-1}$.
Then, $\mathop{\operator@font Fix}\nolimits(\beta) = \hat F$, and
$$
    \ensuremath{{\mathop{\operator@font disp}\nolimits}}(\beta) \le 2\ensuremath{{\mathop{\operator@font disp}\nolimits}}(f) + \ensuremath{{\mathop{\operator@font disp}\nolimits}}(\hat\alpha_{n_0}) < 2 \textstyle\frac{\varepsilon}{8} + \textstyle\frac{\varepsilon}{4}=\textstyle\frac{\varepsilon}{2}.
$$
Using the Venetian Blind Lemma~\ref{JimLemma03}, one may shrink $\hat F$ to the vertex of $C(Q)$ while maintaining control over the sizes of the orbits, i.e., construct a map $\zeta :  C(Q)\to C(Q)$ such that
\begin{enumerate}
\item $\zeta^{-1}(\star) = \hat F$,
\item $\hat F$ is the only non-degenerate point inverse of $\zeta$, and
\item for each $x\in C(Q)$ and $g\in G$, $\varrho(\zeta(x),\zeta(\beta(g,x)) < \frac{\varepsilon}{2} + \ensuremath{{\mathop{\operator@font disp}\nolimits}}(\beta) = \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon$.
\end{enumerate}
Then with $\check \zeta=\ensuremath{{\mathop{\operator@font id}\nolimits}}_G\times \zeta$, $\gamma = \zeta \circ \beta \circ \check \zeta^{-1}$ is a
based-free $G$-action on $C(Q)$ with unique fixed point $\star$ and displacement less than $\varepsilon$.
<!-- end proof-3 -->
<!-- lemma-1: body_md -->
\label{preJimLemma03}
For every $0 < \nu < d < 1$, there is a map $h :  C(Q)\to C(Q)$ such that
\begin{enumerate}
\item $h^{-1}(\star) = F\times_c [d,1]$,
\item $F\times_c [d,1]$ is the only non-degenerate point inverse of $h$,
\item $h$ is supported on $Q\times_c [\nu,1]$, and
\item for each $x\in Q\times_c [\nu,1]$ and $g\in G$, $\varrho(h(x),h(\beta(g,x)) < \frac{\mu}{2}$.\label{devierdepre}
\end{enumerate}
<!-- end lemma-1 -->
<!-- proof-4: body_md -->
Let $f :  [0,1] \to [0,1]$ be the piecewise linear map that is the identity on $[0,\nu]$, sends $[\nu,d]$ onto $[\nu,1]$
and collapses $[d,1]$ to 1.
Let $H :  [0,1]\times [0,1]\to [0,1]$ be defined by $H_s(t) = (1{-}s) t + s f(t)$. Then $H_0$ is the identity,
$H_1 = f$, and each $H_s$ for $s < 1$ is a homeomorphism, being the sum of two increasing functions, one
of them strictly increasing. Let $\phi :  Q\to [0,1]$ be continuous with $\phi^{-1}(1) = F$. Now
define $h$ by $h(x,t) =
(x,H_{\phi(x)}(t))$. We clearly only need to check (\ref{devierdepre}). So, let $x\in Q\times_c [\nu,1]$. Since
$h(x) \in Q\times_c [\nu,1]$,
$\varrho(x,h(x))< \frac{\mu}{8}$.
If $\beta(g,x)\not\in Q\times_c[\nu,1]$, then $\varrho(\beta(g,x),h(\beta(g,x))=0$. And if $\beta(g,x)\in
Q\times_c[\nu,1]$ then, by what we just observed, $\varrho(\beta(g,x),h(\beta(g,x)) < \frac{\mu}{8}$. In
either case,
$$
    \varrho(h(x), h(\beta(g,x)) \le \varrho(h(x),x) + \varrho(x,\beta(g,x)) + \varrho(\beta(g,x), h(\beta(g,x)))
    <\textstyle\frac{3\mu}{8}.\qedhere
$$

<!-- lemma-2: body_md -->
\label{JimLemma03}
There is a map $\zeta :  C(Q)\to C(Q)$ such that
\begin{enumerate}
\item $\zeta^{-1}(\star) = \hat F$,
\item $\hat F$ is the only non-degenerate point inverse of $\zeta$, and
\item for each $x\in C(Q)$ and $g\in G$, $\varrho(\zeta(x),\zeta(\beta(g,x))) < \mu + \ensuremath{{\mathop{\operator@font disp}\nolimits}}(\beta)$.
\end{enumerate}

\item $h_1(F\times [\delta,\frac{k+2}{m}]) = F\times [\frac{k+1}{m},\frac{k+2}{m}])$, and for $i > 1$,\\ $h_{i}(F\times [\frac{k+i-1}{m},\frac{k+i+1}{m}]) = F\times [\frac{k+i}{m},\frac{k+i+1}{m}],$

      $
      \ensuremath{{\mathop{\operator@font diam}\nolimits}}_{\varrho} (\gamma_{i-1}\circ\beta\circ\check\gamma_{i-1}^{-1}(G\times\{x\}))< \textstyle\frac{1}{2}\mu

The first and the last statements in the theorem are consequences of
Theorem~\ref{TheoremOnIsotopiesSpecialCase} and the homogeneity of $Q$. So we are left with the $

Let $\mathscr{H}(Q)$ denote the group of all homeomorphisms of $Q$ endowed with the usual compact-open
topology. For every $p\in Q$, let $\gamma_p :  \mathscr{H}(Q)\to Q$ be the evaluation at $p$. That is, $
\gamma_p(f) = f(p)$ for $f\in \mathscr{H}(Q)$. Since $Q$ is homogeneous by Keller~\cite{keller}, the celebrated
Effros Theorem from~\cite{effros} implies that $\gamma_p$ is an open continuous surjection for every $p$ (see
also~\cite{noteeffros}).

Consider the point $\overline 0$ in $Q$.  By~\cite[2.10; Proposition 18]{bourbaki61}, there is a compact subset
$L$ of $\mathscr{H}(Q)$ such that $\gamma_{\overline 0}(L) = Q$ (the existence of such an $L$ is the main
tool in~\cite{hohti}). Put $K = L^{-1}$, and observe that for every $x\in Q$ there exists $f\in K$ such that $f(x) =
\overline 0$. Since $\mathscr{H}(Q)$ is contractible (essentially due to Wong~\cite{Wong67}, see
also~\cite{Torunczyk77} and~\cite{Ferry77}), there is a homotopy $H :  \mathscr{H}(Q)\times [0,1]\to
\mathscr{H}(Q)$ such that $H_0 = \ensuremath{{\mathop{\operator@font id}\nolimits}}_{\mathscr{H}(Q)}$ and $H_1 = \ensuremath{{\mathop{\operator@font id}\nolimits}}_Q$. Let $K'$ be the compact set
$H(K\times [0,1])$ of $\mathscr{H}(Q)$.

Let $\varepsilon > 0$. By compactness of $K'$ there is $\delta > 0$ such that for all $x,y\in Q$ with $d(x,y) <
\delta$, $d(f(x),f(y)) < \varepsilon$ for each $f\in K'$.

 Now let $G$ be a compact group which acts based-freely on $Q$ by the action $\beta :  G\times Q \to Q$,
 such that $\mathop{\operator@font Fix}\nolimits(\beta)=\{y\}$ and $\ensuremath{{\mathop{\operator@font disp}\nolimits}}(\beta) < \delta$. Pick $f\in K$ such that $f(y) = \overline 0$. Define an isotopy $S :  Q\times [0,1]\to Q$ by $S_t = H_{1-t}(f)$. Then $S_0 = \ensuremath{{\mathop{\operator@font id}\nolimits}}_Q$ and $S_1 = f$. For every
 $t\in [0,1]$, define an action $\gamma_t :  G\times Q\to Q$ by $\gamma_t(g,x) = S_t ( \beta(g,S_t^{-1}(x)))$.
 Then $\gamma_0 = \beta$, and each $\gamma_t$ is a based-free $G$-action with fixed point set $\{S_t(y)\}$.
 Hence $\gamma_1$ is a a based-free $G$-action with fixed point set $\{S_1(y)\} = \{f(y)\} = \{\overline 0\}$. We
 check the displacements of the various $\gamma_t$'s.

To this end, fix $t\in [0,1]$, $x\in Q$, and $g\in G$. We compare $S_t \circ \beta(g,S_t^{-1}(x))$ and $x = S_t
(S_t^{-1}(x))$. Now by assumption,
$$
    d(\beta(g,S_t^{-1}(x)), S_t^{-1}(x)) \le \ensuremath{{\mathop{\operator@font disp}\nolimits}}(\beta) < \delta,
$$
and so
$$
    d(S_t(\beta(g,S_t^{-1}(x)), S_t(S_t^{-1}(x)))<\varepsilon.
$$
Hence the displacements of the $\gamma_t$'s does not exceed $\varepsilon$. Since our choice of $\delta> 0$
does not depend on $\beta$, we are done by applying the special case
Theorem~\ref{TheoremOnIsotopiesSpecialCase}.

\label{acyclicANR}
Let $G$ be a nontrivial compact Lie group.
If $A$ is an acyclic compact
\ensuremath{\mathsf{ANR}}\ embedded in $Q$ as a Z-set, then $A$ is the fixed point set of a semifree \ensuremath{\mathsf{ANR}}\ action $\alpha$ of $G$ on $Q$.
<!-- end theorem-6 -->
<!-- proof-11: body_md -->
Let $Y = A\ast G$ and denote by $A'$ the image of $A\times \{-1\} \times G$ in $Y$.  It suffices to prove that $Y \in \ensuremath{\mathsf{AR}}\ $ since then

\begin{enumerate}

\item $A'$ is the fixed point set of the semifree \ensuremath{\mathsf{ANR}}\ action $\beta = \ensuremath{{\mathop{\operator@font id}\nolimits}} \ast \beta'$ on $Y$, where
$\beta'$ is the left translation action of $G$ on itself;

\item $A'\times \{v\}$ is the fixed point set of the diagonal action $\gamma = \beta \times \alpha_G$ on
$Y \times Q(G)$, where $v$ is the fixed point of the standard based-free action $\alpha_G$ of $G$ on
$Q(G)$;

\item $Y \times Q(G)$ is a Hilbert cube;

\item $A' \times \{v\}$ is a Z-set in $Y \times Q(G)$;

\item there is a homeomorphism $h:Y\times Q(G)\to Q$ such that $h(A' \times \{v\}) = A$ (by the Homeomorphism Extension Theorem); and

\item the $G$-action $\alpha$ on $Q$ induced by $h$ is a semifree \ensuremath{\mathsf{ANR}}\ action
with fixed point set $A$.
\end{enumerate}

Now $Y = B \,\cup \, C$ where $B = A\times C(G), C = C(A) \times G,
\text{ and } B \cap C = A\times G = D$. Because $A$ and $G$ are \ensuremath{\mathsf{ANR}}'s, so are $B, C, \text{ and }D$.
Hence, $Y\in\ensuremath{\mathsf{ANR}}\ $ \cite{borsuk:retracts}.  Therefore we only need to show that it is
contractible.  Since  \ensuremath{\mathsf{ANR}}'s have the homotopy types of CW complexes \cite{Hanner}, this follows from the Whitehead Theorem
\cite[Corollary 4.33]{Hatcher01} once we verify that it is simply-connected and acyclic in integral
homology.

First, assume that $G$ is connected.  Then the van Kampen Theorem applies to show that $Y$ is
simply-connected.  Choose a basepoint $y= (a_0,g_0) \in A \times G$.
Then $\pi_1(D,y) \cong \pi_1(B,y)\times \pi_1(C,y)$.  The inclusion homomorphisms

In integral homology, the Mayer-Vietoris theorem gives a long exact sequence
\begin{multline*}
\dots\to H_n(A\times G)\overset{\phi}\to H_n(A\times C(G))\oplus H_n(C(A)\times G)\to \\ H_n(Y)
\overset{\partial}\to H_{n-1}(A\times G)\to\dots
\end{multline*}

We will first show that we may assume without loss of generality that we deal with actions on $K=C(A)\times
Q$.  As in the proof of
Theorem~\ref{derdestelling}, our use of cones simplifies the technical
details of the construction.

Let $\alpha$ be a semifree action of $G$ on $Q$ with fixed point set $A$.  By Theorem~\ref{point} there is a based-free action $\sigma$ of $G$ on $Q$.  As $Q$ is homogeneous, we may assume that the fixed point of $\sigma$ is $\{\bar 0\}$. Define a semifree action on $Q\times Q\times Q$ by $
(g,x,y,z)\mapsto (\alpha(g,x),y, \sigma (g,z))$.  The fixed point set of this action is
$A\times Q\times \{\bar 0\}$, which is a Z-set in $Q\times Q \times Q$.  Because
$C(A)$ is an \ensuremath{\mathsf{AR}},  the product $K=C(A) \times Q\approx Q$ by Edwards' Theorem (see Section \ref{infdim}).  Also, $(A\times \{\bar 0\})\times Q$ is a Z-set in $K$.
By the Homeomorphism Extension Theorem (see Section \ref{infdim}), there is a homeomorphism of
$Q\times Q\times Q\to K$ carrying
$A\times Q\times \{\bar 0\}$ in $Q\times Q\times Q$ to $(A\times \{\bar 0\})\times Q$ in $K$. Therefore we may
indeed assume without loss of
generality that $\alpha$ acts semifreely on $K$ with Fix($\alpha)=(A\times \{\bar 0\})\times Q$ and that $X$ is a
Z-set in $Q$.

We use the metric $\varrho$ on $K$ given by
$$
    \varrho(((x,s),u),((y,t),v)) = (1-\max\{s,t\}) d(x,y) + |t{-}s| + d(u,v).
$$
(See Section \ref{preliminaries} for this notation).
Denote $A\times [0,t]\times Q$ by $K_t$.  Then Fix($\alpha)= K_0$.  Since $\mathop{\operator@font Sh}\nolimits(K_0)=\mathop{\operator@font Sh}\nolimits(X)$, there is by
the Chapman Complement Theorem \cite[25.2]{chapman:lectures}, a homeomorphism $f: K\setminus K_0\to
Q\setminus X$.
For every $i \ge 1$, let $c_i = 2^{-i}$. Then for each $i$, $P_i=\{((x,s),u) \in K : s \ge c_i\}$ is a compact subset
of $K\setminus K_0$. Hence by uniform continuity, we may choose a sequence $1 > \delta_1 > \delta_2 >\dots
> 0$ such that

\begin{enumerate}
\item if $w,z\in P_i$ and $\varrho(w,z) < \delta_i$, then $d(f(w),f(z)) < \frac{1}{i}$.\label{nieuw2}
\end{enumerate}

\begin{enumerate}[resume*]
\item for $i \ge 1$, $d_{i} < c_{i+1}$, \label{nieuw1}
\item the displacement of $\alpha$ on $K_{d_i}$ is less than $\frac{\delta_i}{3}$, and, \label{deeerste}
\item $\alpha (G\times K_{d_{i+1}})\subseteq K_{d_i}$.\label{detweede}
\end{enumerate}

For each $i\ge 1$ let
$$
    c_{i+1} = t_{k(i)}^i < t_{k(i)-1}^i < \cdots < t_2^i < t_1^i = c_i
$$
be a partition of $[c_{i+1},c_i]=[2^{-(i+1)}, 2^{-i}]$ such that

\begin{enumerate}[resume*]
\item $k(i) > 1$ and each subinterval
$[t_{m+1}^i,t_m^i], m\le k(i){-}1$, has length less than $\frac{\delta_{i+1}}{6}$. \label{hellupvier}
\end{enumerate}
Now let $j(1)=3$ and for $i\ge 1$ set $ j(i{+}1)=j(i)+k(i)-1$. Clearly,
\begin{enumerate}[resume*]
\item $j(i{+}1) > j(i) \ge i{+}2$. \label{afschatting}
\end{enumerate}

Let $\phi:[0,1]\to [0,1]$ be a homeomorphism
such that for each $i \ge 1$,

\begin{enumerate}[resume*]
\item $\phi(c_i)=d_{j(i)}$, \label{devierde}
\item for $m \le k(i)$, $\phi(t_m^i) = d_{j(i) + m-1}$.\label{devijfde}
\end{enumerate}
Note that (\ref{devierde}) and (\ref{devijfde}) are consistent since $\phi(t_{k(i)}^i) = d_{j(i) + k(i)-1}=d_{j(i+1)}=\phi(c_{i+1})$.

Define $h:K\to K$ by $((x,t),u)\mapsto ((x,\phi(t)),u)$ and $\beta: G\times K \to K$ by $\beta =(h^{-1}\circ \alpha) \circ (\ensuremath{{\mathop{\operator@font id}\nolimits}}_G\times h)$. Hence for $((x,t),u) \in K$ and $g\in G$,

$$
For $z=((x,t),u)\in K_{c_i}$, $g\in G$, and $m\le k(i){-}1$ such that
\begin{enumerate}[resume*]
\item $\cdots < t^{i+1}_1=c_{i+1}=t_{k(i)}^i \le t_{m+1}^i < t\le t_m^i \le t_{1}^i=c_i=t^{i-1}_{k(i-1)} < \cdots$, \label{dezevende}

let
$w = \beta (g,z)=h^{-1}(\alpha(g,h(z)))=((y,s),v)$. Also, let $\nu= j(i) + (m{-}1)$.  Then $\phi(t^i_m) = d_\nu$, and $\phi(t^i_{m+1}) = d_{\nu +1}$.

\begin{enumerate}[resume*]
\item $z= ((x,t),u)$,\\ $h(z) = ((x,t'),u)$,\\ $w= \beta(g,z)=h^{-1}(\alpha(g,h(z)))= ((y,s),v)$, and\\ $h(w) = \alpha(g,h(z))= ((y,s'),v)$. \label{opsomming}
\end{enumerate}

We will compute how far $w$ and $z$ are apart, and what that tells us about the distance between $f(z)$ and $f(w)$.
The following diagram is helpful to see what is going on.

\begin{claim}\label{eersteclaimjawel}
$d(u,v) \le \textstyle \frac{\delta_{j(i)}}{3} -(1{-}\max\{s',t'\})d(x,y)$.
\end{claim}

\noindent Since $t \le c_i$, by (\ref{devierde}), $h(z) \in K_{d_{j(i)}}$, hence by (\ref{deeerste}), $\varrho(h(z),\alpha (g,h(z)))\le \frac{\delta_{j(i)}}{3}$.
So
$$

which clearly proves the claim.

\begin{claim}\label{tweedeclaimjawel}
$h(z) \in K_{d_\nu}\setminus K_{d_{\nu+1}}$ and $h(w) \in K_{d_{\nu-1}}\setminus K_{d_{\nu+2}}$.

$h(z) = \alpha (g^{-1}, h(w)) \in K_{d_{\nu+1}}$, which is a contradiction. Hence the claim is proved.

\begin{claim}
If $c_{i+1} \le s \le c_i$, then $d(f(z),f(w)) < \frac{1}{i+1}$.
\end{claim}

\noindent Assume first that $c_{i+1} \le s \le t$, hence $d_{j(i+1)} \le s'\le t'$. Since by Claim~\ref{tweedeclaimjawel}, $d_{\nu+2} < s'$, there are two cases. The first case is that $d_{\nu+1} \le s'$. Then $t^i_{m+1} \le s \le t\le t^i_m$, and so by (\ref{hellupvier}), $t{-}s \le \frac{\delta_{i+1}}{6}$.              &< (t'{-} t) d(x,y) + \delta_{i+1}.
\end{align*}

\end{claim}

\begin{align*}
\varrho(z', z'') &= (1{-}c_i) d(x,y) + d(u,v)\\
                &\le (1{-}c_i) d(x,y) + \textstyle\frac{\delta_{j(i)}}{3} - (1{-}s')d(x,y)\\
                &=(s'{-}c_i) d(x,y) + \textstyle\frac{\delta_{j(i)}}{3}.
\end{align*}

\begin{align*}

    &< \textstyle\frac{3}{i}.
\end{align*}

So we are left with the case that $s < c_{i+1}$. But this case is completely analogous to the previous case (with bound $\frac{3}{i+1}$).

Thus we see that the action $\gamma:G\times Q\setminus X\to Q\setminus X$ given by
$\gamma(g,w)=f(\beta (g,f^{-1}(w)))$ extends to a semifree action on $Q$ with fixed point set $X$.

<!-- theorem-10: body_md -->
\label{stellingoverANRs}
Let $X$ be a compact \ensuremath{\mathsf{ANR}}. Then $X$ is the fixed point set of a periodic homeomorphism of $Q$ of period $n$ acting semifreely if and only if $X$ is acyclic mod $n$.
<!-- end theorem-10 -->
<!-- proof-16: body_md -->
There remains to show that if $X$ is acyclic mod $n$, then it is a fixed point set of a semifree homeomorphism of period $n$. Since
$X$ is a compact \ensuremath{\mathsf{ANR}}, $X\times Q$ is a compact $Q$-manifold by Edwards' Theorem (see Section \ref{infdim}),
cf.~\cite{Tor:hilbertcube}. There consequently is by Chapman~\cite[36.2]{chapman:lectures} a compact
polyhedron $P$ such that $X\times Q\approx P\times Q$. Clearly, $P$ is acyclic mod~$n$. Hence there exists
by Jones~\cite[1.1]{Jones71} a contractible compact polyhedron $L$ containing $P$ and a periodic
semifree homeomorphism
$\alpha :  L\to L$ of period $n$ such that $\mathop{\operator@font Fix}\nolimits(\alpha)=P$.  Let $\tau$ be any semifree homeomorphism of $Q$ of
period $n$ with $\mathop{\operator@font Fix}\nolimits(\tau) = \{\overline 0\}$ (for example, a simple product of rotations).  Consider the space $S=L\times
Q\times Q$ with its period $n$ homeomorphism
$\beta = \alpha \times \tau\times \mathrm{id}_Q$.  By \cite[5.6]{West70} (or Edwards' Theorem), $S\approx Q$. Observe that $\mathop{\operator@font Fix}\nolimits(\beta) = P\times \{\bar 0\}\times
Q$ is a Z-set in $S$, so that the natural homeomorphism $P\times \{\bar 0\}\times Q\to P\times \{\bar 0\}
\times Q\times \{0\}$ extends to a homeomorphism of $S$ onto $P\times \{\bar 0\}\times Q\times [0,1]$.  Since
$P\times Q\approx X\times Q$, there is a cell-like map
$f :  \mathop{\operator@font Fix}\nolimits(\beta)
\to X$. The adjunction space $T = S\cup_f X$ is thus homeomorphic to the mapping cylinder of $f$ and is
homeomorphic to $Q$ by \cite[Theorem 2.4]{west:borsuk} (see also~\cite[Theorem 3]{Tor:hilbertcube}).  Now $f$
induces a period $n$ homeomorphism on the Hilbert cube $T$ with fixed point set $X$.

<!-- corollary-4: body_md -->
\label{shapeanr:p-acyclic}
Let $X$ be a Z-set with the Shape of a compact \ensuremath{\mathsf{ANR}}\ in a Keller space $K$. Then for every $n >1$, the following statements are equivalent:

\begin{enumerate}

\item $X$ is acyclic mod $n$.

\item There is a homeomorphism of $K$ of period $n$ with fixed point set $X$.

\item Arbitrarily close to the identity there are semifree homeomorphisms of $K$ of period~$n$ with fixed point set $X$.
\end{enumerate}

<!-- theorem-16: body_md -->
\label{shapeobstruction} Let $G$ be a finite group and $X$ be a Z-set in
$M$
such that the inclusion $f:X\to M$
induces isomorphisms from $\bar H_i( X;\mathbb F_p\pi)$ to
$\tilde H_i( M ;\mathbb F_p\pi)$ for all $i$ and for each prime $p$ dividing the order of $G$.
If $X$ has the Shape of a compact \ensuremath{\mathsf{ANR}}\
then $f$ determines an element
 $\omega(f) \in \tilde K^{top}_0 (\mathbb Z[\pi] \subset \mathbb Z[\pi \times G])$, where $\pi$ is the
 fundamental group of $M$.  If
 $\boldsymbol{\kappa} :X\to A$ is a Shape equivalence between $X$ and a compact \ensuremath{\mathsf{ANR}}\  $A$,
 then there is
 an embedding $\eta$ of $A^Q$ in $M$ as a Z-set $A_1$ containing $X$ such that $\omega(f) =
 \omega(j)$, where $j:A_1 \to M$ is
 the inclusion and $\omega(j)$ is the obstruction of Theorem \ref{QM:anrhomotopy}.
<!-- end theorem-16 -->
<!-- proof-27: body_md -->
Let $\boldsymbol \kappa:X\to A$ be a Shape equivalence
between $X$ and a compact
\ensuremath{\mathsf{ANR}}\  $A$ and let
$\zeta:X\to A$ be a map inducing
$\boldsymbol \kappa$.  Using the inclusion $A\to A \times \{\bar 0\}\to A^Q$, we
may replace $A$ by the homotopy equivalent $Q$-manifold $A^Q$ and assume
that $\zeta$ is an embedding of $X$ in $ A^Q $ as a Z-set.  Extend
$\zeta^{-1}$ to an embedding $\eta$ of $A^Q$ in $M$ as a Z-set $A_1$ and let
$\kappa$ denote the inclusion $X\to A_1$, which induces a Shape equivalence.

As $\bar H_i(X;\mathbb{F}_p\pi)$ is a Shape invariant,
$\kappa_{\ast}:\bar H_i(X;\mathbb{F}_p\pi)
\cong \bar H_i(A_1;\mathbb{F}_p\pi)\cong \linebreak
\tilde H_i(A_1;\mathbb{F}_p\pi)$.  By functoriality,
$j_{\ast}:\tilde H_i(A_1;\mathbb{F}_p\pi)\cong \tilde H_i(M;\mathbb{F}_p\pi)$ for
all $i$ and all primes
$p$ dividing the order of $G$.  Let $\omega(f) = \omega(j)\in
\tilde K_0^{top}(\mathbb Z[\pi]\subset\mathbb Z[\pi \times G])$ be the
Cappell-Weinberger-Yan obstruction identified in Theorem
\ref{QM:anrhomotopy}.  Then $\omega(j)$ is the image of $o(j)$ under $\phi$ in the following exact sequence
$$
    H_0(\pi;\boldsymbol{\tilde K}(\mathbb{Z}[G])) \to \tilde K_0(\mathbb Z[\pi \times G])\overset{\phi}\to
    \tilde K_0^{top}(\mathbb{Z}[\pi]\subset \mathbb{Z}[\pi\times G])
$$
in the proof of \cite[Theorem 4]{cwy}.

The  \ensuremath{\mathsf{ANR}}\ $A$ is determined only up to homotopy type by $\boldsymbol {\kappa}$, and $\eta$ is
restricted only by the
requirement that the inclusion $j\kappa $ be homotopic to $f$.  The proof of \cite[Theorem 4]{cwy}
explains why different
choices of $A, \boldsymbol {\kappa}$, and
$\eta$ vary $o(j)$ by elements of the kernel of $\phi$, showing that
$\omega(f)$ is uniquely determined by $o(j)$.

<!-- theorem-17: body_md -->
\label{semitame obstruction}  Let $G$ be a finite group and $X$ be a Z-set in
$M$ with the Shape of a compact \ensuremath{\mathsf{ANR}}\ $A$
such that the inclusion $f:X\to M$
induces isomorphisms from $\bar H_i( X;\mathbb{F}_p\pi)$ to
$\tilde H_i( M ;\mathbb{F}_p\pi)$ for all $i$ and for each prime $p$ dividing the order of $G$.
Then $\omega(f) = 0$ if and only if
there is a compact $Q$-manifold $N$
containing $A_1$ as the fixed point set of an \ensuremath{\mathsf{ANR}}\ action $\alpha$ of G on $N$ and an invariant
homotopy equivalence
$\bar f:N\to M$ that is the identity on $A_1$.  If the Whitehead torsion $\tau(\bar f)\in
Wh(\pi)$ lies in $f_{\ast}(Wh(\check \pi_1(X,x_0)))$,  then $X$ is the fixed point set of a semitame
semifree action of G on $M$.
<!-- end theorem-17 -->
<!-- proof-28: body_md -->
The ``if and only if'' part of the Theorem follows from Theorem \ref{QM:anrhomotopy} since Theorem \ref{semitame obstruction} shows that $\omega(f)=\omega (j)$ is uniquely determined in
$\tilde K_0^{top}(\mathbb Z[\pi] \subset\mathbb Z[\pi \times G])$.
Since $f = j\kappa$, $f_{\ast}(\text{Wh} (\check \pi_1(X,x_0)))
\subset j_{\ast}(\text{Wh}(\pi_1(A,x_0)))$.  Hence if
$\tau (\bar f) \in \linebreak f_{\ast}(\text{Wh}(\check \pi_1(X,x_0))$, Theorem \ref{QM:anrhomotopy}
provides an \ensuremath{\mathsf{ANR}}\ Z-set $C$ of $M$ containing $A_1$ as a deformation retract and the
fixed point set of a semifree $G$-action on $M$.  Now the inclusion of $X$ into $C$ is a shape
equivalence, so Theorem  \ref{anrShape} provides a semitame semifree
action of $G$ on $M$ with fixed point set $X$.

<!-- corollary-8: body_md -->
\label{fd1-UV} Let $X$ be a finite-dimensional, connected, 1-UV Z-set in the
simply connected
 compact $Q$-manifold
 $M$.  If the inclusion $f:X\to M$ induces isomorphisms $\check H^{\ast}(M;\mathbb Z)\to
 \check H^{\ast}(X;\mathbb Z)$ on
 \v Cech cohomology with $\mathbb Z$ coefficients, then $X$ is the fixed point set of  periodic
 homeomorphisms of period $2, 3, 5, 7, 11, 13, 17$, and $19$.
<!-- end corollary-8 -->
<!-- proof-30: body_md -->
We use the notation of the proof of Theorem \ref{shapeobstruction}.
\v Cech and singular cohomology agree on \ensuremath{\mathsf{ANR}}'s, and the singular cohomology groups of $M$ are
finitely generated and vanish above some dimension, so the groups
$\check H^{i}(X;\mathbb Z)$ have the same property.
By \cite{geolach}, $X$ is Shape equivalent to a finite cell complex $A$. Thus, for each $i$, $j^{\ast}: \tilde H^i
(M;\mathbb{Z})\to\tilde H^i( A_1;\mathbb{Z})$ is an isomorphism,
where $A_1 = \eta(A^Q)$ and $j:A_1\to M$ is the inclusion.  By the functoriality
of  the Universal Coefficient Theorems \cite[Theorems 5.5.10, 5.5.12]{spanier} and the 5-Lemma, for each $i$, $j_{\ast}:
\tilde H_i(A_1;\mathbb{F}_p)\to
\tilde H_i( M;\mathbb{F}_p)$ is an isomorphism for all primes $p$.

Now Corollary
\ref{QM:1conn} provides a $ \mathbb{Z}_p$ action on
$M$ with fixed point set $A_1$ and Theorem \ref{anrShape} transfers it to one with
fixed point set $X$.
