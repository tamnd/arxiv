\label{rem:absolute_value}
    The Liouville formula
       
                                         
                                                                                             
       
    shows (see~\cite[Thm.~2.2.3]{Golse2013}) that the exact flow is orientation-preserving, so the absolute value in
    \eqref{eq:comp_with_inicond} is redundant. This is no longer the case for the
    network approximations of \cref{sec:flow_networks}, whose Jacobian determinant
    is positive by construction only for the symplectic family.
    We therefore keep the absolute value in \eqref{eq:comp_with_inicond}.
    In all the numerical tests of \cref{sec:results}, however, the velocity field
    is divergence-free, so that the exact flow has unit Jacobian. In the remainder
    of the paper, the solution is therefore reconstructed by the pure pullback
    $\rho(t,\boldsymbol{x})=\rho_0(\boldsymbol{\Phi}_0^{t}(\boldsymbol{x}))$, i.e., with the determinants
    in \eqref{eq:density_reconstruction} and \eqref{eq:composed_density} set to
    one, also for networks that are not volume-preserving.
