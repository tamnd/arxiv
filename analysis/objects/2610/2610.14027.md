Three free-surface densities were used, in a constant refinement ratio
$r=1.5$: 24, 36 and 54 panels along the hull length (Coarse, Medium,
Fine), with the upstream fetch and the longitudinal panel count
upstream of the hull scaled by the same $r$ on all three, so that
free-surface density is the only quantity being refined; the hull grid
itself (the $100\times30$ node file, generated once, \S\ref{sec:wetsurf})
is identical on all three. Each grid was run twice, with the OpenBLAS
solver: linearised (the classical
scheme, no panel motion) and non-linear (ten passes, moving
free-surface panels with under-relaxation, \S\ref{sec:nonlin}), fixed
attitude throughout, and with the area-weighted partial-panel force
correction
enabled (\S\ref{sec:wetsurf}): a single-case check found it changes $C_w$ by a
few percent without altering the flow solution, and it is included
below as the more accurate of the two force-integration options.
Coarse and Medium omit $\mathrm{Fn}=0.150$ (Coarse also $0.180$): at these
speeds the free-surface wavelength is not resolved and the
acute-divergence guard rejects the run before it reaches the fixed
point. The eight Froude numbers common to all three grids,
$\mathrm{Fn}=0.211$--$0.450$, are used for the grid-convergence study below;
Fine alone was also run at $0.150$ and $0.180$.
