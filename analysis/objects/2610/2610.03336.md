\label{thm:allocation-structure}
Problem~\eqref{eq:max-enemy-losses} has an optimal
solution in which all but at most one component satisfy
\[
    R_i\in\{0,R_i^*\}.
\]
If every $k_i$ is strictly convex, every optimal solution
has this property.

Moreover, there exists an optimal solution satisfying
\[
    \sum_{i=1}^n R_i
    =\min\left(R,\sum_{i=1}^n R_i^*\right).
\]
If every $k_i$ is strictly increasing, every optimal
solution satisfies this equality.
<!-- end theorem-1 -->
<!-- proof-1: body_md -->
The feasible set
\[
    P=\left\{
        (R_1,\dots,R_n):
        0\le R_i\le R_i^*,\quad
        \sum_{i=1}^n R_i\le R
    \right\}
\]
is a compact convex polytope, and the objective function
is continuous and convex. Its maximum is therefore
attained at a vertex of $P$.
At each vertex, at most one component $R_i$ can lie strictly between 0 and $R_i^*$.
Indeed, if
$0<R_i<R_i^*$ and $0<R_j<R_j^*$ for distinct indices
$i,j$, then sufficiently small transfers between these
two components in either direction preserve feasibility.
The original point is the midpoint of the resulting
distinct feasible points, so it is not a vertex.
This proves the existence assertion.

If every $k_i$ is strictly convex, their sum is strictly
convex. A point that is not a vertex is a nontrivial convex
combination of two distinct feasible points, and strict
convexity implies that it cannot maximize the objective.
Thus every optimal solution is a vertex and has the
stated property.

Finally, suppose that a feasible allocation satisfies
\[
    \sum_{i=1}^n R_i
    <\min\left(R,\sum_{i=1}^n R_i^*\right).
\]
At least one component can then be increased without
violating the constraints. Since the loss functions
are nondecreasing, we can increase components until
the displayed equality in the theorem holds without
decreasing the objective. If every loss function is
strictly increasing, any such increase strictly improves
the objective, so an optimal solution cannot leave
this amount of the total army unused.

<!-- theorem-2: body_md -->
\label{np-hard-problem}
Let $\{\ell_s\}_{s\in\mathbb N}$ be a prescribed family
of continuous, strictly convex, strictly increasing
functions $\ell_s\colon[0,s]\to\mathbb R$ satisfying
\[
    \ell_s(0)=0,\qquad \ell_s(s)=s.
\]
Then the following allocation problem is NP-hard:
given positive integers $R,R_1^*,\dots,R_n^*$ with
$R<\sum_{i=1}^n R_i^*$, determine the maximum of
\[
    \sum_{i=1}^n \ell_{R_i^*}(R_i)
\]
subject to
\[
    0\le R_i\le R_i^*,\qquad
    \sum_{i=1}^n R_i\le R.
\]
<!-- end theorem-2 -->
<!-- proof-2: body_md -->
Consider a Subset Sum instance with positive integers
$s_1,\dots,s_n$ and target $S$. We may restrict attention
to instances satisfying $S<\sum_{i=1}^n s_i$, since
the remaining cases can be decided immediately.
Set
\[
    R_i^*=s_i,\qquad R=S,\qquad k_i=\ell_{s_i}.
\]
Since the family is prescribed and each function is
specified by its integer index, this construction
takes polynomial time.

Strict convexity and the endpoint normalization give
\[
    \ell_{s_i}(x)\le x,\qquad 0\le x\le s_i,
\]
with equality if and only if $x=0$ or $x=s_i$.
Consequently, every feasible allocation satisfies
\[
    \sum_{i=1}^n k_{i}(R_i)=\sum_{i=1}^n \ell_{s_i}(R_i)
    \le\sum_{i=1}^n R_i\le R=S.
\]

If the Subset Sum instance has a solution $I$, set
$R_i=s_i$ for $i\in I$ and $R_i=0$ otherwise.
This allocation is feasible and has objective value
$S$, so the maximum equals $S$.

Conversely, suppose that a feasible allocation
$(\bar R_1,\dots,\bar R_n)$ has objective value $S$.
Then
\[
    S=\sum_{i=1}^n \ell_{s_i}(\bar R_i)
    \le\sum_{i=1}^n\bar R_i\le S.
\]
Equality holds throughout. Hence
$\ell_{s_i}(\bar R_i)=\bar R_i$ for every $i$, which
implies $\bar R_i\in\{0,s_i\}$, and
$\sum_i\bar R_i=S$. The indices for which
$\bar R_i=s_i$ therefore solve the Subset Sum instance.

Thus the maximum equals $S$ if and only if the
Subset Sum instance has a solution, proving the claim.

<!-- theorem-3: body_md -->
\label{pseudopolynomial-algo}
Let $R,R_1^*,\dots,R_n^*$ be positive integers such that
$R<\sum_{i=1}^n R_i^*$. Suppose that
$k_i\colon[0,R_i^*]\to\mathbb R$ are continuous,
convex, and nondecreasing, with $k_i(0)=0$.
Then an optimal allocation for
\eqref{eq:max-enemy-losses}, together with its
objective value, can be found using $O(n^2R)$
operations and $O(R)$ auxiliary space.
<!-- end theorem-3 -->
<!-- proof-3: body_md -->
An optimal allocation can be chosen to use the entire
initial army size and to consist of a set of fully saturated
battlefields and at most one partially saturated
battlefield. We use $j\in\{1,\dots,n\}$ for the
possible partially saturated battlefield, and $j=0$
for an allocation with no partially saturated
battlefield.

For $j,k\in\{0,\dots,n\}$ and
$m\in\{0,\dots,R\}$, define
\[
    D_j(k,m)=
    \max\left\{
        \sum_{i\in S}k_i(R_i^*):
        S\subseteq\{1,\dots,k\}\setminus\{j\},
        \quad \sum_{i\in S}R_i^*=m
    \right\},
\]
where the maximum of an empty collection is
$-\infty$. Thus, $D_j(k,m)$ is the largest {total loss of the green
army achievable by using exactly $m$ red}  units to saturate
a subset of the first $k$ battlefields, excluding
battlefield $j$.

For each fixed $j$, initialize
\[
    D_j(0,0)=0,\qquad
    D_j(0,m)=-\infty\quad\text{for }m>0.
\]
The recurrence is
\[
D_j(k,m)=
\begin{cases}
\max\bigl\{
    D_j(k-1,m),
    D_j(k-1,m-R_k^*)+k_k(R_k^*)
\bigr\},
    & k\ne j,\ m\ge R_k^*,\\
D_j(k-1,m),
    & \text{otherwise}.
\end{cases}
\]
Indeed, a maximizing subset either omits battlefield
$k$ or includes it, in which case $R_k^*$ units are
used there and the objective increases by $k_k(R_k^*)$.

If $j\ne0$ and the saturated battlefields use $m$
units, the remaining $R-m$ units can be assigned to
battlefield $j$ whenever $0\le R-m\le R_j^*$.
The resulting total loss of the green army is
\[
    D_j(n,m)+k_j(R-m).
\]
The case with no partially saturated battlefield
has value $D_0(n,R)$. Consequently, the desired
maximum is
\begin{equation}\label{final-maximum}
\max\left\{
    D_0(n,R),
    \max_{1\le j\le n}
    \max_{\substack{m\in\{0,\dots,R\}\\
                    0\le R-m\le R_j^*}}
    \bigl(D_j(n,m)+k_j(R-m)\bigr)
\right\}.
\end{equation}
Every finite candidate in this expression corresponds
to a feasible allocation, and the structural result
guarantees that some candidate attains the optimum.

For a fixed $j$,  calculating the array $D_j$ using the recurrence requires $O(nR)$
operations. Running it for $j=0,\dots,n$ therefore
requires $O(n^2R)$ operations. 
The values in row $k$ depend only
on the values in the preceding row $k-1$, so it suffices to store two rows
of length $R+1$.
The tables $D_j$ for different values of $j$ can
be processed successively.

To recover an optimal allocation, retain a maximizing
pair $(j^*,m^*)$ in \eqref{final-maximum}, where
$m^*=R$ if $j^*=0$, together with the value
$D_{j^*}(n,m^*)$. We reconstruct a set of saturated
battlefields attaining this value by recomputing
the necessary rows.

Initially, set
\[
    m=m^*,\qquad V=D_{j^*}(n,m^*),
\]
and initialize the output allocation to zero.
For $k=n,n-1,\dots,1$, skip $k$ if $k=j^*$.
Otherwise, recompute $D_{j^*}(k-1,\cdot)$.
If
\[
    D_{j^*}(k-1,m)=V,
\]
leave battlefield $k$ empty. Otherwise, the recurrence
implies that an optimal subset includes battlefield
$k$; set $R_k=R_k^*$ and update
\[
    m:=m-R_k^*,\qquad
    V:=V-k_k(R_k^*).
\]
Finally, if $j^*\ne0$, set
\[
    R_{j^*}=R-m^*.
\]

Each recomputation requires $O(nR)$ operations and
$O(R)$ auxiliary space. There are at most $n$ such
recomputations, so reconstruction requires
$O(n^2R)$ operations and does not increase the overall
bound. The allocation is recorded directly in the
output vector. Thus the auxiliary space is $O(R)$,
in addition to the space for the input and output.

<!-- lemma-1: body_md -->
\label{lem:survival-superadditivity}
Suppose that $s\colon[0,\infty)\to\mathbb R$ satisfies
the following conditions:
\begin{enumerate}
    \item There exists $c\ge0$ such that $s(x)=0$
    for $x\in[0,c]$.
    \item The function $s$ is continuous and concave
    on $[c,\infty)$ and continuously differentiable
    on $(c,\infty)$.
    \item $\displaystyle\lim_{x\to\infty}s'(x)=1$.
    \item $s(x)\le x$ for every $x\ge c$.
\end{enumerate}
Then $s$ is superadditive on $[0,\infty)$.
<!-- end lemma-1 -->
<!-- proof-6: body_md -->
Concavity implies that $s'$ is nonincreasing on $(c,\infty)$.
Together with its limit at infinity, this gives
$s'(x)\ge1$ for $x>c$. Consequently, $s$ is
nondecreasing on $[0,\infty)$.

If at least one of $x,y$ does not exceed $c$,
monotonicity and the first assumption give
\[
    s(x+y)\ge s(x)+s(y).
\]
If $x,y>c$, then
\[
    s(x+y)-s(x)
    =\int_x^{x+y}s'(u)\,{\mathrm d}u
    \ge \int_x^{x+y}1\,{\mathrm d}u =y
    \ge s(y).
\]
Thus $s$ is superadditive.

<!-- theorem-6: body_md -->
\label{allocation-max-survivors-and-conquer-all}
Suppose that $R>\sum_{i=1}^n R_i^*$ and that
$s_i\colon[R_i^*,\infty)\to\mathbb R$ are continuous,
strictly increasing, strictly concave, and
continuously differentiable on $(R_i^*,\infty)$.
Assume also that
\[
    \lim_{x\to R_i^*+}s_i'(x)=\infty
\]
for every $i$, and that there exists $m\ge0$ such that
\[
    \lim_{x\to\infty}s_i'(x)=m
\]
for every $i$.

Then the problem of maximizing
$\sum_{i=1}^n s_i(R_i)$ subject to
$R_i\ge R_i^*$ and $\sum_iR_i=R$ has a unique solution:
\begin{equation}\label{lambda-optimal}
    R_i=(s_i')^{-1}(\lambda),
    \qquad i\in\{1,\dots,n\},
\end{equation}
where $\lambda\in(m,\infty)$ is the unique solution of
\begin{equation}\label{lambda-equation}
    \sum_{i=1}^n(s_i')^{-1}(\lambda)=R.
\end{equation}
In particular, $R_i>R_i^*$ for every $i$.
<!-- end theorem-6 -->
<!-- proof-7: body_md -->
Strict concavity and continuous differentiability of $s_i$ in $(R_i^*,\infty)$
imply that $s_i'$ is continuous and strictly decreasing
on $(R_i^*,\infty)$. By the assumed limits, it maps
this interval onto $(m,\infty)$.

Consequently, the function
\[
    F(\lambda)=\sum_{i=1}^n(s_i')^{-1}(\lambda)
\]
is continuous and strictly decreasing on $(m,\infty)$,
with
\[
    \lim_{\lambda\to m+}F(\lambda)=\infty,
    \qquad
    \lim_{\lambda\to\infty}F(\lambda)
    =\sum_{i=1}^n R_i^*<R.
\]
There is therefore a unique $\lambda\in(m,\infty)$
such that $F(\lambda)=R$. Set
$R_i=(s_i')^{-1}(\lambda)$. Then $R_i>R_i^*$ and
$\sum_iR_i=R$.

For any other feasible allocation
$(\widetilde R_1,\dots,\widetilde R_n)$,
concavity gives
\[
    s_i(\widetilde R_i)
    \le s_i(R_i)+s_i'(R_i)(\widetilde R_i-R_i)
    =s_i(R_i)+\lambda(\widetilde R_i-R_i).
\]
Summing these inequalities yields
\[
    \sum_{i=1}^n s_i(\widetilde R_i)
    \le\sum_{i=1}^n s_i(R_i),
\]
because both allocations have total size $R$.
Strict concavity makes the inequality strict
whenever the allocations differ, proving uniqueness.

\label{thm:kd-ratio}
Let $R>0$, and assume that $k_i(0)=d_i(0)=0$ and

\[

<!-- theorem-8: body_md -->
\label{thm:power-law-convexity}
Let $A,B>0$. The loss function $k$ in
\eqref{eq:power-law-loss} is strictly increasing on
$[0,R^*]$. Its restriction to this interval is convex
if and only if
\[
    A\ge1,\qquad B\ge1.
\]
It is strictly convex if and only if, in addition,
$(A,B)\ne(1,1)$.
<!-- end theorem-8 -->
<!-- proof-10: body_md -->
Strict monotonicity follows directly from the formula~\eqref{eq:power-law-loss}.

Suppose first that $A,B\ge1$. The function
$x\mapsto G^B-cx^A$ is concave and nonnegative on
$[0,R^*]$, and the function $u\mapsto u^{1/B}$ is
increasing and concave on $[0,\infty)$. Their composition
is therefore concave, so $k$ is convex.

If $A>1$, the inner function is strictly concave,
and the composition is strictly concave because
the outer function is increasing and concave.
If $A=1$ and $B>1$, the inner function is affine
and nonconstant, while the outer function is
strictly concave. Thus $k$ is strictly convex
in both cases. For $A=B=1$, we have $k(x)=cx$,
which is linear.

To prove necessity, differentiation on $(0,R^*)$
gives
\[
    k''(x)=
    \frac{cA}{B}x^{A-2}(G^B-cx^A)^{1/B-2}
    \left((A-1)G^B+
          \left(1-\frac AB\right)cx^A\right).
\]
The factors outside the parentheses are positive.
If $A<1$, the expression in parentheses is negative
for sufficiently small positive $x$. If $B<1$,
its limit as $x\to R^*-$ is
\[
    A\left(1-\frac1B\right)G^B<0.
\]
In either case, $k$ is not convex on $[0,R^*]$.

<!-- theorem-9: body_md -->
\label{thm:power-law-allocation}
Fix nonnegative exponents satisfying
\[

<!-- proof-11: body_md -->
The effective exponents satisfy $A,B\ge1$ and
$(A,B)\ne(1,1)$. For each positive integer $q$, choose

    r=\frac AB q^{B-A}.

instance is specified by the positive integer $q$; the parameters
above are determined by this index.
Then $c=q^{B-A}$ and $R^*=q$. The corresponding loss functions
belong to the family
\[
    \ell_q(x)=
    q\left[
        1-\left(1-\left(\frac{x}{q}\right)^A\right)^{1/B}
    \right],
    \qquad 0\le x\le q.
\]
Each function is continuous, strictly increasing,
and strictly convex, with
$\ell_q(0)=0$ and $\ell_q(q)=q$.
Theorem~\ref{np-hard-problem} therefore applies.

For arbitrary positive battlefield parameters,
Theorem~\ref{thm:power-law-convexity} gives the
assumptions of Theorem~\ref{pseudopolynomial-algo}.
If $R\ge\sum_iR_i^*$, saturating all battlefields
is optimal. Otherwise, the claimed operation
and space bounds follow from that theorem.

<!-- lemma-2: body_md -->
\label{lem:power-law-kd}
Let $A,B>0$. The function $\kappa$ is nondecreasing
on $[0,\infty)$ if and only if $A,B\ge1$.
It is strictly increasing on $[0,\infty)$ if and
only if $A>1$ and $B\ge1$.
<!-- end lemma-2 -->
<!-- proof-12: body_md -->
Suppose first that $A,B\ge1$. By
Theorem~\ref{thm:power-law-convexity}, the restricted enemy
loss function $k$ is convex and $k(0)=0$.
For $0<x<y\le R^*$, convexity gives
\[
    \frac{k(x)}{x}\le \frac{k(y)}{y}.
\]
Thus $\kappa$ is
nondecreasing on $(0,R^*]$. If $A>1$, strict
convexity makes this inequality strict.

For $x>R^*$, the numerator of $\kappa$ is constant,
and differentiation gives
\[
    d(x)^2\kappa'(x)
    =
    G\left[
        \left(1-\left(\frac{R^*}{x}\right)^A
        \right)^{-1+1/A}-1
    \right].
\]
Hence $\kappa'$ is negative when $A<1$, zero when
$A=1$, and positive when $A>1$.
The two branches agree at $R^*$, and
$\kappa(x)>0=\kappa(0)$ for every $x>0$.
This proves sufficiency and shows that
nondecreasing behavior requires $A\ge1$, while
strictly increasing behavior requires $A>1$.

Finally, if $0<B<1$, differentiation of the first
branch gives
\[
    \kappa'(x)=\frac{c^{1/B}}{x^2}
    \left[
        -(R^*)^{A/B}
        +((R^*)^A-x^A)^{1/B}
        +\frac AB x^A((R^*)^A-x^A)^{1/B-1}
    \right].
\]
Therefore,
\[
    \lim_{x\to {R^*}^-}\kappa'(x)
    =-c^{1/B}(R^*)^{A/B-2}<0.
\]
Thus $\kappa$ cannot be nondecreasing when $B<1$.
