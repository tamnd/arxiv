<!-- lemma-1: body_md -->
\label{lem:general-f-condition}
Let $\Delta \ge 3$ and $n \ge \Delta+2$ be integers. The linear program consisting of maximizing \eqref{eq:LP-objective-g} subject to \eqref{eq:LP-constraint-sum-SO} and \eqref{eq:LP-constraint-w-SO} admits a unique optimal basic feasible solution strictly comprising the edges $m_{1, \Delta}$ and $m_{2, \Delta}$, where
\[
m_{1, \Delta} \;=\; \frac{(\Delta-2)n + (\Delta+2)}{\Delta}, 
\qquad
m_{2, \Delta} \;=\; \frac{2(n-\Delta-1)}{\Delta},
\]
if and only if for all valid non-basic pairs $(i,j) \notin \{(1, \Delta), (2, \Delta)\}$, the dual gap function satisfies $G(i,j) > 0$, where:
\begin{equation}
\label{eq:general-gap-function}
G(i,j) = f(1, \Delta) - f(i,j) - y_2 \left( 1 + \frac{1}{\Delta} - \frac{1}{i} - \frac{1}{j} \right),
\end{equation}
and the dual penalty coefficient evaluates to $y_2 = 2 \big( f(1, \Delta) - f(2, \Delta) \big)$.
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
For the basic variables $m_{1, \Delta} > 0$ and $m_{2, \Delta} > 0$, strict complementary slackness dictates that their corresponding dual constraints are exact equalities:
\begin{align}
y_1 + \left(1 + \frac{1}{\Delta}\right)y_2 &= f(1, \Delta), \label{eq:dual_eq1}\\
y_1 + \left(\frac{1}{2} + \frac{1}{\Delta}\right)y_2 &= f(2, \Delta). \label{eq:dual_eq2}
\end{align}
Subtracting \eqref{eq:dual_eq2} from \eqref{eq:dual_eq1} yields $\frac{1}{2}y_2 = f(1, \Delta) - f(2, \Delta)$, explicitly evaluating the dual penalty coefficient as $y_2 = 2 \big( f(1, \Delta) - f(2, \Delta) \big)$. 

By isolating $y_1$ from \eqref{eq:dual_eq1}, we obtain $y_1 = f(1, \Delta) - \left(1 + \frac{1}{\Delta}\right)y_2$. For uniqueness, dual feasibility strictly requires the dual gap function to be positive for all non-basic edges:
\[
G(i,j) = y_1 + \left(\frac{1}{i}+\frac{1}{j}\right)y_2 - f(i,j) > 0.
\]
Substituting the derived expression for $y_1$ directly yields exactly the algebraic formulation of $G(i,j)$ in \eqref{eq:general-gap-function}, thus completing the proof.
<!-- end proof-1 -->
<!-- lemma-2: body_md -->
\label{lem:reduction}
Let $f(x,y)$ be a continuous, differentiable extension of a topological weight function evaluated for $1 \le x < y \le \Delta$. If $f$ is strictly increasing with respect to its second variable, i.e., $\frac{\partial f}{\partial y} > 0$, and if $f(1, \Delta) > f(2, \Delta)$, then for any fixed $x$, the gap function $G(x,y)$ is strictly decreasing with respect to $y$. Consequently, for any valid discrete degrees $3 \le i < j \le \Delta$, the inequality $G(i,j) \ge G(i, \Delta)$ holds.
<!-- end lemma-2 -->
<!-- proof-2: body_md -->
By definition, the gap function extended to continuous variables $x$ and $y$ is given by:
\begin{equation}
G(x,y) = f(1,\Delta) - f(x,y) - y_2 \left( 1 + \frac{1}{\Delta} - \frac{1}{x} - \frac{1}{y} \right),
\end{equation}
with $y_2 > 0$ since $f(1, \Delta) > f(2, \Delta)$. 

Taking the partial derivative of $G(x,y)$ with respect to the second variable $y$, we obtain:
\begin{equation}
\frac{\partial G}{\partial y} = -\frac{\partial f(x,y)}{\partial y} - \frac{y_2}{y^2}.
\end{equation}
Since we assumed that $\frac{\partial f}{\partial y} > 0$ and knowing that $y_2 > 0$, both terms on the right side of the equation are strictly negative. Therefore, $\frac{\partial G}{\partial y} < 0$ for all valid $x, y$. 

This implies that for a fixed $x$, the function $G(x,y)$ monotonically decreases as $y$ increases. Since the maximum possible degree in the graph is bounded by $\Delta$, the function attains its global minimum with respect to $y$ at the upper boundary $y = \Delta$. Thus, restricted to discrete vertex degrees, we conclude that $G(i,j) \ge G(i, \Delta)$ for all $1 \le i < j \le \Delta$.
<!-- end proof-2 -->
<!-- theorem-1: body_md -->
\label{thm:main_1D}
Let $T$ be a tree of order $n$ and maximum degree $\Delta \ge 3$. Let $f$ be a topological weight function possessing a continuous and differentiable extension $f(x,y)$ for $1 \le x < y \le \Delta$. If $f(x,y)$ is strictly increasing with respect to its second variable (i.e., $\frac{\partial f}{\partial y} > 0$) and satisfies $f(1, \Delta) > f(2, \Delta)$, define the single-variable test function $h(x)$ on the interval $[3, \Delta]$ as:
\begin{equation}
\label{eq:test_hx}
h(x) = f(1,\Delta) - f(x,\Delta) - y_2 \left( 1 - \frac{1}{x} \right),
\end{equation}
where $y_2 = 2\big(f(1,\Delta) - f(2,\Delta)\big)$. If $h(x) > 0$ for all $x \in [3, \Delta]$, then the tree configuration maximizing the corresponding topological index is uniquely determined.
<!-- end theorem-1 -->
<!-- proof-3: body_md -->
According to Lemma \ref{lem:general-f-condition}, the optimal configuration is uniquely determined if the gap function satisfies $G(i,j) > 0$ for all internal nodes with degrees $3 \le i < j \le \Delta$. 

By applying Lemma \ref{lem:reduction}, we can establish a lower bound for $G(i,j)$ by projecting it onto the upper boundary $j = \Delta$:
\begin{equation}
G(i,j) \ge G(i, \Delta) = f(1,\Delta) - f(i,\Delta) - y_2 \left( 1 + \frac{1}{\Delta} - \frac{1}{i} - \frac{1}{\Delta} \right).
\end{equation}
Simplifying the expression by cancelling the $1/\Delta$ terms yields exactly our test function evaluated at $i$:
\begin{equation}
G(i,j) \ge h(i).
\end{equation}
Since, by the premise of the theorem, $h(x) > 0$ for all real values $x \in [3, \Delta]$, it trivially holds for all valid discrete degree values $i \in \{3, \dots, \Delta-1\}$. Consequently, $G(i,j) > 0$, fulfilling the necessary condition and concluding the proof.
<!-- end proof-3 -->

Every vertex in $V_k$ must have degree exactly $k$ in $H$. For each vertex $v \in V_\Delta$, attach exactly $\Delta - d_H(v)$ pendant vertices to it, where $d_H(v)$ is its degree in the subtree $H$.

<!-- corollary-1: body_md -->
Let $T$ be a tree of order $n$ with maximum degree $\Delta \ge 3$. The maximum value of the Tangent index is uniquely achieved by the extremal tree configuration restricted strictly to the edge basis $\{(1, \Delta), (2, \Delta)\}$.
<!-- end corollary-1 -->
<!-- proof-4: body_md -->
For the Tangent index, the weight function under the convention $x < y$ is defined as $f(x,y) = \frac{y^2 - x^2}{2xy} = \frac{y}{2x} - \frac{x}{2y}$. We first verify the monotonicity condition of Theorem \ref{thm:main_1D}:
$$
\frac{\partial f}{\partial y} = \frac{1}{2x} + \frac{x}{2y^2} > 0.
$$
Next, we determine the penalty coefficient $y_2$ and simultaneously verify the second requirement $f(1, \Delta) > f(2, \Delta)$:
\begin{equation*}
y_2 = 2\big(f(1,\Delta) - f(2,\Delta)\big) = 2 \left( \frac{\Delta^2 - 1}{2\Delta} - \frac{\Delta^2 - 4}{4\Delta} \right) = \frac{\Delta^2 + 2}{2\Delta}.
\end{equation*}
Since $\Delta \ge 3$, it strictly follows that $y_2 > 0$, thereby confirming $f(1, \Delta) > f(2, \Delta)$. With both conditions of Theorem \ref{thm:main_1D} fulfilled, the optimality reduces to evaluating the single-variable test function defined in \eqref{eq:test_hx}.

Substituting $f(x, \Delta)$ and $y_2$ back into \eqref{eq:test_hx}, we obtain the expression for $h(x)$:
\begin{equation}
h(x) = \frac{\Delta^2 - 1}{2\Delta} - \frac{\Delta^2 - x^2}{2\Delta x} - \frac{\Delta^2 + 2}{2\Delta} \left( \frac{x-1}{x} \right).
\end{equation}
Simplifying this expression algebraically yields a concise closed-form equation:
\begin{equation}
h(x) = \frac{(x-1)(x-2)}{2\Delta x}.
\end{equation}
Taking the first derivative yields $h'(x) = \frac{1}{2\Delta}\left(1 - \frac{2}{x^2}\right)$. For all $x \ge 3$, it holds that $x^2 > 2$, which implies $h'(x) > 0$. Since $h(1)=0$ and $h(2)=0$, the function is strictly positive for all $x \in [3, \Delta]$. According to Theorem \ref{thm:main_1D}, this completes the proof.
<!-- end proof-4 -->
<!-- corollary-2: body_md -->
\label{cor:so1}
Let $T$ be a tree of order $n$ with maximum degree $\Delta \ge 3$. The maximum value of the $SO_1$ index is uniquely achieved by the extremal tree configuration restricted strictly to the edge basis $\{(1, \Delta), (2, \Delta)\}$.
<!-- end corollary-2 -->
<!-- proof-5: body_md -->
The topological weight function characterizing the $SO_1$ index is given by $f(x,y) = \frac{1}{2}(y^2 - x^2)$ for $x < y$. We first establish the monotonicity prerequisite of Theorem \ref{thm:main_1D} by verifying that $\frac{\partial f}{\partial y} = y > 0$.

Next, we evaluate the penalty coefficient $y_2$ to verify the condition $f(1, \Delta) > f(2, \Delta)$:
\begin{equation*}
y_2 = 2\big(f(1,\Delta) - f(2,\Delta)\big) = (\Delta^2 - 1) - (\Delta^2 - 4) = 3.
\end{equation*}
Since $y_2 = 3 > 0$, the initial conditions of Theorem \ref{thm:main_1D} are fully satisfied. Substituting $f(x, \Delta)$ and $y_2$ into the 1D test function \eqref{eq:test_hx}, we obtain:
\begin{equation}
h(x) = \frac{\Delta^2 - 1}{2} - \frac{\Delta^2 - x^2}{2} - 3 \left( \frac{x-1}{x} \right) = \frac{x^2 - 1}{2} - \frac{3(x-1)}{x}.
\end{equation}
By factoring out $(x-1)$, this algebraic expression simplifies directly into a concise closed-form equation:
\begin{equation}
h(x) = \frac{(x-1)(x-2)(x+3)}{2x}.
\end{equation}
Since all factors of $h(x)$ are strictly positive for $x \ge 3$, we have $h(x) > 0$ for all $x \in [3, \Delta]$. By Theorem \ref{thm:main_1D}, the extremal tree uniquely maximizes the $SO_{11}$ index.
<!-- end proof-5 -->
<!-- corollary-3: body_md -->
\label{cor:so2}
Let $T$ be a tree of order $n$ with maximum degree $\Delta \ge 3$. The maximum value of the $SO_2$ index is uniquely achieved by the extremal tree configuration restricted strictly to the edge basis $\{(1, \Delta), (2, \Delta)\}$.
<!-- end corollary-3 -->
<!-- proof-6: body_md -->
The topological weight function characterizing the $SO_2$ index is given by $f(x,y) = \frac{y^2 - x^2}{x^2 + y^2}$ for $x < y$. We first establish the monotonicity prerequisite of Theorem \ref{thm:main_1D} by evaluating the partial derivative with respect to $y$:
\begin{equation*}
\frac{\partial f}{\partial y} = \frac{2y(x^2 + y^2) - 2y(y^2 - x^2)}{(x^2 + y^2)^2} = \frac{4x^2y}{(x^2 + y^2)^2}.
\end{equation*}
Since $x, y \ge 1$, it strictly follows that $\frac{\partial f}{\partial y} > 0$. 

Next, we evaluate the penalty coefficient $y_2$ to confirm the condition $f(1, \Delta) > f(2, \Delta)$:
\begin{align*}
y_2 &= 2\left( \frac{\Delta^2 - 1}{\Delta^2 + 1} - \frac{\Delta^2 - 4}{\Delta^2 + 4} \right) \\
&= 2 \left( \frac{(\Delta^4 + 3\Delta^2 - 4) - (\Delta^4 - 3\Delta^2 - 4)}{(\Delta^2 + 1)(\Delta^2 + 4)} \right) = \frac{12\Delta^2}{(\Delta^2 + 1)(\Delta^2 + 4)}.
\end{align*}
Given $\Delta \ge 3$, $y_2 > 0$, completely satisfying the initial conditions of Theorem \ref{thm:main_1D}. Substituting $f(x, \Delta)$ and $y_2$ into the 1D test function \eqref{eq:test_hx}, we obtain:
\begin{equation}
h(x) = \left( \frac{\Delta^2 - 1}{\Delta^2 + 1} - \frac{\Delta^2 - x^2}{\Delta^2 + x^2} \right) - \frac{12\Delta^2}{(\Delta^2 + 1)(\Delta^2 + 4)} \left( \frac{x-1}{x} \right).
\end{equation}
Algebraically simplifying the first parenthetical term yields $\frac{2\Delta^2(x^2 - 1)}{(\Delta^2 + 1)(\Delta^2 + x^2)}$. By factoring out the common multiplier $\frac{2\Delta^2(x-1)}{\Delta^2 + 1}$, the function can be compactly rewritten as:
\begin{equation}
h(x) = \frac{2\Delta^2(x-1)}{\Delta^2 + 1} \left[ \frac{x+1}{\Delta^2 + x^2} - \frac{6}{x(\Delta^2 + 4)} \right].
\end{equation}
For $h(x) > 0$, we must show that the bracketed expression is positive, which is algebraically equivalent to proving that the cross-multiplied numerator $\mathcal{N}(x, \Delta) = x(x+1)(\Delta^2 + 4) - 6(\Delta^2 + x^2) > 0$. Expanding and regrouping this polynomial gives:
\begin{equation}
\mathcal{N}(x, \Delta) = (x^2 + x - 6)\Delta^2 - 2x^2 + 4x.
\end{equation}
For all valid interior degrees $x \ge 3$, the quadratic factor $(x^2 + x - 6) = (x-2)(x+3)$ is strictly positive. Since the maximum degree satisfies $\Delta \ge x$, we can establish a strict lower bound by substituting $\Delta^2 \ge x^2$:
\begin{equation}
\mathcal{N}(x, \Delta) \ge x^2(x^2 + x - 6) - 2x^2 + 4x = x^4 + x^3 - 8x^2 + 4x.
\end{equation}
This lower bound polynomial factors elegantly into $x(x-2)(x^2 + 3x - 2)$. For $x \ge 3$, every individual factor is strictly positive, definitively ensuring $\mathcal{N}(x, \Delta) > 0$. Consequently, $h(x) > 0$ for all $x \in [3, \Delta]$. By Theorem \ref{thm:main_1D}, the extremal tree configuration uniquely maximizes the $SO_2$ index.

<!-- corollary-4: body_md -->
\label{cor:ag}
Let $T$ be a tree of order $n$ with maximum degree $\Delta \ge 9$. The maximum value of the Arithmetic-Geometric ($AG$) index is uniquely achieved by the extremal tree configuration restricted strictly to the edge basis $\{(1, \Delta), (2, \Delta)\}$.

<!-- proof-7: body_md -->
The weight function for the $AG$ index under the convention $x < y$ is defined as $f(x,y) = \frac{x+y}{2\sqrt{xy}}$. We first verify the monotonicity condition of Theorem \ref{thm:main_1D} by taking the partial derivative with respect to $y$:
\begin{equation*}
\frac{\partial f}{\partial y} = \frac{y-x}{4\sqrt{x}y^{3/2}}.
\end{equation*}
Since $y > x \ge 1$, it strictly follows that $\frac{\partial f}{\partial y} > 0$. 

Next, we evaluate the penalty coefficient $y_2$ to confirm the condition $f(1, \Delta) > f(2, \Delta)$:
\begin{equation*}
y_2 = 2\big(f(1,\Delta) - f(2,\Delta)\big) = 2 \left( \frac{\Delta + 1}{2\sqrt{\Delta}} - \frac{\Delta + 2}{2\sqrt{2\Delta}} \right) = \frac{\sqrt{2}(\Delta + 1) - (\Delta + 2)}{\sqrt{2\Delta}}.
\end{equation*}
To guarantee $y_2 > 0$, the linear numerator of this expression must be strictly positive. Rearranging the terms into a linear function of $\Delta$ yields:
\begin{equation*}
(\sqrt{2}-1)\Delta - (2-\sqrt{2}) > 0 \implies \Delta > \frac{2-\sqrt{2}}{\sqrt{2}-1}  = \sqrt{2}.
\end{equation*}
Since our maximum degree satisfies $\Delta \ge 9 > \sqrt{2}$, this condition is trivially fulfilled. With the initial conditions of Theorem \ref{thm:main_1D} established, we construct the single-variable test function $h(x)$ from \eqref{eq:test_hx}:
\begin{equation}
h(x) = \frac{\Delta + 1}{2\sqrt{\Delta}} - \frac{x + \Delta}{2\sqrt{x\Delta}} - \frac{(\sqrt{2}-1)\Delta - (2-\sqrt{2})}{\sqrt{2\Delta}} \left( \frac{x-1}{x} \right).
\end{equation}
By factoring out the common positive denominator $2x\sqrt{\Delta}$, we can rewrite the test function as $h(x) = \frac{\mathcal{N}(x, \Delta)}{2x\sqrt{\Delta}}$, where the algebraic numerator is:
\begin{equation}
\mathcal{N}(x, \Delta) = x(\Delta+1) - \sqrt{x}(x+\Delta) - \sqrt{2}(x-1)\big[(\sqrt{2}-1)\Delta - (2-\sqrt{2})\big].
\end{equation}
To prove $h(x) > 0$, it is sufficient to prove $\mathcal{N}(x, \Delta) > 0$. Expanding and grouping the terms into a linear function of the parameter $\Delta$, we obtain:
\begin{equation}
\mathcal{N}(x, \Delta) = \Delta \big[ (\sqrt{2}-1)x - \sqrt{x} + 2 - \sqrt{2} \big] - x\sqrt{x} + (2\sqrt{2}-1)x - (2\sqrt{2}-2).
\end{equation}
Let $C_1(x) = (\sqrt{2}-1)x - \sqrt{x} + 2 - \sqrt{2}$ represent the slope of $\mathcal{N}(x, \Delta)$ with respect to $\Delta$. By treating $C_1(x)$ as a quadratic function of the variable $t = \sqrt{x}$, we calculate its discriminant:
\begin{equation}
D = (-1)^2 - 4(\sqrt{2}-1)(2-\sqrt{2}) = 17 - 12\sqrt{2} = (3-2\sqrt{2})^2.
\end{equation}
The roots of this quadratic are exactly $t_1 = 1$ and $t_2 = \sqrt{2}$. With a positive leading coefficient, the parabola is strictly positive for all $t > \sqrt{2}$. Since valid internal degrees require $x \ge 3$, we have $t = \sqrt{x} \ge \sqrt{3} > \sqrt{2}$, definitively proving $C_1(x) > 0$. 

Because the slope is positive, $\mathcal{N}(x, \Delta)$ is a strictly increasing function of $\Delta$. Therefore, for any valid tree with $\Delta \ge 9$, the numerator is bounded below by its evaluation at the minimum boundary $\Delta = 9$:
\begin{equation}
\mathcal{N}(x, \Delta) \ge \mathcal{N}(x, 9) = -x\sqrt{x} + (11\sqrt{2}-10)x - 9\sqrt{x} + (20-11\sqrt{2}).
\end{equation}
Introducing the substitution $t = \sqrt{x}$, the minorant becomes a cubic polynomial $P(t) = -t^3 + (11\sqrt{2}-10)t^2 - 9t + (20-11\sqrt{2})$. Since $x \in [3, 9]$, we analyze $P(t)$ over the domain $t \in [\sqrt{3}, 3]$. Taking the first derivative yields $P'(t) = -3t^2 + 2(11\sqrt{2}-10)t - 9$. The roots of $P'(t) = 0$ dictate the local extrema. Solving this quadratic equation reveals a local minimum at $t_1 \approx 1.196$ (which lies outside our domain) and a local maximum at $t_2 \approx 2.508$ (which lies inside our domain). 

This implies that on the interval $[\sqrt{3}, 3]$, the function $P(t)$ monotonically increases to its local maximum at $t_2$ and then monotonically decreases. Due to this, the absolute minimum of $P(t)$ on this interval must occur at one of the boundary points. Evaluating $P(t)$ at these endpoints gives exactly:
\begin{align}
P(\sqrt{3}) &= 22\sqrt{2} - 12\sqrt{3} - 10 \approx 0.328 > 0, \\
P(3) &= 88\sqrt{2} - 124 \approx 0.451 > 0.
\end{align}
Since the polynomial evaluates to strictly positive values at both bounds, $P(t) > 0$ for the entire interior of the interval. Consequently, $\mathcal{N}(x, \Delta) > 0$, which ensures $h(x) > 0$ for all valid $x \in [3, \Delta]$. According to Theorem \ref{thm:main_1D}, the extremal tree configuration uniquely maximizes the Arithmetic-Geometric index.

<!-- lemma-3: body_md -->
\label{lem:so11_gap}
Let $G(x,y)$ be the continuous extension of the gap function for the $SO_{11}$ index:
\begin{equation*}
G(x,y) = f(1, \Delta) - f(x,y) - y_2(\Delta) \left( 1 + \frac{1}{\Delta} - \frac{1}{x} - \frac{1}{y} \right),
\end{equation*}
where $f(x,y) = y^3 + y^2 x - x^2 y - x^3$ and $y_2(\Delta) = 2(-\Delta^2 + 3\Delta + 7)$. For any integer maximum degree $3 \le \Delta \le 8$, the strict inequality $G(x,y) > 0$ holds for all valid integer pairs $1 \le x < y \le \Delta$, excluding the basic variables $(1, \Delta)$ and $(2, \Delta)$.
<!-- end lemma-3 -->
<!-- proof-8: body_md -->
To definitively prove global positivity $G(x,y) > 0$, we first analyze the dual penalty coefficient $y_2(\Delta)$. By definition, it evaluates to:
\begin{equation*}
y_2(\Delta) = 2\big(f(1,\Delta) - f(2,\Delta)\big) = 2(-\Delta^2 + 3\Delta + 7).
\end{equation*}
Taking the derivative $y_2'(\Delta) = -4\Delta + 6$, we observe that $y_2(\Delta)$ is strictly decreasing on the interval $[3, 8]$. Consequently, it attains its maximum at $\Delta = 3$ with $y_2(3) = 14$, and its absolute minimum at $\Delta = 8$ with $y_2(8) = -66$.

With these bounds established, we partition the valid domain into three strictly defined, mutually exclusive cases based on the value of $x$.

\textbf{Case 1:} $x = 1$ and $y \in [2, \Delta-1]$.
By the definition of the dual constraints, $G(1, \Delta) = 0$. We express $G(1,y)$ directly as:
\begin{equation*}
G(1,y) = f(1,\Delta) - f(1,y) + y_2(\Delta) \left( \frac{1}{y} - \frac{1}{\Delta} \right).
\end{equation*}
Substituting $f(1,y) = y^3 + y^2 - y - 1$ and factoring the difference of polynomials yields:
\begin{equation*}
f(1,\Delta) - f(1,y) = (\Delta - y)(\Delta^2 + \Delta y + y^2 + \Delta + y - 1).
\end{equation*}
We rewrite the fractional term as $y_2(\Delta) \frac{\Delta - y}{y\Delta}$ and factor out the common term $(\Delta - y)$:
\begin{equation*}
G(1,y) = (\Delta - y) \left[ \Delta^2 + \Delta y + y^2 + \Delta + y - 1 + \frac{y_2(\Delta)}{y\Delta} \right].
\end{equation*}
Since $y \le \Delta - 1$, the first factor is strictly positive $(\Delta - y \ge 1)$. Given $\Delta \ge 3$ and $y \ge 2$, the polynomial within the bracket is strictly bounded below by its evaluation at the minimal bounds:
\begin{equation*}
\Delta^2 + \Delta y + y^2 + \Delta + y - 1 \ge 3^2 + 3(2) + 2^2 + 3 + 2 - 1 = 23.
\end{equation*}
Next, we determine the lower bound for the fractional term $\frac{y_2(\Delta)}{y\Delta}$. Isolating the dependence on $\Delta$ yields:
\begin{equation*}
\frac{y_2(\Delta)}{\Delta} = \frac{-2\Delta^2 + 6\Delta + 14}{\Delta} = -2\Delta + 6 + \frac{14}{\Delta}.
\end{equation*}
Let $H(\Delta) = -2\Delta + 6 + \frac{14}{\Delta}$. Taking the derivative $H'(\Delta) = -2 - \frac{14}{\Delta^2} < 0$ dictates that $H(\Delta)$ is strictly decreasing on $[3, 8]$. It attains its absolute minimum at the upper boundary $\Delta = 8$:
\begin{equation*}
H(\Delta) \ge H(8) = -16 + 6 + \frac{14}{8} = -8.25.
\end{equation*}
Because this minimum is negative, dividing by the positive independent variable $y$ yields the most negative possible fraction when $y$ is minimized ($y = 2$). Therefore:
\begin{equation*}
\frac{y_2(\Delta)}{y\Delta} = \frac{1}{y} H(\Delta) \ge \frac{1}{2}(-8.25) = -4.125.
\end{equation*}
Summing these bounds, the bracketed expression is strictly greater than $23 - 4.125 = 18.875 > 0$. Being the product of two strictly positive terms, $G(1,y) > 0$.

\textbf{Case 2:} $x = 2$ and $y \in [3, \Delta-1]$.
By exact constraint evaluation, $G(2, \Delta) = 0$. We analyze the monotonicity of $G(2,y)$ by computing its partial derivative with respect to $y$:
\begin{equation*}
\frac{\partial G(2,y)}{\partial y} = -\frac{\partial f(2,y)}{\partial y} - \frac{y_2(\Delta)}{y^2} = -(3y^2 + 4y - 4) - \frac{y_2(\Delta)}{y^2}.
\end{equation*}
For $y \ge 3$, the polynomial component is bounded as $3y^2 + 4y - 4 \ge 27 + 12 - 4 = 35$. Referencing the extremal values of $y_2(\Delta)$ established at the beginning of the proof, the maximum magnitude of $-y_2(\Delta)$ is exactly $-y_2(8) = 66$. Combined with the minimum of $y^2 = 9$, we obtain $-y_2(\Delta)/y^2 \le 66/9 \approx 7.33$.
\begin{equation*}
\frac{\partial G(2,y)}{\partial y} \le -35 + 7.33 = -27.67 < 0.
\end{equation*}
Since the derivative is strictly negative, $G(2,y)$ is strictly decreasing. Because the function evaluates to zero at the upper boundary, it directly implies that for all internal points $y < \Delta$, the strict inequality $G(2,y) > G(2,\Delta) = 0$ holds.

\textbf{Case 3:} $x \ge 3$ and $y \in [4, \Delta]$.
We analyze the general partial derivative with respect to $y$:
\begin{equation*}
\frac{\partial G(x,y)}{\partial y} = -(3y^2 + 2xy - x^2) - \frac{y_2(\Delta)}{y^2}.
\end{equation*}
Let $P(x,y) = 3y^2 + 2xy - x^2$. Since $\frac{\partial P}{\partial x} = 2(y-x) > 0$, the function $P$ strictly increases with $x$. Bounding $x \ge 3$ and $y > x \implies y \ge 4$:
\begin{equation*}
P(x,y) \ge P(3,y) = 3y^2 + 6y - 9 \ge P(3,4) = 48 + 24 - 9 = 63.
\end{equation*}
Using the previously established maximum $-y_2(8) = 66$ and minimum $y^2 = 16$, we bound the fractional term as $-y_2(\Delta)/y^2 \le 66/16 = 4.125$, obtaining a strict upper bound:
\begin{equation*}
\frac{\partial G(x,y)}{\partial y} \le -63 + 4.125 = -58.875 < 0.
\end{equation*}
Thus, for any $x \ge 3$, the function strictly decreases with $y$, meaning its minimum must occur at $y = \Delta$. We now evaluate the behavior along this upper boundary $G(x, \Delta)$ by taking the partial derivative with respect to $x$:
\begin{equation*}
\frac{\partial G(x, \Delta)}{\partial x} = (3x^2 + 2x\Delta - \Delta^2) - \frac{y_2(\Delta)}{x^2}.
\end{equation*}
Let $Q(x, \Delta) = 3x^2 + 2x\Delta - \Delta^2$. Since $\frac{\partial Q}{\partial x} = 6x + 2\Delta > 0$, $Q$ is strictly increasing with $x$. For $x \ge 3$:
\begin{equation*}
Q(x, \Delta) \ge Q(3, \Delta) = 27 + 6\Delta - \Delta^2.
\end{equation*}
The quadratic function $27 + 6\Delta - \Delta^2$ is monotonically decreasing on $[3, 8]$ and achieves its minimum at $\Delta=8$, evaluating to $27 + 48 - 64 = 11$. For the independent fractional term, the minimum of $-y_2(\Delta)$ occurs at its maximum positive value, $y_2(3) = 14$, so $-y_2(\Delta)/x^2 \ge -14/9$. Thus:
\begin{equation*}
\frac{\partial G(x, \Delta)}{\partial x} \ge 11 - \frac{14}{9} = \frac{85}{9} > 0.
\end{equation*}
Because $\frac{\partial G(x, \Delta)}{\partial x} > 0$, the boundary function $G(x, \Delta)$ strictly increases with $x$. Its absolute minimum over $x \ge 3$ occurs exactly at $x = 3$. Evaluating $G(3, \Delta)$ directly yields a downward-opening parabola:
\begin{equation*}
G(3, \Delta) = -\frac{2}{3}\Delta^2 + 4\Delta + \frac{50}{3}.
\end{equation*}
This parabola takes its absolute minimum on the interval $[3, 8]$ at $\Delta = 8$, evaluating to $G(3, 8) = \frac{18}{3} = 6 > 0$. 

Since $G(x,y) > 0$ strictly holds across all three mutually exclusive and exhaustive cases, the proof is complete.

<!-- lemma-5: body_md -->
\label{lem:ag_alt_gap}
For any integer maximum degree $3 \le \Delta \le 8$, the alternative gap function $G^*(x,y)$ for the Arithmetic-Geometric ($AG$) index is strictly positive for all valid integer pairs $1 \le x \le y \le \Delta$, excluding the basis variables $(1, \Delta)$ and $(\Delta, \Delta)$.
<!-- end lemma-5 -->
<!-- proof-13: body_md -->
From Lemma \ref{lem:alternative-f-condition}, the continuous extension of the alternative gap function and its dual penalty coefficient are analytically defined as:
\begin{equation*}
G^*(x,y) = 1 - \frac{x+y}{2\sqrt{xy}} + y_2^*(\Delta) \left( \frac{1}{x} + \frac{1}{y} - \frac{2}{\Delta} \right), \qquad y_2^*(\Delta) = \frac{\Delta}{\Delta - 1} \left( \frac{\Delta+1}{2\sqrt{\Delta}} - 1 \right).
\end{equation*}

We first establish that the penalty coefficient is strictly positive. Since $\frac{\Delta+1}{2\sqrt{\Delta}} > 1$ for all $\Delta \ge 2$, it trivially follows that $y_2^*(\Delta) > 0$. To prove $G^*(x,y) > 0$ for all non-basic pairs, we partition the valid domain into two cases.

\textbf{Case 1: $x = y < \Delta$.} \\
The alternative gap function simplifies to:
\begin{equation*}
G^*(x,x) = 1 - 1 + y_2^*(\Delta) \left( \frac{2}{x} - \frac{2}{\Delta} \right) = 2y_2^*(\Delta) \frac{\Delta - x}{x\Delta}.
\end{equation*}
Given $y_2^*(\Delta) > 0$ and $x < \Delta$, the fractional multiplier is strictly positive, guaranteeing $G^*(x,x) > 0$.

\textbf{Case 2: $x < y \le \Delta$.} \\
We evaluate the monotonicity of $G^*(x,y)$ with respect to its second variable by computing the partial derivative:
\begin{equation*}
\frac{\partial G^*(x,y)}{\partial y} = -\frac{\partial f(x,y)}{\partial y} - \frac{y_2^*(\Delta)}{y^2} = -\frac{y-x}{4\sqrt{x}y^{3/2}} - \frac{y_2^*(\Delta)}{y^2}.
\end{equation*}
Since $y > x$ and $y_2^*(\Delta) > 0$, both terms are strictly negative, yielding $\frac{\partial G^*}{\partial y} < 0$. This ensures that for any fixed $x$, the penalty function $G^*(x,y)$ is strictly decreasing as $y$ increases. Consequently, the absolute minimum over $y$ occurs at the upper boundary, establishing the lower bound $G^*(x,y) \ge G^*(x, \Delta)$.

To prove global positivity, we formally evaluate $G^*(x, \Delta)$. By factoring the penalty coefficient to $y_2^*(\Delta) = \frac{\sqrt{\Delta}(\sqrt{\Delta}-1)}{2(\sqrt{\Delta}+1)}$, the continuous boundary evaluates as:
\begin{equation*}
G^*(x, \Delta) = 1 - \frac{x+\Delta}{2\sqrt{x\Delta}} + \frac{\sqrt{\Delta}(\sqrt{\Delta}-1)}{2(\sqrt{\Delta}+1)} \left( \frac{\Delta-x}{x \Delta} \right).
\end{equation*}
By establishing a common denominator and factoring out the positive root difference $(\sqrt{\Delta}-\sqrt{x})$, this expression is transformed into the closed-form product:
\begin{equation*}
G^*(x, \Delta) = \frac{(\sqrt{\Delta}-\sqrt{x})(\sqrt{x}-1)}{2\sqrt{\Delta} x (\sqrt{\Delta}+1)} \big[ (\sqrt{\Delta}+1)\sqrt{x} - \sqrt{\Delta}(\sqrt{\Delta}-1) \big].
\end{equation*}
For any strictly internal degree $1 < x < \Delta$, the fractional coefficient is strictly positive. Therefore, the sign of the gap function is entirely governed by the bracketed factor. To guarantee $G^*(x, \Delta) > 0$, the following strict inequality must hold:
\begin{equation*}
(\sqrt{\Delta}+1)\sqrt{x} - \sqrt{\Delta}(\sqrt{\Delta}-1) > 0 \implies \sqrt{x} > \frac{\sqrt{\Delta}(\sqrt{\Delta}-1)}{\sqrt{\Delta}+1}.
\end{equation*}
Let $R(\Delta) = \frac{\sqrt{\Delta}(\sqrt{\Delta}-1)}{\sqrt{\Delta}+1}$. The derivative of $R(\Delta)$, which is
$R'(\Delta) = \frac{(\sqrt{\Delta} + 1)^2 - 2}{2\sqrt{\Delta} (\sqrt{\Delta} + 1)^2}$, confirms it is strictly monotonically increasing. Over the specified parameter space $3 \le \Delta \le 8$, $R(\Delta)$ achieves its maximum at $\Delta = 8$, evaluating to $R(8) = \frac{8 - \sqrt{8}}{\sqrt{8} + 1} \approx 1.35$. Since the minimum possible internal degree is $x=2$, the analytical inequality $\sqrt{x} \ge \sqrt{2} \approx 1.414 > R(8) \ge R(\Delta)$ is unequivocally satisfied.

Because the boundary condition $G^*(x, \Delta)$ remains strictly positive, $G^*(x,y) > 0$ universally holds across the entire non-basic domain.

<!-- corollary-8: body_md -->
\label{cor:ag_chemical}
Let $T$ be a chemical tree ($\Delta = 3$) of order $n \ge 5$. The maximum value of the Arithmetic-Geometric ($AG$) index is uniquely determined by the alternative basis $\{(1, 3), (3, 3)\}$. Specifically:
\begin{itemize}
    \item If $n$ is even, the optimal tree consists strictly of $m_{1,3}$ and $m_{3,3}$ edges.
    \item If $n$ is odd, the optimal integer configuration includes exactly one degree-2 vertex, strictly introducing $m_{2,3} = 2$ alongside the basis edges.
\end{itemize}
<!-- end corollary-8 -->
<!-- proof-14: body_md -->
By Lemma \ref{lem:alternative-f-condition} and Lemma \ref{lem:ag_alt_gap}, the LP maximization for $\Delta=3$ maps to the alternative basis $\mathcal{B} = \{(1,3), (3,3)\}$. To construct the continuous upper bound, we evaluate the dual variables. From Lemma \ref{lem:ag_alt_gap}, the penalty coefficient for $\Delta=3$ is $y_2^*(3) = \frac{3}{2}\big(\frac{4}{2\sqrt{3}} - 1\big) = \sqrt{3} - \frac{3}{2}$. 

The binding dual constraint for the basis edge $(3,3)$ dictates $y_1^* + \frac{2}{3}y_2^* = f(3,3)$. Since $f(3,3) = 1$, isolating the first dual variable yields $y_1^* = 1 - \frac{2}{3}(\sqrt{3} - \frac{3}{2}) = 2 - \frac{2}{\sqrt{3}}$.

Applying the decomposition from Eq. \eqref{eq:general_ti_decomposition}, the parameters resolve to $A = y_1^* + y_2^* = \frac{1}{\sqrt{3}} + \frac{1}{2}$ and $B = -y_1^* = \frac{2}{\sqrt{3}} - 2$. Consequently, the objective function reduces to:
\begin{equation}
AG(T) = \left( \frac{1}{\sqrt{3}} + \frac{1}{2} \right)n + \left( \frac{2}{\sqrt{3}} - 2 \right) - \sum_{(i,j) \notin \{(1,3), (3,3)\}} G^*(i,j)\, m_{i,j}.
\end{equation}

If $n$ is even, the LP solutions $m_{1,3} = \frac{n+2}{2}$ and $m_{3,3} = \frac{n-4}{2}$ are integers. Setting all non-basic $m_{i,j} = 0$ results in a zero penalty, defining the optimal tree.

If $n$ is odd, a tree restricted to degrees 1 and 3 cannot exist. The graph must contain at least one vertex of degree 2 ($n_2 \ge 1$). From the incidence relation \eqref{eq:tree-ni-2}, the degree-2 edges satisfy $m_{1,2} + 2m_{2,2} + m_{2,3} = 2n_2$. Multiplying this identity by $G^*(2,3) \approx 0.018$ gives:
\begin{equation}
2n_2 G^*(2,3) = G^*(2,3)m_{1,2} + 2G^*(2,3)m_{2,2} + G^*(2,3)m_{2,3}.
\end{equation}

Explicit evaluation of the non-basic gap penalties confirms the inequalities $G^*(1,2) \approx 0.133 > G^*(2,3)$ and $G^*(2,2) \approx 0.077 > 2G^*(2,3) \approx 0.036$. This establishes a lower bound for the total penalty function:
\begin{align}
\sum_{(i,j) \notin \{(1,3), (3,3)\}} G^*(i,j) m_{i,j} &= G^*(1,2)m_{1,2} + G^*(2,2)m_{2,2} + G^*(2,3)m_{2,3} \nonumber \\
&\ge G^*(2,3)m_{1,2} + 2G^*(2,3)m_{2,2} + G^*(2,3)m_{2,3} \nonumber \\
&= 2n_2 G^*(2,3).
\end{align}

Since $n_2 \ge 1$, the minimum penalty is bounded below by $2G^*(2,3)$. This minimum is attained if and only if $n_2 = 1$, $m_{2,3} = 2$, and $m_{1,2} = m_{2,2} = 0$. Substituting $m_{2,3} = 2$ into the LP constraints shifts the basic variables to $m_{1,3} = \frac{n+1}{2}$ and $m_{3,3} = \frac{n-5}{2}$, generating a valid integer configuration.

<!-- corollary-9: body_md -->
\label{cor:ag_delta4}
Let $T$ be a tree of order $n \ge 6$ with maximum degree $\Delta = 4$. The maximum value of the Arithmetic-Geometric ($AG$) index is uniquely determined by the alternative basis $\{(1, 4), (4, 4)\}$. Specifically:
\begin{itemize}
    \item If $n \equiv 2 \pmod 3$, the optimal tree consists solely of $m_{1,4}$ and $m_{4,4}$ edges.
    \item If $n \equiv 1 \pmod 3$, the optimal configuration includes exactly one degree-3 vertex, introducing $m_{3,4} = 3$ alongside the basis edges.
    \item If $n \equiv 0 \pmod 3$, the optimal configuration includes exactly one degree-2 vertex, introducing $m_{2,4} = 2$ alongside the basis edges.
\end{itemize}
<!-- end corollary-9 -->
<!-- proof-15: body_md -->
By Lemma \ref{lem:alternative-f-condition}, the LP maximization for $\Delta=4$ maps to the alternative basis $\mathcal{B} = \{(1,4), (4,4)\}$. To construct the continuous upper bound, we evaluate the dual variables. The penalty coefficient evaluates to $y_2^*(4) = \frac{4}{3}(\frac{5}{4} - 1) = \frac{1}{3}$. 

The dual constraint for the basis edge $(4,4)$ dictates $y_1^* + \frac{2}{4}y_2^* = f(4,4)$. Since $f(4,4) = 1$, isolating $y_1^*$ yields $y_1^* = 1 - \frac{1}{2}(\frac{1}{3}) = \frac{5}{6}$.



Applying the decomposition from Eq. \eqref{eq:general_ti_decomposition}, the parameters resolve to $A = y_1^* + y_2^* = \frac{5}{6} + \frac{1}{3} = \frac{7}{6}$ and $B = -y_1^* = -\frac{5}{6}$. The objective function reduces to:
\begin{equation}
AG(T) = \frac{7}{6}n - \frac{5}{6} - \sum_{(i,j) \notin \{(1,4), (4,4)\}} G^*(i,j)\, m_{i,j}.
\end{equation}

The LP solutions are $m_{1,4} = \frac{2n+2}{3}$ and $m_{4,4} = \frac{n-5}{3}$. 

If $n \equiv 2 \pmod 3$, these solutions are integers. Setting all non-basic $m_{i,j} = 0$ results in a zero penalty, defining the optimal tree.

If $n \not\equiv 2 \pmod 3$, a tree restricted to degrees 1 and 4 cannot exist. The graph must contain internal vertices of degree $k \in \{2,3\}$. Evaluation of the non-basic gap penalties yields: $G^*(3,4) \approx 0.017$, $G^*(2,4) \approx 0.023$, $G^*(3,3) \approx 0.055$, $G^*(2,3) \approx 0.090$, $G^*(1,3) \approx 0.123$, $G^*(2,2) \approx 0.166$, and $G^*(1,2) \approx 0.272$. 

To minimize the penalty, we analyze the lower bound required to introduce these vertices using the incidence identities \eqref{eq:tree-ni-i}.

For any degree-3 vertex ($n_3 \ge 1$), the identity $m_{1,3} + m_{2,3} + 2m_{3,3} + m_{3,4} = 3n_3$ holds. Since $G^*(1,3) > G^*(3,4)$, $G^*(2,3) > G^*(3,4)$, and $G^*(3,3) \approx 0.055 > 2G^*(3,4) \approx 0.034$, the penalty associated with degree-3 vertices is bounded below:
\begin{align}
\sum_{(i,3) \text{ or } (3,j)} G^*(i,j) m_{i,j} &= G^*(1,3)m_{1,3} + G^*(2,3)m_{2,3} + G^*(3,3)m_{3,3} + G^*(3,4)m_{3,4} \nonumber \\
&\ge G^*(3,4)m_{1,3} + G^*(3,4)m_{2,3} + 2G^*(3,4)m_{3,3} + G^*(3,4)m_{3,4} \nonumber \\
&= 3n_3 G^*(3,4).
\end{align}

Similarly, for any degree-2 vertex ($n_2 \ge 1$), the identity $m_{1,2} + 2m_{2,2} + m_{2,3} + m_{2,4} = 2n_2$ holds. Since $G^*(1,2) > G^*(2,4)$, $G^*(2,3) > G^*(2,4)$, and $G^*(2,2) \approx 0.166 > 2G^*(2,4) \approx 0.046$, the penalty contribution is bounded below:
\begin{align}
\sum_{(i,2) \text{ or } (2,j)} G^*(i,j) m_{i,j} &= G^*(1,2)m_{1,2} + G^*(2,2)m_{2,2} + G^*(2,3)m_{2,3} + G^*(2,4)m_{2,4} \nonumber \\
&\ge G^*(2,4)m_{1,2} + 2G^*(2,4)m_{2,2} + G^*(2,4)m_{2,3} + G^*(2,4)m_{2,4} \nonumber \\
&= 2n_2 G^*(2,4).
\end{align}

To determine which non-basic vertices must be introduced, we subtract the vertex sum identity ($n_1 + n_2 + n_3 + n_4 = n$) from the degree sum identity ($n_1 + 2n_2 + 3n_3 + 4n_4 = 2n-2$) to isolate $3n_4 = n - 2 - n_2 - 2n_3$. This yields the modular congruence:
\begin{equation}
\label{eq:diophantine-mod3}
n_2 + 2n_3 \equiv n - 2 \pmod 3.
\end{equation}

\textbf{Case $n \equiv 1 \pmod 3$:} 
Constraint \eqref{eq:diophantine-mod3} evaluates to $n_2 + 2n_3 \equiv 2 \pmod 3$. The minimal integer pairs satisfying this congruence are $(0, 1)$ and $(2, 0)$. 
If $(n_2, n_3) = (2, 0)$, the penalty is bounded below by $2 \times (2G^*(2,4)) \approx 0.092$.
If $(n_2, n_3) = (0, 1)$, the penalty is bounded below by $1 \times (3G^*(3,4)) \approx 0.051$.
Since $0.051 < 0.092$, the minimum penalty is attained by setting $n_3 = 1$ and $n_2 = 0$. Substituting $m_{3,4} = 3$ into the LP constraints shifts the basic variables to $m_{1,4} = \frac{2n+1}{3}$, generating a valid integer configuration.

\textbf{Case $n \equiv 0 \pmod 3$:} 
Constraint \eqref{eq:diophantine-mod3} evaluates to $n_2 + 2n_3 \equiv 1 \pmod 3$. The minimal integer pairs satisfying this relation are $(1, 0)$ and $(0, 2)$.
If $(n_2, n_3) = (0, 2)$, the lower penalty bound is $2 \times (3G^*(3,4)) \approx 0.102$.
If $(n_2, n_3) = (1, 0)$, the lower penalty bound is $1 \times (2G^*(2,4)) \approx 0.046$.
Since $0.046 < 0.102$, the minimum penalty is attained by setting $n_2 = 1$ and $n_3 = 0$. Substituting $m_{2,4} = 2$ resolves the basic constraints to $m_{1,4} = \frac{2n}{3}$, defining the minimal discrete configuration.

<!-- theorem-2: body_md -->
\label{thm:degree_dependent_k}
Let $T$ be a tree of order $n$ and maximum degree $\Delta \ge 3$. The linear program maximizing the $SO_{11}$ index admits an optimal basic feasible solution generated by the basis $\{(1, \Delta), (k, \Delta)\}$, where the optimal integer degree $k$ is uniquely determined by maximizing the characteristic polynomial:
\begin{equation}
M(k) = -k^3 - (\Delta+1)k^2 + (\Delta^2-\Delta-1)k.
\end{equation}
This integer solution is strictly bounded to $k \in \{\lfloor x^* \rfloor, \lceil x^* \rceil\}$, where $x^*$ is the continuous critical point evaluated as the positive root:
\begin{equation}
x^* = \frac{\sqrt{4\Delta^2 - \Delta - 2} - (\Delta + 1)}{3}.
\end{equation}
<!-- end theorem-2 -->
<!-- proof-16: body_md -->
To establish the global optimality of the basis $\{(1, \Delta), (k, \Delta)\}$, we evaluate the dual variables $y_1$ and $y_2$. By strict complementary slackness:
\begin{align}
y_1 + \left(1 + \frac{1}{\Delta}\right)y_2 &= f(1, \Delta), \label{eq:dual_dyn1}\\
y_1 + \left(\frac{1}{k} + \frac{1}{\Delta}\right)y_2 &= f(k, \Delta). \label{eq:dual_dyn2}
\end{align}
Subtracting \eqref{eq:dual_dyn2} from \eqref{eq:dual_dyn1} isolates the dual penalty coefficient:
\begin{equation*}
\left(1 - \frac{1}{k}\right)y_2 = f(1, \Delta) - f(k, \Delta) \implies y_2 = \frac{k}{k-1} \big( f(1, \Delta) - f(k, \Delta) \big).
\end{equation*}
We define the characteristic function $M(k) = -y_2 = \frac{k}{k-1} \big( f(k, \Delta) - f(1, \Delta) \big)$. 
For the $SO_{11}$ index, $f(x,y) = y^3 + y^2 x - x^2 y - x^3$. The algebraic difference evaluates to:
\begin{align*}
f(k, \Delta) - f(1, \Delta) &= (\Delta^3 + k\Delta^2 - k^2\Delta - k^3) - (\Delta^3 + \Delta^2 - \Delta - 1) \\
&= (k-1)\Delta^2 - (k^2-1)\Delta - (k^3-1).
\end{align*}
Factoring out the term $(k-1)$ cleanly cancels the denominator in the definition of $M(k)$, yielding the cubic polynomial:
\begin{equation*}
M(k) = -k^3 - (\Delta+1)k^2 + (\Delta^2-\Delta-1)k.
\end{equation*}

The basis is strictly optimal if and only if the dual gap satisfies $G_k^*(x, \Delta) \ge 0$ for all valid degrees $x$. The gap function is defined as:
\begin{equation*}
G_k^*(x, \Delta) = f(1, \Delta) - f(x, \Delta) - y_2 \left( 1 - \frac{1}{x} \right).
\end{equation*}
Substituting $y_2 = -M(k)$ and factoring out $\frac{x-1}{x}$ yields:
\begin{align*}
G_k^*(x, \Delta) &= f(1, \Delta) - f(x, \Delta) + M(k) \left( \frac{x-1}{x} \right) \\
&= \frac{x-1}{x} \left[ \frac{x}{x-1} \big( f(1, \Delta) - f(x, \Delta) \big) + M(k) \right] \\
&= \frac{x-1}{x} \big[ M(k) - M(x) \big].
\end{align*}
For any valid degree $x > 1$, the fractional prefix $\frac{x-1}{x}$ is strictly positive. Therefore, the condition $G_k^*(x, \Delta) \ge 0$ inherently holds if and only if $M(k) \ge M(x)$ for all integer alternatives $x$. This is satisfied by selecting the optimal integer $k$ as the maximum of the polynomial $M$.

To determine this maximum analytically, we set the derivative of the continuous extension to zero, $M'(x) = -3x^2 - 2(\Delta+1)x + (\Delta^2-\Delta-1) = 0$. The global maximum corresponds to the positive root:
\begin{equation*}
x^* = \frac{\sqrt{4\Delta^2 - \Delta - 2} - (\Delta + 1)}{3}.
\end{equation*}
Since the optimal degree $k$ must be an integer, it is strictly bounded to the nearest integers $k \in \{\lfloor x^* \rfloor, \lceil x^* \rceil\}$.

<!-- corollary-10: body_md -->
The optimal basis for the $SO_{11}$ index strictly transitions from $k=2$ to $k=3$ at $\Delta = 9$. Asymptotically, as $\Delta \to \infty$, the optimal integer degree scales proportionally to $\Delta/3$.
<!-- end corollary-10 -->
<!-- proof-17: body_md -->
By Theorem \ref{thm:degree_dependent_k}, the optimal integer degree $k$ is determined by maximizing $M(k)$ near the critical point $x^*$. We evaluate the polynomial at the bounding integers to identify the transition threshold:
\begin{itemize}
    \item For $\Delta = 8$: $x^* = \frac{\sqrt{246}-9}{3} \approx 2.23$. Evaluating the bounding integers yields $M(2) = 66$ and $M(3) = 57$. Since $M(2) > M(3)$, the basis $k=2$ remains optimal.
    \item For $\Delta = 9$: $x^* = \frac{\sqrt{313}-10}{3} \approx 2.56$. Evaluating the bounding integers yields $M(2) = 94$ and $M(3) = 96$. Since $M(3) > M(2)$, the optimal basis strictly shifts to $k=3$.
\end{itemize}

To determine the asymptotic scaling, we evaluate the limit of the continuous critical point as $\Delta \to \infty$:
\begin{equation*}
\lim_{\Delta \to \infty} \frac{x^*}{\Delta} = \lim_{\Delta \to \infty} \frac{\sqrt{4\Delta^2 - \Delta - 2} - (\Delta + 1)}{3\Delta} = \frac{2 - 1}{3} = \frac{1}{3}.
\end{equation*}
Consequently, $x^* \sim \frac{\Delta}{3}$. This rigorously demonstrates that for sufficiently large maximum degrees, the optimal basis parameter strictly diverges from the boundaries $k=2$ and $k=\Delta$, scaling precisely as a one-third fraction of the maximum degree.
