<!-- theorem-2: body_md -->
\label{thm:cts}
  Suppose that an automorphism $\pi$ of $\mathcal{D}_{\mathrm{tt}}$ is induced by a continuous
  function $F\colon2^{\omega}\to2^{\omega}$. Then $\pi$ is the identity, that is,
  $F(X)\equiv_{\mathrm{tt}} X$ for all $X$. Moreover, every nonempty open subset of $2^{\omega}$
  contains a basic open set $N_\tau$ on which $F$ coincides with a total
  computable functional and has a total computable left inverse: there are
  total computable $\Lambda,\Gamma\colon2^{\omega}\to2^{\omega}$ with
  $F(Z)=\Lambda(Z)$ and $\Gamma(F(Z))=Z$ for all $Z\in N_\tau$.

<!-- lemma-1: body_md -->
\label{lem:2adic}
  \begin{enumerate}
  \item\label{2a:tt} The maps $(X,Y)\mapsto X+Y$ and $X\mapsto -X$ are
    computable and total; in particular $X+Y\le_{\mathrm{tt}} X\oplus Y$ and $-X\le_{\mathrm{tt}} X$.
    For each $n$, $(X+Y)\upharpoonright n$ depends only on $X\upharpoonright n$ and $Y\upharpoonright n$: it is
    the binary expansion of the sum of the two integers modulo $2^{n}$.
  \item\label{2a:sub} For each $k$, $N_{0^{k}}$ is a subgroup. If $T\in
    N_{0^{k}}$ then $(X+T)\upharpoonright k=X\upharpoonright k$ for every $X$. Consequently, for
    every $\alpha\in2^{<\omega}$ with $|\alpha|\le k$ and every $T\in N_{0^{k}}$,
    the translation $X\mapsto X+T$ is a homeomorphism of $N_\alpha$ onto
    itself.
  \item\label{2a:half} $2X=0{}^{\frown} X$. For $T\in N_{0^{1}}$ put $T/2=S(T)$; then
    $2(T/2)=T$, the map $T\mapsto T/2$ is computable on $N_{0^1}$, and
    $T\in N_{0^{k+1}}$ implies $T/2\in N_{0^{k}}$.
  \item\label{2a:prefix} Let $\tau\in2^{<\omega}$ have length $l$ and let
    $W\in2^{\omega}$. Then $\tau{}^{\frown} 0^{\omega}+0^{l}{}^{\frown} W=\tau{}^{\frown} W$.
  \end{enumerate}
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
All of this is immediate from the definition of addition with carries.
  For~\eqref{2a:sub}, $N_{0^k}$ is the set of $2$-adic integers divisible by
  $2^{k}$; the translation by $T\in N_{0^{k}}$ maps $N_\alpha$ into itself, and
  so does its inverse, the translation by $-T\in N_{0^{k}}$.
  For~\eqref{2a:prefix}, no carry occurs.

<!-- lemma-2: body_md -->
\label{lem:basic}
  Suppose that $F\colon2^{\omega}\to2^{\omega}$ induces an automorphism $\pi$ of
  $\mathcal{D}_{\mathrm{tt}}$. Then for all $A,B\in2^{\omega}$:
  \begin{itemize}
  \item[\textup{(M)}] if $A\le_{\mathrm{tt}} B$ then $F(A)\le_{\mathrm{tt}} F(B)$;
  \item[\textup{(J)}] $F(A\oplus B)\equiv_{\mathrm{tt}} F(A)\oplus F(B)$;
  \item[\textup{(C)}] if $A$ is computable then $F(A)$ is computable;
  \item[\textup{(I)}] if $F(A)\equiv_{\mathrm{tt}} F(B)$ then $A\equiv_{\mathrm{tt}} B$.
  \end{itemize}
  Consequently:
  \begin{itemize}
  \item[\textup{(N)}] $F$ is not constant on any uncountable set; in
    particular $F$ is not constant on any nonempty open set, nor on any set
    which is comeager in a nonempty open set.
  \end{itemize}
<!-- end lemma-2 -->
<!-- proof-2: body_md -->
(M) and (I) hold because $\pi$ is an order isomorphism. (J) and (C) hold
  because an automorphism of a partial order preserves least upper bounds and
  the least element. For (N): a truth-table degree is a countable set of reals,
  so an uncountable set contains $A,B$ with $A\not\equiv_{\mathrm{tt}} B$, and then
  $F(A)\neq F(B)$ by (I). A set which is comeager in a nonempty open subset of
  $2^{\omega}$ is uncountable.
<!-- end proof-2 -->
<!-- lemma-3: body_md -->
\label{lem:basicD}
  Let $\pi$ be an automorphism of $\mathcal{D}_{\mathrm{tt}}$, let $D\subseteq2^{\omega}$, and suppose
  that $F\colon D\to2^{\omega}$ induces $\pi$ on $D$.
  \begin{enumerate}
  \item\label{bd:mj} Let $B,C_1,\dots,C_n\in D$, where $n\ge 1$. If
    $B\le_{\mathrm{tt}} C_1\oplus\dots\oplus C_n$, then
    $F(B)\le_{\mathrm{tt}} F(C_1)\oplus\dots\oplus F(C_n)$. More generally, let
    $X,A\in2^{\omega}$ with $\deg_{\mathrm{tt}}(A)=\pi(\deg_{\mathrm{tt}}(X))$. If
    $B\le_{\mathrm{tt}} X\oplus C_1\oplus\dots\oplus C_n$, then
    $F(B)\le_{\mathrm{tt}} A\oplus F(C_1)\oplus\dots\oplus F(C_n)$.
  \item\label{bd:inj} If $B,C\in D$ and $F(B)\equiv_{\mathrm{tt}} F(C)$, then $B\equiv_{\mathrm{tt}} C$.
    Consequently $F$ is not constant on any uncountable subset of $D$.
  \end{enumerate}
<!-- end lemma-3 -->
<!-- proof-3: body_md -->
\eqref{bd:mj} Since $\pi$ preserves order and finite joins,
  $\deg_{\mathrm{tt}}(F(B))=\pi(\deg_{\mathrm{tt}}(B))\le\pi(\deg_{\mathrm{tt}}(X)\vee\deg_{\mathrm{tt}}(C_1)\vee\dots\vee\deg_{\mathrm{tt}}(C_n))
  =\pi(\deg_{\mathrm{tt}}(X))\vee\pi(\deg_{\mathrm{tt}}(C_1))\vee\dots\vee\pi(\deg_{\mathrm{tt}}(C_n))
  =\deg_{\mathrm{tt}}(A\oplus F(C_1)\oplus\dots\oplus F(C_n))$. The first statement is proved
  in the same way. \eqref{bd:inj} holds because $\pi$ is injective and
  truth-table degrees are countable.

<!-- lemma-4: body_md -->
\label{lem:unif}
  Let $\mathcal{S}$ be a nonempty Baire space and let
  $\varphi,\psi\colon\mathcal{S}\to2^{\omega}$ be continuous functions such that
  $\varphi(x)\le_{\mathrm{tt}}\psi(x)$ for every $x\in\mathcal{S}$. Then there are a
  nonempty open set $V\subseteq\mathcal{S}$ and a tt-functional $\Phi$
  such that
  \[
    \varphi(x)=\Phi(\psi(x))\qquad\text{for all }x\in V .
  \]
<!-- end lemma-4 -->
<!-- proof-4: body_md -->
For each tt-functional $\Phi$ let
  $C_\Phi=\{x\in\mathcal{S}:\varphi(x)=\Phi(\psi(x))\}$. Since $\varphi$ and
  $\Phi\circ\psi$ are continuous maps into a Hausdorff space, $C_\Phi$ is
  closed in $\mathcal{S}$. By hypothesis $\mathcal{S}=\bigcup_\Phi C_\Phi$, a
  countable union. As $\mathcal{S}$ is a nonempty Baire space, some $C_\Phi$ is
  not nowhere dense, and being closed it has nonempty interior $V$.

<!-- lemma-5: body_md -->
\label{lem:trans}
  Let $E\subseteq D^{*}$ be a set of pairs each of which
  satisfies \textup{(R$_{+}$)}, \textup{(R$_{-}$)}\ and \textup{(R$_{1/2}$)}. Let $G,H,T,\kappa\in2^{\omega}$.
  \begin{enumerate}
  \item\label{tr:trans} If $(G+T,\,H+\kappa)\in E$ and $(G+T+\kappa,\,H)\in E$,

    \[
      F(G+T+\kappa)=\Phi_{-}\Bigl(\Phi_{+}\bigl(F(G+T)\oplus F(H+\kappa)\bigr)\oplus
      F(-H)\Bigr).
    \]
  \item\label{tr:half} If $T\in N_{0^{1}}$, $(G+T,\,H-T/2)\in E$ and
    $(G+T/2,\,H)\in E$, then
    \[
      F(G+T/2)=\Phi_{-}\Bigl(\Phi_{1/2}\bigl(F(G+T)\oplus F(G+2H)\bigr)\oplus
      F(-H)\Bigr).

  \end{enumerate}
<!-- end lemma-5 -->
<!-- proof-5: body_md -->
Note that since $E\subseteq D^{*}$, all arguments of $F$ occurring below lie

<!-- proposition-1: body_md -->
\label{prop:lower}
  Let $F\colon2^{\omega}\to2^{\omega}$ be continuous and suppose that
  \begin{itemize}
  \item[\textup{(M)}] $A\le_{\mathrm{tt}} B$ implies $F(A)\le_{\mathrm{tt}} F(B)$,
  \item[\textup{(J$'$)}] $F(A\oplus B)\le_{\mathrm{tt}} F(A)\oplus F(B)$,
  \item[\textup{(C)}] $F(A)$ is computable whenever $A$ is computable, and
  \item[\textup{(N$'$)}] $F$ is not constant on any nonempty open set.
  \end{itemize}
  Then for every $\rho\in2^{<\omega}$ there are a string $\tau\supseteq\rho$ and a
  tt-functional $\Gamma$ such that
  \[
    \Gamma\bigl(F(\tau{}^{\frown} X)\bigr)=X\qquad\text{for all }X\in2^{\omega}.
  \]
  In particular, $X\le_{\mathrm{tt}} F(X)$ for all $X\in2^{\omega}$.
<!-- end proposition-1 -->
<!-- proof-6: body_md -->
The last sentence follows from the first: $\tau{}^{\frown} X\le_{\mathrm{tt}} X$, so
  $X\le_{\mathrm{tt}} F(\tau{}^{\frown} X)\le_{\mathrm{tt}} F(X)$ by (M). We prove the first assertion. Fix
  $\rho\in2^{<\omega}$.

  \medskip
  \noindent\emph{Step 1: uniform relations on an open set.}
  Here $D=2^{\omega}$ and $D^{*}=2^{\omega}\times2^{\omega}$. By (M) and (J$'$), $F$
  has property \eqref{eq:MJ}, so the reductions \eqref{eq:Fargs} hold for
  every pair $(G,H)$. The maps $(G,H)\mapsto F(G+H)$, $F(G)\oplus F(H)$,
  $F(G)$, $F(G+H)\oplus F(-H)$ and $F(G)\oplus F(G+2H)$ are continuous on
  $2^{\omega}\times2^{\omega}$, since $F$ and the group operations are. We apply
  Lemma~\ref{lem:unif} three times; each time the space is a nonempty open
  subset of the compact space $2^{\omega}\times2^{\omega}$, hence a Baire space.
  First, on the space $N_\rho\times N_\rho$, with $\varphi(G,H)=F(G+H)$ and
  $\psi(G,H)=F(G)\oplus F(H)$, we obtain a nonempty open
  $V_1\subseteq N_\rho\times N_\rho$ and a tt-functional $\Phi_{+}$ such that
  \textup{(R$_{+}$)}\ holds for all pairs in $V_1$. Second, on the space $V_1$, with
  $\varphi(G,H)=F(G)$ and $\psi(G,H)=F(G+H)\oplus F(-H)$, we obtain a nonempty
  open $V_2\subseteq V_1$ and $\Phi_{-}$ such that \textup{(R$_{-}$)}\ holds for all pairs in
  $V_2$. Third, on the space $V_2$, with $\varphi(G,H)=F(G+H)$ and
  $\psi(G,H)=F(G)\oplus F(G+2H)$, we obtain a nonempty open
  $V_3\subseteq V_2$ and $\Phi_{1/2}$ such that \textup{(R$_{1/2}$)}\ holds for all pairs in
  $V_3$. Choose $k$ and $\alpha,\beta\in2^{<\omega}$ with
  $|\alpha|=|\beta|=k$ and $N_\alpha\times N_\beta\subseteq V_3$. Then
  $\alpha\supseteq\rho$, and
  \begin{equation}\label{eq:E}
    \text{every pair in }E:=N_\alpha\times N_\beta
    \text{ satisfies \textup{(R$_{+}$)}, \textup{(R$_{-}$)}\ and \textup{(R$_{1/2}$)}.}
  \end{equation}
  By Lemma~\ref{lem:2adic}\eqref{2a:sub}, $E$ is invariant under translation by
  elements of $N_{0^{k}}\times N_{0^{k}}$.

  \medskip
  \noindent\emph{Step 2: a splitting bit.}
  By (N$'$), $F$ is not constant on $N_\alpha$, so there is $j\in\omega$ such
  that the function $f\colon2^{\omega}\to\{0,1\}$, $f(Z)=F(Z)(j)$, is not constant
  on $N_\alpha$. Since $f$ is continuous and $2^{\omega}$ is compact, there is
  $n_0$ such that $f(Z)$ depends only on $Z\upharpoonright n_0$. Thus $f$ is constant on
  $N_\nu$ whenever $|\nu|\ge n_0$. Let $\tau\supseteq\alpha$ be a string of maximal
  length such that $f$ is not constant on $N_\tau$; such a string exists
  because $\alpha$ has this property and every string with this property has
  length less than $n_0$. By maximality, $f$ is constant on $N_{\tau{}^{\frown} 0}$ and
  on $N_{\tau{}^{\frown} 1}$, and the two constant values are different since $f$ is
  not constant on $N_\tau=N_{\tau{}^{\frown} 0}\cup N_{\tau{}^{\frown} 1}$. Let $l=|\tau|$,
  so $l\ge k$, and let $b$ be the value of $f$ on $N_{\tau{}^{\frown} 0}$. Then
  \begin{equation}\label{eq:read}
    F(\tau{}^{\frown} W)(j)=b\oplus W(0)\qquad\text{for all }W\in2^{\omega} .
  \end{equation}

  \medskip
  \noindent\emph{Step 3: the shift functional.}
  Let
  \[
    G=\tau{}^{\frown} 0^{\omega},\qquad H=\beta{}^{\frown} 0^{\omega},\qquad Y=2^{l}
    =0^{l}{}^{\frown} 1{}^{\frown} 0^{\omega}.
  \]
  These are computable, and so are $H-Y$, $-H$ and $G+2H$. By (C) the reals
  \[
    P_1=F(H-Y),\qquad P_2=F(-H),\qquad P_3=F(G+2H)
  \]
  are computable. By Lemma~\ref{lem:2adic}\eqref{2a:prefix},
  $G+0^{l}{}^{\frown} W=\tau{}^{\frown} W$ for every $W$.

  We claim that there is a tt-functional $\Theta$ such that
  \begin{equation}\label{eq:shift}
    \Theta\bigl(F(\tau{}^{\frown} W)\bigr)=F(\tau{}^{\frown} S(W))
    \qquad\text{for all }W\in2^{\omega} .
  \end{equation}
  Define, for $A\in2^{\omega}$,
  \[
    A'=\begin{cases}
      A & \text{if }A(j)=b,\\
      \Phi_{-}\bigl(\Phi_{+}(A\oplus P_1)\oplus P_2\bigr) & \text{if }A(j)\ne b,
    \end{cases}
  \]
  and
  \[
    \Theta(A)=\Phi_{-}\bigl(\Phi_{1/2}(A'\oplus P_3)\oplus P_2\bigr).
  \]
  Then $\Theta$ is a tt-functional, since $P_1,P_2,P_3$ are computable. To
  verify \eqref{eq:shift}, fix $W$, let $A=F(\tau{}^{\frown} W)$ and
  \[
    T=0^{l}{}^{\frown} W,\qquad T'=0^{l+1}{}^{\frown} S(W).
  \]
  So $T,T'\in N_{0^{l}}\subseteq N_{0^{k}}$, $A=F(G+T)$, $T'\in N_{0^{l+1}}$
  and $T'/2=0^{l}{}^{\frown} S(W)\in N_{0^l}$. If $W(0)=0$ then $T'=T$; if $W(0)=1$
  then $T=T'+Y$ (adding $2^{l}$ to $T'$ changes its bit $l$ from $0$ to $1$,
  with no carry), that is, $T'=T-Y$.

  We first show that $A'=F(G+T')$. If $W(0)=0$ then $A(j)=b$ by
  \eqref{eq:read}, so $A'=A=F(G+T)=F(G+T')$. If $W(0)=1$ then $A(j)\neq b$ by
  \eqref{eq:read}, so $A'=\Phi_{-}(\Phi_{+}(F(G+T)\oplus F(H-Y))\oplus F(-H))$. We
  apply Lemma~\ref{lem:trans}\eqref{tr:trans} with $\kappa=-Y$: the pairs
  $(G+T,H-Y)$ and $(G+T-Y,H)$ belong to $E=N_\alpha\times N_\beta$, because
  $G\in N_\alpha$, $H\in N_\beta$ and $T,\,-Y,\,T-Y\in N_{0^{k}}$. Hence
  $A'=F(G+T-Y)=F(G+T')$.

  Next we apply Lemma~\ref{lem:trans}\eqref{tr:half} to $T'$: the pairs
  $(G+T',H-T'/2)$ and $(G+T'/2,H)$ belong to $E$, because $T'$ and $T'/2$ lie
  in $N_{0^{k}}$. Hence
  \[
    \Theta(A)=\Phi_{-}\bigl(\Phi_{1/2}(F(G+T')\oplus F(G+2H))\oplus F(-H)\bigr)
    =F(G+T'/2)=F(\tau{}^{\frown} S(W)),
  \]
  which is \eqref{eq:shift}.

  \medskip
  \noindent\emph{Step 4: decoding.}
  Define $\Gamma\colon2^{\omega}\to2^{\omega}$ by
  $\Gamma(A)(m)=b\oplus\Theta^{m}(A)(j)$. This is a tt-functional. Let
  $X\in2^{\omega}$. By \eqref{eq:shift} and induction on $m$,
  $\Theta^{m}(F(\tau{}^{\frown} X))=F(\tau{}^{\frown} S^{m}(X))$, so by \eqref{eq:read},
  \[
    \Gamma\bigl(F(\tau{}^{\frown} X)\bigr)(m)=b\oplus F(\tau{}^{\frown} S^{m}(X))(j)
    =b\oplus b\oplus S^{m}(X)(0)=X(m).\qedhere
  \]

<!-- remark-1: body_md -->

  Hypothesis (N$'$) can be replaced by a dichotomy. Let $F$ be continuous and

Let
  \[
    \mathcal{W}=\bigl\{(X,G_1,G_3)\in Q:\ G_1,\ X-G_1,\ G_3,\ X-G_3\in D\bigr\},
  \]
  where $Q$ is as in Lemma~\ref{lem:meet}. Then $\mathcal{W}$ is Borel, since
  $D$ is a $G_\delta$ set and the maps $(X,G)\mapsto X-G$ are continuous. For
  each $X$ the section $\mathcal{W}_X$ is comeager in $2^{\omega}\times2^{\omega}$,
  hence nonempty: it is the intersection of $Q_X$ with the four dense
  $G_\delta$ sets $D\times2^{\omega}$, $(X-D)\times2^{\omega}$, $2^{\omega}\times D$ and
  $2^{\omega}\times(X-D)$, where $X-D=\{X-G:G\in D\}$ is the image of $D$ under
  the homeomorphism $G\mapsto X-G$. On $\mathcal{W}$ define the continuous
  functions
  \[
    K_1(X,G_1,G_3)=F(G_1)\oplus F(X-G_1),\qquad
    K_3(X,G_1,G_3)=F(G_3)\oplus F(X-G_3).
  \]

  \medskip
  \noindent\emph{Claim.} If $(X,G_1,G_3)\in\mathcal{W}$ then $\pi(\deg_{\mathrm{tt}}(X))$ is
  the greatest lower bound of $\deg_{\mathrm{tt}}(K_1)$ and $\deg_{\mathrm{tt}}(K_3)$.

  \smallskip
  Indeed, $G_1\oplus(X-G_1)\equiv_{\mathrm{tt}} X\oplus G_1$ by
  Lemma~\ref{lem:2adic}\eqref{2a:tt}, since $X=G_1+(X-G_1)$. As $F$ induces
  $\pi$ on $D$ and $\pi$ preserves joins,
  \begin{align*}
    \deg_{\mathrm{tt}}(K_1)&=\pi(\deg_{\mathrm{tt}}(G_1))\vee\pi(\deg_{\mathrm{tt}}(X-G_1))\\
    &=\pi\bigl(\deg_{\mathrm{tt}}(G_1)\vee\deg_{\mathrm{tt}}(X-G_1)\bigr)=\pi\bigl(\deg_{\mathrm{tt}}(X\oplus G_1)\bigr),
  \end{align*}
  and likewise $\deg_{\mathrm{tt}}(K_3)=\pi(\deg_{\mathrm{tt}}(X\oplus G_3))$. By
  Lemma~\ref{lem:meet}\eqref{mt:meet}, $\deg_{\mathrm{tt}}(X)$ is the greatest lower bound of
  $\deg_{\mathrm{tt}}(X\oplus G_1)$ and $\deg_{\mathrm{tt}}(X\oplus G_3)$, and an automorphism of a partial
  order maps the greatest lower bound of two elements to the greatest lower
  bound of their images. This proves the claim.

  \medskip
  Let $M$ be the set of triples $(A,K,K')\in(2^{\omega})^{3}$ such that
  \[
    A\le_{\mathrm{tt}} K,\quad A\le_{\mathrm{tt}} K',\quad\text{and for all }B\in2^{\omega},
    \text{ if }B\le_{\mathrm{tt}} K\text{ and }B\le_{\mathrm{tt}} K'\text{ then }B\le_{\mathrm{tt}} A .
  \]
  Thus $(A,K,K')\in M$ if and only if $\deg_{\mathrm{tt}}(A)$ is the greatest lower bound of
  $\deg_{\mathrm{tt}}(K)$ and $\deg_{\mathrm{tt}}(K')$. The relation $\le_{\mathrm{tt}}$ is a countable union of closed
  sets, hence Borel. The last clause in the definition of $M$ is equivalent to:
  for all tt-functionals $\Phi$ and $\Psi$, if $\Phi(K)=\Psi(K')$ then
  $\Phi(K)\le_{\mathrm{tt}} A$. This is a countable conjunction of Borel conditions, so $M$
  is Borel.

  \item[(a)] $(X,A)\in R_\pi$;
  \item[(b)] for all $(G_1,G_3)\in\mathcal{W}_X$, we have

  \item[(c)] for some $(G_1,G_3)\in\mathcal{W}_X$, we have
    $\bigl(A,K_1(X,G_1,G_3),K_3(X,G_1,G_3)\bigr)\in M$.
  \end{enumerate}

  $\mathcal{W}_X\ne\emptyset$; and if (c) holds then $\deg_{\mathrm{tt}}(A)$ and
  $\pi(\deg_{\mathrm{tt}}(X))$ are both the greatest lower bound of $\deg_{\mathrm{tt}}(K_1)$ and
  $\deg_{\mathrm{tt}}(K_3)$ for the witnessing pair, so (a) holds. The set
  \[
    \bigl\{(X,A,G_1,G_3):(X,G_1,G_3)\in\mathcal{W}\text{ and }
    \bigl(A,K_1(X,G_1,G_3),K_3(X,G_1,G_3)\bigr)\in M\bigr\}
  \]
  is Borel, being the preimage of the Borel set $M$ under a continuous function
  defined on a Borel set. By (c), $R_\pi$ is its projection to the coordinates
  $(X,A)$, hence analytic. Similarly, by (b) the complement of $R_\pi$ is the
  projection of the Borel set obtained by replacing ``$\in M$'' by
  ``$\notin M$'', hence analytic. So $R_\pi$ is both analytic and coanalytic,
  and therefore Borel by Suslin's theorem \cite[14.11]{Kec}.

  Theorem~\ref{thm:main}, since they are of different character.

  the identity.}

  Theorem~\ref{thm:main} and Corollary~\ref{cor:bm} are correct as stated with
  a hypothesis on $\pi$ only, is the content of
  Proposition~\ref{prop:inverseD}: a continuous function inducing $\pi$ on a
  comeager set yields a tt-functional inducing $\pi^{-1}$ on a comeager set.
  Its proof uses, in addition, Proposition~\ref{prop:half} for $\pi$ and the
  fact that the sets $B_\Phi$ have the Baire property, which is where

  enough to know that $R_\pi$ is analytic, that is, the equivalence of (a)
  and (c) in the proof of Lemma~\ref{lem:graph}: then each $B_\Phi$ is
  analytic, as a continuous preimage of an analytic set, and analytic sets
  have the Baire property \cite[21.6]{Kec}. Alternatively one uses that
  $R_\pi$ is Borel, as we did. A third route avoids analytic sets altogether:
  with the notation of the proof of Lemma~\ref{lem:graph}, the set
  \[

  nonempty strings $s_0,s_1,\dots\in2^{<\omega}$, and II plays pairs

      \text{I} & s_0 & & s_1 & & \cdots\\ \hline
      \text{II} & & (t_0,a_0) & & (t_1,a_1) & \cdots

  \]

  wins if and only if $(X,A)\in R$. The moves can be coded by integers, so by
  $\mathrm{AD}$ one of the players has a winning strategy. For a finite

  strings played in $p$. We fix an enumeration of $2^{<\omega}$ in order type
  $\omega$; ``least'' refers to it.

  \medskip

  strategy for I. For every position $p$ in which I has just moved according to
  $\varsigma$, and every $a\in\{0,1\}$, let

<!-- definition-1: body_md -->
\label{def:adm}
  An \emph{admissible class} is a countable set $\mathfrak{F}$ of partial
  functionals with the following properties.
  \begin{itemize}
  \item[\textup{(A0)}] For every $\Phi\in\mathfrak{F}$, the set
    $\operatorname{dom}(\Phi)$ is closed, and there is an oracle Turing machine
    which, for every $Y\in\operatorname{dom}(\Phi)$, halts on every input when
    run with oracle $Y$ and computes $\Phi(Y)$.
  \item[\textup{(A1)}] Every tt-functional belongs to $\mathfrak{F}$.
  \item[\textup{(A2)}] For all $\Phi,\Psi\in\mathfrak{F}$ and all $j\in\omega$,
    each of the partial functionals $\Phi\circ\Psi$, $\langle\Phi,\Psi\rangle$,
    $[\Phi,\Psi]_j$ and $\operatorname{It}_j(\Phi,\Psi)$ is extended by some
    element of $\mathfrak{F}$.
  \end{itemize}

\label{lem:adm}
  Let $\mathfrak{F}$ be an admissible class.
  \begin{enumerate}
  \item\label{adm:order} The relation $\le_{\mathfrak{F}}$ is reflexive and
    transitive, and for all $A,B$: $A\le_{\mathrm{tt}} B$ implies $A\le_{\mathfrak{F}}B$,
    and $A\le_{\mathfrak{F}}B$ implies $A\le_{\mathrm{T}}B$. Every
    $\mathfrak{F}$-degree is countable. The degree of $A\oplus B$ is the least
    upper bound of the degrees of $A$ and $B$ in $\mathcal{D}_{\mathfrak{F}}$,
    and the computable reals form the least element of
    $\mathcal{D}_{\mathfrak{F}}$.
  \item\label{adm:closed} Every $\Phi\in\mathfrak{F}$ is continuous on
    $\operatorname{dom}(\Phi)$, and its graph, the set of pairs $(Y,A)$ with
    $Y\in\operatorname{dom}(\Phi)$ and $\Phi(Y)=A$, is a closed subset of
    $2^{\omega}\times2^{\omega}$. Consequently, if $\mathcal{S}$ is a
    topological space and $\varphi,\psi\colon\mathcal{S}\to2^{\omega}$ are
    continuous, then the set of all $x\in\mathcal{S}$ such that
    $\psi(x)\in\operatorname{dom}(\Phi)$ and $\Phi(\psi(x))=\varphi(x)$ is
    closed in $\mathcal{S}$.
  \item\label{adm:total} If $\Phi\in\mathfrak{F}$, $\sigma\in2^{<\omega}$ and
    $N_\sigma\subseteq\operatorname{dom}(\Phi)$, then $Z\mapsto\Phi(\sigma{}^{\frown} Z)$
    is a tt-functional, and $\Phi$ agrees on $N_\sigma$ with a tt-functional.
  \end{enumerate}

\eqref{adm:order} The identity is a tt-functional, so $\le_{\mathfrak{F}}$ is

The class is countable. Note first that if $u\le u'$ pointwise then
  $\Phi_{e,u'}$ extends $\Phi_{e,u}$. Since the four operations in (A2) are
  monotone with respect to extension (if $\Phi'$ extends $\Phi$ and $\Psi'$
  extends $\Psi$ then $\Phi'\circ\Psi'$ extends $\Phi\circ\Psi$, and so on),
  in verifying (A2) we may replace each bound $u$ by the nondecreasing bound
  $n\mapsto\max_{k\le n}u(k)$, that is, we may assume that all bounds are
  nondecreasing.

  (A0) For fixed $n$, whether $\Phi_e^{Y}(n)$ halts with output $0$ or $1$
  while querying only numbers less than $u(n)$ depends only on $Y\upharpoonright u(n)$. So the set of such
  $Y$ is clopen, and $\operatorname{dom}(\Phi_{e,u})$, the intersection of
  these sets over all $n$, is closed. The machine $\Phi_e$ computes
  $\Phi_{e,u}$ on this domain.

  (A1) Let $\Phi$ be a tt-functional, computed by the machine $\Phi_e$, which
  halts on every input with every oracle. For each $n$, by compactness of
  $2^{\omega}$ there is $k$ such that for every string $\sigma$ of length $k$ the
  computation $\Phi_e^{\sigma}(n)$ halts having queried only numbers less than
  $k$; let $u(n)$ be the least such $k$, which can be found effectively. Then
  $u$ is computable and $\Phi=\Phi_{e,u}$.

  (A2) Let $\Phi=\Phi_{e,u}$ and $\Psi=\Phi_{e',u'}$ with $u,u'$ nondecreasing.

  \emph{Composition.} Consider the machine which, with oracle $Y$ and input
  $n$, first computes $\Phi_{e'}^{Y}(k)$ for all $k<u(n)$, obtaining a string
  $\rho$ of length $u(n)$, and then runs $\Phi_e^{\rho}(n)$, diverging if a
  number $\ge u(n)$ is queried. If $Y\in\operatorname{dom}(\Phi\circ\Psi)$
  then this halts with output $\Phi(\Psi(Y))(n)$, and it queries $Y$ only at
  numbers less than $u'(u(n))$.
  So the functional in $\mathfrak{F}_{\mathrm{wtt}}$ given by this machine and
  the bound $n\mapsto u'(u(n))$ extends $\Phi\circ\Psi$.

  \emph{Pairing.} The machine which computes $\Phi_e^{Y}(n)$ on input $2n$ and
  $\Phi_{e'}^{Y}(n)$ on input $2n+1$, with the bound $2n\mapsto u(n)$,
  $2n+1\mapsto u'(n)$, gives $\langle\Phi,\Psi\rangle$.

  \emph{Case distinction.} The machine which on input $n$ queries $Y(j)$ and
  then runs $\Phi_e^{Y}(n)$ or $\Phi_{e'}^{Y}(n)$ accordingly, with the bound
  $n\mapsto\max(u(n),u'(n),j+1)$, gives a functional extending
  $[\Phi,\Psi]_j$.

  \emph{Iteration.} Define $v(m,\ell)$ by $v(0,\ell)=\ell$ and
  $v(m+1,\ell)=v(m,u(\ell))$. By induction on $m$, if
  $Y\in\operatorname{dom}(\Phi^{m})$ then the first $\ell$ bits of
  $\Phi^{m}(Y)$ can be computed, uniformly in $m$ and $\ell$, by iterating the
  machine $\Phi_e$, querying $Y$ only at numbers less than $v(m,\ell)$: for
  $m+1$, compute the first $u(\ell)$ bits of $\Phi^{m}(Y)$ and run $\Phi_e$ on
  the resulting string for the inputs less than $\ell$. Now consider the
  machine which, with oracle $Y$ and input $m$, computes in this way the first
  $u'(j)$ bits of $\Phi^{m}(Y)$ and then runs $\Phi_{e'}$ on the resulting
  string with input $j$. For $Y\in\operatorname{dom}(\operatorname{It}_j(\Phi,
  \Psi))$ it halts with output $\Psi(\Phi^{m}(Y))(j)$, and it queries $Y$ only
  at numbers less than $v(m,u'(j))$, a computable function of $m$. So it gives
  an element of $\mathfrak{F}_{\mathrm{wtt}}$ extending
  $\operatorname{It}_j(\Phi,\Psi)$.

\label{rem:limits}
  (1) \emph{Turing reducibility.} The class of all Turing functionals,
  each restricted to the set of oracles on which it is total, satisfies (A1)
  and (A2), but not (A0): the domains are $G_\delta$ sets which need not be
  closed, and the graphs are $G_\delta$ rather than closed. In fact no
  admissible class induces Turing reducibility. If $\Phi$ belongs to an
  admissible class, then by (A0) and compactness of $\operatorname{dom}(\Phi)$
  the number of oracle bits used to compute $\Phi(Y)(n)$ is bounded, for
  $Y\in\operatorname{dom}(\Phi)$, by some $g_\Phi(n)$; so an admissible
  reducibility is always of ``weak truth-table type'', with use bounds from a
  countable family of functions which need not be computable. By a standard
  diagonalization, for every countable family of functions there are reals
  $A\le_{\mathrm{T}}B$ such that no Turing reduction of $A$ to $B$ has use
  bounded by a member of the family.

  So Theorem~\ref{thm:adm} does not apply to Turing reducibility, and in
  particular the elementary argument of Section~\ref{sec:cts} is not available
  for it. We expect that the arguments of Section~\ref{sec:general}, which take
  place on comeager sets throughout, can be adapted, with ``comeager in an
  open set'' in place of ``open'' in Lemma~\ref{lem:unif}; this would give a
  category version of \cite[Lemma~0.2]{Mar}. We have not carried this out,
  since the Turing degrees are rigid by \cite{OAI}.

  (2) \emph{Reducibilities below $\le_{\mathrm{tt}}$.} For bounded truth-table and many-one
  reducibility the argument does not start: the $n$th bit of $G+H$ depends on
  $n+1$ bits of each of $G$ and $H$, so the reductions \eqref{eq:args} are not
  given by bounded truth-table reductions uniformly on any open set of pairs.
  For bounded truth-table reducibility closure under iteration fails as well
  (iterating $A\mapsto(A(n)+A(n+1)\bmod 2)_{n\in\omega}$ produces bits that
  depend on unboundedly many bits of $A$), and for many-one reducibility
  case distinction fails. This is as it should be, since the many-one degrees
  have many automorphisms.

  (3) \emph{Reducibilities above $\le_{\mathrm{T}}$.} By
  Lemma~\ref{lem:adm}\eqref{adm:order}, a reducibility that is not contained in
  $\le_{\mathrm{T}}$ is not given by an admissible class; for arithmetic
  reducibility, where $A$ is reducible to $B$ if $A$ is computable from some
  finite jump of $B$, already (A0) fails, since the reductions are not
  continuous. There is also a second obstacle, which would remain after an
  adaptation as in (1): closure under iteration fails. The $m$-fold iterate of
  a reduction which uses a fixed positive number of jumps uses a number of
  jumps that grows with $m$, so the decoding procedure of
  Proposition~\ref{prop:coding} is not an arithmetic reduction.
