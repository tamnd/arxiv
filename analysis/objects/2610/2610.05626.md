<!-- proposition-1: body_md -->
\label{prop:1}
    Let $f\in \mathcal{S}^r_0(\mathbb{R}^n)$, for some $r\in \mathbb{N}_{\geq 1}\cup \{\infty\}$ and $n\in \mathbb{N}_{\geq 1}$. If the fact that $0$ is GAS under $f$ can always be certified by a Lyapunov function $V\in \mathscr{V}$, then 
    \begin{enumerate}[(i)]
        \item $\mathcal{S}^r_0(\mathbb{R}^n)$ is path-connected and;
        \item for $n=5$, the validity of the generalized $4$-dimensional smooth Poincar\'e conjecture is implied. 
    \end{enumerate}
<!-- end proposition-1 -->
<!-- proof-1: body_md -->
Regarding $(i)$, suppose we can indeed find a Lyapunov function $V\in \mathscr{V}$, then by its definition there is diffeomorphism $\varphi\in\mathrm{Diff}(\mathbb{R}^n)$ from $\mathbb{R}^n$ to itself such that $V(\varphi^{-1}(y))=\|y\|_2^2$ (as $\inf_{y\in \mathbb{R}^n} V(y)=0$). Thanks to the symmetry of $y\mapsto \|y\|_2^2$, one may pick $\varphi\in \mathrm{Diff}^+(\mathbb{R}^n)$ (\textit{i.e.}, select $\varphi$ as being an orientation preserving diffeomorphism), \textit{e.g.}, compose with a reflection $y_i\mapsto -y_i$ if needed. However, then, $\varphi$ is smoothly isotopic to $y\mapsto \mathrm{id}_{\mathbb{R}^n}(y):=y$ \cite[p. 34]{ref:milnor65}. Let $[0,1]\ni s\mapsto \psi_s$ describe this isotopy, from $\mathrm{id}_{\mathbb{R}^n}$, to $\varphi$. One may select the isotopy such that $\psi_s(0)=0$ $\forall s\in [0,1]$. Let $f_s:=(\psi_s)_* f$ (\textit{i.e.}, $f_s$ is the pushforward of $f$ under $\psi_s$ \cite[p. 183]{Lee2}), then as $f=f_0\in \mathcal{S}^r_0(\mathbb{R}^n)$ and $\psi_s$ is a smooth change of coordinates, $f_s\in \mathcal{S}^r_0(\mathbb{R}^n)$ $\forall s\in [0,1]$. 
                                                        
               
                                                                             
             
                                                                                                                                                                                                                                                                                                                                                                                                         
Hence, $[0,1]\ni s \mapsto f_s\in \mathcal{S}^r_0(\mathbb{R}^n)$ is a smooth path, from $f$ (equipped with Lyapunov function $V=:V_0$), to $f_1=\varphi_* f$ (equipped with a trivial quadratic Lyapunov function $y\mapsto V_1(y):=\|y\|_2^2$). Now one constructs a straight-line homotopy from $f_1$ to the canonical vector field $f_c\in \mathcal{S}^r_0(\mathbb{R}^n)$ defined through $y\mapsto f_c(y):=-y$. To construct this homotopy, observe that $-\nabla V_1(y)/2 = -y$, such that $\left\langle \nabla V_1(y), (1-\tau)f_1(y)-\tau \nabla V_1(y)/2 \right\rangle < 0$ for all $(\tau,y) \in [0,1]\times \mathbb{R}^n\setminus \{0\}$. As this can be done for any $f$, one concludes by transitivity.    

Regarding $(ii)$, if $\mathcal{S}^r_0(\mathbb{R}^5)$ is path-connected, for some $r\in \mathbb{N}_{\geq 1}\cup \{\infty\}$, then the smooth $4$-dimensional Poincar\'e conjecture is true \cite[Prop. 2]{ref:kvalheim2025differential}.
<!-- end proof-1 -->

This means that the arguments above do not readily generalize beyond $\mathbb{R}^5$. 
    }

<!-- theorem-1: body_md -->
\label{thm:Morse:exists:hyperbolic}
  Let $f\in \mathcal{HS}^r_0(\mathbb{R}^n)$, for some $r\in \mathbb{N}_{\geq 1}\cup \{\infty\}$ and $n\in \mathbb{N}_{\geq 1}$, then, there is a smooth Morse Lyapunov function certifying that $0$ is GAS.
<!-- end theorem-1 -->
<!-- proof-2: body_md -->
First, by the GAS property, there is a smooth (\textit{i.e.}, $C^{\infty}$-smooth) Lyapunov function $V_{\infty}: \mathbb{R}^n\to \mathbb{R}_{\geq 0}$, \textit{e.g.}, see \cite[Thm~2.4]{ref:bacciotti2005liapunov}. This function is not known to be Morse. 

    Second, by hyperbolicity, there is some open neighbourhood $B_0$ of $0$ and a quadratic Lyapunov function $V_q:B_0\to \mathbb{R}_{\geq 0}$, such that $\langle \nabla V_q(x),f(x)\rangle < 0$ on $B_0\setminus \{0\}$, \textit{e.g.}, see~\cite[\S 28]{hahn1967stability}. This means in particular that $\nabla^2 V_q(0)\succ 0$. Note, $V_q$ need not be a globally valid Lyapunov function.

    Now we combine $V_q$ and $V_{\infty}$ to create a global, smooth Lyapunov function that is Morse. Pick $c>0$ such that $M_2:=V_{\infty}^{-1}([0,c])\subset B_0$ and set $M_1:=V_{\infty}^{-1}([0,c/2])$. Then, define $V_M:\mathbb{R}^n\to \mathbb{R}_{\geq 0}$ through
\begin{equation*}
    V_M(x) := \begin{cases}
        \varepsilon V_q(x) \quad &x\in \mathrm{int}(M_1)\\
        (1-\beta(x))\varepsilon V_q(x) + \beta(x) V_{\infty}(x)\quad &x\in \mathrm{cl}(M_2\setminus M_1)\\
        V_{\infty}(x) \quad &x\in \mathbb{R}^n\setminus M_2
    \end{cases},
\end{equation*}
for some smooth $\beta:\mathrm{cl}(M_2\setminus M_1)\to [0,1]$ and $\varepsilon>0$. We start by constructing an appropriate $\beta$. Define the function $\psi:\mathrm{cl}(M_2\setminus M_1)\to [0,1]$ through 
\begin{equation*}
     \psi(x) := \frac{V_{\infty}(x)-c/2}{c-c/2},
\end{equation*}
then consider a standard smooth bump function $b:[0,1]\to [0,1]$ defined as 
\begin{equation*}
    b(s) := \frac{\phi(s)}{\phi(s)+\phi(1-s)}
\end{equation*}
for $\phi:[0,1]\to[0,1]$ being a smooth function defined by
\begin{align*}
    \phi(s) := \begin{cases}
        e^{-\frac{1}{s}},\quad &s>0\\
        0 \quad &s=0
    \end{cases}.
\end{align*}
Now set $\beta := b\circ \psi$. 
Note, we employed standard bump functions here, that is, $b$ is smooth and such that $b(0)=0$, $b(1)=1$ with $b^{(k)}(0)=b^{(k)}(1)=0$ for all $k>0$, \textit{e.g.}, see \cite[Lem. 2.20]{Lee2}. Useful for the analysis below is that $b^{(1)}(s)>0$ for all $s\in (0,1)$. 


Next, define
\begin{equation*}
    \alpha_1:= \min_{z\in \mathrm{cl}({M_2\setminus M_1})} V_{\infty}(z),\quad \alpha_2:= \max_{z\in \mathrm{cl}({M_2\setminus M_1})} V_{q}(z) 
\end{equation*}
and set $\varepsilon:=\alpha_1/(2\alpha_2)$. 

Now we verify that $V_M$ is a valid, smooth Morse Lyapunov function. 

\begin{enumerate}[(i)]
    \item $V_M^{-1}(0)=0$ as $\varepsilon>0$ and both $V_q$ and $V_{\infty}$ are positive definite and only $0$ at $0$.
    \item $\langle \nabla V_M(x),f(x) \rangle < 0$ for all $x\in \mathbb{R}^n\setminus \{0\}$ due to the following set of arguments. The only non-trivial domain is $\mathrm{cl}(M_2\setminus M_1)$. Then, as $V_{\infty}$ and $V_q$ are both Lyapunov functions for $f$, see that 
    \begin{align*}
        \langle (1-\beta(x))\varepsilon \nabla V_q(x) + \beta(x) \nabla V_{\infty}(x), f(x) \rangle < 0 
    \end{align*}
    on $\mathrm{cl}(M_2\setminus M_1)$. We are left with the term
    \begin{align*}
        \langle(V_{\infty}(x)-\varepsilon V_q(x))\nabla \beta(x),f(x) \rangle.
    \end{align*}
    Note that by our choice of $\varepsilon$, we have that $(V_{\infty}(x)-\varepsilon V_q(x))> 0$ on $\mathrm{cl}(M_2\setminus M_1)$. By our construction of $\beta$, we have that $\nabla \beta(x)$ vanishes only on the boundary of $\mathrm{cl}(M_2\setminus M_1)$. Moreover, on the interior of $\mathrm{cl}(M_2\setminus M_1)$, we have that $\nabla \beta(x) = \gamma(x) \nabla V_{\infty}(x)$ for some smooth strictly positive function $\gamma$. Putting it all together, we find that $ \langle(V_{\infty}(x)-\varepsilon V_q(x))\nabla \beta(x),f(x) \rangle\leq 0$ on $\mathrm{cl}(M_2\setminus M_1)$, hence, $\langle \nabla V_M(x),f(x) \rangle < 0$ on $\mathrm{cl}(M_2\setminus M_1)$. This line of arguments also shows that $V_M$ is smooth. 
    
    \item At last, $V_M$ is Morse as the only critical point of $V_M$ is $0$ and $\nabla^2 V_M(0)=\varepsilon \nabla^2 V_q(0)\succ 0$.
\end{enumerate}

<!-- remark-2: body_md -->
\label{rem:basins}
\begin{upshape}
    Let $M$ be a smooth $n$-dimensional manifold and let $p^*\in M$ be asymptotically stable under some smooth vector field $F$. Let $B^*$ be the corresponding basin of attraction. In this case, $B^*$ is diffeomorphic to $\mathbb{R}^n$~\cite[Thm. 2.2]{ref:wilson1967structure}. Hence, if this $p^*$ is some hyperbolic equilibrium point under $F$, then by Theorem~\ref{thm:Morse:exists:hyperbolic}, its stability can be certified via a Morse Lyapunov function. Note, this works as those properties (being hyperbolic, being Morse) are coordinate invariant. 
\end{upshape}

\label{cor:HS:path:connected}
The space $\mathcal{HS}^r_0(\mathbb{R}^n)$, for any $r\in \mathbb{N}_{\geq 1}\cup \{\infty\}$ and $n\in \mathbb{N}_{\geq 1}$, is path-connected.
<!-- end corollary-1 -->
<!-- proof-3: body_md -->

<!-- proposition-2: body_md -->
\label{prop:counter}
    For any $n\geq 2$ and $r\in \mathbb{N}_{\geq 1}\cup \{+\infty\}$ there exists a $f\in \mathcal{S}^r_0(\mathbb{R}^n)\setminus \mathcal{HS}_0^r(\mathbb{R}^n)$ such that $0$ being GAS cannot be asserted via a Morse Lyapunov function.
<!-- end proposition-2 -->
<!-- proof-5: body_md -->
Consider the planar dynamical system $\dot{x}=f(x)$ as given by 
    \begin{equation}
        \label{equ:planar:counter}
            \begin{aligned}
        \dot{x}_1 =& -\varepsilon x_1^3+x_2\\
        \dot{x}_2 =& -x_1^3 - x_2^3,
    \end{aligned}
    \end{equation}
    for some $\varepsilon> 0$. See that $0\in \mathbb{R}^2$ is GAS, as one may check via the smooth Lyapunov function $\mathbb{R}^2 \ni (x_1,x_2)\mapsto {V}(x_1,x_2)=:x_1^4/4+x_2^2/2$ (for $\varepsilon=0$, the same is true, but one employs the Krasovskii-LaSalle invariance principle, \textit{e.g.}, see~\cite[Thm. 5.24]{Sastry}), \textit{e.g.}, see Figure~\ref{fig:placeholder}. Observe that $A:=Df(0)$ is nilpotent and in particular non-hyperbolic. Moreover, $V$ is not a Morse function. 

Suppose now that one could find a Morse Lyapunov function $V_M$, let 
    \begin{align*}
        H = \begin{pmatrix}
a & b \\
b & c
        \end{pmatrix},
    \end{align*}
    denote $\nabla^2 V_M(0)$. It follows that $a,c>0$ and $ac-b^2>0$.  
    
Then see that for any $x\in \mathbb{R}^2$, one has $x^\mathsf{T} HA x =a x_1 x_2 + b x_2^2$. There is always a pair $(x_1,x_2)$ such that this product is strictly positive, for instance, fix $x_2=1$, then $x_1> |b|/a$ suffices.

Next, since both $f$ and $V_M$ are smooth, it follows that $f(x) = Ax + \mathrm{h.o.t.}$ ($\mathrm{h.o.t.}$ denotes \textit{higher order terms}) and $V_M(x) = \frac{1}{2}x^\mathsf{T} H x + \mathrm{h.o.t}$. In particular, $\langle \nabla V_M(x), f(x) \rangle = x^\mathsf{T} HA x + \mathrm{h.o.t}$. Now pick some $\widetilde{x}$ such that $\widetilde{x}^\mathsf{T} HA \widetilde{x}>0$ and see that 
\begin{align*}
    \frac{1}{\tau^2} \langle \nabla V_M(\tau \widetilde{x} ),f(\tau \widetilde{x} )\rangle = \widetilde{x}^\mathsf{T} HA \widetilde{x} + O(\tau)
\end{align*}
is positive for sufficiently small $\tau$. This means that $V_M$ was no Lyapunov function after all. Examples beyond $n=2$ are found by appending \eqref{equ:planar:counter} with $\dot{z}=-z$, for $z\in \mathbb{R}^{n-2}$. In that case the obstruction follows by considering states of the form $(\widetilde{x},0)$.

<!-- lemma-1: body_md -->
\label{lem:lyapunov:equ}
    For $A\in \mathbb{R}^{n\times n}$ there exists a $H\succ 0$ such that $HA+A^{\mathsf{T}}H\preceq 0$ if and only if $A$ has $\Re(\mathrm{spec}(A))\leq 0$ and all eigenvalues $\lambda_i$ of $A$, such that $\Re(\lambda_i)=0$, are semisimple.
<!-- end lemma-1 -->
<!-- proof-6: body_md -->
We believe this is a classical result (\textit{e.g.}, see \cite[Exercise 5.6(b)]{ref:Astrom2008feedback}), yet we provide a proof to be self-contained. 

    We start by showing that if $A$ satisfies the assumptions, then such a $H$ exists. Decompose $\mathbb{R}^n=E^s \oplus E^c$. On $E^s$ (the stable subspace), we have that $A^s:=A|_{E^s}$ is Hurwitz, and thus there is a matrix $H^s$ such that $H^s A^s + (A^s)^{\mathsf{T}}H^s \prec 0$. On the center subspace $E^c$ we know that the eigenvalues are semisimple, meaning that we can diagonalize $A^c := A|_{E^c}$, where the blocks are either $0$ or of the form 
\begin{align*}
    A^{\omega} = \begin{pmatrix}
        0 & \omega \\ - \omega & 0
    \end{pmatrix}.
\end{align*}
See that if we select $H^{\omega}=I_2$, then $H^{\omega} A^{\omega}+ (A^{\omega})^{\mathsf{T}}H^{\omega} = 0$. Hence, if we select $H:=\mathrm{diag}(H^s,I_p)$, for $p=\mathrm{dim}(E^c)$, then, the Lyapunov equation $HA+A^{\mathsf{T}}H\preceq 0$ is satisfied. 

Now, for the other direction, assume that $H$ exists. Let $V(x):= \langle Hx, x\rangle $ and consider $V$ as being a Lyapunov function for $\dot{x}=Ax$. As $\langle Hx, Ax \rangle \leq 0$ by assumption, $V$ is non-increasing along solutions under $A$. This directly implies that $\Re(\mathrm{spec}(A))\leq 0$. Now suppose that $A$ has some eigenvalue $\lambda_i$ such that $\Re(\lambda_i)=0$, yet $\lambda_i$ fails to be semisimple. This means that diagonalization is obstructed and we have a non-trivial Jordan block. This however means that the solution under $A$ is unbounded, hence, a contradiction.
<!-- end proof-6 -->
<!-- corollary-3: body_md -->
\label{cor:no:Morse:exists}
  Let $f\in \mathcal{S}^r_0(\mathbb{R}^n)$, for some $r\in \mathbb{N}_{\geq 1}\cup \{\infty\}$ and $n\in \mathbb{N}_{\geq 1}$. Then, there is a smooth Morse Lyapunov function certifying that $0$ is GAS only if the non-hyperbolic (center) part of $Df(0)$ can be diagonalized.
<!-- end corollary-3 -->
<!-- proof-7: body_md -->
For if not, $Df(0)$ must have an eigenvalue $\lambda_i$, with $\Re(\lambda_i)=0$, that is not semisimple. Then, by Lemma~\ref{lem:lyapunov:equ} and the proof strategy as in Proposition~\ref{prop:counter}, it follows that no Morse Lyapunov function can exist.
<!-- end proof-7 -->
