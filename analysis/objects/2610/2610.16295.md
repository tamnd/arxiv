Given $p,\mathcal I,\boldsymbol\beta,\mathbf L,\Delta$ and
$\varepsilon$, an algorithm $A$ adaptively queries $\mathcal O_f$
and outputs $\widehat x_A(f)\in\mathbb R$.
Its queries and output depend on the preceding oracle responses
and, if randomized, an internal random seed independent of $f$.
The algorithm succeeds if $|f'(\widehat x_A(f))|<\varepsilon$.

\[
\frac{1}{b-a}\int_a^b P(x)\,dx
=\frac{\mathsf Q_{[a,b]}(b)-\mathsf Q_{[a,b]}(a)}{b-a}
=\frac{f(b)-f(a)}{b-a}
\ge-\frac{\varepsilon}{4}.
\]
Hence $P$ attains a value at least $-\frac{\varepsilon}{4}$.
In both cases, continuity gives a point $z\in[a,b]$ with
$P(z)=-\frac{\varepsilon}{2}$.
Every such point satisfies
$|f'(z)|\le|P(z)|+\frac{\varepsilon}{8}
=\frac{5\varepsilon}{8}<\varepsilon$.
The root is computed from the known polynomial without additional
oracle queries.

\noindent\textbf{Query budget.}
Lemma~\ref{lmm:value-interpolation} gives $O_r(1)$ value queries
for each derivative estimate and for the terminal interpolant.
The loop makes at most
$\left\lceil\log_2\left(\frac{4/\varepsilon}{h_\varepsilon}\right)\right\rceil$
iterations, in addition to the two initial estimates.
The ratio in the logarithm equals
$4(8a_r)^{\frac{1}{\nu-1}}\varepsilon^{-\frac{\nu}{\nu-1}}$,
so the total is
$O_{r,\beta_r}(1+\log(1/\varepsilon))$.
Cached endpoint values suffice for every secant comparison.

\noindent\textbf{General parameters.}
Lemma~\ref{lmm:normal} gives normalized accuracy
$\widehat\varepsilon:=\frac{\varepsilon}
{L_r^{\frac{1}{\nu}}\Delta^{\frac{\nu-1}{\nu}}}$.
Run the normalized algorithm with accuracy
$\min\{\widehat\varepsilon,1\}$.
Its output also meets accuracy $\widehat\varepsilon$.
Each normalized function-value query is simulated by one original
function-value query, and rescaling preserves the stationarity guarantee.
Thus, for every selected $r$, the query bound is
\[
O_{r,\beta_r}\left(
1+\log_+\left(
\frac{L_r^{\frac{1}{\nu}}\Delta^{\frac{\nu-1}{\nu}}}{\varepsilon}
\right)\right).
\]
Taking the maximum of the constants over $1\le r\le p$ and choosing
an index minimizing
$L_r^{\frac{1}{\nu_r}}\Delta^{\frac{\nu_r-1}{\nu_r}}$
proves the theorem.
