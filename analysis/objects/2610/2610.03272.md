<!-- lemma-1: body_md -->
\label{lem:red}
Let $M\ge 2$ and $N\ge 1$.  Then $\mathrm{PG}(M-1,q)$ contains a $4$-general set of $N$
points \emph{spanning} $\mathrm{PG}(M-1,q)$ if and only if there exists a linear code
$C\subseteq\mathbb{F}_q^{\,N}$ of the form
$[N,N-M,\ge 5]_q$.  In such a code, a parity check matrix has no zero column and
no two proportional columns.
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
($\Rightarrow$) Choose representatives $v_1,\dots,v_N\in\mathbb{F}_q^{\,M}$ of the $N$
points and let $H$ be the $M\times N$ matrix with these columns.  Since the set
spans $\mathrm{PG}(M-1,q)$, $\mathrm{rank}(H)=M$; since no four points are coplanar, no
four columns are linearly dependent, so $C=\ker H$ has length $N$, dimension
$N-M$ and minimum distance at least $5$: indeed, the minimum weight of $C$ equals
the smallest size of a linearly dependent set of columns of $H$.

($\Leftarrow$) Let $H$ be a parity check matrix of $C$, so $H$ has rank $M$.
If some column of $H$ were zero, then taking the corresponding coefficient equal
to $1$ would produce a codeword of weight $1$; if $h_i=\lambda h_j$ with
$\lambda\ne 0$ and $i\ne j$, then the coefficient vectors $c$ with $c_i=1$,
$c_j=-\lambda^{-1}$ and $c_k=0$ otherwise give a codeword of weight $2$; both
contradict $d\ge 5$.  Hence the columns are non-zero and pairwise
non-proportional, so they define $N$ distinct points of $\mathrm{PG}(M-1,q)$.  Since
$d\ge 5$, no four columns are dependent, so no four of these points are coplanar.
<!-- end proof-1 -->
<!-- corollary-1: body_md -->
\label{cor:main}
For every $M\ge 2$,
\[
  M_{3}(M-1,q)=\max\{N:\ \text{there is a projective }[N,N-M,\ge 5]_q\text{ code}\},
\]
and $M_{3}(M-1,q)\ge N$ holds precisely when a $[N,N-M,5]_q$ code exists.
<!-- end corollary-1 -->
<!-- proof-2: body_md -->
The first identity is Lemma~\ref{lem:red}, applied to a largest set: a
$4$-general set of size $M_{3}(M-1,q)$ spans $\mathrm{PG}(M-1,q)$, for if it lay in a
hyperplane then any point outside could be adjoined: a quadruple containing
the new point cannot be coplanar, since the plane through three points of the
set lies in the hyperplane.  For the second, a $4$-general set of
$N$ points yields $[N,N-M,\ge 5]_q$ with $d\in\{5,\dots\}$: the distance cannot
exceed $5$ for $N=M+4$ by the Singleton bound, and in general the tables decide);
conversely $d\ge 5$ is $d=5$ when the value is known to be at most $5$.
<!-- end proof-2 -->
<!-- lemma-2: body_md -->
\label{lem:mono}
Every subset of a $4$-general set is $4$-general, and shortening a code preserves
its minimum distance.  Consequently, if no $[N,N-M,\ge 5]_q$ code exists, then
$M_{3}(M-1,q)\le N-1$.
<!-- end lemma-2 -->
<!-- proof-3: body_md -->
The first claim is immediate from the definition: a subset of a set spanning
$\mathrm{PG}(M-1,q)$ still spans it, and dropping points cannot create a coplanar
quadruple).  If an $[N',N'-M,\ge5]_q$ code existed with $N'>N$, shortening it at
$N'-N$ positions would produce an $[N,N-M,\ge5]_q$ code.  Hence ruling out a
single rung $N$ rules out all larger sizes.
<!-- end proof-3 -->
<!-- proposition-1: body_md -->
\label{prop:n3}
$M_{3}(3,4)=5$.
<!-- end proposition-1 -->
<!-- proof-4: body_md -->
The value is classical: in $\mathrm{PG}(3,q)$ with $q\ge4$ a $4$-general set is an arc,
and the largest arcs have size $q+1$ \cite[Sections~21.2
and~21.3]{Hirschfeld3D}; see also Table~2 of \cite{Pavese}.  The one-line
argument below is what the reduction yields.  The lower bound is the
construction of \cite[Thm.~4.6]{Pavese} for $d=2$.  For the
upper bound, assume that $\mathrm{PG}(3,4)$ contains a $4$-general set of $N\ge 6$ points.
By Lemma~\ref{lem:red} there is a $[N,N-4,\ge 5]_4$ code; shortening it at $N-6$
positions gives a $[6,2,\ge 5]_4$ code, hence a $[6,2,5]_4$ code.  Let $G$ be a
generator matrix of such a code, with columns $g_1,\dots,g_6\in\mathbb{F}_4^2$.  A
non-zero codeword is $\lambda_1 r_1+\lambda_2 r_2$ ($r_i$ the rows of $G$), and its
zero coordinates are exactly the indices $i$ with $g_i$ proportional to
$(-\lambda_2,\lambda_1)$.  Hence $\min$ weight $=6-\max_i m_i$, where $m_i$ is the
multiplicity of the projective point $[g_i]$ among the six columns.  Thus $d=5$
forces the six columns to be pairwise non-proportional, i.e.\ to be six distinct
points of $\mathrm{PG}(1,4)$, which has only $q+1=5$ points: a contradiction.

\label{thm:n4}

\emph{Lower bound.}  The table below gives a $5\times 11$ matrix $H$ over

H=\begin{pmatrix}
1&0&0&0&0&1&\omega&\omega&0&\omega^2&\omega^2\\
0&1&0&0&0&\omega^2&0&\omega^2&\omega&\omega&1\\
0&0&1&0&0&1&1&\omega&\omega^2&1&1\\
0&0&0&1&0&1&\omega^2&\omega^2&\omega&0&\omega\\
0&0&0&0&1&\omega&\omega&0&\omega^2&\omega^2&1
\end{pmatrix}
\end{gather*}

\emph{Upper bound.}  Let $N\ge 12$ and suppose that $\mathrm{PG}(4,4)$ contains a

<!-- lemma-3: body_md -->
\label{lem:large4gen}
Let $q\in\{3,4\}$.  Every $4$-general set of $N\ge7$ points of $\mathrm{PG}(4,q)$ is an
NMDS-set of $\mathrm{PG}(4,q)$.
<!-- end lemma-3 -->
<!-- proof-7: body_md -->
Let $X$ be such a set and let $H$ be the $5\times N$ matrix whose columns are the
points of $X$; put $C=\ker H$, an $[N,N-5,d]_q$ code with $d\ge5$, because no
four columns of $H$ are dependent.

The first condition in the definition of an NMDS-set \cite[Sec.~5.1]{Pavese} is
$4$-generality, so it holds by hypothesis.  The third also holds: if six points
of $X$ lay on a solid, they would form a $6$-point $4$-general set of
$\mathrm{PG}(3,q)$, and for $q=4$ that contradicts $M_{3}(3,4)=5$
(Proposition~\ref{prop:n3}), while for $q=3$ the same computation applies, since
the code attached to six points of $\mathrm{PG}(3,3)$ by Lemma~\ref{lem:red} is a
$[6,2,\ge5]_3$ code, which would require
$6\ge\lceil5/1\rceil+\lceil5/3\rceil=7$ by the Griesmer bound, a contradiction.

It remains to check the second condition.  Suppose that no five points of $X$ lie
on a solid.  Then $H$ has no dependence of size at most five, so $d\ge6$ and
$C$ is an $[N,N-5,\ge6]_q$ code, of dimension $N-5$.  The Griesmer bound gives
\[
  N \;\ge\; \Bigl\lceil \tfrac{6}{1} \Bigr\rceil
        + \Bigl\lceil \tfrac{6}{q} \Bigr\rceil + (N-7)\cdot 1
    \;=\; N+1 ,
\]
because $\lceil6/3\rceil=\lceil6/4\rceil=2$ and each of the remaining $N-7$ terms
of the sum is at least $1$; this is absurd for $N\ge7$.  Hence
some five points of $X$ do lie on a solid, and $X$ is an NMDS-set.
<!-- end proof-7 -->
<!-- proposition-2: body_md -->
\label{prop:nmds}
$M_{3}(4,q)\le 11$ for $q\in\{3,4\}$.
<!-- end proposition-2 -->
<!-- proof-8: body_md -->
Let $X$ be a $4$-general set of $N$ points of $\mathrm{PG}(4,q)$.  If $N\le6$ there is
nothing to prove.  Otherwise $N\ge7$ and $X$ is an NMDS-set by
Lemma~\ref{lem:large4gen}; by \cite[Sec.~6]{DodunekovLandgev} it is then the
column set of a generator matrix of a near-MDS code of dimension $5$ over
$\mathbb{F}_q$, so $N\le m'(5,q)$.  The two halves of \eqref{eq:nmds} now give
$m'(5,4)\le2\cdot4+5-2=11$ for $q=4$ and $m'(5,3)\le2\cdot3+5=11$ for $q=3$.
<!-- end proof-8 -->
<!-- remark-1: body_md -->
\label{rem:nmdsgap}
The two bounds of \eqref{eq:nmds} differ by two, and the case $q=4$ falls under
the stronger one only because $4>3$.  The argument behind that stronger bound is
short enough to recall.  Proposition~5.3(i) of
\cite{DodunekovLandgev}, that an $[n,k]_q$ near-MDS code yields an
$[n-1,k-1]_q$ one, applied exactly $k-3$ times turns a near-MDS code of dimension $k$
into an $[n-k+3,3]_q$ near-MDS code, hence into an $(n-k+3,3)$-arc of
$\mathrm{PG}(2,q)$; Thas's theorem \cite{Thas1975} bounds such an arc by $2q+1$ when
$q>3$, and so $n-k+3\le2q+1$, which is \eqref{eq:nmds}.  The bound is therefore
exactly as strong as the theory of $3$-arcs allows.  What that implies for the
strength of the present results is taken up in Remark~\ref{rem:strength}.
<!-- end remark-1 -->
<!-- remark-2: body_md -->
\label{rem:nogens}
Lemma~\ref{lem:large4gen} is special to $n=4$ and does not generalise in either
direction.  In $q$: for $q\ge5$ the code $[6,2,\ge5]_q$ does exist: take six
distinct points of $\mathrm{PG}(1,q)$ as the columns of a $2\times6$ generator matrix,
as in Proposition~\ref{prop:n3}.  Hence $M_{3}(3,q)\ge6$, and the third NMDS
condition no longer follows automatically.  It is the \emph{third} condition
that fails first as $q$ grows, and it fails alone at $q=5$: the second one is
still automatic there and only breaks at $q=6$, as Lemma~\ref{lem:arc} shows.
In $n$: for $n\ge5$ the first condition is strictly stronger than
$4$-generality, so \eqref{eq:nmds} says nothing about the rungs of
Section~\ref{sec:ladder} above $n=4$: at $n=5$ it gives $12$, against the
$21$-point set of \cite[Thm.~4.6]{Pavese} (see also Remark~\ref{rem:why4}).
The bridge from $4$-general sets to near-MDS codes is therefore a phenomenon
of the small fields $\mathbb{F}_3$ and $\mathbb{F}_4$, and the second proof of
$M_{3}(4,4)\le11$ is a statement about one rung of the ladder and not a method
for climbing it.
<!-- end remark-2 -->
<!-- lemma-4: body_md -->
\label{lem:arc}
Let $X$ be a $4$-general set of $\mathrm{PG}(4,q)$ with $|X|\ge7$ and suppose that no
five points of $X$ lie on a solid.  Then $q\ge6$.
<!-- end lemma-4 -->
<!-- proof-9: body_md -->
Five points of $X$ span $\mathrm{PG}(4,q)$, hence are linearly independent, and a
projectivity may be chosen sending them to the frame $e_1,\dots,e_5$.  Let
$p=(p_1,\dots,p_5)$ and $q=(q_1,\dots,q_5)$ be two further points of $X$.  For
each $i$, the four frame points other than $e_i$ span a solid, so together with
$p$ they must still span $\mathrm{PG}(4,q)$; this forces $p_i\ne0$, and the same
argument gives $q_i\ne0$.  For each pair $\{i,j\}$, the three frame points
outside $\{i,j\}$, together with $p$ and $q$, are five points of $X$ and must
therefore also span $\mathrm{PG}(4,q)$, so that $\det[e_S\mid p\mid q]\ne0$ for the
corresponding set $S$ of three frame points.  Expanding this determinant along
the unit columns, only the $2\times2$ minor of $p$ and $q$ in the complementary
pair $\{i,j\}$ survives, up to a sign; hence $p_iq_j-p_jq_i\ne0$ for all
$i\ne j$, that is, the five ratios $p_i/q_i\in\mathbb{F}_q^*$ are pairwise distinct.
Therefore $q-1\ge5$.

<!-- proposition-4: body_md -->
\label{prop:coinc}
For $q\in\{3,4\}$,
\[
  M_{3}(4,q)\;=\;m'(5,q)\;=\;m'(3,q)+2\;=\;11 .
\]
In particular the extremal $4$-general sets of $\mathrm{PG}(4,3)$ and of $\mathrm{PG}(4,4)$ have
the same size, and the common reason is that $\mathrm{PG}(2,3)$ and $\mathrm{PG}(2,4)$ carry
NMDS-sets of the same maximal size, $m'(3,3)=m'(3,4)=9$.
<!-- end proposition-4 -->
<!-- proof-11: body_md -->
We take the three assertions in the order of increasing depth.

\emph{The values.}  $m'(3,4)=9$ is stated in \cite[p.~42]{DodunekovLandgev}.  For
$q=3$, Proposition~5.1 there gives $m'(3,3)\le2\cdot3+3=9$, while $[9,3,6]_3$ is
a near-MDS code, being one of the codes $[12-i,6-i,6]_3$, $1\le i\le5$, derived
there from the extended ternary Golay code; hence $m'(3,3)=9$.  Moreover
$[11,5,6]_3$ belongs to the same list, so $m'(5,3)\ge11$, while Proposition~5.1
gives $m'(5,3)\le2\cdot3+5=11$.  Finally $m'(5,4)=11$: here the second half of
\eqref{eq:nmds} gives $m'(5,4)\le2\cdot4+5-2=11$, and the $11$-point set of
Theorem~\ref{thm:n4} is an NMDS-set of $\mathrm{PG}(4,4)$ of size $11$.  The two
descriptions coincide, since for $k\ge3$ a near-MDS code of dimension $k$ over
$\mathbb{F}_q$ has length $n$ exactly when it is an NMDS-set of $\mathrm{PG}(k-1,q)$ of size $n$
\cite[Secs.~5.1 and~6]{DodunekovLandgev}.

\emph{Relation with $M_{3}(4,q)$.}  Every NMDS-set of $\mathrm{PG}(4,q)$ satisfies the
first condition of its definition, which is $4$-generality, whence
$m'(5,q)\leM_{3}(4,q)$.  Conversely let $X$ be a $4$-general set of $N$ points.  If
$N\ge7$ then $X$ is an NMDS-set by Lemma~\ref{lem:large4gen}, so $N\le m'(5,q)$;
and if $N\le6$ then $N\le11=m'(5,q)$ trivially, by the values just established.
So $M_{3}(4,q)=m'(5,q)$.

\emph{The middle term.}  Corollary~5.4 of \cite{DodunekovLandgev} with $k=5$ and
$\alpha=2$ gives $m'(5,q)\le m'(3,q)+2$, and the values above turn the right-hand
side into $9+2=11=m'(5,q)$.

<!-- lemma-5: body_md -->
\label{lem:chain}
Let $C$ be an $[N,k,d]_q$ code with $N\ge2$ and $d\ge2$.  Then
\begin{enumerate}
\item puncturing $C$ at any one position gives an $[N-1,k,\ge d-1]_q$ code;
\item shortening $C$ at any one position gives an $[N-1,k-1,\ge d]_q$ code.
\end{enumerate}
Consequently, if no $[N',k',\ge5]_q$ code exists, then neither does any
$[N'+1,k',\ge6]_q$ code and neither does any $[N'+1,k'+1,\ge5]_q$ code.
<!-- end lemma-5 -->
<!-- proof-12: body_md -->
Standard: a punctured code is the image of the projection forgetting one
coordinate, so its minimum distance drops by at most one; a shortened code is
$C$ with one coordinate set to zero and then deleted, so its length drops by one,
its dimension by one, and its minimum distance is unchanged (every shortened
codeword is a codeword of $C$, and every minimal-weight codeword supported away
from the deleted coordinate survives).  For the consequence, argue
contrapositively: a $[N'+1,k',\ge6]_q$ code punctured at one position would give
a $[N',k',\ge5]_q$ code, and a $[N'+1,k'+1,\ge5]_q$ code shortened at one
position would give a $[N',k',\ge5]_q$ code.

<!-- remark-4: body_md -->
\label{rem:why4}
The count above explains arithmetically why the reduction bites at $n=4$ and
not at $n=5$; the second proof of Section~\ref{sec:n4} supplies the structural
reason.  An NMDS-set of $\mathrm{PG}(k-1,q)$ must have every $k-1$ of its points
generate a hyperplane.  In $\mathrm{PG}(4,q)$ the hyperplanes are the solids, so the
condition reads ``no four points coplanar'', exactly $4$-generality; for
$n\ge5$ it demands that every $n$ points generate a hyperplane, which is
strictly stronger.  The NMDS machinery therefore meets the climb problem at
the single rung $n=4$.  Remark~\ref{rem:nogens} records the same fact from the
side of the field.

<!-- proposition-5: body_md -->
\label{prop:rig}
Every $22$-point $4$-general set $T\subset\mathrm{PG}(5,4)$ satisfies
\[
  |T\cap\mathcal{V}_1|\le 12 .
\]
<!-- end proposition-5 -->
<!-- proof-14: body_md -->
Write $T=(\mathcal{V}_1\setminus S)\cup R$ with $S=\mathcal{V}_1\setminus T$ and $|S|=r$.  Then
$|T\cap\mathcal{V}_1|=21-r$ and $|R|=r+1$.  For $T$ to be $4$-general, every point of
$R$ must lie outside every plane spanned by a triple of $\mathcal{V}_1\setminus S$; such
a plane would otherwise contain four points of $T$.  Put
\[
  \mathrm{hol}(S):=\{p\in\mathrm{PG}(5,4)\setminus\mathcal{V}_1\;:\;
   p\notin\langle x,y,z\rangle \ \text{for all}\ \{x,y,z\}\subseteq\mathcal{V}_1\setminus S\}.
\]
Then $R\subseteq\mathrm{hol}(S)$.  Moreover $\mathrm{hol}(\emptyset)=\emptyset$
because $\mathcal{V}_1$ is complete, so $r\ge1$.

All $\binom{21}{r}$ subsets $S$ of $\mathcal{V}_1$ were enumerated for $r=1,\dots,8$.
Two things were computed for each $S$.  The first is the exact size of
$\mathrm{hol}(S)$, which gives the \emph{necessary} condition
$|\mathrm{hol}(S)|\ge r+1$.  The second, whenever that condition held, is an
explicit search for an $(r+1)$-subset $R\subseteq\mathrm{hol}(S)$ such that
$(\mathcal{V}_1\setminus S)\cup R$ is $4$-general.  Within the compatibility graph on
$\mathrm{hol}(S)$ two points $p,q$ are adjacent iff
$(\mathcal{V}_1\setminus S)\cup\{p,q\}$ contains no coplanar quadruple.  This is a
necessary condition, so the search loses no candidate; every survivor is then
verified in full, over all $\binom{22}{4}$ quadruples.  No candidate survived
for any $S$.

The resulting counts are
\[
\begin{array}{c|cccccccc}
 r & 1 & 2 & 3 & 4 & 5 & 6 & 7 & 8\\ \hline
 \binom{21}{r} & 21 & 210 & 1330 & 5985 & 20\,349 & 54\,264 & 116\,280 & 203\,490\\
 \max_S|\mathrm{hol}(S)| & 0 & 0 & 0 & 4 & 8 & 24 & 57 & 146\\
 \#\{S:|\mathrm{hol}(S)|\ge r+1\} & 0 & 0 & 0 & 0 & 924 & 51\,429 & 116\,280 & 203\,490
\end{array}
\]
For $r\le6$ the number of feasible $S$ is small enough for every candidate $R$
to be listed and tested individually.  For $r\ge7$ all $\binom{21}{r}$ subsets
are feasible in the weak sense, so the clique search is essential there.  At
$r=8$ the holes are large, up to $146$ points, which is why that level is by far
the most expensive.  In every case the outcome was negative, so $r\ge9$, i.e.\
$|T\cap\mathcal{V}_1|=21-r\le12$.

<!-- remark-7: body_md -->
\label{rem:spread}
Theorem~\ref{thm:n4} constrains a hypothetical $22$-point set $T$ from below as
well.  Since $4$-generality is intrinsic, $T\cap H$ is a $4$-general set of a
hyperplane $H\cong\mathrm{PG}(4,4)$ and $T\cap S$ one of a solid
$S\cong\mathrm{PG}(3,4)$; hence
\[
  |T\cap H|\leM_{3}(4,4)=11, \qquad |T\cap S|\le5
\]
for every hyperplane $H$ and every solid $S$, in addition to the trivial bound
$|T\cap\pi|\le3$ for every plane $\pi$.  So a $22$-point set of $\mathrm{PG}(5,4)$ must
be spread out over the space and not merely free of coplanar quadruples.  This
is a constraint supplied by the rungs below rather than by the anchor $\mathcal{V}_1$,
and unlike Proposition~\ref{prop:rig} it is unconditional.

<!-- remark-9: body_md -->
\label{it:family}
Let $H_1,H_2$ be the $6\times21$ matrices whose columns are the points of $\mathcal{V}_1$
and of the set $W$ of the $21$ column points of a parity check matrix of a
$[21,15,5]_4$ code.  By Lemma~\ref{lem:red} both are $4$-general, and
\[
  |W\cap\mathcal{V}_1|=0
  \qquad\text{and}\qquad
  |W\cap\mathcal{V}_\alpha|\le 2 \quad\text{for all }\alpha\in\mathbb{F}_{4^3}^* .
\]
So $W$ is disjoint from $\mathcal{V}_1$ and is \emph{not} one of the $63$ sets
$\mathcal{V}_\alpha$ that partition $\mathrm{PG}(5,4)\setminus(\Pi_1\cup\Pi_2)$
\cite[Sec.~4.2, property (iv)]{Pavese}; both intersection statements were
checked by direct point-counting against these sets.  Nevertheless $W$ is
\emph{equivalent} to $\mathcal{V}_1$: a collineation $g$ with $g(\mathcal{V}_1)=W$ exists if
and only if the $[21,6]_4$ codes spanned by the rows of $H_1$ and $H_2$ are
monomially equivalent, and a direct
test with \textsc{Magma}'s \texttt{IsEquivalent} confirms that this equivalence
holds.  Both codes have monomial automorphism group of order
$378 = 2\cdot3^3\cdot7$, so the stabiliser of $\mathcal{V}_1$ in $\mathrm{PGL}(6,4)$ has order
$126=378/3$, the kernel being the scalar matrices.  Pavese's family
$\{\mathcal{V}_\alpha\}$ is therefore a
\emph{proper} subset of the orbit $\mathrm{PGL}(6,4)\cdot\mathcal{V}_1$.  Since the bound of
Proposition~\ref{prop:rig} is orbit-invariant, it holds verbatim with $\mathcal{V}_1$
replaced by any member of that orbit.  By \cite[Sec.~4.2, property (ii)]{Pavese}, $\mathcal{V}_1$
carries a group of order $21$ acting regularly on its points; since $21\nmid22$,
no $22$-point set can carry that symmetry, which rules out the most obvious
equivariant generalisations of $\mathcal{V}_1$ as candidates.  The anchor $\mathcal{V}_1$ was
independently reconstructed from \cite[Thm.~4.6]{Pavese}; see
Appendix~\ref{app:cert}.
