<!-- lemma-3: body_md -->
Let $G$ be a non-elementary geometrically finite Kleinian group and $\Lambda(G)$ be its limit set. Let $\mathcal P$ be the set of all parabolic fixed points of $G$. Suppose that
	$$P=\{p_1,\ldots,p_m\}\subseteq\mathcal P$$
	is the finite set of parabolic vertices of a fundamental domain. Then, for each $i=1,\ldots,m$, one can choose $t_i>0$ sufficiently large so that
	\begin{align}K^{*}=\Lambda(G)\setminus
		\left(
		\mathcal P\cup\bigcup_{i=1}^{m}S(p_i,t_i)
		\right)
	\end{align}
	satisfies
	$\mu_\delta(K^{*})>0.$
	Furthermore,
	$\dim_H K^{*}=\dim_H\Lambda(G)=\delta.$
<!-- end lemma-3 -->
<!-- proof-1: body_md -->
By applying the global measure formula, we know that, for each $x\in \mathcal{P}$, there exists a constant $C$ such that the Patterson-Sullivan measure $\mu _{\delta } $ of the shadow $S(x, t)$  satisfies
	
	$$\mu _{\delta } ( S( x,t))\le C exp\left ( -t\delta -\rho \left ( x,t \right )\left ( \delta -k(x)  \right )   \right )  ,$$
	where $k\left ( x,t \right ) = k\left ( x \right ) $ if $x_{t}\in H_{x}  $ for some $x\in \mathcal{P}$ and $0$ otherwise, and
	$$\rho \left ( x,t \right ) = \inf \left \{ d_{\mathbb{H} }\left ( x_{t},y  \right ) :y\notin H_{x}    \right \} ,$$
	if $x_{t}\in H_{x}  $ for some $x\in \mathcal{P}$ and $0$ otherwise.
	By Fraser's result ( \cite{JF}, Lemma 3.2), we know that $\rho \left ( x,t \right ) \sim t$ as $t\to \infty ,$ for all point $x\in \mathcal{P}.$
	It is easy to see that   $\mu _{\delta }  \left ( S\left ( x,t \right )  \right )\to 0$  by $ exp\left ( -\left ( 2\delta -k \right )t  \right )\to 0 $ as $ t\to \infty .$
	
	Hence, for any $x\in \mathcal{P}$ and positive $r$, there exists a sufficiently large $t_{x} $ such that for any $t>  t_{x} ,$ $\mu _{\delta }  \left ( S(x,t)  \right ) \le r.$ Thus $\mu_\delta(\{p\})=0.$ Note that the set $\mathcal P$ of all parabolic fixed points is countable. Hence $\mu_\delta(\mathcal P)=0,$ since
	$$\mu_\delta(\mathcal P)
	\leq
	\sum_{p\in\mathcal P}\mu_\delta(\{p\})
	=0.$$
	
	
	
	                                                                                                                                                                                                    
	By some easy calculation or see  \cite{JF}, we know that the radius of $S\left ( z,t \right )$ uniformly comparable to $e^{-t} .$ The global measure formula gives $$\mu_\delta\bigl(S(x,t)\bigr)
	\asymp
	e^{-\delta t}
	e^{-(\delta-k(x,t))\rho(x,t)}.$$
	Let \begin{align*}K^{*}=\Lambda(G)\setminus
		\left(
		\mathcal P\cup\bigcup_{i=1}^{m}S(p_i,t_i)
		\right).
	\end{align*}. For each point $p_i\in P$ we can choose a  sufficiently small number $r_{i}$ ,  and  a  sufficiently large number $t_{i}$ such that for $t\geq t_{i},$
	
	$$\mu _{\delta }  \left ( K^{*} \right ) = \mu _{\delta }  \left ( \Lambda(G)\setminus \bigcup_{p_{i}\in P}S(p_i,t_i)
	\right ) \ge 1-\sum_{p_{i} \in P}^{}\mu _{\delta }  \left ( S(p_i,t)  \right )\ge  1- \sum_{p_{i} \in P}r_{i}> 0 .$$
	
	Next we will show $\dim_H K^{*}=\dim_H\Lambda(G)=\delta.$ We consider a Frostman-type estimate.
	
	Notice that $G$ is of divergence type, the associated geodesic flow is ergodic by the Hopf-Tsuji-Sullivan theorem (\cite{DS3}, Theorem 14). Thus, by the ergodic law for the ray excursion function (\cite{DS3}, Corollary 19), we have
	$$\lim_{t\to\infty}\frac{\rho(x,t)}{t}=0
	\quad\text{for }\mu_\delta\text{-almost every }x\in \Lambda(G).$$
	Taking logarithms in the global measure formula and dividing by $(-t),$ we obtain $$\lim_{t\to\infty}
	\frac{\log \mu_\delta\bigl(S(x,t)\bigr)}{-t}
	=\delta.$$
	Setting $l=e^{-t},$ it follows that $$\lim_{r\to0}
	\frac{\log \mu_\delta(S(x,l))}{\log l}
	=\delta$$
	for $\mu_\delta$-almost every $x\in \Lambda(G).$
	
	                                                                                                                                                  
	
	Fixing $s<\delta$, for $\mu_\delta$-almost every $x\in K^{*}$, there exists $l_x>0$ such that for every $0<l<l_x,$
	$$\frac{\log\mu_\delta(S(x,l))}{\log l}>s.$$
	Whenever $0<l<1$, this inequality is equivalent to
	$$\mu_\delta(S(x,l))\leq l^s.$$
	For each positive integer $n$, define
	$$K_n= \left\{ x\in K^{*}:
	\mu_\delta(S(x,l))\leq l^s \text{ for every }0<l<\frac1n
	\right\}.$$
	Note the fact that
	$$\mu_\delta\left(
	K^{*}\setminus\bigcup_{n=1}^{\infty}K_n
	\right)=0$$
	and $\mu_\delta(K^{*})>0$, there exists some positive integer $n$ such that $\mu_\delta(K_n)>0.$ Define the normalized restricted measure as
	$$\nu(A)=
	\frac{\mu_\delta(A\cap K_n)}
	{\mu_\delta(K_n)}.$$
	Then $\nu$ is a probability measure supported on $K_n$.
	
	Fix point $y$. For $0<l<\frac1{2n},$ if $S(y,l)\cap K_n=\varnothing,$ then $\nu(S(y,l))=0.$ Otherwise choose point $\xi\in B(y,l)\cap K_n.$
	Then $B(y,l)\subseteq B(\xi,2l).$ Notice that
	and $\xi\in K_n$, we have
	$$\mu_\delta(S(x,2l))\leq(2l)^s.$$
	
	
	Therefore,
	$$\begin{aligned}
		\nu(S(y,l))=
		\frac{\mu_\delta(S(y,l)\cap K_n)}
		{\mu_\delta(K_n)}
		\leq
		\frac{\mu_\delta(S(x,2l))}
		{\mu_\delta(K_n)}
		\leq
		\frac{2^s}{\mu_\delta(K_n)}l^s.
	\end{aligned}$$
	Thus, there exists a constant
	$C_s=\frac{2^s}{\mu_\delta(K_n)}>0$
	such that
	$\nu(S(y,l))\leq C_s l^s$
	for all sufficiently small $l>0$.
	
	Hence by the mass distribution principle (Lemma 3.3), we have $\dim_H K_n\geq s.$
	It follows that $\dim_H K^{*}\geq s,$ since $K_n\subseteq K^{*}.$
	Letting $s$ tend to $\delta$, we have
	$\dim_H K^{*}\geq\delta.$
	On the other hand, $K^{*}\subseteq\Lambda(G)$ shows
	$$\dim_H K^{*}\leq\dim_H\Lambda(G).$$
	
	In conclusion, we have $\dim_H K^{*}=\delta=\dim_H\Lambda(G).$

The proof will be divided into three parts.

First, we  consider the case $\delta(r) \longrightarrow \frac{1}{2}$ as $r\to 0$  to ensure the continuity of $\delta(r)$ at $0.$ The method we adopted  here is from McMullen (\cite{Mc2}, Theorem 3.6 ).  It can be see that for sufficiently small $r$ , the limit set $\Lambda_r$ is a Cantor set.
After removing the infinity point $\infty$  and its countable orbit under the group action, the limit set can be decomposed into a sequence of connected                                                   branches . Let $\Lambda_r(0)$ denote the basic branch containing the origin, and let $\Lambda_r(n)$ denote the branch concentrated near $2n,$ where $n\in\mathbb Z.$ Then up to a countable set with measure zero, there is a self-similar decomposition $$\Lambda_r(0)
=
\rho_r\left(
\bigcup_{n\ne0}\Lambda_r(n)
\right),$$ where $\rho_r$ is the reflection about the circle $C_r.$

Let $\mu_r$ be a $\delta(r)$ dimension critical conformal measure of $\Gamma_r.$ Since the derivatives of the translations $T_{2n}$ are modulus $1$ in the Euclidean metric,  all the translated branches have the same measure $\mu_r(\Lambda_r(n))
=
\mu_r(\Lambda_r(0)).$
By conformal invariant of the measures $\mu_{r}$, we obtain $$\mu_r(\Lambda_r(0))
=
\sum_{n\ne0}
\int_{\Lambda_r(n)}
|D\rho_r(z)|^{\delta(r)}
\,d\mu_r(z).$$
For sufficiently large $|n|$ and $z\in\Lambda_r(n)$ , the branch $\Lambda_r(n)$ is concentrated near $2n.$ Hence  $|z|\asymp2|n|.$  Furthermore notice that $|D\rho_r(z)|=\displaystyle \frac{r^{2}}{|z|^{2}}$, we have $$|D\rho_r(z)|^\delta
=
\left(\frac r{2|n|}\right)^{2\delta}
\bigl(1+\text{distortion term}\bigr).$$
By the symmetry between $n$ and $-n,$ we obtain the critical normalization equation $$1=
2\sum_{n=1}^{\infty}
\left(\frac r{2n}\right)^{2\delta(r)}
a_n(\delta(r)),$$ where $a_n(\delta(r))\longrightarrow1
,$ as $n\to\infty.$

If we temporarily ignore the branch distortion and set $a_n(\delta,r)\sim 1,$ we obtain the model equation
\begin{align} 1\sim
2\sum_{n=1}^{\infty}
\left(\frac r{2n}\right)^{2\delta}.
\end{align}

Let us consider the Riemann zeta function $$\zeta(s)
=
\sum_{n=1}^{\infty}\frac1{n^s},
\qquad
\operatorname{Re}s>1.$$ Then (5.2) becomes $1
\sim
2\left(\frac r2\right)^{2\delta}
\zeta(2\delta),$ or equivalently
\begin{align}2\zeta(2\delta)
\sim
\left(\frac r2\right)^{-2\delta}.
\end{align}

Now let  $r\to 0,$ note that  the Riemann zeta function has a unique pole at $s=1,$ it follows that $2\delta(r)\longrightarrow1, $ i.e. $\delta(r)\longrightarrow\frac{1}{2} $ as $r\to 0.$

Note that (5.2) is a asymptotic estimation formula, in the following  we will give a more precise estimation to prove that $\delta(r) = \frac{1+r}{2} + O(r^2) \quad \text{as } r \to 0,$ which is a result of McMullen.

Set $\delta=\frac12+\varepsilon,
$ $ \varepsilon>0.$ For $s$ near $1$, the Riemann zeta function has the Laurent expansion
$$\zeta(s)
=
\frac1{s-1}
+\mathcal{C }_{0}
+O(s-1),$$ where $\mathcal{C }_{0} $ is the Euler-Mascheroni constant defined as
$$\mathcal{C }_{0}
=
\lim_{N\to\infty}
\left(
\sum_{n=1}^{N}\frac1n-\log N
\right).$$
Thus \begin{align}\zeta(1+2\varepsilon)
=
\frac1{2\varepsilon}
+\mathcal{C }_{0}
+O(\varepsilon).
\end{align}
Substituting (5.4) into the model equation (5.3), we can have

\begin{align}\frac1{\varepsilon}
+2\mathcal{C }_{0}
+O(\varepsilon)
=
\frac2r
\exp\left(
2\varepsilon\log\frac2r
\right)= \frac{2}{r}\Bigl(1 - 2\varepsilon\ln(r/2) + O(\varepsilon)\Bigr).
\end{align}
Let $\varepsilon = cr + o(r),$ it follows from (5.5) that
$$\frac{1}{cr} + 2\mathcal{C }_{0}  + O(r) = \frac{2}{r}\Bigl(1 - 2cr\ln(r/2) + O(r)\Bigr).$$
Multiplying both sides by $r$, we have
$$\frac{1}{c} + 2\mathcal{C }_{0}  r + O(r) = 2 - 4cr\ln(r/2) + O(r).$$
Note that $r\log\frac1r\longrightarrow0$ as $r\to 0,$ the dominant terms in (5.5) imply $\varepsilon\asymp r,$ which implies $c = 1/2,$ and thus $\varepsilon = \frac{r}{2} + O(r).$

=

=
\frac{1+r}{2}+O(r^2),
\qquad r\to0.$$
Consequently, after defining $\delta(0)=\frac12,$ the function $\delta(r)$ is continuous at $r=0.$


Second,  we will prove  that $\delta(r) \to 1 \quad \text{as } r \to 1.$

For $r=1,$ the circle $C_1$ is tangent to  $\ell_{+}$ and $\ell_{-}.$ Hence the limit set is $\Lambda_1=\widehat{\mathbb R}$ and $\delta(1)
=
\dim_{H}(\Lambda_1)
=

Let $r\to 1.$ Since the circles $C_{r}$ converge to $C_1,$ the reflections $\rho_{r}$ in these circles converge to $\rho_1.$  Note that the reflections about the two vertical lines   $\ell_{+}$ and $\ell_{-}$ are  independent of $r.$ Hence the generators converge, and therefore $\Gamma_{r}\longrightarrow\Gamma_1$ algebraically, for the definition of algebraical convergence see \cite{Mc1}.

                     
            
                                                          
                    
             

For $r<1,$ the circle $C_r$ is disjoint from the line $\ell_{+}.$ Hence the product of the reflections in these two geodesics is a hyperbolic element. Let $d_r=d_{\mathbb H^2}(C_r,\ell_{+}),$ denote the hyperbolic distance between the two geodesics. The translation length of the product of the two reflections is $2d_r.$ Consequently, its multiplier is $\lambda_r=e^{2d_r},$ or its reciprocal, depending on the chosen of fixed points.

As $r\to1,$ the circle $C_r$ becomes tangent to $\ell_{+},$ and therefore $d_r\longrightarrow0.$ It follows that $\lambda_r\longrightarrow1.$
Moreover, $\lambda_r$ approaches $1$ along the positive real axis, which is precisely the condition for radial convergence of the accidental parabolic element.

By symmetry, the same argument applies to the geodesic pair $(C_r,\ell_{-}).$ Hence he limiting group arise from the geodesic pairs $(C_1,\ell_{+}), (C_1,\ell_{-})$ contains two accidental parabolic elements.


In \cite{Mc2}, McMullen showed that
if $\Gamma_n\to\Gamma$ algebraically and  all accidental parabolics converge radially, then $\Gamma_n\to\Gamma$ dynamically.
In the present family, all accidental parabolic elements arise from the two tangent pairs described above, and we have verified that they converge radially. Therefore, $\Gamma_{r}\longrightarrow\Gamma_1$ dynamically, which implies $\dim_{H}(\Lambda_{r_j})
\longrightarrow
\dim_{H}(\Lambda_1) \:\:\text{as}\:\: r_{j} \to 1.$

In order to prove the analytic property, we need a more precise quantitative estimate as $r\to1.$ In the following, we will provide a quantitative estimate for $1 - \delta(r) \sim \lambda_0(X_r) \asymp \sqrt{1 - r} $ as $ \to 1.$
To do so,  we divide the quotient surface into three parts, separating the convex core from the ends of infinite volume.


Let $X_r$ denote the orientate double cover of the quotient surface $\mathbb H/\Gamma_r.$ Consider the convex core of the surface $X_r.$ For $0<r<1,$ it is easy to see that $X_r$ has a geometrically finite hyperbolic pair of pants with one rank-one cusp and two ends of infinite volume. Its convex core, denoted by $\operatorname{Core}(X_r)$,  has finite area. The boundary of $\operatorname{Core}(X_r)$ consists of two simple closed geodesics of equal length, denoted their common length by $L_r.$ Furthermore, the two  geodesics divide $X_r$ into three parts:
$$X_r=
\operatorname{Core}(X_r)
\cup E_r^+
\cup E_r^-,$$ where $E_r^+$ and $E_r^-$ are the two ends of infinite volume.
As $r\to1,$ we can see   $L_r\longrightarrow0$  and the two boundary geodesics degenerate into the two rank-one cusps of the limiting surface.

Denote the bottom of the spectrum of the surface $X_{r}$ by $\lambda_0(X_r).$		The variational characterization of the bottom of the spectrum is
\begin{align}\lambda_0(X_r)

\frac{\displaystyle\int_{X_r}|\nabla f|^2\,dA}
{\displaystyle\int_{X_r}|f|^2\,dA}.
\end{align}
The bottom of the spectrum of the Laplacian is controlled by the short geodesics. In the following, we will use the standard short-geodesic estimate to give $\lambda_0(X_r)\asymp L_r.$

For the asymptotic estimates at $r\to 1,$ the method we used here is from \cite{Mc2} and \cite{Mc3}.

By McMullen \cite{Mc1} , we know that $\Gamma_r\to\Gamma_1$ converges strongly as $r\to 1.$ Hence the two infinite-volume ends degenerate into two rank-1 cusps. At this point, two accidental parabolic points are generated. These short geodesics control the least eigenvalue of the Laplacian. We have

since the quotient above is approximately minimized by a function with $f=1$ in $\operatorname{Core}(X_r)$, and $f=0$ in the infinite volume ends, and $\nabla f$ supported in standard collar neighborhoods of the short geodesics, see \cite{JT}.

& \delta(\Gamma)\le\dfrac d2,\\[6pt]
\delta(\Gamma)\bigl(d-\delta(\Gamma)\bigr),
& \delta(\Gamma)\ge\dfrac d2.
\end{cases}$$
Hence for the case of Fuchsian groups ($d=1,$ )
we have $$\lambda_0(X_r)
=
\delta(r)\bigl(1-\delta(r)\bigr)
\sim
1-\delta(r).$$
Thus, $1-\delta(r)
\sim
\lambda_0(X_r).$ On the other hand, $\lambda_0(X_r)\asymp L_r$ and $L_r\asymp\sqrt{1-r}.$
                                                        
 
                                                              
               
Combining these estimates gives $$1-\delta(r)
\sim
\lambda_0(X_r)
\asymp
L_r
\asymp
\sqrt{1-r},
\qquad r\to1.$$
              
 
   
                      
     
               
       
            
              
   
 
                                                                 

Now its time to give the proof of the real analyticity of the Hausdorff dimensions of the limit set $\Lambda(\Gamma_{r})$ for $ r \in (0, 1).$
We firstly construct the Ruelle transfer operator $(\mathcal L_{s,r}u)(x)$ for this group using the group elements.

Fix $r\in(0,1)$. After removing the parabolic fixed points in the limit set and their countable orbits under the group action, the basic branch, denoted by $\Lambda_r(0)$, admits a countable Markov partition. Denote by $\Sigma
=
(\mathbb Z\setminus\{0\})^{\mathbb N}$ the symbolic space
with the left shift map
$$\sigma(n_1,n_2,n_3,\ldots)
=
(n_2,n_3,\ldots).$$
For each $n\ne0$, define the inverse branch by
$$f_{n,r}
=
\rho_r\circ T_{2n},
\qquad
T_{2n}(z)=z+2n.$$
                                                        
For a finite word
$$\omega=(n_1,\ldots,n_k)
\in(\mathbb Z\setminus\{0\})^k,$$
let
$$f_{\omega,r}
=
f_{n_1,r}\circ\cdots\circ f_{n_k,r}.$$
Note that
$|DT_{2n}|=1$
and
$|D\rho_r(z)|
=
\frac{r^2}{|z|^2},$
we have
$$|Df_{n,r}(z)|
=
\frac{r^2}{|z+2n|^2}$$
and
$$|Df_{\omega,r}(z)|
=
\prod_{j=1}^{k}
\left|
Df_{n_j,r}
\left(
f_{n_{j+1},r}\circ\cdots\circ f_{n_k,r}(z)
\right)
\right|.$$
Thus for sufficiently large $|n|$,
$$|Df_{n,r}(z)|
\asymp
\left(\frac r{2|n|}\right)^2.$$
Therefore, for every $s>\frac{1}{2}$,
$$\sum_{n\ne0}
\sup_z |Df_{n,r}(z)|^s
<\infty.$$
For $s>\frac12$, define the Ruelle transfer operator by
$$(\mathcal L_{s,r}u)(x)
=
\sum_{n\ne0}
|Df_{n,r}(x)|^s
u(f_{n,r}(x)).$$
                                                            
 
                                                                                        
Since this system has countably many branches, we use the transfer-operator theory for countable Markov systems rather than the ordinary matrix theory for finite-branch systems. Let $\mathcal L_{s,r}$ act on a suitable space of analytic functions on an appropriate complex neighborhood.
According to Theorem 1.2, the operator family
$$(s,r)\longmapsto\mathcal L_{s,r}$$
is real-analytic in $(s,r)$, and its maximal eigenvalue is a positive, isolated simple eigenvalue. Denote this maximal eigenvalue by $\lambda(s,r).$
Hence there exist a strictly positive eigen-function $h_{s,r}$ and a positive eigen-measure $\nu_{s,r}$ normalized by
$$\int h_{s,r}\,d\nu_{s,r}=1$$ such that
$$\mathcal L_{s,r}h_{s,r}
=
\lambda(s,r)h_{s,r}$$
and
$$\mathcal L_{s,r}^{*}\nu_{s,r}
=
\lambda(s,r)\nu_{s,r}.$$
Define the equilibrium measure
$$\mu_{s,r}
=
h_{s,r}\nu_{s,r}.$$
For a word of length $k$, define the partition function $Z_k(s,r;x)$ as
$$Z_k(s,r;x)
=
\sum_{|\omega|=k}
|Df_{\omega,r}(x)|^s.$$
By the iteration formula for the transfer operator, we have
$$\mathcal L_{s,r}^{\,k}\mathbf1(x)
=
Z_k(s,r;x).$$
According to the Ruelle-Perron-Frobenius theorem,
$$Z_k(s,r;x)
=
\lambda(s,r)^k
\bigl(h_{s,r}(x)+o(1)\bigr),$$
where the error estimate is understood in the sense of exponential growth.
Similar calculations can be referenced in Rocha's \cite{R}, Anderson and Rocha's \cite{AW}, and Ruelle's \cite{Ru}.
Therefore, the topological pressure is defined by
$$P(s,r)
=
\lim_{k\to\infty}
\frac1k\log Z_k(s,r;x),$$
and this limit is independent of the initial point $x$.

By Gelfand’s formula for the spectral radius, we have
$$\lambda(s,r)
=
\lim_{k\to\infty}
\|\mathcal L_{s,r}^{\,k}\|^{1/k},$$
where the operator norm is taken in the space of continuous functions. More generally, the spectral radius can be expressed as:
$$\lambda(\delta,r) = \lim_{k\to\infty} \left( \sum_{n_1,\dots,n_k\neq 0} \prod_{i=0}^{k} |f_{n_i}'(x_{i-1})|^{\delta} \right)^{1/k},$$
where $x_{i-1}=f_{n_1}\cdots f_{n_{i-1}}(x_0)$ and the limit is independent of the initial point $x_0.$
Furthermore,  there exists a positive eigenfunction $h$ such that $\mathcal{L}_{\delta,r}h = \lambda(\delta,r)h.$ For the special case of the Hecke groups, we can derive the expression for the spectral radius as
$$\lambda(\delta,r) = 2\sum_{n=1}^{\infty} \left(\frac{r}{2n}\right)^{2\delta} a_n(\delta,r).$$
and hence
$$P(s,r)=\log\lambda(s,r).$$

In \cite{MU},  Mauldin and Urbanski  showed that for a regular system, the dimension of the limit set is the unique zero of the function $r \mapsto P(\delta(r),r)$, i.e. the Hausdorff dimension is the unique zero of the pressure function with respect to $s.$ Hence we only need to take the unique zero point of the equation $\lambda(\delta(r), r) = 1.$

                                                                                                                                                                                                                                                                                               
 
                                                                   
Applying the implicit function theorem to $P(\delta(r),r),$  we have  the existence of a unique zero point of the equation $\lambda(\delta(r), r) = 1.$

                                                                                     
 
                                                                                                                           
                     
                                                    
                      
  
                       
                                                        
                      
  
                       
                                   
                 
  
                  
              
                       
                                             

By Lemma 4.3 of this article, since the group $\Gamma _{r} $ contains parabolic elements, hence the regular index is $\theta =1/2.$ We can directly use Lemma 3.2 in \cite{MU} to conclude that $P(s,r)$ is strictly decreasing in the variable $s$ on the interval $\left ( 1/2,+  \infty  \right ) .$
Moreover, by Theorem 1.2 we can conclude that $P(\delta,r)$ is real-analytic in the region $(0,1)\times(1/2,1).$ The real-analytic implicit function theorem implies that there exists a neighborhood $U_{r_0}$ of $r_0$ and a unique real-analytic function
$$\widetilde\delta:U_{r_0}\longrightarrow\mathbb R$$
such that
$$P(\widetilde\delta(r),r)=0,
\qquad
\widetilde\delta(r_0)=s_0.$$

On the other hand, since $P(s,r)$ is strictly decreasing in $s$, the equation
$P(s,r)=0$
has at most one zero for each fixed $r$. Hence,
$\widetilde\delta(r)=\delta(r)$
on $U_{r_0}$. Since $r_0\in(0,1)$ was arbitrary, we conclude that
$r\longmapsto H.\!\dim(\Lambda_r)$
is real-analytic on $(0,1)$.
