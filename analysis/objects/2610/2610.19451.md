<!-- theorem-1: body_md -->
\label{th:first}
For $N=31$ or every integer $N\ge37$, \eqref{eq:first} defines a CSS code with parameters $[[6N,2N+2,6]]$, row weight six, column degrees two, and $g_X=g_Z=12$. Both check matrices have rank $2N-1$.
<!-- end theorem-1 -->
<!-- proof-1: body_md -->
\emph{Orthogonality:} The four block products obtained via \eqref{eq:cssblock} correspond to block-row pairs $(0,0)$, $(0,1)$, $(1,0)$, and $(1,1)$. Using \eqref{eq:affine} we obtain the shift lists $-b$, $-c$, $a-b$, $a-c$ with components in each sum given as
\begin{equation}
\begin{array}{c|rrrrrr}
 -b&0&5&5&0&-12&-12\\
 -c&0&0&-2&-8&-2&-8\\
 a-b&0&6&8&8&0&6\\
 a-c&0&1&1&0&10&10
\end{array}.
\label{eq:difftable}
\end{equation}
Each row has even multiplicities, so all four sums vanish. For example, the third gives $C_0+C_6+C_8+C_8+C_0+C_6=0$. Orthogonality holds for every $N$.


\emph{Ranks:} The X incidence graph $G_X$ is connected because $a_1-a_0=1$.                                                                                                                                                                                                                                                                            
To see the rank directly, let $\lambda\in\mathbb{F}_2^{m_X}$ assign a binary coefficient to each check row. Requiring $\lambda^TH_X=0$ implies that the coefficients of $\lambda$ must be equal. This follow from the fact that the $G_X$ is connected and the column weight of $H_X$ is two. Thus the only solutions are $\lambda =0$ or $\lambda = 1$                                                                 
and the rank is therefore $m_X-1 = 2N-1$. Multiplying block column $v$ of $H_Z$ by $C_{-b_v}$ modifies its row block shifts to $0$ and $c_v-b_v$, respectively. With
\begin{equation}
 \pi=(3,2,1,0,5,4),\quad (c-b)_{\pi(v)}=8-a_v,
 \label{eq:isomorphism}
\end{equation}
a column permutation, coordinate negation, and translation of one vertex class give a graph isomorphism. The same proof for $H_X$ follows from above and hence $\operatorname{rank}_{\mathbb F_2}H_Z=2N-1$ as well. Finally,~\eqref{eq:k} gives $k=2N+2$.

\emph{Girth:}
The positive differences among the entries of $a$ are
$D=\{1,\ldots,12,15,17,18\}$.
The thirty elements of $D\cup(-D)$ are distinct
modulo $31$. They also remain distinct modulo
every $N\ge37$, since the difference between any
two has absolute value at most $36$.
Thus the $G_X$ has neither parallel
edges nor 4-cycles for these $N$ and $g_X=2G_X\geq 12$~\cite{prelift, girth}. Since any $2\times r$ array of circulants has girth bounded above by 12 \cite{sv12}, we have $g_X=12$. A similar proof holds for $G_Z$ and then $g_X, g_Z = 12$.
\emph{Distance:}                                                                                                                                                                                                                                                             
Every nonzero kernel vector of a graph incidence matrix contains a cycle, so \eqref{eq:distance} gives $d_X,d_Z\ge6$. For the reverse bound, let $e_t$ be the length $N$ unit column vector at $t\pmod N$, and set
\begin{equation}
 \begin{split}
 z_0&=e_1,\qquad z_1=z_2=z_3=0,\\
 z_4&=e_1+e_{-11}+e_{-5},\qquad z_5=e_{-11}+e_{-5}.
 \end{split}\label{eq:logical6}
\end{equation}
This vector has weight six for every allowed $N$. Its two X block syndromes vanish 
\begin{gather*}
 z_0+z_4+z_5=0,\\
 \begin{aligned}
 z_0+C_{12}z_4+C_{18}z_5
 &=e_1+(e_{13}+e_1+e_7)\\
 &\quad +(e_7+e_{13})=0.
 \end{aligned}
\end{gather*}
Every row of $H_Z$ has one nonzero entry in each of the six blocks. Any vector in $\operatorname{row}(H_Z)$ therefore has the same parity in all six blocks. The block parities of \eqref{eq:logical6} are $(1,0,0,0,1,0)$, so $z\notin\operatorname{row}(H_Z)$. Consequently $d_Z=d=6$.

<!-- proposition-1: body_md -->
\label{prop:girthbound}
If every column of $H_X$ has weight two and $H_Z$ has a nonzero row of weight $w$, CSS orthogonality implies $g_X\le2w$. The analogous statement holds with X and Z interchanged.
<!-- end proposition-1 -->
<!-- proof-2: body_md -->
The rows in $H_Z$ are codewords in $\ker H_X$, and each codeword in a $2\times n$ matrix of weight $w$ is associated with a $2w$-cycle, hence $g_X\leq 2w$.

<!-- theorem-2: body_md -->
\label{th:mix}
The matrices in~\eqref{eq:mix-base} satisfy $AB=BA$.
For every integer $q\ge2$, the checks in~\eqref{eq:mix-specialize}
define a length $96q$ CSS code. Each check matrix has $48q$ rows,
row weight six, and column weight three.
<!-- end theorem-2 -->
<!-- proof-3: body_md -->
Set $D=I+zC_2$, $U=zC_8+z^3C_{10}$, and
$V=C_8+z^2C_{22}$, so
$$A=\begin{bmatrix}D&zF\\F&D\end{bmatrix} \textrm{ and
 }B=\begin{bmatrix}I&U\\V&I\end{bmatrix}.$$
The circulant coefficients commute, giving $DU=UD$ and $DV=VD$.
The affine identity $F_{a,b}C_s=C_{as}F_{a,b}$ gives
\begin{equation}
FC_8=C_8F,\quad FC_{22}=C_{10}F,\quad FC_{10}=C_{22}F.
\label{eq:mix-affine}
\end{equation}
For example, $7\cdot22\equiv10\pmod{24}$.
Consequently $zFV=UF$ and $FU=zVF$.
The two block products are
\begin{equation}
\begin{split}
AB&=\begin{bmatrix}D+zFV&DU+zF\\F+DV&FU+D\end{bmatrix},\\
BA&=\begin{bmatrix}D+UF&zF+UD\\VD+F&zVF+D\end{bmatrix}.
\end{split}
\label{eq:mix-products}
\end{equation}
The identities $DU = UD$, $DV = VD$, $zFV = UF$, and $FU = zVF$ make the corresponding blocks of (19) equal, so $AB = BA$. Since the lift preserves sums and products, lifting gives $H_X^{(q)} (H_Z^{(q)})^T = A_q B_q + B_q A_q = (AB + BA)_q = 0$ over $\mathbb{F}_2$ for every $q \geq 2$. 
In $D_q = I_q \otimes I + S_q \otimes C_2$, the two terms have outer exponents $0$ and $1$, so for $q \geq 2$ they lie in different $24 \times 24$ blocks and no entries cancel. In $B_q$, the two terms of each off-diagonal block differ in outer
shift by two. They occupy distinct outer positions for $q>2$.
For $q=2$, the shifts coincide, but the internal shifts $8,10$
and $8,22$ are distinct, so no entries cancel.
Hence $A_q$ and $B_q$ each have row and column weight three.
Their concatenations have the claimed weights and dimensions.
