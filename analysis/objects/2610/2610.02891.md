<!-- theorem-1: body_md -->
\label{thm:uniform_neuron}
Given a set of $N$ hyperplanes of $\mathbb{R}^d$ defined by
\[
\mathbf{a}_i^\top \mathbf{x} + r_i = 0, \quad i = 1,2,\dots,N.
\]
If $\{\mathbf{a}_i\}_{i=1}^N$ are i.i.d. and uniformly distributed on the $d$-dimensional unit sphere, and $\{r_i\}_{i=1}^N$ are i.i.d. and uniformly distributed in $[0,1]$, then for a fixed $\tau \in (0,1)$,
\begin{equation}
\mathbb{E}\left[ D_N^\tau(\mathbf{x}) \right] = \tau, \quad \forall \|\mathbf{x}\|_2 \leq 1 - \tau,
\end{equation}
where $D_N^\tau(\mathbf{x})$ is the density function of the neurons defined by
\begin{equation}
D_N^\tau(\mathbf{x}) = \frac{1}{N} \sum_{i=1}^N \chi_{\{d_i(\mathbf{x}) < \tau\}}(\mathbf{x}),
\end{equation}
with $\chi_{\{d_i(\mathbf{x}) < \tau\}}(\mathbf{x})$ denoting the indicator function whether the distance between $\mathbf{x}$ and the $i$-th partition hyperplane is smaller than $\tau$.

<!-- remark-1: body_md -->
The classical two-phase Stefan problem in two dimensions serves as a concrete example of the above framework. For an interface represented by $x=s(y,t)$, the two subdomains are $\Omega_1(t)=\{(x,y)\in\Omega\mid x<s(y,t)\}$ and $\Omega_2(t)=\{(x,y)\in\Omega\mid x>s(y,t)\}$. The diffusion coefficient is $\kappa=\kappa_1$ in $\Omega_1(t)$ and $\kappa=\kappa_2$ in $\Omega_2(t)$, where $\kappa_1,\kappa_2>0$ are constants. The governing PDE is given by
\begin{equation}\label{eq:stefan}
\dfrac{\partial u}{\partial t} - \kappa \Delta u = 0, \quad (x,y,t) \in \Omega_1(t) \cup \Omega_2(t),
\end{equation}
with jump conditions $\ensuremath{[\![ u ]\!]} = h,~\ensuremath{[\![ \kappa\nabla u\cdot \mathbf{n} ]\!]} = q$ on $\Gamma(t)$ and appropriate initial/boundary data. The interface is parameterized as $\Gamma(t) = \{(x,y,t)\mid x = s(y,t)\}$, which corresponds to choosing the level-set function $\zeta(x,y,t) = x - s(y,t)$ in~\eqref{eq:interface_def}.
The operator $\mathcal{F}$ in~\eqref{eq:interface_condition} then takes the specific form of the Stefan condition:
\begin{equation}
\mathcal{F}(\zeta,u) = \partial_t \zeta + \ensuremath{[\![ \kappa\nabla u\cdot\mathbf{n} ]\!]} = 0,
\end{equation}
 where $\ensuremath{[\![ \kappa\nabla u\cdot\mathbf{n} ]\!]}$ denotes the jump of normal heat flux across the interface. 
Alternatively, we also can directly represent $s(y,t)$ by a TransNet (instead of $\zeta_{\rm NN}$ for $\zeta(x,y,t)$)
\begin{equation}
s_{\rm NN}(y,t) = \sum_{i=1}^{N_s} \beta_i \phi_i(y,t) = \boldsymbol{\beta}^\top \boldsymbol{\phi}(y,t),
\end{equation}
then the interface loss~\eqref{eq:loss_zeta} consequently reduces to
  \begin{equation}
\mathrm{Loss}_s({\boldsymbol{\alpha}},\boldsymbol{\beta})  = \sum_{i=1}^{K_{\Gamma^n}} \mu_1\left(\partial_t s_{\rm NN}(y^i,t^i) + \ensuremath{[\![ \kappa\nabla u_{\rm NN}\cdot\mathbf{n} ]\!]}(y^i,t^i)\right)^2 + \sum_{i=1}^{K_{\Omega_0}} \mu_2\left(s_{\rm NN}(y^i,0) - s_0(y^i)\right)^2.
 \end{equation}
