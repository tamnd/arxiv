\label{d:weak}
A function $u \in \mathbf{C^{\pmb 0}}([0, +\infty); {\mathbf{BV}}_{\rm loc}(\mathbb{R};\Omega))$ is a weak solution of the Cauchy problem \eqref{e:system}, \eqref{e:ini} in $[0, +\infty) \times \mathbb{R}$ if it satisfies the following conditions, for any test function $\varphi \in \mathbf{C_c^{\infty}}([0, +\infty) \times \mathbb{R}; \mathbb{R})$:
\begin{equation}
\label{e:wcond}
\begin{aligned}
\int_0^{\infty} \int_{\mathbb{R}} \left(\rho \, \varphi_t + q \, \varphi_x\right) \, {\rm{d}} x \, {\rm{d}} t + \int_{\mathbb{R}} \rho_o(x) \, \varphi(0,x) {\rm{d}} x = 0,
\\
\int_0^{\infty} \int_{\mathbb{R}} \left(q \, \varphi_t + P(\rho,q) \, \varphi_x\right) \, {\rm{d}} x \, {\rm{d}} t + \int_{\mathbb{R}} q_o(x) \, \varphi(0,x) {\rm{d}} x = 0.
\end{aligned}
\end{equation}

<!-- defi-2: body_md -->
\label{d:entro}
An entropy solution $u \in \mathbf{C^{\pmb 0}}([0, +\infty); {\mathbf{BV}}_{\rm loc}(\mathbb{R};\Omega))$ of the Cauchy problem \eqref{e:system}, \eqref{e:ini} in $[0, +\infty) \times \mathbb{R}$ is a weak solution such that for any convex entropy pair $(\mathcal{E},\mathcal{Q})$ and test function $\varphi \in \mathbf{C_c^{\infty}}((0, +\infty) \times \mathbb{R}; [0, +\infty))$:
\begin{equation}
\label{e:econd}
\int_0^{\infty} \int_{\mathbb{R}} \left(\mathcal{E}(u) \, \varphi_t + \mathcal{Q}(u) \, \varphi_x\right) \, {\rm{d}} x \, {\rm{d}} t \geqslant 0.
\end{equation}

\begin{enumerate}[leftmargin=*, label={\bf(\alph*)}]\setlength{\itemsep}{0cm}\setlength\itemsep{0em}

\item
$\mathcal{R}_1^{(\rho_o, - q_o)} \equiv - \mathcal{R}_2^{(\rho_o,q_o)}$ and $\mathcal{S}_1^{(\rho_o, - q_o)} \equiv - \mathcal{S}_2^{(\rho_o,q_o)}$.

\item
$\mathcal{R}_i^{u_o}$, $\mathcal{S}_i^{u_o}$, $\mathcal{FL}_i^{u_o}$, $\mathcal{BL}_i^{u_o}$ are $\mathbf{C^{\pmb 2}}$ functions in $(0,+\infty)$ and
\begin{align*}
&\mathcal{R}_i^{u_o}(0^+) = \mathcal{S}_i^{u_o}(0^+) = 0,&
&\frac{{\rm{d}}\mathcal{R}_i^{u_o}}{{\rm{d}}\rho}(0^+) = \frac{{\rm{d}}\mathcal{S}_i^{u_o}}{{\rm{d}}\rho}(0^+) = (-1)^{i+1} \cdot \infty,
\\
&\mathcal{R}_i^{u_o}(\infty) = \mathcal{S}_i^{u_o}(\infty) = (-1)^i \cdot \infty,&
&\frac{{\rm{d}}\mathcal{R}_i^{u_o}}{{\rm{d}}\rho}(\rho_o) = \frac{{\rm{d}}\mathcal{S}_i^{u_o}}{{\rm{d}}\rho}(\rho_o) = \lambda_i(u_o).
\end{align*}

\item
$\mathcal{R}_1^{u_o}$, $\mathcal{S}_1^{u_o}$, $\mathcal{FL}_1^{u_o}$, $\mathcal{BL}_1^{u_o}$ are strictly concave, while $\mathcal{R}_2^{u_o}$, $\mathcal{S}_2^{u_o}$, $\mathcal{FL}_2^{u_o}$, $\mathcal{BL}_2^{u_o}$ are strictly convex.

\item
\label{i:d}
$\mathcal{S}_2^{u_o} = \mathcal{FL}_2^{u_o} < \mathcal{R}_2^{u_o} = \mathcal{BL}_2^{u_o} < \mathcal{R}_1^{u_o} = \mathcal{FL}_1^{u_o} < \mathcal{S}_1^{u_o} = \mathcal{BL}_1^{u_o}$ in $(0,\rho_o)$, and $\mathcal{S}_1^{u_o} = \mathcal{FL}_1^{u_o} < \mathcal{R}_1^{u_o} = \mathcal{BL}_1^{u_o} < \mathcal{R}_2^{u_o} = \mathcal{FL}_2^{u_o} < \mathcal{S}_2^{u_o} = \mathcal{BL}_2^{u_o}$ in $(\rho_o,+\infty)$.

\item
$\mathsf{R}_i^{u_o} \cap \mathsf{R}_i^{u^o} \neq \emptyset$ if and only if $\mathsf{R}_i^{u_o} = \mathsf{R}_i^{u^o}$, while if $u^o \in \mathsf{S}_i^{u_o}$ then $\mathsf{S}_i^{u_o} \cap \mathsf{S}_i^{u^o} = \{u_o,u^o\}$.
\end{enumerate}

\label{p:Korn}

\end{enumerate}

\label{r:Leprous}
Fix $u_\ell \in \Omega$. Proposition \ref{p:Leprous} shows that
$\overline{Q}(u_\ell)$ represents the {\em maximum achievable flow} at $x=0$ of a solution to the Riemann problem \eqref{e:system}, \eqref{e:iniRie} with $u_r \in \Omega$.

<!-- defi-4: body_md -->
\label{d:csol}
For a given initial datum $(u_o,h_o) \in {\mathbf{BV}}_{\rm loc}(\mathbb{R};\Omega) \times \{0,1\}$, a function $(u,h)\in{\mathbf{BV}}_{\rm loc}([0, +\infty) \times \mathbb{R};\Omega) \times \mathbf{L^{\pmb \infty}}([0, +\infty);\{0,1\})$ is a global c-solution of the Cauchy problem
\begin{equation}
\label{e:csystem}
\left\{\begin{array}{@{}l@{}}
\rho_t + q_x = 0, \\
q_t + P_x = 0, \\
\left(u(0,x),h(0)\right) = (u_o,h_o),
\end{array}\right.
\end{equation}
if away from $x=0$ the function $u$ is an entropy solution in the sense of Definition~\ref{d:entro}, and at $x=0$ it satisfies the following coupling conditions for a.e.\ $t>0$:
\begin{gather}
\label{e:csol-q}
q(t,0^-) = q(t,0^+) = q^0(t),
\\
\label{e:csol-h}
h(t) = 0 \Longrightarrow q^0(t) = 0.
\end{gather}
<!-- end defi-4 -->
<!-- rmk-2: body_md -->
Some comments on Definition~\ref{d:csol} are in order.
\begin{itemize}[leftmargin=*]
\item 
Condition \eqref{e:csol-q} ensures that a c-solution satisfies the first Rankine-Hugoniot condition \eqref{e:RH1} at $x=0$, which expresses the conservation of gas through the valve.  
Condition \eqref{e:csol-h} ensures that if the valve is closed, then no flow occurs through $x=0$.

\item 
Away from $x=0$, the $u$-component of a c-solution is an entropy solution of the Cauchy problem \eqref{e:csystem} in the sense of Definition~\ref{d:entro}; namely, it satisfies condition \eqref{e:wcond} for any test function $\varphi \in \mathbf{C_c^{\infty}}([0, +\infty) \times (\mathbb{R}\setminus\{0\}); \mathbb{R})$, and condition \eqref{e:econd} for any entropy pair $(\mathcal{E},\mathcal{Q})$ and test function $\varphi \in \mathbf{C_c^{\infty}}((0, +\infty) \times (\mathbb{R}\setminus\{0\}); [0, +\infty))$.
In particular, along the two pipes $\pm x>0$ the gas flow is described by \eqref{e:system}.
Across $x=0$, non-entropic stationary waves may arise; we refer to such waves as c-waves.
\end{itemize}

<!-- defi-5: body_md -->
\label{d:RSV} 
A function
\begin{equation}
\label{e:C}
\begin{array}{cccc@{\;}l}
C \colon& \mathsf{D} \times \{0,1\}& \to &\mathsf{D} \times \{0,1\}
\\
&(u_\ell,u_r,h_o)&\mapsto& \left(u_{\rm c}^-(u_\ell,h_o), u_{\rm c}^+(u_\ell,u_r,h_o), h_{\rm c}(u_\ell,h_o) \right)
\end{array}
\end{equation}
is a \emph{c-function} if there exist $\rho_{\rm c}^-\colon \Omega \times \{0,1\} \to (0, +\infty)$, $\rho_{\rm c}^+ \colon \mathsf{D} \times \{0,1\} \to (0, +\infty)$ and $q_{\rm c}^{0} \colon \Omega \times \{0,1\} \to [0, +\infty)$ such that $u_{\rm c}^- =(\rho_{\rm c}^- ,q_{\rm c}^{0} )$ and $u_{\rm c}^+ = (\rho_{\rm c}^+ ,q_{\rm c}^{0} )$ satisfy, for any $(u_\ell,u_r,h_o)\in\mathsf{D}\times\{0,1\}$,
\begin{align}
\label{e:RSV1}
&u_{\rm c}^-(u_\ell,h_o) \in \Gamma^-(u_\ell),&
&q_{\rm c}^{0}(u_\ell,h_o) \in \left[ 0 , \overline{Q}\left(u_\ell\right) \right],
\\
\label{e:RSV2}
&u_{\rm c}^+(u_\ell,u_r,h_o) \in \Gamma^+(u_r),&
&h_{\rm c}(u_\ell,h_o) = 0 \Longrightarrow
q_{\rm c}^{0}(u_\ell,h_o) = 0.
\end{align}
The corresponding \emph{c-Riemann solver} $\mathcal{RS}_{\rm c} \colon \mathsf{D} \times \{0,1\} \to {\mathbf{BV}_{\rm loc}}(\mathbb{R};\Omega) \times \{0,1\}$ is defined as
\begin{align*}
\mathcal{RS}_{\rm c}[u_\ell,u_r,h_o](\xi) &\doteq
\begin{cases}
\left(\mathcal{RS}_{\rm s}\left[u_\ell,u_{\rm c}^- \right](\xi),h_{\rm c}\right) &\hbox{if }\xi<0,\\[5pt]
\left(\mathcal{RS}_{\rm s}\left[u_{\rm c}^+ ,u_r\right](\xi),h_{\rm c}\right) &\hbox{if }\xi\geqslant 0,
\end{cases}&
(u_{\rm c}^- ,u_{\rm c}^+,h_{\rm c}) &= C(u_\ell,u_r,h_o).
\end{align*}
<!-- end defi-5 -->
<!-- rmk-3: body_md -->
We now comment on Definition~\ref{d:RSV}.

\begin{enumerate}[label={(\roman*)},leftmargin=*,nolistsep]\setlength{\itemsep}{0cm}\setlength\itemsep{0em}

\item 
The map $(t,x) \mapsto u_{\rm c}(x/t)$ satisfies the first Rankine-Hugoniot condition \eqref{e:RH1} in the whole of $\mathbb{R}$, the second Rankine-Hugoniot condition \eqref{e:RH2} in $\mathbb{R}\setminus\{0\}$, but it does not necessarily satisfy \eqref{e:RH2} at $x=0$.
Hence, mass is conserved, whereas momentum may fail to be conserved through $x=0$.
As a consequence, $u_{\rm c}$ \emph{may fail} to be a weak solution of \eqref{e:system} in the whole of $\mathbb{R}$ in the sense of Definition~\ref{d:weak}.
On the other hand, $(u_{\rm c},h_{\rm c})$ is a c-solution in the sense of Definition~\ref{d:csol}.

\item 
A c-Riemann solver $\mathcal{RS}_{\rm c}$ is uniquely characterized by the function $C$, which associates to any initial value $(u_\ell,u_r,h_o)$ the traces $u_{\rm c}^\pm$ of $u_{\rm c}$ at $\xi=0$ and the corresponding value of $h_{\rm c}$. 
For brevity we omitted the dependence of $\mathcal{RS}_{\rm c}$ on $C$.

\item
By the definitions \eqref{e:Gammaum}, \eqref{e:Gammaup} of $\Gamma^-(u_\ell)$ and $\Gamma^+(u_r)$, conditions \eqref{e:RSV1}\textsubscript{$1$} and \eqref{e:RSV2}\textsubscript{$1$} imply that for any $(u_\ell,u_r,h_o) \in \mathsf{D} \times \{0,1\}$ the following conditions are satisfied by $u_{\rm c}^-=u_{\rm c}^-(u_{\ell},h_o)$ and $u_{\rm c}^+=u_{\rm c}^+(u_{\ell},u_{r},h_o)$:
\begin{enumerate}[label={\bf\alph*)}]\setlength{\itemsep}{0cm}\setlength\itemsep{0em}
\item
$\mathcal{RS}_{\rm s}\left[u_\ell,u_{\rm c}^-\right](0^-) = u_{\rm c}^-$, hence $\mathcal{RS}_{\rm s}\left[u_\ell,u_{\rm c}^-\right]$ has no waves with positive speed;
\item
$\mathcal{RS}_{\rm s}\left[u_{\rm c}^+,u_r\right](0^+) = u_{\rm c}^+$, hence $\mathcal{RS}_{\rm s}\left[u_{\rm c}^+,u_r\right]$ has no waves with negative speed.
\end{enumerate}
\item
Again by \eqref{e:Gammaum}, \eqref{e:Gammaup}, for any $q_{\rm c}^{0} \in \left[ 0 , \overline{Q}\left(u_\ell\right) \right]$ we have that $u_{\rm c}^-=u_{\rm c}^-(u_{\ell},h_o)$ and $u_{\rm c}^+=u_{\rm c}^+(u_{\ell},u_{r},h_o)$ are given by:
\begin{align}
\label{e:ucpm}
u_{\rm c}^- &= \begin{cases}
u_{\ell}&\hbox{if } v(u_{\ell})>a \hbox{ and } q_{\rm c}^{0}=q_{\ell},
\\
\hat{u}(q_{\rm c}^{0},u_{\ell})&\hbox{otherwise},
\end{cases}&
u_{\rm c}^+ &= \begin{cases}
\check{u}(q_{\rm c}^{0},u_r)&\hbox{if } q_{\rm c}^{0} \in [0,q^{a}(u_{r})],
\\
(q_{\rm c}^{0}/a,q_{\rm c}^{0})&\hbox{if } q_{\rm c}^{0} > q^{a}(u_{r}).
\end{cases}
\end{align}
As a consequence, $v(u_{\rm c}^-)>a$ if and only if $v(u_{\ell})>a$ and $q_{\rm c}^{0}=q_{\ell}$, whereas $v(u_{\rm c}^+) \leqslant a$ holds in any case.
\end{enumerate}

\label{d:coherent}
A c-Riemann solver $\mathcal{RS}_{\rm c} \colon \mathsf{D}\times\{0,1\} \to {\mathbf{BV}}(\mathbb{R};\Omega)\times\{0,1\}$ is \emph{coherent} at $(u_\ell,u_r,h_o)\in\mathsf{D}\times\{0,1\}$ if the traces $(u_{\rm c}^\pm,h_{\rm c}) \doteq \mathcal{RS}_{\rm c}[u_\ell,u_r,h_o](0^\pm)$ satisfy
\begin{align}
(u_{\rm c}^-,u_{\rm c}^+) \in \mathsf{D}
\qquad 
\hbox{ and }
\qquad
C(u_{\rm c}^-,u_{\rm c}^+,h_{\rm c}) = (u_{\rm c}^-,u_{\rm c}^+,h_{\rm c}).
\label{e:coherent}
\end{align}
The \emph{coherence domain} $\mathsf{CH}$ of $\mathcal{RS}_{\rm c}$ is the set of all triples $(u_\ell,u_r,h_o)\in\mathsf{D}\times\{0,1\}$ where $\mathcal{RS}_{\rm c}$ is coherent. The set $\mathsf{CH}^{\scriptscriptstyle\complement}\doteq(\mathsf{D}\times\{0,1\}) \setminus \mathsf{CH}$ is the \emph{incoherence domain}.

<!-- rmk-6: body_md -->
\label{r:caus}
The evolution described by \eqref{e:hrelay}, \eqref{e:h=H} is an example of causal-memory relation between the input $\overline{Q}\left(u_\ell^0\right)$ and the output $h$: $H\left[\overline{Q}\left(u_\ell^0\right),h_o\right](t)$ depends on the whole past history in $[0,t]$ of $\overline{Q}\left(u_\ell^0\right)$ (but not on the future).
<!-- end rmk-6 -->
<!-- prop-4: body_md -->
The hysteresis relation \eqref{e:h=H} satisfies
\begin{equation}
\label{e:Landmvrks}
H\left[\overline{Q}\left(u_\ell^0\circ\varphi\right),h_o\right] = H\left[\overline{Q}\left(u_\ell^0\right),h_o\right]\circ\varphi,
\end{equation}
for all increasing homeomorphism $\varphi \colon [0, +\infty)\to[0, +\infty)$. Moreover, for all $\tau\in[0,t]$ we have
\begin{equation}
\label{e:Zytecki}
H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](t) = H\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right), H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](\tau)\right](t-\tau).
\end{equation}
<!-- end prop-4 -->
<!-- proof-1: body_md -->
Condition \eqref{e:Landmvrks} holds because $\varphi(0)=0$ and $\mathcal{T}_t^\pm\left[\overline{Q}\left(u_\ell^0\circ\varphi\right)\right] = \mathcal{T}_{\varphi(t)}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right]$, see \eqref{e:TT}.
We prove now \eqref{e:Zytecki}.
Fix $\tau\in[0,t]$.
By \eqref{e:TT} we have
\[\mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] = 
\left\{s\in[\tau,t] : \pm\left(\overline{Q}\left(u_\ell^0(s)\right) - q_*^-\right) > 0 \right\},\]
and therefore
\begin{equation}\label{e:aldd}
\mathcal{T}_{t}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] = \mathcal{T}_{\tau}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] \cup \mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right].
\end{equation}
Observe that if $s_{1} \in \mathcal{T}_{\tau}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right]$ and $ s_{2} \in \mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right]$, then $s_{1} \leqslant \tau \leqslant s_{2}$.
This implies 
\begin{align*}
\mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] \neq \emptyset
&\Longrightarrow
\sup \mathcal{T}_{\tau}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] \leqslant \tau \leqslant\sup \mathcal{T}_{t}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] = \sup \mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] \leqslant t,
\\
\mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] = \emptyset
&\Longrightarrow
\sup \mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] \leqslant \sup \mathcal{T}_{t}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] = \sup \mathcal{T}_{\tau}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] \leqslant \tau.
\end{align*}

Based on  \eqref{e:hrelay}, we distinguish the following cases.
\begin{itemize}[leftmargin=*]

\item
If $\mathcal{T}_{t-\tau}^\pm\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] = \emptyset$, then by \eqref{e:aldd} we deduce $\mathcal{T}_{t}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right] = \mathcal{T}_{\tau}^\pm\left[\overline{Q}\left(u_\ell^0\right)\right]$. Then \eqref{e:Zytecki} holds true because of \eqref{e:hrelay}: indeed
\[H\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right), H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](\tau)\right](t-\tau) = H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](\tau) = H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](t).\]

\item
Assume that $\sup \mathcal{T}_{t-\tau}^-\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] < \sup \mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right]$.
In this case we have $\mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] \neq \emptyset$ and $\sup \mathcal{T}_t^+\left[\overline{Q}\left(u_\ell^0\right)\right] = \sup\mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] \geqslant \tau$.
Moreover
\begin{align*}
\mathcal{T}_{t-\tau}^-\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] \neq \emptyset
&\Longrightarrow
\sup \mathcal{T}_t^-\left[\overline{Q}\left(u_\ell^0\right)\right] = \sup \mathcal{T}_{t-\tau}^-\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] < \sup \mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right],
\\
\mathcal{T}_{t-\tau}^-\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] = \emptyset
&\Longrightarrow
\sup \mathcal{T}_t^-\left[\overline{Q}\left(u_\ell^0\right)\right] = \sup \mathcal{T}_\tau^-\left[\overline{Q}\left(u_\ell^0\right)\right] \leqslant \tau \leqslant \sup\mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right].
\end{align*}
As a consequence, we have
\[\sup \mathcal{T}_t^-\left[\overline{Q}\left(u_\ell^0\right)\right] < \sup \mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] = \sup \mathcal{T}_t^+\left[\overline{Q}\left(u_\ell^0\right)\right].
\]
Therefore \eqref{e:Zytecki} holds true because by \eqref{e:hrelay}
\[H\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right), H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](\tau)\right](t-\tau) = 1 = H\left[\overline{Q}\left(u_\ell^0\right), h_o\right](t).\]

\item
Similarly to the previous case, if $\sup \mathcal{T}_{t-\tau}^+\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right] < \sup \mathcal{T}_{t-\tau}^-\left[\overline{Q}\left(u_\ell^0(\,\cdot\,+\tau)\right)\right]$, then

\end{itemize}
This concludes the proof.

We first prove \eqref{e:incodom1}.
Observe that $(u_{\rm c}^-,u_{\rm c}^+)$ given in \eqref{e:ucpm} is well defined because $q_{\rm c}^{0} \in [0,\overline{Q}(u_\ell)] \subseteq [0,\Bar{q}(u_\ell)]$, see Definition~\ref{d:notation}, and $(u_{\rm c}^-,u_{\rm c}^+) \in \mathsf{D}$.
Hence, by Definition~\ref{d:coherent}, $\mathcal{RS}_{\rm c}$ is coherent at $(u_\ell,u_r,h_o)$ if and only if
\begin{equation*}
C\left(u_{\rm c}^-(u_\ell,h_o),u_{\rm c}^+(u_\ell,u_r,h_o),h_{\rm c}(u_\ell,h_o)\right) = \left(u_{\rm c}^-(u_\ell,h_o),u_{\rm c}^+(u_\ell,u_r,h_o),h_{\rm c}(u_\ell,h_o)\right),
\end{equation*}
which, by \eqref{e:ucpm}, is equivalent to require that
\begin{align*}
&h_{\rm c}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = h_{\rm c}(u_\ell,h_o),&
&q_{\rm c}^{0}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = q_{\rm c}^{0}(u_\ell,h_o).
\end{align*}
The proof is carried out by the following case-by-case analysis.

\begin{itemize}[leftmargin=*]

\item
Assume $q_{\rm c}^{0}(u_\ell,h_o)=q_{*}$.
In this case $h_{\rm c}(u_\ell,h_o) = 1$ and $\overline{Q}\left(u_{\rm c}^-(u_\ell,h_o)\right) \geqslant q_{\rm c}^{0}(u_\ell,h_o) = q_{*}$.
By \eqref{e:hc} and \eqref{e:qc} we have then
\begin{align*}
&h_{\rm c}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = 1 = h_{\rm c}(u_\ell,h_o),&
&q_{\rm c}^{0}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = q_{*} = q_{\rm c}^{0}(u_\ell,h_o).
\end{align*}
Therefore, $\mathcal{RS}_{\rm c}$ is coherent at $(u_\ell,u_r,h_o)$.

\item
Assume $q_{\rm c}^{0}(u_\ell,h_o) \in [q_{*}^{-},q_{*})$.
In this case $h_{\rm c}(u_\ell,h_o) = 1$ and $q_{\rm c}^{0}(u_\ell,h_o) = \overline{Q}(u_\ell)$.
By \eqref{e:hc} and \eqref{e:qc} we have $\overline{Q}\left(u_{\rm c}^-(u_\ell,h_o)\right) \geqslant q_{\rm c}^{0}(u_\ell,h_o) \geqslant q_{*}^{-}$ and then
\begin{align*}
&h_{\rm c}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = 1 = h_{\rm c}(u_\ell,h_o),&
&q_{\rm c}^{0}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = \min\left\{ q_* , \overline{Q}\left(u_{\rm c}^-(u_\ell,h_o)\right) \right\}.
\end{align*}
We distinguish two subcases:
\begin{itemize}[leftmargin=*]
\item
Assume $v(u_{\ell}) \geqslant a$.
In this case $q_{\rm c}^{0}(u_{\ell},h_{o}) = \overline{Q}(u_\ell) = q_{\ell} \in [q_{*}^{-},q_{*})$, see \eqref{e:SleepToken}; by \eqref{e:ucpm}\textsubscript{$1$} we have $u_{\rm c}^-(u_{\ell},h_{o}) = u_{\ell}$.
As a consequence, we deduce
\[q_{\rm c}^{0}\left(u_{\rm c}^-(u_\ell,h_o),h(u_\ell,h_o)\right) = \min\left\{ q_* , \overline{Q}(u_\ell) \right\} = q_{\ell} = q_{\rm c}^{0}(u_{\ell},h_{o}).\]

\item
Assume $v(u_{\ell}) < a$.
In this case $q_{\rm c}^{0}(u_{\ell},h_{o}) = \overline{Q}(u_\ell) = \Bar{q}(u_\ell) \in [q_{*}^{-},q_{*})$, hence $u_{\rm c}^-(u_{\ell},h_{o}) = \Bar{u}(u_\ell)$.
This implies $\overline{Q}\left(u_{\rm c}^-(u_{\ell},h_{o})\right) = \Bar{q}(u_\ell) \in [q_{*}^{-},q_{*})$ and therefore
\[q_{\rm c}^{0}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = \Bar{q}(u_\ell) = q_{\rm c}^{0}(u_{\ell},h_{o}).\]
\end{itemize}
Therefore, in both cases, $\mathcal{RS}_{\rm c}$ is coherent at $(u_\ell,u_r,h_o)$.

\item
Assume $q_{\rm c}^{0}(u_\ell,h_o) = 0$.
In this case $h_{\rm c}(u_\ell,h_o) = 0$ and $\overline{Q}(u_{\ell}) \leqslant q_{*}^{+}$.
By \eqref{e:ucpm}\textsubscript{$1$} we have then $u_{\rm c}^-(u_\ell,h_o) = \hat{u}(0,u_{\ell})$.
We distinguish two cases:
\begin{itemize}[leftmargin=*]
\item
Assume $\overline{Q}\left(\hat{u}(0,u_{\ell})\right) > q_{*}^{+}$.
By \eqref{e:hc} we have $h_{\rm c}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = 1 \neq 0 = h_{\rm c}(u_\ell,h_o)$.
Therefore, $\mathcal{RS}_{\rm c}$ is not coherent at $(u_\ell,u_r,h_o)$, see \figurename~\ref{f:coherence}.
Furthermore, in this case $v(u_{\ell}) > a$.
Indeed, if by contradiction $v(u_{\ell}) \leqslant a$, then by item~\ref{i:d} of Lemma~\ref{l:JSatriani} we have $q_{*}^{+} \geqslant \overline{Q}(u_{\ell}) = \Bar{q}(u_\ell) \geqslant \Bar{q}(\hat{\rho}(0,u_{\ell})) = \overline{Q}\left(\hat{u}(0,u_{\ell})\right) > q_{*}^{+}$, which gives a contradiction.

\item
Assume $\overline{Q}\left(\hat{u}(0,u_{\ell})\right) \leqslant q_{*}^{+}$.
In this case, by \eqref{e:hc} we have $h_{\rm c}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = h_{\rm c}(u_\ell,h_o) = 0$ and therefore $q_{\rm c}^{0}\left(u_{\rm c}^-(u_\ell,h_o),h_{\rm c}(u_\ell,h_o)\right) = 0 = q_{\rm c}^{0}(u_\ell,h_o)$.
Therefore, $\mathcal{RS}_{\rm c}$ is coherent at $(u_\ell,u_r,h_o)$.
\end{itemize}
\end{itemize}
This concludes the proof of \eqref{e:incodom1}.

We first consider $\mathsf{CH}_{\ell,0}^{\scriptscriptstyle\complement}(q_*^+)$.
By definition of $u_{*a}^{+}$ and \eqref{e:laxRS}\textsubscript{$1$} we have $u_{*0}^+ = (\frac{e}{a}\,q_{*}^{+},0)$ (see \figurename~\ref{f:CH}), because
\begin{equation*}
\{u_{*0}^+\} = \{u\in \mathsf{BL}_{1}^{u_{*a}^+} : q=0\}
\Longrightarrow
a\left(1 - \ln\left(\frac{a\,\rho_{*0}^+}{q_{*}^{+}}\right) \right) \rho_{*0}^+ = 0
\Longrightarrow
\rho_{*0}^+ = \frac{e}{a}\,q_{*}^{+}.
\end{equation*}
Recall that $u_{*a0}^{+}$ is the state with the smallest $\rho$-coordinate in the intersection of $\mathsf{BL}_{1}^{u_{*0}^+}$ and $q=q_{*}^{+}$, see \figurename~\ref{f:CH}, on the left.
By \eqref{e:laxRS}\textsubscript{$2$} we have then
\[
- a \left(\sqrt{\dfrac{\rho_{*a0}^{+}}{\rho_{*0}^+}} - \sqrt{\dfrac{\rho_{*0}^+}{\rho_{*a0}^{+}}}\right) \rho_{*a0}^{+} = q_{*}^{+}
\Longrightarrow
\sqrt{e} = \sqrt{\dfrac{a}{v(u_{*a0}^{+})}}  \left( e - \frac{a}{v(u_{*a0}^{+})} \right),
\]
because $q_{*a0}^{+} = q_{*}^{+}$ and $\rho_{*0}^+ = \frac{e}{a}\,q_{*}^{+}$.
The rightmost formula above, together with the definition of $u_{*a0}^{+}$, implies $v(u_{*a0}^{+})/a \doteq \kappa \approx 1.6294$.
We compute now the area of $\mathsf{CH}_{\ell,0}^{\scriptscriptstyle\complement}(q_*^+)$:
\[
\left| \mathsf{CH}_{\ell,0}^{\scriptscriptstyle\complement}(q_*^+) \right| =
\rho_{*a0}^{+} \, q_*^+ - \int_{0}^{\rho_{*a0}^{+}} \mathcal{BL}_{1}^{u_{*0}^+}(\rho) \,{\rm{d}} \rho =
\rho_{*a0}^{+} \, q_*^+ +  a\int_{0}^{\rho_{*a0}^{+}} \left(\sqrt{\dfrac{\rho \vphantom{\rho_{*0}^+} }{\rho_{*0}^+}} - \sqrt{\dfrac{\rho_{*0}^+}{\rho}}\right) \rho \,{\rm{d}} \rho =
\frac{C_{1}}{a} \, (q_*^+)^2,
\]
where $C_{1} \doteq \frac{1}{\kappa}-\frac{2 \sqrt{e}}{3\kappa^{3/2}}+\frac{2}{5\sqrt{e} \, \kappa^{5/2}} \approx 0.1568$ because $\rho_{*a0}^{+}=\frac{q_*^+}{a \, \kappa}$. Formula \eqref{e:keeel}\textsubscript{$1$} follows at once.

Consider $\mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)$.
First, formula \eqref{e:kkwj}\textsubscript{$1$} is straightforward, see \figurename~\ref{f:CH} on the right.
We now prove \eqref{e:keeel}\textsubscript{$2$}.
As a first step, we compute $\rho_{*a0}^-$.
By definition of $u_{*a0}^-$ and \eqref{e:laxRS}\textsubscript{$2$}, we have that $\rho_{*a0}^-$ is the smallest solution $\rho$ in $[0,\rho_{*0}^+] = [0,e\,q_*^+/a]$ of the equation
\[q_*^- = \mathcal{S}_1^{u_{*0}^+}(\rho) = - a \left(\sqrt{\frac{a\,\rho}{e\,q_*^+}} - \sqrt{\frac{e\,q_*^+}{a\,\rho}}\right) \rho.\]
By introducing $r \doteq \frac{a\,\rho}{e\,q_*^+} \in [0,1]$ and $c \doteq \frac{q_*^-}{e\,q_*^+} \in \left(0,\frac{1}{e}\right)$, the above equation becomes
\[r\left(\sqrt{1/r}-\sqrt{r}\right) = c.\]
Observe that the left-hand side of the above equation is non-negative since $r\in[0,1]$.
By squaring such equation we get
\[r\left(r-1\right)^2=c^2.\]
By studying the map $\mathbb{R} \ni r \mapsto r\left(r-1\right)^2$, we deduce that the above equation admits three solutions in $[0,+\infty)$ because $c^2 \in (0, 4/27)$.
We set $s\doteq r-\frac{2}{3} \in \left[-\frac{2}{3},\frac{1}{3}\right]$ and get the equation
\begin{equation}
\label{e:eqs}
s^3 - \frac{1}{3} \, s + \frac{2}{27} - c^2 = 0.
\end{equation}
We recall that the solutions of the equation $x^3+\alpha\,x+\beta=0$, for $\alpha,\beta\in\mathbb{R}$, are given by Cardano's formula 
\[
x = \sqrt[3]{-\frac{\beta}{2}+\sqrt{\frac{\beta^2}{4} + \frac{\alpha^3}{27}}} + \sqrt[3]{-\frac{\beta}{2}-\sqrt{\frac{\beta^2}{4} + \frac{\alpha^3}{27}}},
\]
where roots are meant in the complex sense. About \eqref{e:eqs}, this yields
\[s = \sqrt[3]{\frac{c^2}{2}-\frac{1}{27} +  {\rm i} \, \frac{c}{2} \sqrt{\frac{4}{27}-c^2}} + \sqrt[3]{\frac{c^2}{2}-\frac{1}{27} -  {\rm i} \, \frac{c}{2} \sqrt{\frac{4}{27}-c^2}}.\]
Observe that the module of the complex numbers under cubic roots above is
\[\sqrt{\left(\frac{c^2}{2}-\frac{1}{27}\right)^2 + \left(\frac{c}{2} \sqrt{\frac{4}{27}-c^2}\right)^2} = \frac{1}{27},
\]
and therefore their arguments are $\pm\theta$, where
\[\theta \doteq \operatorname{arccos}\left(\frac{27}{2} \, c^2 - 1\right).\]
The three real solutions of equation \eqref{e:eqs} are then
\begin{align*}
&s_1 \doteq \frac{2}{3} \cos \left(\frac{\theta}{3}\right),&
&s_2 \doteq \frac{2}{3} \cos \left(\frac{\theta}{3}+\frac{2 \pi }{3}\right),&
&s_3 \doteq \frac{2}{3} \cos \left(\frac{\theta}{3}+\frac{4 \pi }{3}\right).
\end{align*}
By observing that $\theta \in \left(\operatorname{arccos}\left(\frac{27}{2e^2}-1\right),\pi\right)$ one checks that $s_2 < s_3 < s_1$.
The above arguments show that
\begin{align*}
\rho_{*a0}^- &= \frac{e\,q_*^+}{a} \, r_2,&
r_2 &\doteq \frac{2}{3} \left( 1 + \cos \left(\frac{\theta}{3}+\frac{2 \pi }{3}\right) \right).
\end{align*}
We are now in the position to compute the area of $\mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)$:
\begin{align*}
&\left|\mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)\right| = 
\rho_{*a0}^- \, q_*^- - \int_0^{\rho_{*a0}^-} \mathcal{S}_1^{u_{*0}^+}(\rho) \, {\rm{d}} \rho =
\frac{e \, q_*^+ r_2 \left(15 \, q_*^- + 2 e \, q_*^+ (3 r_2-5) \sqrt{r_2}\right)}{15 a} 
\\={}&
\frac{4 e^2}{45 a} \, (q_*^+)^2 \sin\left(\frac{\operatorname{arccos}\left(1-\frac{27 c^2}{2}\right)}{6}\right)^2 \left[\frac{16}{\sqrt{3}} \sin\left(\frac{\operatorname{arccos}\left(1-\frac{27 c^2}{2}\right)}{6}\right)^3 - \frac{20}{\sqrt{3}} \sin \left(\frac{\operatorname{arccos}\left(1-\frac{27 c^2}{2}\right)}{6}\right) + 15 c\right].
\end{align*}
The second equality above can be directly proved or by using a symbolic software. Then we prove \eqref{e:keeel}\textsubscript{$2$} for $C_2\doteq\frac{4 e^2}{45}$ and 
\begin{align}
\label{e:A}
A(z) &\doteq S(z)^2 \left[\frac{16}{\sqrt{3}} \, S(z)^3 - \frac{20}{\sqrt{3}} \, S(z) + \frac{15}{e} \, z \right],&
S(z) &\doteq \sin\left(\frac{\operatorname{arccos}\left(1-\frac{27 z^2}{2e^2}\right)}{6}\right).
\end{align}
The fact that $A$ is strictly increasing, strictly convex and $A(0)=0$ can be proved by tedious calculations or, better, by exploiting a symbolic software.
Again by direct computations, or by using a symbolic software, we deduce
\begin{align*}
\partial_{q_*^-} \left|\mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)\right| &=
\frac{4 e}{3 a} \, q_*^+ \, S\left(\frac{q_*^-}{q_*^+}\right)^2, \quad \partial_{q_*^+} \left|\mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)\right| =

\end{align*}
that imply the monotonicity properties of $\left|\mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)\right|$ because $S(x)$ is proved to be strictly increasing, $S(0)=0$ and $S'(x) \geqslant \frac{\sqrt{3}}{2 e} > \frac{9}{16 \sqrt{3} e}$.
Notice that from \eqref{e:keeel}\textsubscript{$2$} we find again \eqref{e:kkwj}\textsubscript{$2$} because $S(0)=0$.
This concludes the proof.

The total area of the incoherence domain $\mathsf{CH}^{\scriptscriptstyle\complement}$ is 
\[
\mathcal{A}(q_*^-,q_*^+) \doteq \frac{C_1}{a} \, (q_*^+)^2+
\frac{C_2}{a} \, A\left(\frac{q_*^-}{q_*^+}\right)(q_*^+)^2.

The function $A=A(z)$ can be extended to $0$ as a $C^1$ function and $A'(0)=0$. With this remark we have
\[
a \, \nabla\mathcal{A}(q_*^-,q_*^+)= \left(C_2 A'\left(\frac{q_*^-}{q_*^+}\right)q_*^+, 2C_1q_*^+ - C_2A'\left(\frac{q_*^-}{q_*^+}\right)q_*^- + 2C_2A\left(\frac{q_*^-}{q_*^+}\right)q_*^+\right).
\]
The function $\mathcal{A}$ has no critical points in the interior of $[0,q_*] \times [q_*,+\infty)$. Therefore, the problem of minimizing the incoherence domain with respect to $(q_*^-,q_*^+)$ only has solutions lying on the boundary. 
Also the problem of minimizing $[0,q_{*}]\ni q\mapsto\mathcal{A}(q,q_*^+) $, for $q_*^+ \in [q_*,+\infty)$ fixed, only has solutions on the boundary, more precisely at $q=0$. 
At last, also the problem of minimizing $[q_{*},+\infty)\ni q\mapsto\mathcal{A}(q_*^-,q) $ for $q_*^- \in [0,q_*]$ fixed only has solutions on the boundary, more precisely at $q=q_{*}$.
Indeed, it is sufficient to observe that $C_2A'(z)z < 2C_1+2C_2A(z)$ for any $z=q_*^-/q \in (0,1]$.

Consider the same initial states $u_\ell=(0.25,2.5)$ and $u_r = (2,3.5)$ as in Example~\ref{ex:3}, but with $h_o=0$.
Again, as in Example~\ref{ex:CHc2}, the numerical solution does not exhibit chattering at $T$, even if $\bigl(u_\Delta(T,0^-),u_\Delta(T,0^+),h_\Delta(T)\bigr)\neq C_\Delta(u_\ell,u_r,0)$, as shown in \figurename~\ref{fig:no_chattering}. Instead, we have $\bigl(u_\Delta(T,0^-),u_\Delta(T,0^+),h_\Delta(T)\bigr)=C_\Delta(u_\ell,u_r,1)$. Thus, during an initial time interval, the numerical solution approximates the first two components of $\mathcal{RS}_{\rm c}[u_\ell,u_r,h_o]$, and afterwards those of $\mathcal{RS}_{\rm c}[u_\ell,u_r,1]$, with some time delay. Moreover, $u_\ell \in \mathsf{CH}_{\ell,0}^{\scriptscriptstyle\complement}(q_*^+) \setminus \mathsf{CH}_{\ell,1}^{\scriptscriptstyle\complement}(q_*^-,q_*^+)$. 
This example and Example~\ref{ex:3} show that, {\em depending on the choice of $h_o$}, the numerical solution may or may not be able to capture the exact solution, see also Figure~\ref{fig:ex3}.

\label{ex:nohis}
Take $q_*^-=q_*=q_*^+ = 3$, corresponding to a valve without hysteresis. The oscillatory incoming waves force the valve to open and close frequently, producing strong oscillations in the space domain $[0,1]$ downstream of the valve, see Figure~\ref{fig:exnohis}.

\label{ex:hissp}
Take $q_*^-=q_*=3$ and $q_*^+=3.5$. Compared to Example~\ref{ex:nohis}, when the valve is closed then the set of states for which it opens is {\em reduced}; however, if the valve is open, then the states that lead to closure are the {\em same} as in Example~\ref{ex:nohis}. As a result, we observe some switches of the valve between the open and closed configurations, which persist with time, see Figure~\ref{fig:exhissp}. Nevertheless, the oscillatory behavior observed in Example~\ref{ex:nohis} is no longer present.

<!-- ex-10: body_md -->
\label{ex:hisspsm}
Take $q_*^-=2$, $q_*=3$ and $q_*^+=3.5$. Compared to Examples~\ref{ex:nohis} and~\ref{ex:hissp}, both the opening and closing conditions are more restrictive. In particular, after some time $t>0$ the valve eventually opens and then no longer closes. We can still see an oscillatory behavior in $[0,1]$, with a low amplitude, as the trace of $q$ at $x=0^+$ is allowed to take values in the interval $[q_*^-, q_*]$, see Figure~\ref{fig:exhisspsm}.

\label{ex:hissm}
Take $q_*^-=2$ and $q_*^+=q_*=3$. This example is similar to Example~\ref{ex:hisspsm}. The main difference is that the valve opens earlier, since the threshold $q_*^+$ to pass from closed to open is lower. As before, once the valve opens, it remains open for all subsequent times, see Figure~\ref{fig:exhissm}.
