<!-- theorem-1: body_md -->
\label{thm:225}
    $(2,2,r)$-MCA with the flip neighborhood has the all-exp property  for $r \ge 5$.
<!-- end theorem-1 -->
<!-- theorem-2: body_md -->
\label{thm:222-short}
Every strictly improving flip sequence for a $(2,2,2)$-MCA instance on $n$ variables has length $O(n^2)$. 
In particular, $(2,2,2)$-MCA does not have the is-exp property, and hence not the all-exp property.
<!-- end theorem-2 -->
<!-- theorem-3: body_md -->
\label{thm:225-all-exp}
$(2,2,5)$-MCA with the flip neighborhood has the all-exp property.
<!-- end theorem-3 -->
<!-- proof-1: body_md -->
We will prove this result by showing that for every $n\geq1$ there is a $(2,2,5)$-MCA instance $Q_n$ with $2n+1$ variables and nonnegative integer constraint values, and an initial assignment such that every maximal sequence of
strictly improving flips starting from this assignment has length exactly $2^{n+3}-7$.  
Moreover, we will see that at every assignment occurring in this sequence, except the last one, there is a unique strictly improving flip, and that it increases the objective value by exactly one.

The $2n+1$ variables of $Q_n$ are as follows: for $i\in\{1,\ldots,n\}$ we have two variables $a_i,b_i$, and we additionally have a variable $b_0$. 
All variables have the domain $D=\{0,1,2,3,4\}$.

Our instance $Q_n$ contains one unary constraint $K_0$ on the variable $b_0$ and, for every $i \in \{1, \ldots, n\}$, two binary constraints $J_i$ and $K_i$. The constraint $J_i$ contains the two variables $b_{i-1}$ and $a_i$, while the constraint $K_i$ contains the two variables $a_i$ and $b_i$.
Hence, the constraint graph is a path $(b_0, a_1, b_1, \dots, a_n, b_n)$.
Thus, every constraint contains at most two variables, and every variable occurs in at most two constraints, so the resulting instance $Q_n$ is a $(2,2,5)$-MCA instance.

The initial assignment assigns $0$ to all $b_i$-variables and $\@empty{A}$ to all $a_i$-variables; since $\@empty{A}=0$, it is the all-zero assignment.

We write $x\colon u\rightsquigarrow v$ for the flip that changes the value of the variable $x$ from $u$ to $v$. 
Recall that a flip is improving if it strictly increases the objective value; we call the increase its \emph{gain}. Since every variable occurs in at most two constraints, the gain of a flip of a variable depends only on the values of that variable and of its (at most two) neighbors on the path.  Explicitly:
\begin{itemize}
\item the gain of a flip of $a_i$ is determined by $b_{i-1}$ and
      $b_i$, through $J_i$ and $K_i$;
\item the gain of a flip of $b_i$, $1\leq i<n$, is determined by
      $a_i$ and $a_{i+1}$, through $K_i$ and $J_{i+1}$;
\item the gain of a flip of $b_n$ is determined by $a_n$, through
      $K_n$ alone;
\item the gain of a flip of $b_0$ is determined by $a_1$, through
      $K_0$ and $J_1$.
\end{itemize}


By the \emph{state} of level $i\geq1$ we mean the pair of values $(x,y)$ currently assigned to $(a_i,b_i)$; we write ``level $i$ is at $(x,y)$'' or simply ``at $(x,y)$''.  Let 
\begin{equation*}
  \mathcal A=\bigl\{(\@empty{A},0),(\@empty{A},2),(\@empty{A},4),(\@empty{B},2),(\@empty{C},2),(\@empty{C},3),(\@empty{C},4),
                   (\@empty{D},3),(\@empty{D},4),(\@empty{E},1),(\@empty{E},2),(\@empty{E},3)\bigr\}
\end{equation*}
be the set of pairs of values at which the table of $K_i$ has a
nonzero entry; this set is the same for every $i$.  We call the pairs in
 $\mathcal A$ \emph{admissible}.
Every entry $K_i(x,y)$ with $(x,y)\in\mathcal A$ is at least
$9M_i-3$, whereas $K_i(x,y)=0$ for $(x,y)\notin\mathcal A$.  A flip of
$a_i$ or of $b_i$ that changes the state of level $i$ from an
admissible to a non-admissible pair therefore loses at least $9M_i-3$
in $K_i$.

In the following three claims, we analyze those combinations of states and variable values that occur in the improving sequence described afterwards.
Note that we are only concerned with admissable pairs, since as argued above, starting from admissiable pairs, we will not encounter inadmissible pairs in an improving flip sequence.



\begin{claim}[Flips of $a_i$]\label{cl:a}
Let $1\leq i\leq n$.  For each of the following combinations of the
state of level $i$ and the value of $b_{i-1}$, the improving flips of
$a_i$ are as stated, and each flip listed is the only improving flip
of $a_i$ and has gain $1$.

\begin{enumerate}[label=(\alph*),ref=\theclaim(\alph*)]
\item\label{cl:a:idle}
      If level $i$ is at $(\@empty{A},0)$ or at $(\@empty{E},1)$, then for every value
      of $b_{i-1}$ the variable $a_i$ has no improving flip.
\item\label{cl:a:F}
      If level $i$ is at $(\@empty{B},2)$, then $a_i$ has an improving flip if
      and only if $b_{i-1}=1$, namely $a_i\colon \@empty{B}\rightsquigarrow \@empty{C}$.
\item\label{cl:a:H3}
      If level $i$ is at $(\@empty{D},3)$, then $a_i$ has an improving flip if
      and only if $b_{i-1}=0$, namely $a_i\colon \@empty{D}\rightsquigarrow \@empty{E}$.
\item\label{cl:a:H4}
      If level $i$ is at $(\@empty{D},4)$, then $a_i$ has an improving flip if
      and only if $b_{i-1}=0$, namely $a_i\colon \@empty{D}\rightsquigarrow \@empty{A}$.
\item\label{cl:a:zero}
      Let $b_{i-1}=0$.  If level $i$ is at $(\@empty{A},2)$ or at $(\@empty{E},2)$, then
      $a_i$ has the improving flip $a_i\colon \@empty{A}\rightsquigarrow \@empty{B}$ or
      $a_i\colon \@empty{E}\rightsquigarrow \@empty{B}$, respectively.  If level $i$ is at $(\@empty{E},3)$ or
      at $(\@empty{A},4)$, then $a_i$ has no improving flip.
\item\label{cl:a:one}
      Let $b_{i-1}=1$.  If level $i$ is at $(\@empty{C},3)$ or at $(\@empty{C},4)$, then
      $a_i$ has the improving flip $a_i\colon \@empty{C}\rightsquigarrow \@empty{D}$.  If level $i$ is
      at $(\@empty{C},2)$, then $a_i$ has no improving flip.
\end{enumerate}
\end{claim}


\begin{proof}[Proof of Claim~\ref{cl:a}]
A flip of $a_i$ changes only the constraints $J_i$ and $K_i$.  For
fixed values of $b_{i-1}$ and $b_i$ and a value $y\in D$ of $a_i$ let
\begin{equation*}
        \Phi(y) := J_i(b_{i-1},y)+K_i(y,b_i).   
\end{equation*}
Then the flip $a_i\colon x\rightsquigarrow y$ is improving if and only if
$\Phi(y)>\Phi(x)$, and its gain is $\Phi(y)-\Phi(x)$. Since
$H_{i-1}$ is even, all values of $\Phi$ are integers.

From any of the admissible states, a flip to a non-admissible pair loses at least $9M_i-3$ in $K_i$ and
gains at most $2M_i+H_{i-1}$ in $J_i$; since $H_{i-1}<M_i$, it is not
improving.  

It therefore suffices to compare the admissible alternatives.
Using Tables~\ref{tab:Ji} and~\ref{tab:Ki}, we obtain:
\[
\begin{array}{c | c  | c | c}
(a_i,b_i)
    & b_{i-1}
    & \text{improving target for $a_i$}
    & \text{gain}\\
\hline
(\@empty{A},0)  & \text{any} & \text{none} & -\\
(\@empty{E},1)  & \text{any} & \text{none} & -\\
\hline
(\@empty{B},2)   & 1          & \@empty{C}    & 1\\
(\@empty{B},2)   & \neq 1     & \text{none} & -\\
\hline
(\@empty{D},3) & 0          & \@empty{E}   & 1\\
(\@empty{D},3) & \neq 0     & \text{none} & -\\
(\@empty{D},4) & 0          & \@empty{A}   & 1\\
(\@empty{D},4) & \neq 0     & \text{none} & -\\
\hline
(\@empty{A},2)  & 0          & \@empty{B}    & 1\\
(\@empty{E},2)  & 0          & \@empty{B}    & 1\\
(\@empty{E},3)  & 0          & \text{none} & -\\
(\@empty{A},4)  & 0          & \text{none} & -\\
\hline
(\@empty{C},3)   & 1          & \@empty{D}  & 1\\
(\@empty{C},4)   & 1          & \@empty{D}  & 1\\
(\@empty{C},2)   & 1          & \text{none} & -
\end{array}
\]
Here ``none'' means that every admissible alternative has value at most
$\Phi(a_i)$. The first two rows are immediate because
$(\@empty{A},0)$ and $(\@empty{E},1)$ are the only admissible pairs with
second component $0$ and $1$, respectively. The remaining entries follow
by direct comparison of the corresponding entries in
Tables~\ref{tab:Ji} and~\ref{tab:Ki}. This proves all parts of the claim.
\end{proof}

\begin{claim}[Flips of $b_i$]\label{cl:b}
Let $1\leq i\leq n$.  For each of the following combinations of the
state of level $i$ and, if $i<n$, the value of $a_{i+1}$, the
improving flips of $b_i$ are as stated, and each flip listed is the
only improving flip of $b_i$ and has gain $1$.
\begin{enumerate}[label=(\alph*),ref=\theclaim(\alph*)]
\item\label{cl:b:F}
      Let $i=n$ or $a_{i+1}=\@empty{B}$.  If level $i$ is at $(\@empty{A},0)$, $(\@empty{C},2)$,
      or $(\@empty{E},3)$, then $b_i$ has the improving flip $b_i\colon 0\rightsquigarrow 2$,
      $b_i\colon 2\rightsquigarrow 3$, or $b_i\colon 3\rightsquigarrow 1$, respectively.  If level $i$
      is at $(\@empty{A},2)$, $(\@empty{B},2)$, $(\@empty{C},3)$, $(\@empty{D},3)$, or $(\@empty{E},1)$, then $b_i$
      has no improving flip.
\item\label{cl:b:H}
      Let $i<n$ and $a_{i+1}=\@empty{D}$.  If level $i$ is at $(\@empty{E},1)$, $(\@empty{C},2)$,
      or $(\@empty{A},4)$, then $b_i$ has the improving flip $b_i\colon 1\rightsquigarrow 2$,
      $b_i\colon 2\rightsquigarrow 4$, or $b_i\colon 4\rightsquigarrow 0$, respectively.  If level $i$
      is at $(\@empty{E},2)$, $(\@empty{B},2)$, $(\@empty{C},4)$, $(\@empty{D},4)$, or $(\@empty{A},0)$, then $b_i$
      has no improving flip.
\item\label{cl:b:pin}
      Let $i<n$.  If level $i$ is at $(\@empty{A},0)$ and $a_{i+1}\in\{\@empty{A},\@empty{E}\}$,
      or if level $i$ is at $(\@empty{E},1)$ and $a_{i+1}=\@empty{C}$, then $b_i$ has no
      improving flip.
\end{enumerate}
\end{claim}

\begin{proof}[Proof of Claim~\ref{cl:b}]
A flip of $b_i$ changes only the constraint $K_i$ and, if $i<n$, the
constraint $J_{i+1}$.  For fixed values of $a_i$ and, if $i<n$, of
$a_{i+1}$, and a value $y\in D$ of $b_i$ let
\begin{equation*}
        \Psi(y) :=
        \begin{cases}
          K_i(a_i,y)+J_{i+1}(y,a_{i+1}), & i<n,\\
          K_i(a_i,y), & i=n.
        \end{cases}
\end{equation*}
Then the flip $b_i\colon x\rightsquigarrow y$ is improving if and only if
$\Psi(y)>\Psi(x)$, and its gain is $\Psi(y)-\Psi(x)$.  The values of
$J_{i+1}$ are given by Table~\ref{tab:Ji} with $i$ replaced by $i+1$;
its entries involve $M_{i+1}$ and $H_i=2H_{i-1}+14$.

                                                                               
                                                                  
                                                                       
                  
                                                                                          
                                                                                   
                                                                       
                                             
                                                                      
                                                                               
                                                                                  
                                                                        
                                                                       
                                                                                
                                                                                   
                                                                         
                                                                                 
                                                                                        
                                 

Let $i=n$ or $a_{i+1}=\@empty{B}$. Since
$J_{i+1}(y,\@empty{B})=M_{i+1}$ for all $y\in D$, in both cases
$\Psi(y)$ differs from $K_i(a_i,y)$ by a constant. The relevant
comparisons are therefore:
\[
\begin{array}{c|c}
a_i & \text{relevant ordering of values}\\
\hline
\@empty{A}
    & \Psi(2)=\Psi(0)+1>\Psi(y)
      \quad (y\notin\{0,2\})\\
\@empty{B}
    & \Psi(2)>\Psi(y)
      \quad (y\neq2)\\
\@empty{C}
    & \Psi(3)=\Psi(2)+1>\Psi(y)
      \quad (y\notin\{2,3\})\\
\@empty{D}
    & \Psi(3)>\Psi(y)
      \quad (y\neq3)\\
\@empty{E}
    & \Psi(1)=\Psi(3)+1>\Psi(y)
      \quad (y\notin\{1,3\})
\end{array}
\]
Hence, at $(\@empty{A},0)$, $(\@empty{C},2)$, and
$(\@empty{E},3)$ the only improving flips are
$b_i\colon 0\rightsquigarrow 2$, $b_i\colon 2\rightsquigarrow 3$, and
$b_i\colon 3\rightsquigarrow 1$, respectively, and each has gain $1$.
At $(\@empty{A},2)$, $(\@empty{B},2)$, $(\@empty{C},3)$,
$(\@empty{D},3)$, and $(\@empty{E},1)$ there is no improving
flip. This proves Claim~\ref{cl:b:F}.

Let $i<n$ and $a_{i+1}=\@empty{D}$.  By Table~\ref{tab:Ji}, the values
$J_{i+1}(y,\@empty{D})-M_{i+1}$ for $y=0,1,2,3,4$ are
$H_i,\,0,\,\tfrac12H_i,\,0,\,H_i$.

    &0

$K_i$.  If level $i$ is at $(\@empty{E},1)$ and $a_{i+1}=\@empty{C}$, then
$J_{i+1}(1,\@empty{C})=2M_{i+1}$ and $J_{i+1}(y,\@empty{C})=0$ for $y\neq1$.  Hence
every flip of $b_i$ loses $2M_{i+1}$ in $J_{i+1}$, while $K_i(\@empty{E},1)$ is
the largest entry of row $\@empty{E}$.  In both cases no flip of $b_i$ is
improving.  This proves Claim~\ref{cl:b:pin}.
\end{proof}







\begin{claim}[Flips of $b_0$]\label{cl:b0}
Each flip listed below is the only improving flip of $b_0$ and has
gain $1$.
\begin{enumerate}[label=(\alph*),ref=\theclaim(\alph*)]
\item\label{cl:b0:F}
      If $a_1=\@empty{B}$, then at $b_0=0$ the variable $b_0$ has the improving
      flip $b_0\colon 0\rightsquigarrow 1$, and at $b_0=1$ it has no improving flip.
\item\label{cl:b0:H}
      If $a_1=\@empty{D}$, then at $b_0=1$ the variable $b_0$ has the improving
      flip $b_0\colon 1\rightsquigarrow 0$, and at $b_0=0$ it has no improving flip.
\item\label{cl:b0:pin}
      If $a_1\in\{\@empty{A},\@empty{E}\}$ and $b_0=0$, or if $a_1=\@empty{C}$ and $b_0=1$, then
      $b_0$ has no improving flip.
\end{enumerate}
\end{claim}

\begin{proof}[Proof of Claim~\ref{cl:b0}]
A flip of $b_0$ changes only $K_0(b_0)+J_1(b_0,a_1)$.  By
Table~\ref{tab:Ji} with $i=1$, where $H_0=2$, the values of this sum
for $b_0=0,1,2,3,4$ are $M_1+(100,101,0,0,0)$ if $a_1=\@empty{B}$, which
proves Claim~\ref{cl:b0:F}, and $M_1+(102,101,1,0,2)$ if $a_1=\@empty{D}$,
which proves Claim~\ref{cl:b0:H}.  If $a_1\in\{\@empty{A},\@empty{E}\}$, they are
$(102+2M_1,\,101,\,1,\,0,\,2)$, and if $a_1=\@empty{C}$, they are
$(100,\,101+2M_1,\,0,\,0,\,0)$; in both cases the value at the current
value of $b_0$ exceeds every other value by more than $2M_1$.  This
proves Claim~\ref{cl:b0:pin}.
\end{proof}

This shows that $(2,2,5)$-MCA with the flip neighborhood has the all-exp property.

Let $x = (x_1, \ldots, x_n)$ be the $n$ Boolean variables of a $(2,2,2)$-MCA instance and let 
$F$ be the objective function. 
Every function of one or two Boolean variables can be written as a multilinear polynomial of degree at most two. 
Since every constraint involves at most two variables, collecting the terms of all constraints gives
\[
    F(x)=K+\sum_{i=1}^n h_ix_i+\sum_{\{i,j\}\in E}c_{ij}x_ix_j,
\]
where $E$ is the set of pairs with $c_{ij}\neq0$. 

Let $G=(\{1,\dots,n\},E)$. A term $x_ix_j$ can only arise from a constraint containing both $x_i$ and $x_j$. 
Since every variable occurs in at most two constraints, $G$ has maximum degree at most two. 
Hence, writing $m:=|E|$, we have $m\le n$.

For $i\in\{1,\dots,n\}$, let $N(i)$ be its neighbors in $G$ and define $q_i(x):=\sum_{j\in N(i)}c_{ij}x_j$. 
Flipping $x_i$ from its current value to $1-x_i$ changes the objective value by $(1-2x_i)(h_i+q_i(x))$. Thus, to preserve which flips are improving, it is enough to preserve the sign of $h_i+q_i(x)$ for every $i$ and every $x\in\{0,1\}^n$.

We first replace the coefficients $c_{ij}$ by small integers. 
These coefficients are shared by the flips of both endpoints of an edge and therefore have to be replaced consistently. 
Once they have been fixed, the coefficient $h_i$ can be replaced independently for each $i$.

\smallskip
\noindent\textbf{Compressing the quadratic coefficients.}
For an edge $e=ij$, write $c_e:=c_{ij}$. 
Let $0<\alpha_1<\cdots<\alpha_s$ be the distinct values among $\{|c_e|:e\in E\}$. 
For each $e\in E$, let $r_e$ be the index for which $|c_e|=\alpha_{r_e}$, and set $d_e:=2\operatorname{sgn}(c_e)r_e$. 
Thus, the replacement of $c_e$ by $d_e$ preserves the sign of every coefficient, and for any $e,f\in E$ it also preserves whether $|c_e|<|c_f|$, $|c_e|=|c_f|$, or $|c_e|>|c_f|$.
Define $q_i'(x):=\sum_{j\in N(i)}d_{ij} x_j$ (i.e., $q'_i$ is the same as $q_i$ except that we replace every $c_{ij}$ by $d_{ij}$).


\begin{claim}\label{cl:order}
For every $i$ and all $x,x'\in\{0,1\}^n$,
\[
    \operatorname{sgn}\bigl(q_i(x)-q_i(x')\bigr)
    =\operatorname{sgn}\bigl(q_i'(x)-q_i'(x')\bigr).
\]
\end{claim}

\begin{proof}[Proof of \cref{cl:order}]
We have
\[
  q_i(x)-q_i(x')=\sum_{j\in N(i)}c_{ij}(x_j-x'_j)
  \qquad\text{and}\qquad
  q_i'(x)-q_i'(x')=\sum_{j\in N(i)}d_{ij}(x_j-x'_j),
\]
where $x_j-x'_j\in\{-1,0,1\}$ and $|N(i)|\leq2$.  Since $\operatorname{sgn}(d_{ij})=\operatorname{sgn}(c_{ij})$, corresponding terms of the two sums have the same sign.  The sign of a sum of at most two terms is determined by the signs of the terms and, if these are opposite, by the comparison of their absolute values.  If two terms have opposite signs, then $i$ has two neighbors $j$ and $k$ with $x_j\neq x'_j$ and $x_k\neq x'_k$, so these absolute values are $|c_{ij}|$ and $|c_{ik}|$ in the first sum and $|d_{ij}|$ and $|d_{ik}|$ in the second.  Since the replacement preserves the comparison of absolute values, both sums have the same sign.
\end{proof}

           

                                         
                                                                                                                                          

                                                                                                            
                                                       
                                                                                                                
                                                                                                                                                                        
                                                                                                               
                               
                                                                                                                    
                                              
            

\smallskip
\noindent\textbf{Compressing the unary coefficients.}
Fix $i$, and let $S_i:=\{q_i(x):x\in\{0,1\}^n\}$. Since $q_i$ depends only on the at most two variables $x_j$ with $j\in N(i)$, we have $|S_i|\le4$. Define $S_i'$ analogously
for $q_i'$. By Claim~\ref{cl:order}, the correspondence
$q_i(x)\mapsto q_i'(x)$ is well defined and preserves the order of all values;
denote it by $\varphi_i:S_i\to S_i'$.

We choose an integer $h_i'$ so that $h_i'+\varphi_i(s)$ has the same sign as
$h_i+s$ for every $s\in S_i$. There are four cases:
\begin{itemize}
\item if $-h_i\in S_i$, set
      $h_i':=-\varphi_i(-h_i)$;
\item if $-h_i<\min S_i$, set
      $h_i':=1-\min S_i'$;
\item if $-h_i>\max S_i$, set
      $h_i':=-1-\max S_i'$;
\item otherwise, let $a<b$ be consecutive elements of $S_i$ with
      $a<-h_i<b$, and set
      $h_i':=-\varphi_i(a)-1$.
\end{itemize}
Every element of $S_i'$ is even, since every $d_e$ is even. Thus, in the last
case, $\varphi_i(b)\ge\varphi_i(a)+2$, so $-\!h_i'$ lies strictly between
$\varphi_i(a)$ and $\varphi_i(b)$. It follows in all four cases that
\begin{equation}
\label{eq:222_equiv}
    \operatorname{sgn}\bigl(h_i+q_i(x)\bigr)
    =\operatorname{sgn}\bigl(h_i'+q_i'(x)\bigr)
\end{equation}
for every assignment $x$. Moreover,
$|h_i'|\le\max_{s'\in S_i'}|s'|+1
\le\sum_{e\ni i}|d_e|+1$.

\smallskip
\noindent\textbf{Bounding the length of an improving sequence.}
Define
\[
    \widetilde F(x)
      :=\sum_{i=1}^n h_i'x_i
        +\sum_{e=\{i,j\}\in E}d_e x_ix_j .    
\]

Equation~\eqref{eq:222_equiv} implies that for every assignment and every variable, flipping that variable increases $F$ if and only if it increases $\widetilde F$. 
Thus $F$ and $\widetilde F$ have exactly the same strictly improving flips. 
Since $\widetilde F$ is integer-valued, every improving flip increases its value by at least $1$, and
therefore every improving flip sequence has length at most $\max\widetilde F-\min\widetilde F$.

We have $\max\widetilde F-\min\widetilde F
 \le\sum_i|h_i'|+\sum_e|d_e|$.
The preceding bound on $|h_i'|$, summed over all $i$, yields $\sum_i|h_i'|\le2\sum_e|d_e|+n$, since every edge has two endpoints.
Consequently, $\max\widetilde F-\min\widetilde F\le3\sum_e|d_e|+n$.

Finally, we have $\sum_e |d_e| = 2\sum_e r_e \leq 2\left((m-s)s+\sum^s_{i=1}i \right) \leq 2\sum^m_{i=1} i \leq m(m+1)$.
Using $m\le n$, we obtain 
\[
    \max\widetilde F-\min\widetilde F
    \le3m(m+1)+n
    \le3n(n+1)+n
    =3n^2+4n .
\]
This proves the theorem.
