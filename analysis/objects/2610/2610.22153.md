<!-- definition-1: body_md -->
For a parameter $M > 0$, let the update map $\rho_M : \mathds{R}^n \times \mathds{R}^n \rightarrow \mathds{R}^n$ be given by
\begin{equation*}
\rho_M(y,m) = \begin{cases}  m&, \quad \text{ if } \left\| y-m \right\|_{ } < M \\ y&, \quad \text{ if } \left\| y-m \right\|_{ } \geq M.  \end{cases}
\end{equation*}
Then, the event-triggered sampling operator $S_M: C([0,\tau), \mathds{R}^n) \rightarrow L_{\text{loc}}^{\infty}([0,\tau), \mathds{R}^n)$ is defined via $(S_Mu)(0) = u(0),$ and
\begin{equation}
(S_Mu)(t) = \rho_M(u(t), (S_Mu)(t_-)), \quad \forall t \in (0,\tau),
\end{equation}
where $(S_Mu)(t_-) = \lim_{s \uparrow t} (S_Mu)(s)$ denotes the left-hand limit.
<!-- end definition-1 -->
<!-- thm-1: body_md -->
\label{Thm:event}
Consider the closed-loop system~\eqref{eq:System},~\eqref{eq:Controller}. Assume that the initial values satisfy $\varphi(0)\left\| y^0-y_{\text{ref}}(0) + I^0 \right\|_{ } < 1$. Then the closed-loop system has a global solution satisfying
\begin{enumerate}
\item $\varphi(t)\left\| e(t) \right\|_{ } < \varepsilon$ for all times $t \geq 0$ for some $\varepsilon \in (0,1)$ depending on $M$ and $\alpha$,
\item there exists a uniform lower bound $t_{\text{min}}>0$ depending on $M$ and $\alpha$ for the length of the intervals where $S_M u$ is constant, 
\item $u$ remains bounded, and
\item $\Vert I \Vert_{\infty} \leq \max \{ \frac{M}{\alpha}, \left\| I^0 \right\|_{ } \}$. 
\end{enumerate}
<!-- end thm-1 -->
<!-- proof-1: body_md -->
\emph{Step 1:} We show the existence of a maximal solution $(y,I):[0,\omega) \rightarrow \mathds{R}^n \times \mathds{R}^n$.\\
We will inductively show the existence of a solution on the intervals on which $S_Mu$ is constant. Define the non-empty open set
$$\mathcal{D} \!\coloneq \!\left\{  (t,y,I)\! \in \!\mathds{R}_{\geq 0}\! \times\! \mathds{R}^n \!\times \!\mathds{R}^n \mid \varphi(t)\left\| y-y_{\text{ref}}(t) + I \right\|_{ }\! <\! 1 \right\}\!. $$
Define the function 
\begin{align*}
G_v:\ &\mathcal{D} \rightarrow \mathds{R}^n \times \mathds{R}^n, \\
 (t,y,I) &\mapsto \begin{pmatrix} f(y)+v\\  -\alpha I+\frac{-(y-y_{\text{ref}}(t) +I)}{1-\varphi(t)^2\left\| y-y_{\text{ref}}(t) +I \right\|_{ }^2}-v\end{pmatrix},
\end{align*}
for some fixed $v \in \mathds{R}^n$. 
Then, the initial value problem~\eqref{eq:System},~\eqref{eq:Controller} takes the form
\begin{equation} \label{eq:ClosedLoop}
\begin{pmatrix} \dot{y}(t) \\ \dot{I}(t) \end{pmatrix} = G_v(t,y(t),I(t)), \quad \begin{pmatrix} y(s) \\ I(s) \end{pmatrix} = \begin{pmatrix} y^s \\ I^s \end{pmatrix}
\end{equation}
on an interval $[s,\tau)$ such that there are no points of discontinuity of $S_Mu$ in this interval, with $v = S_Mu(s)$. We observe that $G_u$ is locally Lipschitz in $(y,I)$, and locally integrable in $t$. Whenever $(s, y^{s}, I^{s})\in \mathcal{D}$, application of~\cite[\S\,10, Thm.~XX]{Walt98} yields the existence of a maximal solution $(y,I):[s,\tilde\omega) \rightarrow \mathds{R}^n \times \mathds{R}^n$ for some $\tilde\omega \in (s,\infty]$. Moreover, the closure of the graph of the maximal solution is not contained in a compact subset of $\mathcal{D}$.

If $\left\| u(t) - v \right\|_{ } < M$ for all $t \in [s,\tilde\omega)$ where $u$ is defined as in~\eqref{eq:Controller}, then $\frac{\left\| e(t) \right\|_{ }}{1-\varphi(t)^2\left\| e(t) \right\|_{ }^2} \leq \left\| v \right\|_{ } + M$ for all $t \in [s,\tilde\omega)$. This implies that $u(\cdot)$ is uniformly bounded on this interval. Hence, either $\tilde{\omega} = \infty$, or the solution is contained in a compact subset of $\mathcal{D}$, which is a contradiction. This shows that either $\tilde\omega = \infty$, or there exists $t \in [s,\tilde\omega)$ such that $\left\| v - u(t) \right\|_{ } \geq M$.

We inductively define the sequence $(t_k)_{k \in T}$ for some index set $T \subseteq \mathds{N}$ as follows. Set $t_0 = 0$, and observe that $(t_0,y^0,I^0) \in \mathcal{D}$. For each $k \in \mathds{N}_0$, apply the above argument for the existence of a maximal solution on some interval $[t_k,\tilde\omega)$. If $\left\| u(t) - u(t_k) \right\|_{ } < M$ for all $t \in [t_k,\tilde\omega) $, then $\tilde\omega = \infty$ by the previous argument, and the induction terminates with $T = \{ 1, \ldots, k\}$. Otherwise, choose $t_{k+1} \coloneq \inf \{ t\in [t_k,\tilde\omega) \mid \left\| u(t) - u(t_k) \right\|_{ } = M \}$, which is well-defined by the previous argument and the continuity of $u$. Moreover, we observe that $(t_{k+1},y(t_{k+1}),I(t_{k+1})) \in \mathcal{D}$ since $t_{k+1} < \tilde\omega$, closing the induction step. Set $T = \mathds{N}$ if the induction did not terminate at any step $k \in\mathds{N}$.

By construction, the sequence $(t_k)_{k \in T}$ is the sequence of discontinuities of $S_Mu$, and the closed-loop system~\eqref{eq:System},~\eqref{eq:Controller} coincides with~\eqref{eq:ClosedLoop} on the intervals $[t_k,t_{k+1})$ with $v=u(t_k)$. 

Hence, we can inductively conclude that there exists a maximal solution of the closed-loop system~\eqref{eq:System},~\eqref{eq:Controller} on $[0,\omega)$ for $\omega = \lim_{k \rightarrow \infty} t_k$, if $T = \mathds{N}$, and $\omega = \infty$ if $\vert T \vert < \infty$. Note that, at this point, $\omega< \infty$ is not excluded in the case $T=\mathds{N}$.

\emph{Step 2:} We show boundedness of the displacement $I$.\\  
Aiming for a contradiction, assume that there is $\tau_0 \in (0,\omega)$ such that $\left\| I(\tau_0) \right\|_{ } > \max \{ \frac{M}{\alpha}, \left\| I^0 \right\|_{ } \} =: \tilde{M}$. Choose $\tau^{\star} \coloneq \sup \{ t \leq \tau_0 \mid \left\| I(t) \right\|_{ } = \tilde{M} \}, $ which is well-defined by continuity of $I$ and the choice of $\tilde{M}$. 
Since by construction of the operator $S_M$, the estimate
\begin{equation} \label{eq:SamplingCondition}
\left\| u(t) - S_Mu(t) \right\|_{ } \leq M
\end{equation}
holds, we can conclude
\begin{align*}
\frac{1}{2} \frac{d}{dt} \left\| I(t) \right\|_{ }^2 &= \langle I(t), -\alpha I(t)+u(t)-S_Mu(t) \rangle\\
&\leq \left\| I(t) \right\|_{ } (- \alpha \left\| I(t) \right\|_{ } + \left\| u(t) - S_Mu(t) \right\|_{ } )\\
&\leq  \left\| I(t) \right\|_{ } (-M+M) = 0 
\end{align*}
 for all $t \in [\tau^{\star},\tau_0]$. Integration yields
$$ \tilde{M} = \left\| I(\tau^{\star}) \right\|_{ } \geq \left\| I(\tau_0) \right\|_{ } > \tilde{M}, $$
a contradiction. Hence, we can conclude that $\left\| I(t) \right\|_{ } \leq \tilde{M}$ holds for all $t \in [0,\omega)$. 

\emph{Step 3:} We show $\varphi(t) \left\| e(t) \right\|_{ } < \varepsilon$ and boundedness of $u$.
Due to its continuity, $f$ is uniformly bounded on each compact subset of $\mathds{R}^n$. We define $F:\mathds{R}_{\geq 0} \rightarrow \mathds{R}_{\geq 0}, r \mapsto \left \Vert f_{\vert B_{r+\left\Vert \frac{1}{\varphi} \right\Vert_{\infty} + \Vert y_{\text{ref}} \Vert_{\infty}}(0)} \right\Vert_{\infty}$, where $B_r(0) \subseteq \mathds{R}^n$ denotes the ball of radius $r$ centered at the origin. Then by construction, the estimate
\begin{equation} \label{eq:fEstimate}
f(y) \leq F(\tilde{M}), \quad \text{ for all } \left\| y \right\|_{ } \leq \Vert y_{\text{ref}} \Vert_{\infty} + \tilde{M} + \left\Vert \frac{1}{\varphi} \right\Vert_{\infty},
\end{equation}
holds, where $\tilde{M}$ is defined in the previous step. Choose the constant $\varepsilon \in (0,1) $ depending on the system parameters such that $\varphi(0)\left\| y^0-y_{\text{ref}}(0) + I^0 \right\|_{ } < \varepsilon$ and
\begin{equation} \label{eq:eps}
\frac{\varepsilon^2}{1-\varepsilon^2} \geq  \left\Vert \frac{\dot{\varphi}}{\varphi} \right\Vert_{\infty} + \Vert \varphi \Vert_{\infty} \left( \Vert \dot{y}_{\text{ref}} \Vert_{\infty} + F(\tilde{M}) + \alpha\tilde{M} \right) .
\end{equation}

Assume that there exists $s_1 \in [0,\omega)$ such that $\varphi(s_1) \left\| e(s_1) \right\|_{ } > \varepsilon$. Then $s_0 \coloneq \sup \{ s \in [0,s_1] \mid \varphi(s)\left\| e(s) \right\|_{ } = \varepsilon \}$ is well-defined by the continuity of $e$ and $\varphi$, as well as the choice of $\varepsilon$. Then on $[s_0,s_1]$, the estimate
\begin{equation}\label{eq:relError}
\begin{aligned}  
\frac{1}{2} \frac{d}{dt} \varphi(t)^2 \left\| e(t) \right\|_{ }^2 &= \dot{\varphi}(t) \varphi(t) \left\| e(t) \right\|_{ }^2 + \varphi(t)^2 \langle e(t), \dot{e}(t)\rangle \\
&\overset{\eqref{eq:SamplingCondition}, \eqref{eq:fEstimate}}{\leq} \Vert \varphi \Vert_{\infty} \left( \Vert \dot{y}_{\text{ref}} \Vert_{\infty} + F(\tilde{M}) + \alpha\tilde{M} \right) \\
&\quad \quad + \left\Vert \frac{\dot{\varphi}}{\varphi} \right\Vert_{\infty}  - \frac{\varepsilon^2}{1- \varepsilon^2} \leq 0
\end{aligned}
\end{equation}
holds. Integration yields
$$ \varepsilon = \varphi(s_0)\left\| e(s_0) \right\|_{ } \geq \varphi(s_1)\left\| e(s_1) \right\|_{ } >  \varepsilon,$$
a contradiction. We can conclude that $\varphi(s)\left\| e(s) \right\|_{ } \leq \varepsilon$ for all $s \in [0,\omega)$. Moreover, this yields $\left\| u(t) \right\|_{ } \leq \frac{1}{1-\varepsilon^2} \left\Vert \frac{1}{\varphi} \right\Vert_{\infty}$, hence $u$ remains bounded.

\emph{Step 4:} We derive a uniform lower bound on the length of the sampling intervals.\\
We can observe that, using $\left\| I(t) \right\|_{ } \leq \tilde{M}$ on $[0,\omega)$ from Step 2 and $\left\| u(t) \right\|_{ } \leq \frac{1}{1-\varepsilon^2} \left\Vert \frac{1}{\varphi} \right\Vert_{\infty}$ from Step 3, we can obtain the estimate
\begin{equation} \label{eq:Derivative}
\begin{aligned} 
\left\| \frac{d}{dt} u(t) \right\|_{ }\! &\leq \!\left\|  \frac{\dot{e}(t)}{1\!-\!\varphi(t)^2 \left\| e(t) \right\|_{ }^2}  \right\|_{ } \!+ \!\left\| \frac{\frac{d}{dt} (\varphi(t)^2 \left\| e(t) \right\|_{ }^2)}{(1\!-\!\varphi(t)^2\left\| e(t) \right\|_{ }^2)^2} e \right\|_{ } \\
&\overset{\eqref{eq:relError}}{\leq} \frac{1}{1-\varepsilon^2} \left( \Vert \dot{y}_{\text{ref}} \Vert_{\infty} + F(\tilde{M}) + \alpha \tilde{M} + \frac{\Vert \frac{1}{\varphi} \Vert_{\infty}}{1-\varepsilon^2} \right) \\
&\quad +\! \frac{2 \Vert \frac{1}{\varphi} \Vert_{\infty}}{(1-\varepsilon^2)^2} \Bigg(\!\Vert \varphi \Vert_{\infty} \!\left( \Vert \dot{y}_{\text{ref}} \Vert_{\infty} \!+\! F(\tilde{M}) + \alpha \tilde{M} \right) \\
& \quad \quad \quad + \left\Vert \frac{\dot{\varphi}}{\varphi} \right\Vert_{\infty} + \frac{\varepsilon^2}{1- \varepsilon^2}\Bigg) =: c(\tilde{M}). 
\end{aligned}
\end{equation}

This yields
\begin{equation*}
\begin{aligned}
\left\| u(t_{k+1}) - u(t_k) \right\|_{ } &= \left\| \int_{t_k}^{t_{k+1}} \frac{d}{ds} u(s) ds \right\|_{ } \\
&\leq (t_{k+1}-t_k) \left\| \frac{d}{ds} u(s) \right\|_{ } \\
&\leq (t_{k+1}-t_k) c(\tilde{M}), 
\end{aligned}
\end{equation*}
for each $k \in \mathds{N}$, hence 
\begin{equation*}
t_{k+1}-t_k \geq \frac{\left\| u(t_{k+1}) - u(t_k) \right\|_{ }}{c(\tilde{M})} = \frac{\tilde{M}}{c(\tilde{M})}.
\end{equation*}
In particular, this estimate ensures $t_k \rightarrow \infty$ as $k \rightarrow \infty$.

\emph{Step 5:} We show the existence of a global solution.\\
Assume that $\omega < \infty$. Then $T = \mathds{N}$, and by Step~1, $\omega = \lim_{k \rightarrow \infty} t_k = \infty$, due to the uniform lower bound on the interval lengths $t_{k+1} - t_k$ established in Step~4. We can conclude $\omega = \infty$, finishing the proof.

<!-- remark-1: body_md -->
The presence of the correction term $I$ allows the controller to accommodate arbitrarily large initial tracking errors $y^0 - y_{\text{ref}}(0)$, provided that the initial tracking error is known with sufficient accuracy, in order to allow for a suitable $I^0$ that ensures $\left\| e(0) \right\|_{ } \varphi(0) < 1$.
<!-- end remark-1 -->
<!-- remark-2: body_md -->
While the bound prescribed by $\varphi$ holds for $e(t) = y(t) - y_{\text{ref}}(t) + I(t)$, we can use the boundedness of $I$ to conclude that the tracking error satisfies $\Vert y(t) - y_{\text{ref}}(t) \Vert < \varphi(t)^{-1} + \tilde M$. Since $\tilde M>0$ is determined through design parameters $M,\alpha, \left\| I^0 \right\|_{ }$, the right hand side can resemble an arbitrary bound $\psi \in W^{1,\infty}(\mathds{R}_{\geq 0}, \mathds{R}_{\geq 0})$ with $\inf_{t \geq 0} \psi(t) > 0$.
<!-- end remark-2 -->
<!-- remark-3: body_md -->
The choice of $\tilde{M}$ entails a trade-off between the admissable sampling interval lengths and the resulting transient performance bounds. Choosing $\tilde{M} $ such that $\frac{\tilde{M}}{c(\tilde{M})}$ is maximized yields the least restrictive a priori bound on the sampling interval length and hence allows for the coarsest sampling scheme. On the other hand, choosing $\tilde{M}$ small reduces the offset from the prescribed performance bound, since $\Vert I \Vert_{\infty} \leq \tilde{M}$. Thus, when tighter safety margins are desired, $\tilde{M}$ can be decreased, at the expense of a more restrictive bound on the lengths of the sampling intervals.

<!-- lemma-1: body_md -->
\label{Lem:F}
If 
\begin{equation}\label{eq:condF}
  \alpha F\left(\frac{M}{\alpha}\right)^3 \rightarrow 0, \quad \text{ as } \alpha \downarrow 0,
\end{equation}
where $F$ is defined as in Step~3 of the proof of Theorem~\ref{Thm:event}, then for each $h\geq 0$, there exist parameters $\alpha, M > 0$ such that $t_{\min}(\tilde M) \geq h$.
<!-- end lemma-1 -->
<!-- proof-2: body_md -->
We derive a lower bound on $\frac{\tilde{M}}{F(\tilde{M})}$ by fixing an arbitrary $M>0$ and choosing a sufficiently small $\alpha > 0$ satisfying $\left\| I^0 \right\|_{ } \alpha \leq M$, implying $\tilde{M} = \frac{M}{\alpha}$. For a fixed $M > 0$, the dependence of $\varepsilon$ on the choice of $\alpha$ can be quantified via
$$ \frac{1}{1-\varepsilon^2} = b + \Vert \varphi \Vert_{\infty} F\left(\frac{M}{\alpha}\right), $$
by choosing equality in~\eqref{eq:eps} for a suitable choice of initial values, where $b = 1 + \left\Vert \frac{\dot{\varphi}}{\varphi} \right\Vert_{\infty} + \Vert \varphi \Vert_{\infty} (\Vert \dot{y}_{\text{ref}} \Vert_{\infty} + M)$. Hence, the dependence of the coefficient $c(\tilde{M})$ defined in~\eqref{eq:Derivative} can be determined via
\begin{align*}
c\left(\frac{M}{ \alpha}\right) &= c_1 + c_2  F\left(\frac{M}{\alpha}\right) + c_3  F\left(\frac{M}{\alpha}\right)^2 + c_4  F\left(\frac{M}{\alpha}\right)^3,
\end{align*}
for some $c_1,\ldots,c_4\in\mathds{R}$ which do not depend on $\alpha$.
Since $F \geq 0$, we use $\alpha F\left( \frac{M}{\alpha} \right)^k \leq \max \left\{ \alpha, \alpha F\left(\frac{M}{\alpha} \right)^3 \right\} \rightarrow 0$ as $\alpha \downarrow 0$ for $0 \leq k \leq 3$, where the convergence follows from assumption~\eqref{eq:condF}, to conclude $t_{\min}(\tilde M) = \frac{M}{ \alpha c\left(\frac{M}{\alpha}\right) } \overset{\alpha \downarrow 0}{\rightarrow} \infty$.

<!-- corollary-1: body_md -->
Consider the closed-loop system~\eqref{eq:System},~\eqref{eq:Controller} with the time-triggered sampling operator $S_T$ replacing $S_M$ in~\eqref{eq:Controller}. Choose $M,h >0$ and assume that~\eqref{eq:condF} holds, so that we can choose $\alpha>0$ small enough with $t_{\min}(\tilde M) \geq h$ by Lemma~\ref{Lem:F}. Let the sampling sequence $(t_k)$ be such that $t_{k+1} - t_k \le h$ for all $k\in\mathds{N}$. Assume that the initial values satisfy $\Vert y^0 - y_{\text{ref}}(0) + I^0 \Vert < 1$ and $\left\| I^0 \right\|_{ } < \tilde{M}$. Then the closed-loop system has a global solution satisfying $\varphi(t) \left\| e(t) \right\|_{ } < \varepsilon$ for all times $t\geq 0$, for some $\varepsilon \in (0,1)$, with $u$ remaining bounded, and $\Vert I \Vert_{\infty} \leq \tilde{M}$.
<!-- end corollary-1 -->
<!-- proof-3: body_md -->
We verify that the arguments from the proof of Theorem~\ref{Thm:event} carry over inductively to each interval in the time-triggered setting. 

\emph{Step 1:} Existence of a global solution.\\
On each interval $[t_k,t_{k+1}),$ the input signal $u(t) = u(t_k)$ is constant, and the system takes the form~\eqref{eq:ClosedLoop}. The existence of a maximal solution on $[t_k,\tilde{\omega}_k)$ follows exactly as in the proof of Theorem~\ref{Thm:event}. Moreover, $\tilde{\omega}_k - t_k \geq t_{\min}(\tilde M)$, hence $t_{k+1} < \tilde{\omega}_k$. Concatenating the solutions on the respective intervals and using $t_k \to \infty$ as $k\to\infty$, this shows the existence of a solution on $[0,\infty)$.

\emph{Step 2:} Boundedness of $I$.\\
Assume that there is a $t^{\star} \in [0,\omega)$ such that $\left\| I(t^{\star}) \right\|_{ } > \tilde{M}$. Then there exists $t_{\star} \in [0,t^{\star})$ such that $\left\| I(t_{\star}) \right\|_{ } = \tilde{M}$, and $\frac{d}{dt} \Vert I(t)\Vert^2_{\vert t = t_{\star}} > 0$, and $\left\| I(t) \right\|_{ } \leq \tilde{M}$ for all $t \in [0,t_{\star}).$ Fix $k \in \mathds{N}$ such that $t_{\star} \in [t_k,t_{k+1})$. Then on $[0,t_{\star}],$ the estimate $\left\| I(t) \right\|_{ } \leq \tilde{M}$ implies that~\eqref{eq:relError}, and therefore~\eqref{eq:Derivative} hold on $[0,t_{\star}]$. Hence, we can use the assumption $t_{k+1} - t_{k} < t_{\min}(\tilde{M})$ implying $(t_{k+1} - t_{k})c(\tilde{M}) < \tilde{M}$ to obtain the estimate
\begin{align*}
\frac{1}{2} \frac{d}{dt} \Vert I(&t)\Vert^2_{\vert t = t_{\star}} = \langle I(t_{\star}), -\alpha I(t_{\star}) + u(t_{\star}) - S_Tu(t_{\star}) \rangle\\
&\leq \left\| I(t_{\star}) \right\|_{ } (-\alpha \left\| I(t_{\star}) \right\|_{ } + \left\| u(t_{\star}) - S_Tu(t_{\star}) \right\|_{ }) \\
&\leq M (-\tilde{M} + (t_{k+1} - t_k)c(\tilde{M})) \leq 0,
\end{align*}
a contradiction. We can conclude that $\left\| I(t) \right\|_{ } \leq \tilde{M}$, for all $t \in [0,\omega)$.

\emph{Step 3:} The boundedness of $u$ and $\varphi(t) \left\| e(t) \right\|_{ } < \varepsilon$ carry over verbatim.

<!-- remark-4: body_md -->
Lemma~\ref{Lem:F} guarantees that, under a suitable growth condition on $F$, the parameters $\alpha,M>0$ can be chosen to accommodate an arbitrarily large bound $t_{\min}(\tilde M)\ge h$ on the sampling intervals for given $h>0$. If this condition is not satisfied, the largest achievable bound may be limited. In either case, an upper bound on $F$, and hence some knowledge of the system dynamics, is required to select suitable parameters $\alpha,M>0$ for a given $h$, in contrast to the event-triggered controller in Theorem~\ref{Thm:event}, which does not require such knowledge.
