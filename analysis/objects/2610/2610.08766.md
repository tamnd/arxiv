We use standard asymptotic notation. For two sequences $a_n,b_n$, we write $a_n\ll b_n$ if $a_n/b_n\to0$; $a_n\gg b_n$ if $b_n/a_n\to0$; and $a_n\sim b_n$ if $a_n/b_n\to1$. We additionally write $b_n = o(a_n)$ to denote any sequence $b_n\ll a_n$; $\omega(a_n)$ to denote any sequence $b_n\gg a_n$; $b_n=\mathcal{O}(a_n)$ if $\lim\sup_{n\to\infty}|b_n/a_n|<\infty$; $b_n=\Omega(a_n)$ if $\lim\inf_{n\to\infty}|b_n/a_n|>0$; and $b_n=\Theta(a_n)$ if $a_n=\mathcal{O}(b_n)$ and $b_n=\mathcal{O}(a_n)$.

<!-- theorem-1: body_md -->
\label{thm:estimation}
Suppose that the graph is generated according to $G(n,p_n,\alpha,\xi)$, with $1 \ll np_n \ll n^{2\alpha-1} / \log n $, $\alpha\in(1/2,1)$, and $\xi\in(0,1]$. 
Then, there exist estimators $\hat{K}_1$, $\hat{K}_2$, $\hat{\alpha}$, $\hat{p}$ and $\hat{\xi}$, computed from the exploration times $\mathcal{D}_{\mathrm{time}}$ of a single continuous-time FPP process with known rate $\lambda=1$, such that the following statements hold. 

\begin{enumerate}
 \item The dense-phase change-points are localized as                                      
 \[
 \mathbb{P}\left( \left| \hat{K}_1 - K_1 \right| \ \le \  4.1 \log n \right) = 1-o(1)
 \quad \text{ and } \quad 
 \left|\hat{K}_2 - K_2^{\star} \right| \ = \  \mathcal{O}_{\mathbb{P}}\left( n p_n \log n \right).
 \] 
 \item The model parameters are consistently estimated:
 \[
 \frac{|\widehat p-p_n|}{p_n} \ = \  \mathcal{O}_{\mathbb{P}} \left( \frac{1}{\sqrt{ n p_n } } \right),
  \quad 
 |\widehat\xi-\xi| = o_{\mathbb{P}}(1), 
 \quad 
 |\widehat\alpha-\alpha|
 \ = \  \mathcal{O}_{\mathbb{P}} \left( n^{1-\alpha} p_n \right).                                                                    
 \]
\end{enumerate}

<!-- lemma-1: body_md -->
\label{lem:first-entry}
Suppose $\alpha\in(0,1)$ and $np_n\to\infty$. Set $K_1=\infty$ if the exploration never reaches $V_1$. Then
$\varepsilon_n:=\mathbb{P}(K_1=\infty)=o(1)$, and, for every
$k\in\mathbb N$,
\[
 \mathbb{P}(K_1>k)
 \ \le \  \left(1-\frac{n_1}{n}\right)^k+\varepsilon_n.
\]
In particular, for every sequence $f_n\to\infty$, we have 
$\mathbb{P}\bigl(K_1\le f_n n^{1-\alpha}\bigr)=1-o(1).$
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
First, we show that $\varepsilon_n=o(1)$. 
Because $\xi\ge p_n$, we may couple the planted graph with a graph $H\sim G(n,p_n)$ such that every edge of $H$ is also present in the planted graph. 
Fix a vertex $v\in V_1$.
As $np_n\to\infty$, the graph $H$ has a unique giant component of size $n-o(n)$ with high probability. 
By exchangeability, both $v$ and the uniformly chosen source belong to this component with probability $1-o(1)$.  
They are therefore connected in the planted graph with probability $1-o(1)$, which proves $\varepsilon_n=o(1)$.

Next, extend the exploration by restarting from a uniformly
chosen unexplored vertex whenever its cut becomes empty.
Let $\widetilde K_1$ be the first index at which this extended
exploration visits $V_1$.

Before the first visit to $V_1$, no edge internal to $V_1$
can affect the exploration. Hence, the extended
exploration up to this visit has the same law as the
corresponding exploration on a Erd\H{o}s\xspace-R{\'e}nyi\xspace $G(n,p_n)$ graph.
In that graph, exchangeability of vertex labels, together
with the uniform source and restart rules, implies that the
full exploration order is a uniformly random permutation. 
                                                                        
It follows that, for $0\le k\le n-n_1$,
\[
    \mathbb{P}(\widetilde K_1>k)
    =\prod_{i=0}^{k-1}
        \left(1-\frac{n_1}{n-i}\right)
    \le \left(1-\frac{n_1}{n}\right)^k.
\]
For $k>n-n_1$, the left-hand side is zero, so the inequality
remains valid.

On the event $\{K_1<\infty\}$, the original exploration reaches $V_1$ before any restart occurs. Hence
$\widetilde K_1=K_1$ on this event, and therefore
\[
 \mathbb{P}(K_1>k) \ \le \  \mathbb{P}(\widetilde K_1>k)+\mathbb{P}(K_1=\infty),
\]
which proves the claimed bound.

Finally, take $k=\lfloor f_n n^{1-\alpha}\rfloor$.
Because $n_1/n^\alpha\to1$, we have $kn_1/n\to\infty$.
Thus
\[
 \mathbb{P}(K_1>k)
 \ \le \  \exp\left(-\frac{kn_1}{n}\right)+\varepsilon_n
 \ = \  o(1).
\]

<!-- lemma-3: body_md -->
\label{lem:PIT_plugin_stability}
Let $\varepsilon_n:=\left|\frac{\widehat p_n}{p_n}-1\right|$. 
Conditionally on \(\{\varepsilon_n<1\}\), we have 
\[
 \max_{1 \le k \le \lfloor n / 2 \rfloor } \left| \widehat Z_k-Z_k \right| \ \le \  \frac{\sqrt{12}}{e} \, \frac{\varepsilon_n}{1-\varepsilon_n}.
\]
In particular, for every collection of bins \(B_j \subseteq [1, \lfloor n / 2 \rfloor ] \),
\[
 \sup_j \left| \frac1{|B_j|}\sum_{k\in B_j}\widehat Z_k - \frac1{|B_j|}\sum_{k\in B_j}Z_k \right|
 \ \le \  \frac{\sqrt{12}}{e} \, \frac{\varepsilon_n}{1-\varepsilon_n}.
\]
<!-- end lemma-3 -->
<!-- proof-2: body_md -->
Write $r_n:=\frac{\widehat p_n}{p_n}$ and $y_k:=m_k a_k\ge0$. 
Then $\widehat m_k a_k=r_n y_k$, and hence
\[
 |\widehat Z_k-Z_k|
 \ = \  \sqrt{12}\left|e^{-r_n y_k}-e^{-y_k}\right|.
\]
By the mean-value theorem, we have $\left|e^{-r_n y_k}-e^{-y_k}\right| = |r_n-1|\,y_k e^{-s y_k}$ for some $s \in [1, r_n]$.                                           
On the event \(\{|r_n-1|<1\}\), we have \(s\ge 1-\varepsilon_n\). Therefore
\[
 y_k e^{-s y_k}
 \ \le \  \sup_{y\ge0} \, y e^{-(1-\varepsilon_n)y}
 \ = \  \frac{1}{e(1-\varepsilon_n)}.
\]
Thus $|\widehat Z_k-Z_k| \le \frac{\sqrt{12}}{e} \frac{\varepsilon_n}{1-\varepsilon_n}$. Averaging over bins gives the second claim.

\[

 \ \le \  2\exp\left(-\frac{\delta_n^2\mu_k}{3}\right)
 \ \le \  2\exp\left(-\frac{\delta_n^2 d_n k}{6}\right).

Rooting such a tree at $u_1$ assigns a parent to each of the other
$k-1$ vertices, so there are at most $k^{k-1}$ possible trees.
Each tree has $k-1$ edges and is present with probability $p_n^{k-1}$.

\[

 \ \le \  2k^{k-1}p_n^{k-1} \exp\left(-\frac{\delta_n^2 d_n k}{6}\right).

\[

 \ \le \  (ed_n)^{k-1} \left(\frac{k}{k-1}\right)^{k-1}

\textit{(i) Early regime.}

The \(n-n_1\) other vertices occupy \(n_1+1\) exchangeable gaps: before, between, and after the vertices of \(V_1\). Each gap has expected size \((n-n_1)/(n_1+1)\). Because \(\widetilde K_1\) is one plus the first gap’s size, we obtain
$\mathbb{E}[\widetilde K_1] = 1+\frac{n-n_1}{n_1+1} = \frac{n+1}{n_1+1}.$}

\[

 := \bigl\{ \{u,v\}\in E(G[V_1]) \colon u\in S,\ v\in V_1\setminus S \bigr\}.

We decompose the cut $C_k = | \operatorname{Cut}(\mathcal{I}_k) |$ after $k$ explored vertices as 
$C_k \ = \  C_k^{\mathrm{in}}+C_k^{\mathrm{out}},$ 
where $C_k^{\mathrm{in}} := \left| \operatorname{Cut}_{G[V_1]}(I_k\cap V_1) \right|$  is the contribution of cut edges internal to $V_1$, and $C_k^{\mathrm{out}}:=C_k-C_k^{\mathrm{in}}$ contains all remaining cut edges.

\medskip\noindent

The induced graph $G[V_1]$ is distributed as $G(n_1,\xi)$.

If $\xi<1$, then, because $\xi$ is fixed, we have $\xi(1-\xi)n_1\gg\log n_1,$ and the assumptions of Lemma~\ref{lm:dense_cut_conc} hold for sufficiently large $n$.

\begin{align*}

 & \ \le \  (1+\eta)  \sqrt{ 2\xi(1-\xi) |S|(n_1-|S|) \min\{|S|, n_1-|S|\}\log\left( \frac{e n_1}{\min\{|S|, n_1-|S|\}} \right) },

As this bound holds simultaneously for all subsets of $V_1$, we can apply it to the random set $S=\mathcal{I}_k\cap V_1$.

\begin{align}

\end{align}

\textit{(ii) Sparse contribution.}
We condition on $V_1$ and let $X_i$ be the random variable counting the number of edges from $u_i$ to $\mathcal{I}_i^c$ excluding pairs contained in $V_1$. 
Conditioned on the exploration history just before $u_i$ is explored, the edge-indicators from $u_i$ to $\mathcal{I}_i^c$ but excluding pairs contained in $V_1$ are independent $\operatorname{Ber}(p_n)$ variables, and there are at most $n$ of them.

\[

\label{lemma:homogeneous-cut-upper}
Consider the sequence $(C_1,\cdots,C_n)$ of cut-sizes of a continuous FPP process with rate $\lambda=1$ in a $G_{n,{p_n}}$ graph.

Compare the FPP exploration with an auxiliary exploration on $G(n,p)$ that selects each next vertex uniformly from the unexplored vertices, independently of the graph. 
Its explored set $\mathcal J_k$ has size $k$ and is independent of the graph, so its cut size satisfies
\[
 C_k^+:=|\operatorname{Cut}(\mathcal J_k)|
 \sim \operatorname{Bin}(k(n-k),p).
\]
We couple the two explorations by revealing edges only when one of
their endpoints is explored.

After $k$ steps, let $x_1\le\cdots\le x_m$ and $y_1\le\cdots\le y_m$, where $m=n-k$, be the ordered numbers of explored neighbors of the remaining vertices in the FPP and auxiliary explorations, respectively. 
Observe that $C_k =\sum_{i=1}^m x_i$ and $C^+_k =\sum_{i=1}^m y_i.$

It remains to be shown that there exists a coupling such that $x_i\le y_i$ for every $i$.
Initially, couple these sequences to be equal. Suppose inductively
that $x_i\le y_i$ for every $i$ and that $\sum_i x_i>0$.
The FPP exploration selects a rank $R$ with probabilities proportional
to the $x_i$, whereas the auxiliary exploration selects a uniform
rank $U$. Since the $x_i$ are nondecreasing,
\[
    \mathbb{P}(R\le r\mid x_1,\ldots,x_m)
    =\frac{\sum_{i=1}^r x_i}{\sum_{i=1}^m x_i}
    \le \frac{r}{m},
    \qquad 1\le r\le m.
\]
Thus $R$ and $U$ can be coupled so that $R\ge U$.

Deleting $x_R$ and $y_U$ preserves the coordinatewise ordering
of the remaining ordered sequences. Indeed, between the two deleted
ranks, the new comparison is $x_i\le y_{i+1}$; elsewhere the original
comparisons remain valid. The edges from each newly selected vertex
to its remaining unexplored vertices have not yet been revealed.
Their indicators are fresh independent Bernoulli$(p)$ variables.
Couple these indicators coordinatewise in the two explorations.
Adding the same indicators and then reordering preserves the
coordinatewise inequality.

Induction gives $C_k\le C_k^+$ until the FPP exploration stops.
Afterward, $C_k=0\le C_k^+$ by convention. The claimed stochastic
domination follows.

so the contribution of these terms is exponentially small in $\sqrt n$, and this establishes~\eqref{eq:in_proof_binomial_sum_bound}.

\label{lm:algo_correctness}
 The cut size sequence $\left(C_k\right)_{k \in [n]}$ produced by \textsc{SampleCutSizes}$(n,p)$ has the same distribution as the sequence of cut sizes in a $G_{n,{p_n}}$.
<!-- end lemma-16 -->
<!-- proof-25: body_md -->
We prove the claim by coupling the algorithm with the FPP exploration of
\(G(n,p)\), using the deferred-decisions principle.

Let the FPP process start from a fixed vertex \(s\). For an infected set
\(\mathcal I_k\), define the cut-degree of an inactive vertex \(v\in \mathcal{I}_k^c\) by
$d_{\mathcal I_k}(v) = |\{u\in \mathcal I_k:(u,v)\in E\}|.$ 
The corresponding cut-degree histogram is $H_{\mathcal{I}_k}(i) = |\{v\in \mathcal{I}_k^c:d_{\mathcal I_k}(v)=i\}|$ and the cut size is $C_k=\sum_i iH_{\mathcal{I}_k}(i).$

We construct the graph exploration lazily. Initially, only the edges from the
source \(s\) to the other \(n-1\) vertices are revealed. Each such edge is
present independently with probability~\(p\). Therefore
$H_{\{s\}}(1)\sim \operatorname{Bin}(n-1,p),$ $H_{\{s\}}(0)=n-1-H_{\{s\}}(1),$ 
and \(H_{\{s\}}(i)=0\) for \(i\notin\{0,1\}\). This agrees with Line
\ref{ln:scs_init}.

Now suppose the current infected set is \(\mathcal I_k\), and write
$H(i)=H_{\mathcal I_k}(i).$ 
Let $C=\sum_i iH(i)$  be the current cut size. If \(C=0\), the connected component of the source has
been exhausted, and the cut size remains zero thereafter. Thus assume \(C>0\).

Conditionally on the currently revealed graph, the exponential clocks on the
cut edges are independent and have the same rate. By the memorylessness of the
exponential distribution, the next infection edge is therefore uniformly
distributed among the \(C\) cut edges. Hence, the probability that the newly
infected vertex has current cut-degree \(i\) is
\[
\frac{iH(i)}{\sum_j jH(j)}.
\]
This is exactly the sampling rule in Line \ref{ln:scs_sample_u}. After this
vertex is infected, it is removed from the inactive side, which corresponds to
subtracting one from the appropriate histogram bin, as in Line
\ref{ln:scs_rmv_u}.

It remains to update the cut-degrees of the remaining inactive vertices. Let
\(u\) be the newly infected vertex. For any remaining inactive vertex \(w\), the
edge \((u,w)\) was previously an edge between two inactive vertices. Hence it was
not revealed by the previous exploration. Since the underlying graph is
\(G(n,p)\), these edges are still conditionally independent Bernoulli\((p)\)
random variables.

Therefore, among the vertices that currently have cut-degree \(j\), the number
that are adjacent to \(u\) is distributed as $R_j\sim \operatorname{Bin}(H(j),p).$ 
Those \(R_j\) vertices move from bin \(j\) to bin \(j+1\). This is exactly the
promotion step in Lines \ref{ln:scs_sample_promotion}--\ref{ln:scs_calc_Ck}.
The descending order ensures that a vertex promoted from \(j\) to \(j+1\) is
not considered again in the same update.

Thus, the graph exploration and the algorithm can be coupled so that, at
every step, the histogram stored by the algorithm is exactly the cut-degree
histogram of the FPP exploration. Consequently, the cut size $C$ returned by the algorithm
has the same distribution as the cut size in the FPP exploration of \(G(n,p)\).
Therefore, the sequence returned by \textsc{SampleCutSizes} has the same
distribution as the true cut-size sequence.
