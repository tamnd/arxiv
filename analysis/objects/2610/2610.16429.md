<!-- remark-1: body_md -->
The least-squares residual regularizer $R(x) =
\frac{1}{2}\|x - N_\theta(x)\|^2$ fits within
architecture~\eqref{eq:network} as follows. Let $z_L = N_\theta(x)$
denote the output of the denoiser, and define an additional layer
$z_{\mathrm{LSR}} = x - z_L$. Setting $\sigma_{\mathrm{LSR}}(s) =
s^2$ componentwise and $V = \frac{1}{2}\mathbf{1}$ then gives
$R(x) = V^\top \sigma_{\mathrm{LSR}}(z_{\mathrm{LSR}}) =
\frac{1}{2}\|x - N_\theta(x)\|^2$.
<!-- end remark-1 -->
<!-- proposition-1: body_md -->
\label{prop:G_rho}
The penalized lifted regularizer $G_{\boldsymbol{\rho}}$ satisfies the
following properties:
\begin{enumerate}
    \item \textbf{Lower approximation.} $G_{\boldsymbol{\rho}}(x)
    \leq R(x)$ for all $x$ and all $\boldsymbol{\rho} \geq 0$.

    \item \textbf{Monotonicity and concavity.} If
    $\boldsymbol{\rho}_1 \leq \boldsymbol{\rho}_2$ componentwise,
    then $G_{\boldsymbol{\rho}_1}(x) \leq G_{\boldsymbol{\rho}_2}(x)$
    for all $x$. In the scalar-parameter setting
    $\rho_1 = \cdots = \rho_L = \rho$, the map $\rho \mapsto
    G_\rho(x)$ is nondecreasing and concave for every fixed $x$.

    \item \textbf{Finite exactness.} There exists a finite threshold
    $\bar{\boldsymbol{\rho}}$ such that $G_{\boldsymbol{\rho}}(x) =
    R(x)$ for all $x$ whenever $\boldsymbol{\rho} \geq
    \bar{\boldsymbol{\rho}}$. In the scalar-parameter setting, an
    explicit threshold is
    \begin{equation}\label{eq:rho_bar}
        \bar{\rho} = \max_{\ell=1,\ldots,L}
        \Bigl\{
            \|V\|_\infty \, L_\sigma^{L-\ell+1}
            \prod_{j=\ell+1}^{L+1} \|W_j\|_{1\to1}
        \Bigr\},
    \end{equation}
    where $L_\sigma$ is the Lipschitz constant of $\sigma$.

    \item \textbf{Exactness for monotone convex networks.} If
    $\sigma$ is nondecreasing and $W_\ell \geq 0$ componentwise
    for all $\ell$, then $G_{\boldsymbol{\rho}}(x) = R(x)$ for
    all $x$ and all $\boldsymbol{\rho} \geq 0$.
\end{enumerate}
<!-- end proposition-1 -->
<!-- proposition-2: body_md -->
\label{prop:DC_convex_activation_L}
Assume that $\sigma:\mathbb{R}\to\mathbb{R}$ is convex and
applied componentwise, and that $D$ is convex. Then the
optimization problem
\begin{equation}
\label{eq:min_g_G_L}
\min_{x} \; \left\{D(x) + \lambda G_{\boldsymbol{\rho}}(x) \right\}
\end{equation}
is equivalent to the lifted DC problem
\begin{equation}
\label{eq:lifted_DC_problem_L}
\min_{x,\boldsymbol{z}} \;
P_{\lambda,\boldsymbol{\rho}}(x,\boldsymbol{z})
-
Q_{\lambda,\boldsymbol{\rho}}(x,\boldsymbol{z}),
\end{equation}
where
\begin{align}
P_{\lambda,\boldsymbol{\rho}}(x, \boldsymbol{z})
&=
D(x)
+
\lambda V^\top z_L
+
\lambda
\sum_{\ell=1}^{L}
\rho_\ell \mathbf{1}^\top z_\ell
+
\iota_{\mathcal{C}_{\sigma}^{L}},
\label{eq:P_DC_L}
\\
Q_{\lambda,\boldsymbol{\rho}}(x, \boldsymbol{z})
&=
\lambda \sum_{\ell=1}^{L}
\rho_\ell \mathbf{1}^\top
\sigma(\phi_\ell).
\label{eq:Q_DC_L}
\end{align}
Both $P_{\lambda,\boldsymbol{\rho}}$ and
$Q_{\lambda,\boldsymbol{\rho}}$ are convex, and
$\mathcal{C}_{\sigma}^{L}$ is a convex set.
<!-- end proposition-2 -->
<!-- corollary-1: body_md -->
\label{cor:DC_piecewise_affine}
If $\sigma$ is additionally piecewise affine, then
$\mathcal{C}_{\sigma}^{L}$ is polyhedral and each DCA
subproblem reduces to a quadratic program (QP) with linear
constraints.
<!-- end corollary-1 -->
<!-- remark-2: body_md -->
\label{rem:practicaleval}

For a fixed $x$, the piecewise-linear structure of $\sigma$ allows
$G_{\rho}(x)$ to be expressed as the minimum of a collection of linear
programs, one for each possible activation pattern, corresponding to
the different linear pieces of $\sigma$. If $
m=\sum_{\ell=2}^L n_\ell
$ denotes the number of binary variables defining these patterns, this amounts
to solving up to $2^m$ linear programs for each $x$.

In practice, we obtained good approximation results exploiting the activation pattern $\varepsilon_R(x)$ obtained
from the forward pass of the original network. The optimal pattern for $G_\rho(x)$
is typically found within a small Hamming neighborhood of
$\varepsilon_R(x)$. Restricting the search to patterns satisfying
$d_H(\varepsilon,\varepsilon_R(x))\le r$ reduces the number of LPs to
$
\sum_{k=0}^r \binom{m}{k},
$
which is polynomial in $m$ for fixed $r$, instead of exponential. 
This strategy is currently heuristic, as no theoretical guarantee on the
distance between $\varepsilon_R(x)$ and an optimal pattern is available.
<!-- end remark-2 -->

<!-- remark-3: body_md -->
The LSR regularizer $R(x) = \frac{\alpha}{2}\|x -N_\theta(x)\|^2$ does not satisfy the Lipschitz assumption of Proposition~\ref{prop:G_rho}, as the quadratic activation $\sigma(s) = s^2$ is not globally Lipschitz. In particular, the finite exactness result and the explicit threshold $\bar\rho$ in~\eqref{eq:rho_bar} do not necessarily apply. However, as shown above, the quadratic term is handled directly as part of $P_{\lambda,\boldsymbol{\rho}}$ and is never penalized, so the subproblem remains a well-posed QP. H-DC is applied with an manually chosen $\rho$ schedule and is shown empirically to reach the global minimum from all initializations.
<!-- end remark-3 -->
<!-- head-2: body_md -->
As shown in Figure~\ref{fig:circle}, H-DC converges to the global minimum from all 25 initializations, including those near the origin where Adam stagnates. The trajectory plot reveals a qualitative difference between the two methods: H-DC navigates directly toward the ground truth as $\rho$ increases along the homotopy path, while Adam follows the local gradient and terminates at a spurious local minimum. This illustrates the key advantage of the homotopic scheme: by starting from a loose relaxation and progressively tightening, H-DC escapes basins of attraction that trap gradient-based methods.
