<!-- definition-1: body_md -->
A derivation of degree $r\in \mathbb{Z}$ on $\Lambda(M)$ is an $\mathbb{R}$-linear map $D: \Lambda^k(M) \to \Lambda^{k+r}(M)$, which is a local operator and satisfies the graded Leibniz rule:

$D(\omega \wedge \theta) =D\omega \wedge \theta + (-1)^{kr}\omega \wedge D\theta, \forall \omega \in \Lambda^k(M).$
<!-- end definition-1 -->
<!-- definition-2: body_md -->
\label{defnFinsler}
A Finsler function $F:TM \to \mathbb{R}$ is given by a family of norms $F: x\in M \to F_x: T_xM \to \mathbb{R_+}$ that satisfies:
\begin{itemize}
\item[$F_1)$] $F$ is smooth on $T_0M=TM \setminus \{0\}$ and continuous on $TM$;
\item[$F_2)$] $F$ is positively $1$-homogeneous: $F(x,\lambda y)=\lambda F(x,y)$, $\forall \lambda \geq 0$;
\item[$F_3)$] the metric tensor $g_{ij}(x,y)=\dfrac{1}{2}\dfrac{\partial^2 F^2}{\partial y^i \partial y^j}(x,y)$ is non-degenerate (or positive definite).
\end{itemize}
<!-- end definition-2 -->
<!-- definition-3: body_md -->
A vector field $X \in \mathfrak{X}(M)$ is called a \emph{Killing vector field} for a Finsler manifold $(M, F)$ if the flow of its complete lift $X^c$ preserves the Finslerian norm:
\begin{equation*}\label{eq:DefKilling}
F\left(\varphi_t(x), (\varphi_t)_{*,x}(y)\right) = F(x,y), \quad \forall (x,y) \in T_0M, \; \forall t.
\end{equation*}
<!-- end definition-3 -->
<!-- theorem-1: body_md -->
\label{thmKglobal}
Consider $(M,F)$ a Finsler manifold and $X\in \mathfrak{X}(M)$. The following statements are equivalent:
\begin{itemize}
\item[i)] $X$ is a Killing vector field: $X^c(F)=0$;
\item[ii)] $X^c$ is tangent to the sphere bundle $SM$: $X^c\in \mathfrak{X}(SM)$;
\item[iii)] $f_1=X^v(E)$ is a first integral for the geodesic spray $S$: $S(X^v(E))=0$;
\item[iv)] $f_0=X^v(F)$ is a first integral for any projectively related spray $\widetilde{S}$: $\widetilde{S}(X^v(F))=0$;
\item[v)] $X^c$ is a contact vector field: $\mathcal{L}_{X^c}d_\mathcal{T}F=0$;
\item[vi)] $X^c$ preserves the Poincar\'e-Cartan $1$-form $d_\mathcal{T}E$: $\mathcal{L}_{X^c}d_\mathcal{T}E=0$;
\item[vii)] $X^c$ is a Hamiltonian vector field: $\exists f_1\in C^{\infty}(T_0M)$, $i_{X^c}\omega_E=-df_1$; 
\item[viii)] $X^c$ is a symplectic vector field: $\mathcal{L}_{X^c}dd_\mathcal{T}E=0$;
\item[ix)] $X^c$ is a Killing vector field for the Sasaki metric $G$: $\mathcal{L}_{X^c}G=0$;
\item[x)] $X^c$ is a Lie symmetry for the Reeb vector field: $[X^c, S/F]=0$;
\item[xi)] $X^c$ is almost analytic with respect to the homogenized almost complex structure $J_0$: $[X^c, J_0]=0$;
\item[xii)] $X^c$ is a Killing vector field for the homogenized Sasaki metric $G_1$: $\mathcal{L}_{X^c}G_1=0$.
\end{itemize}

\emph{Equivalence of $i)$, $ii)$, $iii)$ and $iv)$ (scalar conditions):}
The first equivalence is immediate: $X$ is a Killing vector field if and only if the flow of its complete lift $Fl_t^{X^c}$ preserves the hyper-surfaces $F=\text{constant}$, meaning that $X^c$ is tangent to $SM$.

Contracting the Euler-Lagrange equations \eqref{lsdje} with the complete lift $X^c$ gives:
\begin{eqnarray*}
X^c(E) = i_{X^c}dE = i_{X^c} \mathcal{L}_Sd_\mathcal{T}E \stackrel{\eqref{ildt}}{=}  \mathcal{L}_Si_{X^c} d_\mathcal{T}E  = S(X^v(E)),  
\end{eqnarray*}
proving $i)\Longleftrightarrow iii)$.

We prove the equivalence $iii) \Longleftrightarrow iv)$. First, we recall that for the geodesic spray $S$, any projectively related spray is given by $\widetilde{S}=S-2P\mathcal{C}$, with $P\in C^{\infty}(T_0M)$ an arbitrary $1$-homogeneous function \cite[Chapter 12]{S2001}. Since $X^v$ is $(-1)$-homogeneous and $F$ is $1$-homogeneous, it follows that $f_0$ is a $0$-homogeneous function, meaning $\mathcal{C}(f_0)=0$. Thus, $\widetilde{S}(f_0)=S(f_0)$. Now, the equivalence comes from  the fact that $f_1=Ff_0$, $S(F)=0$, and therefore $S(f_1)=FS(f_0)$.

\emph{Equivalence with $v)$, $vi)$ and $vii)$ ($1$-form conditions):}
For $i) \Longrightarrow v)$ we invoke the commutation rule \eqref{lxcdt}. Thus, $X^c(F)=0$ implies $0=d_\mathcal{T}\mathcal{L}_{X^c}F=\mathcal{L}_{X^c}d_\mathcal{T}F$.

Conversely, to show $v) \Longrightarrow i)$, we use the commutation rule \eqref{ildt} for the function $F$, and $i_Sd_\mathcal{T}F=dF(\mathcal{T}S)=dF(\mathcal{C})=\mathcal{C}(F)=F$, which yields: 
\begin{eqnarray*}
0=i_S\mathcal{L}_{X^c}d_\mathcal{T}F=\mathcal{L}_{X^c}i_Sd_\mathcal{T}F=X^c(F).
\end{eqnarray*} 
 
Since conditions $i)$ and $iii)$ are equivalent, it suffices to show that either one of these two is equivalent to condition $vi)$. Given $E=F^2/2$, the direct implication follows by expanding the derivative: $\mathcal{L}_{X^c}d_\mathcal{T}E=X^c(F)d_\mathcal{T}F+F\mathcal{L}_{X^c}d_\mathcal{T}F=0$.

Assume now that condition $vi)$ is satisfied. Using again the commutation formula \eqref{ildt} for the energy function $E$, we have:
\begin{eqnarray*}
i_S\mathcal{L}_{X^c}d_\mathcal{T}E=\mathcal{L}_{X^c}i_Sd_\mathcal{T}E=2X^c(E), 
\end{eqnarray*}
since $i_Sd_\mathcal{T}E=dE(\mathcal{T}S)=dE(\mathcal{C})=\mathcal{C}(E)=2E$. Therefore, $\mathcal{L}_{X^c}d_\mathcal{T}E=0$ implies $X^c(E)=0$, which is equivalent to $X^c(F)=0$, recovering $i)$.  

For $vi \Longrightarrow vii)$, Cartan's formula allows us to write condition $vi)$ as follows: 
\begin{eqnarray} \label{ixcddje}
\mathcal{L}_{X^c}d_{\mathcal{T}}E=i_{X^c}dd_\mathcal{T}E+di_{X^c}d_\mathcal{T}E=0.
\end{eqnarray}
This shows that $X^c$ is a Hamiltonian vector field with corresponding $1$-homogeneous Hamiltonian $f_1=i_{X^c}d_\mathcal{T}E=dE(\mathcal{T}X^c)=X^v(E)$. Conversely, if $vii)$ holds for some (necessarily $1$-homogeneous) function $f_1\in C^{\infty}(T_0M)$, contracting it with the Liouville vector field we obtain:
\begin{eqnarray*}
f_1=\mathcal{C}(f_1)=i_{\mathcal{C}}df_1=-i_{\mathcal{C}}i_{X^c}dd_\mathcal{T}E= i_{X^c} i_{\mathcal{C}} dd_\mathcal{T}E = i_{X^c} \mathcal{L}_{\mathcal{C}}d_\mathcal{T}E =  i_{X^c} d_\mathcal{T}E =X^v(E).  
\end{eqnarray*}
For this function $f_1$, condition $vii)$ is equivalent to \eqref{ixcddje}, which is equivalent to the condition $vi)$.
 
\emph{Equivalence with $viii)$ and $ix)$ ($(0,2)$-type conditions):}  
Since the Lie derivative $\mathcal{L}_{X^c}$ commutes with the exterior derivative $d$, $vi) \Longrightarrow viii)$ is trivial. In order to prove the converse, we exploit the $0$-homogeneity of $X^c$, which implies the following commutation rule:
\begin{eqnarray*}
[i_{\mathcal{C}}, \mathcal{L}_{X^c}]=i_{[\mathcal{C}, X^c]}=0.
\end{eqnarray*} 
Contracting $viii)$ with the Liouville vector field $\mathcal{C}$ and using the above commutation rule, we obtain condition $vi)$:
\begin{eqnarray*}
0=i_{\mathcal{C}} \mathcal{L}_{X^c}dd_\mathcal{T}E = \mathcal{L}_{X^c} i_{\mathcal{C}} dd_\mathcal{T}E = \mathcal{L}_{X^c} \mathcal{L}_{\mathcal{C}} d_\mathcal{T}E - \mathcal{L}_{X^c} d i_{\mathcal{C}} d_\mathcal{T}E = \mathcal{L}_{X^c} d_\mathcal{T}E. 
\end{eqnarray*}
Here we used that $d_\mathcal{T}E$ is $1$-homogeneous ($\mathcal{L}_{\mathcal{C}} d_\mathcal{T}E=d_\mathcal{T}E$) and $i_{\mathcal{C}} d_\mathcal{T}E=0$.

We prove now the equivalence of $viii)$ and $ix)$. For one implication, if $X^c$ is a Killing vector field for the Sasaki metric $G$, using $\mathcal{L}_{X^c}\mathcal{T}=[X^c, \mathcal{T}]=0$ and the second formula \eqref{acs}, which gives the $2$-form $\omega_E$ in terms of the Sasaki metric $G$, we obtain $\mathcal{L}_{X^c}\omega_E=0$, which is condition $viii)$. 

For the other implication, we assume that $X^c$ preserves the symplectic form $\omega_E$. In order to prove that $X^c$ is also a Killing vector field for the Sasaki metric $G$, in view of formula \eqref{gomega}, it suffices to show $\mathcal{L}_{X^c}J=[X^c, J]=0$. 

First, we will prove that infinitesimal isometries take geodesics into geodesics, meaning $[X^c, S]=0$. Using the commutation rule of $i_S$ and $\mathcal{L}_{X^c}$ we obtain:
\begin{eqnarray*}
i_S\mathcal{L}_{X^c}\omega_E= \mathcal{L}_{X^c} i_S\omega_E + i_{[S,X^c]}\omega_E = -dX^c(E) + i_{[S,X^c]}\omega_E. \label{sxc}
\end{eqnarray*}
Using the assumption that $X$ is a Killing vector field, then $\mathcal{L}_{X^c}\omega_E=0$, $X^c(E)=0$ and since $\omega_E$ has maximal rank, we obtain that $[S,X^c]=0$.

We prove now that $[X^c, \Gamma]=0$. This follows from $[S, X^c]=0$, $[\mathcal{T}, X^c]=0$ and the Jacobi identity:
\begin{eqnarray*}
[X^c, [S, \mathcal{T}]]+ [\mathcal{T}, [X^c, S]] + [S, [\mathcal{T}, X^c]]=0.
\end{eqnarray*}
Using the definition of the horizontal projector $h=(\operatorname{Id}-[S,\mathcal{T}])/2$ we also have $[X^c, h]=0$ and in view of formula \eqref{acs} we obtain $[X^c, J]=0$. This formula and first formula \eqref{gomega} assures that $\mathcal{L}_{X^c}G=0$, hence $X^c$ is a Killing vector field for the Sasaki metric $G$.

\emph{Equivalence of $x)$ through $xii)$ (homogenized conditions)}: 
For the equivalence $i) \Longleftrightarrow x)$, expanding the Lie bracket yields:
\begin{eqnarray}
[X^c, S/F]=-\dfrac{X^c(F)}{F^2}S+\dfrac{1}{F}[X^c, S]. \label{xcsf}
\end{eqnarray}
The geodesic spray $S$ is a horizontal vector field while, according to formula \eqref{tsxc}, $[X^c, S]$ is a vertical vector field. Therefore, from \eqref{xcsf}, we have that $[X^c, S/F]=0$ if and only if $X^c(F)=0$ and $[X^c, S]=0$. While discussing condition $ix)$ above, we have proved that $X^c(F)=0$ implies $[X^c, S]=0$. This completes the proof that the condition $x)$ characterises Killing vector fields.

For a Killing vector field $X$, its complete lift preserves all the geometric structures that define the homogenized almost complex structure $J_0$ in formula \eqref{acs0}. Therefore, $\mathcal{L}_{X^c}J_0=0$, which is condition $xi)$. Assuming $[X^c, J_0]=0$ and using formula \eqref{acs0} we have that $J_0(S/F)=-\mathcal{C}$. Therefore, using also \eqref{xcsf}, we have
\begin{eqnarray*}
& 0 & =\left[X^c, J_0\right]\left(\frac{S}{F}\right)=[X^c, -\mathcal{C}]-J_0\left[X^c,\frac{S}{F}\right] \\ & = & -J_0\left( -\dfrac{X^c(F)}{F^2}S+\dfrac{1}{F}[X^c, S] \right) = -\dfrac{X^c(F)}{F} \mathcal{C} - J_0\left(\dfrac{1}{F}[X^c, S]\right),
\end{eqnarray*}
which means that $X^c(F)=0$ and $[X^c, S]=0$, hence $X$ is a Killing vector field.

We have seen that a Killing vector field satisfies $vii)$ and $xi)$ and, in view of the first formula in \eqref{g1omega}, it satisfies $xii)$. If condition $xii)$ is satisfied, using second formula \eqref{g1omega} and the fact that $\mathcal{L}_{X^c}\mathcal{T}=0$, it follows that condition $viii)$ holds, which means that $X$ is a Killing vector field.

Consider $(M, F)$ a Finsler manifold and $X \in \mathfrak{X}(M)$. The following local expressions of the Killing equations are equivalent:

\begin{enumerate}
    \setlength{\itemsep}{12pt}
    
    \item[\textnormal{i)}] $X$ is a Killing vector field: 
    \[ X_{i|j}y^{i}y^{j} = 0. \]
    
    \item[\textnormal{ii)}] $X^{c}$ is tangent to the sphere bundle $SM$: 
    \[ g_{ij}y^{i}\nabla X^{j} = 0. \]
    
    \item[\textnormal{iii)}] The $1$-homogeneous function $f_{1} = g_{ij}X^{j}y^{i} = X_{i}y^{i} = X^{i}y_{i}$ is a first integral for the geodesic spray: 
    \[ \nabla(X_{i}y^{i}) = 0. \]
    
    \item[\textnormal{iv)}] The $0$-homogeneous function $f_{0} = \frac{1}{F}X_{i}y^{i} = \frac{1}{F}X^{i}y_{i}$ is a first integral for any projectively related spray $\tilde{S}$: 
    \[ \tilde{\nabla}\left(\frac{X_{i}y^{i}}{F}\right) = 0. \]
    
    \item[\textnormal{v)}] $X^{c}$ is a contact vector field: 
    \[ \nabla(h_{ij}X^{j}) + (y_{j}X^{j})_{|i} = 0. \]
    
    \item[\textnormal{vi)}] $X^{c}$ preserves the Poincar\'e-Cartan $1$-form $d_{\mathcal{T}}E$: 
    \[ (X_{i|j} + X_{j|i})y^{j} = 0. \]
    
    \item[\textnormal{vii)}] $X^{c}$ is a Hamiltonian vector field: 
    \[ X_{i} = \frac{\partial f_{1}}{\partial y^{i}}, \quad \nabla X_{i} = -\frac{\delta f_{1}}{\delta x^{i}}. \]
    
    \item[\textnormal{viii)}] $X^{c}$ is a symplectic vector field: 
    \[ X^{c}(g_{kl}) + g_{il}\frac{\partial X^{i}}{\partial x^{k}} + g_{ki}\frac{\partial X^{i}}{\partial x^{l}} = 0. \]
    
    \item[\textnormal{ix)}] $X^{c}$ is a Killing vector field for the Sasaki metric $G$: 
    \[ X_{i|j} + X_{j|i} + 2\nabla(C_{ijk}X^{k}) = 0. \]
\end{enumerate}

\emph{Equivalence of $i)$, $ii)$, $iii)$ and $iv)$ (scalar Killing equations)}:
For the first four Killing equations we have that $X$ is a Killing vector field if and only if $X^c(F)=0$, which is equivalent to:
\begin{eqnarray*}
\nonumber 0& = & X^c(F^2) \stackrel{\eqref{xc}}{=}\left(X^i\frac{\delta}{\delta x^i}+\nabla X^i \frac{\partial}{\partial y^i} \right) (F^2) \stackrel{\eqref{dhe}}{ = } \nabla X^i \frac{\partial F^2}{\partial y^i} \\ &  \stackrel{\eqref{fgij}}{=} & 2\nabla X^ig_{ij}y^j \stackrel{\eqref{nablag}}{=} 2y^i\nabla X_i \stackrel{\eqref{dnabla}}{=}2y^i\mathcal{D}_SX_i= 2y^i X_{i|j}y^j. \label{k12}
\end{eqnarray*}
We justify now that the second Killing equation is equivalent to the second condition of Theorem \ref{thmKglobal}. Indeed, $X^c\in \mathfrak{X}(SM)$ if and only if $G(X^c, \mathcal{C})=0$, which is equivalent to $0=g_{ij}\nabla X^i y^j=\nabla(X_iy^i)=\nabla(X_iy^i/F)$.

While, the four conditions $i)$, $ii)$, $iii)$ and $iv)$ of Theorem \ref{thmKglobal} have different geometric interpretations, their local expressions (the four scalar Killing equations) are very similar:
\begin{eqnarray*}
y^iX_{i|j}y^j=y^ig_{ij}\nabla X^j=\nabla(X_iy^i)=\nabla\left(\frac{1}{F}X_iy^i\right)=0. \label{kyy}
\end{eqnarray*}
We emphasize here that, in the Finslerian context, the components of the $(0,2)$-type tensor, $X_{i|j}$ are $0$-homogeneous and depend on the fibre coordinates, while in the Riemannian context these components do not depend on the fibre coordinates.

\emph{Equivalence with $v)$, $vi)$ and $vii)$ ($1$-form Killing equations)}: Locally, the equivalent formulation \eqref{dhe} of the Euler-Lagrange equations can be written as follows:
\begin{eqnarray*}
\frac{\delta E}{\delta x^i}=E_{|i}=0 \Longleftrightarrow \frac{\delta F}{\delta x^i}=F_{|i}=0.
\end{eqnarray*}
In these formulae, taking the derivative with respect to the fibre coordinates $y^j$ yields:
\begin{eqnarray*}
0=\frac{\partial}{\partial y^j}\left(\frac{\delta E}{\delta x^i}\right) = \frac{\partial}{\partial y^j}\left(E_{|i}\right)=\left(\frac{\partial E}{\partial y^j}\right)_{|i}, \ 0=\frac{\partial}{\partial y^j}\left(\frac{\delta F}{\delta x^i}\right) = \frac{\partial}{\partial y^j}\left(F_{|i}\right)=\left(\frac{\partial F}{\partial y^j}\right)_{|i}.
\end{eqnarray*} 
To expand the Lie derivative of the contact $1$-form $d_{\mathcal{T}}F$, we use the local expression of the complete lift $X^c$, the expression \eqref{hij} of the angular metric, and the corresponding formula above for the norm $F$. Hence: 
\begin{eqnarray*}
\nonumber \mathcal{L}_{X^c}d_{\mathcal{T}}F & = & \mathcal{L}_{X^c} \left(\frac{\partial F}{\partial y^i}dx^i \right) =X^c\left(\frac{\partial F}{\partial y^i} \right)dx^i+ \frac{\partial F}{\partial y^j} \frac{\partial X^j}{\partial x^i} dx^i \\ & = & \left(\nabla X^j \frac{\partial^2 F}{\partial y^j \partial y^i} + \frac{\partial F}{\partial y^j} X^j_{|i} \right) dx^i = \frac{1}{F} \left(h_{ij} \nabla X^j + y_j X^j_{|i}\right) dx^i, \label{k3}
\end{eqnarray*}
and hence the Killing equations $v)$ are equivalent to the corresponding condition of Theorem \ref{thmKglobal}.

Using very similar computations, if we expand the Lie derivative of the Poincar\'e-Cartan $1$-form $d_{\mathcal{T}}E$, we obtain the equivalence of the Killing equations $vi)$ and the corresponding condition of Theorem \ref{thmKglobal} :
\begin{eqnarray*}
\mathcal{L}_{X^c}d_{\mathcal{T}}E = \left( \nabla X^j \frac{\partial^2 E}{\partial y^j \partial y^i} + \frac{\partial E}{\partial y^j} X^j_{|i} \right) dx^i = \left( g_{ij} \nabla X^j + y_j X^j_{|i}\right) dx^i = \left( X_{j|i} + X_{i|j}\right) y^j dx^i. \label{k4}
\end{eqnarray*}
Alternatively, we can prove the equivalence of Killing equations $v)$ and $vi)$ using formula \eqref{hij} that connects the metric tensor and the angular metric.

We can also prove directly the equivalence of the Killing equations $i)$ and $vi)$. We emphasize that, except for the Riemannian case, the Killing equation $i)$ is not quadratic in the fibre coordinates. If we contract $vi)$ with $y^i$ we get $i)$. For the other implication, we take the derivative of $i)$ with respect to the fibre coordinates. Therefore, we have:
\begin{eqnarray*}
0=\frac{\partial}{\partial y^k}\left(X_{i|j}y^iy^j\right) = \left(X_{k|j}+X_{j|k}\right)y^j + \frac{\partial}{\partial y^k}\left(X_{i|j}\right)y^iy^j = \left(X_{k|j}+X_{j|k}\right)y^j.
\end{eqnarray*}
For the last equality above, we use $C_{ilk}y^i=0$ and $g_{il|k}y^i=-2\nabla C_{ilk}y^i=0$ to obtain: 
\begin{eqnarray}
\frac{\partial}{\partial y^k}\left(X_{i|j}\right)y^i = \frac{\partial}{\partial y^k}\left(g_{il}X^l_{|j}+g_{il|j}X^l\right)y^i = C_{ilk}y^iX^l_{|j}-2\nabla C_{ilk}y^iX^l=0. \label{partialxiji}
\end{eqnarray} 

Using the local expression \eqref{oedelta} of the symplectic $2$-form $\omega_E$, $X^c$ is a Hamiltonian vector field if and only if there exists a $1$-homogeneous function $f_1$ such that:
\begin{eqnarray}
X^c=g^{ij}\frac{\partial f_1}{\partial y^j}\frac{\delta}{\delta x^i} - g^{ij}\frac{\delta f_1}{\delta x^j}\frac{\partial}{\partial y^i}. \label{xch}
\end{eqnarray} 
If we compare \eqref{xch} with the expression of $X^c$ given by last formula \eqref{xc}, we obtain Killing equations $vii)$. 

Of the two sets of Killing equations $vii)$, the first one, $X_i=\frac{\partial f_1}{\partial y^i}$, is equivalent to $f_1=X_iy^i$. The direct implication comes from the contraction with $y^i$ and the $1$-homogeneity of $f_1$. The second implication follows by taking the derivatives with respect to the fibre coordinates. Thus, the second set of Killing equations $vii)$ can be written as follows:
\begin{eqnarray*}
0=\nabla X_i + \frac{\delta f_1}{\delta x^i} = \nabla X_i+(f_1)_{|i}= X_{i|j}y^j+ (X_jy^j)_{|i} = \left( X_{i|j}+X_{j|i}\right)y^j,
\end{eqnarray*} 
which shows the equivalence with the Killing equations $vi)$.


\emph{Equivalence with $viii)$ and $ix)$ ($(0,2)$-type form Killing equations)}: Using the local expression \eqref{oedelta} of the symplectic $2$-form $\omega_E$, we have:
\begin{eqnarray*}
\left(\mathcal{L}_{X^c} g_{ij} \delta y^i \wedge dx^j\right)\left(\frac{\partial}{\partial y^k}, \frac{\delta}{\delta x^l}\right) = X^c(g_{kl})+g_{il}\frac{\partial X^i}{\partial x^k} + g_{ki}\frac{\partial X^i}{\partial x^l},
\end{eqnarray*}
which shows the equivalence of Killing equations $viii)$ and the corresponding condition of Theorem \ref{thmKglobal}.

If we express the Lie derivative $\mathcal{L}_{X^c}G$ in terms of the covariant derivative $\mathcal{D}_{X^c}G$ with respect to the Berwald connection, we have:
\begin{eqnarray*}
\left(\mathcal{L}_{X^c}G\right)\left(\frac{\delta}{\delta x^i}, \frac{\delta}{\delta x^j}\right)& = & \left(\mathcal{D}_{X^c}G \right)\left(\frac{\delta}{\delta x^i}, \frac{\delta}{\delta x^j}\right) + G\left(\mathcal{D}_{\frac{\delta}{\delta x^i}}X^c, \frac{\delta}{\delta x^j} \right) + G\left(\frac{\delta}{\delta x^i}, \mathcal{D}_{\frac{\delta}{\delta x^j}}X^c \right) \\ &\stackrel{\eqref{xc}}{=}& 
X^kg_{ij|k} + 2\nabla X^k C_{ijk} + g_{lj}X^l_{|i} + g_{il}X^l_{|j} \stackrel{\eqref{gijk}}{=} X_{i|j} + X_{j|i} + 2\nabla\left(X^kC_{ijk}\right). 
\end{eqnarray*}
This shows the equivalence of the Killing equation $ix)$ and the condition $ix)$ of Theorem \ref{thmKglobal}.

Similarly, as we proved the equivalence of Killing equations $i)$ and $vi)$, we can prove now the equivalence of Killing equations $vi)$ and $ix)$. One implication is very simple, if we contract $ix)$ with $y^i$ and use $C_{ijk}y^i=0$, we obtain $vi)$. For the other implication, we take the derivative of $vi)$ with respect to the fibre coordinates:
\begin{eqnarray*}
\frac{\partial}{\partial y^k}\left(X_{i|j}y^j+X_{j|i}y^j\right) \stackrel{\eqref{partialxiji}}{=} X_{i|k} + X_{k|i} + \frac{\partial}{\partial y^k}\left(X_{i|j}\right) y^j = X_{i|k} + X_{k|i} + 2\nabla(C_{ilk}X^l).
\end{eqnarray*} 
For the last equality above, we used the following computations:
\begin{eqnarray*}
\frac{\partial}{\partial y^k}\left(X_{i|j}\right) y^j & = & \frac{\partial}{\partial y^k}\left(g_{il}X^l_{|j} + g_{il|j}X^l\right) y^j = 2C_{ilk}X^l_{|j}y^j - g_{il|k}X^l \\ & = & 2C_{ilk}\nabla X^l + 2X^l\nabla C_{ilk} = 2\nabla(C_{ilk}X^l).
\end{eqnarray*}

One can directly prove the equivalence of the Killing equations $viii)$ and $ix)$ by using last formula \eqref{xc}, formula \eqref{gijk}, and rewriting the partial derivatives $\partial X^i/\partial x^j$ in terms of the covariant derivatives $X^i_{|j}$.
