<!-- proposition-1: body_md -->
\label{prop:correspondence}
Assume $\Lambda_{ij}\ge 0$ for all $i,j\in\mathcal{C}$, $\Lambda_{ii}=0$,
$\Gamma_i\ge 0$ for all $i\in\mathcal{C}$, and $\mathcal{K}=\{1,\ldots,S\}$. Then 
\begin{equation}
        \operatorname{proj}_x(\mathcal{F}_1)
    =
    \operatorname{proj}_x\bigl(\mathcal{F}_2(\mathcal{P}^{\mathrm{all}})\bigr).
\end{equation} 
As both formulations have the same objective function (
$
   \max \sum_{i\in\mathcal{C}} w_i x_i
$), 
they have the same optimal objective value.
<!-- end proposition-1 -->
<!-- proof-1: body_md -->
Given any arbitrary feasible solution $(x,y)$ of \Cref{mod:direct}. For each
sub-channel $k\in\mathcal{K}$, we define 
    $p_k=\{i\in\mathcal{C}:y_{ik}=1\}$.
Beam-disjointness in \Cref{mod:direct} implies that $p_k\in\mathcal{P}^{\mathrm{all}}$. Let $z_p$ be
the number of sub-channels whose occupancy pattern is $p$. Then, we have that 
\begin{equation}
    \sum_{p\in\mathcal{P}^{\mathrm{all}}} z_p\le S, 
\end{equation}
and that 
\begin{equation}
        \sum_{p\in\mathcal{P}^{\mathrm{all}}_i} z_p
    =
    \sum_{k\in\mathcal{K}} y_{ik}
    =
    \Psi_i x_i, \quad \forall i \in \mathcal{C}
\end{equation} 
This gives 
\begin{equation}
      \sum_{p\in\mathcal{P}^{\mathrm{all}}_i} q_{ip}z_p
    =
    \sum_{k\in\mathcal{K}}\sum_{j\in\mathcal{C}}
    \Lambda_{ij}y_{ik}y_{jk}
    \le \Gamma_i,   \quad \forall i \in \mathcal{C}
\end{equation} 
Hence $(x,z)$ is feasible for \Cref{mod:pattern}, with the same activation vector
$x$.

Conversely, let $(x,z)$ be feasible for \Cref{mod:pattern} over $\mathcal{P}^{\mathrm{all}}$. Since
$\sum_{p\in\mathcal{P}^{\mathrm{all}}} z_p\le S$, assign $z_p$ distinct sub-channels to each
pattern $p$. This yields a beam-disjoint allocation in which carrier
$i$ occupies
\[
    T_i=\sum_{p\in\mathcal{P}^{\mathrm{all}}_i} z_p\ge \Psi_i x_i
\]
sub-channels. If $x_i=1$, retain any $\Psi_i$ of those sub-channels and
delete the remaining occurrences of carrier $i$. If $x_i=0$, delete all
of its occurrences. Let $y$ denote the resulting allocation. Then
\[
    \sum_{k\in\mathcal{K}} y_{ik}=\Psi_i x_i
    \qquad \forall i\in\mathcal{C}.
\]
Deleting carrier occurrences cannot create a beam conflict. It also
cannot increase interference, because all $\Lambda_{ij}$ are
nonnegative. Therefore, we have that
\begin{equation}
        \sum_{k\in\mathcal{K}}\sum_{j\in\mathcal{C}}
    \Lambda_{ij}y_{ik}y_{jk}
    \le
    \sum_{p\in\mathcal{P}^{\mathrm{all}}_i} q_{ip}z_p
    \le \Gamma_i, 
    \quad \forall i\in\mathcal{C}.
\end{equation} 
Thus the resulting allocation is feasible for \Cref{mod:direct} and has the same
activation vector $x$.
The two feasible sets (of \Cref{mod:direct} and \Cref{mod:pattern} respectively) have the same projection onto the $x$-space. Since both objective functions depend only on $x$ and are identical, the two formulations produce the same optimal objective value.
