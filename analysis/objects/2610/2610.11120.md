\label{lemma_yarotsky_product}
Let $M_0>0$.  
For every $0<\delta<M_0^2$, there exists a scalar ReLU network $R_\delta:\mathbb{R}^2\to\mathbb{R}$ with constant width, and depth $ D_{\rm sq}(\delta)

 c_0+c_1\log\left(\frac{M_0^2}{\delta}\right)$
such that
\begin{align*}
    \sup_{s, t\in[-M_0, M_0]}\left\lvert R_\delta(s, t) - st \right\rvert\le\delta.
\end{align*}
The network may additionally be chosen so that
$R_\delta(s,0)=R_\delta(0,s)=0$
for every $s\in\mathbb R$.
When $s = t$, the network will give us a network which approximates the square.

Let

$C(d,n)\varepsilon^{-d/n}(1+\log(1/\varepsilon))$.

<!-- remark-1: body_md -->
\label{remark_quadrature_example}
A standard example with positive weights is the
Gauss--Legendre rule.
On the reference interval $[-1,1]$, the $n_G$-point
Gauss--Legendre rule has nodes $\xi_1,\ldots,\xi_{n_G}$,
the roots of the Legendre polynomial $P_{n_G}$, and weights
$\widehat\omega_i
=
\frac{2}{(1-\xi_i^2)[P_{n_G}'(\xi_i)]^2},
\quad i=1,\ldots,n_G.$
Hence $\widehat\omega_i>0$.
The rule satisfies
\begin{align*}
\int_{-1}^1 p(\xi)\,d\xi
=
\sum_{i=1}^{n_G}\widehat\omega_i p(\xi_i),
\quad
\forall p\in\mathbb P_{2n_G-1}([-1,1]).
\end{align*}
On a physical interval $[a,b]$, the affine map
$x=(a+b)/2+(b-a)\xi/2$ gives nodes $x_i$ and positive
weights $\omega_i=(b-a)\widehat\omega_i/2$.
Therefore, to integrate all one-dimensional polynomials
of degree at most $3r$ exactly, it is enough to choose
$n_G\ge\left\lceil(3r+1)/2\right\rceil$.
The degree-$3r$ requirement is used in the Fisher--KPP
analysis below, since $v_h^2\phi_i$ has degree at most
$3r$ on each affine simplicial element for $P_r$
finite elements.
\medskip

On affine tensor-product quadrilateral or hexahedral
elements, one takes the tensor product of this
one-dimensional rule.
The tensor-product weights remain positive, and the rule
is exact for polynomials whose degree in each reference
coordinate is at most $2n_G-1$.
With the above choice of $n_G$, this includes polynomials
of degree at most $3r$ in each reference coordinate,
as required for products of three $Q_r$ finite element
functions.
On simplex elements, one may instead choose any positive
elementwise quadrature rule exact on $\mathbb P_{3r}$,
when such a rule is available for the desired degree
and element type.
Positivity and degree-$3r$ exactness are stated explicitly
in Assumption~\ref{assumption_quadrature}.

is independent of $h$.

of this reference rule.

The formula $L_h=I+\Delta t I-\Delta t M^{-1}S$ contains the linear reaction contribution coming from the $+v$ part of $v-v^2$.  If the quadrature is not mass-exact, then the quadrature approximation of the linear reaction vector is $M_Qu$, not $Mu$.  The quadrature-based KPP update would then be
\begin{align*}

\end{align*}
Equivalently, the difference $\Delta t M^{-1}(M_Q-M)u_h^n$ would be an additional quadrature consistency term.  In the rest of this note we do not pursue this case; we assume degree-$3r$ exact quadrature, so $M_Q=M$ and $q_Q=q$.

<!-- definition-1: body_md -->
\label{def_network_predicted_traj}
    Let $\tilde{R}_\delta$ be the scalar square network from Lemma~\ref{lemma_yarotsky_product} with $\delta$ accuracy with domain $[-M_0, M_0]$.
Define the network-implemented coefficient $u_{h, \delta}^n\in\mathbb{R}^{N}$ by
\begin{align*}
     u_{h,\delta}^{n+1}=L_hu_{h,\delta}^n+C_h{R}_\delta(Bu_{h,\delta}^n), \text{ where } R_{\delta} = \tilde{R}_{\delta}\circ \chi_{M_0}.
\end{align*}
Here $\chi_{M_0}$ is the clipping operator implemented by ReLU, $\tilde{R}_{\delta}$ is applied to $\chi_{M_0} (Bu_{h, \delta}^n)$ entry-wise, and  initial finite element encoding ($n = 0$) is the same as as the reference scheme $ u_{h,\delta}^0=u_h^0.$
We then call the associated finite element function  $v_{h,\delta}^n(x):=\sum_{j=1}^N (u_{h,\delta}^n)_j\phi_j(x)$ semi-network approximation.
Define the coefficient error $ e^n:=u_h^n-u_{h,\delta}^n.$

<!-- lemma-4: body_md -->
\label{lem:recursion}
Let $u_{h, \delta}^n$, $e^n$ and network $R_\delta$ be defined as in Definition \ref{def_network_predicted_traj}.
Assume the boundedness Assumption~\ref{assumption_reference_bounded} and let $M_0\ge M_*$.  Then,
\begin{align*}
     \left\lVert e^{n+1} \right\rVert_M
 \le
 \left(\left\lVert L_h \right\rVert_{M\to M}+2M_0\left\lVert C_h \right\rVert_{W\to M}\left\lVert B \right\rVert_{M\to W}\right)\left\lVert e^n \right\rVert_M
 +
 \left\lVert C_h \right\rVert_{W\to M}\sqrt{\operatorname{tr}(W)}\,\delta.
\end{align*}
<!-- end lemma-4 -->
<!-- proof-1: body_md -->
Because $\left\lvert (Bu_h^n)_q \right\rvert\le M_*\le M_0$, clipping does not change the reference solution values $ \chi_{M_0}(Bu_h^n)=Bu_h^n$.  Therefore the reference update \eqref{eq:kpp-one-step-final} can be written as
$u_h^{n+1}=L_hu_h^n+C_h\chi_{M_0}(Bu_h^n)^{\odot2}.$
Subtracting the network approximation to coefficients \eqref{def_network_predicted_traj} from the reference update equation above gives
$e^{n+1}
 =
 L_he^n
 +
 C_h\left(
 \chi_{M_0}(Bu_h^n)^{\odot2}-R_\delta(Bu_{h,\delta}^n)
 \right).$
For the second term of the nonlinear difference, we add and subtract, 
\begin{align*}
\tilde{e}^n &= \chi_{M_0}(Bu_h^n)^{\odot2}-R_\delta(Bu_{h,\delta}^n)\notag\\
 &=
 \left[
 \chi_{M_0}(Bu_h^n)^{\odot2}
 -
 \chi_{M_0}(Bu_{h,\delta}^n)^{\odot2}
 \right]
 +
 \left[
 \chi_{M_0}(Bu_{h,\delta}^n)^{\odot2}
 -
 R_\delta(Bu_{h,\delta}^n)
 \right].
\end{align*}
For the first bracket of the above equation for of $\tilde{e}^n$
and the $q-$th entry, we apply the Lipschitz estimate \eqref{eqn_clipped_square_lipschitztz} of the clipping,
$$
 \left\lvert \chi_{M_0}(Bu_h^n)_q^2-\chi_{M_0}(Bu_{h,\delta}^n)_q^2 \right\rvert
 \le
 2M_0\left\lvert (B e^n)_q \right\rvert,  q = 1,2,.., Q.
 $$
We then consider the entire vector's norm estimate.
This estimate is naturally written in the $W$-norm because this bracket is still a vector of nonlinear values at quadrature points, before the matrix $C_h$ maps it back into coefficient space.  
Squaring each entry, multiplying by $\omega_q$, and summing over $q$ yields
\begin{equation}\label{eqn_clipped_lipschitz_W}
 \left\lVert \chi_{M_0}(Bu_h^n)^{\odot2}-\chi_{M_0}(Bu_{h,\delta}^n)^{\odot2} \right\rVert_W
 \le
 2M_0\left\lVert Be^n \right\rVert_W
 \le
 2M_0\left\lVert B \right\rVert_{M\to W}\left\lVert e^n \right\rVert_M.
\end{equation}
For the second bracket of $\tilde{e}^n$, by Lemma~\ref{lemma_yarotsky_product}, we have
$\left\lvert \chi_{M_0}(Bu_{h,\delta}^n)_q^2- R_\delta((Bu_{h,\delta}^n)_q) \right\rvert\le\delta.$
It follows the estimate for the entire vector in $W-$norm,
\begin{equation}\label{eq:clipped-approx-W}
 \left\lVert \chi_{M_0}(Bu_{h,\delta}^n)^{\odot2}-R_\delta(Bu_{h,\delta}^n) \right\rVert_W
 \le
 \sqrt{\operatorname{tr}(W)}\,\delta.
\end{equation}
                                                                                                                                     
Using \eqref{eqn_clipped_lipschitz_W} and \eqref{eq:clipped-approx-W}, we can now estimate $\tilde{e}^n$,
\begin{align*}
     \left\lVert \tilde{e}^n \right\rVert_W
 \le
 2M_0\left\lVert B \right\rVert_{M\to W}\left\lVert e^n \right\rVert_M+\sqrt{\operatorname{tr}(W)}\,\delta.
\end{align*}
The triangle inequality in the $M$-norm gives the estimate for $e^{n}$,
\begin{align*}
     \left\lVert e^{n+1} \right\rVert_M
 \le
 \left\lVert L_he^n \right\rVert_M+\left\lVert C_h \tilde{e}^n \right\rVert_M\leq  \left\lVert L_h \right\rVert_{M\to M}\left\lVert e^n \right\rVert_M +  \left\lVert C_h \right\rVert_{W\to M}\left\lVert \tilde{e}^n \right\rVert_W. 
\end{align*}
Using the definition of the induced operator norms and Lemma \ref{lemma_numerical_operator_bounds} prove the results.

<!-- proposition-1: body_md -->
\label{prop_accumulative_error}
Assume Assumption \ref{assumption_quadrature} (quadrature) and the exact-quadrature consequences \eqref{eq:kpp-exact-quadrature-consequences}, Assumption \ref{assumption_cfl} (CFL), Assumption~\ref{assumption_reference_bounded} (numerical bounded).
Let the predicted trajectory $u_{h, \delta}^n$, semi-network approximation $v_{h, \delta}^n$, error $e^n$ and network $R_{\delta}$ be defined as in the Definition \ref{def_network_predicted_traj}.
Then there exists a constant $C_T>0$ depending on $T$, independent of $\delta, \Delta t$, such that
\begin{align*}
     \left\lVert v_h^{N_t}-v_{h,\delta}^{N_t} \right\rVert_{L^2(\Omega)} = \left\lVert e^{N_t} \right\rVert_M\le C_T\delta.
\end{align*}
<!-- end proposition-1 -->
<!-- proof-2: body_md -->
By Lemma~\ref{lemma_numerical_operator_bounds} and \eqref{eq:kpp-exact-quadrature-consequences},
$ \left\lVert L_h \right\rVert_{M\to M}\le1+\Delta t,
 \left\lVert C_h \right\rVert_{W\to M}\le\Delta t,
 \left\lVert B \right\rVert_{M\to W}=1,
 \sqrt{\operatorname{tr}(W)}=|\Omega|^{1/2}.$
Therefore Lemma~\ref{lem:recursion} gives constants $c_0,c_1>0$, independent of $h$, $\Delta t$, and $\delta$, such that
\begin{equation}\label{eq:discrete-recursion}
 \left\lVert e^{n+1} \right\rVert_M\le(1+c_0\Delta t)\left\lVert e^n \right\rVert_M+c_1\Delta t\delta.
\end{equation}
Let $E_n:=\left\lVert e^n \right\rVert_M$.  
Since $E_0=0$, repeated use of \eqref{eq:discrete-recursion} gives
\begin{align*}
    E_{N_t}
 \le
 c_1\Delta t\delta\sum_{\ell=0}^{N_t-1}(1+c_0\Delta t)^\ell =  c_1\Delta t\delta \frac{(1+c_0\Delta t)^{N_t}-1}{c_0\Delta t}, \text{ when } c_0>0.
\end{align*}
$N_t\Delta t=T$ and the elementary inequality $1+x\le e^x, x\geq 0$ gives 
$(1+c_0\Delta t)^{N_t}\le (e^{c_0\Delta t})^{N_t}=e^{c_0N_t\Delta t}=e^{c_0T}.$
Thus $ E_{N_t}
 \le
 \frac{c_1}{c_0}\left(e^{c_0T}-1\right)\delta
 =:C_T\delta.$
If $c_0=0$, the same conclusion follows from $E_{N_t}\le C_0T\delta$.  Finally, the mass norm and $L_2$ equivalence gives the result.

<!-- remark-4: body_md -->
For continuous $P_1$ elements on affine simplicial meshes, the finite element basis functions are continuous piecewise affine functions and hence can be represented exactly by ReLU networks.  
The result is established in \cite{he2020relu} and is summarized as the lemma below.
\begin{lemma}
\label{lemma_jinchao_xu}

$Ck_h$, where $C$ is independent of $h$.
\end{lemma}

Thus $Q_1$ bases would require an additional approximation argument unless $d=1$, where $Q_1=P_1$.

<!-- theorem-1: body_md -->
\label{thm_semi_approximation}
Suppose Assumption~\ref{assumption_cfl} (CFL), \ref{assumption_quadrature} (exact quadrature), \ref{assumption_reference_bounded} (numerical bounded) and \ref{assumption_fem_p1} (FEM settings) hold.  
Assume also that the classical fully discrete $P_1$ finite element solution satisfies $ \left\lVert v(T;v_0)-v_h^{N_t}(v_0) \right\rVert_{L^2(\Omega)}
 \le
 C_{\rm num}\bigl(h^m+\Delta t\bigr)$
uniformly for $v_0\in\mathcal{A}$.  
                                                                                
Let $0<\varepsilon<1/2$ be arbitrary, and $0<\delta<M_0^2$ be estimated later.
Then there exist: $h>0$, $\Delta t>0$, $N>0$, and one ReLU finite element coefficient network
$\mathcal{N}_{h,\varepsilon}:\mathbb{R}^N\to\mathbb{R}^N$, 
and basis networks $\{\phi_{h, j}\}_{j = 1}^{N}:\mathbb{R}^d \rightarrow \mathbb{R}$
and the neural operator
\begin{equation}\label{eqn_semi_operator_structure}
 \mathcal{G}_{h,\varepsilon}(v_0)(x)
 :=
 \sum_{j=1}^N [\mathcal{N}_{h,\varepsilon}(\mathcal{E}_h(v_0))]_j\phi_{h, j}(x)
\end{equation}
such that $\textcolor{black}{\left\lVert v(T;v_0)-\mathcal{G}_{h,\varepsilon}(v_0) \right\rVert_{L^2(\Omega)}
 \le
 C\bigl(h^m+\Delta t+\delta\bigr)
 }$, for any admissible initial condition $v_0$.
Here $C$ is independent of $h$, $\Delta t$, $\delta$, and $v_0\in\mathcal{A}$. 
\medskip 

With additional $\Delta t\sim h^2$ from the CFL assumptions, and set $ \eta:=\min\{m,2\}.$
One can choose
$ h\sim\varepsilon^{1/\eta},
 \Delta t\sim h^2,
 \delta\sim\varepsilon$.
 Then $N \sim \varepsilon^{-d/\eta}$, and $N_t \sim h^{-2}$. 
 It follows $\left\lVert v(T;v_0)-\mathcal{G}_{h,\varepsilon}(v_0) \right\rVert_{L^2(\Omega)}
 \lesssim \varepsilon$. 
Coefficient network $\mathcal{N}_{h, \varepsilon}$ depth and width can be chosen to satisfy
\begin{equation}\label{eq:depth-width-final}
 \operatorname{depth}(\mathcal{N}_{h, \varepsilon})
 \lesssim
 \varepsilon^{-2/\eta}(1+ \log(1/\varepsilon)),
 \operatorname{width}(\mathcal{N}_{h, \varepsilon})
 \lesssim
 \varepsilon^{-d/\eta}.
\end{equation}
\textcolor{black}{Each basis network $\phi_{h, j}$ can be chosen to have constant depth with width independent of $h, \varepsilon$.}

<!-- proof-3: body_md -->
We have the numerical error  estimate $\left\lVert v(T;v_0)-v_h^{N_t}(v_0) \right\rVert_{L^2}$, it follows to construct neural networks to approximate  $v_{h}^{N_t}(v_0)$ uniformly holds for all $v_0$.
This can be done by using networks to approximate the coefficients $u_{h}^{N_t}$ and construct basis $\phi_j$ separately.
\medskip

We first construct the coefficient network $\mathcal{N}_{h,\varepsilon}$.  
$\mathcal{N}_{h,\varepsilon}$ has an iterative structure while the each layer can be constructed by using the Definition \ref{def_network_predicted_traj}.
Specifically, given each time-step block's input $u\in\mathbb{R}^{N}$,
we have the block output as $u\longmapsto L_hu+C_hR_\delta(Bu).$
$L_h, C_h$ and $B$ are derived depending on the numerical scheme and can be exactly representable by affine layers in a ReLU network. 
The only approximation inside the coefficient network is the scalar clipped-square approximation $R_{\delta}$.  
Stacking this block $N_t$ times gives a ReLU coefficient network $\mathcal{N}_{h,\varepsilon}:\mathbb{R}^N\to\mathbb{R}^N$ whose output is the coefficient vector $u_{h,\delta}^{N_t}$.

Now for the basis $\phi_j$.
By Lemma \ref{lemma_jinchao_xu},  $P_1$ basis functions $\phi_j$ can be exactly represented by ReLU networks denoted as $\phi_{h, j}$.
Hence there is no approximation error of the network realization of the basis.
The neural operator in \eqref{eqn_semi_operator_structure} is exactly the finite element reconstruction of the network-generated coefficient vector $ \mathcal{G}_{h,\varepsilon}(v_0)(x)
 =
 \sum_{j=1}^N (u_{h,\delta}^{N_t})_j\phi_j(x)
 =
 v_{h,\delta}^{N_t}(x;v_0).$
 \medskip
 
The error estimate follows from the triangle inequality:
\begin{align*}
     \left\lVert v(T;v_0)-v_{h,\delta}^{N_t}(v_0) \right\rVert_{L^2}
 \le
 \left\lVert v(T;v_0)-v_h^{N_t}(v_0) \right\rVert_{L^2}
 +
 \left\lVert v_h^{N_t}(v_0)-v_{h,\delta}^{N_t}(v_0) \right\rVert_{L^2}.
\end{align*}
The first term is bounded by the classical finite element estimate $ \left\lVert v(T;v_0)-v_h^{N_t}(v_0) \right\rVert_{L^2}
 \le
 C_{\rm num}(h^m+\Delta t).$
The second term is bounded by Proposition~\ref{prop_accumulative_error}, specifically, we have  $ \left\lVert v_h^{N_t}(v_0)-v_{h,\delta}^{N_t}(v_0) \right\rVert_{L^2}
 \le
 C_T\delta$.
Combining these two bounds gives the estimate.
Now for any $\varepsilon>0$, by the  CFL assumption $\Delta t\sim h^2$, set $\eta = \min\{m,2\}$, $\delta \sim \varepsilon$ and choose 
$h\sim \varepsilon^{1/\eta}$, 
gives $\sup_{v_0\in\mathcal{A}}
 \left\lVert v(T;v_0)-\mathcal{G}_{h, \varepsilon}(v_0) \right\rVert_{L^2(\Omega)}
 \le
 C\varepsilon.$
 \medskip 
 
Now let us estimate the depth and width of the coefficient network.
Since the structure is iterative, we consider one layer.
Let us first consider $R_{\delta} = \tilde{R}_{\delta}\circ \chi_{M_0}$. 
By Lemma~\ref{lemma_yarotsky_product}, the $\tilde{R}_{\delta}$ has depth
$D_{\rm sq}(\delta)\le c_0+c_1\log(M_0^2/\delta)$ and constant width.
The clipping network is implemented by ReLU and has constant depth and width, and the affine maps $L_h\in\mathbb{R}^{N\times N}$, $C_h\in\mathbb{R}^{N\times Q}$ and $B\in \mathbb{R}^{Q\times N}$ in each time-step block add only a constant number of layers.  
Therefore one time-step block has depth dominated by $\tilde{R}_{\delta}$, i.e. $D_{\rm block}(\delta)\le \widetilde c_0+\widetilde c_1\log(M_0^2/\delta)$
with $\tilde{c}_0, \tilde{c}_1$ are constants.
\medskip

Since $N_t=T/\Delta t\sim h^{-2}$, the coefficient network has depth $ \operatorname{depth}(\mathcal{N}_{h,\varepsilon})
 \lesssim
 h^{-2}(1+\log(M_0^2/\delta)).$
With $h\sim\varepsilon^{1/\eta}$ and $\delta\sim\varepsilon$, this gives
\begin{align*}
     \operatorname{depth}(\mathcal{N}_{h, \varepsilon})
 \lesssim
 \varepsilon^{-2/\eta}(1 + \log(1/\varepsilon)).
\end{align*}

For width, each block stores vectors of size comparable to $N$ and $Q$, and applies $Q$ scalar square subnets in parallel.  
Since the scalar square subnet has bounded width up to $N, Q \sim h^{-d}$ ($Q \sim N\times n_q$, where $n_q$ is the number of quadrature points which depends on fixed constants $r$ and $d$), we have
$ \operatorname{width}(\mathcal{N}_{h,\varepsilon})\lesssim N+Q\lesssim h^{-d}.$
Using $h\sim\varepsilon^{1/\eta}$ gives
\begin{align*}
     \operatorname{width}(\mathcal{N}_{h, \varepsilon})\lesssim\varepsilon^{-d/\eta}.
\end{align*}
This proves \eqref{eq:depth-width-final}.
For the basis network $\phi_{h, j}$, by Lemma \ref{lemma_jinchao_xu}, depth $\sim \log_2 k_h$ and width $\sim k_h$. 
Due to the uniform shape regular mesh assumption of $\mathcal{T}_h$, $k_h$ is of an order constant, which completes the proof.

For $C_h = -\Delta t M^{-1}B^TW\in \mathbb{R}^{N\times Q}$, let $z\in\mathbb{R}^Q$ be arbitrary, and set $ x:=M^{-1}B^TWz.$
We estimate $\left\lVert x \right\rVert_M$.  The dual representation of the norm induced by the inner product $\langle a,b\rangle_M=a^TMb$ is
\begin{equation}\label{eq:M-duality}
 \left\lVert x \right\rVert_M
 =
 \sup_{y\ne0}\frac{\left\lvert \langle x,y\rangle_M \right\rvert}{\left\lVert y \right\rVert_M}.
\end{equation}
Since $Mx=B^TWz$ and the $M$ adjointness of the inner product $\langle \cdot, \cdot\rangle$ (See Appendix \ref{section_cfl_appendix}) for the details,
\begin{align*}
     \langle x,y\rangle_M
 =
 x^TMy
 =
 y^TMx
 =
 y^TB^TWz
 =
 (By)^TWz.
\end{align*}
By the Cauchy--Schwarz inequality in the $W$-inner product and by $\left\lVert B \right\rVert_{M\to W}=1$,
\begin{align*}
     \left\lvert (By)^TWz \right\rvert
 \le
 \left\lVert By \right\rVert_W\left\lVert z \right\rVert_W
 \le
 \left\lVert y \right\rVert_M\left\lVert z \right\rVert_W.
\end{align*}
Inserting this into \eqref{eq:M-duality} gives
\begin{align*}
     \left\lVert M^{-1}B^TWz \right\rVert_M\le \left\lVert z \right\rVert_W.
\end{align*}
Multiplying by $\Delta t$ proves $\left\lVert C_h \right\rVert_{W\to M}\le \Delta t$.
Next, we prove $\sqrt{\operatorname{tr}(W)}=|\Omega|^{1/2}$.
Since $W=\operatorname{diag}(\omega_1,\dots,\omega_Q)$, $\operatorname{tr}(W)=\sum_{q=1}^Q\omega_q$.
If the quadrature is exact for constants, then $\sum_q\omega_q=\int_\Omega1\,dx=|\Omega|$.  
In the degree-$3r$ exact setting of Section~\ref{subsec_kpp-quad}, exactness for constants is automatic because constants are polynomials of degree zero.

\medskip
It remains to prove $L_h$ operator norm.  
Because $M$ is symmetric positive definite and $S$ is symmetric, the generalized eigenproblem
\begin{align*}
     S\psi_j=\lambda_jM\psi_j,
 \qquad j=1,\ldots,N,
\end{align*}
has $N$ generalized eigenvectors that may be chosen $M$-orthonormal and therefore forms an $M$-orthonormal basis of $\mathbb{R}^N$. 
Therefore every $e\in\mathbb{R}^N$ has a unique expansion $e=\sum_{j=1}^N c_j\psi_j$.
By the definition of $L_h$, we have
\begin{align*}
     L_h\psi_j
 =
 \left(I+\Delta t I-\Delta t M^{-1}S\right)\psi_j
 =
 (1+\Delta t-\Delta t\lambda_j)\psi_j
 =
 \mu_j\psi_j.
\end{align*}
Under $\Delta t\lambda_{\max}\le2$ CFL condition, we have $\Delta t\lambda_j\in[0,2]$, hence
\begin{align*}
     \left\lvert \mu_j \right\rvert=\left\lvert 1+\Delta t-\Delta t\lambda_j \right\rvert\le1+\Delta t.
\end{align*}
Using the expansion above,
\begin{align*}
     L_he=\sum_{j=1}^N c_jL_h\psi_j
      =\sum_{j=1}^N c_j\mu_j\psi_j.
\end{align*}
By $M$-orthonormality of $\psi_j$, all cross terms vanish:
\begin{align*}
     \left\lVert e \right\rVert_M^2
 =\left(\sum_i c_i\psi_i\right)^TM\left(\sum_j c_j\psi_j\right)
 =\sum_{i,j}c_ic_j\psi_i^TM\psi_j
 =\sum_{j=1}^N\left\lvert c_j \right\rvert^2,
\end{align*}
and similarly
\begin{align*}
     \left\lVert L_he \right\rVert_M^2
 =\left(\sum_i c_i\mu_i\psi_i\right)^TM
  \left(\sum_j c_j\mu_j\psi_j\right)
 =\sum_{j=1}^N\left\lvert \mu_j \right\rvert^2\left\lvert c_j \right\rvert^2.
\end{align*}
Thus
\begin{align*}
     \left\lVert L_he \right\rVert_M
 \le
 \max_{1\le j\le N}\left\lvert \mu_j \right\rvert\,\left\lVert e \right\rVert_M
 \le
 (1+\Delta t)\left\lVert e \right\rVert_M.
\end{align*}
Taking the supremum over $e\ne0$ gives $\left\lVert L_h \right\rVert_{M\to M}\le1+\Delta t$.

Fix a basis index $j$ and $0<\gamma<1$. Throughout the proof, constants may depend on the fixed degree $r$, dimension $d$, reference nodal basis, and the shape-regularity and quasi-uniformity constants, but are independent of $h$, $j$, and $\gamma$.

Extend $\phi_j$ by zero outside $\Omega$, and denote its extension by $\bar\phi_j$. Since $\phi_j$ is continuous and has zero boundary trace, its zero extension is continuous and belongs to $W^{1,\infty}(\mathbb R^d)$. Standard scaling estimates for fixed-degree nodal Lagrange basis functions give
$\|\bar\phi_j\|_{L^\infty(\mathbb R^d)}
+h\|\nabla\bar\phi_j\|_{L^\infty(\mathbb R^d)}\le C_0$.
Moreover, the support of $\bar\phi_j$ has diameter at most $Ch$. We may therefore choose a closed box
$D_{j,h}=\prod_{i=1}^d[a_{j,i},a_{j,i}+\ell_{j,i}]$
such that
$\operatorname{supp}\bar\phi_j\subset\operatorname{int}D_{j,h}$
and $ch\le\ell_{j,i}\le Ch$ for every $i$. The box need not lie inside $\Omega$.

Define the affine bijection
$F_{j,h}:\mathbb R^d\to\mathbb R^d$
by
$(F_{j,h}(y))_i=a_{j,i}+\ell_{j,i}y_i$.
Then $F_{j,h}([0,1]^d)=D_{j,h}$, and its inverse is defined for every $x\in\mathbb R^d$ by
$(F_{j,h}^{-1}(x))_i=(x_i-a_{j,i})/\ell_{j,i}$.
On the reference cube, set
$\psi_{j,h}=\bar\phi_j\circ F_{j,h}$.
We have
$\|\psi_{j,h}\|_{L^\infty([0,1]^d)}\le C_0$,
and the weak chain rule gives
$\partial_{y_i}\psi_{j,h}
=\ell_{j,i}(\partial_{x_i}\bar\phi_j)\circ F_{j,h}$
almost everywhere. Consequently,
$\|\partial_{y_i}\psi_{j,h}\|_{L^\infty([0,1]^d)}
\le \ell_{j,i}C_0h^{-1}\le C$.
Thus there exists a constant $A\ge1$, independent of $h$ and $j$, such that
$\|\psi_{j,h}\|_{W^{1,\infty}([0,1]^d)}\le A$.
Our choice of the box also ensures that
$\psi_{j,h}=0$ on $\partial[0,1]^d$.

Apply Yarotsky's approximation theorem' with $n=1$, to
$\psi_{j,h}/A$ with accuracy $\gamma/A$, and multiply the network output by $A$.
This gives a ReLU network $\widehat\Phi_{j,h,\gamma}$ satisfying
$\sup_{y\in[0,1]^d}
|\widehat\Phi_{j,h,\gamma}(y)-\psi_{j,h}(y)|\le\gamma$.
The estimate holds on the closed cube because both functions are continuous.
Since $A$ is independent of $h$ and $j$, the construction has depth at most
$C(1+\log(1/\gamma))$, width at most $C\gamma^{-d}$, and size at most
$C\gamma^{-d}(1+\log(1/\gamma))$.
Here size denotes the number of nonzero parameters.
The width bound follows from the parallel realization of
$O((\gamma/A)^{-d})$ local subnetworks in the theorem's construction,
each with width bounded in terms of $d$.

Let $\sigma(t)=\max\{t,0\}$, and define the coordinatewise clipping map
$\Pi:\mathbb R^d\to[0,1]^d$ by
$\Pi(y)_i=\sigma(y_i)-\sigma(y_i-1)$.
For every $x\in\mathbb R^d$, set
$\Phi_{j,h,\gamma}(x)
=\widehat\Phi_{j,h,\gamma}\bigl(\Pi(F_{j,h}^{-1}(x))\bigr)$.

If $x\in D_{j,h}$, then $F_{j,h}^{-1}(x)\in[0,1]^d$, so clipping leaves this point unchanged. Hence
$|\Phi_{j,h,\gamma}(x)-\bar\phi_j(x)|
=|\widehat\Phi_{j,h,\gamma}(F_{j,h}^{-1}(x))
-\psi_{j,h}(F_{j,h}^{-1}(x))|
\le\gamma$.

If $x\notin D_{j,h}$, at least one coordinate of
$F_{j,h}^{-1}(x)$ lies outside $[0,1]$. Therefore,
$z:=\Pi(F_{j,h}^{-1}(x))\in\partial[0,1]^d$,
where $\psi_{j,h}(z)=0$.
Also, $\bar\phi_j(x)=0$, since its support lies inside $D_{j,h}$.
It follows that
$|\Phi_{j,h,\gamma}(x)-\bar\phi_j(x)|
=|\widehat\Phi_{j,h,\gamma}(z)-\psi_{j,h}(z)|
\le\gamma$.
Combining the two cases yields
$\|\Phi_{j,h,\gamma}-\bar\phi_j\|_{L^\infty(\mathbb R^d)}\le\gamma$,
and consequently
$\|\Phi_{j,h,\gamma}-\phi_j\|_{L^\infty(\Omega)}\le\gamma$.

Finally, the affine map $F_{j,h}^{-1}$ and the clipping map are represented exactly by networks with complexity bounded in terms of $d$. Composing these with $\widehat\Phi_{j,h,\gamma}$ preserves the stated depth, width, and size bounds up to uniform constants. Although the affine weights may grow as $h^{-1}$, their number is independent of $h$. This proves the lemma.

Because $n\geq1$, the function $f$ is Lipschitz, or 
$\|f(x) - f(y)\|\leq L_f \|x-y\|_{\infty}$ for $x, y$ in the domain, where $L_f$ is the Lipschitz constant.
Besides, let $ B_f:=\left\lVert f \right\rVert_{L^\infty(\mathbb R^d)}+1.$
Since $f$ is continuous and vanishes outside the closed box $D$, it
vanishes on $\partial D$. 
Hence
\begin{equation}\label{eqn_support_boundary_distance_local}
 \left\lvert f(x) \right\rvert
 \leq
 L_f\operatorname{dist}(x,\partial D),
 \quad x\in D.
\end{equation}

Choose a buffer width $\kappa$ satisfying $ 0<\kappa<\frac12\min_{1\leq i\leq d}(b_i-a_i),$
and define $ D_\kappa
 :=
 \prod_{i=1}^d[a_i+\kappa,b_i-\kappa].$
For each coordinate, define the exact ReLU trapezoid
\begin{equation}\label{eq:coordinate-mask-local}
 \psi_{i,\kappa}(t)
 :=
 \frac1\kappa
 \Bigl[
 \operatorname{ReLU}(t-a_i)
 -\operatorname{ReLU}(t-(a_i+\kappa))
 -\operatorname{ReLU}(t-(b_i-\kappa))
 +\operatorname{ReLU}(t-b_i)
 \Bigr].
\end{equation}
Then $0\leq\psi_{i,\kappa}\leq1$, the function
$\psi_{i,\kappa}$ vanishes outside $[a_i,b_i]$, and it equals one on
$[a_i+\kappa,b_i-\kappa]$; 
it continuous linearly connect between $a_i$ and $a_i + \kappa$ and $b_i-\kappa$ and $b_i$.
Now we use the minimum function constructed by constant size ReLU network,
\begin{align*}
     \min\{s,t\}
 =
 \frac12\bigl(s+t-\operatorname{ReLU}(s-t)-\operatorname{ReLU}(t-s)\bigr),
\end{align*}
and construct a mask,
\begin{align*}
     M_\kappa(x)
 :=
 \min_{1\leq i\leq d}\psi_{i,\kappa}(x_i), \quad x = [x_1, ..., x_d]^{\intercal}.
\end{align*}
Thus $ 0\leq M_\kappa\leq1,
 M_\kappa=1\ \text{on }D_\kappa,
 M_\kappa=0\ \text{on }\mathbb R^d\setminus D.$
Since mask is implemented by the ReLU structure of minimizing $d$ inputs, we can use the binary tree structure. Consequently, the mask has depth $\sim 1+\log d$ and width $\sim d$.

Let $0<\rho,\mu<1$ be determined later.  
The target domain $D$ is a cube,
then apply an affine rescaling of $D$ to the unit cube and
normalization by the $W^{n,\infty}$-norm,
Yarotsky's approximation Lemma \ref{lemma_yarotsky} gives a ReLU network $F_\rho$ such that
$ \left\lVert f-F_\rho \right\rVert_{L^\infty(D)}\leq\rho.$
Its depth is $O(1+\log(1/\rho))$, and its size is
$O(\rho^{-d/n}(1+\log(1/\rho)))$ with width $\rho^{-d/n}$.  
Besides, $\left\lvert F_\rho(x) \right\rvert\leq B_f,$ for $x\in D$.
\medskip

Let $\operatorname{Mult}_{\mu,B_f}$ be a ReLU multiplication network in Lemma \ref{lemma_yarotsky_product} such that
\begin{align}
 \left\lvert \operatorname{Mult}_{\mu,B_f}(s,t)-st \right\rvert
 &\leq\mu, \text{ for }\left\lvert s \right\rvert\leq B_f,\ \left\lvert t \right\rvert\leq B_f, \nonumber
 \\
 \operatorname{ Mult}_{\mu,B_f}(s,0)
 &=0, \text{ for every }s\in\mathbb R.
 \label{eqn_multiplication_properties}
\end{align}
This network has width order constant, depth and size $\sim 1+\log(1/\mu)$.  
Define
\begin{align*}
     \widetilde f_\varepsilon(x)
 :=
 \operatorname{Mult}_{\mu,B_f}\bigl(F_\rho(x),M_\kappa(x)\bigr).
\end{align*}
We now study the value of $\tilde{f}_{\varepsilon}$ at different intervals.

(1) If $x\notin D$, then $M_\kappa(x)=0$, and
\eqref{eqn_multiplication_properties} gives
$\widetilde f_\varepsilon(x)=0$.  
Hence
$\operatorname{supp}(\widetilde f_\varepsilon)\subseteq D$.

(2) If $x\in D_\kappa$, then $M_\kappa(x)=1$. 
By the
multiplication approximation property,
$|\widetilde f_\varepsilon(x)-f(x)|\leq\mu+\rho$.
(3) If $x\in D\setminus D_\kappa$, then
$\operatorname{dist}(x,\partial D)\leq\kappa$.  
Using
\eqref{eqn_support_boundary_distance_local}, $0\leq M_\kappa\leq1$, and
\eqref{eqn_multiplication_properties}, we obtain
\begin{align*}
 \left\lvert \widetilde f_\varepsilon(x)-f(x) \right\rvert
 &\leq
 \left\lvert \operatorname{Mult}_{\mu,B_f}(F_\rho,M_\kappa)-F_\rho M_\kappa \right\rvert
 +\left\lvert (F_\rho-f)M_\kappa \right\rvert
 +\left\lvert f(M_\kappa-1) \right\rvert\\
 &\leq
 \mu+\rho+L_f\kappa.
\end{align*}
Note that the first estimate above is true as $B_f >1$ by the definition. 
Choose
$$
 \rho=\frac\varepsilon3,
 \quad
 \mu=\frac\varepsilon3,
 \quad
\kappa
=
\min\left\{
\frac14\min_{1\le i\le d}(b_i-a_i),
\frac{\varepsilon}{3\max\{L_f,1\}}
\right\}.
$$
Since $\mu\sim\rho\sim\varepsilon$, the size of $F_{\rho}$ dominates the entire network size over the mask $M_{\kappa}$ and $\operatorname{Mult}_{\mu,B_f}$.
Consequently, we have the estimate as in the theorem argument.
