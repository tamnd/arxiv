<!-- definition-1: body_md -->
\label{def:repbudget}
Fix $\varepsilon,\delta\in(0,1)$. For a ranking algorithm $\mathcal{A}$, its $(\varepsilon,\delta)$-repetition budget $d_{\mathcal{A}}(\varepsilon,\delta)$ is the smallest positive integer $d$ for which there exists a finite positive integer $n$ and a model-pair sampling distribution $\mathcal{C}$ such that, for every problem instance with minimum average utility gap $\Delta\ge\varepsilon$, a dataset $S$ generated with parameters $(n,d)$ satisfies
\[
\mathbb{P}\bigl(\mathrm{RankErr}(\mathcal{A}(S))=0\bigr)\ge 1-\delta.
\]
The probability is over the data generation process and any internal randomness of $\mathcal{A}$. 
The sample size $n$ may depend on $\mathcal{A}$, $\varepsilon$, $\delta$, and the fixed parameters $\beta$ and $|\mathcal{M}|$, but not on the particular instance. If no such $d$ exists, set $d_{\mathcal{A}}(\varepsilon,\delta)=+\infty$.

<!-- lemma-1: body_md -->
\label{lem:controlobs}
Fix $r \geq 1$, $\delta \in (0,1)$, and a dataset $S$ generated by parameters $(n,d)$. Let $\mathcal{C} = \mathrm{Unif}(\{\{m,m_0\}:m \in \mathcal{M} \setminus m_0\})$. Then, if we obtain
\[
n \geq \max\left\{2(|\mathcal{M}|-1)r\;,\;8(|\mathcal{M}|-1)\log\frac{|\mathcal{M}|-1}{\delta} \right\}
\]
sampled contexts, we have that 
\[
\mathbb{P}(|\{j \in [n]: \{m_1^j,m_2^j\} = \{m,m_0\}\}| \geq r) \geq 1-\delta
\]
simultaneously for all $m \neq m_0$.
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
Fix $m \neq m_0$. Let 
\[
I_m := \{j \in [n]: \{m_1^j,m_2^j\} = \{m,m_0\}\}
\]
Then by definition, $|I_m| \sim \text{Binomial}\left(n,\frac{1}{|\mathcal{M}|-1}\right)$. Then, if we take $n \geq 2(|\mathcal{M}|-1)r$, we have that 
\[
\frac{1}{2}\mathbb{E}[|I_m|] = \frac{1}{2}\frac{n}{|\mathcal{M}|-1} \geq r.
\]
Applying a multiplicative Chernoff bound gives,
\[
\mathbb{P}(|I_m| < r) \leq \mathbb{P}\left(|I_m| < \frac{\mathbb{E}[|I_m|]}{2}\right) \leq \exp\left(-\frac{\mathbb{E}[|I_m|]}{8}\right) = \exp\left(-\frac{n}{8(|\mathcal{M}|-1)}\right)
\]
Taking a union bound over the $|\mathcal{M}|-1$ non-reference models gives that simultaneously for all $m \neq m_0$,
\[
\mathbb{P}(|I_m| < r) \leq (|\mathcal{M}|-1)\exp\left(-\frac{n}{8(|\mathcal{M}|-1)}\right)
\]
Taking $n \geq 8(|\mathcal{M}|-1)\log\frac{|\mathcal{M}|-1}{\delta}$ guarantees that the right hand side is at most $\delta$, concluding the proof.
<!-- end proof-1 -->
<!-- proof-2: body_md -->
It suffices to consider two models, $\mathcal{M} = \{m,m_0\}$ and one task $t$, so the task distribution is degenerate and there is only one possible model-pair sampling distribution $\mathcal{C}$. For a user $i$, let $W_i \sim \text{Binomial}(d,\sigma(\beta(u_i(t,m) - u_i(t,m_0))))$ denote the number of wins for model $m$ under $d$ comparisons by user $i$. The constrained MLE has a closed form representation
\[
\widehat{v}(i,t,m) = \frac{1}{\beta}\log \frac{\min \{1-\sigma(-\beta), \max\{\sigma(-\beta),W_i/d\}\}}{1-\min \{1-\sigma(-\beta), \max\{\sigma(-\beta),W_i/d\}\}}
\]
Now, we derive two bounds relating to $\mathbb{E}[\widehat{v}(i,t,m)|u_i(t,m)-u_i(t,m_0)]$. For the first bound, consider $u_i(t,m)-u_i(t,m_0) = 1$. By a standard application of the Berry-Esseen Theorem \citep{berry,esseen} to Binomial random variables, there exist constants $c_1$ and $c_2$, depending only on $\beta$, such that for sufficiently large $d$
\[
\mathbb{P}\left(\frac{W_i}{d} \leq \sigma(\beta) - \frac{c_1}{\sqrt{d}} \mid u_i(t,m)-u_i(t,m_0)=1 \right) \geq c_2
\]
Now, when the true utility difference is 1, the corresponding Bradley-Terry win probability is just $\sigma(\beta)$. On this event, the truncated empirical win probability satisfies, \[\widehat{p}_i \leq \sigma(\beta) - \frac{c_1}{\sqrt{d}},\] where $\widehat{p}_i = \min \{1-\sigma(-\beta), \max\{\sigma(-\beta),W_i/d\}\}$. 
\[
\begin{aligned}
1-\widehat{v}(i,t,m) &= \frac{1}{\beta}\log \frac{\sigma(\beta)}{1-\sigma(\beta)} - \frac{1}{\beta}\log \frac{\widehat{p}_i}{1-\widehat{p}_i} \\
&\geq \frac{4}{\beta}(\sigma(\beta) - \widehat{p}_i) \\
& \geq \frac{4c_1}{\beta \sqrt{d}},
\end{aligned}
\]
where the first inequality follows by applying the Mean-Value Theorem to $h(p) = \frac{1}{\beta}\log \frac{p}{1-p}$ and using $p(1-p) \leq (1/4)$ for every $p \in (0,1)$. This gives the bias bound discussed in the main paper. 

Now, fix $u_i(t,m) - u_i(t,m_0) = 1/2$. The win probability for model $m$ here is $\sigma(\beta/2)$ which is a constant distance away from both truncation boundaries $\sigma(\beta)$ and $\sigma(-\beta)$ in the constrained MLE. Thus, Hoeffding's Inequality implies that on this event, the probability that $W_i/d$ reaches either of these boundaries decays exponentially with $d$. Now, if truncation does not occur, then the MLE estimate is simply $h(W_i/d)$. A second-order Taylor expansion centered around $p_i = \sigma(\beta/2)$ then gives
\[
h(W_i/d) = h(p_i) + h'(p_i)\left(\frac{W_i}{d}-p_i\right) + O\left(\left(\frac{W_i}{d}-p_i \right)^2\right).
\]
Since $\mathbb{E}[W_i/d - p_i] = 0$ and \[\mathbb{E}\left[\left(\frac{W_i}{d}-p_i \right)^2\right] = \frac{p_i(1-p_i)}{d} = O(1/d),\]
we have that 
\[
\left|\mathbb{E}[\widehat{v}(i,t,m)|u_i(t,m)-u_i(t,m_0)=1/2]-1/2\right| \leq \frac{C_{\beta}}{d}
\]
for some constant $C_{\beta} > 0$.

We now construct a problem instance where these two bias bounds cause $\mathcal{A}_{\mathrm{MLE-AVG}}$ to output the incorrect ranking for any finite number of contexts. Choose a sufficiently small constant $\eta>0$,
depending only on $\beta$ and $\delta$, and suppose that a fraction
\[
q_+ = \frac13+\frac{\eta}{\sqrt d}
\]
of users have utility difference $1$, while the remaining users have
utility difference $-1/2$. The average utility difference between $m$
and $m_0$ is then
\[
\overline{u}(m)-\overline{u}(m_0)
=
q_+-\frac{1-q_+}{2}
=
\frac{3\eta}{2\sqrt d}.
\]
Thus, $m$ is ranked above $m_0$.

On the other hand, using the two bias bounds above,
\[
\begin{aligned}
\mathbb E[\widehat v(i,t,m)]
&\leq
q_+\left(1-\frac{c_\beta}{\sqrt d}\right)
+
(1-q_+)\left(-\frac12+\frac{C_\beta}{d}\right)\\
&=
\frac{3\eta}{2\sqrt d}
-
q_+\frac{c_\beta}{\sqrt d}
+
(1-q_+)\frac{C_\beta}{d}.
\end{aligned}
\]
Take $\eta\leq c_\beta/12$. Since $q_+\geq 1/3$, for sufficiently large
$d$ the final term is at most $c_\beta/(12\sqrt d)$, and therefore
\[
\mathbb E[\widehat v(i,t,m)]
\leq
-\frac{c_\beta}{8\sqrt d}.
\]
Hence, although $m$ has larger average utility, the quantity averaged by
$\mathcal{A}_{\mathrm{MLE-AVG}}$ has negative expectation.

We next show that increasing the number of sampled contexts cannot resolve
this issue. Since every constrained MLE lies in $[-1,1]$, Hoeffding's
Inequality gives
\[
\Pr\left(
\widehat g_{\mathrm{MLE-AVG}}(m)\geq 0
\right)
\leq
\exp\left(
-\frac{c_\beta^2 n}{128d}
\right).
\]
Therefore, whenever $n\geq C_{\beta,\delta}d$ for a sufficiently large
constant $C_{\beta,\delta}$, the algorithm outputs the incorrect ranking
with probability greater than $\delta$.

It remains to rule out using fewer contexts. Consider a second population
in which the fraction of users with utility difference $1$ is
\[
q_-=\frac13-\frac{\eta}{\sqrt d},
\]
with the remaining users again having utility difference $-1/2$. Its
average utility difference is
\[
u(m)-u(m_0)
=
-\frac{3\eta}{2\sqrt d},
\]
so the two populations have opposite rankings and the same magnitude of
the average utility gap.

Even if we reveal which of the two user types was sampled in each context,
distinguishing the two populations from $n$ contexts amounts to
distinguishing $n$ Bernoulli draws with parameters $q_+$ and $q_-$. Since
$q_+$ and $q_-$ are bounded away from $0$ and $1$,
\[
D_{\mathrm{KL}}
\left(
\operatorname{Bernoulli}(q_+)
\,\middle\|\,
\operatorname{Bernoulli}(q_-)
\right)
=
O_\beta\left(\frac{\eta^2}{d}\right).
\]
Thus, for $n$ independently sampled contexts, the KL divergence is
$O_\beta(n\eta^2/d)$. Pinsker's Inequality and the standard two-point
testing bound imply that, whenever
\[
n
\leq
c_{\beta,\delta}\frac{d}{\eta^2},
\]
at least one of the two populations has ranking error greater than
$\delta$.

We may choose $\eta$ sufficiently small so that
\[
c_{\beta,\delta}\frac{d}{\eta^2}
\geq
C_{\beta,\delta}d.
\]
Hence, the small-$n$ and large-$n$ cases together cover every finite
$n$.

Finally, both populations have average utility gap
\[
\frac{3\eta}{2\sqrt d}.
\]
Therefore, whenever
\[
d
\leq
\frac{9\eta^2}{4\varepsilon^2},
\]
their average utility gap is at least $\varepsilon$, yet no finite choice of
$n$ gives the guarantee required by Definition~2.1. It follows that
\[
d_{\mathcal{A}_{\mathrm{MLE-AVG}}}(\varepsilon,\delta)
=
\Omega_{\beta,\delta}\left(\frac{1}{\varepsilon^2}\right).
\]

The argument above was written for sufficiently large $d$. The finitely
many remaining values of $d$ can be absorbed by decreasing the constant
in the final lower bound. For any fixed $d$, the expected constrained MLE
is a degree-$d$ polynomial in the Bradley--Terry win probability, whereas
the true utility difference is its log-odds. Thus, the two cannot agree up
to a common multiplicative constant over all contexts, and the same
two-population testing lower bound argument gives a fixed positive utility gap on which
direct MLE averaging has the wrong sign.

<!-- lemma-2: body_md -->
\label{lem:defq}
There exists a constant $c_{\beta} > 0$ such that for every odd $d \geq 1$, there exists a degree-$d$ polynomial $Q_d(p)$ with Bernstein representation
\[
Q_d(p) = \sum_{w=0}^d b_w\binom{d}{w}p^w(1-p)^{d-w}
\]
satisfying
\[
\sup_{p \in [\sigma(-\beta),1-\sigma(-\beta)]}\left|Q_d(p)-\frac{1}{\beta}\log \frac{p}{1-p}\right| \leq \exp\{-c_{\beta}d\}.
\]
Also, the Bernstein coefficients of $Q_d(p)$ satisfy 
\[
b_0 = \ldots = b_{\ell}, \qquad b_{d-\ell}=\ldots=b_{d},
\]
where $\ell = \lfloor \sigma(-\beta)d \rfloor$.
<!-- end lemma-2 -->
<!-- proof-3: body_md -->
Let $h(p) = \frac{1}{\beta}\log \frac{p}{1-p}$. Our goal is to construct a degree-$d$ polynomial that approximates $h$ while also respecting the truncation of the constrained MLE. To start, we impose that $Q_d(1/2)=h(1/2) = 0$, so $Q_d$ shares the same zero as $h$. Then, we have that 
\[
Q_d(p) - h(p) = \int_{1/2}^p (Q'_d(q)-h'(q))dq.
\]
Hence, if the derivative of $Q_d$ approximates the derivative of $h$ well, integrating gives that $Q_d$ approximates $h$ well. This motivates defining $Q_d$ through its derivative. We can differentiate the Bernstein representation of $Q_d$ to obtain
\[
Q'_d(p) = d\sum_{w=0}^{d-1}
(b_{w+1}-b_w)
\binom{d-1}{w}
p^w(1-p)^{d-1-w}.
\]
Now, observe that because of the truncation of the constrained MLE, the MLE outputs corresponding to $0,...,\ell$ wins are all $-1$ and the outputs corresponding to $d-\ell,...,d$ wins are all $1$. This explains the desired conditions $b_0=...=b_{\ell}$ and $b_{d-\ell}=...=b_d$. A natural way to enforce this is by requiring that $Q_d'(p)$ contain the factor $p^{\ell}(1-p)^{\ell}$. Now, we want $Q_d'$ to also approximate 
\[
h'(p) = \frac{1}{\beta p(1-p)} = \frac{4}{\beta(1-(2p-1)^2)}
\]
Now, we can apply the power series identity
\[
\frac{1}{(1-z)^{\ell+1}}
=
\sum_{r=0}^{\infty}
\binom{\ell+r}{r}z^r
\]
to obtain
\[
h'(p)
=
\frac{4}{\beta}
\left(1-(2p-1)^2\right)^\ell
\sum_{r=0}^{\infty}
\binom{\ell+r}{r}(2p-1)^{2r} = \frac{4^{\ell+1}}{\beta}p^{\ell}(1-p)^{\ell}\sum_{r=0}^{\infty}
\binom{\ell+r}{r}(2p-1)^{2r}.
\]
Conveniently, we already have the factor $p^{\ell}(1-p)^{\ell}$. Now, since we want $Q_d$ to have degree at most $d$, we write its derivative as a truncation of this series, obtaining
\[
Q_d'(p)
=
\frac{4}{\beta}
\left(1-(2p-1)^2\right)^\ell
\sum_{r=0}^{(d-1)/2-\ell}
\binom{\ell+r}{r}(2p-1)^{2r}.
\]
Since $\sigma(-\beta)<1/2$ and $d$ is odd, $\ell\leq(d-1)/2$. Moreover, the degree of $Q_d'$ is at most
\[
2\ell
+
2\left(\frac{d-1}{2}-\ell\right)
=
d-1,
\]
so $Q_d$ has degree at most $d$, as needed. It remains to show that the approximation error decays exponentially with $d$. To start, we write
\[
\frac{Q_d'(p)}{h'(p)}
=
(1-(2p-1)^2)^{\ell+1}
\sum_{r=0}^{(d-1)/2-\ell}
\binom{\ell+r}{r}(2p-1)^{2r}.
\]
Using the standard equivalence between the negative binomial and binomial CDFs gives
\[
\frac{Q_d'(p)}{h'(p)}
=
\mathbb{P}\left(
X\leq\frac{d-1}{2}-\ell
\right),
\]
where
\[
X\sim
\operatorname{Binomial}\left(
\frac{d+1}{2},(2p-1)^2
\right).
\]
Hence,
\[
1-\frac{Q_d'(p)}{h'(p)}
=
\mathbb{P}\left(
X\geq\frac{d+1}{2}-\ell
\right).
\]

For every $p\in[\sigma(-\beta),1-\sigma(-\beta)]$,
\[
(2p-1)^2\leq(1-2\sigma(-\beta))^2.
\]
On the other hand,
\[
\frac{\frac{d+1}{2}-\ell}{(d+1)/2}
=
1-\frac{2\ell}{d+1}
\geq
1-2\sigma(-\beta).
\]
Since
\[
(1-2\sigma(-\beta))^2<1-2\sigma(-\beta),
\]
we have that 
\[
\frac{\frac{d+1}{2}-\ell}{(d+1)/2}-(2p-1)^2
\ge
(1-2\sigma(-\beta))-(1-2\sigma(-\beta))^2
=
2\sigma(-\beta)(1-2\sigma(-\beta))>0.
\]
Thus, Hoeffding's Inequality gives that,
\[
0
\leq
1-\frac{Q_d'(p)}{h'(p)}
\leq
\exp(-c_\beta d)
\]
uniformly over $p\in[\sigma(-\beta),1-\sigma(-\beta)]$, where $c_{\beta} = (2\sigma(-\beta)(1-2\sigma(-\beta)))^2$.

Finally, since
$Q_d(1/2)=h(1/2)=0$, we have that
\[
\begin{aligned}
|Q_d(p)-h(p)|
&=
\left|
\int_{1/2}^p
(Q_d'(q)-h'(q))dq
\right|\\
&\leq
\exp(-c_\beta d)
\left|
\int_{1/2}^p
h'(q)dq
\right|\\
&=
\exp(-c_\beta d)|h(p)|\\
&\leq
\exp(-c_\beta d),
\end{aligned}
\]
where the final inequality follows since $h(p)\in[-1,1]$ for $p\in[\sigma(-\beta),1-\sigma(-\beta)]$.

<!-- lemma-3: body_md -->
\label{lem:boundbernstein}
Let 
\[
Q_d(p) = \sum_{w=0}^d b_w\binom{d}{w}p^w(1-p)^{d-w}
\]
be the polynomial constructed in \cref{lem:defq}. There exists a constant $C_{\beta} > 0$ such that 
\[
max_{w \in \{0,\ldots,d\}}|b_w| \leq C_{\beta}5^d.
\]
<!-- end lemma-3 -->
<!-- proof-4: body_md -->
Start by writing $Q_d$ in its monomial representation:
\[
Q_d(p)
=
\sum_{r=0}^d q_rp^r.
\]
We first bound the sum of the absolute values of the coefficients $q_r$.

Recall from the construction in \cref{lem:defq} that
\[
Q_d'(p)
=
\frac{4}{\beta}
(4p(1-p))^\ell
\sum_{r=0}^{(d-1)/2-\ell}
\binom{\ell+r}{r}(2p-1)^{2r}.
\]
The sum of the absolute values of the coefficients of $4p(1-p)$ is $8$, so the corresponding sum for
\[
(4p(1-p))^\ell
\]
is at most $8^\ell$. Similarly, the sum of the absolute values of the coefficients of $(2p-1)^{2r}$ is
\[
3^{2r}=9^r.
\]
It follows that the sum of the absolute values of the monomial coefficients of $Q_d'$ is at most
\[
\frac{4}{\beta}
8^\ell
\sum_{r=0}^{(d-1)/2-\ell}
\binom{\ell+r}{r}9^r.
\]
Using $\binom{\ell+r}{r}
\leq
2^{\ell+r},$
the above expression is bounded by
\[
\frac{
16^\ell}{\beta}

0, & \text{otherwise}
\end{cases}.

\label{prop:mus}
Fix $\beta > 0$, $d \geq 1$. Let $P_d$ denote the set of polynomials of degree at most $d$ and define 
\[
E_d = \inf_{P \in P_d}\sup_{p \in [\sigma(-\beta),1-\sigma(-\beta)]}|h(p)-P(p)|
\]

\[
\int p^k d\mu_+(p) = \int p^k d\mu_-(p), \qquad k=0,1,...,d,
\]

Let $P^* \in P_d$ denote a polynomial where 
\[
||P^*-h||_{\infty} = E_d.
\]
That is, $P^*$ by definition minimizes $\ell_{\infty}$ norm with respect to $h$. Note that $E_d > 0$, since $h$ is not a degree $d$ polynomial. By Chebyshev's Alternation Theorem, this is the case if and only if there exist distinct points $p_0>p_1 >...>p_{d+1} \in [\sigma(-\beta),1-\sigma(-\beta)]$ such that 
\[
P^*(p_i)-h(p_i) = s(-1)^iE_d,
\]
where $s \in \{-1,+1\}$.
Now, for each $i$, define the coefficient 
\[
c_i = \frac{1}{\prod_{j \neq i}(p_i - p_j)}.
\]
We will show that these coefficients annihilate $P_d$. In particular, consider the Lagrange basis polynomials,
\[
L_i(x) = \prod_{j \neq i}\frac{x - p_j}{p_i-p_j}.
\]
Observe that $L_i(p_i)=1$ and $L_i(p_j)=0$ for all $j \neq i$. Now, for any $P \in P_d$, we can use Lagrange interpolation to write 
\[
P(x) = \sum_{i=0}^{d+1} P(p_i)L_i(x).
\]
Now, observe that the coefficient in front of $x^{d+1}$ in $L_i(x)$ is exactly $c_i$. Thus, the coefficient in front of $x^{d+1}$ in the right hand side above is 
\[
\sum_{i=0}^{d+1} c_i P(p_i).
\]
However, since $P$ is a polynomial of degree at most $d$, it follows that 
\[
\sum_{i=0}^{d+1} c_i P(p_i) = 0.
\]
Next, observe that since the points $p_0,...,p_{d+1}$ are ordered, the $c_i$'s alternate in sign, and the Chebyshev's Alternation Theorem statement says that $P^*(p_i)-h(p_i)$ also alternates in sign. Thus, without loss of generality, we can multiply all the $c_i$'s by $-1$ if necessary and normalize so that $\sum_i |c_i| = 1$ and 
\[
c_i(h(p_i)-P^*(p_i))=|c_i|E_d
\]
for all $i$.

Now, we proceed with actually defining the desired distributions. To start, define the signed measure 
\[
\nu = \sum_{i=0}^{d+1}c_i \delta_{p_i}
\]
Then, for any $P \in P_d$,
\[
\int P(p)d\nu(p) = 0.
\]
This gives that 
\begin{align*}
\int h(p) d\nu(p) &= \int (h(p)-P^*(p))d\nu(p) + \int P^*(p) d\nu(p) \\
&= \int (h(p)-P^*(p))d\nu(p) \\
&= \sum_{i=0}^{d+1}c_i(h(p_i)-P^*(p_i)) \\
&= E_d.
\end{align*}
Now that we have defined $\nu$, let $R_{\#}\nu = \sum_{i=0}^{d+1}c_i \delta_{1-p_i}$ denote the pushforward of $\nu$ by $R(p)=1-p$ and define a new measure $\widetilde{\nu} = \nu - R_{\#}\nu$. It follows that for any $P \in P_d$
\[
\int P(p)d\widetilde{\nu}(p) = \int P(p)d\nu(p) - \int P(1-p)d\nu(p) = 0,
\]
so $\widetilde{\nu}$ retains the property of annihilating every polynomial in $P_d$. Next, using the fact that $h(p) = -h(1-p)$, we have that 
\[
\int h(p)d\widetilde{\nu}(p) = \int h(p)d\nu(p) - \int h(1-p)d\nu(p) = 2 \int h(p) d\nu(p) = 2E_d.
\]
Now, write $\widetilde{\nu} = \widetilde{\nu}^+ - \widetilde{\nu}^-$, where $(\widetilde{\nu}^+,\widetilde{\nu}^-)$ is the Jordan decomposition of $\widetilde{\nu}$. Since $\widetilde{\nu}$ annihilates every polynomial in $P_d$, which includes the constant polynomial, $\widetilde{\nu}$ must have a mass of 0, which implies that $\widetilde{\nu}^+$ and $\widetilde{\nu}^-$ have identical positive mass $C$. We now have all of the components to define our distributions. Concretely, set 
\[
\mu_+ = \frac{\widetilde{\nu}^+}{C} \qquad \text{and} \qquad \mu_- = \frac{\widetilde{\nu}^-}{C}.
\]
Now for any $k \in \{0,...,d\}$, we know that 
\[
\int p^k d\widetilde{\nu}(p) = \int p^k d\widetilde{\nu}^+(p) -  \int p^k d\widetilde{\nu}^-(p) = 0 \implies \int p^k d\widetilde{\nu}^+(p) = \int p^k d\widetilde{\nu}^-(p),
\]
since $p^k \in P_d$. Dividing by $C$ gives 
\[
\int p^k d\mu_+(p) = \int p^k d\mu_-(p),
\]
proving the first part of the proposition. For the second part, note that 
\[
R_{\#}\widetilde{\nu} = R_{\#}\nu - R_{\#}R_{\#}\nu = R_{\#}\nu - \nu = -\widetilde{\nu}.
\]
This implies that $R_{\#}\mu_+ = \mu_-$. Then, we have that 
\[
\int h(p)d\mu_-(p) = \int h(p)d(R_{\#}\mu_+)(p) = \int h(1-p)d\mu_+(p) = -\int h(p)d\mu_+(p) = -\gamma_d.
\]
This proves the second part of the proposition. It remains to show that $\gamma_d \geq E_d$. To see this, observe that 
\[
2C\gamma_d = \int h(p) d\widetilde{\nu}(p) = 2E_d,
\]
so it suffices to show that $C \leq 1$. Indeed, since the total variation norm satisfies triangle inequality, we have that 
\[
||\widetilde{\nu}||_{\mathrm{TV}} \leq ||\nu||_{\mathrm{TV}}+||R_{\#}\nu||_{\mathrm{TV}} \leq 2,
\]
where the final inequality follows from the definitions of the respective measures and that fact that $\sum_i |c_i| = 1$. At the same time, we have that 
\[
||\widetilde{\nu}||_{\mathrm{TV}} = ||\widetilde{\nu}^+||_{\mathrm{TV}} + ||\widetilde{\nu}^-||_{\mathrm{TV}} = 2C
\]
It follows that $C \leq 1$, completing the proof.

h\left(\frac{1+\tanh(\beta/2)x}{2}\right) = \frac{1}{\beta}\left[\log(1+r_{\beta}^2+2r_\beta \cos\theta)-\log(1+r_{\beta}^2-2r_\beta \cos\theta) \right].
\]
Then, we use the series expansion $\log(1+r^2-2r\cos\theta) = -2\sum_{k=1}^{\infty} \frac{r^k}{k}\cos(k\theta)$ to obtain the desired Chebyshev Expansion,
\[
h(p) = \frac{4}{\beta}\sum_{k \geq 1, k\text{ odd}}\frac{r_{\beta}^k}{k}\cos(k\theta).
\]
Take any $P \in P_d$. Now, let $k_d$ denote the smallest odd integer strictly greater than $d$. By definition, in the Chebyshev expansion of $P$, the coefficient in front of $\cos(k_d \theta)$ is 0. On the other hand, the coefficient in front of  $\cos(k_d \theta)$ in the Chebyshev expansion of $h$ above is 
\[
\frac{4r_{\beta}^{k_d}}{\beta k_d}.
\]
Putting this together and using the fact that for any continuous function $f$, the $k$'th Chebyshev coefficient $a_k(f)$ is such that $|a_k(f)| \leq 2||f||_{\infty}$, we get 
\[
||h-P||_{\infty} \geq \frac{1}{2}\frac{4r_{\beta}^{k_d}}{\beta k_d} \geq \frac{2r_{\beta}^{k_d}}{\beta k_d}
\]
Taking the infimum over $P \in P_d$ then gives that 
\[
E_d \geq \frac{2r_{\beta}^{k_d}}{\beta k_d},
\]
and the result follows by the fact that $d < k_d \leq d+2$.

<!-- proof-14: body_md -->
Define 
\[
\mathcal{C} = \mathrm{Unif}(\{\{m,m_0\}: m \in \mathcal{M} \setminus m_0\}).
\]
Fix $m \neq m_0$ and $j \in I_m$.
Let
$
p_j(m)
=
\sigma\left(
\beta\left(
u_{i^j}(t^j,m)-u_{i^j}(t^j,m_0)
\right)
\right)
$
denote the Bradley--Terry win probability for $m$ against $m_0$ in this context. Then,
\[
u_{i^j}(t^j,m)-u_{i^j}(t^j,m_0)
=
\frac{1}{\beta}\log\frac{p_j(m)}{1-p_j(m)}
=
\frac{1}{\beta}
\sum_{k=1}^{\infty}
\frac{p_j(m)^k-(1-p_j(m))^k}{k}.
\]

We first compute the expectation of $Z_j(m)$ conditional on the context.
By the definition of $K_j$,
\[
\begin{aligned}
\mathbb E[Z_j(m)\mid i^j,t^j,j\in I_m]
&=
\sum_{k=1}^{\infty}
(1-\rho)\rho^{k-1}
\frac{
p_j(m)^k-(1-p_j(m))^k
}{
\beta k(1-\rho)\rho^{k-1}
}\\
&=
\frac{1}{\beta}
\sum_{k=1}^{\infty}
\frac{
p_j(m)^k-(1-p_j(m))^k
}{k}\\
&=
u_{i^j}(t^j,m)-u_{i^j}(t^j,m_0).
\end{aligned}
\]
Thus, $Z_j(m)$ is an unbiased estimator of the context-level utility difference. Since the sampled model pair is independent of the user-task context,
\[
\mathbb E[Z_j(m)\mid j\in I_m]
=
\overline{u}(m)-\overline{u}(m_0).
\]
Thus, $Z_j(m)$ is an unbiased estimator of the average utility difference
between $m$ and $m_0$.

Next, we bound its variance by bounding its second moment. Conditional on
$K_j=k$, the events that $m$ wins all $k$ comparisons and that $m_0$ wins
all $k$ comparisons are disjoint. Therefore,
\[
\mathbb E[Z_j(m)^2\mid i^j,t^j,j\in I_m]
=
\frac{1}{\beta^2}
\sum_{k=1}^{\infty}
\frac{
p_j(m)^k+(1-p_j(m))^k
}{
k^2(1-\rho)\rho^{k-1}
}.
\]
Since the utility difference lies in $[-1,1]$,
$
p_j(m),\,1-p_j(m)\leq\sigma(\beta).
$
Hence,
\[
\begin{aligned}
\mathbb E[Z_j(m)^2\mid i^j,t^j,j\in I_m]
&\leq
\frac{2\rho}{\beta^2(1-\rho)}
\sum_{k=1}^{\infty}
\frac{1}{k^2}
\left(
\frac{\sigma(\beta)}{\rho}
\right)^k\\
&\leq
\frac{2\rho}{\beta^2(1-\rho)}
\sum_{k=1}^{\infty}
\left(
\frac{\sigma(\beta)}{\rho}
\right)^k\\
&=:V_\beta<\infty,
\end{aligned}
\]
where the series converges because $\rho>\sigma(\beta)$. Averaging over
the context gives
\[
\operatorname{Var}(Z_j(m)\mid j\in I_m)\leq V_\beta.
\]

We now control the median-of-means estimator. Choose $B$ to be the
smallest odd integer satisfying
\[
B\geq 8\log\frac{2|\mathcal{M}|}{\delta},
\]
and let
\[
b
=
\left\lceil
\frac{64V_\beta}{\varepsilon^2}
\right\rceil.
\]
By \cref{lem:controlobs}, if
\[
n
\geq
\max\left\{
2(|\mathcal{M}|-1)Bb,\,
8(|\mathcal{M}|-1)
\log\frac{2(|\mathcal{M}|-1)}{\delta}
\right\},
\]
then with probability at least $1-\delta/2$,
\[
|I_m|\geq Bb
\]
simultaneously for every $m\neq m_0$.

Condition on this event. Since
\[
b_m
=
\left\lfloor
\frac{|I_m|}{B}
\right\rfloor
\geq b,
\]
each block mean satisfies
\[
\mathbb E[\overline Z_s(m)\mid I_m]
=
\overline{u}(m)-\overline{u}(m_0)
\]
and
\[
\operatorname{Var}(\overline Z_s(m)\mid I_m)
\leq
\frac{V_\beta}{b_m}
\leq
\frac{V_\beta}{b}.
\]
Thus, Chebyshev's Inequality gives
\[
\Pr\left(
\left|
\overline Z_s(m)-(\overline{u}(m)-\overline{u}(m_0))
\right|
>
\frac{\varepsilon}{4}
\;\middle|\;
I_m
\right)
\leq
\frac{16V_\beta}{b\varepsilon^2}
\leq
\frac14.
\]

For the median of the $B$ block means to differ from $u(m)-u(m_0)$ by
more than $\varepsilon/4$, at least half of the block means must differ by more
than $\varepsilon/4$. Since the blocks are disjoint, Hoeffding's Inequality gives
\[
\Pr\left(
\left|
\widehat g_{\mathrm{URR}}(m)
-
(u(m)-u(m_0))
\right|
>
\frac{\varepsilon}{4}
\;\middle|\;
I_m
\right)
\leq
\exp(-B/8)
\leq
\frac{\delta}{2|\mathcal{M}|}.
\]
Taking a union bound over $m\neq m_0$ gives that, with conditional
probability at least $1-\delta/2$,
\[
\left|
\widehat g_{\mathrm{URR}}(m)
-
(\overline{u}(m)-\overline{u}(m_0))
\right|
\leq
\frac{\varepsilon}{4}
\]
simultaneously for every $m\neq m_0$. Combining this with the earlier
event controlling the sizes of the sets $I_m$, the same statement holds
with probability at least $1-\delta$.

Take any pair of models $m,m'$. The triangle inequality gives
\[
\left|
\left(
\widehat g_{\mathrm{URR}}(m)
-
\widehat g_{\mathrm{URR}}(m')
\right)
-
\left(
\overline{u}(m)-\overline{u}(m')
\right)
\right|
\leq
\frac{\varepsilon}{2}.
\]
Every nonzero average utility difference has magnitude at least
$\Delta\geq\varepsilon$, so ranking according to $\widehat g_{\mathrm{URR}}$
preserves every strict average-utility ordering.

Finally,
\[
B
=
O\left(
\log\frac{|\mathcal{M}|}{\delta}
\right)
\qquad\text{and}\qquad
b
=
O\left(
\frac{1}{\varepsilon^2}
\right),
\]
so the choice of $n$ above gives
\[
n
=
O\left(
\frac{|\mathcal{M}|}{\varepsilon^2}
\log\frac{|\mathcal{M}|}{\delta}
\right).
\]

It remains to calculate the expected number of repeated comparisons.
Since $K_j$ is geometric with success probability $1-\rho$,
\[
\mathbb E[K_j]
=
\frac{1}{1-\rho}
=
O(1).
\]
Since only one model pair is sampled in each context, the total number of
pairwise comparisons is $\sum_{j=1}^n K_j$. Therefore,
\[
\mathbb E\left[
\sum_{j=1}^n K_j
\right]
=
\frac{n}{1-\rho}
=
O\left(
\frac{|\mathcal{M}|}{\varepsilon^2}
\log\frac{|\mathcal{M}|}{\delta}
\right),
\]
which concludes the proof.
