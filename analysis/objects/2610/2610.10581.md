\textbf{\label{TR}} Suppose $a\leq 1$, $b>0$\ and $c\geq \max \left\{
-a,b\right\} $. If $c\geq \max \left\{ 1-2a,2b\right\} $, then 
\begin{equation}
M_{p}\left( 1-x,\frac{b}{c}\right) \leq \left[ F\left( -a,b;c;x\right)  
\right] ^{1/a},\text{ \ for all }x\in \left( 0,1\right) ,
\label{RI-Mp<Hm-p0}
\end{equation} 
if and only if $p\leq p_{0}$, where 
\begin{equation}
p_{0}=\frac{a+c}{1+c}.  \label{p0}
\end{equation} 
If $c\leq \min \left\{ 1-2a,2b\right\} $, then 
\begin{equation}
\left[ F\left( -a,b;c;x\right) \right] ^{1/a}\leq M_{p}\left( 1-x,\frac{b}{c} 
\right) ,\text{ \ for all }x\in \left( 0,1\right) ,  \label{RI-Hm<Mp-p0}
\end{equation} 
if and only if $p\geq p_{0}$. If $c=1-2a=2b$; or $c=\max \left\{
-a,b\right\} $; or $a=1$, then the equality holds.

<!-- remark-1: body_md -->
Clearly, Theorem \ref{TR} provides a type of sharp power mean bounds $ 
M_{p_{0}}\left( 1-x,b/c\right) $ for the hypergeometric mean $\left[ F\left(
-a,b;c;x\right) \right] ^{1/a}$, which is sharp at $x=0$. If Conjecture \ref 
{Cj-BRT} is proved to be true, then it provides another type of sharp power
mean bounds $M_{p_{0}^{\ast }}\left( 1-x,b/c\right) $ for the hypergeometric
mean $\left[ F\left( -a,b;c;x\right) \right] ^{1/a}$, which is sharp at $x=1$ 
. For convenience, we call them \textquotedblleft the first and second type
of power mean bounds\textquotedblright , respectively. Moreover, we call the
inequity 
\begin{equation}
\left[ F\left( -a,b;c;x\right) \right] ^{1/a}\leq \left( \geq \right)
M_{p}\left( 1-x,\frac{b}{c}\right) \text{ for }x\in \left( 0,1\right)
\label{Hm<>Pm}
\end{equation} 
as "Hm-Pm inequality". If such inequality is sharp at $x=0$ ($x=1$) then it
is called \textquotedblleft the first (second) Hm-Pm
inequality\textquotedblright .

\label{MT-m}Suppose that $a<1$, $b>0$ and $c>\max \left\{ -a,b\right\} $.
Let $p_{0}$ and $C_{p_{0}}$ be defined by (\ref{p0}) and (\ref{Cp}),
respectively.

(i) The function $f_{p_{0}}$ defined by (\ref{fp}) is increasing on $\left(
0,1\right) $ if and only if $c\geq 2b$ and $a-b+c\geq p_{0}$. Therefore, the
double inequality 
\begin{equation}
M_{p_{0}}\left( 1-x,\frac{b}{c}\right) <\left[ F\left( -a,b;c;x\right)  
\right] ^{1/a}<C_{p_{0}}M_{p_{0}}\left( 1-x,\frac{b}{c}\right)
\label{Pm<Hm<CPm-p0}
\end{equation} 
holds for $x\in \left( 0,1\right) $ if $c\geq 2b$ and $a-b+c\geq p_{0}$.

(ii) If $c\geq 2b$ and $a-b+c<p_{0}$, then there is an $x_{0}\in \left(
0,1\right) $ such that the function $f_{p_{0}}$ is increasing on $\left(
0,x_{0}\right) $ and decreasing on $\left( x_{0},1\right) $. Consequently,
the inequality 
\begin{equation}
\min \left\{ 1,C_{p_{0}}\right\} M_{p_{0}}\left( 1-x,\frac{b}{c}\right) < 
\left[ F\left( -a,b;c;x\right) \right] ^{1/a}  \label{Pm<Hm-p0}
\end{equation} 
holds for $x\in \left( 0,1\right) $ if $a-b+c>0$.

(iii) The function $f_{p_{0}}$ is decreasing on $\left( 0,1\right) $ if and
only if $c\leq 2b$ and $a-b+c\leq p_{0}$. Therefore, if $c\leq 2b$ and $ 
a-b+c\leq p_{0}$, then the inequality 
\begin{equation}
\left[ F\left( -a,b;c;x\right) \right] ^{1/a}<M_{p_{0}}\left( 1-x,\frac{b}{c} 
\right)  \label{Hm<Pm-p0}
\end{equation} 
holds for $x\in \left( 0,1\right) $. Further, the double inequality 
\begin{equation}
C_{p_{0}}M_{p_{0}}\left( 1-x,\frac{b}{c}\right) <\left[ F\left(
-a,b;c;x\right) \right] ^{1/a}<M_{p_{0}}\left( 1-x,\frac{b}{c}\right)
\label{CPm<Hm<Pm-p0}
\end{equation} 
holds for $x\in \left( 0,1\right) $ if $a-b+c>0$.

(iv) If $c\leq 2b$ and $a-b+c>p_{0}$, then there is an $x_{0}\in \left(
0,1\right) $ such that the function $f_{p_{0}}$ is decreasing on $\left(
0,x_{0}\right) $ and increasing on $\left( x_{0},1\right) $. Consequently,
the inequality 
\begin{equation}
\left[ F\left( -a,b;c;x\right) \right] ^{1/a}<\max \left\{
1,C_{p_{0}}\right\} M_{p_{0}}\left( 1-x,\frac{b}{c}\right)  \label{Hm<cPm-p0}
\end{equation} 
holds for $x\in \left( 0,1\right) $.

Let $p_{0}$ be defined by (\ref{p0}) and $p\in \mathbb{R}$.

(i) If $c\geq 2b$ and $p\leq p_{0}\leq a-b+c$, then the function $f_{p}$
defined by (\ref{fp}) is increasing on $\left( 0,1\right) $, and therefore,
the double inequality 
\begin{equation}
M_{p}\left( 1-x,\frac{b}{c}\right) <\left[ F\left( -a,b;c;x\right) \right]
^{1/a}<C_{p}M_{p}\left( 1-x,\frac{b}{c}\right)  \label{Pm<Hm<CPm-p}
\end{equation} 
holds for $x\in \left( 0,1\right) $, where $C_{p}$ is defined by (\ref{Cp}).

(ii) If $c\leq 2b$ and $p\geq p_{0}\geq a-b+c$, then the function $f_{p}$ is
decreasing on $\left( 0,1\right) $, and therefore, the reverse of the left
hand side inequality of (\ref{Pm<Hm<CPm-p}) holds for $x\in \left(

{Pm<Hm<CPm-p}) reverses.

<!-- proof-1: body_md -->
We first show that the function 
\begin{equation*}
x\mapsto \frac{f_{p}\left( x\right) }{f_{p_{0}}\left( x\right) }=\frac{\left[
1-b/c+\left( b/c\right) \left( 1-x\right) ^{p_{0}}\right] ^{1/p_{0}}}{\left[
1-b/c+\left( b/c\right) \left( 1-x\right) ^{p}\right] ^{1/p}}
\end{equation*} 
is increasing (decreasing) on $\left( 0,1\right) $ if $p\leq \left( \geq
\right) p_{0}$. In fact, logarithmic differentiation yields 
\begin{eqnarray*}
\left[ \ln \frac{f_{p}\left( x\right) }{f_{p_{0}}\left( x\right) }\right]
^{\prime } &=&b\frac{\left( 1-x\right) ^{p-1}}{c-b+b\left( 1-x\right) ^{p}}-b 
\frac{\left( 1-x\right) ^{p_{0}-1}}{c-b+b\left( 1-x\right) ^{p_{0}}} \\
&=&b\left( c-b\right) \frac{t^{p-1}-t^{p_{0}-1}}{\left( c-b+bt^{p}\right)
\left( c-b+bt^{p_{0}}\right) }\geq \left( \leq \right) 0
\end{eqnarray*} 
for $t=1-x\in \left( 0,1\right) $ if $p\leq \left( \geq \right) p_{0}$. Now
using Theorem \ref{MT-m} (i) we deduce that, the function 
\begin{equation*}
x\mapsto f_{p}\left( x\right) =\frac{f_{p}\left( x\right) }{f_{p_{0}}\left(
x\right) }\times f_{p_{0}}\left( x\right)
\end{equation*} 
is increasing on $\left( 0,1\right) $ if $c\geq 2b$, $a-b+c\geq p_{0}$ and $ 
p\leq p_{0}$. Similarly, $f_{p}\left( x\right) $ is decreasing on $\left(
0,1\right) $ if $c\leq 2b$, $a-b+c\leq p_{0}$ and $p\geq p_{0}$. The
required inequalities follow from the monotonicity of $f_{p}\left( x\right) $ 
, which completes the proof.

<!-- remark-5: body_md -->
We claim that $p\mapsto C_{p}M_{p}\left( 1-x,b/c\right) $ is decreasing on $ 
\left( 0,\infty \right) $. In fact, it suffices to prove that $\phi ^{\prime
}\left( p\right) <0$ for $p>0$, where 
\begin{equation*}
\phi \left( p\right) =\ln \left[ \left( \frac{c}{c-b}\right)
^{1/p}M_{p}\left( 1-x,\frac{b}{c}\right) \right] =\frac{1}{p}\ln \left(
1+\sigma t^{p}\right)
\end{equation*} 
with $\sigma =b/\left( c-b\right) $ and $t=1-x\in \left( 0,1\right) $.
Differentiation leads to 
\begin{eqnarray*}
p^{2}\phi ^{\prime }\left( p\right) &=&\frac{\sigma pt^{p}}{1+\sigma t^{p}} 
\ln t-\ln \left( 1+\sigma t^{p}\right) :=\phi _{1}\left( p\right) , \\
\phi _{1}^{\prime }\left( p\right) &=&p\sigma \frac{t^{p}\ln ^{2}t}{\left(
1+\sigma t^{p}\right) ^{2}}>0
\end{eqnarray*} 
for $p>0$. This gives $\phi _{1}\left( p\right) <\lim_{p\rightarrow \infty
}\phi _{1}\left( p\right) =0$, so $\phi ^{\prime }\left( p\right) <0$ for $ 
p>0$, thereby completing the proof.

We denote 
\begin{equation*}
\rho \left( c\right) =\delta \left( p_{0}\right) =a-b+c-\frac{a+c}{1+c}=

\rho ^{\prime }\left( c\right) =\frac{\left( c^{2}+c\right) +\left(
c+a\right) }{\left( c+1\right) ^{2}}>0
\end{equation*}

\begin{eqnarray*}
\rho \left( 2b\right) &=&\frac{b}{2b+1}\left( 2a+2b-1\right) , \\

<!-- proof-4: body_md -->
A simple computation yields that $c=2b$, $p_{0}=\left( a+2\right) /3$, $ 
\delta \left( p_{0}\right) =a-b+c-p_{0}=\left( 2a+1\right) /3$ and 
\begin{equation*}
p_{0}^{\ast }=\frac{a\ln 2}{\ln \left( 1+a\right) }\text{ if }a\neq 0\text{
\ and \ }p_{0}^{\ast }=\ln 2\text{ \ for }a\in \left( -1,1\right) \text{.}
\end{equation*} 
We first show that 
\begin{equation}
p_{0}<p_{0}^{\ast }\text{ for }a\in \left( -1/2,1\right) \text{ \ and \ } 
p_{0}>p_{0}^{\ast }\text{ for }a\in \left( -1,-1/2\right) .  \label{p0<>p0*}
\end{equation}

\begin{equation*}

\left( a+1\right) }{a}\text{, }
\end{equation*}

\left( -1,0\right) $. Differentiation yields

\left( 3a^{2}\ln 2\right) \frac{d}{da}\frac{p_{0}}{p_{0}^{\ast }} &=&\frac{ 
a\left( a+2\right) }{\left( a+1\right) }-2\ln \left( a+1\right) =\mu \left(
a\right) , \\
\mu ^{\prime }\left( a\right) &=&\frac{a^{2}}{\left( a+1\right) ^{2}}\geq 0 
\text{.}
\end{eqnarray*} 
This together with the facts that $\left. \left( p_{0}/p_{0}^{\ast }\right)
\right\vert _{a=1}=\left. \left( p_{0}/p_{0}^{\ast }\right) \right\vert
_{a=-1/2}=1$ leads to the inequalities (\ref{p0<>p0*}).

Theorem \ref{MT-3} (ii), the inequality (\ref{Hm<Pm--a,1,2}) reverses if and
only if $p\geq p_{0}=\left( a+2\right) /3$

<!-- definition-1: body_md -->
\label{D-NPs}Let $m\in \mathbb{N}$. A real sequence $\left\{ a_{n}\right\}
_{n\geq 0}$ is called an negative-positive-type sequence, NP-type sequence
for short, if the subsequences $\left\{ a_{n}\right\} _{0\leq n\leq m}$ and $ 
\left\{ a_{n}\right\} _{n>m}$ are negative and positive sequences,
respectively. $\left\{ -a_{n}\right\} _{n\geq 0}$ is called a
positive-negative-type sequence, PN-type sequence for short.
<!-- end definition-1 -->
<!-- definition-2: body_md -->
\label{D-NPp}If a real sequence $\left\{ a_{n}\right\} _{n\geq 0}$ is
NP-type, then the normal power series $S\left( t\right) =\sum_{k=0}^{\infty
}a_{k}t^{k}$ is called an NP-type power series, and $-S\left( t\right) $ is
called a PN-type power series.
<!-- end definition-2 -->
<!-- proposition-1: body_md -->
\label{P-sgnS}Let $S\left( t\right) $ be an NP-type power series converging
on the interval $\left( 0,r\right) $ ($r>0$). (i) If $S\left( r^{-}\right)
\leq 0$, then $S\left( t\right) <0$ for all $t\in \left( 0,r\right) $. (ii)
If $S\left( r^{-}\right) >0$, then there is a unique $t_{0}\in \left(
0,r\right) $ such that $S\left( t\right) <0$ for $t\in \left( 0,t_{0}\right)
$ and $S\left( t\right) >0$ for $t\in \left( t_{0},r\right) $.
<!-- end proposition-1 -->
<!-- remark-13: body_md -->
If $r=\infty $, then Proposition \ref{P-sgnS} is reduced to \cite[Lemma 6.3] 
{Belzunce-I:M-E-40-2007} (see also \cite[Lemma 2]{Yang-JIA-157-2015}, \cite[ 
Lemma 2.1]{Yang-JIA-299-2015}).
<!-- end remark-13 -->
<!-- remark-14: body_md -->

t_{1}\right) <0$, then we have $S\left( t\right) <0$ for all $t\in \left(

x\right) =\sum_{n=0}^{\infty }\xi _{n}\left( p_{0}\right) x^{n}\geq 0$ for $ 
x\in \left( 0,1\right) $. It is deduced from (\ref{dfp}) that the function $ 
f_{p_{0}}$ is increasing on $\left( 0,1\right) $, and the double inequality ( 
\ref{Pm<Hm<CPm-p0}) therefore holds for $x\in \left( 0,1\right) $.

\textbf{Part 2}: If $c\geq 2b$ and $a-b+c<p_{0}$, that is, $\left(
a,b,c\right) \in \left\{ c\geq 2b,\delta \left( p_{0}\right) <0\right\} $,
then by Lemma \ref{L-sgngn-p0}, there is an $n_{1}\geq 1$ such that $\gamma
_{n}\geq 0$ for $1\leq n\leq n_{1}$ and $\gamma _{n}<0$ for $n\geq n_{1}+1$.
By the relation (\ref{xin+1-n-n-1-e-1}), we have 
\begin{equation}
\eta _{n+1}-\lambda _{n}\eta _{n}=\tau _{n}\gamma _{n}u_{n-1}\left\{
\begin{array}{cc}
\geq 0 & \text{ if }1\leq n\leq n_{1}, \\
<0 & \text{if }n\geq n_{1}+1. 
\end{array} 
\right.   \label{etan-rr}
\end{equation}

\textbf{When }$1\leq n\leq n_{1}$. Similarly, $\xi _{2}-\theta _{1}\xi
_{1}=\xi _{2}\geq 0$, and by induction, $\xi _{n}\geq 0$ for $1\leq n\leq
n_{1}+1$.

\textbf{When }$n\geq n_{1}+1$. If there is no negative term in the
subsequence $\left\{ \xi _{n}\right\} _{n\geq n_{1}+2}$, then $\xi _{n}\geq
0 $ for all $n\geq 1$, which implies $\left\{ \xi _{n}\right\} _{n\geq 0}$
is a nonnegative sequence. This implies that the function $g_{p_{0}}\left(
x\right) $ is increasing on $\left( 0,1\right) $, which yields a
contradiction with $g_{p_{0}}\left( 1\right) <0$ by Lemma \ref{L-gp(1)}
(ii). Hence, there are some negative terms in the sequence $\left\{ \xi
_{n}\right\} _{n\geq n_{1}+2}$. Assume that the first negative term is $\xi
_{n_{0}}$ ($n_{0}\geq n_{1}+2$), then we can prove that all terms after that
are negative. In fact, since $\xi _{n_{0}-1}\geq 0$, $\xi _{n_{0}}<0$, by
Lemma \ref{L-xin-rr}, the recurrence relation (\ref{xin-rr-2}) implies that 
\begin{equation*}
\eta _{n_{0}}=\xi _{n_{0}+1}-\theta _{n_{0}}\xi _{n_{0}}=\lambda
_{n_{0}}\left( \xi _{n_{0}}+\theta _{n_{0}-1}\left( -\xi _{n_{0}-1}\right)
\right) +\tau _{n_{0}}\gamma _{n_{0}}u_{n_{0}-1}<0,
\end{equation*} 
which yields $\eta _{n_{0}}<0$, and so $\xi _{n_{0}+1}<\theta _{n_{0}}\xi
_{n_{0}}<0$.

Suppose that $\xi _{n}<0$ for $n_{0}+1\leq n\leq m$. Using the relation (\ref 
{etan-rr}) for $n\geq n_{1}+1$ yields $\eta _{n+1}-\lambda _{n}\eta
_{n}=\tau _{n}\gamma _{n}u_{n-1}<0$ for $n\geq n_{0}+1$. It then follows
that
\begin{equation*}
\eta _{n+1}<\lambda _{n}\eta _{n}<\left( \lambda _{n}\lambda _{n-1}\right)
\eta _{n-1}<\cdot \cdot \cdot <\left( \lambda _{n}\lambda _{n-1}\cdot \cdot
\cdot \lambda _{n_{0}}\right) \eta _{n_{0}}<0,
\end{equation*} 
which, by induction hypothesis, leads to $\xi _{n+1}<\theta _{n}\xi _{n}<0$.
We thus deduce that $\xi _{n}<0$ for $n\geq n_{0}$ by induction. So, $ 
\left\{ \xi _{n}\right\} _{n\geq 0}$ is a PN-type sequence, and $ 
g_{p_{0}}\left( x\right) =\sum_{n=0}^{\infty }\xi _{n}x^{n}$ is undoubtedly
a PN-type power series. By Proposition \ref{P-sgnS}, there is an $x_{0}\in
\left( 0,1\right) $ such that $g_{p_{0}}\left( x\right) >0$ for $x\in \left(
0,x_{0}\right) $ and $g_{p_{0}}\left( x\right) <0$ for $x\in \left(
x_{0},1\right) $. This, by (\ref{dfp}), shows that function $f_{p_{0}}$ is
increasing on $\left( 0,x_{0}\right) $ and decreasing on $\left(
x_{0},1\right) $. Consequently, the inequality (\ref{Pm<Hm-p0}) holds for $ 
x\in \left( 0,1\right) $ if $a-b+c>0$.

\textbf{Part 3}: \textbf{Necessity}. If $f_{p_{0}}$ is decreasing on $\left(
0,1\right) $, then $g_{p_{0}}\left( x\right) \leq 0$ for all $x\in \left(
0,1\right) $. Then the necessary condition follows from the inequalities 
\begin{equation}
\lim_{x\rightarrow 0}\frac{g_{p_{0}}\left( x\right) }{x^{2}}\leq 0\text{ \
and }g_{p_{0}}\left( 1^{-}\right) \leq 0.  \label{nci<0}
\end{equation} 
It is seen from (\ref{nL1}) that the first inequality of (\ref{nci<0})
implies that $c\leq 2b$. By Lemmas \ref{L-gp(1)} and \ref{L-gp0(1)}, the
second inequality of (\ref{nci<0}) implies that $a-b+c<p_{0}$ and $ 
a-b+c=p_{0}\geq 1/2$. Therefor, the required necessary conditions are 
\begin{equation*}
\left( a,b,c\right) \in \left\{ c\leq 2b\right\} \cap \left\{
a-b+c<p_{0}\right\} \cup \left\{ a-b+c=p_{0}\geq 1/2\right\} ,
\end{equation*} 
which, by (\ref{E-}) shown in Remark \ref{R-dp=0}, can be simplified to 
\begin{equation*}
\left( a,b,c\right) \in \left\{ c\leq 2b\text{, }a-b+c<p_{0}\right\} .
\end{equation*} 
This proves the necessity.

\textbf{Sufficiency}. Suppose that $c\leq 2b$ and $a-b+c\leq p_{0}$, that
is, $\left( a,b,c\right) \in \left\{ c\leq 2b,\delta \left( p_{0}\right)
\leq 0\right\} $. Applying the same technique as the sufficiency of Part 1,
we easily prove that $\xi _{n}\leq 0$ for all $n\in \mathbb{N}$, which
implies $g_{p_{0}}\left( x\right) =\sum_{n=0}^{\infty }\xi _{n}\left(
p_{0}\right) x^{n}\leq 0$ for $x\in \left( 0,1\right) $. It is deduced from ( 
\ref{dfp}) that the function $f_{p_{0}}$ is decreasing on $\left( 0,1\right)
$.

\textbf{Part 4}: If $c\leq 2b$ and $a-b+c>p_{0}$, that is, $\left(
a,b,c\right) \in \left\{ c\leq 2b,\delta \left( p_{0}\right) >0\right\} $.
Then by Lemma \ref{L-sgngn-p0}, there is an $n_{1}\geq 1$ such that $\gamma
_{n}\leq 0$ for $1\leq n\leq n_{1}$ and $\gamma _{n}>0$ for $n\geq n_{1}+1$.
By the relation (\ref{xin+1-n-n-1-e-1}), we have 
\begin{equation*}
\eta _{n+1}-\lambda _{n}\eta _{n}=\tau _{n}\gamma _{n}u_{n-1}\left\{
\begin{array}{cc}
\leq 0 & \text{ if }1\leq n\leq n_{1}, \\
>0 & \text{if }n\geq n_{1}+1. 
\end{array} 
\right.
\end{equation*} 
In a similar way as Part 2, we can prove that the sequence $\left\{ \xi
_{n}\right\} _{n\geq 0}$ is an NP-type sequence, and therefore, $ 
g_{p_{0}}\left( x\right) =\sum_{n=0}^{\infty }\xi _{n}\left( p_{0}\right)
x^{n}$ is an NP-type power series. Note that $g_{p_{0}}\left( 1\right)
=\infty $ due to Lemma \ref{L-gp(1)} (i). By Proposition \ref{P-sgnS}, there
is an $x_{0}\in \left( 0,1\right) $ such that $g_{p_{0}}\left( x\right) <0$
for $x\in \left( 0,x_{0}\right) $ and $g_{p_{0}}\left( x\right) >0$ for $ 
x\in \left( x_{0},1\right) $. This, by (\ref{dfp}), shows that function $ 
f_{p_{0}}$ is decreasing on $\left( 0,x_{0}\right) $ and increasing on $ 
\left( x_{0},1\right) $. Consequently, the inequality (\ref{Pm<Hm-p0}) holds
for $x\in \left( 0,1\right) $.

This completes the proof.
