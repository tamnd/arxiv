\label{conj:disjoint}
For every $n\ge1$, the rows $R_{2n-1}$ and $R_{2n}$ are disjoint.
<!-- end conjecture-1 -->
<!-- conjecture-2: body_md -->
\label{conj:strong}
For every $n\ge1$, if the numbers in rows $2n-1$ and $2n$ are arranged together in increasing order and each number is replaced by its position in this ordering, then the two resulting rows are rows $1$ and $2$.
<!-- end conjecture-2 -->

<!-- lemma-1: body_md -->
\label{lem:member}
Let $\alpha>1$ be irrational and $N\ge1$ an integer. Then $N\in B(\alpha)$ if and only if $\left\{ N/\alpha\right\}>1-1/\alpha$.
Moreover, if $\alpha\ge N+1$ then $N\notin B(\alpha)$.
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
$N=\left\lfloor k\alpha\right\rfloor$ if and only if $N/\alpha<k<(N+1)/\alpha$.
The open interval $(N/\alpha,(N+1)/\alpha)$ has length $1/\alpha<1$ and irrational endpoints, so it contains an integer exactly when the least integer above $N/\alpha$, which is $N/\alpha+1-\left\{ N/\alpha\right\}$, is less than $(N+1)/\alpha$, that is, when $\left\{ N/\alpha\right\}>1-1/\alpha$.
If $\alpha\ge N+1$ then $\left\lfloor k\alpha\right\rfloor\ge\left\lfloor \alpha\right\rfloor\ge N+1$ for all $k\ge1$.
<!-- end proof-1 -->
<!-- lemma-2: body_md -->
\label{lem:dioph}
For every integer $q\ge1$ we have $\left\| q\varphi\right\|>1/(3q)$.
Consequently, for integers $K\ge1$ and $i\ge1$, $\left\| K\varphi^{-i}\right\|>1/(3KF_i)$.
<!-- end lemma-2 -->
<!-- proof-2: body_md -->
Let $p$ be the integer nearest to $q\varphi$, so $p\ge1$.
Then $(p-q\varphi)(p-q\psi)=p^2-pq-q^2$ is an integer, and it is nonzero because $p/q$ is rational while $\varphi,\psi$ are not.
Hence $\left\| q\varphi\right\|=|p-q\varphi|\ge 1/|p-q\psi|=1/(p+q/\varphi)$.
Since $p\le q\varphi+\tfrac12$, we get $p+q/\varphi\le q(\varphi+\varphi^{-1})+\tfrac12=q\sqrt5+\tfrac12<3q$.
For the second statement, by~\eqref{eq:phineg} we have $K\varphi^{-i}\equiv \pm KF_i\varphi\pmod 1$, so $\left\| K\varphi^{-i}\right\|=\left\| KF_i\varphi\right\|>1/(3KF_i)$.
<!-- end proof-2 -->
<!-- theorem-1: body_md -->
\label{thm:SB}
Let $\alpha,\beta>1$ be irrational. Then $B(\alpha)\cap B(\beta)=\emptyset$ if and only if there are positive integers $r,s$ with $r/\alpha+s/\beta=1$.
<!-- end theorem-1 -->
<!-- theorem-2: body_md -->
\label{thm:pairs}
Let $1\le i<j$ and $d=j-i$. Then $R_i\cap R_j=\emptyset$ if and only if $d$ is odd and $d\mid i$.
<!-- end theorem-2 -->
<!-- proof-3: body_md -->
By Theorem~\ref{thm:SB}, $R_i\cap R_j=\emptyset$ if and only if $r\varphi^{-i}+s\varphi^{-j}=1$ for some positive integers $r,s$, that is, $r\varphi^{d}+s=\varphi^{j}$.
By~\eqref{eq:phipow} and the linear independence of $1,\varphi$ over $\mathbb{Q}$, this is equivalent to
\[
rF_d=F_j,\qquad rF_{d-1}+s=F_{j-1}.
\]
Thus $r=F_j/F_d$, and by d'Ocagne's identity with $(m,n)=(j-1,d-1)$,
\[
s=\frac{F_dF_{j-1}-F_jF_{d-1}}{F_d}=\frac{(-1)^{d-1}F_{j-d}}{F_d}=(-1)^{d-1}\frac{F_i}{F_d}.
\]
So positive integers $r,s$ exist if and only if $F_d\mid F_j$, $F_d\mid F_i$, and $d$ is odd.
Since $F_j=F_{i+d}=F_iF_{d+1}+F_{i-1}F_d$, the condition $F_d\mid F_i$ already implies $F_d\mid F_j$.
Finally, for odd $d$ we have $F_d\mid F_i\iff d\mid i$.
This is trivial for $d=1$.
For $d\ge3$, strong divisibility gives $F_d\mid F_i\iff F_{\gcd(d,i)}=F_d$, and since $F_g<F_d$ for $1\le g<d$ when $d\ge3$, this holds if and only if $\gcd(d,i)=d$.
<!-- end proof-3 -->
<!-- corollary-1: body_md -->
\label{cor:kimberling}
For every $m\ge1$:
\begin{enumerate}
\item $R_m\cap R_{m+1}=\emptyset$. In particular Conjecture~\ref{conj:disjoint} holds.
\item For all $k,j\ge1$, $\left\lfloor k\varphi^m\right\rfloor<\left\lfloor j\varphi^{m+1}\right\rfloor$ if and only if $\left\lfloor k\varphi\right\rfloor<\left\lfloor j\varphi^2\right\rfloor$.
Consequently, when $R_m\cup R_{m+1}$ is listed in increasing order, the element $\left\lfloor k\varphi^m\right\rfloor$ has position $\left\lfloor k\varphi\right\rfloor$ and the element $\left\lfloor j\varphi^{m+1}\right\rfloor$ has position $\left\lfloor j\varphi^2\right\rfloor$. In particular Conjecture~\ref{conj:strong} holds.
\end{enumerate}
<!-- end corollary-1 -->
<!-- proof-4: body_md -->
(1) is the case $d=1$ of Theorem~\ref{thm:pairs}.
(Directly: $F_{m+1}/\varphi^m+F_m/\varphi^{m+1}=(F_{m+1}\varphi+F_m)/\varphi^{m+1}=1$ by~\eqref{eq:phipow}, so $B(\varphi^m/F_{m+1})$ and $B(\varphi^{m+1}/F_m)$ are complementary, which is Theorem~2.2 of Russo and Schwiebert~\cite{russo}; these two sets contain $R_m$ and $R_{m+1}$, respectively.)

(2) If $k\varphi^m<j\varphi^{m+1}$ then $\left\lfloor k\varphi^m\right\rfloor\le\left\lfloor j\varphi^{m+1}\right\rfloor$, and equality is impossible by (1).
The same holds with the inequality reversed, and $k\varphi^m\neq j\varphi^{m+1}$ since $\varphi$ is irrational.

Now the position of $\left\lfloor k\varphi^m\right\rfloor$ in $R_m\cup R_{m+1}$ is
\[
k+\#\{j\ge1: j\varphi<k\}=k+\left\lfloor k/\varphi\right\rfloor=\left\lfloor k+k/\varphi\right\rfloor=\left\lfloor k\varphi\right\rfloor,
\]
using $\varphi=1+1/\varphi$.
Likewise the position of $\left\lfloor j\varphi^{m+1}\right\rfloor$ is $j+\#\{k\ge1:k<j\varphi\}=j+\left\lfloor j\varphi\right\rfloor=\left\lfloor j\varphi^2\right\rfloor$.

<!-- proposition-1: body_md -->
\label{prop:lucas}
Let $m\ge3$ be odd. Then
\[
\mathcal{M}(L_m)=\{\,i \text{ odd}: 1\le i\le (m-1)/2\,\}\cup\{m\},
\]
and hence $a(L_m)=\left\lfloor (m+1)/4\right\rfloor+1$. In particular $a(L_{4v-5})=v$ for every $v\ge2$.
<!-- end proposition-1 -->
<!-- proof-5: body_md -->
Since $m$ is odd, $L_m=\varphi^m-\varphi^{-m}$ by~\eqref{eq:lucas}, so $L_m\varphi^{-i}=\varphi^{m-i}-\varphi^{-m-i}$ for every $i\ge1$.
We apply~\eqref{eq:rowcrit} to each $i$.

\emph{Case $i=m$.} $L_m\varphi^{-m}=1-\varphi^{-2m}$, whose fractional part $1-\varphi^{-2m}$ exceeds $1-\varphi^{-m}$. So $m\in\mathcal{M}(L_m)$.

\emph{Case $i>m$.} $0<L_m\varphi^{-i}<\varphi^{-1}$. Since $i\ge4$, we have $1-\varphi^{-i}>1-\varphi^{-2}=\varphi^{-1}$, so $i\notin\mathcal{M}(L_m)$.

\emph{Case $i<m$, $i$ even.} Then $m-i$ is odd, and~\eqref{eq:lucas2} gives $\varphi^{m-i}=L_{m-i}+\varphi^{i-m}$. So $\left\{ L_m\varphi^{-i}\right\}=\varphi^{i-m}-\varphi^{-m-i}$, which lies in $(0,1)$ and is less than $\varphi^{-1}$. Since $1-\varphi^{-i}\ge 1-\varphi^{-2}=\varphi^{-1}$, we get $i\notin\mathcal{M}(L_m)$.

\emph{Case $i<m$, $i$ odd.} Then $m-i\ge2$ is even, and $\varphi^{m-i}=L_{m-i}-\varphi^{i-m}$. So
\[
\left\{ L_m\varphi^{-i}\right\}=1-\varphi^{i-m}-\varphi^{-m-i},
\]
because $0<\varphi^{i-m}+\varphi^{-m-i}\le\varphi^{-2}+\varphi^{-4}<1$.
By~\eqref{eq:rowcrit}, $i\in\mathcal{M}(L_m)$ if and only if $\varphi^{i-m}+\varphi^{-m-i}<\varphi^{-i}$, that is, $\varphi^{2i-m}+\varphi^{-m}<1$.
Here $2i-m$ is odd.
If $2i-m\le-1$, then $\varphi^{2i-m}+\varphi^{-m}\le\varphi^{-1}+\varphi^{-3}<1$.
If $2i-m\ge1$, then $\varphi^{2i-m}>1$.
So $i\in\mathcal{M}(L_m)$ if and only if $i\le(m-1)/2$.

The number of odd $i$ with $1\le i\le (m-1)/2$ is $\left\lfloor (m+1)/4\right\rfloor$.
For $m=4v-5$ this is $v-1$, so $a(L_{4v-5})=v$.
<!-- end proof-5 -->
<!-- lemma-3: body_md -->
\label{lem:shift}
Let $N\ge1$ be such that $N+1\ne L_{2e}$ for every $e\ge1$.
Put $R=\left\lfloor \log_\varphi(N+1)\right\rfloor+3$ and let $b$ be an even integer with
\begin{equation}\label{eq:bcond}
b\ge 2R\qquad\text{and}\qquad 6(N+1)\varphi^{2R-1-b}<1.
\end{equation}
Then $\mathcal{M}(N+L_b)=\mathcal{M}(N)$.
<!-- end lemma-3 -->
<!-- proof-6: body_md -->
Write $M=N+L_b$.
Since $b$ is even, $L_b=\varphi^b+\varphi^{-b}$, so
\begin{equation}\label{eq:Mexp}
M\varphi^{-i}=N\varphi^{-i}+\varphi^{b-i}+\varphi^{-b-i}\qquad(i\ge1).
\end{equation}
For $1\le i\le b$, identity~\eqref{eq:lucas2} with $n=b-i$ and $(-1)^{b-i}=(-1)^i$ gives $\varphi^{b-i}=L_{b-i}-(-1)^i\varphi^{i-b}$. Hence
\begin{equation}\label{eq:delta}
M\varphi^{-i}\equiv N\varphi^{-i}+\delta_i\pmod 1,\qquad \delta_i:=-(-1)^i\varphi^{i-b}+\varphi^{-b-i},
\end{equation}
with $|\delta_i|<2\varphi^{i-b}$.
We compare $\mathcal{M}(M)$ with $\mathcal{M}(N)$ in three ranges of $i$.

\emph{(A) $1\le i\le R$.}
By~\eqref{eq:rowcrit}, $N\in R_i$ iff the point $N\varphi^{-i}$ of $\mathbb{R}/\mathbb{Z}$ lies in the open arc $(-\varphi^{-i},0)$, and $M\in R_i$ iff $N\varphi^{-i}+\delta_i$ does.
The distances from $N\varphi^{-i}$ to the endpoints $0$ and $-\varphi^{-i}$ of this arc are $\left\| N\varphi^{-i}\right\|$ and $\left\| (N+1)\varphi^{-i}\right\|$.
By Lemma~\ref{lem:dioph}, both exceed $1/(3(N+1)F_i)$.
Since $F_i\le\varphi^{i-1}$ and $i\le R$, condition~\eqref{eq:bcond} gives
\[
|\delta_i|<2\varphi^{i-b}\le\frac{1}{3(N+1)F_i}\cdot 6(N+1)\varphi^{2i-1-b}<\frac{1}{3(N+1)F_i}.
\]
So adding $\delta_i$ does not move the point across an endpoint of the arc, and $i\in\mathcal{M}(M)\iff i\in\mathcal{M}(N)$.

\emph{(B) $R<i\le b$.}
Here $\varphi^i\ge\varphi^{R+1}>\varphi^{\log_\varphi(N+1)+3}=\varphi^3(N+1)>N+1$, so $i\notin\mathcal{M}(N)$, and moreover $(N+1)\varphi^{-i}<\varphi^{-3}$.
Put $y=N\varphi^{-i}+\delta_i$; by~\eqref{eq:delta}, $\left\{ M\varphi^{-i}\right\}=\left\{ y\right\}$.

If $i$ is odd then $i\le b-1$, so $0<y=N\varphi^{-i}+\varphi^{i-b}+\varphi^{-b-i}$ with $\varphi^{i-b}\le\varphi^{-1}$.
Adding $\varphi^{-i}$ gives $y+\varphi^{-i}\le(N+1)\varphi^{-i}+\varphi^{-1}+\varphi^{-b-i}<\varphi^{-3}+\varphi^{-1}+\varphi^{-4}=1$, so $\left\{ y\right\}=y<1-\varphi^{-i}$ and $i\notin\mathcal{M}(M)$.

If $i$ is even then $y=N\varphi^{-i}-\varphi^{i-b}+\varphi^{-b-i}$.
If $y\ge0$, then $y+\varphi^{-i}\le (N+1)\varphi^{-i}+\varphi^{-b-i}<\varphi^{-3}+\varphi^{-4}<1$, so $i\notin\mathcal{M}(M)$.
If $y<0$, then $y>-\varphi^{i-b}\ge-1$, so $\left\{ y\right\}=1+y$, so $i\in\mathcal{M}(M)$ iff $y>-\varphi^{-i}$.
Multiplying the two conditions $y<0$ and $y>-\varphi^{-i}$ by $\varphi^i$ shows that $i\in\mathcal{M}(M)$ iff
\begin{equation}\label{eq:window}
N+\varphi^{-b}<\varphi^{2i-b}<N+1+\varphi^{-b}.
\end{equation}
Put $2e=2i-b$, an even integer with $2e\le b$.
If $e\le0$, then $\varphi^{2e}\le1\le N$, so~\eqref{eq:window} fails.
If $e\ge1$, then $\varphi^{2e}=L_{2e}-\varphi^{-2e}$ by~\eqref{eq:lucas2}, and $\varphi^{-2e}\ge\varphi^{-b}$.
The left inequality of~\eqref{eq:window} gives $L_{2e}>N+\varphi^{-b}+\varphi^{-2e}>N$, so $L_{2e}\ge N+1$.
The right inequality gives $L_{2e}<N+1+\varphi^{-b}+\varphi^{-2e}\le N+1+2\varphi^{-2}<N+2$, so $L_{2e}\le N+1$.
Thus~\eqref{eq:window} forces $L_{2e}=N+1$, which is excluded by hypothesis.
So $i\notin\mathcal{M}(M)$.

\emph{(C) $i>b$.}
By~\eqref{eq:Mexp}, $0<M\varphi^{-i}\le N\varphi^{-b-1}+\varphi^{-1}+\varphi^{-2b-1}$.
Since $b\ge2R\ge R+3$ we have $(N+1)\varphi^{-b-1}<\varphi^{-3}$, and hence $M\varphi^{-i}+\varphi^{-i}\le(N+1)\varphi^{-b-1}+\varphi^{-1}+\varphi^{-2b-1}<\varphi^{-3}+\varphi^{-1}+\varphi^{-4}=1$.
So $\left\{ M\varphi^{-i}\right\}=M\varphi^{-i}<1-\varphi^{-i}$ and $i\notin\mathcal{M}(M)$.
Also $i\notin\mathcal{M}(N)$, since $\varphi^i>\varphi^R>N+1$.

Combining (A), (B) and (C) gives $\mathcal{M}(M)=\mathcal{M}(N)$.

<!-- theorem-4: body_md -->
\label{thm:occ}
For every $v\ge1$ there are infinitely many $N\ge1$ with $a(N)=v$. Hence Conjecture~\ref{conj:occ} is true.
<!-- end theorem-4 -->
<!-- proof-7: body_md -->
For $v=1$ take $N_1=1$.
Since $1=\left\lfloor \varphi\right\rfloor$ and $\varphi^m\ge\varphi^2>2$ for $m\ge2$, Lemma~\ref{lem:member} gives $\mathcal{M}(1)=\{1\}$.
Also $N_1+1=2=L_0$ is not of the form $L_{2e}$ with $e\ge1$.
For $v\ge2$ take $N_v=L_{4v-5}$.
Then $a(N_v)=v$ by Proposition~\ref{prop:lucas}.
Moreover $N_v+1$ is not a Lucas number: for $m\ge3$ we have $L_m<L_m+1<L_m+L_{m-1}=L_{m+1}$ because $L_{m-1}\ge3$.
In both cases Lemma~\ref{lem:shift} applies to $N_v$, and the numbers $N_v+L_b$, for all sufficiently large even $b$, form an infinite set of integers with exactly $v$ occurrences.

<!-- proposition-2: body_md -->
\label{prop:density}
For every $v\ge1$, the set $\{N:a(N)=v\}$ has natural density $d_v=\lambda(\{x\in[0,1):A(x)=v\})$, and $d_v>0$.
<!-- end proposition-2 -->
<!-- proof-8: body_md -->
By~\eqref{eq:phineg}, $N\varphi^{-m}\equiv(-1)^{m+1}F_mN\varphi\pmod 1$.
So by~\eqref{eq:rowcrit}, $N\in R_m$ if and only if $x_N:=\left\{ N\varphi\right\}\in S_m$, and hence $a(N)=A(x_N)$.

\emph{Existence.} The set $\{x:A_M(x)=v\}$ is a finite union of intervals, so by Weyl's theorem the set $\{N:A_M(x_N)=v\}$ has density $\lambda(\{A_M=v\})$.
If $a(N)\ne A_M(x_N)$ then $N\in R_m$ for some $m>M$, and $\#(R_m\cap[1,X])\le(X+1)\varphi^{-m}$, so
\[
\#\{N\le X:a(N)\ne A_M(x_N)\}\le(X+1)\sum_{m>M}\varphi^{-m}=(X+1)\varphi^{1-M}.
\]
Similarly $\lambda(\{A_M\ne A\})\le\sum_{m>M}\lambda(S_m)=\varphi^{1-M}$.
Hence the upper and lower densities of $\{N:a(N)=v\}$ differ from $d_v$ by at most $2\varphi^{1-M}$, for every $M$.

\emph{Positivity.} Fix $N\ge2$ with $a(N)=v$: take $N=2$ if $v=1$ (here $\mathcal{M}(2)=\{2\}$), and $N=L_{4v-5}$ if $v\ge2$ (Proposition~\ref{prop:lucas}).
Put $R=\left\lfloor \log_\varphi(N+1)\right\rfloor+3$ and $\delta=1/(3(N+1)F_R^2)$, and let $W$ be the open arc of $\mathbb{R}/\mathbb{Z}$ of length $2\delta$ centred at $x_N$.
Let $x\in W$.
For $m\le R$, the point $(-1)^{m+1}F_mx$ differs from $N\varphi^{-m}$ modulo~$1$ by less than $F_m\delta\le1/(3(N+1)F_m)$, so, exactly as in step~(A) of the proof of Lemma~\ref{lem:shift}, $x\in S_m$ if and only if $x_N\in S_m$.
Since $\mathcal{M}(N)\subseteq\{m:\varphi^m<N+1\}\subseteq[1,R]$, this gives $A_R(x)=a(N)=v$.
Now let $m>R$, so that $0<N\varphi^{-m}<(N+1)\varphi^{-m}<\varphi^{-3}$.
If $F_m\delta\le N\varphi^{-m}$, then modulo~$1$ the point $(-1)^{m+1}F_mx$ lies in $(0,2N\varphi^{-m})\subseteq(0,1-\varphi^{-m})$, so $x\notin S_m$.
Since $F_m\varphi^m$ increases with $m$, the other $m>R$ are exactly those with $m\ge m_0$, for some $m_0>R$, and for them the periodicity of $S_m$ gives $\lambda(W\cap S_m)\le(2\delta+1/F_m)\varphi^{-m}$.
Using $\varphi^{m-2}\le F_m\le\varphi^{m-1}$, $m_0\ge R+1\ge6$ and $N\varphi^{-m_0}<F_{m_0}\delta\le\varphi^{m_0-1}\delta$, we get
\[
\sum_{m\ge m_0}\lambda(W\cap S_m)\le2\delta\varphi^{2-m_0}+\varphi^{3-2m_0}<2\varphi^{-3}\delta+\varphi^{2}\delta/N.
\]
As $A=v$ on $W\setminus\bigcup_{m\ge m_0}S_m$, we obtain $d_v\ge(2-2\varphi^{-3}-\varphi^2/N)\delta>0$, because $N\ge2$ and $2\varphi^{-3}+\varphi^2/2<1.79$.
