<!-- defn-1: body_md -->
\label{L1}
Let $\mathcal L_{\operatorname{type}}(T)=\mathcal L\cup\left\{\operatorname*{\bigwedge\mkern-15mu\bigwedge}_{\varphi(\overline x)\in p(\overline x)}\varphi(\overline x)\mid p(\overline x)\in S_n(T),n\in\omega\right\}$ be the language obtained from $\mathcal L$ by adding all the complete types over $T$ as additional predicates.

Let $\mathcal L_1(T)$ be the first-order closure of $\mathcal L_{\operatorname{type}}(T)$, i.e. the smallest fragment of $\mathcal L_{\omega_1\omega}$ containing $\mathcal L_{\operatorname{type}}(T)$ (closed under $\wedge, \neg$, and universal quantification).
<!-- end defn-1 -->
<!-- conj-1: body_md -->
\label{martin}
Suppose $T$ has fewer than $2^{\aleph_0}$ countable models. Then the $\mathcal L_1(T)$-theory of any $\mathcal M\vDash T$ is ${\aleph_0}$-categorical.
<!-- end conj-1 -->
<!-- rmk-1: body_md -->
To obtain a Scott sentence we need to take an infinite conjunction over the $\mathcal L_1(T)$-theory, which would then be $\Pi^{\mathrm{in}}_{\omega+\omega}$ over the base theory.
<!-- end rmk-1 -->
<!-- defn-2: body_md -->
The \emph{Vaught ordinal} of $T$, $vo(T)$, is the least $\beta$ such that:
\begin{itemize}
  \item If $T$ has countably many countable models, then all of them have Scott rank $<\beta$.
  \item If $T$ has uncountably many countable models, then there are uncountably many of them which are not $\Pi^{\mathrm{in}}_\beta$-equivalent to each other.
\end{itemize}
<!-- end defn-2 -->
<!-- rmk-2: body_md -->
The conjecture we are about to state bounds the Vaught ordinal above by some limit ordinal. As a result, it mostly does not matter which notion of Scott rank we use, since most variants differ only by a finite amount. For example, we can replace ``have Scott rank $<\beta$'' above by ``have a $\Pi^{\mathrm{in}}_\beta$ Scott sentence,'' or use the robuster notion of Scott rank of Montalb\'an \cite{robusterSR}.
<!-- end rmk-2 -->
<!-- conj-2: body_md -->
\label{wVC}
For a limit ordinal $\alpha$, say $T$ satisfies the \emph{$\alpha$-Vaught's conjecture} if for every $\beta<\omega_1$ such that $T$ is equivalent to a $\Pi^{\mathrm{in}}_\beta$-sentence, we have $vo(T)\le\beta+\alpha$.
<!-- end conj-2 -->
<!-- rmk-3: body_md -->
This version differs slightly from the original formulation of $\omega$-Vaught's conjecture, which requires both $T$ and all (infinitary) sentences that imply $T$ to satisfy the bound on the Vaught ordinal. As we work with only first-order theories, where the only consistent theory that can imply a complete theory $T$ is $T$ itself, this statement should be sensible to make.
<!-- end rmk-3 -->
<!-- defn-3: body_md -->
Let $\mathcal L_1^{\text{in}}(T)$ be set of $\Pi^{\mathrm{in}}_{<\omega}$-sentences over $\mathcal L_{\operatorname{type}}(T)$ (equivalently over $\mathcal L_1(T)$), where $\Pi^{\mathrm{in}}_{<\omega}=\bigcup_{n<\omega}\Pi^{\mathrm{in}}_{n}$.
<!-- end defn-3 -->
<!-- rmk-4: body_md -->
\begin{itemize}
  \item $\mathcal L_1(T)\subseteq\mathcal L_1^{\text{in}}(T)$.
  \item $\mathcal L_1(T)$ and $\mathcal L_1^{\text{in}}(T)$ have the same complexity: If all types over $T$ are $\forall_n$-axiomatizable for some $n$, then $\mathcal L_1(T)$ and $\mathcal L_1^{\text{in}}(T)$ are both subsets of $\Pi^{\mathrm{in}}_{<\omega}$; otherwise, in general both will contain strictly $\Pi^{\mathrm{in}}_\omega$-sentences, but are still subsets of $\Pi^{\mathrm{in}}_{<\omega+\omega}$.
\end{itemize}
<!-- end rmk-4 -->
<!-- conj-3: body_md -->
\label{twVC}
For any complete first-order theory $T$:
\begin{itemize}
  \item If $T$ has countably many countable models, then any countable $\mathcal M\vDash T$ has a Scott sentence in $\mathcal L_1^{\mathrm{in}}(T)$.
  \item If $T$ has uncountably many countable models, then there are $2^{\aleph_0}$ countable models of $T$ which are pairwise not $\mathcal L_1^{\mathrm{in}}(T)$-equivalent.
\end{itemize}
<!-- end conj-3 -->
<!-- rmk-5: body_md -->
\label{wVCcomparison}
The Type $\omega$-Vaught's conjecture for $T$ implies the $(\omega+\omega)$-Vaught's conjecture for $T$. If in addition that either every type over $T$ is \emph{boundedly axiomatizable} (i.e. $\forall_n$-axiomatizable for some $n\in\omega$) or $T$ is not boundedly axiomatizable, then it actually implies the $\omega$-Vaught's conjecture for $T$.
<!-- end rmk-5 -->
<!-- notn-1: body_md -->
When $T$ is obvious from context, we will abbreviate $\mathcal L_1(T)$ as just $\mathcal L_1$, and similarly for $\mathcal L_1^{\mathrm{in}}$ and $\mathcal L_{\operatorname{type}}$.
<!-- end notn-1 -->
<!-- thm-1: body_md -->
\label{main}
The Type $\omega$-Vaught's conjecture holds for any complete $\omega$-stable theory $T$. In fact, we obtain uniform bounds on the quantifier complexity:
\begin{itemize}
  \item If $T$ has countably many countable models, then any countable $\mathcal M\vDash T$ has a $\operatorname{d-\Sigma^{\mathrm{in}}_4}(\mathcal L_{\operatorname{type}})$ Scott sentence.
  \item If $T$ has uncountably many countable models, then there are $2^{\aleph_0}$ countable models of $T$ which are pairwise not $\Pi^{\mathrm{in}}_6(\mathcal L_{\operatorname{type}})$-equivalent.
\end{itemize}
<!-- end thm-1 -->
<!-- cor-1: body_md -->
\label{wVCbound}
  The $(\omega+6)$-Vaught's conjecture holds for all complete $\omega$-stable theories.
<!-- end cor-1 -->
<!-- prop-1: body_md -->
\label{indep}
For any type $p\in S_n(T)$. There is a quantifier-free $\mathcal L_{type}$-formula $Indep_{p}(\overline x,\overline y,\overline z)$ (technically, a different formula for each $n$ and each arity of $\overline z$) such that for any $\mathcal M\vDash T$ and $n$-tuples $\overline a,\overline b, \overline c$ in $\mathcal M$ with matching arities:

$\mathcal M\vDash Indep_{p}(\overline a,\overline b,\overline c)\iff(\operatorname{tp}(\overline {ab})=p)\wedge(\overline c\mathrel{\raise0.2ex\hbox{\ooalign{\hidewidth$\vert$\hidewidth\cr\raise-0.9ex\hbox{$\smile$}}}}_{\overline a}\overline b)$.
<!-- end prop-1 -->
<!-- proof-1: body_md -->
The theory is $\omega$-stable, thus has finite multiplicity, so in particular there are only finitely many nonforking extensions of any type to any (finite) set. Thus, independence can be phrased as $\overline{zy}$ realizing any of the finitely many nonforking extensions of $\operatorname{tp}(\overline y/\overline x)$ (which can be found from $p$), which is just a disjunction of finitely many predicates and thus quantifier-free expressible in $\mathcal L_{type}$.
<!-- end proof-1 -->
<!-- prop-2: body_md -->
\label{dim}
Fix $l<\omega$. Let $r\in S_n(T)$. Let $p$ be a type over a finite set (of size $n$) realizing $r$. Let $s\in\omega+1$. Then there is an $\mathcal L_1^{\mathrm{in}}(T)$ formula $\psi_{r,p,s}(\overline x)$ such that for any $\mathcal M\vDash T$ and tuple $\overline m$ in $\mathcal M$ matching the arity of $r$:

$\mathcal M\vDash \psi_{r,p,s}(\overline m)\iff\operatorname{tp}(\overline m)=r\wedge\dim(p_{\overline m},\mathcal M)=s$.

The complexity of $\psi_{r,p,s}$ is as follows:
    \begin{itemize}
      \item In general, $\psi_{r,p,s}$ can be taken to be $\Pi^{\mathrm{in}}_2$ over $\mathcal L_{type}$.
      \item If $s<\omega$, then $\psi_{r,p,s}$ can be taken to be $d\mhyph\exists_1$ over $\mathcal L_{type}$.
    \end{itemize}
<!-- end prop-2 -->
<!-- proof-2: body_md -->
Note that the first claim follows from the second: If $s=\omega$, then we can simply use the formula that says $r(\overline x)\wedge(\operatorname*{\bigwedge\mkern-15mu\bigwedge}_{s\in\omega}\neg\psi_{r,p,s})$, which is now $\Pi^{\mathrm{in}}_2$ over $\mathcal L_{type}$ (and thus in $\mathcal L_1^{\mathrm{in}}(T)$).

  For the second claim, assume $s\in\omega$. The construction follows immediately from the ``first remark'' in \cite[Proposition 4]{Bouscaren}.\footnote{It should be noted that while in that proposition Bouscaren claims $\psi_{r,p,s}$ can be written in $\mathcal L_1(T)$ even for $s=\omega$, that uses the assumption of $T$ having countably many models. However, the remark for $s\in\omega$ does not use this assumption.}
  To be more explicit: The first part that says $\overline x$ realizes $r$ is quantifier-free because $r(\overline x)$ is in the language $\mathcal L_{type}$. The second part just says there are $s$ (but not $s+1$) realizations of $p_{\overline m}$ which are independent. Saying $\overline y$ realizes $p_{\overline x}$ is expressible by $q(\overline y,\overline x)$ where $q$ is the type of $\overline aA$ with $\overline a$ any realization of $p$ and $A$ the base of $p$. (Note again that $q$ is in the language so this is quantifier-free.)
  At last it remains to express a tuple of variable (realizing the same type $p$) being independent, but we can just apply \autoref{indep}. Hence $\psi_{r,p,\omega}$ is $d\mhyph\exists_1$ over $\mathcal L_{type}$. This establishes the second claim.
<!-- end proof-2 -->
<!-- rmk-6: body_md -->
It is crucial in the above propositions that the formulas depend on the types of the free variables. This allows us to know (non-uniformly) the finitely many nonforking types, reducing the complexity of the independence relation down. The story would be different if we were to give formulas uniformly.
<!-- end rmk-6 -->
<!-- thm-2: body_md -->
Every countable model of $T$ has a Scott sentence that is $\Sigma^{\mathrm{in}}_5$ over $\mathcal L_{\operatorname{type}}$.
<!-- end thm-2 -->
<!-- proof-3: body_md -->
We use essentially the same Scott sentence as in \cite[Proposition 5]{Bouscaren}, but improve on the number of quantifiers required.. First of all, everything that follows depends on a fixed tuple $a^0$ of a given isolated type, which takes an (outermost) existential quantifier to pin down. The Scott sentence has four parts, defined using a given fixed tuple $d^0$ and finite sets of types $P=\left\{p^i\mid i<l\right\}$, $Q$, and $R$. Before we give the sentence, though, it is necessary to introduce another piece of notation from \cite{Bouscaren}:
   \begin{defn}
     $D(\overline m)=\overline u$ means the dimension of $p^i_{\overline m}$ is $s_i$ for all~$i$.
   \end{defn}
   The following result improves the na\"ive complexity of the formula $D(\overline m)=\overline s$, which is a priori $\Pi^{\mathrm{in}}_2$ over $\mathcal L_{\operatorname{type}}$ by \autoref{dim}.
   \begin{lem}\label{Ddimension}
     If $\operatorname{tp}(\overline m)=r$ is fixed, then $D(\overline m)=\overline s$ can be expressed as a formula (with $\overline m$ as the variables) that is $\forall_2$ over $\mathcal L_{\operatorname{type}}$ (in particular in $\mathcal L_1(T)$).
   \end{lem}
   \begin{proof}
     We use a related but slightly different method as in the proof of \cite[Proposition 4]{Bouscaren}. Given tuples $\overline u,\overline t\in(\omega+1)^l$, say $\overline u\sim_r\overline t$ if $D(\overline m)=\overline u, D(\overline n)=\overline t$ for some tuples $\overline m\not\mathrel{\raise0.2ex\hbox{\ooalign{\hidewidth$\vert$\hidewidth\cr\raise-0.9ex\hbox{$\smile$}}}}\overline n$. \cite[Proposition 2 and Lemma 6]{Bouscaren} shows that $\overline u\sim_r\overline t$ implies $\overline u$ and $\overline t$ have the same number of infinite coordinates, and \cite[Proposition 3]{Bouscaren} shows that there are only finitely many $\sim_r$-equivalence classes.

     Define $\overline u\lesssim\overline t$ as the following: for all $i$ such that $(\overline t)_i<\omega$, $(\overline u)_i=(\overline t)_i$. Note that if $\overline u\lesssim\overline t$, then $\overline u$ has at most the same number of infinite coordinates than that of $\overline t$. By \autoref{dim}, $D(\overline m)\lesssim\overline t$ is $d\mhyph\exists_1$ over $\mathcal L_{type}$.

     Now suppose $\overline s$ has $k$ infinite coordinates, and let $C_0,\ldots,C_N$ be all $\sim_r$-classes with fewer than $k$ infinite coordinates. Choose representatives $\overline n_i\in C_i$ with dimension $\overline t^i$, for all $i<N$. Now we claim the following formula expresses $D(\overline m)=\overline s$:
        \begin{itemize}
          \item $D(\overline m)\lesssim\overline s$; and
          \item ($\forall \overline n\not\mathrel{\raise0.2ex\hbox{\ooalign{\hidewidth$\vert$\hidewidth\cr\raise-0.9ex\hbox{$\smile$}}}}\overline m)\ D(\overline n)\not\lesssim\overline t_i$, for all $i<N$.
        \end{itemize}
     This formula is $\forall_2$ over $\mathcal L_{\operatorname{type}}$ by \autoref{dim} and \autoref{indep}. Clearly, if $D(\overline m)=\overline s$ then the formula is satisfied. Conversely, if the formula is true of $\overline m$ then $D(\overline m)$ cannot be in any of the classes $C_i$ (by the second part), so it has at least $k$ infinite coordinates. But the first part shows $D(\overline m)$ has at most $k$ infinite coordinates, and all the finite ones agree with $\overline s$. Hence $D(\overline m)=\overline s$.
   \end{proof}

  Now we are finally ready to begin describing the Scott sentence.
  \begin{itemize}
    \item The first part $\Phi_M$ describes the dimension of $q_{\overline d}$ in $\mathcal M$, where $q\in Q$ and $\overline d$ is any tuple of $\mathcal M$ with type $\operatorname{tp}(d^0)$.

        The complexity of this part is $\Pi^{\mathrm{in}}_2$ over $\mathcal L_{\operatorname{type}}$ by \autoref{dim}.
    \item The second part is a finite conjunction over $r\in R$ of sentences of the form $\theta^r(\overline s,\overline t)$, which says: There exists $\overline v,\overline w$ both with type $r$ that are dependent, such that $D(\overline v)=\overline s, D(\overline w)=\overline t$.

        The complexity of this part is $\exists_3$ over $\mathcal L_{\operatorname{type}}$ by \autoref{indep} and \autoref{Ddimension}.
    \item The third part is a finite conjunction over $r\in R$ of sentences of the form $\neg\theta^r(\overline s_i,\overline s_j)$.

        The complexity of this part is $\forall_3$ over $\mathcal L_{\operatorname{type}}$ by the same calculation as in the previous part.
    \item The last part is a finite conjunction over $r\in R$ of sentences expressing the cardinality of the set $r_{\overline s}(\mathcal M)$, which is a maximal independent set in $\mathcal M$ of tuples $\overline m$ realizing $r$ with $D(\overline m)=\overline s$.

        Saying $\overline m$ is a tuple realizing $r$ with $D(\overline m)=\overline s$ is $\forall_2$ over $\mathcal L_{\operatorname{type}}$, so expressing the dimension of $r_{\overline s}(\mathcal M)$ is $\Pi^{\mathrm{in}}_4$ over $\mathcal L_{\operatorname{type}}$ (by a computation similar to \autoref{dim}).
  \end{itemize}
  Combining everything, we get a $\Sigma^{\mathrm{in}}_5$ over $\mathcal L_{\operatorname{type}}$ Scott sentence.

<!-- thm-3: body_md -->
There exists an $\omega$-stable $T$ with countably many countable models and an $\mathcal M\vDash T$, such that $\mathcal M$ does not have a Scott sentence that is $\Sigma^{\mathrm{in}}_4$ over $\mathcal L_{\operatorname{type}}$.

<!-- proof-6: body_md -->
We take $T$ to be Shelah's theory with ENI-depth 2 but countably many models (see for example \cite[Chapter XVIII.4]{Baldwin}). We provide a relatively self-contained description of the theory here (following terminologies of \cite{Baldwin}), but those who are less detail-oriented should feel free to skip to the next paragraph. The (relational) language is $\left\{E,R,G\right\}\cup\left\{P_i\mid i\in\omega\right\}$, where each $P_i$ is unary, $E,R$ are binary, and $G$ is 5-ary. The first part of $T$ says $E$ is an equivalence relation, $R$ defines a directed acyclic graph on equivalence classes of $E$ (i.e. $R$ is $E$-invariant without loops), $G$ is symmetric in the second and third coordinates, and the $P_i$'s are pairwise disjoint and each intersects every $E$-class infinitely. Next, we say an element $a$ has \emph{order} $i$ if $P_i(a)$, or $\omega$ if it satisfies no $P_i$. The second part of the theory says for any $E$-classes $\alpha,\beta$ with $\alpha R \beta$, there exist unique $a\in\alpha, \left\{b,c\right\}\subseteq\beta$, such that $G(a,b,c,\cdot,\cdot)$ (equivalently $G(a,c,b,\cdot,\cdot)$) is nonempty; and whenever this is nonempty, it defines a \emph{proper link}, i.e. a bijection $\gamma_{\alpha,\beta}$ from $\alpha-\left\{a\right\}$ to $\beta-\left\{b,c\right\}$, interacting with order as follows: (1) If $a$ has infinite order then so do $b$ and $c$; (2) If $a$ has order $i<\omega$ then so does either $b$ or $c$; (3) If there is an $x$ with a different order than that of $\gamma_{\alpha,\beta}(x)$, then it is unique, with the order of $\gamma_{\alpha,\beta}(x)$ the same as that of $a$, and in this case the orders of $b,c$ needs to be different. The third and last part of the theory says for every $E$-class $\alpha$ and each $a\in\alpha$, there exist infinitely many $\beta$ properly linked to $\alpha$ via $a$ and some $\left\{b,c\right\}\subseteq\beta$; if $a$ has order $i<\omega$, then infinitely such $\beta$ exist with orders of $b,c$ equal to each other, and for each $d\in\alpha$ with order $j>i$ infinitely such $\beta$ exist with order of $b,c$ different and $\gamma_{\alpha,\beta}(d)$ having order $i$; Symmetrically, for every $E$-class $\beta$ and each $\left\{b,c\right\}\subseteq\beta$, there exist infinitely many $\alpha$ properly linked to $\beta$ via $\left\{b,c\right\}$ and some $a\in\alpha$; if $b$ has order $i<\omega$, then for each $c\in\beta$ with order at least $i$, and $e\in\beta$ with order $i$, neither equal to $b$, infinitely such $\alpha$ exist with orders of $a$ equal to $i$, and infinitely such $\beta$ exist with order of $a$ being $i$ and order of $\gamma^{-1}_{\alpha,\beta}(e)$ has order not equal to $i$. This concludes the description of the theory.

  The key takeaway of this theory is that each $\mathcal M\vDash T$ consists of ``connected components'' (of $R$), where each ``node'' is actually an equivalence class (of $E$), and each class $\alpha$ is characterized by the dimension of a certain type $q_\alpha$ (which describes an element of order $\omega$). Additionally, for each component $C$, the set of dimensions of $q_\alpha$ over $\alpha\in C$ can only be $\left\{0\right\}$, $\omega$, or $\left\{\omega\right\}$, which we name as Sort I, II, III components, respectively. The number of components of each sort determines a model of $T$ completely. Now, let $\mathcal M$ be the model where all three types of components appear infinitely often. It has a Scott sentence that is $\Pi^{\mathrm{in}}_4$ over $\mathcal L_{\operatorname{type}}$: just say each type of component appears infinitely many often.

  Now we show $\mathcal M$ does not have a $\Sigma^{\mathrm{in}}_4$ over $\mathcal L_{\operatorname{type}}$ Scott sentence. To do this, we work in the (infinitary) theory where all finitary quantifiers are eliminated (by Morleyization) and all types are added to the language (requiring type predicates behave as expected), and then show $\mathcal M$ does not have a $\Sigma^{\mathrm{in}}_4$ Scott sentence in this language. The construction is as follows.

  Suppose towards a contradiction that $\mathcal M$ has a $\Sigma^{\mathrm{in}}_4$ Scott sentence in this language. Take an oracle $X$ computing the Scott sentence, and let $\left\{\mathcal N_i\right\}_{i\in\omega}$ be an $X$-computable enumeration of all $X$-computable structures in the same language, and let $\left\{\mathcal R_i\right\}_{i\in\omega}$ be an $X$-computable enumeration of all $X$-computable equivalence structures. Consider the set $A^{X}=\left\{x\mid\mathcal R_x\text{ has infinitely many infinite classes}\right\}$, which is $\Pi^0_4(X)$-complete (see \cite[Proof of Theorem 4.6]{bfrsm}). We will show $\left\{i\mid\mathcal N_i\cong\mathcal M\right\}$ is $\Pi^0_4(X)$-hard (among models of $T$), contradicting the existence of an $X$-computable $\Sigma^{\mathrm{in}}_4$ Scott sentence. We do this by reducing $A^X$ to the given set, as follows: Let $f$ be the computable function such that $\mathcal N_{f(i)}$ is the following structure: We put in infinitely many Sort I,II components; Then for each $y$, we put a new component $C_y$, generated by a class $\alpha_y$. Whenever we see the $y$-th component of $\mathcal R_x$ gain a new element, we put in a new realization of $q_{\alpha_y}$ (and change all other classes in $C_y$ correspondingly). It is clear that we always build a model of $T$, and $\mathcal N_{f(i)}\cong\mathcal M$ if and only if $i\in A^X$.
