<!-- definition-1: body_md -->
Let $\xi_{{\cal A}}(\cdot)$ denote a Gaussian process at node ${\cal A}$ with covariance function $C_{\cal A}(\mathbf{x}, \mathbf{x}'):=\text{cov}\{\xi_{\cal A}(\mathbf{x}), \xi_{\cal A}(\mathbf{x}')\}$.
Fix a pre-specified knot set ${\cal R}_{\cal A}$ from the region ${\cal A}$. Define $f_{{\cal A}}(\cdot) := E[\xi_{{\cal A}}(\cdot) | \xi_{{\cal A}}({\cal R}_{{\cal A}})]$. At the root, define $\xi_{\cal A}=y$; at internal node ${\cal A}$, let $B$ be a child of ${\cal A}$, define $\xi_{{\cal B}}(\cdot):=\{\xi_{{\cal A}}(\mathbf{x}) - f_{{\cal A}}(\mathbf{x}): \mathbf{x} \in {\cal B}\}$. Let ${\cal A}_i,{\cal A}_j$ be two different child nodes of ${\cal A}$, assume $\text{cov}(\xi_{{\cal A}_i}(\mathbf{x}), \xi_{{\cal A}_j}(\mathbf{x}'))=0$. Then We call $\xi_{{\cal B}}(\cdot)$ a residual process at node ${\cal B}$.
<!-- end definition-1 -->
<!-- remark-1: body_md -->
This residual process construction starts at root where we assume $\xi_{\cal A}(\cdot) = y(\cdot)$ and then repeats recursively at each node down the tree until a maximum tree depth is reached. The covariance function of $\xi_{{\cal B}}(\cdot)$ is given by 
 $C_{{\cal B}}(\mathbf{x}, \mathbf{x}')=\{C_{{\cal A}}(\mathbf{x}, \mathbf{x}') - C_{{\cal A}}^*(\mathbf{x}, \mathbf{x}')\} \mathds{1}(\mathbf{x}, \mathbf{x}'\in {\cal B})$, where $C_{\cal A}^*(\mathbf{x}, \mathbf{x}'):=C_{\cal A}(\mathbf{x}, {\cal R}_{\cal A}) C_{\cal A}^{-1}({\cal R}_{\cal A}, {\cal R}_{\cal A}) C_{\cal A}({\cal R}_{\cal A}, \mathbf{x}')$ is the covariance function for $f_{\cal A}(\cdot)$ \citep{Banerjee2008}. 
 The resulting residual covariance is assumed to be blockwise independent given knots which is different from the \textit{full-scale} residual process $\xi_{\cal A}(\cdot)-f_{\cal A}(\cdot)$.
<!-- end remark-1 -->
<!-- theorem-1: body_md -->
\label{thm: orthogonal decomposition}
Let $\xi_0(\cdot) := y(\cdot)$ be any GP on a domain $\mathscr{D}\subset\mathbb{R}^d$. Fix any integer $k \in [1,n]$. Let ${\cal R}^i$ be a nonempty subset of ${\cal A}^i$ such that ${\cal A}^{i+1}:={\cal A}^{i} \setminus {\cal R}^{i}$ is recursively defined for $i=0,1, \ldots, k-1$. Given the knots ${\cal R}^i$, let $f_i(\cdot)$ be the predictive process of ${\xi}_i(\cdot)$ and  ${\xi}_{i+1}(\cdot):={\xi}_i(\cdot) - f_i(\cdot)$ be the full-scale residual process. It follows that the process $y(\cdot)$ admits the following decomposition
$
y(\mathbf{x}) = f_0(\mathbf{x}) + f_1(\mathbf{x}) + \cdots + f_{k-1}(\mathbf{x}) + \xi_{k}(\mathbf{x}), \mathbf{x}\in \mathscr{D},
$
where $f_0(\cdot), \ldots, f_{k-1}(\cdot), \xi_{k}(\cdot)$ are mutually independent. 
In addition, the sampling density has the following factorization
$
p(y({\cal A}^0)) = p(f_0({\cal R}^0)) \times p(f_1({\cal R}^1)) \times \cdots \times p(f_{k-1}({\cal R}^{k-1})) \times p(\xi_{k}({\cal A}^{k})).
$
<!-- end theorem-1 -->
<!-- remark-2: body_md -->
This orthogonal decomposition and the Vecchia approximations \citep{Datta2016, Katzfuss2017MRA} both use the device of predictive processes. One important distinction is that the orthogonal decomposition leads to exact computation and inference for GP modeling, while the Vecchia's approximations factor the joint density into the product of a collection of conditional densities, each of which is approximated by a small number of random variables in the conditioning set. While the above decomposition does not bring any computational benefit by itself, it will lead to efficient computation when coupled with tree-based modeling strategies (in particular the within-resolution blockwise independence assumptions) described in this paper.
<!-- end remark-2 -->
<!-- head-1: body_md -->
A simple choice is to consider the covariance function induced by the residual covariance. In particular, we can use a modified predictive process \citep{Finley2009} representation of the residual covariance function at leaf node as the baseline model so that the leaf model allows efficient computation based on residuals at that leaf. Let $C_{{\cal A}}$ denote the covariance function at leaf node ${\cal A}$. Given a set of knots ${\cal R}_{\cal A}$, the leaf model for $\delta_{\cal A}(\cdot)$ can be constructed: ${\delta}_{\cal A}(\mathbf{x}) :=  C_{{\cal A}}^\top({\cal R}_{\cal A}, \mathbf{x}) C_{{\cal A}}({\cal R}_{\cal A}, {\cal R}_{\cal A})^{-1} \xi_{{\cal A}}({\cal R}_{\cal A}) + \epsilon_*(\mathbf{x})$, where $\epsilon_*(\cdot)$ is a residual error process assumed with $\text{cov}(\epsilon_*(\mathbf{x}), \epsilon_*(\mathbf{x}')) = \{C_{{\cal A}}(\mathbf{x}, \mathbf{x}') - C_{{\cal A}}^\top({\cal R}_{\cal A}, \mathbf{x}) C_{{\cal A}}^{-1}({\cal R}_{\cal A}, {\cal R}_{\cal A})C_{{\cal A}}({\cal R}_{\cal A}, \mathbf{x}')\}$ $\mathds{1}(\mathbf{x}=\mathbf{x}')$. This specification preserves the orthogonal structure for residual processes between internal nodes and leaf nodes by construction and also allows efficient computation at leaf node. The resulting likelihood function given the tree is essentially a multi-scale predictive process approximation to the base GP likelihood. This specification will adaptively infer the tree partition via the proposed tree prior. This is particularly useful when the goal is to approximate a base GP. This model is referred to as \texttt{ResTGP-PP} hereafter.
<!-- end head-1 -->
<!-- head-2: body_md -->
Another simple choice for the baseline covariance model is a white-noise model: $\delta_{{\cal A}}(\mathbf{x}) \overset{iid}{\sim} N(\mu_{\cal A}, \kappa^2_{\cal A}), \, \mathbf{x} \in {\cal A}$  with conjugate priors $\mu_{\cal A} |\kappa^2_{\cal A} \sim N(\mu_0, \kappa^2_{\cal A}/\kappa_0), \kappa^2_{\cal A} \sim IG(a_0, b_0)$, where $z \sim IG(a_0, b_0)$ has density $p(z) = b_0^{a_0} z^{-a_0-1} \exp(-b_0/z) / \Gamma(a_0), z>0, a_0>0, b_0>0$.  This specification will be referred to as \texttt{ResTGP-WN}, hereafter. This model assumes that the residuals at each node do not contain any spatial variation and are modeled with heteroskedastic errors with tree-node dependent means and variances. This can capture different degrees of heteroskedasticity over different regions to allow regime changing behaviors. This specification also facilitates predictive inference as the underlying covariance structure is estimated from the data. Model comparison under this baseline can be performed in a fully Bayesian way; see Section~\ref{sec: likelihood recursion} for details.
<!-- end head-2 -->
<!-- head-3: body_md -->
A more flexible choice is to assume a parametric covariance function over the tree nodes whose covariance parameters might be shared across different tree levels but allows certain degrees of nonstationary behaviors as in \cite{Fox2012}. However, this situation would then require efficient computation of the marginal likelihood for the baseline model when the number of observations is large. The computational challenge due to the large number of observations can be addressed by adopting existing fast GP approximation methods such as Vecchia approximations \citep{Katzfuss2021}, however, the calculation of the marginal likelihood could still pose potential challenges, and hence this choice is left for future investigation.
<!-- end head-3 -->
<!-- theorem-2: body_md -->
\label{thm: marginal likelihood}  Suppose that the knots are sequentially selected from existing observations.
Let $q_0({\cal A})$ denote the (marginal) likelihood when ${\cal A}$ is a leaf node under either PP or WN leaf model.   Let $\Phi({\cal A})$ be the marginal residual likelihood function in node ${\cal A}$ when the partition tree ${\cal T}$ is integrated out, where hyperparameters are suppressed. It can be established that if the node ${\cal A}$ is a leaf node, $\Phi({\cal A}) = q_0({\cal A})$, which is the likelihood of the corresponding residual process on ${\cal A}$; otherwise, the marginal likelihood can be expressed recursively as
\begin{equation}\label{eqn: marginal likelihood}
\begin{split}
\Phi({\cal A}) = \rho({\cal A}) q_0({\cal A}) + (1-\rho({\cal A})) \biggr\{ \sum_{j=1}^{d} \lambda_j q_{{\cal A}}({\cal R}_{{\cal A}}) 
\times \int \Phi({\cal A}^{j,c}_{{\text{l}}}) \cdot \Phi({\cal A}^{j,c}_{{\text{r}}}) F_{\cal A}(\mathrm{d} c | j)  \biggr\}.
\end{split}
\end{equation}
<!-- end theorem-2 -->
<!-- remark-3: body_md -->
It follows immediately from Theorem~\ref{thm: marginal likelihood} that a bottom-up recursion can be used to compute the marginal likelihood                               
under the ResTGP($\boldsymbol \theta, {\cal T}$) model. It suggests an alternative to MCMC-based computation for the posterior. For a fixed tree with depth $D$,
the computational complexity for one likelihood evaluation with $n$ observations 
is bounded by ${\cal O}(nr^2D^2 + nrdD)$, where $r$ is the maximum number of knots among all the tree nodes. Detailed analysis of computational cost is given in Section S.1.1. The linear scaling in the sample size is notable, but it does not indicate that exact computation of the posterior is always feasible, though often the case when there are less than a handful of dimensions in the domain. In higher dimensional cases, we present later a sequential Monte Carlo algorithm for posterior inference that maintains scalable computation given the tree.
<!-- end remark-3 -->
<!-- remark-4: body_md -->
Theorem~\ref{thm: marginal likelihood} also implies that when the data are collected sequentially, it is only necessary to update the likelihood over the nodes where data are added without recomputing the likelihood over all the tree nodes. This has important consequences for online streaming data and sequential design of computer experiments.
<!-- end remark-4 -->
<!-- remark-5: body_md -->
For given hyperparameters, let $\rho({\cal A} \mid {\cal A}^0):=\mathbb{P}(S({\cal A})|\mathbf{y}({\cal A}^0))$ be the \textit{posterior stopping probability} of $S$ at node ${\cal A}$ and $\tilde{\lambda}_{j}({\cal A} \mid {\cal A}^0):=\mathbb{P}(J=j \mid {\cal A}^0)$ be the \textit{posterior selection probability} of $J$ for the $j$th way of partitioning for node ${\cal A}$. Denote the posterior distribution of cutting variable $L$ by $\tilde{F}_{{\cal A}}(\mathrm{d}c|j) = \mathbb{P}(L\in  \mathrm{d}c|J=j,S=0, {\cal A}^0)$. Then it follows from Bayes' theorem and Theorem~\ref{thm: marginal likelihood} that 
\begin{equation} \label{eqn: tree posterior}
\begin{split}
                                                                   
    \tilde{\lambda}_{j}({\cal A}) &\propto \lambda_j({\cal A}) q_{{\cal A}}({\cal R}_{{\cal A}})\times \int \Phi({\cal A}_{{\text{l}}}^{j,c}) \Phi({\cal A}_{{\text{r}}}^{j,c}) F_{{\cal A}}(\mathrm{d} c | j), \quad j=1, \ldots, d, \\
    \tilde{\rho}({\cal A}) &= \frac{\rho q_0({\cal A})}{\Phi({\cal A})}, \quad \tilde{F}_{{\cal A}}(\mathrm{d} c \mid j) = \frac{\Phi({\cal A}_{{\text{l}}}^{j,c} ) \Phi({\cal A}_{{\text{r}}}^{j,c} )}{\int \Phi({\cal A}_{{\text{l}}}^{j,u} ) \Phi({\cal A}_{{\text{r}}}^{j,u} ) F_{{\cal A}}(\mathrm{d} u | j)} \cdot F_{{\cal A}}(\mathrm{d} c | j)
\end{split}
\end{equation}
It should be mentioned that sampling from the posterior distribution of the partition tree using above formula is quite straightforward and computationally cheap as regular Monte Carlo simulation with Bernoulli distribution and categorical distribution can be used.

<!-- theorem-3: body_md -->
\label{thm: predictive distribution}
Let ${\cal T}, \boldsymbol \theta, v$ be fixed. Let ${\cal A}$ denote the terminal node containing $\mathbf{x}_0$.  Then 
\begin{itemize}[itemsep=-2pt, topsep=0pt, partopsep=0pt]
\item[(i)] Under PP leaf model, $y(\mathbf{x}_0) | \mathbf{y}, {\cal T}, \boldsymbol \theta, v \sim N(\phi_{{\cal T}}(\mathbf{x}_0), V_{{\cal T}}(\mathbf{x}_0))$ where 
$
\phi_{{\cal T}}(\mathbf{x}_0) :=  h_{{\cal T}}(\mathbf{x}_0) + h_{{\cal A}}(\mathbf{x}_0)$, 
$V_{{\cal T}}(\mathbf{x}_0) := C_{{\cal A}}(\mathbf{x}_0, \mathbf{x}_0) - C_{{\cal A}}({\cal R}_{\cal A}, \mathbf{x}_0)^\top {C}_{{\cal A}}({\cal R}_{\cal A}, {\cal R}_{\cal A})^{-1} C_{{\cal A}}({\cal R}_{\cal A}, \mathbf{x}_0) 
$.
\item[(ii)] Under WN leaf model, $y(\mathbf{x}_0) | \mathbf{y}, {\cal T}, \boldsymbol \theta, v \sim  t_{2\tilde{a}}(\phi_{{\cal T}}(\mathbf{x}_0), V_{{\cal T}}(\mathbf{x}_0) (\tilde{a}-1)/\tilde{a})$ provided that $\tilde{a}>1$, where
$
\phi_{{\cal T}}(\mathbf{x}_0):=  h_{{\cal T}}(\mathbf{x}_0) + \tilde{\kappa}^{-1} \{ \kappa_0 \mu_0 + n_{\cal A} \bar{\xi}({\cal A}) \},\, 
V_{{\cal T}}(\mathbf{x}_0):= \tilde{b} (1 + \tilde{\kappa}^{-1}) / (\tilde{a} -1)
$
with $\tilde{a} := a_0 + n_{\cal A}/2, \tilde{\kappa}:=\kappa_0 + n_{\cal A}, \bar{\xi}({\cal A}) := {1}/{n_{\cal A}}\sum_{i=1}^{n_{\cal A}} \xi_i({\cal A})$, $\tilde{b}:=b_0 + 1/2 \sum_{i=1}^{n_{\cal A}} [ \xi_i({\cal A})  - \bar{\xi}({\cal A})]^2 + \kappa_0 n_{\cal A} / (2\tilde{\kappa}) [\bar{\xi}({\cal A}) - \mu_0]^2$.
\end{itemize}

<!-- corollary-1: body_md -->
\label{cor: predictive mean}
Let $\phi^*(\mathbf{x}_0; {\cal A}):=E_{p(\xi(\mathbf{x}_0)\mid \mathbf{y}, \boldsymbol \theta, v)}[\xi(\mathbf{x}_0)]$ denote the residual predictive mean of the predictive distribution $p(\xi(\mathbf{x}_0)\mid \mathbf{y}, \boldsymbol \theta, v)$ on any potential node ${\cal A}$ that could arise in a partition tree.

\begin{equation*}

     + \sum_{j=1}^{d}\tilde{\lambda}_j({\cal A}) \int \phi^*(\mathbf{x}_0; {\cal B}^{j,c}) \tilde{F}_{\cal A}(\mathrm{d} c | j) \bigr\}.
    \end{split}
\end{equation*}
where ${\cal B}^{j,c}$ denotes the child node of ${\cal A}$ that contains $\mathbf{x}_0$ under cut rule $J=j, L=c$.

<!-- assumption-1: body_md -->
\label{ass: truth}
Fix $g_0\in C(\mathscr{D})$ and $v_0>0$. Under the true law $\mathbb P_0$, use either:
\begin{enumerate}[label=(\roman*),leftmargin=*,nosep]
\item For each $n$, let $\mathbf{x}_1, \ldots, \mathbf{x}_n \in \mathscr{D}$ be design locations with their dependence on $n$ suppressed. Let $y_i$ denote their random response at $\mathbf{x}_i$ on a common probability space, with $
y_i=g_0(\mathbf{x}_i)+\sqrt{v_0}\varepsilon_i,
\varepsilon_1,\ldots,\varepsilon_n\overset{iid}{\sim}N(0,1).
$
\item An iid sequence $(\mathbf{x}_i,\varepsilon_i)$ with law $\mathbb P_X\otimes N(0,1)$, where $\mathbb P_X$ is a fixed Borel probability measure on $\mathscr{D}$, and $y_i=g_0(\mathbf{x}_i)+\sqrt{v_0}\varepsilon_i$.
\end{enumerate}
<!-- end assumption-1 -->
<!-- assumption-2: body_md -->
\label{ass: tree-prior}
The Bayesian CART prior satisfies: (i) $0<\rho_0<1$ and $\beta_0>0$; (ii) $\lambda_j>0$, and $\sum_{j=1}^d\lambda_j=1$; (iii) $\{c_1, \ldots, c_M\} \subset (0,1)$ with one of them being $1/2$.
<!-- end assumption-2 -->
<!-- assumption-3: body_md -->
\label{ass: knots}
Every internal node has a deterministic ordered knot set $\mathcal R_{\mathcal A}$ in its cell interior, with $1\leq |\mathcal R_{\mathcal A}|\leq r$ for a fixed finite integer $r$. Knots are distinct within a node and do not coincide with ancestor knots. The rule  does not depend on $n$.
<!-- end assumption-3 -->
<!-- assumption-4: body_md -->
\label{ass: covariance}
The prior on covariance parameters is supported on
$[\log\sigma_-^2,\log\sigma_+^2]\times\mathbb R^d$, where $0<\sigma_-^2\leq\sigma_+^2<\infty$, and satisfies, for all sufficiently large $n$ and constants $C_\ell, c_\ell$,
\begin{equation}\label{eqn: range-tail}
\Pi_{\boldsymbol \theta}\!\left(\max_{1\leq j\leq d}|\theta_j|>n\right)\leq C_\ell e^{-c_\ell n},
\qquad 0\leq C_\ell<\infty,\quad c_\ell>0.
\end{equation}
The error variance $v$ has a proper prior $\Pi_v$ supported on $[v_-,v_+]$, where $0<v_-<v_0<v_+<\infty$, with $\Pi_v(|v-v_0|<\delta)>0$ for every $\delta>0$. Assume that $\mu_0\in \mathbb{R}$, $\kappa_0>0$ are fixed constants, and there exists a constant $\kappa_+^2>0$ such that $\kappa^2_{\cal A}<\kappa_+^2$ for all ${\cal T}$ and ${\cal A} \in {\cal L}$.
<!-- end assumption-4 -->
<!-- remark-6: body_md -->
Only continuity of $g_0$ is assumed but prior functions may jump. The knots require no uniform separation or space-filling condition. Covariance parameters may be fixed, and random ranges are allowed under \eqref{eqn: range-tail}.

<!-- theorem-4: body_md -->
\label{thm: consistency}
Under Assumptions~\ref{ass: truth}--\ref{ass: covariance}, with fixed truth $g_0\in C(\mathscr{D})$, for the fixed prior $\Pi_{g,v}$ described above and every $\epsilon>0$,
\[
\Pi_{g,v}\!\left(H_{\mathbb P_{X,n}}((g,v),(g_0,v_0))>\epsilon\mid\mathcal O_n\right)
\longrightarrow0\qquad \mathbb P_0\text{-almost surely}.
\]
<!-- end theorem-4 -->
<!-- remark-7: body_md -->
This theorem implies that under regularity conditions, the posterior distributions of the regression function and the variance parameter under the proposed model converge to the truth under the corresponding topologies as the sample size goes to infinity. This ensures that the proposed model behaves well and can provide enough support to predict the class of functions in Assumption~\ref{ass: truth}.
<!-- end remark-7 -->
<!-- corollary-2: body_md -->
\label{cor: convergence in measure}
Under the same assumptions in Theorem~\ref{thm: consistency}, for every $\epsilon>0$,
\[
\Pi_{g,v}\!\left(\{d_{\mathbb P_{X,n}}(g,g_0)\geq\epsilon\}
\cup\{|v/v_0-1|\geq\epsilon\}\,\middle|\,\mathcal O_n\right)
\longrightarrow0\qquad \mathbb P_0\text{-almost surely}.
\]
In particular, on the same probability-one event,
\[
\Pi_g(d_{\mathbb P_{X,n}}(g,g_0)\geq\epsilon\mid\mathcal O_n)\to0,
\qquad
\Pi_v(|v/v_0-1|\geq\epsilon\mid\mathcal O_n)\to0.
\]
<!-- end corollary-2 -->
<!-- remark-8: body_md -->
This result concerns convergence in measure under the empirical input distribution in fixed design and under $\mathbb P_X$ in random design. This implies that for every fixed error tolerance, the posterior concentrates on functions whose error exceeds that tolerance on a vanishing fraction of design locations in fixed design, or on a set of vanishing $\mathbb{P}_{X}$-probability in random design.
<!-- end remark-8 -->
<!-- corollary-3: body_md -->
\label{cor: bounded fun}
If Assumptions~\ref{ass: truth}--\ref{ass: covariance} hold and $\|g_0\|_\infty<M$, then, for every $\epsilon>0$,
\[
\Pi_{g,v}^M\!\left(\{\|g-g_0\|_{L_1(\mathbb P_{X,n})}>\epsilon\}
\cup\{|v/v_0-1|\geq\epsilon\}\,\middle|\,\mathcal O_n\right)
\longrightarrow0\qquad \mathbb P_0\text{-almost surely}.
\]
If the random-design distribution $\mathbb{P}_{X}$ has a Lebesgue density $p_X$ that is bounded below away from zero, the same conclusion holds with $L_1(\mathrm{d}\mathbf{x})$ in place of $L_1(\mathbb P_X)$.
<!-- end corollary-3 -->
<!-- remark-9: body_md -->
This result implies that under fixed design, the  absolute regression error averaged over observed inputs vanishes in posterior probability almost surely; under random design, this  absolute regression error averaged over the population distribution of inputs vanishes in posterior probability almost surely.

<!-- lemma-1: body_md -->
\label{lem: OD for Gaussian rv}
Let $\mathbf{Y}$ be an $n$-dimensional Gaussian random vector with mean vector $\boldsymbol \mu$ and positive-definite covariance matrix $\boldsymbol \Sigma$. Suppose that $\{\mathbf{y}_1, \mathbf{y}_2, \ldots, \mathbf{y}_k\}$ is an arbitrary partition of $\mathbf{Y}$ such that $\mathbf{Y} = (\mathbf{y}_1^\top, \mathbf{y}_2^\top, \ldots, \mathbf{y}_k^\top)^\top$, where $\mathbf{y}_i\sim {N}_{r_i}(\boldsymbol \mu_i, \boldsymbol \Sigma_{ii})$, $\boldsymbol \Sigma_{ij}:=\text{cov}(\mathbf{y}_i, \mathbf{y}_j)$, and $\sum_{i=1}^k r_i = n$. For $m=1, \ldots, k-1$, we define the following quantities:
\begin{align*}

\partial_{\theta_0}\log s_{\boldsymbol \theta} =1,\qquad
\partial_{\theta_j}\log s_{\boldsymbol \theta} 
=1-(2\nu+d)\frac{\ell_j^2\omega_j^2}{1+\sum_{k=1}^d \ell_k^2\omega_k^2}, \, j=1, \ldots, d.
\end{align*} 
Thus $|\partial_{\theta_j}\log s_{\boldsymbol \theta}(\omega)|\leq 1+2\nu+d\leq C$ for $0\leq j\leq d$, uniformly in $\boldsymbol \theta,\omega$ for some fixed constant $C$. For $h\in\mathbb R^{d+1}$, applying the chain rule and fundamental theorem of calculus yields 
\begin{align*}
\left|\log\frac{s_{\boldsymbol \theta+h}(\omega)}{s_{\boldsymbol \theta}(\omega)}\right|
=\left|\int_0^1\sum_{j=0}^d h_j\partial_{\theta_j}\log s_{\boldsymbol \theta+th}(\omega)\,dt\right|
\leq C\|h\|_1.
\end{align*}
Exponentiating and using $\partial_{\theta_j}s=s\,\partial_{\theta_j}\log s$ yields
\[
s_{\boldsymbol \theta+h}\leq e^{C\|h\|_1}s_{\boldsymbol \theta},\qquad
|\partial_{\theta_j}s_{\boldsymbol \theta+h}|\leq Ce^{C\|h\|_1}s_{\boldsymbol \theta}.
\]
For the $j$th coordinate vector $e_j$ and $0<|u|\leq1$, applying the fundamental theorem of calculus gives
\begin{align*}
\left|\frac{s_{\boldsymbol \theta+ue_j}-s_{\boldsymbol \theta}}{u}\right|
=\left|\int_0^1\partial_{\theta_j}s_{\boldsymbol \theta+tue_j}\,dt\right|
\leq Ce^C s_{\boldsymbol \theta}.
\end{align*}
By the spectral representation of the $C_{\boldsymbol \theta}$ and dominated convergence theorem, $C_{\boldsymbol \theta}$ is differentiable in $\boldsymbol \theta$. By continuity of the derivatives of the spectral density and the above bound, $C_{\boldsymbol \theta}$ has  continuous derivatives in $\boldsymbol \theta$.

Next, we show that $\partial_{\theta_j} b_{{\cal T}, \boldsymbol \theta}(\cdot)$ is also bounded. 

Write $\mathbf K_{ij}=C_{\boldsymbol \theta}(\mathbf{x}_i,\mathbf{x}_j)$ and $\mathbf{K}=[K_{ij}]_{i,j=1,\ldots, k}$ for a set of fixed $k$ locations $\mathbf{x}_1, \ldots, \mathbf{x}_k$. Denote the matrix derivative by $\dot{\mathbf K}=\partial_{\theta_j}\mathbf K$. For fixed vectors $\mathbf{a}_1,\mathbf{a}_2\in\mathbb R^k$, with components $a_{1,i},a_{2,i}, i=1,\ldots, k$, 
\[
\mathbf{a}_1^\top\dot{\mathbf K}\mathbf{a}_2
=\sum_{i,j=1}^k \mathbf{a}_{1,i}\mathbf{a}_{2,j}\,\partial_{\theta_j}C_{0,\boldsymbol \theta}(\mathbf{x}_i,\mathbf{x}_j)
=\partial_{\theta_j}(\mathbf{a}_1^\top\mathbf K\mathbf{a}_2).
\]
Observe that  
\begin{align*}
\dot{\mathbf K}_{pq}
=\int\cos\{\omega^\top(\mathbf{x}_p-\mathbf{x}_q)\}\dot s_{\boldsymbol \theta}(\omega)\,d\omega,
\qquad |\dot s_{\boldsymbol \theta}|\leq Cs_{\boldsymbol \theta}.
\end{align*}
Direct calculation yields that 
\begin{equation} \label{eqn: bilinear-derivative}
\begin{split}
|\mathbf{a}_1^\top\dot{\mathbf K}\mathbf{a}_2|
&=\left| \int
\left(\sum_i a_{1,i}e^{\mathrm i\omega^\top \mathbf{x}_i}\right)
\overline{\left(\sum_j a_{2,j}e^{\mathrm i\omega^\top \mathbf{x}_j}\right)}
\dot s_{\boldsymbol \theta}(\omega)\,d\omega\right|\\
&\leq\int\left|\sum_i a_{1,i}e^{\mathrm i\omega^\top \mathbf{x}_i}\right|
\left|\sum_j a_{2,j}e^{\mathrm i\omega^\top \mathbf{x}_j}\right|\,|\dot s_{\boldsymbol \theta}(\omega)|\,d\omega\\
&\leq C\int\left|\sum_i a_{1,i}e^{\mathrm i\omega^\top \mathbf{x}_i}\right|
\left|\sum_j a_{2,j}e^{\mathrm i\omega^\top \mathbf{x}_j}\right|s_{\boldsymbol \theta}(\omega)\,d\omega\\
&\leq C\left(\int\left|\sum_i a_{1,i}e^{\mathrm i\omega^\top \mathbf{x}_i}\right|^2s_{\boldsymbol \theta}\,d\omega\right)^{1/2}
\left(\int\left|\sum_j a_{2,j}e^{\mathrm i\omega^\top \mathbf{x}_j}\right|^2s_{\boldsymbol \theta}\,d\omega\right)^{1/2}\\
&=C(\mathbf{a}_1^\top\mathbf K\mathbf{a}_1)^{1/2}(\mathbf{a}_2^\top\mathbf K\mathbf{a}_2)^{1/2},
\end{split}
\end{equation}
where the last inequality is due to Cauchy-Schwarz inequality. 
For the last equality, direct calculation gives 
\[
\int\left|\sum_i a_{1,i}e^{\mathrm i\omega^\top \mathbf{x}_i}\right|^2s_{\boldsymbol \theta}(\omega)\,d\omega
=\sum_{i,j}a_{1,i}a_{1,j}\int\cos\{\omega^\top(\mathbf{x}_i-\mathbf{x}_j)\}s_{\boldsymbol \theta}(\omega)\,d\omega
=\mathbf{a}_1^\top\mathbf K\mathbf{a}_1,
\]
and likewise for $\mathbf{a}_2$. The finite sums are bounded and $s_{\boldsymbol \theta}$ is integrable, so all integrals above are absolutely convergent. 

Fix $\mathbf{x}$ and $j\in\{0,\ldots,d\}$. Let $U$ contain the $k\geq1$ knots on the active internal-node path. Set 
\begin{align*}
\mathbf K=C_{\boldsymbol \theta}(U,U)=\mathbf L\mathbf L^\top,\qquad
\mathbf{c}_{\mathbf{x}}=C_{\boldsymbol \theta}(U,\mathbf{x}),\qquad b_U(\mathbf{x})=\mathbf L^{-1}\mathbf{c}_{\mathbf{x}}.
\end{align*}
The knots are distinct by Assumption~3. Substituting $\mathbf{a}_1=\mathbf L^{-\top}u$, $\mathbf{a}_2=\mathbf L^{-\top}w$ in \eqref{eqn: bilinear-derivative} gives
\begin{align*}
|u^\top\mathbf L^{-1}\dot{\mathbf K}\mathbf L^{-\top}w|
\leq C\|u\|_2\|w\|_2,\qquad
\|\mathbf L^{-1}\dot{\mathbf K}\mathbf L^{-\top}\|_{\mathrm{op}}\leq C.
\end{align*}
Here $\|\cdot\|_{\mathrm{op}}$ denotes  the operator norm. 

Write $\mathbf{H}=\mathbf{L}^{-1} \dot{\mathbf{L}}$. Then it can be verified that 
\begin{align*}
\mathbf H+\mathbf H^\top&=\mathbf L^{-1}\dot{\mathbf K}\mathbf L^{-\top},\\
\|\mathbf H\|_{\mathrm{op}}&\leq\|\mathbf H\|_{\mathrm F}
\leq\|\mathbf H+\mathbf H^\top\|_{\mathrm F}\\
&\leq\sqrt{k}\,\|\mathbf L^{-1}\dot{\mathbf K}\mathbf L^{-\top}\|_{\mathrm{op}}
\leq C\sqrt{k}.
\end{align*}
Here $\|\cdot\|_{\mathrm F}$ is the Frobenius norm with
  $\|\mathbf H+\mathbf H^\top\|_{\mathrm F}^2=2\|\mathbf H\|_{\mathrm F}^2+2\sum_a H_{aa}^2$. 

Applying \eqref{eqn: bilinear-derivative} to the covariance matrix at $(U,\mathbf{x})$, with vectors $a_1=\binom{\mathbf L^{-\top}u}{0}$ and $a_2=\binom{0_k}{1}$ yields
\begin{align*}
|u^\top\mathbf L^{-1}\dot \mathbf{c}_{\mathbf{x}}|
\leq C\{u^\top\mathbf L^{-1}\mathbf K\mathbf L^{-\top}u\}^{1/2}\sigma
=C\sigma\|u\|_2,\qquad
\|\mathbf L^{-1}\dot \mathbf{c}_{\mathbf{x}}\|_2\leq C\sigma,
\end{align*}
where the last inequality follows by taking the supremum over unit $u$. 

Differentiating $\mathbf Lb_U=\mathbf{c}_{\mathbf{x}}$ and multiplying by $\mathbf L^{-1}$ yields
\begin{align*}
\dot b_U&=\mathbf L^{-1}\dot \mathbf{c}_{\mathbf{x}}-\mathbf H b_U,\\
\|\dot b_U(\mathbf{x})\|_2
&\leq\|\mathbf L^{-1}\dot \mathbf{c}_{\mathbf{x}}\|_2+\|\mathbf H\|_{\mathrm{op}}\|b_U(\mathbf{x})\|_2
\leq C\sigma+C\sqrt{k}\,\sigma
\leq C(1+\sqrt{k})\sigma_+.
\end{align*}

These calculations also hold when $\mathbf{x}\in U$: the augmented covariance need only be nonnegative definite. Indeed, for an active internal node $\mathcal A$, let $V$ list its strict ancestor knots. Then  
\begin{align*}
[b_U(\mathbf{x})]_{\mathcal R_{\mathcal A}}
&=\mathbf L_{\mathcal A}^{-1}\bigl\{C_{\boldsymbol \theta}(\mathcal R_{\mathcal A},\mathbf{x})
-C_{0,\boldsymbol \theta}(\mathcal R_{\mathcal A},V)C_{\boldsymbol \theta}(V,V)^{-1}C_{\boldsymbol \theta}(V,\mathbf{x})\bigr\}\\
&=\mathbf L_{\mathcal A}^{-1}C_{\mathcal A,\boldsymbol \theta}(\mathcal R_{\mathcal A},\mathbf{x})
=u_{\mathcal A,\boldsymbol \theta}(\mathbf{x}),
\end{align*}
where the subtracted term is zero for $V=\varnothing$. Off-path coordinates vanish, and leaf scales and partition indicators do not depend on $\boldsymbol \theta$. Hence 
\begin{align*}
\|\partial_{\theta_j}b_{\mathcal T,\boldsymbol \theta}(\mathbf{x})\|_2^2
=\sum_{\substack{\mathcal A\in\mathcal I(\mathcal T)\\\mathbf{x}\in\mathcal A}}
\|\partial_{\theta_j}u_{\mathcal A,\boldsymbol \theta}(\mathbf{x})\|_2^2
=\|\dot b_U(\mathbf{x})\|_2^2.
\end{align*}
Since $k\leq r(K-1)$,
\[
\|\partial_{\theta_j}b_{\mathcal T,\boldsymbol \theta}(\mathbf{x})\|_2
\leq C\sigma_+(1+\sqrt{r(K-1)})
\leq C\sigma_+(1+\sqrt r)\sqrt K
\leq C\sqrt K.
\]
For $k=0$ the derivative is zero. The bound is uniform in $\mathbf{x},\boldsymbol \theta$ and $j$. Along $\boldsymbol \theta_t=(1-t)\boldsymbol \theta+t\boldsymbol \theta'$, the chain rule and fundamental theorem of calculus give
\[
\begin{aligned}
b_{\mathcal T,\boldsymbol \theta'}(\mathbf{x})-b_{\mathcal T,\boldsymbol \theta}(\mathbf{x})
&=\int_0^1\sum_{j=0}^d\partial_{\theta_j}b_{\mathcal T,\boldsymbol \theta_t}(\mathbf{x})(\theta_j'-\theta_j)\,dt,\\
\sup_{\mathbf{x}}\|b_{\mathcal T,\boldsymbol \theta'}(\mathbf{x})-b_{\mathcal T,\boldsymbol \theta}(\mathbf{x})\|_2
&\leq C\sqrt K\,\|\boldsymbol \theta'-\boldsymbol \theta\|_1
\leq C\sqrt{(d+1)K}\,\|\boldsymbol \theta'-\boldsymbol \theta\|_2.
\end{aligned}
\]
Absorbing $\sqrt{d+1}$ into $C$ yields the desired results.

Write $\mathcal N(u,E,\cdot)$ for the minimum number of open radius-$u$ balls covering $E$. For any input probability measure $\mathbb P$, \citet[Lemma 2.7(i)]{Ghosal2017} gives
\begin{equation}\label{prop: hellinger-upper}
H_{\mathbb P}((g,v),(g',v'))
\leq\frac{\|g-g'\|_{L_2(\mathbb P)}}{2\sqrt{v_-}}+
\frac{|v-v'|}{2v_-}
\leq C\{\|g-g'\|_{L_2(\mathbb P)}+|v-v'|\}.
\end{equation}
Choose $C\geq1$ also valid in Eq.~\eqref{eqn: cov lipschitz}, and put $u=\epsilon/(216C)$.

Next, we compute the metric entropy. For each tree with $K\leq\alpha n$, a covariance grid $\mathcal Q_{\mathcal T}$ of coordinate mesh $u/\{C\sqrt{(d+1)nK}\}$ covers the covariance box. Proposition~\ref{prop: covariance continuity} implies
\begin{align*}
|\mathcal Q_{\mathcal T}|\leq(1+C_\epsilon n^2)^{d+1},\qquad
\inf_{\boldsymbol \theta'\in\mathcal Q_{\mathcal T}}\sup_{\|z\|_2\leq\sqrt n}
\|g_{\mathcal T,\boldsymbol \theta,z}-g_{\mathcal T,\boldsymbol \theta',z}\|_\infty\leq u.
\end{align*} 
Write $b=b_{\mathcal T,\boldsymbol \theta'}$. The coefficient image $E=\{b^\top z:\|z\|_2\leq\sqrt n\}$ is an ellipsoid in $L_2(\mathbb P_{\mathbf{X},n})$ with squared semiaxes equal to the eigenvalues of $n\int bb^\top\,\mathrm{d}\mathbb P_{\mathbf{X},n}$, including zeros. Let $a_j$ denote the length of the $j$th semiaxis of the ellipsoid $E$, that is $a_j=\sqrt{n \lambda_j}$ where $\lambda_j$ is the $j$th eigenvalue of $\int b(\mathbf{x}) b(\mathbf{x})^\top \mathrm{d} \mathbb{P}_{\mathbf{X},n}(\mathbf{x})$. 
Proposition~\ref{prop: residual process bound} gives $\sum_{j=1}^q a_j^2 = n \int \| b(\mathbf{x})\|_2^2  \mathrm{d} \mathbb{P}_{\mathbf{X},n}(\mathbf{x}) \leq nB^2$.

Since covering numbers are invariant under translation, we have 
\begin{align*}
    \mathcal N(u,\mu_0 + E,L_2(\mathbb P_{\mathbf{X},n})) = \mathcal N(u,E,L_2(\mathbb P_{\mathbf{X},n})).
\end{align*}
Use the packing-volume argument of \citet[Appendix C.1 and Proposition C.2]{Ghosal2017}: in Euclidean coordinates, $D=\operatorname{diag}(a_j+u/2)$ satisfies $E+(u/2)B_2^q\subset2DB_2^q$. Disjoint open radius-$u/2$ balls around a maximal subset with pairwise distances at least $u$ therefore give
\begin{equation}\label{eqn: coefficient-cover}
\begin{split}
\log\mathcal N(u,E,L_2(\mathbb P_{\mathbf{X},n}))
&\leq\log\frac{\operatorname{vol}(2DB_2^q)}{\operatorname{vol}((u/2)B_2^q)}
=\sum_{j=1}^q\log\{2(1+2a_j/u)\}\\
&\leq q\log\left\{2\left(1+\frac{2B\sqrt n}{u\sqrt q}\right)\right\}.
\end{split}
\end{equation}
The inclusion follows from $\|D^{-1}e\|_2\leq1$ for $e\in E$ and $\|D^{-1}w\|_2\leq1$ for $\|w\|_2\leq u/2$; the last inequality uses concavity of $\log$ and $\sum_j a_j\leq\sqrt{q\sum_j a_j^2}$. Here $B_2^q$ is the Euclidean unit ball. A variance grid of mesh $u$ completes a Hellinger cover of radius $3Cu=\epsilon/72$.

Let $\mathcal C_{\mathrm{cut}}$ be the finite relative cut set in Assumption~2. There are at most $(4d|\mathcal C_{\mathrm{cut}}|)^{K-1}$ labeled trees with $K$ leaves. The function $q\log\{2(1+c/\sqrt q)\}$ increases in $q>0$: its derivative is $\log\{2(1+t)\}-t/[2(1+t)]>0$, where $t=c/\sqrt q$. For $n\geq2$ with $\lfloor\alpha n\rfloor\geq1$, sum over $K\leq\lfloor\alpha n\rfloor$ and use $q\leq\tilde r\alpha n$ to obtain
\begin{equation}\label{eqn: entropy}
\begin{split}
\log\mathcal N(\epsilon/72,\mathcal S_{n,\alpha},H_{\mathbb P_{\mathbf{X},n}})
&\leq C\alpha n+\log n+(d+1)\log(1+C_\epsilon n^2)+\log C_\epsilon\\
&\quad+\tilde r\alpha n\log\{2(1+C_\epsilon/\sqrt\alpha)\}\\
&\leq C_\epsilon\{n\alpha\log(e/\alpha)+\log n\}.
\end{split}
\end{equation}
All bounds are uniform in the input probability measure. Fixed covariance coordinates require only one grid point.

Then we construct the tests. Since $\alpha\log(e/\alpha)\to0$, choose $\alpha_\epsilon\leq\alpha_{\max}$ so that the cover size $N_n$ satisfies $\log N_n\leq n\epsilon^2/16$ for sufficiently large $n$. In each ball intersecting the alternative set, choose one alternative as center; the resulting radius is $\epsilon/36<\epsilon/5$. 

In fixed design, the $i$th factors of the sampling densities in Section~4 have squared Hellinger distance $H_{\delta_{\mathbf{x}_i}}^2((g,v),(g',v'))$; averaging over $i$ gives $H_{\mathbb P_{\mathbf{X},n}}^2((g,v),(g',v'))$. In random design, each factor has squared distance $H_{\mathbb P_{\mathbf{X}}}^2((g,v),(g',v'))$, giving the same identity. Thus by \citet[Proposition D.9]{Ghosal2017}, with $c=1$, there exists a local Borel test $\psi_{n,j}$ with both errors at most $e^{-n\epsilon^2/8}$ at each center and throughout its ball. Their maximum $\psi_n=\max_j\psi_{n,j}$ satisfies
\begin{align*}
\mathbb E_0\psi_n(\mathcal O_n)&\leq\sum_{j=1}^{N_n}\mathbb E_0\psi_{n,j}(\mathcal O_n)
\leq N_ne^{-n\epsilon^2/8}\leq e^{-n\epsilon^2/16},\\
\mathbb E_{g,v}^{(n)}(1-\psi_n)
&\leq\mathbb E_{g,v}^{(n)}(1-\psi_{n,j})\leq e^{-n\epsilon^2/8}
\end{align*}
whenever $(g,v)$ belongs to the $j$th ball.

Fix $\epsilon>0$, write $\mathcal H_n=\{(g,v):H_{\mathbb P_{\mathbf{X},n}}((g,v),(g_0,v_0))>\epsilon\}$ and $\Psi_n=\psi_n(\mathcal O_n)$, and put
\begin{align*}

N_{2,n}=\int_{\mathcal S_n^c}e^{-L_n(g,v)}\,\Pi_{g,v}(dg,dv).
\end{align*}
The density-ratio identity gives, for every fixed $(g,v)$,
\begin{align*}
\mathbb E_0\{(1-\Psi_n)e^{-L_n(g,v)}\}
=\int(1-\psi_n(o))\frac{p_{g,v}^{(n)}(o)}{p_{g_0,v_0}^{(n)}(o)}\,\mathbb P_0^{(n)}(do)
=\mathbb E_{g,v}^{(n)}(1-\psi_n).
\end{align*}
Here $\mathbb P_0^{(n)}$ is the law of $\mathcal O_n$ under $\mathbb P_0$; the same identity without the test gives $\mathbb E_0e^{-L_n(g,v)}=1$. 

It follows from C2--C3 and Markov's inequality that with $c=c_\epsilon$,
\begin{align*}
\mathbb E_0N_{j,n}\leq C_\epsilon e^{-cn},\qquad
\mathbb P_0(N_{j,n}>e^{-cn/2})\leq C_\epsilon e^{-cn/2}\ (j=1,2),\qquad
\sum_n\mathbb P_0(\Psi_n=1)<\infty.
\end{align*}
For $0<a<c/2$, it follows from Borel--Cantelli and C1 that eventually almost surely,
\begin{align*}
\Pi_{g,v}(\mathcal H_n\mid\mathcal O_n)
\leq\Psi_n+\frac{N_{1,n}+N_{2,n}}{\int e^{-L_n(g,v)}\,\Pi_{g,v}(dg,dv)}
\leq2e^{-n(c/2-a)}\longrightarrow0.
\end{align*}
This proves the criterion for general experiments, without an iid assumption across observations or independence across experiments.

Fix an input probability measure $\mathbb P$ and write $\Delta=g-g_0$. The Gaussian affinity formula \citep[proof of Lemma 2.7]{Ghosal2017} is
\begin{equation}\label{eqn: normal-affinity}
H_{\mathbb P}^2((g,v),(g_0,v_0))
=2-2\left\{\frac{2\sqrt{vv_0}}{v+v_0}\right\}^{1/2}

\end{equation}
Since $2(1-\sqrt t)\geq1-t$ for $0\leq t\leq1$ and $v,v_0\leq v_+$,
\begin{equation}\label{eqn: metric-lower-bounds}
H_{\mathbb P}^2\geq\frac{(\sqrt v-\sqrt{v_0})^2}{v+v_0}
\geq\frac{(v-v_0)^2}{8v_+^2},\qquad
H_{\mathbb P}^2\geq2(1-e^{-s^2/(8v_+)})\mathbb P(|\Delta|>s),\quad s>0.
\end{equation}
