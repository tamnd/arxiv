\label{thm:general}
    Let $R$ be a finite ring, $q$ be a prime power, and $\xi $ a group homomorphism from $\mathbb{F}_q^*$ to $R^*$ such that $\xi(-1_{\mathbb{F}_q})=-1_R$. Extend $\xi$ to $\mathbb{F}_q$ by setting $\xi(0_{\mathbb{F}_q})=0_R$, and define $\psi:\mathbb{F}_q \to R$ by $\psi(x)=\xi(x)-\xi(x-1_{\mathbb{F}_q})$. Write $B=\psi^{-1}(1_R)$ and $b=|B|$. Let $\Gamma(R,q,\xi)$ be the Cayley graph of $(R\times \mathbb{F}_q,+)$ with connecting set $\{(\xi(x),x) : x \in \mathbb{F}_q^*\}$. Then the following hold.
    \begin{enumerate}
        \item The graph $\Gamma(R,q,\xi)$ is an edge-regular graph with parameters $(q|R|,q-1,b-2)$ whose vertex set can be partitioned into $q$ many $1$-regular cocliques of size $|R|$.
        \item If $|R|$ is a divisor of $b$ (say $t=b/|R|$), then for any choice of permutations $\pi_2,\dots,\pi_t \in \operatorname{Sym}_q$ the graph $\overline \Gamma (R,q,\xi) \coloneqq F_{(\pi_2,\dots,\pi_t)}(\Gamma(R,q,\xi),\dots,\Gamma(R,q,\xi))$ is a Neumaier graph with parameters $(bq,b+q-2,b-2;1,b)$.
        \item The graph $\overline \Gamma(R,q,\xi)$ is strongly regular if and only if $t=1$ and $|\psi^{-1}(r)|$ is constant over all $r\in R\setminus \{1_R\}$. In this case $\overline \Gamma(R,q,\xi)$ has parameters $(bq,b+q-2,b-2,\frac{b+q-2}{b-1})$.
        \item If $R$ is not a field or $\xi:\mathbb{F}_q^*\to R^*$ is not surjective, then $\overline \Gamma (R,q,\xi)$ is a strictly Neumaier graph.
    \end{enumerate}
<!-- end thm-6 -->
<!-- proof-2: body_md -->
For the first part, 
    note that the connecting set
    $S := \{(\xi(x),x) : x \in \mathbb{F}_q^*\}$ contains $-1_{R\times\mathbb{F}_q}=(-1_R,-1_{\mathbb{F}_q})$ because $\xi(-1_{\mathbb{F}_q})=-1_R$, and so $\Gamma(R,q,\xi)$ is a well-defined Cayley graph. Because $S$ is a subgroup of $(R\times \mathbb{F}_q)^*$, the graph $\Gamma(R,q,\xi)$ is edge-transitive by Lemma~\ref{lema:edge-transitive}, and hence edge-regular. It is easy to see that $\Gamma(R,q,\xi)$ has $q|R|$ vertices and has valency $q-1$. For the parameter $\lambda$, note that $B$ contains $0_{\mathbb{F}_q}$ and $1_{\mathbb{F}_q}$, and that the common neighbors of $(0_R,0_{\mathbb{F}_q})$ and $(1_R,1_{\mathbb{F}_q})$ are precisely $(\xi(x),x)$ for $x\in B\setminus \{0_{\mathbb{F}_q},1_{\mathbb{F}_q}\}$, so that $\lambda=b-2$. Next, note that $T\coloneqq S\sqcup \{(0_R,0_{\mathbb{F}_q})\}$ forms a transversal for the subgroup $\{(r,0) : r\in R\}$ of $(R\times \mathbb{F}_q,+)$, so that for each $x\in \mathbb{F}_q$, the set $\{(r,x) : r\in R\}$ is a 1-regular coclique.
    
    The second part follows from Theorem~\ref{thm:EvansMachine} and from the parameters given in the first part.

    For the third part, we first claim that if $\overline\Gamma(R,q,\xi)$ is strongly regular, then $t=1$. Indeed, if $t>1$, then by Theorem~\ref{thm:EMstrict} we know that $\Gamma(R,q,\xi)$ is a disjoint union of complete graphs. This implies that $T$ is a subgroup of $(R\times \mathbb{F}_q,+)$, and that $\xi$ is additive. In particular $\xi:\mathbb{F}_q \to R$ is a ring morphism. Since $\mathbb{F}_q$ is a field, $\xi$ is injective, so $|R|\ge q$. Furthermore, since $\xi$ is additive, it is clear that $\psi(x)=1_R$ for every $x\in \mathbb{F}_q$, and that $b=q$, so that $t=b/|R|>1$ contradicts $|R|\ge q$.

    We now assume that $t=1$, and show that in this case $\overline\Gamma(R,q,\xi)$ is strongly regular if and only if $|\psi^{-1}(r)|$ is constant over all $r\in R\setminus \{1_R\}$. Let $u$ and $v$ be two vertices that are not adjacent in $\overline\Gamma(R,q,\xi)$, then their second coordinates are not equal, and we can apply a suitable automorphism $\varphi$ so that $\varphi(u)=(0_R,0_{\mathbb{F}_q})$ and $\varphi(v)=(r,1_{\mathbb{F}_q})$ for some $r\in R\setminus \{1_R\}$. Note that then a neighbor $w$ of $\varphi(u)$ is also a neighbor of $\varphi(v)$ if and only if $w$ is one of $(1_R,1_{\mathbb{F}_q})$ and $(r-1_R,0_{\mathbb{F}_q})$, or $w=(\xi(x),x)$ with $\psi(x)=r$. In particular, the number of common neighbors of $u$ and $v$ in $\overline \Gamma(R,q,\xi)$ is equal to $2+|\psi^{-1}(r)|$. It follows that $\overline\Gamma(R,q,\xi)$ is strongly regular if and only if $|\psi^{-1}(r)|$ is constant over all $r\in R\setminus \{1_R\}$.

    For the last part, note that $|\psi^{-1}(1_R)|=b$ and
    $$\sum_{r\in R} |\psi^{-1}(r)|=|\mathbb{F}_q|=q.$$
    From this and the previous part it follows that if $\overline \Gamma(R,q,\xi)$ is strongly regular, then $|\psi^{-1}(r)|=(q-b)/(b-1)$ for every $r\in R\setminus \{1_R\}$. In particular, this holds for $r=0_R$. Note that $\psi(x)=0_R$ is equivalent to $\xi(1-1/x)=1_R$. If we write $m=|\xi(\mathbb{F}_q^*)|$, then there are exactly $(q-1)/m$ solutions $y$ to $\xi(y)=1_R$. As this includes $y=1$ which is never equal to $1-1/x$, this means that there are exactly $(q-m-1)/m$ solutions $x$ to $\psi(x)=0_R$. In other words, $|\psi^{-1}(0_R)|=(q-m-1)/m$. Now $|\psi^{-1}(0_R)|=(q-b)/(b-1)$ it implies that $m=b-1$. Because $t=1$ by the previous part, we see that $|R|=b$, and hence that $\xi(\mathbb{F}_q^*)=R\setminus \{0_R\}$. We conclude that $\xi:\mathbb{F}_q^*\to R^*$ is surjective and that $R$ is a field. The result now follows.

        \item $\operatorname{char}(R)=2$, $\ell$ is even, and $q\equiv_{2\ell} 1$,

First, suppose that the characteristic of $R$ is 2. Then $-1_R=1_R$, and the order of $\rho$ in $R^*$ is $\ell$. Now $\xi$ is well-defined if and only if $q\equiv_\ell 1$. If $q$ is even, then $\xi(-1_{\mathbb{F}_q})=-1_R$ is automatically satisfied. If $q$ is odd, then

<!-- lema-5: body_md -->
\label{lema:norm}
    Let $q$ be a prime power and $d$ a positive integer. Let $\psi_q^d:\mathbb{F}_{q^d}\to \mathbb{F}_q$ be defined as $x\mapsto N_q^d(x)-N_q^d(x-1)$. Then $|(\psi^d_q)^{-1}(r)|$ is divisible by $q$ for every $r \in \mathbb{F}_q$.
<!-- end lema-5 -->
<!-- proof-5: body_md -->
We use a proof technique from \cite{MorenoMoreno} that uses a basis $\alpha_1=1,\alpha_2,\dots,\alpha_d$ of $\mathbb{F}_{q^d}$ seen as a vector space over $\mathbb{F}_q$. For $x\in \mathbb{F}_{q^d}$, write $x=x_1+x_2\alpha_2+\dots+x_d\alpha_d$ with $x_1,\dots,x_d\in \mathbb{F}_q$. Using the fact that $x\mapsto x^q$ is a field automorphism of $\mathbb{F}_{q^d}$ fixing every element of $\mathbb{F}_q$, we have
    \begin{align*}
        N_q^d(x) &= \prod_{i=0}^{d-1} x^{q^i}=\prod_{i=0}^{d-1} \big(x_1+x_2\alpha_2+\dots+x_d\alpha_d \big )^{q^i}\\
        &=\prod_{i=0}^{d-1} \left (x_1^{q^i} +x_2^{q^i}\alpha_2^{q^i}+\dots+x_d^{q^i}\alpha_d^{q^i}\right )=\prod_{i=0}^{d-1}\left ( x_1 +x_2\alpha_2^{q^i}+\dots+x_d\alpha_d^{q^i}\right ).
    \end{align*}
    Write $f$ for this homogeneous $d$-variate polynomial of degree $d$ with coefficients in $\mathbb{F}_{q^d}$. By writing these coefficients in terms of the basis $\{\alpha_1=1,\alpha_2,\dots,\alpha_d\}$, we obtain homogeneous $d$-variate polynomials $f_1,\dots,f_d$ of degree $d$ with coefficients in $\mathbb{F}_q$ such that
    $$f=f_1+\alpha_2f_2+\dots+\alpha_df_d.$$
    Since the norm of any element of $\mathbb{F}_{q^d}$ is in $\mathbb{F}_q$, we have that
    $$f(x_1, x_2, \ldots, x_d) = f_1(x_1,x_2,\dots,x_d)$$
    for every choice of $x_1,\dots,x_d \in \mathbb{F}_q$.

    Now consider the polynomial
    $$g(x_1,\dots,x_d)=f_1(x_1,x_2,\dots,x_d)-f_1(x_1-1,x_2,\dots,x_d)-r.$$
    Note that
    $$g(x_1,x_2,\dots,x_d)=\psi_q^d(x_1+x_2\alpha_2+\dots+x_d\alpha_d)-r$$ for all $x_1, \ldots, x_d \in \mathbb{F}_q$.
    Furthermore, since $f_1$ is a homogeneous polynomial of degree $d$, the homogeneous part of degree $d$ of $f_1(x_1-1,x_2,\dots,x_d)$ is equal to $f_1(x_1,x_2,\dots,x_d)$, and so the degree of $g$ is at most $d-1$.
    
    From the Ax-Katz Theorem (Theorem~\ref{thm:Ax-Katz}) it follows that the number of zeroes of $g$ (i.e.\ the number of $x\in \mathbb{F}_{q^d}$ with $\psi_q^d(x)=r$) is divisible by $q$.
<!-- end proof-5 -->
<!-- proof-6: body_md -->
Note that $N_q ^d$ is a multiplicative function sending 0 to 0 and 1 to 1. Furthermore, if $q$ is even then $N_q^d(-1)=N_q^d(1)=1=-1$, and if $d$ is odd then $N_q^d(-1)=(-1)^d=-1$. Next, $b_q^d=|(\psi_q^d)^{-1}(1)|$ is divisible by $q$ by Lemma~\ref{lema:norm}. The result now follows from Theorem~\ref{thm:general}, where the strictness follows from $t=b_q^d/q$; if $b_q^d>q$, then $t>1$, and the graph is a strictly Neumaier graph.

<!-- thm-9: body_md -->
\label{thm:norm infinite}
    Let $q$ be a prime power and $d$ a positive integer such that $q$ is even or $d$ is odd. Then $b_q^d$ is even if and only if either $q$ is even, or $q$ is odd and $d\not \equiv_{\omega(q)} 1$, where $\omega(q)$ is the order of $2$ in $\mathbb{F}_q^*$.
    
    Consequently, if $q$ is an odd prime power, and $d$ an odd positive integer with $d \not \equiv_{\omega(q)} 1$, then $b_q^d>q$ and so the graph $\overline \Gamma(\mathbb{F}_q,q^d,N_q^d)$ is a strictly Neumaier graph. In particular, infinitely many graphs from Theorem~\ref{thm:norm} are strictly Neumaier graphs.

<!-- proof-7: body_md -->
Write $B$ for the set of elements $x$ of $\mathbb{F}_{q^d}$ such that $N_q^d(x-1)=N_q^d(x)-1$, so that $|B|=b_q^d$. Consider the involution $\varphi:\mathbb{F}_{q^d} \to \mathbb{F}_{q^d}$ given by $x\mapsto 1-x$. If $x\in B$, then
    $$N_q^d(\varphi(x)-1)=N_q^d(-x)=-N_q^d(x)=-N_q^d(x-1)-1=N_q^d(\varphi(x))-1,$$
    so that $\varphi(x)\in B$. Since $\varphi(\varphi(x))=x$ for all $x$, the parity of $b_q^d$ is equal to that of the number of fixed points of $\varphi$ in $B$.

    Note that $a$ is a fixed point of $\varphi$ if and only if $1=2a$. In particular, if $q$ is even, then $\varphi$ has no fixed points at all, and so $b_q^d$ is even. If $q$ is odd, then $B$ has the fixed point $1/2$ if and only if $-N_q^d(1/2)=N_q^d(1/2)-1$, which is equivalent to $N_q^d(2)=2$. Since $2\in \mathbb{F}_q$, we have $N_q^d(2)=2^d$. We conclude that $B$ has a (necessarily unique) fixed point if and only if $2^d=2$, which holds if and only if $d\equiv_{\omega(q)}1$. The first part of the statement follows.

    If $q$ is an odd prime power and $d$ an odd integer such that $d \not \equiv_{\omega(q)} 1$, then we have that $b_q^d \not \equiv_2 q$. It is therefore impossible that $b_q^d=q$, so we have $b_q^d>q$. The second part of the statement now follows from Theorem~\ref{thm:norm}, where for the infinitude, take for example $q=5$, for which $\omega(q)=4$, providing a strictly Neumaier graph for every $d\equiv_4 3$.

\label{thm:weil_bound}
  If $d \geq 3$ and $q > 15 (d-1)^{13/3}$ then $b_q^d > q$. In particular, if moreover $q$ is even or $d$ is odd, then $\overline{\Gamma}(\mathbb{F}_q,q^d,N_q^d)$ is a strictly Neumaier graph.

<!-- proof-17: body_md -->
We build on the proof of Lemma~\ref{lema:norm} and keep the same notation. If $q > 15 (d-1)^{13/3}$ then the number of zeroes of the polynomial $g$ is at least
\[
  q^{d-1} - (d-2)(d-3)q^{d-3/2} - (d - 2/5)q^{d-2}
\]
by~\cite[Theorem 1.10]{Slavov}, provided that $g$ is absolutely irreducible, i.e., irreducible as an element of $\overline{\mathbb{F}}_q[x_1, \ldots, x_d]$ where $\overline{\mathbb{F}}_q$ denotes an algebraic closure of $\mathbb{F}_q$. One verifies:
\[
  q^{d-1} - (d-2)(d-3)q^{d-3/2} - (d - 2/5)q^{d-2} - q > q^{d-1} - 3(d-1)^2q^{d - 3/2} > 0,
\]
using $d \geq 3$ and the lower bound on $q$.

So it is enough to show that $g$ is absolutely irreducible. In the proof of Lemma~\ref{lema:norm} we observed that the degree-$d$ polynomials $f_2, \ldots, f_d$ evaluate to $0$ at all elements of $\mathbb{F}_q^d$. Since $q > d$ this means that $f_2 = \ldots = f_d = 0$, see~\cite[Lemma 7.40]{LidlNiederreiter}. Therefore
\[ f_1 = f = \prod_{i=0}^{d-1}\left ( x_1 +\alpha_2^{q^i}x_2+\dots+\alpha_d^{q^i}x_d\right ), \]
really as an identity of polynomials. The $d$ linear factors on the right are polynomials over $\mathbb{F}_{q^d}$ and they are $\mathbb{F}_{q^d}$-linearly independent: to see this, one can assume that $\alpha_1 = 1, \alpha_2, \alpha_3 = \alpha_2^2, \ldots, \alpha_d = \alpha_2^{d-1}$ is a power basis and then the matrix
\[ \left( \alpha_j^{q^i} \right)_{1 \leq j \leq d, 0 \leq i \leq d - 1} = \left( (\alpha_2^{q^i} )^{j-1} \right)_{1 \leq j \leq d, 0 \leq i \leq d - 1} \] 
is the Vandermonde matrix associated with the roots of the minimal polynomial of $\alpha_2$ over $\mathbb{F}_q$, which are all distinct.

Thus, an $\mathbb{F}_{q^d}$-linear change of variables transforms the polynomial $f_1(x_1, x_2, \ldots, x_d)$ into $x_1x_2 \cdots x_d$ and under this transformation $f_1(x_1 - 1, x_2, \ldots, x_d)$ transforms into the polynomial $(x_1 - 1)(x_2 - 1) \cdots (x_d - 1)$. It is therefore sufficient to prove that the polynomial $x_1 x_2 \cdots x_d - (x_1 - 1)(x_2-1) \cdots (x_d - 1) - r$
is absolutely irreducible. For this it is enough that its homogeneous part of highest degree is absolutely irreducible; call this part $h$. Since $h$ has degree $1$ in $x_1$, any candidate-factorization $h = h_1 h_2$ must be such that one factor, say $h_1$, involves $x_1$ and the other factor does not. 
Then upon writing $h = h' x_1 + h''$ for polynomials $h', h''$ not involving $x_1$, we have $h_2 \mid h'$ and $h_2 \mid h''$. But one explicitly checks that $h'$ has no common factors with $h'' = x_2 x_3 \cdots x_d$, so $h_2$ must be a unit, i.e., the factorization is necessarily trivial.
