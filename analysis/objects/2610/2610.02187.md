<!-- theorem-1: body_md -->
\label{thm:information} Let $(X,Y,U)$ be an error-free record of a controllable real plant, started from the known state $x_0=0$. \begin{enumerate} \item With exact states, the record is certifiable for some positive $\delta_w$ if and only if $\operatorname{rank}X=n$. \item Regarded as a measured record, it is certifiable for some positive $\delta_w$ and $\delta_v$ if and only if \begin{equation} \operatorname{rank}\begin{bmatrix}X\\U\end{bmatrix}=n+\operatorname{rank}U. \label{eq:information-rank} \end{equation} If \eqref{eq:information-rank} fails, then for every $\delta_v>0$, even with $\delta_w=0$, no single gain stabilizes all compatible models. \end{enumerate} When the corresponding rank condition holds, for all sufficiently small error bounds, every physical record generated by the same input sequence is certifiable ($\delta_w$ in part~1; $\delta_w$ and $\delta_v$ in part~2).
<!-- end theorem-1 -->
<!-- head-1: body_md -->
With exact states and $\operatorname{rank}X=n$, the zero initial state allows us to choose a right inverse $\Theta$ of $X$ for which $Y\Theta$ is Schur. The gain $K=U\Theta$ then gives $A'+B'K=Y\Theta-W'\Theta$ for every compatible model, so a strict Lyapunov inequality for $Y\Theta$ survives small process errors. Sensor errors create a different ambiguity. If $a^\top X+c^\top U=0$ with $a\ne0$, then for every $s$ sufficiently near one the rescaled trajectory $sx_t$ is consistent with the measurements and is explained, without process error, by $A'=A+va^\top$, $B'=s(B+vc^\top)$ for arbitrary $v$. A common gain would need $a^\top+sc^\top K=0$ for two distinct values of $s$, which forces $a=0$. Conversely, under \eqref{eq:information-rank} the compatible models, restricted to the used input directions, shrink to the true plant as the error bounds vanish. \par
\begin{example}[A scalar discontinuity] Take $A=2$, \mbox{$B=[1\ -2]$}, and the inputs $e_1,e_2,0$. The error-free state sequence is $(0,1,0,0)$. Exact-state alternatives satisfy $|A'+B'_2|\le\delta_w$, so $K=(0,1)^\top$ certifies every $\delta_w<1$. With any positive sensor-error bound, the underlying trajectory $(0,s,0,0)$ is consistent with the measurements for every $s$ sufficiently near one and is explained without process error by $A'=a$, $B'=[s\ -sa]$ for every $a\in\mathbb R$. For $K=(k_1,k_2)^\top$, the closed-loop scalar is $a(1-sk_2)+sk_1$. Stability for all $a$ forces $sk_2=1$; two distinct admissible values of $s$ make this impossible. \end{example} \par
The rank conditions concern one record; the minimum-duration question asks for one input sequence, fixed in advance, that satisfies them on every controllable plant. The following pulse sequences do so without resetting the state: \begin{align} U_{\mathrm{exact}}&:\ u_{jn}=e_{j+1}, & T_{\mathrm{exact}}&=mn+1, \label{eq:word-e}\\ U_{\mathrm{meas}}&:\ u_{j(n+1)}=e_{j+1}, & T_{\mathrm{meas}}&=m(n+1), \label{eq:word-s} \end{align} for $0\le j<m$; all other inputs are zero. Thus $U_{\mathrm{exact}}$ applies the unit pulses $e_1,\ldots,e_m$ every $n$ steps and $U_{\mathrm{meas}}$ every $n+1$ steps; both end with $n$ zero inputs. In $U_{\mathrm{exact}}$, the final zero input makes the last response $x_{mn}$ a column of $X$. \par
\begin{theorem}[Exact universal minimum durations]\label{thm:minimal} For real $n$-state, $m$-input plants, the minimum duration of a universal predetermined sequence is $mn+1$ with exact states and $m(n+1)$ for every fixed $\kappa>0$; $U_{\mathrm{exact}}$ and $U_{\mathrm{meas}}$ attain these minima. The lower bounds hold even for controllable diagonal plants with one eigenvalue in each of $n$ prescribed disjoint nonempty open intervals in $(0,1)$. For $m=1$, the common minimum $n+1$ is necessary even for deterministic causal policies. \end{theorem} \par
Thus any positive sensor uncertainty, however small, costs exactly $m-1$ additional transitions. \par

<!-- head-2: body_md -->
For exact states, suppose $a^\top X=0$; for measured states, suppose $a^\top X+c^\top U=0$. The pulse spacing tests the relevant relation against $Be_j,ABe_j,\ldots,A^{n-1}Be_j$, one actuator at a time, so controllability forces $a=0$. With measured states, each pulse column also forces the corresponding entry of $c$ to vanish. For the lower bound, the samples of any shorter sequence satisfy a nonzero polynomial relation, and a diagonal plant built from it yields a nonzero state-row dependence in the exact-state case, or a relation $a^\top X+c^\top U=0$ with $a\ne0$ in the measured-state case. Its poles may be chosen in the prescribed intervals. Counting polynomial coefficients gives $m(n+1)$ for measured states; the zero initial column gives $mn+1$ for exact states. \par
Set \begin{equation}\label{eq:short-tolerances} \begin{aligned} E_{\mathrm{exact}}&=\varepsilon_{mn+1}^0(U_{\mathrm{exact}};A,B),\\ E_{\mathrm{meas}}^\kappa&=\varepsilon_{m(n+1)}^\kappa(U_{\mathrm{meas}};A,B). \end{aligned} \end{equation} The subscripts name the sequences, not the measurement model: $E^0_{\mathrm{meas}}$ evaluates $U_{\mathrm{meas}}$ with exact states and need not equal $E_{\mathrm{exact}}$. Universality asks only that these tolerances be positive; the next section asks how large they are compared with the best possible experiment. \par

<!-- lemma-1: body_md -->
\label{lem:margin} Let $X,Y,U$ be real matrices of compatible sizes; they need not come from a trajectory or start at zero. Suppose $\Sigma_{\delta_w}(X,Y,U)$ is nonempty. If $\delta_w<r_{\mathrm{rec}}(X,Y)$, a certificate for $\Sigma_{\delta_w}(X,Y,U)$ can be computed from $(X,Y,U,\delta_w)$, with no rank assumption on $[X;U]$. If some real pair fits the record exactly, that is, $Y=AX+BU$, this condition is also necessary. Factor the controllability Gramian as $LL^\top=\mathcal C\mathcal C^\top$ and use the analysis coordinates $\bar x=L^{-1}x$. Then \[ \begin{gathered} \overline{\mathcal C}\,\overline{\mathcal C}^{\top}=I, \quad\|L^{-1}\|=1/\sigma_{\min}(\mathcal C),\\ \|L^{-1}W\|\le\delta_w/\sigma_{\min}(\mathcal C), \quad\|L^{-1}V\|\le\delta_v/\sigma_{\min}(\mathcal C), \end{gathered} \] where $\overline{\mathcal C}=L^{-1}\mathcal C$. Cayley--Hamilton bounds the normalized matrices using only $n$ and $M$. Together with the displayed identity, this places them in a compact family of controllable pairs. The error-free pulse records then have uniformly positive certification margins. The weak direction enters only through the error amplification $1/\sigma_{\min}(\mathcal C)$. This normalization depends on the unknown plant and is only for analysis; the procedure uses the observed data ($S$ above). \par
For the oracle bound, consider the error-free run of an arbitrary causal policy at a certified level; its record must still be certifiable. Polynomial (Chinese-remainder) identities split the roots of $p_A$ into three groups: inside, outside, and near the unit circle. Filtered responses bound the stable group, robustness to actuator perturbations bounds the unstable group, and the pencil bound \eqref{eq:margin-pencil} bounds each isolated root near the circle. Uniformly bounded polynomial coefficients then recombine these estimates along the least controllable direction. At no point is the norm of an eigenvector matrix or spectral projector estimated. The bound holds for every duration and policy, hence for $\Gamma$. Weak controllability can still reduce the absolute tolerance, but the theorem shows that it limits the oracle on the same scale. \par
