\label{gibPolyThm}
    Define sequence $(G_n)$ by $G_0 = a$, $G_1 = b$, and $G_n = rG_{n-1} + sG_{n-2}$ for $n \ge 2$, where $a$ and $b$  are not both zero, $r$ and $s$ are both nonzero, and $s \ne \frac{-r^2}{4}$.
    Then $(G_n)$ satisfies an identity of the form
    \begin{equation}\label{polyIdForm}
        G_{kn} = \sum_{i=0}^{\left\lfloor k/2 \right\rfloor}  (-s)^{ni} a_i G_n^{k-2i}
    \end{equation}
    for some coefficients $a_i$ (that depend only on the sequence $(G_n)$ and $k$) if one of the following cases holds:
    \begin{enumerate}[label=\bf{Case \arabic*.},leftmargin=46pt]
        \item $(G_n)$ is a geometric sequence and $k$ is a positive integer;
        \item the initial term $a=0$ and $k$ is a positive odd integer;
        \item $a$ divides $2b$, $r = \frac{2b}{a}$, and $k$ is a positive integer.
    \end{enumerate}
<!-- end theorem-1 -->
<!-- proof-1: body_md -->
The recurrence relation that defines $(G_n)$ has characteristic equation $t^2 - rt - s = 0$.
    The roots of the characteristic polynomial are 
    \[ t_{1,2} = \frac{r \pm \sqrt{r^2 + 4s}}{2} .\]
    Since $s \ne \frac{-r^2}{4}$, these roots are distinct.
    Thus, the terms of the sequence can be written using the Binet formula
    \[ G_n = c_1 t_1^n + c_2 t_2^n \] 
    for some coefficients $c_1$ and $c_2$.
    Note that since $s$ is nonzero, the roots $t_1$ and $t_2$ are also both nonzero.
    Using the initial values $a = c_1 + c_2$ and $b = c_1t_1 + c_2 t_2$, we find
    \[ c_1 = \frac{2b -ar + a\sqrt{r^2 + 4s}}{2\sqrt{r^2 + 4s}}  = \frac{b-at_2}{\sqrt{r^2 + 4s}}\]
    and
    \[ c_{2} = \frac{ar+ a\sqrt{r^2 + 4s} -2b}{2\sqrt{r^{2} + 4s}} = \frac{at_{1} -b}{\sqrt{r^2 + 4s}}.\]
    Assume without loss of generality that $c_1 \ne 0$ (otherwise swap indexes).

    Let $x = c_1t_1^n$ and $y = c_2t_2^n$.
    Substituting these values of $x$ and $y$ into the Girard-Waring formula (\cref{waring}), we obtain
    \begin{equation}\label{waring2}
        (c_1t_1^n)^k + (c_2t_2^n)^k = \sum_{i=0}^{\left\lfloor k/2 \right\rfloor} (-1)^i \frac{k}{k-i} \binom{k-i}{i} (c_1t_1^n + c_2t_2^n)^{k-2i} (c_1t_1^n c_2t_2^n)^i.
    \end{equation}
    On the left side, we can isolate the quantity $c_1 t_1^{kn} + c_2 t_2^{kn}$, which equals $G_{kn}$.
    To simplify the right side, note that $c_1 t_1^n + c_2 t_2^n = G_n$ and $t_1t_2 = -s$.
    The identity then becomes
    \begin{equation}\label{gibWaring}
        c_1^{k-1} G_{kn} + c_2\left( c_2^{k-1} - c_1^{k-1}\right) t_2^{kn} = \sum_{i=0}^{\left\lfloor k/2 \right\rfloor} (-1)^i \frac{k}{k-i} \binom{k-i}{i} (c_1c_2)^i (-s)^{ni} G_n^{k-2i}.
    \end{equation}

    Observe that \cref{gibWaring} is nearly in the desired form, but the left side contains the term $c_2\left( c_2^{k-1} - c_1^{k-1}\right) t_2^{kn}$, which we would like to eliminate.
    This term vanishes in three cases.
    \begin{enumerate}[label=\textbf{Case \arabic*:},leftmargin=55pt]
        \item If $c_2=0$, then the sequence $(G_n)$ is in fact a geometric sequence given by $G_n = c_1t_1^n$.
            In this case, \cref{gibWaring} reduces to the identity
            \begin{equation}\label{idCase1}
                G_{kn} = \frac{1}{c_1^{k-1}} G_n^k
            \end{equation}
            for all positive integers $k$.
            This is an identity in the form of \cref{polyIdForm} with $a_0 = \frac{1}{c_1^{k-1}}$ and all other $a_i = 0$.

    \item If $c_2 = -c_1$, then $\left( c_2^{k-1} - c_1^{k-1}\right) = 0$ when $k$ is odd.
        In this case, let $c = c_1 = -c_2$, and note that this implies the initial term $G_0 = a = 0$.
        Then \cref{gibWaring} reduces to the identity
        \begin{equation}\label{idCase2}
            G_{kn} = \sum_{i=0}^{\left\lfloor k/2 \right\rfloor} \frac{k}{k-i} \binom{k-i}{i} c^{2i-k+1} (-s)^{ni} G_n^{k-2i}
        \end{equation}
        for all positive odd integers $k$.
        This is an identity in the form of \cref{polyIdForm} with $a_i = \frac{k}{k-i} \binom{k-i}{i} c^{2i-k+1}$, for any sequence $(G_n)$ as defined above whose initial term is zero.
        
    \item If $c_2 = c_1$, then $\left( c_2^{k-1} - c_1^{k-1}\right) = 0$ and for all $k$.
        In this case, let $c = c_1 = c_2$. 
        Then \cref{gibWaring} reduces to the identity
        \begin{equation}\label{idCase3}
            G_{kn} = \sum_{i=0}^{\left\lfloor k/2 \right\rfloor} (-1)^i \frac{k}{k-i} \binom{k-i}{i} c^{2i-k+1} (-s)^{ni} G_n^{k-2i}
        \end{equation}
        for all positive integers $k$.
        This is an identity in the form of \cref{polyIdForm} with $a_i = (-1)^i \frac{k}{k-i} \binom{k-i}{i} c^{2i-k+1}$.

        Now $c_1 = c_2 = c$ exactly when the initial values are $a = 2c$ and $b = c(t_1 + t_2) = cr$, which implies that $r = \frac{2b}{a}$.
        Since we require $r$ to be an integer, we must have that $a$ divides $2b$.
        Thus, whenever $a$ divides $2b$ and $r = \frac{2b}{a}$, \cref{idCase3} holds for all positive integers $k$. 
                                                                 
        \qedhere
    \end{enumerate}

<!-- theorem-2: body_md -->
\label{genpoly}
    Let sequence $(G_n)$ be defined $G_0 = a$, $G_1 = b$, and $G_n = rG_{n-1} + sG_{n-2}$ for $n \ge 2$, where $a$ and $b$  are not both zero, $r$ and $s$ are both nonzero, and $s \ne \frac{-r^2}{4}$.
    Then 
    \begin{equation}\label{polyId1}
        G_{kn} = \sum_{i=0}^{k}  a_i(n) G_n^{i}
    \end{equation}
    where $a_0(n) = c_2 t_2^{kn} + \frac{(-c_2 t_2^{n})^k }{c_1^{k-1}}$ and $a_i(n) = \binom{k}{i} \frac{(-c_2 t_2^{n})^{k-i} }{c_1^{k-1}}$ for $i \in \{1, 2, \ldots, k\}$.
<!-- end theorem-2 -->
<!-- proof-2: body_md -->
The Binet formula for this sequence is $G_n = c_1 t_1^n + c_2 t_2^n$.
                                        
                                                                                                                             
                                                
                                           
                                      
    Assume without loss of generality that $c_1 \ne 0$ (otherwise swap indexes).
    Since $s \ne \frac{-r^2}{4}$, roots $t_1$ and $t_2$ are distinct, so Binet's formula allows us to rewrite \cref{polyId1} as
    \begin{equation}\label{proofEq1}
        c_1 t_1^{kn} + c_2 t_2^{kn} = \sum_{i=0}^k a_i(n) \left( c_1 t_1^n + c_2 t_2^n \right)^i.
    \end{equation}
    Expanding the right-hand side, we can rewrite \cref{proofEq1} as
    \begin{equation}\label{proofEq2}
        c_1 t_1^{kn} + c_2 t_2^{kn} = \sum_{i=0}^k \sum_{j=0}^k a_i(n) \binom{i}{j} (c_1 t_1^n)^j (c_2 t_2^{n})^{i-j}.
    \end{equation}
    
    By separating out distinct powers of $t_1$, we can rewrite \cref{proofEq2} as $k+1$ distinct equations, each of which is linear in the coefficients $a_i(n)$.
    Equation \cref{proofEq2} can be then written in matrix form as follows:    
    \begin{equation}\label{proofMxEq}
        \begin{bmatrix}
            c_2 t_2^{kn} \\ 0 \\ 0 \\ \vdots \\ 0 \\ c_1
        \end{bmatrix}
        = 
        \begin{bmatrix}
            1 & c_2 t_2^{n} & c_2^2 t_2^{2n} & \cdots & c_2^{k-1} t_2^{(k-1)n} & c_2^k t_2^{kn} \\ 
            0 & c_1 & 2c_1c_2 t_2^{n} & \cdots & (k-1) c_1 c_2^{k-2} t_2^{(k-2)n} & k c_1 c_2^{k-1} t_2^{(k-1)n} \\
            0 & 0 & c_1^2 &  \cdots & \binom{k-1}{2} c_1^2 c_2^{k-3} t_2^{(k-3)n} & \binom{k}{2} c_1^2 c_2^{k-2} t_2^{(k-2)n} \\
            \vdots & \vdots & \vdots & \ddots & \vdots & \vdots \\
            0 & 0 & 0 & \cdots & c_1^{k-1} & k c_1^{(k-1)} c_2 t_2^{n} \\
            0 & 0 & 0 & \cdots & 0 & c_1^{k} \\
        \end{bmatrix}
        \begin{bmatrix}
            a_0(n) \\ a_1(n) \\ a_2(n) \\ \vdots \\ a_{k-1}(n) \\ a_{k}(n)
        \end{bmatrix}.
    \end{equation}
    In the square matrix above, the entry in row $j$ column $i$ (indexing rows and columns from $0$ to $k$) is 
    \[ \binom{i}{j} c_1^j (c_2 t_2^{n})^{i-j}. \]
    Importantly, since since $c_1 \ne 0$, this matrix has nonzero determinant.
    Therefore, there exist coefficients $a_i(n)$ that satisfy \cref{polyId1}.
    These coefficients are:
    \begin{align*}
       a_0(n) &= c_2 t_2^{kn} + \frac{(-c_2 t_2^{n})^k }{c_1^{k-1}},   \\
       a_i(n) &= \binom{k}{i} \frac{(-c_2 t_2^{n})^{k-i} }{c_1^{k-1}} \quad \text{for} \quad i \in \{1, 2, \ldots, k\}.
    \end{align*}

    To verify this solution, consider row $j \in \{1, 2, \ldots, k-1\}$ of the matrix product in \cref{proofMxEq}. This row of the product is:
    \begin{align*}
        \sum_{i=j}^k \binom{i}{j} c_1^j (c_2 t_2^{n})^{i-j} \cdot a_i(n) 
        &= \sum_{i=j}^k \binom{i}{j} c_1^j (c_2 t_2^{n})^{i-j} \cdot \binom{k}{i} \frac{(-c_2 t_2^{n})^{k-i} }{c_1^{k-1}} \\
        &= \frac{(c_2t_2^n)^{k-j}}{c_1^{k-j-1}} \sum_{i=j}^k (-1)^{k-i} \binom{i}{j}\binom{k}{i} = 0,
    \end{align*}
    where the last equality is due to the binomial coefficient orthogonality identity.
    The justification for row $0$ of the product is essentially the same, except that $a_0(n)$ adds the $c_2t_2^{kn}$ term that is found on the left side of \cref{proofMxEq}.
    For row $k$ of \cref{proofMxEq}, it is straightforward to verify that $c_1^k \cdot a_k(n) = c_1$.

<!-- proposition-1: body_md -->
Define sequence $(G_n)$ by $G_0 = a$, $G_1 = b$, and $G_n = 2\ell G_{n-1} - \ell^2 G_{n-2}$ for $n \ge 2$, where integers $a$ and $b$ are not both zero, and $\ell$ is a nonzero integer.
    Then $(G_n)$ satisfies polynomial identities in the following cases.
    \begin{enumerate}[label=\bf{Case \arabic*.},leftmargin=46pt]
        \item If $b = a\ell$, then $(G_n)$ is a geometric sequence and
            \begin{equation}\label{repeatedRootsGeoId}
                G_{kn} = \frac{1}{a^{k-1}} G_n^k.
            \end{equation}
        \item If $\ell = 1$, then $(G_n)$ is an arithmetic sequence and
            \begin{equation}\label{repeatedRootsArithId}
                G_{kn} = kG_n + (1-k)a.
            \end{equation}
        \item If $\ell = -1$, then $(G_n)$ is an alternating arithmetic sequence and
            \begin{equation}\label{repeatedRootsAltArithId}
                G_{kn} = (-1)^{(k-1)n}kG_n + (-1)^{kn}(1-k)a.
            \end{equation}
    \end{enumerate}
<!-- end proposition-1 -->
<!-- proof-5: body_md -->
We proceed case by case.

    \textbf{Case 1.} If $b = a\ell$, then $G_n = a\ell^n$ for all nonnegative integers $n$. 
        Thus, $(G_n)$ is a geometric series and satisfies the identity $G_{kn} = \frac{1}{a^{k-1}} G_n^k$.

    \textbf{Case 2.} If $\ell = 1$, then Binet's formula becomes $G_n = a + (b-a)n$.
        This means that $(G_n)$ is an arithmetic sequence. By Binet's formula and simple algebra,
        \begin{align*}
            G_{kn} &= a + (b-a)kn \\
            &= k(a + (b-a)n) - (k-1)a \\
            &= kG_n - (k-1)a,
        \end{align*}
        which is \cref{repeatedRootsArithId}.

    \textbf{Case 3.} If $\ell = -1$, then Binet's formula becomes $G_n = (a -n(a+b))(-1)^n$.
        Thus, $(G_n)$ is an alternating arithmetic sequence.
        \begin{align*}
            G_{kn} &= (a -kn(a+b))(-1)^{kn} \\
            &= (ak -kn(a+b))(-1)^{kn} - ak(-1)^{kn} + a(-1)^{kn} \\
                                                                            
            &= (-1)^{(k-1)n}kG_n + (-1)^{kn}(1-k)a,
        \end{align*}
        which is \cref{repeatedRootsAltArithId}.
        \qedhere
