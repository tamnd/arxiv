<!-- proposition-1: body_md -->
\label{lem:nfl}
Consider a function $f^*:\mathbb Z_n\rightarrow\mathbb Z_k$, and let $D_\mathrm{train}\subset\mathbb Z_n$ be a set of $|D_\mathrm{train}|=m<n$ observations. Then, there are exactly $k^{n-m}$ functions $f:\mathbb Z_n\rightarrow\mathbb Z_k$ consistent with these observations, in the sense that $f(x)=f^*(x)$ for all $x\in D_\mathrm{train}$.
At every unobserved $x'\in\mathbb Z_n\setminus D_\mathrm{train}$, for every $y' \in \mathbb Z_k$, exactly $k^{n-m-1}$ of the functions consistent with $f^*$ on $D_\mathrm{train}$ have $f(x')=y'$.
<!-- end proposition-1 -->
<!-- corollary-1: body_md -->
\label{thm:meta-nfl}
    Take $N$ prediction problems, with the $i$th revealing a function $g_i:\mathbb Z_n \to \mathbb Z_k$.
    After observing $g_1,\ldots,g_m$ with $m<N$, there remain $k^{(N-m)n}$ consistent meta-mappings $i\mapsto g_i$, exactly $k^{(N-m-1)n}$ of which predict each of the $k^n$ possible choices for $g_{m+1}$.
<!-- end corollary-1 -->
<!-- proof-1: body_md -->
Uniquely label each function $g:\mathbb Z_n \to \mathbb Z_k$ by a number $\operatorname{enc}(g)\in\mathbb Z_{k^n}$.
    Now consider the problem of learning the meta-function $f:\mathbb Z_{N}\rightarrow\mathbb Z_{k^n}$ given by $f(i) := \operatorname{enc}(g_{i+1})$. The result follows from applying \cref{lem:nfl} with $n,k,D_\mathrm{train},x'$ replaced by $N,k^n,\mathbb Z_m,m$, respectively.

<!-- theorem-2: body_md -->
\label{thm:noinfoexnihilo}
Let $r\in\mathbb B^*$ be such that the randomly generated string $p := U^q(r\beta)$ is infinitely long for almost all $\beta\sim\lambda$. Then, for all $x\in\mathbb B^*$,
\begin{equation*}
\operatorname{\mathbb E}_p \left[\mathit{MI}^q(p:x)\right]
\le \log_2 \operatorname{\mathbb E}_p \left[2^{\mathit{MI}^q(p:x)}\right]
 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 |r|.
\end{equation*}
<!-- end theorem-2 -->
<!-- proof-4: body_md -->
Consider again the machine $T_j^q(\alpha\oplus\beta) := U^{U^q(\beta)\oplus q}(\alpha)$. A random string $\gamma\sim\lambda$ has probability $2^{-|\bar j|-|r|}$ of having the form $\bar j (\alpha\oplus r\beta)$ for some $\alpha,\beta\in\mathbb B^\infty$. Since $j$ is constant,
\begin{align*}
M^q(x)
&= \mathbb P_{\gamma\sim\lambda}\left(x\sqsubseteq U^q(\gamma)\right)
\\& 
  \mathrel{\smash{\mathchoice
    {\stackrel{\times}{\ge}} 
    {\scriptstyle\stackrel{\times}{\ge}} 
    {\scriptstyle\stackrel{\times}{\ge}} 
    {\scriptscriptstyle\stackrel{\times}{\ge}} 
  }} 
 2^{-|r|} \mathbb P_{\alpha,\beta\sim\lambda}\left(x\sqsubseteq U^q(\bar j(\alpha\oplus r\beta))\right)
\\&= 2^{-|r|} \operatorname{\mathbb E}_{\beta\sim\lambda}\mathbb P_{\alpha\sim\lambda}\left(x\sqsubseteq T_j^q(\alpha\oplus r\beta)\right)
\\&= 2^{-|r|} \operatorname{\mathbb E}_{\beta\sim\lambda}\mathbb P_{\alpha\sim\lambda}\left(x\sqsubseteq U^{U^q(r\beta)\oplus q}(\alpha)\right)
\\&= 2^{-|r|} \operatorname{\mathbb E}_p \mathbb P_{\alpha\sim\lambda}\left(x\sqsubseteq U^{p\oplus q}(\alpha)\right)
\\&= 2^{-|r|} \operatorname{\mathbb E}_p M^{p\oplus q}(x).
\end{align*}

Rearranging, and applying the definition \labelcref{eq:mutinf},
\[\operatorname{\mathbb E}_p \left[2^{\mathit{MI}^q(p:x)}\right]
= \frac{\operatorname{\mathbb E}_p M^{p\oplus q}(x)}{M^q(x)}
 
  \mathrel{\smash{\mathchoice
    {\stackrel{\times}{\le}} 
    {\scriptstyle\stackrel{\times}{\le}} 
    {\scriptstyle\stackrel{\times}{\le}} 
    {\scriptscriptstyle\stackrel{\times}{\le}} 
  }} 
 2^{|r|}.\]
The result now follows from Jensen's inequality.

<!-- theorem-3: body_md -->
\label{thm:prefixinformation}
Suppose $p,q\in\mathbb B^\infty$ and $r,x\in\mathbb B^*$, with $r$ belonging to a fixed computably enumerable set, no member of which is a proper prefix of another. Then,
\begin{equation*}
\mathit{MI}^q(rp:x)
 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 |r| + \mathit{MI}^q(p:x).
\end{equation*}
<!-- end theorem-3 -->
<!-- proof-5: body_md -->
Since $r$ is self-delimiting, there exists a fixed machine $T_j$ that reads $r$, and simulates $U$ on a modified oracle and program, so that $T_j^{p\oplus q}(r\alpha) := U^{(rp)\oplus q}(\alpha)$. A random string $\gamma\sim\lambda$ has probability $2^{-|\bar j|-|r|}$ of starting with $\bar j r$. Since $j$ is constant,
\begin{align*}
M^{p\oplus q}(x)
&= \mathbb P_{\gamma\sim\lambda}
   \left(x\sqsubseteq U^{p\oplus q}(\gamma)\right)
\\& 
  \mathrel{\smash{\mathchoice
    {\stackrel{\times}{\ge}} 
    {\scriptstyle\stackrel{\times}{\ge}} 
    {\scriptstyle\stackrel{\times}{\ge}} 
    {\scriptscriptstyle\stackrel{\times}{\ge}} 
  }} 
 2^{-|r|}
   \mathbb P_{\alpha\sim\lambda}
   \left(x\sqsubseteq U^{p\oplus q}(\bar j r\alpha)\right)
\\&= 2^{-|r|}
   \mathbb P_{\alpha\sim\lambda}
   \left(x\sqsubseteq T_j^{p\oplus q}(r\alpha)\right)
\\&= 2^{-|r|}
   \mathbb P_{\alpha\sim\lambda}
   \left(x\sqsubseteq U^{(rp)\oplus q}(\alpha)\right)
\\&= 2^{-|r|} M^{(rp)\oplus q}(x).
\end{align*}
Applying the definition \labelcref{eq:mutinf},
\[
\mathit{MI}^q(rp:x) - \mathit{MI}^q(p:x)
= \log_2\frac{M^{(rp)\oplus q}(x)}{M^{p\oplus q}(x)}
 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 |r|.
\qedhere \]

<!-- corollary-2: body_md -->
\label{cor:oraclesolcomputable}
For all $p,q\in\mathbb B^\infty$ such that $\mu_p$ is a probability measure (i.e.\ not merely a semimeasure), and $t\in\mathbb N$, we have
\begin{equation*}
L_t(M^q,\,\mu_p)-\inf_\nu L_t(\nu,\,\mu_p)
 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 \mathit{KM}^q(p)
.\end{equation*}
<!-- end corollary-2 -->
<!-- proof-6: body_md -->
\Cref{thm:oraclesolregret,thm:infobounds} together imply
\[L(M^q,\,x)-L(\mu_p,\,x)
 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 \mathit{KM}^q(p).\]
Taking $x$ to be the first $t$ bits generated by $\mu_p$, and taking expectations,
\[L_t(M^q,\,\mu_p)-L_t(\mu_p,\,\mu_p)
 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 \mathit{KM}^q(p).\]

Hence, for every semimeasure $\nu$ (computable or otherwise),
\begin{align*}
L_t(M^q,\,\mu_p)-L_t(\nu,\,\mu_p)
& 
  \mathrel{\smash{\mathchoice
    {\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptstyle\stackrel{+}{\le}} 
    {\scriptscriptstyle\stackrel{+}{\le}} 
  }} 
 \mathit{KM}^q(p) + L_t(\mu_p,\,\mu_p)-L_t(\nu,\,\mu_p)
\\&= \mathit{KM}^q(p) - \operatorname{\mathbb E}_{x\sim\mu_p}\left[\log\frac{\mu_p(x_{\le t})}{\nu(x_{\le t})}\right]
\\&= \mathit{KM}^q(p) - D_\mathrm{KL}\left(\mu_p(\cdot_{\le t})\mathrel\Vert\nu(\cdot_{\le t})\right)
\\&\le \mathit{KM}^q(p).
\end{align*}
In the last line, we used the fact that the Kullback-Leibler divergence is non-negative even when the second argument is a semimeasure; normalizing would only decrease its value.
Taking the supremum of both sides over all semimeasures $\nu$ completes the proof.

<!-- proposition-3: body_md -->
\label{thm:translate-rad}
    Let $\mathcal H$ be any set of functions $\mathcal X \to \mathbb R$,
    $f : \mathcal X \to \mathbb R$ any function,
    and write $\mathcal H + \{ f \} := \{ x \mapsto h(x) + f(x) : h \in \mathcal H \}$.
    Then $\operatorname{Rad}_{\mathcal D^m}(\mathcal H + \{f\}) = \operatorname{Rad}_{\mathcal D^m}(\mathcal H)$.
<!-- end proposition-3 -->
<!-- proof-7: body_md -->
Since $f$ does not interact with $h$
    and $\operatorname{\mathbb E} \sigma_i = 0$,
    we have
    \[
        \operatorname{\mathbb E}\left[ \sup_{h' \in \mathcal H + \{f\}}
        \sum_i \sigma_i h'(x_i) \right]
        = 
        \operatorname{\mathbb E} \sup_{h \in \mathcal H} \left[
        \sum_i \sigma_i h(x_i)
        + \sum_i \sigma_i f(x_i)
        \right]
        = 
        \operatorname{\mathbb E} \sup_{h \in \mathcal H} \left[
        \sum_i \sigma_i h(x_i)
        \right]
    .\qedhere\]

<!-- proposition-4: body_md -->
\label{thm:vc-xor}
    Define the operation
    $a \mathbin{\mathtt{xor}} b := \mathds{1}(a \ne b)$ for $a, b \in \{0, 1\}$.
    Write $\mathcal H \mathbin{\mathtt{xor}} f := \{ x \mapsto h(x) \mathbin{\mathtt{xor}} f(x) : h \in \mathcal H \}$.
    Then, $\operatorname{VCdim}(\mathcal H \mathbin{\mathtt{xor}} f) = \operatorname{VCdim}(\mathcal H)$.
<!-- end proposition-4 -->
<!-- proof-8: body_md -->
Let $h_1, \dots, h_N \in \mathcal H$
    be hypotheses
    achieving the vectors of labels $y_1, \dots, y_N \in \{0, 1\}^{\abs X}$
    for the points in a set $X$.
    Write $y$ for the vector of labels achieved by $f$ on $X$.
    Then $h_1 \mathbin{\mathtt{xor}} f, \dots, h_N \mathbin{\mathtt{xor}} f$
    achieve the labels $y_1 \mathbin{\mathtt{xor}} y, \dots, y_N \mathbin{\mathtt{xor}} y$,
    with $\mathbin{\mathtt{xor}}$ elementwise.
    As xor is a bijection,
    the number of labelings in each set is the same;
    thus $\mathcal H$ shatters $X$ iff $\mathcal H \mathbin{\mathtt{xor}} f$ does.

<!-- proposition-5: body_md -->
Let $\mathcal H$ be a class of functions from $\mathcal X$ to $\mathcal Y \subseteq \mathbb N$.
    For each $x \in \mathcal X$, let $\pi_x$ be an arbitrary bijection on $\mathcal Y$,
    and let $\pi \circ \mathcal H = \{ x \mapsto \pi_x(h(x)) : h \in \mathcal H \}$.
    Then the Natarajan dimensions \citep{natarajan-dim} of $\mathcal H$ and $\pi \circ \mathcal H$ are equal;
    the same is true for the DS dimension \citep{ds-dim}.

<!-- definition-1: body_md -->
When $Z = (z_1, \dots, z_m)$,
    let $Z_{\lnot i}$ denote $(z_1, \dots, z_{i-1}, z_{i+1}, \dots, z_m)$.
    A (possibly randomized) learning algorithm $\mathcal A$ is
    \emph{$\beta(m)$-uniformly stable} if for all $m \ge 1$,
    \[
        \sup_{\substack{Z \in \mathcal Z^m, \, i \in [m] \\ z \in \mathcal Z}}
        \abs{\operatorname{\mathbb E}_{\mathcal A} \ell(\mathcal A(Z_{\lnot i}), z) - \operatorname{\mathbb E}_{\mathcal A} \ell(\mathcal A(Z), z)}
        \le \beta(m)
    .\]
    We say an algorithm is \emph{uniformly stable} if $\lim_{m \to \infty} \beta(m) = 0$.
