<!-- remark-1: body_md -->
It is obvious that the proof system $\mathcal{S}{\sf CL}_{\omega_1}$ has the sub-formula property:
    for any partial $\mathcal{S}{\sf CL}_{\omega_1}$ proof-tree with $\Gamma$ at its root,
    all the formulas appearing above it are  also in ${\sf sub}(\Gamma)$.
<!-- end remark-1 -->
<!-- theorem-1: body_md -->
\@gobble{SCLA-sound-comp}
$\mathcal{S}{\sf CL}_{\omega_1}$ is sound and complete for classical interpretations,
i.e.~for every sequent $\Gamma_0$, we have
$\mathcal{S}{\sf CL}_{\omega_1}\vdash  \Gamma_0$ iff $\models \Gamma_0$.
<!-- end theorem-1 -->
<!-- proof-1: body_md -->
The soundness is by a straightforward transfinite induction on the proof-tree. So we only treat the completeness part.
Let $\mathcal{S}{\sf CL}_{\omega_1}\nvdash \Gamma_0$.
We find a model $I$ such that  $I\not\models \Gamma_0$.


Before we continue with the proof, let us fix some notation.
Let $B_0,B_1,\ldots $ be an enumeration of all  formulas in ${\sf sub}(\Gamma_0)$ such that each formula
appears infinitely often. Notice that such an enumeration exists since ${\sf sub}(\Gamma_0)$ is countable.
Also let us fix a pairing function $\langle \cdot,\cdot\rangle\colon\mathbb{N}\times\mathbb{N}\to\mathbb{N}$
that is a bijection and satisfies $\langle i,j\rangle \geq  i$.

We first define, by recursion on $n$, a partial $\mathcal{S}{\sf CL}_{\omega_1}$-proof tree $T_n$ as follows.
$T_0$ is a single-node tree whose root is labelled by $\Gamma_0$.
Then assuming that $T_n$ is already defined and
$n+1=\langle i,j\rangle$, for every non-trivial sequent $\Gamma$
appearing as a label of a leaf $w$ in $T_n$ such that  $B_i\in\Gamma$,
we do the following:
\begin{itemize}
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax  If $B_{i}=\bigvee X$ and $B_j\in X$: then add $\Gamma,B_j$ above the
node $w$ in $T_n$ and label its edge by $\vee$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax If $B_i=\bigwedge X$:
then for any $B\in X$, add $\Gamma,B$
above $w$ labeling the edges by $\wedge$. Notice in particular that if $X=\emptyset$,
we do not add any node above $w$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax In other cases, do not add any node above $w$ in $T_n$.
\end{itemize}
Then, let $T^*$ be the union of all partial proofs $T_n$.
Since $\mathcal{S}{\sf CL}_{\omega_1}\nvdash A$,
$T^*$ cannot be an $\mathcal{S}{\sf CL}_{\omega_1}$ proof-tree. Therefore, either there exists an infinite
branch in the proof-tree labelled by $\Gamma_0\subseteq\Gamma_1\subseteq\ldots$, or there is a leaf sequent $\Gamma^*$ that is not an axiom.
In the first case we put $\Gamma^*:=\bigcup_{n=0}^\infty\Gamma_n$. In both cases, it is straightforward to verify that
the following properties hold for $\Gamma^*$:
\begin{itemize}
 \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\Gamma_0\subseteq\Gamma^*$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax For any atomic $p$, either $p\not\in\Gamma^*$ or $\overline{p}\not\in\Gamma^*$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax If $\bigvee X\in\Gamma^*$, then $X\subseteq\Gamma^*$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax If $\bigwedge X\in\Gamma^*$, then $X\cap\Gamma^*$ is non-empty.
\end{itemize}
Then define $I\models p$ iff $\overline{p}\in \Gamma^*$. By induction on the construction
of $B$, using the properties listed above for $\Gamma^*$, one may easily show that
for every $B\in\Gamma^*$ we have $I\not\models B$. Therefore $I\not\models \Gamma_0$, as desired.

<!-- definition-1: body_md -->
A labelled rooted tree\footnote{A tree is a partially-ordered set $(T,<)$ such that for every
$w\in T$, the set $\{u\in W: u\leq w\}$ is a finite linear ordering. A labelled tree is a tree with all of its nodes labelled.} is called a
\textit{non-well-founded nested tree} if all leaves are labelled by $\mathcal{L}^\Box_{\omega_1}$-formulas, its root is
labelled by ${\sf root}$, and the other nodes are labelled by $[\,]$. A non-well-founded nested tree is called a
general nested tree if it is conversely well-founded, i.e.~no infinite  branch exists.
Finally, a finite  non-well-founded nested tree is simply called a nested tree.

<!-- lemma-1: body_md -->
\@gobble{lem-cut}
    Let  $\delta$ be an occurrence of $\Delta$ in $\Gamma$, with $\Delta$ and $\Gamma$ being general nested sequents.
    Also let $\mathcal{K}=(W,\sqsubset,\mathrel{\textup{E}},S)$ be a Kripke model, and $w\in W$. Then $\mathcal{K},w\models \Gamma$ iff there is an
    occurrence ${\delta}^{\scriptscriptstyle{{\Gamma}}}_{\scriptscriptstyle{\!{\Delta}}}$ such that for every  $u\in W$ with
    ${w}\sqsubset_{r({{\delta}^{\scriptscriptstyle{{}}}_{\scriptscriptstyle{\!{}}}})}{u}$ we have
    $\mathcal{K},u\models\Delta$.
<!-- end lemma-1 -->
<!-- proof-3: body_md -->
For the left-to-right direction, take $\delta$ to be the root occurrence in $\Gamma$.
For the other direction, let $\mathcal{K},w\not\models \Gamma$. By induction on
$n=r({{\delta}^{\scriptscriptstyle{{}}}_{\scriptscriptstyle{\!{\Delta}}}})$, we show that there is some $u$ with ${w}\sqsubset_{n}{u}$
such that  $\mathcal{K},u\not\models\Delta$.
The case $n=0$ is obvious. So assume that $r({\delta})>0$. Then ${\delta}^{\scriptscriptstyle{{\Gamma}}}_{\scriptscriptstyle{\!{\Delta}}}$
is an immediate sub-occurrence of
the occurrence ${\theta}^{\scriptscriptstyle{{\Gamma}}}_{\scriptscriptstyle{\!{\Theta}}} $. This means that $[\Delta]\in\Theta$.
By the induction hypothesis, there is some $v$ with ${w}\sqsubset_{r({\theta})}{v}$ such that $\mathcal{K},v\not\models\Theta$.
Since $[\Delta]\in\Theta$, this implies $\mathcal{K},u\not\models \Delta$ for some $v\sqsubset u$.
Therefore, by definition, we have ${w}\sqsubset_{r({\theta})+1}{u}$.  Since
$r({\delta})=r({\theta})+1$, we have the desired result.
<!-- end proof-3 -->

<!-- proof-4: body_md -->
We prove the soundness of $\mathcal{S}{\sf K4}_{\omega_1}$ and leave the similar argument for $\mathcal{S}{\sf K}_{\omega_1}$ to the reader.
Let $\mathcal{P}$ be a $\mathcal{S}{\sf K4}_{\omega_1} $-proof tree for $\Gamma_0$. Also assume that $\mathcal{K}=(W,\sqsubset,\mathrel{\textup{E}},S)$
is a transitive model supporting $\Gamma_0$ such that $\mathcal{K},w_0\not\models \Gamma_0$. We show that there is an
infinite branch in the proof-tree, a contradiction.


We inductively define a sequence $\{\Gamma_n\}_{n\in\omega}$ of nested sequents
 and  functions $f_n$ with the following properties:
 \begin{enumerate}
 \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\Gamma_0,\Gamma_1,\Gamma_2,\ldots, \Gamma_n$ is a branch in the proof-tree.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The domain of $f_n$ is the set of all occurrences
in $\Gamma_n$ and its co-domain is $W$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\mathcal{K},f_n(\delta)\not\models\Delta$,
for every occurrence $\delta$ of $\Delta$ in $\Gamma_n$.
 \end{enumerate}

Let us now define $\Gamma_n$ and $f_n$ with the above properties.
We only provide the definitions and leave the straightforward arguments for showing
the required properties 1--3 to the reader.
As the induction hypothesis, assume that we have already defined $f_m$ and $\Gamma_m$ for
every $m<n$, satisfying properties 1--3.
We have the following cases:
\begin{itemize}
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax   $n=0$:                                                        
                                                                                                
                                                                                                                        
                                                                                
                                                                                          
                                                                                                
                                                                             
Given an occurrence $\delta$ of $\Delta$ in $\Gamma_0$, by \Cref{lem-cut}, there is some $u\sqsupseteq w_0$ such that
$\mathcal{K},u\not\models \Delta$. Define $f_n(\delta):=u$ for some such $u$.
                                                                       
                                                                    
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $n>0$ and $\Gamma_{n-1}$ is derived by the $\neg$-rule:
Let $\Gamma_{n-1}={\Gamma}\{\Delta,B,\neg B\}$ with $\delta$ being the designated occurrence
of $\Delta,B,\neg B$ in $\Gamma_{n-1}$. Then by IH3
(i.e.~item 3 of the induction hypothesis) we have
$\mathcal{K},f_{n-1}(\delta)\not\models \Delta,B,\neg B$. Therefore,
$\mathcal{K},f_{n-1}(\delta)\not\models  B $ and $\mathcal{K},f_{n-1}(\delta)\not\models  \neg B $,
a contradiction. This shows that this case is impossible.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $n>0$ and $\Gamma_{n-1}$ is derived by the $\vee$-rule:
define $\Gamma_n$ to be the sequent just above $\Gamma_{n-1}$.
Then $\Gamma_n$ and $\Gamma_{n-1}$ share the same set of occurrences.
Therefore, for any occurrence $\delta$ in $\Gamma_{n-1}$, we define
$f_n({\delta}^{\scriptscriptstyle{{\Gamma_n}}}_{\scriptscriptstyle{\!{}}}):=f_{n-1}(\delta)$.
                                                                    
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $n>0$ and $\Gamma_{n-1}$ is derived by the $\wedge$-rule:
let $\Gamma_{n-1}={\Gamma}\{\Theta,\bigwedge\Delta\}$, with $\delta$
being the designated occurrence
of $\Theta,\bigwedge\Delta$ in $\Gamma_{n-1}$. By IH3 we have
$\mathcal{K},f_{n-1}(\delta)\not\models \bigwedge\Delta$. Therefore, there is some $B\in\Delta$
such that $\mathcal{K},f_{n-1}(\delta)\not\models B$.
Define $\Gamma_n:={\Gamma}\{\Theta,B,\bigwedge\Delta\}$.
Then $\Gamma_n$ and $\Gamma_{n-1}$ share the same set of occurrences.
Therefore, for any occurrence $\delta$ in $\Gamma_{n-1}$, we define
$f_n({\delta}^{\scriptscriptstyle{{\Gamma_n}}}_{\scriptscriptstyle{\!{}}}):=f_{n-1}(\delta)$.
                                                                    
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax   $n>0$ and $\Gamma_{n-1}$ is derived by the $\lozenge$-rule:
define $\Gamma_n$ to be the sequent just above $\Gamma_{n-1}$.
Then $\Gamma_n$ and $\Gamma_{n-1}$ share the same set of occurrences.
Therefore, for any occurrence $\delta$ in $\Gamma_{n-1}$, we define
$f_n({\delta}^{\scriptscriptstyle{{\Gamma_n}}}_{\scriptscriptstyle{\!{}}}):=f_{n-1}(\delta)$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $n>0$ and $\Gamma_{n-1}$ is derived by the $\Box$-rule:
then $\Gamma_{n-1}={\Gamma_{n-1}}\{\Theta,\Box B\}$
is derived from  $\Gamma_n:={\Gamma_{n-1}}\{\Theta,[B],\Box B\}$.
Let $\theta$ be the occurrence of $\Theta,\Box B$ in $\Gamma_{n-1}$.
The set of occurrences in
$\Gamma_n$ has exactly one additional occurrence which is not in $\Gamma_{n-1}$
(this is the only case in which a new occurrence is introduced),
namely $\delta$, the occurrence of the newly added bracket $[B]$ in $\Gamma_n$.
By the induction hypothesis (item 3), we have $\mathcal{K},f_{n-1}(\theta)\not\models \Box B$.
Therefore, there is some $u\in W$ with $f_{n-1}(\theta)\sqsubset u$. Define $f_n(\delta):=u$.
For all occurrences $\tau$ in $\Gamma_{n-1}$, define
$f_n({\tau}^{\scriptscriptstyle{{\Gamma_n}}}_{\scriptscriptstyle{\!{}}}):= f_{n-1}(\tau)$.
\qedhere
\end{itemize}

<!-- proof-5: body_md -->
Let $\mathcal{P}$ be a ${\mathcal{S}{\sf GL}_{\omega_1}^{{\!\infty}}} $-proof tree for $\Gamma_0$. Also assume that $\mathcal{K}=(W,\sqsubset,\mathrel{\textup{E}},S)$
supports $\Gamma_0$, that $\sqsubset$ is transitive, and that $\mathcal{K},w_0\not\models \Gamma_0$.
We show that there is an infinite sequence $ w_0\sqsubset w_1\sqsubset\ldots$. Therefore, $(W,\sqsubset)$ is not conversely well-founded.
Notice that this implies the desired soundness.

We define recursively a sequence $\{\Gamma_n\}_{n\in\omega}$ of nested sequents
 and  functions $f_n$ with the following properties:
 \begin{enumerate}
 \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\Gamma_0,\Gamma_1,\Gamma_2,\ldots, \Gamma_n$ is a branch in the proof-tree.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The domain of $f_n$ is the set of all occurrences
in $\Gamma_n$ and its co-domain is $W$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\mathcal{K},f_n(\delta)\not\models\Delta$,
for every occurrence $\delta$ of $\Delta$ in $\Gamma_n$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax If $\theta$ is a strict sub-occurrence of $\delta$,
then $f_n(\delta)\sqsubset f_n(\theta)$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The family of functions
$\{f_m\}_{m\leq n}$ is
compatible: if
$\delta$ is an occurrence in $\Gamma_m$ and $m<n$, then
$f_m({\delta}^{\scriptscriptstyle{{}}}_{\scriptscriptstyle{\!{}}})=f_{n}({\delta}^{\scriptscriptstyle{{\Gamma_n}}}_{\scriptscriptstyle{\!{}}})$.
Notice that, since $\Gamma_n$ appears above $\Gamma_m$ in the proof-tree,
every occurrence $\delta $ in $\Gamma_m$
can also be considered as an occurrence in $\Gamma_n$, denoted by
${\delta}^{\scriptscriptstyle{{\Gamma_n}}}_{\scriptscriptstyle{\!{}}}$.
 \end{enumerate}

Exactly the same definitions as in the proof of \Cref{dsk-soundness} work here.
 Since  $\{\Gamma_n\}_{n\in\omega}$ is an infinite branch in a ${\mathcal{S}{\sf GL}_{\omega_1}^{{\!\infty}}}$-proof tree,
it must include infinitely many
nested  $\Box$-rules. Namely, let $I$ be an infinite set of indices
such that
$\{\AxiomC{$\Gamma_i$}\UnaryInfC{$\Gamma_{i-1}$} \DisplayProof \}_{i\in I}$
is an infinite sequence of nested $\Box$-rules.
Hence, for each $i\in I$, there are $A_i$ and $\Theta_i$  such that 
$\Gamma_i={\Gamma_i}\{\Theta_i,[A_i],\Box A_i\}$ is the nested sequent
in the premise of the $\Box$-rule, with $\delta_i$ being the occurrence of
$A_i$ in the bracket.  Therefore, for every $i,j\in I$ with $j>i$,
$\delta_{j}$ is a strict sub-occurrence of ${\delta_i}^{\scriptscriptstyle{{\Gamma_{j}}}}_{\scriptscriptstyle{\!{}}}$.
Define $w_{i}:=f_{i}(\delta_{i})$.
By items 3 and 4, for every
$i,j\in I$ with $i<j$, we have $w_i\sqsubset w_j$.
Given that $I$ is infinite, we have the desired infinite ascending sequence of worlds.

<!-- lemma-2: body_md -->
\@gobble{saturation-dgla}
For every  weakly cosaturated non-well-founded nested sequent $\Gamma$,
every occurrence $\delta$ of $\Delta$ in $\Gamma$, and every
$B\in \Delta\cap\mathcal{L}^\Box_{\omega_1}$,
we have $\mathcal{K}_\Gamma,\delta\not\models B$.
Furthermore, if   $\Gamma$ is also cosaturated, then we have
$\mathcal{K}^t_\Gamma,\delta\not\models B$.

<!-- proof-6: body_md -->
We prove this by induction on the complexity of $B$.
This means that by the induction hypothesis,
for every subformula $C$ of $B$ and every occurrence $\delta$ of $\Delta$ in $\Gamma$
with $C\in \Delta$, we have $\mathcal{K}_\Gamma,\delta\not\models C$.
Let $B\in\Delta\cap\mathcal{L}^\Box_{\omega_1}$ and let $\delta$ be an occurrence of $\Delta$ in $\Gamma$.
We need to show that
$\mathcal{K}_\Gamma,\delta\not\models B$.
We have the following cases for $B$:
\begin{itemize}
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=p$ is atomic: obvious by definition.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=\overline{p}$: since $\overline{p}\in \Delta$, by $\neg$-cosaturation we have
$p\not\in\Delta$. Therefore, by definition, $\mathcal{K}_\Gamma,\delta\models p$.
Hence $\mathcal{K}_\Gamma,\delta\not\models \overline{p}$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=\bigwedge \Theta$: by $\wedge$-cosaturation, there is some $C\in\Theta\cap\Delta$.
	Therefore, by the induction hypothesis, $\mathcal{K}_\Gamma,\delta\not\models C$.
	Thus $\mathcal{K}_\Gamma,\delta\not\models \bigwedge\Theta$, as desired.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=\bigvee\Theta$: by $\vee$-cosaturation, we have $\Theta\subseteq \Delta$.
	Therefore, by the induction hypothesis we get
	$\mathcal{K}_\Gamma,\delta\not\models C$ for
	every $C\in\Theta$.
	Thus $\mathcal{K}_\Gamma,\delta\not\models \bigvee\Theta$, as desired.
                                                                          
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=\Box C$: by $\Box$-cosaturation,
there is some $[\Theta]\in\Delta$ such that
$C\in\Theta$. Let $\theta$ be the occurrence of the mentioned $\Theta$.
Therefore, $\delta\sqsubset\theta$.
By the induction hypothesis,
$\mathcal{K}_\Gamma,\theta\not\models C$,
and thus $\mathcal{K}_\Gamma,\delta\not\models \Box C$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=\lozenge C$:
let  $\theta\sqsupset \delta$ be an occurrence of some $\Theta$ in $\Gamma$.
                          
By w$\lozenge$-cosaturation, we have $C\in\Theta$. Then by the induction hypothesis,
$\mathcal{K}_\Gamma,\theta\not\models C$. Thus, by definition,
we get $\mathcal{K}_\Gamma,\delta\not\models\lozenge C$, as desired.
\end{itemize}
The above argument works identically for the second statement of the lemma with the following
modifications.
First, replace $\mathcal{K}_\Gamma$ with $\mathcal{K}^t_\Gamma$
and $\sqsubset$ with $\sqsubset^t$.
We also have the following argument for the case $B=\lozenge C$:
\begin{itemize}
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B=\lozenge C$:
let  $\theta\sqsupset^t \delta$ be an occurrence of some $\Theta$ in $\Gamma$.
Since $\theta$ is a strict sub-occurrence of $\delta$ and $\lozenge C\in\Delta$,
                          
by $\lozenge$-cosaturation we have $C\in\Theta$. Then by the induction hypothesis,
$\mathcal{K}^t_\Gamma,\theta\not\models C$. Thus, by definition,
we get $\mathcal{K}^t_\Gamma,\delta\not\models\lozenge C$, as desired.\qedhere
\end{itemize}

We have the following completeness results:

<!-- proof-7: body_md -->
Let ${\sf T}$ be any of $\mathcal{S}{\sf K}_{\omega_1}$, $\mathcal{S}{\sf K4}_{\omega_1}$ or ${\mathcal{S}{\sf GL}_{\omega_1}^{{\!\infty}}}$. Also assume that
$\Gamma_0$ is a nested sequent such that ${\sf T}\nvdash  \Gamma_0$.
By induction on $n$,
we construct a partial ${\sf T}$ proof-tree $T_n$ as follows. The construction is such that
each $T_n$ is a tree of finite depth. Furthermore, $T_{n+1}$ is an extension of $T_n$ obtained by adding
some nodes above the leaves of $T_n$. Also, each
$T_n$ will be well-founded.

For a given nested sequent $\Gamma$ appearing as a label of a leaf in some
$T_n$, let                                                          
$${\Gamma}\{\Delta{}_0\},{\Gamma}\{\Delta{}_1\},\ldots, {\Gamma}\{\Delta{}_m\}$$
be an enumeration of all occurrences in $\Gamma$.
We make this enumeration in such a way
that for any $\Gamma'$ which appears above $\Gamma$ in later steps of the construction,
the first $m$ occurrences remain the same as for $\Gamma$ (see \cref{sec-limit}).

Also, let $B_0,B_1,\ldots$ be an enumeration of all formulas in ${\sf sub}(\Gamma_0)$ such that
every formula occurs infinitely often.
Let $T_0$ be the tree with a single node labelled by the nested sequent $\Gamma_0$.
Also, assume that $n+1=\langle i,j,k\rangle$, i.e.~$n+1$ is the code of the triple $(i,j,k)$ of
numbers. We assume that this coding satisfies $i<\langle i,j,k\rangle $.
We then define $T_{n+1}$ by adding to $T_n$ some nodes on top of
its leaves, as described in what follows.
For each non-trivial\footnote{This means that for every $\Delta$ occurring in $\Gamma$  we have 
$\top\not\in\Delta$ and
  for any atomic $p$, either $p\not\in\Delta$ or $\overline{p}\not\in\Delta$.} $\Gamma$
appearing as the label of a leaf in $T_n$,
with ${\Gamma}\{\Delta_j\}$
(notice that this $j$ is the second component of $n+1$) being the   occurrence
of $\Delta_j$ in $\Gamma$,
we add corresponding new node(s) on top of $\Gamma$ according to the following cases.
\begin{itemize}
                                   
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B_i=\bigvee\Delta\in\Delta_j$ and $B_k\in \Delta$:
add ${\Gamma}\{\Delta{}_j,B_k\}$ on top of $\Gamma$ with its edge labelled by $\vee$.
Notice that $k$ here is the third component of $n+1$.
                                                                                
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B_i=\bigwedge\Delta\in\Delta_j$:
for every $B\in\Delta$, add
${\Gamma}\{B,\Delta{}_j\}$ on top of $\Gamma$ with the label $\wedge$ on the edges.
This in particular means that if  $\Delta=\emptyset$, we do not add anything.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B_i=\Box B\in\Delta_j$:
add ${\Gamma}\{[B],\Delta{}_j\}$ on top of $\Gamma$ with the label $\Box$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $B_i=\lozenge B$ and
  ${\Gamma}\{\Delta_j\}$ is the immediate sub-occurrence of some other occurrence
$\theta$ of $\Theta$ in $\Gamma$
such that $B_i\in\Theta$:
notice that this implies $[\Delta{}_j]\in\Theta$.
Then in the case ${\sf T}=\mathcal{S}{\sf K}_{\omega_1}$,
add ${\Gamma}\{\Delta{}_j,B\}$ on top of $\Gamma$ with the label $\lozenge$.
In the other cases,
add ${\Gamma}\{\Delta{}_j,B,\lozenge B\}$ on top of $\Gamma$ with the label $\lozenge$.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax Otherwise: add nothing.
\end{itemize}
Then let $T^*:=\bigcup_{n=0}^\infty T_n$.
Given that $\Gamma_0$ is not ${\sf T}$-derivable,
$T^*$ cannot be an ${\sf T}$-proof.
By its definition, it is obvious that $T^*$
is a partial ($\mathcal{S}{\sf K}_{\omega_1}$) proof-tree.
Since $T^*$ is not a  ${\sf T}$-proof, one of the following two cases occurs:
\begin{itemize}
    \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax There is some leaf node $\Gamma$ in $T^*$ which is not the conclusion of any of the inference rules.
    This means that $\Gamma$ is cosaturated (in the case of ${\sf T}=\mathcal{S}{\sf K}_{\omega_1}$, weakly cosaturated), and hence by \Cref{saturation-dgla} we have the desired countermodel.
    \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax There is an infinite branch  $\Gamma_0,\Gamma_1,\ldots$ in $T^*$ such that in the case ${\sf T}={\mathcal{S}{\sf GL}_{\omega_1}^{{\!\infty}}}$, this branch does not have infinitely many instances of $\Box$-rule nested to each other.
    So for the rest of this proof, assume that such an infinite branch exists.
\end{itemize}
For every $i$, let $S_i$ be a syntax-tree of $\Gamma_i$ as described in \cref{sec-limit}.
 Therefore, for every $i\in\omega$, we have $S_{i+1}\supset S_i$.
Then define $S^*:=\bigcup_{i\in\omega}S_i$.
\\[2mm]
\textit{Claim 1}.
We have the following properties for $S^*$:
\begin{itemize}
    \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax[i.]  $S^* $  is a non-well-founded nested tree.
Let $\Gamma^*$ denote the non-well-founded nested sequent corresponding to $S^*$.
    \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax[ii.] In the case ${\sf T}={\mathcal{S}{\sf GL}_{\omega_1}^{{\!\infty}}}$,
this branch of the proof includes only finitely many nested applications of
the $\Box$-rule, and hence in this case $\Gamma^*$ is a general nested
sequent. However, in the two other cases, $\Gamma^*$ is just a non-well-founded
nested sequent.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax[iii.] For any occurrence $\delta$  of some $\Delta^*$ in $\Gamma^*$ and any
$B\in\Delta^*\cap\mathcal{L}^\Box_{\omega_1}$, there is some $n$ such that $\delta$ is also an occurrence
of some $\Delta_n$ in $\Gamma_n$ with $B\in\Delta_n$. Furthermore, $\delta$
remains an occurrence of some $\Delta_m$ in $\Gamma_m$  with $B\in\Delta_m$, for any $m>n$.
\end{itemize}
                                                            
\vspace{1mm}
\textit{Proof of Claim 1.}
 The proofs of all the above-mentioned properties are straightforward and left to the reader.

\textit{Claim 2.} If ${\sf T}=\mathcal{S}{\sf K}_{\omega_1}$, then $\Gamma^*$ is weakly cosaturated.
Otherwise, it is cosaturated.

Hence, by Claim 1, there is some $n$ such that $\Gamma_n$ is trivial.
This means that by the definition of $T^*$, there should be no node above $\Gamma_n$ in the proof-tree $T^*$,

  on $\mathcal{L}[A]$ as the smallest relation such that:
  \begin{itemize}
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\mathsf{T}\vdash^A \varphi$ holds for every $\varphi\in \mathsf{T}$;

  \par\setbox0=\hbox{--\,--\,--\enspace}

  \par\setbox0=\hbox{--\,--\,--\enspace}

\@gobble{rem:proof-system}
    Analogously to what happens in the case of admissible sets, we should be careful
    about the meaning of the formula $\mathsf{Proof}(x,\varphi)$: namely, we should not view $x$
    as giving a proof tree of $\varphi$ in the standard sense of the term, due to the fact that,
    in general, $A$ will not be a model of the axiom of choice.
    To give an intuitive idea of the problem, suppose that we want to deduce that, for a set
    $\Phi$ of formulas, if every $\varphi\in \Phi$ has a proof in $A$, then so does $\bigwedge \Phi$.
    If we were to use a ``standard'' notion of proof, then a proof $p_{\bigwedge\Phi}$ of
    $\bigwedge\Phi$ would be something like a function mapping every $\varphi\in\Phi$ to a
    proof $p_\varphi$: the problem is that, in the absence of the axiom of choice,
    we cannot pick \emph{one} proof of $\varphi$. What we can do in $\mathsf{KP}$ is use strong
    $\Sigma$ replacement to produce a function $f$ whose domain is $\Phi$ and such that $f(\varphi)\neq\emptyset$ for every $\varphi$ in the domain, and every $p\in f(\varphi)$ is a
    proof of $\varphi$. Hence, we adapt our notion of proof to allow for this kind of derivation,
    where ``multirule'' derivations of this form are permitted. We remark that this is exactly
    the approach followed in \cite{barwise}: we refer in particular to Chapter III.5
    there for a more thorough discussion of the topic.

\@gobble{lem:truth-imp-prov}
  Let $\varphi$ be a $\Sigma[A]$ sentence, and let $\mathsf{T}$ be an $A$-theory extending $\mathsf{R}[A]$. Then, if $\models^A_\Sigma\varphi$ holds,
  so does $\mathsf{T}\vdash^A \varphi$.
<!-- end lemma-3 -->
<!-- proof-10: body_md -->
We proceed by induction on the complexity of the formula $\varphi$.

    If $\varphi$ is an atomic formula, then the claim basically corresponds to the fact that $\mathsf{R}[A]$ proves every true closed literal of the language $\mathcal{L}[A]$ (sentences of the form $\Godelnum{a}\in \Godelnum{b}$, $\lnot \Godelnum{a}\in \Godelnum{b}$, $\Godelnum{a} = \Godelnum{b}$, or $\lnot \Godelnum{a} = \Godelnum{b}$).
    For this fact, the cases of true membership relations follow from the axioms \ref{R_A_ax1}.\ of $\mathsf{R}[A]$, and the cases of true negated membership relations follow from the axioms \ref{R_A_ax2}.\ of $\mathsf{R}[A]$. The only cases of true equalities are $\Godelnum{a}=\Godelnum{a}$, which constitute a first-order provable property of the equality predicate. Finally, to prove sentences of the form $\lnot \Godelnum{a} = \Godelnum{b}$ for $a\ne b$, we reason as follows. Without loss of generality we assume that there is $c\in a$ such that $c\notin b$ (the reasoning when there is $c\in b$ such that $c\notin a$ is analogous). Then we note that $\mathsf{R}[A]\vdash^A \Godelnum{c} \in \Godelnum{a}\land \lnot \Godelnum{c}\in \Godelnum{b}$, and via first-order reasoning with equality we conclude that $\mathsf{R}[A]\vdash^A \lnot \Godelnum{a} = \Godelnum{b}$.


    The cases of conjunction and disjunction are easy.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
    Suppose $\varphi$ is $\bigwedge\Psi$; then from the assumption $\models^A_\Sigma\varphi$
    we have that $\models^A_\Sigma\psi$ holds for every $\psi\in\Psi$, and hence so does $\mathsf{T}\vdash^A\psi$.
    An application of the rule of conjunction gives the desired result (technically,
    we should first conclude that $\mathsf{T}\vdash^A \top \rightarrow \psi$, where $\top$, as before, is $\bigwedge \emptyset$).

                                                                                                    
                                                                                      
                                                                                            
                                                                              
    The case of disjunction is analogous to the case of conjunction.

                                                                                                                                                                                                               

    We now deal with the case of $\varphi$ being $\exists x\psi$. Let $a\in A$ be such that
    $\models^A_\Sigma \psi(\Godelnum{a})$; then by the inductive assumption we have that $\mathsf{T}\vdash^A  \psi(\Godelnum{a})$.
    Since $\psi(\Godelnum{a})\rightarrow \exists x\psi(x)$ is one of the axioms of $\mathsf{T}$, by modus ponens
    we conclude that $\mathsf{T}\vdash^A \varphi$.

    Finally, suppose that $\varphi$ is $\forall x\in \Godelnum{a}\,\psi(x)$. Then $\models^A_\Sigma \psi(\Godelnum{b})$
    for every $b\in a$, which gives $\mathsf{T}\vdash^A \psi(\Godelnum{b})$ for every $b\in a$.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   
    Since $\{\psi(\Godelnum{b}): b\in a\}$ is a set of formulas,
    we can conclude that $\mathsf{T}\vdash^A \bigwedge_{b\in a} \psi(\Godelnum{b})$.
    From this, using infinitary first-order reasoning,
    we can conclude that \[\mathsf{T}\vdash^A \forall x (\bigvee_{b\in a}(x=\Godelnum{b})\rightarrow \psi(x)).\]
    On the other hand, by the assumption that $\mathsf{T}$ extends $\mathsf{R}[A]$, we have that \[\mathsf{T}\vdash^A \forall x(x\in \Godelnum{a}\rightarrow \bigvee_{b\in a} (x=\Godelnum{b})).\]
    We can conclude that
    $\mathsf{T}\vdash^A \forall x(x\in \Godelnum{a}\rightarrow \psi(x))$ by the axioms concerning the universal
    quantifier and the classical derivations of the transitivity of implication in Hilbert-style systems,
    followed by a final application of the generalization rule.

<!-- remark-9: body_md -->
For subtheories of arithmetic, it is well known that a version of Gödel's Diagonal
    Lemma can be proved already in $\mathsf{Q}$ (and in fact in $\mathsf{R}$); it is therefore natural to expect that something
    similar should happen here. In the present paper we do not try to optimize the assumptions on the theory needed to prove
    the Lemma. We point out that we do not see how to immediately adapt the proof that we give for $\mathsf{KP}[A]$ to the case of, for instance, the theory $\mathsf{R}[A]$. The main issue is the representability of the

<!-- definition-11: body_md -->
Let $(W,\sqsubset)$ be a relational structure. A \emph{co-ranking function} for the relation $\sqsubset$ on $W$ is a function $f$ from $W$ to the ordinals such that for all $u \in W$:
$$f(u) = \sup_{v\sqsupset u}(f(v)+1)$$
<!-- end definition-11 -->
<!-- lemma-9: body_md -->
\@gobble{lem:global-coranking}
Suppose $A$ is a set. If $(W,\sqsubset)\in A$ is a conversely well-founded binary relation, then there exists a global co-ranking function for $W$ within $A$.
<!-- end lemma-9 -->
<!-- proof-18: body_md -->
We say that a function $f$ from a subset of $W$ to the ordinals is a \emph{partial co-rank} if its domain is $\sqsubset$-upward-closed (i.e., if $u,v\in W$, $u\in \operatorname{\mathrm{dom}}(f)$ and $u\sqsubset v$, then $v\in \operatorname{\mathrm{dom}}(f)$), and $\forall u\in \operatorname{\mathrm{dom}}(f) (f(u) = \sup_{v\sqsupset u}(f(v)+1))$.

First, observe that any two partial co-ranks have the same values on the intersection of their domains: if not, then we use the converse well-foundedness of $\sqsubset$ to find a maximal point of divergence, and trivially obtain a contradiction.

Next, we prove by contradiction that each $u\in W$ is in the domain of some partial co-rank $f\in A$.

                                                                                                               
Suppose for a contradiction that this does not hold. We want to consider the set of all $u\in W$ that are not in the domain of any partial co-rank, and consider a minimal element of this set, as given by the well-foundedness of $W$. In any case, the definition of this set would require $\Sigma^A$-separation in general, which can be performed since $A$ is a set, which makes $\Sigma^A$-formulas $\Delta_0$-formulas with $A$ as a parameter.

Since all successors of $u$ are in the domain of some partial co-rank, using $\Sigma^A$-collection in $A$ we find a set $F\in A$ of partial co-ranks such that each successor of $u$ is in the domain of some $f\in F$. Note that, since all partial co-ranks agree with each other,  $f_u=\bigcup F$ is a partial co-rank. We extend $f_u$ to $f_u^+$ by setting $f_u^+(u)=\sup_{v\sqsupset u}f_u(v)+1$. Since $f_u^+$ is clearly a partial co-rank having $u$ in its domain, we obtain a contradiction.

Finally, we use $\Sigma^A$-collection on $A$ to find a set $F\in A$ of partial co-ranks such that for each $u\in W$ there is $f\in F$ with $u\in \operatorname{\mathrm{dom}}(f)$. Clearly, $\bigcup F\in A$ is a partial co-rank having all of $W$ as its domain, i.e., a global co-ranking function for $W$.
<!-- end proof-18 -->

\@gobble{theo:km-compl}
    Suppose $A$ is a set. Let $\mathsf{T}$ be a $\Sigma[A]$-sound $A$-theory extending $\mathsf{KP}[A]$ such that there is a $\mathsf{T}$-provable $\Sigma[A]$-definable function $e(x)$ for which $\mathsf{T}$ proves that its restriction to the ordinals is a surjection onto $V$. Let $B$ be a formula in the
    modal language $\mathcal{L}[A]^{\Box}$ such that there is a conversely well-founded Kripke model
    $\mathcal{K}\in A$ with $\mathcal{K}\not\models B$. Then there is also an interpretation
    $(\cdot)^*$ such that $\mathsf{T}\not\vdash^A  B^*$.
<!-- end theorem-11 -->
<!-- proof-19: body_md -->
We start the proof with two technical observations.

The first is that, since the existence of the co-ranking function $\mathsf{rk}$ for $(W,\sqsubset)$ is a $\Sigma$-sentence that is true in $A$, it is also provable in $\mathsf{T}$. The existence of $\mathsf{rk}$ has important corollaries. We say that $f\colon \alpha\to W$ is a $\sqsubseteq$-\emph{weakly ascending} function if $\alpha\in\mathsf{On}$ and $\forall \beta,\gamma\in \alpha(\beta<\gamma\to f(\beta)\sqsubseteq f(\gamma))$. Since $\mathsf{rk}\circ f$ is an anti-monotone function from an ordinal to the class of ordinals, it must attain its least value at some $\beta\in \alpha$. Notice that $f$ must stabilize after this $\beta$, with $f(\gamma)\sqsubseteq f(\beta)$ for any $\gamma\in \alpha$. The same holds for weakly ascending class functions $f\colon \mathsf{Ord}\to W$. This reasoning about weakly ascending functions can also be formalized inside $\mathsf{T}$. In particular, we will be interested in the version of the theorem for $\mathsf{T}$-provable $\Sigma[A]$-definable functions in the case of class functions.

The second observation is that, as one can easily show,
if there exists a surjection $e$ as in the hypothesis, then, provably in $\mathsf{T}$,
there is also one that enumerates every element
of $A$ cofinally often; we will assume to be working with such an $e$.

The rest of the proof follows the classical proof of Solovay's theorem.
                                                                                                                                                                                                                                                                                                         
We are going to define an interpretation $(\cdot)^*$ such that $\mathsf{T}\not\vdash^A  B^*$.

                                                                                                   
                                                                                                 
                                                                                                  
                                                                                                   
                                                                                                      
                                                                               
                                                                                                                     

Without loss of generality we may assume that the model $\mathcal{K}$ has a root $t$ and $\mathcal{K},t\not\models  B$: if not, then pick $t\in W$ such that $\mathcal{K},t\not\models  B$ and replace $\mathcal{K}$ with its restriction to the upper cone of $t$. We let $\mathcal{K}'=(W',\sqsubset,\mathrel{\textup{E}},S)$ be $\mathcal{K}$ extended with a new root $r$.
Let $t$ be the root of $\mathcal{K}$; we extend the relation $\mathrel{\textup{E}}$ to $r$ by saying that,
for every $p\in S$,
$r\mathrel{\textup{E}} p$ holds if and only if $t \mathrel{\textup{E}} p$ does.
Notice that we are technically abusing notation by using the same symbols $\sqsubset$ and
$\models$ for the models $\mathcal{K}$ and $\mathcal{K}'$, but this should not cause any confusion,
since the relations coincide on common points of the domain $W$. We also naturally extend the co-ranking function $\mathsf{rk}$ to the root $r$.

The idea is, similarly to the arithmetical case, to define a function $h:\mathsf{Ord} \to W'$
that moves along $W'$ to a new point $w$ every time it finds a proof that the limit of $h$ is not $w$.
                                                                   
Namely, we claim that there exists a $\mathsf{T}$-provable $\Sigma[A]$-definable function $h$ from the ordinals into $W'$ such that $h(0)=r$ and for $\alpha>0$:
\begin{equation}
\@gobble{h_def}
 h(\alpha)=
\begin{cases}
    v  & \text { if } \sup_{\sqsubset} \{h(\beta): \beta<\alpha\} \sqsubset v \text { and }\\
       & e(\alpha) \text{ is a pair } \langle v,p \rangle \text{ such that } p \text{ is a witness of}\\
       & \mathsf{Pr}(\Godelnum{\forall \gamma\exists \beta>\gamma (h(\beta)\neq v)}) \\
    \sup_{\sqsubset} \{h(\beta): \beta<\alpha\} & \text{ otherwise.}
\end{cases}
\end{equation}


                                                                                                             

                                                                                                                                                                  

Let us consider the following $\Sigma[A]$ formula, which we define using the Diagonal Lemma. To keep the displayed formula readable, we write $\nu(x)$ for the $\Sigma[A]$-formula
\[\nu(x) \;:\mathrel{\leftrightarrow}\; \forall \gamma\,\exists \beta>\gamma\,\exists v'\,( G_h(\beta, v')\land v'\neq x),\]
which expresses that $x$ is not the limit of $h$ (compare~(\ref{h_def})). With this abbreviation, the formula reads
\[
\begin{aligned}
 G_h(\alpha,x) :\mathrel{\leftrightarrow}{} &  (\alpha \not\in \mathsf{Ord} \rightarrow x= r ) \wedge (\alpha=0\rightarrow x=r) \wedge {}\\
   & (\alpha>0\to \exists h_{app} \, (\text{Func}(h_{app}) \wedge \operatorname{\mathrm{dom}}(h_{app}) = \alpha \wedge {}\\
   &\quad \forall \beta <\alpha \,\models_\Sigma \Godelnum{G_h(\Godelnum{\beta}, \Godelnum{h_{app} (\beta)})} \wedge {}\\
   &\quad \exists s\in W' \, ( \forall \beta<\alpha \,(h_{app}(\beta)\sqsubseteq s) \wedge \exists \beta<\alpha \,(h_{app}(\beta)=s) \wedge {}\\
   &\qquad (s\sqsubset x \wedge \mathsf{Proof}(\pi_1(e(\alpha)), \Godelnum{\nu(\dot x)} ) \wedge \pi_0(e(\alpha))= x ) \vee {}\\
   &\qquad ( s= x \wedge ( \neg (s \sqsubset \pi_0(e(\alpha))) \vee \neg \mathsf{Proof}(\pi_1(e(\alpha)), \Godelnum{\nu(\dot x)} ) ) ) ) ))
\end{aligned}
\]

We claim that this formula describes the graph of the function $h$ we are after.
We start by showing that, provably in $\mathsf{T}$, $G_h$, when restricted to the ordinals, describes a function to $W'$.
\begin{claim}
    $\mathsf{T}$ proves that, for every ordinal $\alpha$, the restriction of $G_h$ to ordinals smaller than $\alpha$ is the graph of a $\sqsubseteq$-weakly ascending function to $W'$.
\end{claim}
\begin{proof}
    We reason in $\mathsf{T}$ and prove the claim by transfinite induction on $\alpha$.
                                                                                                                                                                 

    If $\alpha=0$ or $\alpha=1$, the claim follows from the first line of the equivalence describing $G_h$.

    Suppose $\alpha>1$ and the claim holds for all $\beta<\alpha$.
    Notice that if $\alpha$ is a limit, then the claim follows immediately from the inductive assumption. We can thus suppose that $\alpha$ is a successor, say $\alpha=\alpha'+1$. What we have to show is that there exists $x\in W'$ such that $G_h(\alpha',x)$ holds, that there is no $x'\ne x$ for which $G_h(\alpha',x')$ holds, and that $x$ is $\sqsubseteq$-above every $y$ for which $G_h(\beta,y)$ holds for some $\beta<\alpha'$.

    For the sake of readability, we will denote by $h{\restriction}_{\alpha'}$ the function $h:\alpha'\to W'$ given by our inductive assumption. The existence of this function follows from $\Sigma$-Reflection. This $h{\restriction}_{\alpha'}$ will serve as the witness for $h_{app}$ in $G_h(\alpha,x)$.

    We start by showing that $\sup_\sqsubset\{ v\in W': \exists \beta<\alpha'(h{\restriction}_{\alpha'}(\beta)=v)\}$ exists, and is actually a maximum. This maximum will be used as the witness for $s$ in $G_h(\alpha,x)$.

    As we mentioned at the beginning of the proof of the theorem, the presence of the co-ranking function $\mathsf{rk}\colon W'\to\mathsf{Ord}$ and the fact that $h{\restriction}_{\alpha'}$ is $\sqsubseteq$-weakly ascending guarantee that $h{\restriction}_{\alpha'}$ attains the maximum value $m$ from some ordinal $\beta<\alpha'$ onwards.

    Next, we show that we can find an $x$ such that $G_h(\alpha',x)$ holds. First, notice that if we set $h_{app}=h{\restriction}_{\alpha'}$ and $s=m$ in the fixed-point definition of $G_h$, from the inductive assumption and the previous argument we obtain that $\text{Func}(h_{app})$, $ \operatorname{\mathrm{dom}}(h_{app}) = \alpha'$, $\forall \beta<\alpha' (h_{app}(\beta)\sqsubseteq s)$ and $\exists \beta<\alpha' (h_{app}(\beta)=s)$ all hold. Moreover, since we know (in $\mathsf{T}$) that $G_h(\beta,h_{app}(\beta))$ holds, by \Cref{lem:coded-truth} we can conclude that, for every $\beta<\alpha'$,
    $\models_\Sigma \Godelnum{G_h(\Godelnum{\beta}, \Godelnum{h_{app} (\beta)})}$, and conclude that $\forall \beta <\alpha \models_\Sigma \Godelnum{G_h(\Godelnum{\beta}, \Godelnum{h_{app} (\beta)})}$ by $\Sigma$-Collection.

    We then examine $e(\alpha)$: if $s\sqsubset\pi_0(e(\alpha'))$ and the formula \[\mathsf{Proof}(\pi_1(e(\alpha')), \Godelnum{\forall \gamma\exists \beta>\gamma \exists v'( G_h(\beta, v')\land \lnot v'=\Godelnum{\pi_0(e(\alpha'))})} )\]  holds, then we can set $x=\pi_0(e(\alpha'))$. Otherwise, we let $x=s$.

    Next, we prove that the $x$ we selected is unique. Indeed, for every $x'\in W'$, if $G_h(\alpha',x')$ holds, then this is witnessed by some $h_{app}'$ and some $s'$. Hence, $\models_\Sigma \Godelnum{G_h(\Godelnum{\beta}, \Godelnum{h_{app} (\beta)})}$ and $\models_\Sigma \Godelnum{G_h(\Godelnum{\beta}, \Godelnum{h_{app}' (\beta)})}$ both hold, which implies that $h_{app}'= h_{app}$. This in turn easily implies that $s'=s$, and thus that $x'=x$.
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            

    Since the unique $x$ we chose is weakly above $m$, we are done.
\end{proof}

Thanks to the previous claim, we can conclude that $G_h$ defines a $\sqsubseteq$-weakly increasing function from the ordinals into $W'$. We denote by $h$ the function defined by $G_h$. We can now verify by straightforward induction on $\alpha$ that $h$ satisfies the recursive definition (\ref{h_def}). We will henceforth write $h(\alpha)=u$ instead of the more cumbersome $G_h(\alpha,u)$.

Since $\mathsf{T}$ is $\Sigma[A]$-sound, we can also make sense of $h$ as a $\Sigma^A$-definable function on $A$ from the perspective of the metatheory. Namely, we define $h^\circ\colon \mathsf{Ord}\cap A \to W'$ by \[h^\circ(\alpha)=v\iff \models_\Sigma^A G_h(\Godelnum{\alpha},\Godelnum{v}).\]
To see that this definition indeed yields a well-defined function, we first observe that for each $\alpha$ there should be at least one $v$ such that $h^\circ(\alpha)=v$, since $\mathsf{T}$ is $\Sigma[A]$-sound and proves $\exists v\in W' (h(\Godelnum{\alpha})=v)$. Second, we observe that for each given $\alpha$ there can be at most one $v$ for which $h^\circ(\alpha)=v$, since otherwise, by $\Sigma[A]$-completeness, those two different $v$ would be values of $h(\alpha)$ from the perspective of $\mathsf{T}$, leading to a contradiction in $\mathsf{T}$, which cannot exist by the $\Sigma[A]$-soundness of $\mathsf{T}$.

Since now we know that $\mathsf{T}$ proves that $h$ is weakly increasing function to $\mathcal{K}'$ that has co-ranking function, as mentioned in the beginning of the proof of the theorem, we can conclude that $\mathsf{T}$ proves that $h$ stabilizes from some point.

<!-- remark-11: body_md -->
It is known that, over $\mathsf{NBG}$, the existence of a surjection
    from the ordinals onto the universe is equivalent to the Axiom of Global Choice.
    This makes it easy to find examples of $A$ that do not satisfy the assumptions of the Theorem:
    it is sufficient, for instance, to take as $A$ any model of $\mathsf{ZF}$ without choice to
    see that no such surjection can exist, which precludes any $\mathsf{T}$ from proving its existence.
    For more on the Axiom of Global Choice, we refer to \cite{found-set-theopfraenkel-bar-hillel-levy}.

   The assumption of the existence of a $\Sigma$-definable surjection from the ordinals onto $V$ in $A$-theories $\mathsf{T}$ is of course satisfied for those $A$ that are admissible $L_\alpha$ and $\mathsf{T}$ extending $\mathsf{KP}[A]+L=V$. In fact, the assumption of the existence of a $\Sigma[A]$-definable surjection from the $A$-ordinals onto $A$, for an admissible set $A$, is rather close to the assumption that $A$ is a level of $L$. Namely, suppose that $A$ is an admissible set satisfying the axioms that every set is at most countable and that every set is contained in an admissible set. Then, using Shoenfield's Absoluteness Theorem, it is easy to prove that the existence of a $\Sigma[A]$-definable surjection from the $A$-ordinals onto $A$ is equivalent to the fact that $A=L_\alpha[x]$ for some $x\subseteq \omega$.

<!-- remark-12: body_md -->
We note that the reason why we need to assume the existence of a $\Sigma[A]$ surjection from the ordinals onto $V$ appears to be similar in nature to the unresolved issues with the adaptation of the standard Solovay proof to the case of systems of bounded arithmetic. Note that the question of what the provability logic of systems of bounded arithmetic such as $\mathsf{S}^1_2$ is is a well-known problem in the field of provability logic \citep[Section 5]{problems_beklemishev-visser}. Namely, Solovay's construction essentially relies on considerations of statements about comparisons of smallest G\"odel numbers of proofs of two given sentences. Those comparison sentences must be such that their truth implies their provability within the theory being analyzed. The latter is problematic for systems of bounded arithmetic, since the natural complexity class in which the comparison sentences reside is $\exists \Pi_1^b$, while the provability predicate is only $\exists\Sigma_1^b$-complete. That is, the issue is that the quantifier over all smaller G\"odel numbers of proofs has a range that is too large. The proper analogue of this in the set-theoretic language is the distinction between set-sized range (bounded quantifiers) and quantifiers whose range is a proper class. When we use the surjection from the ordinals onto $V$, we enforce the fact that our enumeration of proofs is such that all initial segments of the enumeration are set-sized.

To enhance readability, we will assume that the formula $\varphi$ has one variable $x$. This entails that the predicate letter $S$ is unary. Hence, what we want to find is a $\Sigma^A$ formula $\mathsf{Fix}_\varphi(x)$ such that $\mathsf{KP} + \mathsf{Tr}(A) + \mathsf{KP}^A\vdash \forall x\in A(\mathsf{Fix}_\varphi( x) \mathrel{\leftrightarrow} \varphi( x,\lambda {x}.\mathsf{Fix}_\varphi( x)))$.

We will use several times the fact that if $S$ occurs only positively in $\varphi(\ensuremath{\mathchoice
                     {\mbox{\boldmath$\displaystylex$}}
                     {\mbox{\boldmath$\textstylex$}}
                     {\mbox{\boldmath$\scriptstylex$}}
                     {\mbox{\boldmath$\scriptscriptstylex$}}}, S)$, then for any two formulas $R(x)$ and $V(x)$, $\mathsf{KP} + \mathsf{Tr}(A) + \mathsf{KP}^A$ proves  \[\forall x (R(x)\rightarrow V(x))\rightarrow \forall x(\varphi(x,\lambda x. R(x))\rightarrow \varphi(x,\lambda x.V(x))),\]
which can be shown by a straightforward induction on the complexity of $\varphi$.

The main idea of the proof is that we will build the desired fixed point by approximating it from below. To this end, we define the formula $\text{App}_\varphi(s)$ as
\[
  \text{Func}(s) \wedge \operatorname{\mathrm{dom}}(s) \in \mathsf{Ord} \wedge \zeta(s),
\]
where $\text{Func}(s)$ is the $\Delta$ formula asserting that $s$ is a function, and the auxiliary formula $\zeta(s)$ is defined as follows:
\[
  \forall \alpha\in \operatorname{\mathrm{dom}}(s) \forall  x\in s(\alpha) ( \varphi(x,\lambda x.x\in\bigcup_{\beta<\alpha}s(\beta)).
\]
Technically speaking, we are abusing notation in the formula above, since if $s$ is not a function then $\operatorname{\mathrm{dom}}(s)$ and $s(\beta)$ have no meaning. But since in these cases $\text{App}_\varphi(s)$ is false anyway, we ignore these trivialities.

Notice that, thanks to the assumption that the predicate $S$ in $\varphi$ occurs positively, substituting $S$ with the formula $x\in \bigcup_{\beta<\alpha}s(\beta)$ produces a $\Sigma^A$ formula with parameter $s$. In turn, this implies that $\text{App}_\varphi(s)$ is a $\Sigma^A$ formula.

From now on, we will shorten $\varphi(x,\lambda x.x\in\bigcup_{\beta<\alpha}s(\beta))$ to $\varphi(x,\bigcup_{\beta<\alpha}s(\beta))$, for added clarity.

We claim that the $\Sigma^A$ formula $\mathsf{Fix}_\varphi(x)$ defining the desired fixed point is
\[
  \exists s\in A( \text{App}_\varphi(s) \wedge \exists \alpha \in \operatorname{\mathrm{dom}}(s) (x\in s(\alpha))).
\]

We start by showing, in $\mathsf{KP} + \mathsf{Tr}(A) + \mathsf{KP}^A$, that $\text{Fix}_\varphi(x)\mathrel{\leftrightarrow} \varphi( x,\lambda {x}.\text{Fix}_\varphi( x))$.

We reason in $\mathsf{KP} + \mathsf{Tr}(A) + \mathsf{KP}^A$.
Suppose that $\text{Fix}_\varphi(x)$ holds; then there exists a function $s$ such that $\text{App}_\varphi(s)$ holds and, for some $\alpha\in \operatorname{\mathrm{dom}}(s)$, $x\in s(\alpha)$. Hence, $\varphi(x,\bigcup_{\beta<\alpha}s(\beta))$ holds. Moreover, notice that $y\in\bigcup_{\beta<\alpha}s(\beta)$ trivially implies $\text{Fix}_\varphi(y)$, as witnessed by $s$ itself. Hence, we have that $\text{Fix}_\varphi(x)\rightarrow \varphi( x,\lambda {x}.\text{Fix}_\varphi( x))$, giving the left-to-right implication.

Suppose now that $\varphi( x,\lambda {x}.\text{Fix}_\varphi( x))$ holds. By the principle of $\Sigma^A$-Reflection, available in $\mathsf{KP}^A$, we have that there exists an $a\in A$ such that the relativization $\varphi^a( x,\lambda {x}.\text{Fix}^a_\varphi( x))$ also holds. Let us define $U=\{ s\in a: \text{App}^a_\varphi(s)\}$, and write $\delta_{s_0}=\bigcup_{s\in U} \operatorname{\mathrm{dom}}(s)$ for brevity. Let $s_0^-$ be the function defined as having domain equal to $\delta_{s_0}$, and setting $s_0^-(\alpha)=\bigcup_{s\in U}s(\alpha)$ for every $\alpha\in\operatorname{\mathrm{dom}}(s_0^-)$. Finally, we define the function $s_0$ as $s_0^-\cup \{ \langle \delta_{s_0},\{x\}\rangle\}$, i.e.\ $s_0$ maps the ordinal $\delta_{s_0}$ to $x$.
                                                                                 

We claim that $s_0$ witnesses $\text{Fix}_\varphi(x)$, which would prove the right-to-left implication. Since obviously $\exists \alpha\in \operatorname{\mathrm{dom}}(s_0)(x\in s_0(\alpha))$ holds, we only have to show that $\text{App}_\varphi(s_0)$ holds too, which boils down to verifying $\zeta(s_0)$, i.e., that $\forall \alpha\in \operatorname{\mathrm{dom}}(s_0) \forall  y\in s_0(\alpha) ( \varphi(y,\bigcup_{\beta<\alpha}s_0(\beta))$. We distinguish two cases.
\begin{itemize}
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax Suppose $\alpha<\delta_{s_0}$, and fix $y\in s_0(\alpha)$. Then there is $s\in U$ such that $y\in s(\alpha)$. Since $\text{App}_\varphi^a(s)$ holds, so does $\text{App}_\varphi(s)$, and hence $\varphi(y,\bigcup_{\beta<\alpha}s(\beta))$ holds. Since clearly $\bigcup_{\beta<\alpha}s(\beta)\subseteq \bigcup_{\beta<\alpha}s_0(\beta)$, we have that $\varphi(y,\bigcup_{\beta<\alpha}s_0(\beta))$ holds, as we wanted.
\par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax Suppose instead that $\alpha= \delta_{s_0}$, we need to show that $\varphi(x,\bigcup_{\beta<\alpha}s_0(\beta))$ holds. Since we know that $\varphi^a( x,\lambda {x}.\text{Fix}^a_\varphi( x))$ holds, it suffices to show that, for every $y\in a$, $\text{Fix}_\varphi^a(y)$ implies $y\in \bigcup_{\beta<\alpha}s_0(\beta)$. This follows from the fact that $\text{Fix}_\varphi^a(y)$ implies that there is $s\in U$ with $y\in \operatorname{\mathrm{ran}} s$.
\end{itemize}
This argument shows that $\mathsf{KP} + \mathsf{Tr}(A) + \mathsf{KP}^A$ proves $\text{Fix}_\varphi(x)$ to be a fixed point of $\varphi$. 

We are only left to show that $\text{Fix}_\varphi(x)$ describes the minimal upper pre-fixed point of $\varphi$. Suppose not, and let $\theta(x)$ be a formula in the expanded language (i.e., we put no requirements on its complexity, nor on the fact that all the quantifiers are bounded by $A$). Now we reason in $\mathsf{KP}+\mathsf{Tr}(A)+\mathsf{KP}^A$ and assume for a contradiction that $\forall x\in A ( \varphi( x,\lambda {x}.\theta( x))\rightarrow \theta( x))$, yet there is some $x$ such that $\text{Fix}_\varphi(x)\wedge \neg\theta(x)$ holds. By definition, there is a function $s$ such that $\text{App}_\varphi(s)$ holds and $x\in s(\beta)$ for some $\beta\in \operatorname{\mathrm{dom}}(s)$. Using Foundation for formulas in the expanded language, we can find the minimal $\alpha\in\operatorname{\mathrm{dom}}(s)$ such that for some $y\in \operatorname{\mathrm{ran}}(s)$ we have $\neg\theta(y)$. Hence, $\varphi(y,\bigcup_{\beta<\alpha}s(\beta))$ holds by the definition of $\text{App}_\varphi$. But we also have that for every $z\in \bigcup_{\beta<\alpha}s(\beta)$, by the minimality of $\alpha$, $\theta(z)$ holds, from which we conclude that $\varphi(y,\lambda y.\theta(y))$ holds, and hence also $\theta(y)$. This gives the desired contradiction.

\@gobble{def:langl}
  We fix some  $11$ distinct elements of $\mathbb{HF}$, which we denote by \[\lnot,\to,\forall,\exists,\bigwedge,\bigvee,\mathsf{var},\mathsf{cnst}^{\ulcorner\urcorner},\mathsf{atm},\mathsf{=},\mathsf{\in};\] for the sake of completeness, let us take the finite ordinals $1,\ldots,11$ for this role.
  \begin{enumerate}
      \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The class of $\mathcal{L}[A]$-variables consists of all the pairs $v_a=\langle \mathsf{var},a\rangle$, where $a\in A$.
      \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The class of $\mathcal{L}[A]$-constants consists of all the pairs $\Godelnum{a} = \langle \mathsf{cnst}^{\ulcorner\urcorner},a\rangle$.
      \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The class of $\mathcal{L}[A]$-terms is the union of the classes of constants and variables.
      \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax The class of atomic $\mathcal{L}[A]$-formulas consists of all the tuples $\langle \mathsf{atm},\langle =,\langle t_0,t_1\rangle\rangle \rangle$ (representing $t_0=t_1$) and $\langle \mathsf{atm},\langle \in,\langle t_0,t_1\rangle\rangle \rangle$ (representing $t_0\in t_1$), where $t_0,t_1$ are $\mathcal{L}[A]$-terms.
  \end{enumerate}

  We let $\mathcal{L}[A]$ be the smallest class such that:
  \begin{enumerate}
                                                     
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\mathcal{L}[A]$ contains all the atomic $\mathcal{L}[A]$-formulas;
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax\@gobble{item:lang2} $\varphi\in \mathcal{L}[A]$ $\Rightarrow$
  $\langle \neg, \varphi\rangle\in \mathcal{L}[A]$;
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax\@gobble{item:langl-impl} $\varphi,\psi\in \mathcal{L}[A]$ $\Rightarrow$
  $\langle \rightarrow, \langle \varphi, \psi\rangle\rangle\in \mathcal{L}[A]$;
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax\@gobble{item:lang3} $\varphi\in \mathcal{L}[A]$ and $x$ is an $\mathcal{L}[A]$-variable $\Rightarrow$
  $\langle\forall,\langle x, \varphi\rangle \rangle\in \mathcal{L}[A]$;
   \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax\@gobble{item:lang4} $\varphi\in \mathcal{L}[A]$ and $x$ is an $\mathcal{L}[A]$-variable $\Rightarrow$
  $\langle\exists, \langle x, \varphi\rangle \rangle\in \mathcal{L}[A]$;
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\Phi\in A$ and $\Phi\subseteq \mathcal{L}[A]$ $\Rightarrow$ $\langle \bigwedge, \Phi\rangle\in \mathcal{L}[A]$;
  \par\setbox0=\hbox{--\,--\,--\enspace} 
                  \hangindent\wd0\relax $\Phi\in A$ and $\Phi\subseteq \mathcal{L}[A]$ $\Rightarrow$ $\langle \bigvee, \Phi\rangle\in \mathcal{L}[A]$.
  \end{enumerate}
