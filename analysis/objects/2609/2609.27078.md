A {\em transitive frame} is a pair ${\mathcal A}=(|{\mathcal A}|,\sqsubset_{\mathcal A})$, where $|{\mathcal A}|$ is any set and $\sqsubset_{\mathcal A}$ is a transitive relation on $|{\mathcal A}|$.
We write:
\begin{itemize}




\item $w\sqsupset _{\mathcal A} v$  if $v\sqsubset_{\mathcal A} w$, $w\sqsubseteq_{\mathcal A} v $ if $w\sqsubset_{\mathcal A} v $ or $w=v $,

\item $w\equiv_{\mathcal A}   v $  if $w\sqsubseteq_{\mathcal A} v $ and $v\sqsubseteq_{\mathcal A} w $,

\item $w \sqsubsetneq_{\mathcal A}  v $  if $w\sqsubseteq_{\mathcal A} v $ but $v \not \sqsubseteq_{\mathcal A} w $, and

\item $w\sqsubset_{\mathcal A}^1  v $  if $v$ is an immediate $\sqsubset_{\mathcal A}$-successor of $w$, in the sense that $w\sqsubsetneq_{\mathcal A} v $ and there is no $u$ such that $w \sqsubsetneq_{\mathcal A}  u \sqsubsetneq _{\mathcal A} v$.

\end{itemize}

<!-- definition-3: body_md -->
Let ${\mathcal A}$ and ${\mathcal B}$ be transitive frames.
A relation $R\subseteq |{\mathcal A}|\times|{\mathcal B}|$ is
\begin{enumerate}

\item {\em forward confluent} if whenever $y \sqsupset_{\mathcal A} x \mathrel R x'$, there is $y'$ such that $y  \mathrel R y' \sqsupset_{\mathcal B} x'$,

\item {\em backward confluent} if whenever $x \sqsubset_{\mathcal A} y \mathrel R y'$, there is $x'$ such that $x  \mathrel R x' \sqsubset_{\mathcal B} y'$, and

\item {\em expansive} if it is both forward and backward confluent.

\end{enumerate}
If $R$ is a total, expansive relation between $|{\mathcal A}|$ and $|{\mathcal B}|$, we write $R\colon {\mathcal A} \mathrel{\vcenter{\offinterlineskip \vskip 0ex\hbox{\rotatebox{30}{$\shortrightarrow$}} \vskip -.9ex\hbox{\hskip -.2ex\rotatebox{-30}{$\shortrightarrow$}}}} {\mathcal B}$.
An expansive relation which is a function is a {\em homomorphism.}

<!-- proposition-1: body_md -->
\label{propExpandingClos}
Let ${\mathcal A}$, ${\mathcal B}$, ${\mathcal C}$ be transitive frames.

\begin{enumerate}

\item If $\mathfrak R$ is a family of relations $R\subseteq |{\mathcal A}|\times |\mathcal B|$ and every $R\in \mathfrak R$ is expansive, then so is $\bigcup \mathfrak R$.

\item If $R \subseteq |{\mathcal A}|\times|{\mathcal B}|$ and $S\subseteq |{\mathcal B}|\times|{\mathcal C}|$ are both expansive, then $S\circ R \subseteq |{\mathcal A}|\times|{\mathcal C}| $ is expansive.

\item If $R \subseteq |{\mathcal A}|\times|{\mathcal A}|$ is expansive, then so are its transitive closure  $R^+$ and its transitive, reflexive closure $R^*$.

\end{enumerate}
<!-- end proposition-1 -->
<!-- proof-1: body_md -->
It suffices to show that forward confluent relations are closed under the above three operations, since $R$ is backward confluent if and only if $R^{-1}$ is forward confluent and we can apply the claim to $R^{-1}$.
Moreover, $R^+$ and $R^*$ are unions of iterated compositions of $R$, so the third claim follows from the other two.

For the first claim, if $a\sqsubset_{\mathcal A} a'$ and $a\mathrel{\bigcup \mathfrak R} b$, then $a\mathrel R b$ for some $R\in\mathfrak R$.
Since $R$ is forward confluent, there is $b'\sqsupset_{\mathcal B} b$ such that $a' \mathrel R b'$, hence $a' \mathrel{\bigcup \mathfrak R} b'$, as required.

For the second claim, if $a\sqsubset_{\mathcal A} a'$ and $a \mathrel{S\circ R} c$, then there is $b$ so that $a\mathrel R b$ and $b\mathrel Sc$.
By forward confluence for $R$, there is $ b ' \sqsupset_{\mathcal B}  b$ such that $a'\mathrel R b'$, then by forward confluence for $S$, there is $ c ' \sqsupset _{\mathcal C} c$ such that $b'\mathrel R c'$.
We then have that $c\sqsubset_{\mathcal C} c'$ and $a' \mathrel{S\circ R} c'$, as required.

<!-- proposition-2: body_md -->
\label{propQMSound}
Given $\varphi\in{\mathbb L}$, the following are equivalent:
\begin{enumerate}

\item There is a model $\mathcal M$ falsifying $\varphi$.

\item There is an ${\mathbb L}$-model $\mathcal Q$ falsifying $\varphi$.

\item There are $\Sigma\Subset{\mathbb L}$ and a $\Sigma$-model $\mathcal Q$ falsifying $\varphi$.

\end{enumerate}
In all cases, $\mathcal Q$ is finite if and only if $\mathcal M$ is.

<!-- proof-2: body_md -->
Given a model $\mathcal M$ and a set $\Sigma$ closed under subformulas, we can define $\ell_\mathcal M(w) = \{\varphi\in\Sigma:(\mathcal M,w)\models \varphi\}$ and easily check that $(|\mathcal M|,\preccurlyeq_\mathcal M,\sqsubset_\mathcal M,\ell_\mathcal M)$ is a quasimodel.
By setting $\Sigma={\mathbb L}$, we obtain the second item from the first, and by letting $\Sigma$ be the set of subformulas of $\varphi$, we obtain the third.

Conversely, given a $\Sigma$-model $\mathcal Q$, we may define $\left\llbracket p \right\rrbracket_\mathcal Q =\{w\in|\mathcal Q|:p\in\ell(w)\}$. 
Then, for $\varphi\in \Sigma$, a standard induction shows that $\varphi\in\ell(w)$ if and only $ \mathcal Q \models\varphi(w) $, so the first item is obtained from the second when $\Sigma={\mathbb L}$ and from the third when $\Sigma$ is finite.

\label{lemCompleteType}
Let $\Phi$ be a prime theory.

<!-- proof-3: body_md -->
It suffices to check that $\Phi$ is $({\mathbb L} \setminus \Phi)$-consistent, since, in this case, the pair is clearly complete.

<!-- lemma-5: body_md -->

That $\Phi \sqsubset_{\rm c} \Psi$ follows tautologically from $\Phi\sqsubset_{\mathbb L} \Psi$, since if $\Box\varphi\in \Phi$ then from $\varphi,\Box\varphi\in \Phi$ we in particular deduce $\varphi\in \Psi$, and likewise if $ \varphi\in \Psi $ then this is sufficient to obtain $ \varphi\in \Psi^\diamonddot$  and thus $\Diamond\varphi\in\Phi$.

Conversely, assume that $\Phi \sqsubset_{\rm c} \Psi$. Let $\Box\varphi \in \ell_{\rm c}(\Phi)$, i.e., $\Box\varphi\in \Phi$.

Let $\Sigma \subseteq \Delta$ be closed under subformulas, ${\mathcal A}$ be a $\Sigma$-frame, ${\mathcal B}$ be a $\Delta$-frame, $w\in |{\mathcal A}|$ and $v\in |{\mathcal B}|$.

\item there is $v'$ such that $v \mathrel R v'$ and $({\mathcal A},w) \subseteq_{\Sigma} ({\mathcal B},v') $, and

\item whenever $v'$ is such that $v \mathrel R v'$ and $({\mathcal A},w) \subseteq_{\Sigma} ({\mathcal B},v') $, it follows that $v' \mathrel R v$.

\end{enumerate}

Similarly, $v$ is {\em simulably $R$-Final for $({\mathcal A},w)$} if 
\begin{enumerate}[label=(\alph*')]

\item there is $v'$ such that $v \mathrel R v'$ and $({\mathcal A},w) \mathrel{\vcenter{\offinterlineskip \vskip 0ex\hbox{\rotatebox{30}{$\shortrightarrow$}} \vskip -.9ex\hbox{\hskip -.2ex\rotatebox{-30}{$\shortrightarrow$}}}}_\Sigma ({\mathcal B},v') $, and

\begin{enumerate}

\item Suppose that $\Theta \in W_{\rm c}$ is such that $({\mathcal A},r)\subseteq_{\Sigma} \Theta  $.
Then, there is $\Theta^* $ such that $\Theta\mathrel R \Theta^*$ and $\Theta$ is $R$-Final for $ {\mathcal A} $.

\item Suppose that $\Theta \in W_{\rm c}$ is such that $({\mathcal A},r)\mathrel{\vcenter{\offinterlineskip \vskip 0ex\hbox{\rotatebox{30}{$\shortrightarrow$}} \vskip -.9ex\hbox{\hskip -.2ex\rotatebox{-30}{$\shortrightarrow$}}}}_\Sigma \Theta  $.
Then, there is $\Theta^* $ such that $\Theta \mathrel R \Theta^*$ and $\Theta$ is simulably $R$-Final for $ {\mathcal A} $.

\end{enumerate}

Both claims follow from compactness for classical first order logic, using the standard translation.
Let $\tt IK4$ be a first order formula which holds on a model $\mathcal M$ if and only if $\mathcal M$ is based on an intuitionistic transitive frame and $\forall x\preccurlyeq y(p(x)\to p(y))$ for all atoms $p$ occurring in $\Sigma$.

Let us define
\begin{align*}
\Xi_{\preccurlyeq}  & = \{\varphi(x):\varphi\in{\mathbb L}\},\\
\Xi_{\sqsubseteq}  & = \{ \boxdot \varphi(x) :\varphi\in{\mathbb L}\} \cup \{ \neg {\diamonddot\varphi(x)}:\varphi\in{\mathbb L}\}\\
\Xi_{\sqsupseteq}  & = \{ \neg {\boxdot} \varphi(x)  :\varphi\in{\mathbb L}\} \cup \{  {\diamonddot\varphi(x)}:\varphi\in{\mathbb L}\}\\
\Xi_{\mathrel{\vcenter{\offinterlineskip
\hbox{$\ll$}\vskip.1ex\hbox{\hskip.25ex $\sim$}}}}  & = \{\boxdot \varphi(x):\varphi\in{\mathbb L}\} .\\ 
\end{align*}
Note that the negations are classical, i.e.~they are applied {\em after} the standard translation into classical first order logic.

For the first claim, we regard each $w\in |{\mathcal A}| $, including the root $r$, as a new constant.
Let ${\tt Acc}(\Theta) $ be the set of all formulas of the form $ \varphi(r)  $  such that $\varphi(x) \in \Xi_R $ and $\mathcal M_{\rm c} \models \varphi(\Theta)$.

Let $\Gamma = {\tt IK4}\cup {\tt Acc}(\Theta) \cup {\tt Hom}({\mathcal A})$ and enumerate the elements of $\Xi_R $ by $\{\xi_i\}_{i<\omega}$.

Letting $\mathcal N$ be any model of $\Gamma\cup\Delta_\omega$ and $ w \in|{\mathcal A}|$, we take $h'(w):= \{\varphi\in{\mathbb L}: \mathcal N \models \varphi(w)\}$.
Each $h' (w)$ is an element of the canonical model, and hence $h' \colon |\mathcal A| \to W_{\rm c} $.
It is not hard to check that $h$ is a homomorphism and, by our choice of $\Delta_\omega$, $h'(r)$ is $R$-Final.

The second claim is proven similarly, but we instead regard each $w\in |{\mathcal A}| $, including the root $r$, as a new predicate $w(x)$, whose intended interpretation is that $ w \mathrel{\vcenter{\offinterlineskip \vskip 0ex\hbox{\rotatebox{30}{$\shortrightarrow$}} \vskip -.9ex\hbox{\hskip -.2ex\rotatebox{-30}{$\shortrightarrow$}}}}_\Sigma x$.

Let the collection of these formulas be ${\tt Sim}({\mathcal A})$.

Let $\Gamma = {\tt IK4}\cup {\tt Acc}(\Theta) \cup {\tt Sim}({\mathcal A})$ and define $\Delta_i$ inductively so that $\Delta_{0}=\varnothing$ and $\Delta_{i+1} = \Delta_i\cup \{\forall x(r(x) \to \xi_i(x))\}$ if $\Gamma \cup \Delta_i\cup \{\forall x(r(x) \to \xi_i(x))\}$ is consistent, otherwise, $\Delta_{i+1} = \Delta_i$.
Reasoning as above, $\Gamma\cup\Delta_\omega$ is consistent.
Letting $\mathcal N$ be any model of $\Gamma\cup\Delta_\omega$ and $x\in|\mathcal N|$, we take $\Phi_x:=\{\varphi\in{\mathbb L}: \mathcal N \models \varphi(x)\}$.
Then, for $w\in  |{\mathcal A}|$, set $E'(w) = \{\Phi_x : \mathcal N\models w(x) \}$.
It is not hard to check that $E'$ is a simulation and thus, by the same reasoning as above, $\Theta \mathrel R \Phi_r$ is simulably $R$-Final, as desired.

$w\sqcap w' = w'  = u\sqcap u''$ and $c\sqcap u \sqsubseteq u\sqcap u'' $
since $c$ is admissible for ${\mathcal A}$, or else 
$w\sqcap w' = w = u' \sqcap u $.
We cannot have $ u' \sqcap u \sqsubset c \sqcap u$, since this would entail $w\sqsubset c$.

<!-- lemma-23: body_md -->
\label{lemmInductive}
Let ${\mathcal A}$ be a stable, canonical $\Sigma$-quasimodel and suppose that ${\mathcal A} $ has at least one defect.

Since there is at least one defect, we can pick $\delta=(v,\varphi)$ so that $w$ is maximal admissible and, for this fixed $w$, $v$ is $\sqsubseteq$-maximal.
By Proposition~\ref{propExistsStrategic}, there is a strategic potential resolution $({\mathcal B}',w)$ for $\delta$.
Let us define ${\mathcal B}$ according to the following cases:
\begin{enumerate}

\item If $({\mathcal B}',w)$ is progressive or budding, then ${\mathcal B} = {\mathcal B}'$.

\item If $({\mathcal B}',w)$ is internal, then ${\mathcal B}$ is a flower resolving all internal defects as given by Proposition~\ref{propBloom}.

\item If $({\mathcal B}',w)$ is nuclear, then ${\mathcal B}$ is a bouquet, as given by Proposition~\ref{propnuclear}.

\end{enumerate}
Let ${\mathcal A}'={\mathcal A}\sqcup_w {\mathcal B}$, $o :=o_{\mathcal A}$, $o' := o_{{\mathcal A}'}$, and define $\nabla,\nabla',\beta,\beta'$ analogously.
By Proposition~\ref{propStillStable},~\ref{propBloom}, or~\ref{propnuclear}, ${\mathcal A}'$ is stable.
Recall that
\[  o(w)   =  \mu \big ( \omega^3\cdot \|w\|+\omega^2 \beta(w) + \nabla (w) \big ) \cdot    \big (1 + \bigoplus_{v\sqsubsetneq w}   o(v) \big ). \]
We prove by induction on the depth of $x \in |{\mathcal A}|$ that $o'(x) \leq o(x) $, $\beta'(x) \leq \beta(x) $, $\nabla'(x) \leq \nabla (x) $  and if $x \sqsubseteq v$, then $o'(x) < o(x) $.
Note that $\nabla' x  \leq \nabla' x$, since ${\mathcal A}'$ does not introduce new defects to elements of $|{\mathcal A}|$ by Proposition~\ref{propStillStable}\eqref{itStillStableOne}.
If $x \equiv v $, then $\partial ' v  < \partial  v$, since we have resolved the defect $\delta$.
From this, we obtain $\nabla ' x  < \nabla   v$, which together with the induction hypothesis for $y\sqsubsetneq v$ yields $o'(x)<o(x)$.

If $x\sqsubsetneq v$, then choosing $u$ so that $x \sqsubset^1 u \sqsubseteq v$, we can apply the induction hypothesis to obtain $o'(u)<o(u)$.
This yields $o'(x)<o(x)$, except in the critical case where $x\equiv w$, in which we have grafted one or more new subtrees.

Here, we consider four cases.
\begin{Cases}

\item ($({\mathcal B},w)$ is progressive).
In this case, we have added a subtree ${\mathcal B}$ with $\rho( u) \ll \rho({\mathcal B})$, so $\|{\mathcal B}\|< \|u\|$ (where, as usual, $\|{\mathcal B}\|$ indicates that it is evaluated at a root).
By Lemma~\ref{lemmOmon}\eqref{itOMonMu},  $o({\mathcal B}) < \mu( \omega^2\| u\|) $, and by Lemma~\ref{lemmOmon}\eqref{itOMuMult}, both $o(u)$ and $o'(u)$ are multiples of $\mu( \omega^2\| u\|)$, so $o'(u)\oplus o'({\mathcal B}) < o(u)$, yielding $o'(x)<o(x)$.

\item ($({\mathcal B},w)$ is budding).
As before, $o'(u)<o(u)$ and both are multiples of $\mu( \omega^2\| u\|)$.
We have once again grafted a new subree ${\mathcal B}$ with $\beta({\mathcal B}) = 0$, whereas $\beta(u) = 1$, and since $\mu:= \mu \big ( \omega^3\cdot \|w\|+\omega^2 \beta(w) + \nabla (w) \big )$ is multiplicatively indecomposable, $o'({\mathcal B}) <\mu $.
We thus have, once again, that $o'(u)\oplus o'({\mathcal B}) < o(u)$, yielding $o'(x)<o(x)$.

\item ($({\mathcal B},w)$ is internal).
According to Lemma~\ref{lemmPetal}, $x$ does not have any internal resolutions in ${\mathcal A}'$, so whenever $y\sqsupseteq^\bullet_{{\mathcal A}'} w$, it follows that $\partial' (y)<\omega$ and hence $\nabla' x <\omega$.
We thus have that
\[o'(x) < \mu \big (\omega^2 \|x\| + \omega  \big ) \leq \mu \big (\omega^2  \|x\| + \nabla x  \big  ) \leq o(x) .\]

\item ($({\mathcal B},w)$ is nuclear).
We have resolved at least one defect of $[w]$ and added subtrees ${\mathcal C}_\delta$ resolving each nuclear defect.
We have that $\rho(w)\ll \rho({\mathcal C}_\delta)$, so these new subtrees do not contribute to $\nabla ' x$ and, since there was at least one nuclear defect resolved, $\nabla ' x < \nabla x$.
Thus, we have that
\[o'(x) <  \mu \big (\omega^2  \|x\| + \nabla x  \big  ) \leq o(x) .\]



\end{Cases}

\label{propRemoveDefect}
If $\Sigma\Subset{\mathbb L}$ and ${\mathcal A}$ is any stable, canonical $\Sigma$-quasimodel, then ${\mathcal A}$ can be extended to a $\Sigma$-model ${\mathcal A}^*$.
<!-- end proposition-10 -->
<!-- proof-31: body_md -->
By induction on $o({\mathcal A})$; if ${\mathcal A}$ has no defects then we can take ${\mathcal A}^* = {\mathcal A}$, otherwise, by Lemma~\ref{lemmInductive}, there is  ${\mathcal A}' \supseteq_{\rm c} {\mathcal A} $ such that ${\mathcal A}'$ is stable and $o({\mathcal A}') < o({\mathcal A})$.
By the induction hypothesis, ${\mathcal A}'$ (and hence ${\mathcal A}$) can be extended to a $\Sigma$-model, as desired.

<!-- theorem-3: body_md -->
$\sf IK4$ has the finite model property.
<!-- end theorem-3 -->
<!-- proof-32: body_md -->
Suppose that ${\sf IK4} \not \vdash \varphi$ and let $\Phi \in W_{\rm c}$ be such that $\overline \varphi \in \Phi $, which exists by the Lindenbaum lemma (\ref{lem:lindenbaum}) and Lemma~\ref{lemCompleteType}.
Define a canonical sprout with root $\Perp$ followed by a node labelled by $\Phi$, then extend it to a canonical $\Sigma$-tree ${\mathcal A}$ using Lemma~\ref{lemmModalDefects}, and note that ${\mathcal A}$ is rooted.
Letting $\preccurlyeq_{\mathcal A}$ be the identity, we see that ${\mathcal A}$ is trivially stable.
Hence by Proposition~\ref{propRemoveDefect}, ${\mathcal A}$ can be extended to a $\Sigma$-model ${\mathcal A}^*$, thus providing a finite countermodel for $\varphi$.
