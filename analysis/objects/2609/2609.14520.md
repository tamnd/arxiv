\label{thm: iterate_braided}
   Suppose that for $i=1,\cdots,k$, $P_i$ is a braided L-space satellite pattern. If $K$ is a non-trivial knot which is not $T_{2,3}$, then $u(P_k \circ \cdots \circ P_1(K)) \geq |\ell_k \cdots \ell_1|.$  Here, $P_i(K)$ denotes $P_i(K,\lambda_i)$  for any $\lambda_i\in \mathbb{Z}$.
<!-- end thm-1 -->
<!-- thm-2: body_md -->
\label{thm: iterate_general} Suppose that $P_1,\dots, P_k$ are L-space satellite operators with $\theta_i=g_3^{\operatorname{{rel}}}(P_i)-g_3(P_i)$. If $K$ is a non-trivial knot which is not $ T_{2,3}$, then
\[
u(P_k\circ \cdots\circ  P_1(K))\ge |\ell_k| (\cdots (|\ell_2|(|\ell_1| + \theta_1 -1) + \theta_2 -1) \cdots -1)  + \theta_k.
\]
In the above, $P_i(K)$ denotes $P_i(K,\lambda_i)$ for any $\lambda_i\in \mathbb{Z}$.
<!-- end thm-2 -->
<!-- rem-1: body_md -->
It follows from \cite{CZZApp}*{Proposition~7.2} that $\theta(P)$ can alternatively be described as $R_{\ell/2}-g_3(P)-|\ell|/2$,   where $R_{\ell/2}\in \mathbb{Z}+\ell/2$ is a number defined using the $H$-function of $L_P$. See Definition~\ref{def: R_t}.

<!-- thm-3: body_md -->
\label{thm: tor_ord}
Suppose $P$ is an L-space satellite operator. For any nontrivial knot $K\neq T_{2,3}$ and $\lambda \in\mathbb{Z}$, we have
\begin{equation*}
    \operatorname{Ord}(P(K,\lambda )) \geq  \max\{|\ell|(\operatorname{Ord}(K)-1),|\ell|\} + \theta.
\end{equation*}
<!-- end thm-3 -->
<!-- proof-1: body_md -->
The unknotting number satisfies $u(K)\ge \operatorname{Ord}(K)$ by \cite[Theorem 1.1]{AlishahiEftekhary_Unknotting} and so the result follows by repeatedly applying Theorem \ref{thm: tor_ord}.

<!-- thm-4: body_md -->
\label{thm: tor_ord_braided}
Let $P$ be a braided L-space satellite pattern. For any nontrivial knot $K$ and $\lambda\in\mathbb{Z}$, we have
\begin{equation*}
    \operatorname{Ord}(P(K,\lambda)) \geq    \max\{|\ell|(\operatorname{Ord}(K)-1)+1,|\ell|\}.
\end{equation*}
<!-- end thm-4 -->
<!-- rem-2: body_md -->
We may replace the $u(K)$ in Theorem \ref{thm: iterate_braided} and \ref{thm: iterate_general} by $u_q(K)$,  
 the \emph{proper rational tangle replacement number} of $K$, defined analogously to the unknotting number. Explicitly, $u_q(K)$ is the
minimum number of rational tangle replacements required to turn a diagram of $K$ to a diagram of the unknot, where the new tangle  connects the same tangle end points.
    By \cite[Theorem 1.2]{EftekharyRational}, $\operatorname{Ord}(K)$ is a lower bound for $u_q(K)$.

<!-- define-1: body_md -->
A link $L$ is called an \emph{L-space link} if $S^3_\Lambda(L)$ is an L-space for all sufficiently large positive integer framing $\Lambda$.  By \cite[Theorem 12.1]{MOIntegerSurgery}, $L$ is an L-space link if and only if $\mathcal{H\hspace{-.5mm}F\hspace{-.3mm}L}(L,\boldsymbol{\mathbf{s}})\cong \mathbb{F}[U]$ for all $\boldsymbol{\mathbf{s}}\in \mathbb{H}(L).$

<!-- define-2: body_md -->
\label{def: R_t}
	If $L$ is a two-component L-space link with linking number $\ell$ and $H$-function $H_L(t,r)$, we set
	\[
	R_t := \max\left\{r\in \mathbb{Z}+\ell/2 \middle|  \begin{array}{l}  H_{L}(t,r+1)=H_L(t,r)\text{ and}\\   H_L(t,r-1)=H_L(t,r)+1\end{array} \right\}. 
	\]

<!-- define-3: body_md -->
Let $\hat\mathcal{R}=\mathbb{F}[W,Z]/(U)$. If $n_1,\dots, n_m$ are positive integers, and 
$       \sigma_1,\dots, \sigma_m$ are in $\{-1,1\}$,  we define the \textit{standard complex} $\mathcal{C}(\sigma_1 n_1,\dots, \sigma_m n_m)$ to be the free $\hat{\mathcal{R}}$ chain complex with generators $a_0,\dots, a_m$ and with differential as follows: for each $1\le i\le m$, there is an arrow between $a_i$ and
$a_{i-1}$ weighted by $Z^{n_i}$ if $i$ is odd, and weighted by
$W^{n_i}$ if $i$ is even, for some $n_i>0$. If $\sigma_i=1$, this arrow points from $a_i$ to $a_{i-1}$, and if $\sigma_i=-1$, the arrow points from $a_{i-1}$ to $a_i$.
<!-- end define-3 -->
<!-- define-4: body_md -->
\label{def:local-system-complex} (Local system complex) Let $\vec{n}=( n_1,n_2,\dots,n_{2p})$ be a sequence of positive integers and let $\vec{\sigma}=(\sigma_1,\dots, \sigma_{2p})$ be a sequence of numbers in $\{-1,+1\}$. Assume, furthermore, that 
\begin{equation}\label{eq: local_system}
\sum_{i=1}^p \sigma_{2i}n_{2i}=\sum_{i=1}^p\sigma_{2i-1} n_{2i-1}=0.
\end{equation}
Let $w$ be a positive integer and $A\in \mathit{GL}_{w}(\mathbb{F})$. Then there is a type-$D$ module $\mathcal{L}=\mathcal{L}(w,\vec{n},\vec{\sigma},A)$ over $\hat{\mathcal{R}}$, defined as follows. The underlying vector space is given by $\bigoplus_{i=1}^{2p} X_i$ where each $X_i$ is identified with $\mathbb{F}^{w}$. The differential is as follows. If $i\neq 1$, then the differential contains a component mapping between $X_i$ and $X_{i-1}$ which is weighted by $W^{n_i}$ if $i$ is even and $Z^{n_i}$ if $i$ is odd. If $\sigma_i>0$, then this component maps from $X_i$ to $X_{i-1}$, and if $\sigma_i<0$, this component maps from $X_{i-1}$ to $X_i$. Finally, if $\sigma_1=1$, then there is a component of $\partial$ from $X_1$ to $X_{2p}\otimes \hat{\mathcal{R}}$ which is given by $A\otimes Z^{n_1}$. If $\sigma_1=-1$, then there is a component of $\partial$ which maps $X_{2p}$ to $X_1$ by $A^{-1}\otimes Z^{n_1}$. We refer to any complex $\mathcal{L}$ constructed in the above manner as a \emph{local system complex}.

<!-- thm-5: body_md -->
\label{thm:standard_decomp} If $K$ is a knot in $S^3$, then there is a decomposition
\[
    \mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat\mathcal{R}} \simeq \mathcal{C} \oplus \mathcal{L}_1 \oplus \cdots \oplus \mathcal{L}_k
\]   where $\mathcal{C}$ is a standard complex and each $\mathcal{L}_i$ is a local system complex.
<!-- end thm-5 -->
<!-- proof-2: body_md -->
We give a very brief sketch of the proof of Theorem~\ref{thm:standard_decomp}, and describe how it follows from Hanselman's work \cite{HanselmanMinus}. We note it also follows from \cite{KWZKhovanov}*{Theorem~5.14}. Both works build on \cite{HRWImmersedCurves}. Hanselman describes a way of representing $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{\mathcal{R}} }$ as an immersed multicurve  $\Gamma_K$ in a punctured torus. The immersed multicurve is compact, and equipped with a bounding cochain. Informally, a bounding chain is a collection of self intersections of the immersed curve with itself where a holomorphic curve is allowed to turn. Hanselman proves in \cite{HanselmanMinus}*{Proposition~7.1} that the bounding chain can be taken to be of \emph{local system type} \cite{HanselmanMinus}*{Definition~6.3}. For such bounding chains, there are no distinguished points between different components of an immersed curve. Furthermore, the only self intersections occur on components which are not primitive (\textit{i.e.}, homotopic to $k$ times another curve for some $|k|>1$). Hanselman proves that such immersed curves can be taken to consist of $k$-parallel copies of a single immersed curve, connected by a simple crossing region (see \cite{HanselmanMinus}*{Figure~25}). 

 To recover the hat theory, one takes a distinguished meridian in the torus $\mu$ that runs through the puncture. One fills in the puncture with a disk containing two basepoints $w$ and $z$ on either side of the puncture. Write $\mu$ also for the Lagrangian in the non punctured torus. Then
 \[
 \mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{R}}\cong \mathit{CF}(\Gamma_K,\mu,w,z).
\]
 In the above, $\mathit{CF}(\Gamma_K,\mu,w,z)$ is the free $\hat{\mathcal{R}}$-module generated by intersection points between $\Gamma_K$ and $\mu$. The differential counts immersed bigons $u$ which are weighted by $W^{n_w(u)}Z^{n_z(u)}$.
 
 
Write $\mu'$ for a parallel copy of $\mu$, which is disjoint from the region containing $w$ and $z$. If $K$ is a knot in $S^3$, then we can apply a regular homotopy to $\Gamma_K$ so that only a single component intersects $\mu'$, and furthermore there is only a single intersection point. (See \cite{HanselmanMinus}*{Section~8}). The component of $\Gamma_K$ intersecting $\mu'$ does not have a local system. 

We may assume, via regular homotopy, that there are no bigons bounded by $\mu$ and $\Gamma_K$ which do not contain one of $w$ or $z$.  We also consider the image of $\Gamma_K$ in the complement of $\mu'$, which we view as $S^1\times [-1,1]$. This multi-curve can be lifted to an immersed multi-curve in the infinite strip $\mathbb{R}\times [-1,1]$, which we denote $\gamma_K$. By convention, we will assume that $z$ occurs in $(-1,0)\times S^1$ and $w$ is in $(0,1)\times S^1$. 

We claim that the decomposition in Theorem~\ref{thm:standard_decomp} can be read off of the curve $\Gamma_K$, put in this position. The standard complex $\mathcal{C}$ corresponds to the non-compact component of $\gamma_K$, while each compact component of $\gamma_K$ gives one of the local system complexes $\mathcal{L}_i$. We see this as follows. Consider the non-compact component $\gamma_0$ of $\gamma_K$. Consider the components of $\gamma_0\setminus \mu$. Call these \emph{segments}. There is a first segment of $\gamma_K$ which goes from $\{-1\}\times \mathbb{R}$ to $\mu$. This first intersection point corresponds to $a_0$. The second segment could travel from $a_0$ to $\{1\}\times \mathbb{R}$, in which case $\mathcal{C}$ has a single generator. Otherwise, the next segment of $\gamma_0$ travels from $a_0$ to some other intersection point $a_1$. In particular, the segment from $a_0$ to $a_1$ cannot have any self intersections. There is clearly a bigon from $a_0$ to $a_1$ which is weighted by some power of $W$. Continuing this procedure builds the complex $\mathcal{C}$. One may check that there are no other immersed bigons bounding $\gamma_0$ and $\mu$ which cover only $w$ or $z$ other than the ones constructed above.

 Applying the analogous procedure to the non compact components of $\Gamma_K$ yields the local system complexes $\mathcal{L}_1,\dots, \mathcal{L}_n$.

By \cite{MartinT26}*{Proposition~1}, we know that $H_*(\widetilde{Y}_{\ell/2})$ has rank $2$.

\item $\widetilde{\mathcal{C}}_{\ell/2-1}$ has a single generator $\boldsymbol{\mathbf{x}}_{\ell/2-1}^{\mathrm{top}}$.
\item $\widetilde{\mathcal{C}}_{\ell/2-1}$ has more than one generator and $L_Z(\boldsymbol{\mathbf{x}}_{\ell/2-1}^{\mathrm{top}})=0\in \widetilde{\mathcal{C}}_{\ell/2}$.
\item $\widetilde{\mathcal{C}}_{\ell/2-1}$ has more than one generator and $L_Z(\boldsymbol{\mathbf{x}}_{\ell/2-1}^{\mathrm{top}})\neq 0\in \widetilde{\mathcal{C}}_{\ell/2}$.
\end{enumerate}

We first address the case that $\widetilde{\mathcal{C}}_{\ell/2-1}$ contains a single generator. In this case, we can use the stabilization properties of the $H$-function, to see that $R_{\ell/2-1}<R_{\ell/2}$, as follows. Firstly, since $\widetilde{\mathcal{C}}_{\ell/2-1}$ contains a single generator, we see that
\begin{equation}

\end{cases}
\label{eq:H_L-initial-braid}
\end{equation} 
We know also that 
\begin{equation}
H_{L}(1-\ell/2,t)=H_U(1-\ell)=\ell-1

\end{equation} if $t\gg 0$, where $U$ is the unknot (note that by convention we assume that $\ell\ge 0$ and furthermore $\ell\neq 0$ for a braid). Using the symmetry of the H-function (i.e., $H_L(s,t)=H_L(-s,-t)-s-t$), we conclude from Equation~\eqref{eq:H(1-ell/2)} that if $t\ll 0$, then
\[

\]
In light of Equation~\eqref{eq:H_L-initial-braid}, we conclude therefore that $R_{\ell/2-1}=\ell/2-1$. Finally, since $N_{L_P}=\ell/2$ (i.e. there is a $\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}}$-grading preserving isomorphism $\mathcal{C}_t\cong \mathcal{S}$ to $t\ge \ell/2$), we know that $R_{\ell/2}= \ell/2+g_3(P)>\ell/2-1=R_{\ell/2-1}$,   completing the proof in this case.

We henceforth assume that $\widetilde{\mathcal{C}}_{\ell/2-1}$ has more than one generator.

In the case that $L_Z(\boldsymbol{\mathbf{x}}_{\ell/2-1}^{\mathrm{top}})=0$, we know that $H_*(\widetilde{X}_{\ell/2})$ is spanned by $\boldsymbol{\mathbf{x}}_{\ell/2}^{\mathrm{top}}$ and $\boldsymbol{\mathbf{x}}_{\ell/2-1}^{\mathrm{top}}$. completing the proof.

\[
\begin{split}
(\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}},\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}})(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0) =& (-2,-2 R_{\ell/2 -1} - \ell ) \\ (\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}},\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}})(\boldsymbol{\mathbf{x}}^{\ell/2}_0) =& (0,-2 R_{\ell/2} - \ell ). \end{split}\]

Using the definition of the $R_t$ invariants  and the above grading formula for $L_Z$, we observe that 
\[
(\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}},\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}})(L_Z(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0)) = (-2, -2 R_{\ell/2 -1} - \ell -2) = (\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}},\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}})(\boldsymbol{\mathbf{x}}^{\ell/2}_0) + (-2,2\omega-2).
\]
 If $\omega \leq 1$, we  can set $L_Z(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0) = \boldsymbol{\mathbf{x}}^{\ell/2}_0\otimes WZ^{1- \omega} = 0$ on the full $DA$-bimodule ${}_{\mathcal{K}} \mathcal{X}(L_P)^{\mathbb{F}[W,Z]}$. After setting $W=0$ on the right and forming the bimodule ${}_{\hat{\mathcal{K}}} \mathcal{X}(L_P)_{\mathbb{F}[Z]}$, we obtain $L_Z(\boldsymbol{\mathbf{x}}^{\ell/2-1})=0$.

If $\omega > 1,$ 
the only possible generator in $\mathcal{C}_{\ell/2}$ with the same bigrading as $L_Z(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0)$ is of the form $\boldsymbol{\mathbf{x}}^{\ell/2}_1 Z^p$ for some $p$. 
By definition, in the module ${}_{\mathcal{K}} \mathcal{X}(L_P)^{\mathbb{F}[W,Z]}$, the element $L_Z(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0)$ is a non-zero generator of the homology of $\mathcal{C}_{\ell/2}$. Therefore,
 we must have $L_Z(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0) = \boldsymbol{\mathbf{x}}^{\ell/2}_1 Z^p$ for some $p\ge 0$.  Comparing  $\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}}$ values  yields
\[-2 R_{\ell/2 -1} - \ell - 2 = -2 R_{\ell/2}  - \ell+ 2 \xi_1^{\ell/2} -2p\]
 and we solve that $ p= \xi_1^{\ell/2} + 1 - \omega .$ 
 
 
We now consider the claim about $L_\sigma (\boldsymbol{\mathbf{x}}^{\ell/2-1})$. Similarly to the above argument, we have 
\[
(\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}},\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}})(L_{\sigma}(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0))=(-2,-2 R_{\ell/2 -1} + \ell -2)= (\operatorname{{gr}}_{\boldsymbol{\mathbf{w}}},\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}})(\boldsymbol{\mathbf{x}}'_0) + (-2, 2\Xi).
\]
 If $\Xi \leq 0,$ we can take $L_{\sigma}(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0) = \boldsymbol{\mathbf{x}}'_0 \otimes WZ^{-\Xi},$ which vanishes after passing from ${}_{\mathcal{K}} \mathcal{X}(L_P)^{\mathbb{F}[W,Z]}$ to ${}_{\hat{\mathcal{K}}} \mathcal{X}^{\diamond}(L_P)_{\mathbb{F}[Z]}$.

If $\Xi > 0,$ the only possible generator in $\mathcal{S}$ with the same bigrading as $L_{\sigma}(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0)$ is $\boldsymbol{\mathbf{x}}'_1 Z^q$ for some $q$. 
By definition, $L_{\sigma}(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0)$ is nonzero, thus  we must have $L_{\sigma}(\boldsymbol{\mathbf{x}}^{\ell/2-1}_0) = \boldsymbol{\mathbf{x}}'_1 Z^q$ where $q \geq 0$ over ${}_{\mathcal{K}} \mathcal{X}(L_P)^{\mathbb{F}[W,Z]}$. Therefore we have the same map over ${}_{\hat\mathcal{K}} \mathcal{X}^{\diamond}(L_P)_{\mathbb{F}[Z]}$.
Comparing  $\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}}$  yields
\[-2 R_{\ell/2 -1} + \ell -2 = -2 g_3(P) + 2 \xi'_1  -2q\]
 and we solve that $ q= \xi'_1+ R_{\ell/2-1}-\ell/2-g_3(P) +1 =\xi'_1 - \Xi.$ 

 The other equations are proven in \cite[Lemma 4.17]{CZZApp}.
 
 The claim that $\Xi>0$ implies that $g_3(P)>0$ and $\xi_1'\ge \Xi$ follows from the above argument: if $\Xi>0$ then $\mathcal{S}$ must have a generator $\boldsymbol{\mathbf{x}}_1'$ in addition to $\boldsymbol{\mathbf{x}}_0'$, and therefore $g_3(P)>0$. Since $\xi_1'-\Xi$ appears as an exponent of $Z$, it must be nonnegative.

In the following proof,  we use $\partial^{\operatorname{{free}}}$ for the differential on $\mathbb{X}^{\operatorname{{free}}}(P,K,\lambda)$ and $\partial$ for the differential on $\mathbb{X}^{\diamond}(P,K,\lambda)$.
We proceed case by case.

\medskip
\noindent\textbf{Case \eqref{it: non_ending_general_case_1}: when $\eta_0, \eta_1>0$.} An example is depicted in Figure \ref{fig: prop_non_ending}\subref{subfig: non_ending_1}. 
Since this case does not involve $\mathbb{X}^{\operatorname{{Tor}}}(P,K,\lambda)$,  the proof is comparatively simple.

We set \[\alpha_0 = a_0 | x'_{-\frac{1}{2}},  \qquad \alpha_1 =   a_0 \Big|  \sum_{i=1}^n x_{i - \frac{1}{2}}Z^{\ell (n-i)} +  a_1 | x'_{-\frac{1}{2}} Z^ \theta\] and  make the following claims:

\begin{enumerate}[label=(\alph*), ref=\alph*]
 \item \label{it: alpha0_cycle}$\partial \alpha_0 =0$;
    \item \label{it: Zn_claim}$\partial \alpha_1 =  \alpha_0 Z^{\ell n + \theta}$;
    \item \label{it: shortest_arrow_claim} $\{\alpha_0,\alpha_1\}$ generates a direct summand of the chain complex $\mathbb{X}^{\diamond}(P,K,\lambda)$. 
\end{enumerate} 


Claim \eqref{it: alpha0_cycle} follows from the fact that $\delta^1(a_0)=0$ in $\mathcal{X}_{\lambda}(K)^{\hat\mathcal{K}} $, and $m_{0|1|0}(x'_{-\frac{1}{2}})=0$.

Next, to prove Claim \eqref{it: Zn_claim}, we compute the differential of each term in $\alpha_1.$ 
 Since  $\delta^1(a_0)=0$, the only differentials each generator
 $ a_0 | x_{i-\frac{1}{2}}$ admits are $\Phi^{\mu}+\Phi^{-\mu} = \mathbb{I} |( L_\sigma + L_\tau)$.      
 Recall from Lemma \ref{lem: C_S_structure_maps} that
\begin{equation}\label{eq: L_sigma+L_tau}
(L_\sigma + L_\tau) (x_{i-\frac{1}{2}})=\begin{cases}
    x'_{i-\frac{1}{2}} Z^{ \theta} +  x'_{i-\frac{3}{2}} Z^{\ell + \theta}  \qquad &i>0 \\
     \epsilon \cdot  \widetilde{x}'_{i-\frac{1}{2}} Z^{\xi'_1 - \Xi} +  x'_{i-\frac{3}{2}} Z^{\kappa}  \qquad &i\leq 0
\end{cases}
\end{equation}
where $\epsilon\in \{0,1\}$ is nonzero if and only if $\Xi>0$.   Therefore
\begin{align}\label{eq: nonending_case_1_horizontal_diff}
    \partial (a_0 | x_{i-\frac{1}{2}}) &= a_0 | ( x'_{i-\frac{1}{2}} Z^{ \theta} + x'_{i-\frac{3}{2}} Z^{\ell + \theta} )   \qquad \text{for} \quad i \geq 1. 
    \end{align}
    
  Since $\delta^1(a_1)$ has coefficients in $\hat\mathcal{R}$ (in particular, no components weighted by a non-zero multiple of $\sigma$ or $\tau$) \ and $m_{0|1|0}(x'_{-\frac{1}{2}})=0$,  $ a_1 | x'_{-\frac{1}{2}}$ admits only  length-$0$ differentials, which take the form of
  \[
       \begin{tikzcd}[column sep=0 cm, row sep=0.3 cm]
     \mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat\mathcal{R}}  \mathrm{a.r.}[d ]& \otimes& \mathscr{F}^{\diamond}\mathrm{a.r.}[dd] \\
     \delta^1_{\hat\mathcal{R}} \mathrm{a.r.}[dd]\mathrm{a.r.}[drr] \\
     & & m_{1|1|0}  \mathrm{a.r.}[d]  \\
     \mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat\mathcal{R}} &  \otimes  & \mathscr{F}^{\diamond} 
	 \end{tikzcd}.
     \]   
    Since  $\delta^1(a_1) = a_0 Z^n$ and $m_{1|1|0}(Z^n,x'_{-\frac{1}{2}}) = x'_{n-\frac{1}{2}}$ we obtain
\begin{align*}    
    \partial  (a_1 | x'_{-\frac{1}{2}}) &= a_0 | x'_{n-\frac{1}{2}}. 
\end{align*} We  compute
\begin{align*}
    \partial \alpha_1 &=    \sum_{i=1}^n  \partial (a_0 | x_{i - \frac{1}{2}}) Z^{\ell (n-i)} + \partial ( a_1 | x'_{-\frac{1}{2}}) Z^ \theta\\
    &=     a_0 \Big|   \sum_{i=1}^n  \left( x'_{i - \frac{3}{2}}Z^{\ell (n-i)}\cdot Z^{\ell + \theta} +     x'_{i - \frac{1}{2}}Z^{\ell (n-i)}\cdot Z^{\theta}\right) +  a_0 |x'_{n-\frac{1}{2}}Z^ \theta\\
    &=  a_0 | x'_{-\frac{1}{2}}Z^{\ell n + \theta},
\end{align*}
which proves Claim \eqref{it: Zn_claim}.


To prove Claim \eqref{it: shortest_arrow_claim}, we perform a change of basis as follows (the changes in the second line apply only when $n>1$):  
\begin{align*}
a_0 | x_{n - \frac{1}{2}} &\mapsto \alpha_1 \\
   a_0 | x'_{i-\frac{1}{2}} &\mapsto a_0 | ( x'_{i-\frac{1}{2}} +   x'_{i-\frac{3}{2}} Z^{\ell } )    \qquad i= 1,\dots, n-1. 
\end{align*}
The remainder of the basis is unchanged. A schematic illustration of this change of basis is depicted in Figure \ref{fig: Zzigzag}. 

By Lemma \ref{lem: horizontal_chain}, in the resulting basis of $\mathbb{X}^{\diamond}(P,K,\lambda)_{\mathbb{F}[Z]}$, for $i=1,\dots, n-1$, the only arrow pointing to $a_0 |( x'_{i-\frac{1}{2}} +   x'_{i-\frac{3}{2}} Z^{\ell })$ comes from $a_0 | x_{i-\frac{1}{2}}$.
Since $\partial^2 =0$ and each $a_0 | x'_{i-\frac{1}{2}}$ is non-torsion,  there is no arrow pointing to $a_0 | x_{i-\frac{1}{2}}$ for $i=1,\dots,n-1$. Therefore, $\{a_0 | x_{i-\frac{1}{2}},a_0 | ( x'_{i-\frac{1}{2}} +   x'_{i-\frac{3}{2}} Z^{\ell }):i=1,\dots,n-1 \}$  generates a direct summand in $\mathbb{X}^{\diamond}(P,K,\lambda)$. 
In the resulting basis,
the only arrow pointing to  $\alpha_0$ comes from $\alpha_1.$
Since $\partial^2 =0$ and  $\alpha_0$ is non-torsion,
it follows that  $\{\alpha_0,\alpha_1\}$ generates a direct summand in $\mathbb{X}^{\diamond}(P,K,\lambda)$.

From the claims \eqref{it: alpha0_cycle}, \eqref{it: Zn_claim} and \eqref{it: shortest_arrow_claim}, we conclude that  $\operatorname{Ord}(P(K)) \geq \ell n + \theta.$

\intertext{and}
\partial (a_0 | x'_{-\frac{1}{2}}) &= a'_0 | x'_{\eta_0 -\frac{1}{2}}. \notag

We consider two cases depending on the sign of $\omega - \theta =  \Xi +1$, as follows.
\begin{enumerate}[label=\roman*$)$]

    \item $\partial \alpha_1 =  \alpha_0 Z^{\ell (n-1) + \theta}$;

    \item

 \item \label{it: alpha0_cycle_case_2}  $\partial \alpha_0 Z^{\Xi} = 0$;
    \item \label{it: Zn_claim_case_2} $\partial \alpha_1 =  \alpha_0 Z^{\ell (n-1) + \omega}$;

  the next arrow weighted by $Z$-powers be outgoing from $a'_0$ in $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat\mathcal{R}}$. In either case,
   by Lemma \ref{lem: snake_structure}, we have $\eta_0 \leq -2.$  Hence $\frac{1}{2}+\eta_0 < -1$, 
   and by \eqref{eq: scE_scJ_actions}, we have \[ m_{1|1|0}(Z,x_{\frac{1}{2}+\eta_0}) = m_{1|1|0}(\sigma,x_{\frac{1}{2}+\eta_0}) = 0. \]
   Therefore
   any length-$0$ differential and $\Phi^{\pm K}$ from $a'_0|x_{\frac{1}{2}+\eta_0}$ must vanish.  It follows that the only outgoing arrows from $a'_0|x_{\frac{1}{2}+\eta_0}$ are of the form $\mathbb{I} | (L_\sigma + L_\tau)$, which were computed in \eqref{eq: L_sigma+L_tau}.  Suppose $\Xi = 0,$ it is straightforward to verify that $\partial \alpha_0 = 0$ and the claim holds.  If $\Xi > 0$, we compute
   \begin{align*}
       \partial \alpha_0 &= \partial ( a'_0|x_{\frac{1}{2}+\eta_0}) +  \partial (a_0 | x'_{-\frac{1}{2}}) Z^{\kappa}\\
       &=    a'_0|\widetilde{x}'_{\frac{1}{2}  +\eta_0} Z^{\xi'_1 - \Xi}  +   a'_0|x'_{-\frac{1}{2}+\eta_0} Z^{\kappa}     +   a'_0|x'_{-\frac{1}{2}+\eta_0} Z^{\kappa}\\
       &=  a'_0|\widetilde{x}'_{\frac{1}{2}  +\eta_0} Z^{\xi'_1 - \Xi}.
   \end{align*}
   Since $ a'_0|\widetilde{x}'_{\frac{1}{2}+\eta_0} Z^{\xi'_1} = 0$ in $\mathcal{S}^{\diamond}$,   Claim \eqref{it: alpha0_cycle_case_2} follows. 
   
We leave the verification of Claim \eqref{it: Zn_claim_case_2}  to the reader, which is similar to the previous case.

To prove Claim \eqref{it: shortest_arrow_claim_case_2},  we first observe that $a'_0|x_{\frac{1}{2}+\eta_0}$ admits no other incoming arrows than the one from $a_0|x_{\frac{1}{2}+\eta_0}$. Indeed, any such arrow must be a length-$0$ differential, which requires an incoming arrow to $a'_0$ weighted by $Z^j$ for some $j>0$ in $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat \mathcal{R}}$. Since $\frac{1}{2}+\eta_0-j < -1,$ by \eqref{eq: scE_scF_actions}, $m_{1|1|0}(Z^j, x_{\frac{1}{2}+\eta_0-j})=0$. Therefore any such arrow vanishes.

We perform a change of basis as follows:
\begin{align*}
    a'_0|x_{\frac{1}{2}+\eta_0} &\mapsto \alpha_0  \hspace{7em} a_0 | x_{n - \frac{1}{2}} \mapsto \alpha_1 \\
     a_0 | x'_{\frac{1}{2}} &\mapsto a_0 | x'_{\frac{1}{2}} + \alpha_0 Z^{\omega - \theta}\\
    a_0 | x'_{i-\frac{1}{2}} &\mapsto a_0 | (x'_{i-\frac{1}{2}} +  x'_{i-\frac{3}{2}} Z^{\ell })     \qquad i= 2,\dots, n-1.
\end{align*}
The remainder of the basis is unchanged. 

In the resulting basis,
by the observation earlier together with Lemma \ref{lem: horizontal_chain},  the only arrow pointing to $a_0 | x'_{\frac{1}{2}} + \alpha_0 Z^{\omega - \theta}$ comes from $a_0 | x_{\frac{1}{2}}$. It follows that $\{a_0 | x_{\frac{1}{2}}, a_0 | x'_{\frac{1}{2}} + \alpha_0 Z^{\omega - \theta}\}$ generates a direct summand in $\mathbb{X}^{\operatorname{{free}}}(P,K,\lambda)$.
Also, similarly as before, for $i=2,\dots, n-1$, $\{a_0 | x_{i-\frac{1}{2}},a_0 |( x'_{i-\frac{1}{2}} +  x'_{i-\frac{3}{2}} Z^{\ell })\}$ generates a direct summand in $\mathbb{X}^{\diamond}(P,K,\lambda)$.

In the resulting basis, the only arrow pointing to $\alpha_0$ comes from $\alpha_1.$
It follows that $\{ \alpha_0, \alpha_1 \}$ generates a summand in $\mathbb{X}^{\operatorname{{free}}}(P,K,\lambda)$.

 Having proved all three claims, we now apply Lemma \ref{lem: torsion_order_criterion} to compute the torsion order. Letting $A= \mathbb{X}^{\operatorname{{free}}}(P,K,\lambda), B= \mathbb{X}^{\operatorname{{Tor}}}(P,K,\lambda)$ and $f=\partial$, we conclude that $\operatorname{Ord}(P(K)) \geq \ell(n-1)+ \omega - \Xi = \ell(n-1)+ \theta + 1.$ 
\end{enumerate}

<!-- lem-10: body_md -->
\label{lem: alpha0_hori}
Let $a$ be a generator in a reduced basis of  $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{\mathcal{R}}}$ such that $\delta^1(a)=0$ in $\mathcal{X}_{\lambda}(K)^{\hat{\mathcal{K}}}$.
Given a braided L-space satellite pattern $P$ with $\ell>1$, then
\begin{itemize}
    \item $ a| x'_{-\frac{1}{2}}$ is a cycle in $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(P(K))$ (recall that this lies in $\hat{\mathbb{F}}$, the product of the $F_{s,t}$ complexes);
    \item  $[a| x'_{-\frac{1}{2}}] \neq 0$ and  $[a| x'_{-\frac{1}{2}}]W =0$ in $H_*(\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(P(K))/(Z))$.
\end{itemize}

The first bullet point 
 follows from $\delta^1(a)=0$ and $\delta^1_1(x'_{-\frac{1}{2}})=0$. 
 
To prove the second  bullet point, we analyze all possible incoming arrows to
$a|x'_{-\frac{1}{2}}$
in $\hat\mathbb{X}(P,K,\lambda)$.
The images of $\Phi^{\pm K}$ and $\Phi^{\pm K,\pm\mu}$ are not contained in $\hat{\mathbb{F}}$ and hence the only possible differentials pointing to $a|x_{-\frac{1}{2}}'$ are from $\Phi^{\pm \mu}$ or from the internal differential of $\hat{\mathbb{F}}$. 

We first consider the internal arrows in $\hat{\mathbb{F}}$. Since the basis of $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{R}}$ is reduced, every component of the differential of $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{\mathcal{R}}}$ is weighted by a power of $W$ or $Z$. We observe firstly that there are no differentials in the box tensor product pointing to $a|x_{-\frac{1}{2}}$ contributed by a single application of the differential of $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{\mathcal{R}}}$ because there are no components of $\delta_2^1(W,-)$ or $\delta_2^1(Z,-)$ which point to $x'_{-\frac{1}{2}}\in \hat{\mathscr{F}}_{-\frac{1}{2},\frac{\ell-1}{2}}$ (see Figure~\ref{fig:the-maps-f-pm-mu}). 

Next, we observe that there are no components of the differential of the box tensor product pointing to $a|x_{-\frac{1}{2}}$ which are contributed by two applications of the differential of $\mathcal{C\hspace{-.5mm}F\hspace{-.3mm}K}(K)^{\hat{\mathcal{R}}}$ because these maps all involve a factor of one of
\[
h_{Z,W},\ h_{W,Z},\ h_{\sigma,W},\ h_{\sigma,Z},\ h_{\tau,W},
\text{ and } h_{\tau,Z},
\]
and these maps have image in algebraic grading $1$, while
$x'_{-\frac{1}{2}}$ lies in algebraic grading 0.

We now consider the map $\Phi^{-\mu}$. This map is shown schematically in Figure~\ref{fig:the-maps-f-pm-mu}. If such an arrow points to $a|x'_{-\frac{1}{2}}$, it must originate from $a|x_{\frac{1}{2}}$. However,  by Lemma~\ref{lem: C_S_structure_maps}, the arrow of $\mathbb{I}|L_\tau$ originating from
$a|x_{\frac{1}{2}}$ is weighted by $Z^{\ell+\theta}=Z^{\ell}$ (recall from Lemma~\ref{lem: braided_property} that $\theta=0$ for braided L-space satellite patterns). Since $\ell>1$, this arrow vanishes in
$\hat\mathbb{X}(P,K,\lambda)/(Z)$.

Thus, the only remaining possibilities are the internal differentials of
$\hat\mathcal{S}$ and the arrows of the form $\mathbb{I}|L_\sigma$ coming from $\Phi^{\mu}$.  
We divide the argument into two cases depending on $\Xi$. Recall from Lemma~\ref{lem: braided_property} that  $\Xi \geq 0$ for braided L-space satellite patterns.

If $\Xi>0,$  then  by Lemma \ref{lem: C_S_structure_maps}, $g_3(P)>0$, and by \cite[Theorem 7]{HeddenWatson} the internal arrow of $\hat\mathcal{S}$ from $\boldsymbol{\mathbf{y}}'_1$ to $\boldsymbol{\mathbf{x}}'_0$ is weighted by $W$. On the other hand,
following a similar argument as in the proof of Lemma \ref{lem: C_S_structure_maps},
by Equation~\eqref{eq: gradingxs} and the definition of $\hat\mathcal{C}_{\frac{\ell}{2}-1}$,  for any basis element  $\boldsymbol{\mathbf{w}} \in \hat\mathcal{C}_{\frac{\ell}{2}-1}$ we  have 
\[\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}}(\boldsymbol{\mathbf{w}})\ge \operatorname{{gr}}_{\boldsymbol{\mathbf{z}}}(\boldsymbol{\mathbf{x}}_0^{\ell/2-1}) = -2 R_{\frac{\ell}{2}-1} - \ell.\]
 Therefore by Equation \eqref{eq: grading_shift}
\[
\operatorname{{gr}}_{\boldsymbol{\mathbf{z}}}(L_\sigma(\boldsymbol{\mathbf{w}})) \geq  -2 R_{\frac{\ell}{2}-1} + \ell -2 = \operatorname{{gr}}_{\boldsymbol{\mathbf{z}}}(\boldsymbol{\mathbf{x}}'_0) + 2\Xi.
\]
Since $\Xi>0,$ we conclude that  $\operatorname{{im}}(L_\sigma)$ does not contain $x'_{-\frac{1}{2}} \cdot b$ for any $b \in \hat \mathcal{R}$. 

 
Therefore the only incoming arrow to $ a| x'_{-\frac{1}{2}}$ is from $a| \hat{y}'_{-\frac{1}{2}}$.

\[ \partial_{\operatorname{{hori}}} (a| \hat{y}'_{-\frac{1}{2}}) = a| x'_{-\frac{1}{2}}W \]

 We break the proof into two main cases:
 \begin{enumerate}
 \item $x_0=0$
 \item $x_0\neq 0$.
 \end{enumerate} 
 We first consider the case that $x_0=0$. In this case, $y=[Z^{-1}x_Z]_{W=0}$ is an element of homology with $Z^{N}\cdot [y]\neq 0\in H_*(\mathcal{C}/W)$ and $Z^{N+1}\cdot [y]=0$. Therefore $\operatorname{Ord}(\mathcal{C})\ge N+1>\operatorname{Ord}'(\mathcal{C})$, as claimed.
 
  We now consider the case that $x_0\neq 0$. We observe firstly that $x_0$ must itself be a cycle. Furthermore, $x_0$ cannot contain any endpoints of the standard complex of $\mathcal{C}$ since $[x]_{W=0}$ and $[x]_{Z=0}$ are torsion.  Therefore, $x_0$ must be a sum of sinks.
