<!-- theorem-1: body_md -->
\label{first}
Let $(A,\mathfrak{m} ), (B,\mathfrak{n} ) $ be  Gorenstein local rings. Suppose we have an equivalence $\Phi \colon \operatorname{\underline{CM}}(A) \cong \operatorname{\underline{CM}}(B)$ as triangulated categories. We have
\begin{enumerate}[\rm (1)]
  \item If $A, B$ are not hypersurfaces then $\dim A = \dim B$.
  \item  If $A$ (and so $B$)  is a hypersurface  singularity and if the completion of $A$ has a MCM module $M$ with $\Omega(M) \ncong M$  and $M$ free on the punctured spectrum of $A$ then $\dim A - \dim B$ is even.
 \end{enumerate}
<!-- end theorem-1 -->
<!-- theorem-2: body_md -->
\label{second}Let $(A,\mathfrak{m} ), (B,\mathfrak{n} ) $ be  Gorenstein local rings. Suppose we have an equivalence $\Phi \colon \operatorname{\underline{CM}}(A) \cong \operatorname{\underline{CM}}(B)$ as triangulated categories. Then
\begin{enumerate}[\rm (1)]
  \item $\operatorname{curv}_A(M) = \operatorname{curv}_B(\Phi(M))$ for any $M \in \operatorname{\underline{CM}}(A)$.
  \item $\operatorname{curv}_A(A/\mathfrak{m} ) = \operatorname{curv}_B(B/\mathfrak{n} )$.
  \item If $M \in \operatorname{\underline{CM}}(A)$ then $\operatorname{cx}_A(M)$ is infinite if and only if $\operatorname{cx}_B(\Phi(M))$ is infinite.
  \item If $M \in \operatorname{\underline{CM}}(A)$ and $\operatorname{cx}_A(M)$ is finite then $\operatorname{cx}_A(M) = \operatorname{cx}_B(\Phi(M))$.
\end{enumerate}
<!-- end theorem-2 -->
<!-- theorem-3: body_md -->
\label{third}Let $(A,\mathfrak{m} ), (B,\mathfrak{n} ) $ be  Gorenstein local rings. Suppose we have an equivalence $\Phi \colon \operatorname{\underline{CM}}(A) \cong \operatorname{\underline{CM}}(B)$ as triangulated categories. Assume $A$ (and so $B$) is not regular. Let $k$ be the residue field of $A$ and let $l$ be the residue field of $B$. Then
\begin{enumerate}[\rm (1)]
  \item $\operatorname{char} k = \operatorname{char} l$.
  \item $k$ is finite if and only if $l$ is finite.
  \item If $k$ is infinite then both $k$ and $l$ have the same cardinality.
  \item $k$ is perfect if and only if $l$ is perfect.
  \item Assume $k$ is algebraically closed.
  Then
  \begin{enumerate}[\rm (a)]
    \item If $\operatorname{char} k > 0$ then $l \cong k$.
    \item If $\operatorname{char} k = 0$ then either $l \cong k$ or $l$ is a real closed field and $l(\sqrt{-1}) \cong k$.
  \end{enumerate}
  \end{enumerate}

\begin{enumerate}[\rm (1)]

\begin{enumerate}[\rm (i)]
\item

\item

\item
$\operatorname{depth} \Omega^n(M)\otimes X  \geq 1$ for all $n \in \mathbb{Z} $.
\end{enumerate}

<!-- lemma-1: body_md -->
\label{krs-equi}
Let  $\mathcal{C}, \mathcal{D} $ be triangulated KRS $R$-categories. If $f \colon \mathcal{C} \rightarrow \mathcal{D} $ is a $R$-triangulated functor which is an equivalence upto direct summands then $f$ is dense. In particular $f$ is an equivalence.
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
Let $Y \in \mathcal{D} $. Then $Y$ is a direct summand of $f(Z)$ for some $Z \in \mathcal{C}$. So there exists
an idempotent $\phi \colon f(Z) \rightarrow f(Z)$ and a factorization $f(Z) \xrightarrow{p} Y \xrightarrow{u} f(Z)$ such that $\phi = u\circ p$ and $p\circ u = 1_Y$. As $f$ is fully faithful there exists $\psi \colon Z \rightarrow Z$ such that $\phi = f(\psi)$. We note that $\psi$ is also an idempotent in $\mathcal{C}$. As $\mathcal{C}$ is KRS we get that $\psi$-splits. Let $Z \xrightarrow{q} K \xrightarrow{v} Z$ such that $\psi = v\circ q$ and $q\circ v = 1_K$.
It follows that $\phi$ also splits as $f(Z) \xrightarrow{f(q)} f(K) \xrightarrow{f(v)} f(Z)$ such that $\phi = f(v)\circ f(q)$ and $f(q)\circ f(v) = 1_f(K)$. By uniqueness of splittings
we get $Y \cong f(K)$. So $f$ is dense.

<!-- theorem-13: body_md -->
\label{crucial}
Let $\mathcal{C}, \mathcal{D} $ be Hom-finite triangulated $R$-categories with $\mathcal{D} $ a KRS category. Suppose there exists $\eta \colon \mathcal{C} \rightarrow \mathcal{D} $ an equivalence up to direct summands. Then  $K(\eta) \colon K(\mathcal{C}) \rightarrow \mathcal{D} $ is an equivalence of triangulated $R$-categories.
<!-- end theorem-13 -->
<!-- proof-3: body_md -->
By Proposition \ref{K-hom-f} and   Lemma \ref{krs-equi} it suffices to prove that $K(\eta)$ is an equivalence up to direct summands. Let $\theta \colon \mathcal{C} \rightarrow K(\mathcal{C})$ be the  canonical functor.

We first show that $K(\eta)$ is  fully faithful. Let $U, V \in K(\mathcal{C})$. We want to show
the map $K(\mathcal{C})_{U,V} \colon \operatorname{Hom}_{K(\mathcal{C})}(U, V) \rightarrow \operatorname{Hom}_\mathcal{D} (K(\eta)(U), K(\eta)(V))$ is an isomorphism of $R$-modules.

There exists  $X, Y \in \mathcal{C}$ such that $U$ is a direct summand of $\theta(X)$ and $V$ is a direct summand of $\theta(Y)$. So there exists $U_1,V_1$ in $K(\mathcal{C})$ with $U\oplus U_1 = \theta(X)$ and
$V \oplus V_1 = \theta(Y)$.

We have a commutative diagram
\[
\xymatrix{
\
&\operatorname{Hom}_{K(\mathcal{C})}(\theta(X), \theta(Y))
\ar@{->}[dr]^{K(\eta)(\theta(X), \theta(Y))}
 \\
\operatorname{Hom}_\mathcal{C}(X, Y)
\ar@{->}[rr]_{\eta(X,Y)}
\ar@{->}[ur]^{\theta(X,Y)}
&\
&\operatorname{Hom}_\mathcal{D} (\eta(X), \eta(Y))
}
\]

We note that $K(\eta)\circ \theta(X) = \eta(X)$. Similar assertion for $Y$. We note that $\eta(X,Y)$ and  $\theta(X,Y)$ are isomorphisms. So $K(\eta)(\theta(X), \theta(Y))$ is an isomorphism.

We have a commutative diagram
\[
  \xymatrix
{
 \operatorname{Hom}_{K(C)}(U, V)
\ar@{->}[r]^{ K(\mathcal{C})_{U,V} }
\ar@{->}[d]^{i}
 & \operatorname{Hom}_\mathcal{D} (K(\eta)(U), K(\eta)(V))
\ar@{->}[d]^{j}
\\
 \operatorname{Hom}_{K(C)}(\theta(X), \theta(Y))
 \ar@{->}[r]^{ K(\eta)(\theta(X), \theta(Y))  }
 & \operatorname{Hom}_\mathcal{D} (\eta(X), \eta(Y))
\
 }
\]
Here $i,j$ are inclusions. Also $K(\eta)(\theta(X), \theta(Y))$ is an isomorphism. So $K(\mathcal{C})_{U,V}$ is an inclusion of $R$-modules. In particular

\begin{equation*}
\ell_R(\operatorname{Hom}_{K(\mathcal{C})}(U,V)) \leq
\ell_R (\operatorname{Hom}_\mathcal{D} (K(\eta)(U), K(\eta)(V))).  \tag{i}
\end{equation*}
Similarly we have
\begin{equation*}
\ell_R(\operatorname{Hom}_{K(\mathcal{C})}(U,V_1)) \leq
\ell_R (\operatorname{Hom}_\mathcal{D} (K(\eta)(U), K(\eta)(V_1))),  \tag{ii}
\end{equation*}
\begin{equation*}
\ell_R(\operatorname{Hom}_{K(\mathcal{C})}(U_1,V)) \leq
\ell_R (\operatorname{Hom}_\mathcal{D} (K(\eta)(U_1), K(\eta)(V))).  \tag{iii}
\end{equation*}
Finally we have
\begin{equation*}
\ell_R(\operatorname{Hom}_{K(\mathcal{C})}(U_1,V_1)) \leq
\ell_R (\operatorname{Hom}_\mathcal{D} (K(\eta)(U_1), K(\eta)(V_1))).  \tag{iv}
\end{equation*}
If we add the left side of the above four inequalities we get \\ $\ell_R(\operatorname{Hom}_{K(\mathcal{C})}(\theta(X), \theta(Y)))$. While if add up the right side of the four inequalities we obtain
$$\ell_R(\operatorname{Hom}_\mathcal{D} (K(\eta)(\theta(X), K(\eta)(\theta(Y))) = \ell_R(\operatorname{Hom}_\mathcal{D} (\eta(X), \eta(Y))).$$
We had earlier demonstrated that the natural map \\ $\operatorname{Hom}_{K(\mathcal{C})}(\theta(X), \theta(Y))) \rightarrow \operatorname{Hom}_\mathcal{D} (\eta(X), \eta(Y))$ is an isomorphism of $R$-modules. In particular they have the same length.
It follows that all the four inequalities are equalities. In particular $K(\mathcal{C})_{U, V}$ is an isomorphism (as we had earlier proved it is an injection). Thus $K(\eta)$ is fully faithful.

Let $V \in \mathcal{D} $. Then by assumption $V$ is a direct summand of $\eta(U)$ for some $U \in \mathcal{C}$. We note that $K(\eta)(\theta (U)) = \eta(U)$. Thus $K(\eta)$ is an equivalence upto direct summands.

<!-- definition-3: body_md -->
\label{tri-f}
 Let $\mathcal{C}$ be a triangulated category with shift operator $\Sigma$. Assume $\mathcal{C}$ is skeletally small. Let $I(\mathcal{C})$ denote the set consisting of isomorphism classes of objects in $\mathcal{C}$.


We say a function $\xi \colon I(\mathcal{C}) \rightarrow \mathbb{Z} $ is a \emph{triangle
 function} on $\mathcal{C}$, see \cite[Introduction]{P-liason} if it satisfies the following properties:
\begin{enumerate}
\item
$\xi([M]) \geq 0$ for all $M \in \mathcal{C}$.
\item
$\xi([M]) = 0$ if and only if $M = 0$ in $\mathcal{C}$ .
\item
$\xi([M_1 \oplus M_2]) = \xi([M_1]) + \xi([M_2])$ for all $M_1, M_2 \in \mathcal{C}$.
\item
\emph{
(sub-additivity)} If $M \rightarrow N \rightarrow L \rightarrow \Sigma (M)$ is an exact triangle in $\mathcal{C}$ then
\begin{enumerate}
\item
$\xi([N]) \leq \xi([M]) + \xi([L])$.
\item
$\xi([L]) \leq \xi([N]) + \xi([\Sigma(M)])$.
\item
$\xi([\Sigma(M)]) \leq \xi([L]) + \xi([\Sigma(N)])$.
\end{enumerate}
\end{enumerate}

\item
