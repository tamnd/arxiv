\end{itemize}

For $e \in \{0,1\}^{\ast}$ a RAM program, assume that we are given a \emph{trace} of the program~$e$ as a list of instructions executed in chronological order (\textit{i.e.}~for each operation, we record the addresses and values that were read and written).   Thus, if $e \in \{0,1\}^{\ast}$ is a $\log$-RAM program, the word length of the processor array is large enough for processors to each non-deterministically ``guess'' a computation step in $\mathcal{O}(1)$ steps.
