<!-- remark-1: body_md -->
\rm 
We observe that, for a  given data  $(\Phi, \xi)\in {\mathcal Y}_n\times {\mathbb{R}}^n$, where ${\mathcal Y}_n:=({\mathcal X}^*)^n$, the primary goal of the paper is to identify an  $f\in {\mathcal X}$ which  minimizes the function  ${\mathcal E}_{\Phi, \xi}: {\mathcal X}\to {\mathbb{R}}$, defined by 
$${\mathcal E}_{\Phi, \xi}(f) := \|\Phi(f)- \xi\|_{{\mathbb{R}}^n}^2,\quad f\in {\mathcal X}.$$
This  goal is modest in comparison with an associated   regression problem, where the goal is to identify an  $f\in {\mathcal X}$, which  minimizes the function ${\mathcal E}: {\mathcal X}\to {\mathbb{R}}$, defined by 
$${\mathcal E}(f) := \int_{{\mathcal Y}_n\times {\mathbb{R}}}{\mathcal E}_{\Phi, \xi}(f) d\mu,$$
where $\mu$ is an appropriate probability measure on ${\mathcal Y}_n\times {\mathbb{R}}^n$.  For a comprehensive analysis of such regression problem, in the setting of  ${\mathcal X}$ being a reproducing kernal Hilbert space  and $n=1$, one may refer to Lin et. al. \cite{lin-et-al}. However,  the problem considered in this paper has relevance to learning theory, and at the same time in includes considerations of  solving ill-posed integral equations and operator equations based on finite data points. Further, the  proposed  regularization procedure, which yields order  optimal error estimates in the setting of a normed linear space.

\rm 
For $1\leq p\leq \infty$, let  ${\mathcal X}$ be a subspace of $L^p(\Omega)$  and let ${\mathcal Y} = C(\Omega)$, where $\Omega$  is a compact subset of ${\mathbb{R}}^d$ for some $d\in {\mathbb{N}}$. Let  $K: {\mathcal X}\to {\mathcal Y}$ be   an integral operator with a continuous kernel $k(\cdot, \cdot)$, that is,  
$$(Kf)(x) = \int_\Omega k(x,y)f(y)dy,\quad f\in {\mathcal X}.$$
Suppose we are interested in finding $f\in  {\mathcal X}$  such that 
$$(Kf)(x_i) =  \xi_i,\quad i=1, \ldots, n,$$
for a given data set $\{(x_i, \xi_i) \in \Omega\times {\mathbb{R}}: i=1, \ldots, n\}$.  Now, defining 
$$\varphi_i(f) = (Kf)(x_i)\quad\hbox{for}$$
for $f\in {\mathcal X}$ and for $i\in \{1, \ldots, n\}$, we see, using H\"{o}lder's inequality  (cf. Nair \cite{Nair-FA}) that $\varphi_i$ is a continuous linear functional on $L^p(\Omega)$ for each $i\in \{1, \ldots, n\}$. 
Thus, the problem here is to identify $f\in L^p(\Omega)$ such that 
$$\varphi_i(f) = \xi_i\quad\forall\, i\in \{1, \ldots, n\}.$$
In this case, it is to be observed that for each $i\in \{1, \ldots, n\}$, 
$$\varphi_i(f) = \<f, k_{x_i}\>_{L^2(\Omega)},$$
where $k_{x_i}(y) = k(x_i, y)$ for $y\in \Omega$.  In particular, for $p=2$, the functions $k_{x_1}, \ldots, k_{x_n}$ are the Riesz-representers of $\varphi_1, \ldots, \varphi_n$, respectively.  This problem has been addressed in detail in the papers in the papers  \cite{MTN-SP, Nair-ACM,  Nair-discrete} for the case $p=2$.

<!-- theorem-1: body_md -->
\label{Th-onto-0}
Let $V$ be a vector space over the field ${\mathbb{K}}$, which is either ${\mathbb{K}}$ or ${\mathbb{C}}$,  and let $\psi_1, \ldots, \psi_m$ be linear functionals on $V$. Then the map $F: V\to {\mathbb{K}}^m$ defined by 
$$F(v) = (\psi_1(v), \ldots, \psi_m(v)),\quad v\in V,$$
is onto if and only if $\psi_1, \ldots, \psi_m$ are linearly independent, and in that case,   there exist $v_1, \ldots, v_m$ in $X$ such that 
$$\psi_i(v_j) = \delta_{ij},\quad i,j\in \{1, \ldots, m\}.$$
<!-- end theorem-1 -->
<!-- proof-1: body_md -->
Taking an orthonormal basis of the range of $\Phi$, \w.r.t. the standard inner product on ${\mathbb{K}}^m$, and extending it to an orthonormal bases of ${\mathbb{K}}^n$ (cf. \cite{NS}, Theorem 4.36),  we obtain that  
$F$ is not onto if and only if  there exists a nonzero $n$-tuple  $(\alpha_1, \ldots, \alpha_m)  \in {\mathbb{K}}^m$ such that  $\sum_{i=1}^m \alpha_i\psi_i(u) = 0$ for all $v\in V$. But, for a  nonzero $(\alpha_1, \ldots, \alpha_m)  \in {\mathbb{K}}^m$,   $\sum_{i=1}^m \alpha_i\psi_i(v) = 0$ for all $v\in V$  if and only if $\sum_{i=1}^m \alpha_i\psi_i =0$  if and only if  $\psi_1, \ldots, \psi_m$ are linearly dependent. 
Further,   if $F$ is onto, then  for each $e_j = (\delta_{1j}, \ldots, \delta_{mj} )\in {\mathbb{K}}^m$ for $j\in \{1, \ldots, m\}$, there exists $v_j\in V$ such that $F(v_j)=e_j$, equivalently,  $\psi_i(v_j) = \delta_{ij}$ for $ i,j\in \{1, \ldots, m\}$.

However,  we derived it as a particular case of a general result using simpler arguments in the setting of a vector  space.

<!-- head-1: body_md -->
Throughout the paper,  if $X$ and $Y$ are linear spaces and  $T: X\to Y$, is a linear  operator, then  its range  will be denoted by $R(T)$ and its kernel or null-space will be denoted by $N(T)$. Thus, 
$$
R(T)  =  \{Tu: u\in X\},\quad N(T) = \{u\in X: Tu=0\}.$$
If $X$ is a  normed linear space, 
then the norm on $X$ will be 
denotd by $\|\cdot\|_X$. If $X$ is an inner product space, then the inner product on $X$  will be denote by  $\<\cdot, \cdot\>_X$ and the induced the norm will be denoted by $\|\cdot\|_X$, and for  $S\subseteq X$,  the orthogonal complement of $S$ will be denoted by $S^\perp$.  Thus, 
$$S^\perp = \{u\in X: \<u, v\>_X=0\hbox{ for every } v\in S\}.$$
If $X$ is a normed linear space, then the set of all continuous linear functionals on $X$ is denoted by $X^*$, and  for $\varphi\in X^*$ and $u\in X$, the scalar $\varphi(u)$ will also be denoted by the {\it duality pair} $\<u, \varphi\>$.  
Thus,      
$$\<f, \varphi\> :=  \varphi(f)\quad\forall\, \varphi\in X^*,\, f\in X.$$
This notation is found to be useful while deducing results associated with the adjoint of an operator from a normed linear space to ${\mathbb{R}}^n$.
Recall also that $\Phi: {\mathcal X}\to {\mathbb{R}}^n$ is a continuous linear operator defined by (\ref{op}) \w.r.t. any  inner product $\<\cdot, \cdot\>_{{\mathbb{R}}^n}$ on ${\mathbb{R}}^n$, and \w.r.t. this inner product,   we have 
$${\mathbb{R}}^n = R(\Phi) \oplus R(\Phi)^\perp.$$ 
The conclusions in the following theorem can be verified easily.
<!-- end head-1 -->
<!-- theorem-3: body_md -->
\label{Th-adj} 
For each ${\bf u}\in {\mathbb{R}}^n$, the function $f\mapsto   \<\Phi(f), {\bf u}\>_{{\mathbb{R}}^n}$ belongs to ${\mathcal X}^*$ and 
  $\Phi^*:  {\mathbb{R}}^n\to {\mathcal X}^*$  defined given by 
$$\<f, \Phi^*({\bf u})\> = \<\Phi(f), {\bf u}\>_{{\mathbb{R}}^n},\quad f\in {\mathcal X},\, {\bf u}\in {\mathbb{R}}^n,$$
is a continuous linear operator.
<!-- end theorem-3 -->
<!-- theorem-4: body_md -->
\label{adj}
Suppose the  inner product  $\<\cdot, \cdot\>_{{\mathbb{R}}^n}$ is  the weighted  inner product induced by $(w_1, \ldots, w_n)$. Then $\Phi^*: {\mathbb{R}}^n\to {\mathcal X}^*$ and $\Phi^*\Phi: {\mathcal X}\to {\mathcal X}^*$ are given by 
$$\Phi^*({\bf u}) = \sum_{j=1}^n w_j {\bf u}_j \varphi_j,\quad {\bf u}\in {\mathbb{R}}^n,$$ 
$$\Phi^*\Phi(f) =  \sum_{j=1}^n w_j  \<f, \varphi_j\>  \varphi_j,$$
respectively.
<!-- end theorem-4 -->
<!-- proof-2: body_md -->
For $f\in {\mathcal X}$ and ${\bf u}\in {\mathbb{R}}_w^n$,  we have 
$$
\<f, \Phi^*({\bf u})\> =  \<\Phi(f), {\bf u}\>_{{\mathbb{R}}^n} 
= \sum_{j=1}^n w_j \< f,   \varphi_j \> {\bf u}_j = \Big\< f,  \sum_{j=1}^n w_j {\bf u}_j \varphi_j \Big\>.$$
Thus,  
$$\Phi^*({\bf u}) = \sum_{j=1}^n w_j {\bf u}_j \varphi_j,\quad {\bf u}\in {\mathbb{R}}^n.$$ 
Therefore, for every  $f\in {\mathcal X}$, we have 
$$\Phi^*\Phi(f) =  \sum_{j=1}^n w_j  \<f, \varphi_j\>  \varphi_j.$$
This completes the proof.
<!-- end proof-2 -->
<!-- lemma-1: body_md -->
\label{lem-adj}   Let $\Phi^*$ be  the adjoint of $\Phi$, defined as in Theorem \ref{Th-adj}.   Then 
$$ N(\Phi^*) = R(\Phi)^\perp, \quad N(\Phi^*\Phi) = N(\Phi).$$
<!-- end lemma-1 -->
<!-- proof-3: body_md -->
We observe that, for ${\bf u}\in {\mathbb{R}}_w^n$, 
\begin{eqnarray*} 
\Phi^*({\bf u}) = 0 & \iff &    \<f, \Phi^*({\bf u}) \> = 0\quad\forall\, f\in {\mathcal X},\\
& \iff &    \<\Phi(f),  {\bf u} \>_{{\mathbb{R}}^n} = 0\quad\forall\, f\in {\mathcal X},\\
& \iff &     {\bf u}\in R(\Phi)^\perp.
\end{eqnarray*} 
Hence,  $N(\Phi^*) = R(\Phi)^\perp.$   
Now, to show that $N(\Phi^*\Phi) = N(\Phi)$, first we  observe that 
$N(\Phi) \subseteq N(\Phi^*\Phi)$. To show the other way inclusion, let $f\in N(\Phi^*\Phi)$. Then, we have $\Phi(f) \in N(\Phi^*)=R(\Phi)^\perp$, so that we obtain $\Phi(f) \in  R(\Phi) \cap R(\Phi)^\perp$, resulting in $\Phi(f)=0$, that is, $f\in N(\Phi)$.  Thus, the proof is completed.
<!-- end proof-3 -->
<!-- theorem-5: body_md -->
\label{Th-LS}
 There exists $f\in {\mathcal X}$ such that 
\begin{equation}\label{eq-LS}\|\Phi(f) - \xi\|_{{\mathbb{R}}^n} = \inf_{h\in {\mathcal X}}\|\Phi(h)-\xi\|_{{\mathbb{R}}^n}.\end{equation} 
Further,  for $f\in {\mathcal X}$, the above equality  holds iff 
$$\Phi^*\Phi(f) = \Phi^*(\xi),$$
where $\Phi^*$ is the adjoint of $\Phi$, defined as in Theorem \ref{Th-adj}.
<!-- end theorem-5 -->
<!-- proof-4: body_md -->
Let $P: {\mathbb{R}}_w^n\to {\mathbb{R}}^n$ be the  orthogonal projection onto $R(\Phi)$.  Let  $f\in {\mathcal X}$ be such that  $\Phi(f) = P\xi$. Then, we obtain 
$$\|\xi  - \Phi(f)\|_{{\mathbb{R}}^n} = \|\xi  - P\xi\|_{{\mathbb{R}}^n} = 
 \inf_{{\bf u}\in R(\Phi)}\|\xi- {\bf u}\|_{{\mathbb{R}}^n} =  \inf_{h\in {\mathcal X}}\|\xi-\Phi(h)\|_{{\mathbb{R}}^n}.$$
Thus,  this $f$ satisfies (\ref{eq-LS}).   
Also, for any $f\in {\mathcal X}$,  using Lemma \ref{lem-adj}, we obtain 
\begin{eqnarray*} \Phi(f) = P\xi  &\iff&  P(\Phi(f)-\xi) = 0 \\
& \iff&  \Phi(f)-\xi\in R(\Phi)^\perp = N(\Phi^*) \\
&\iff & \Phi^*\Phi(f) = \Phi^*(\xi).
\end{eqnarray*} 
This completes the proof.
<!-- end proof-4 -->
<!-- remark-5: body_md -->
\rm
It is to be observed that Theorem \ref{Th-LS}, specially the second part,  is analogous to Theorem 4.5 in \cite{Nair-linop} and Theorem 14.3.2 in \cite{Nair-FA}, which are proved in the case when ${\mathcal X}$ is a Hilbert space. However,  using the inner product structure on ${\mathbb{R}}^n$, we could  prove  Theorem \ref{Th-LS}  using only the normed linear structure on  ${\mathcal X}$.

<!-- theorem-6: body_md -->
\label{LS-1} 
Let  $\varphi_1, \ldots, \varphi_n$ be  linearly independent  in ${\mathcal X}^*$ and  $f_1, \ldots, f_n$ in ${\mathcal X}$ be   as in Theorem  \ref{Th-onto}. Then  the equation  (\ref{op-1}) has  a unique  solution  $f_0$ belonging to $\hbox{span}\{f_1, \ldots, f_n\}$, and  it is given by 
$$f_0= \sum_{i=1}^n \xi_if_i.$$
<!-- end theorem-6 -->
<!-- proof-5: body_md -->
Let  $f_0 = \sum_{i=1}^n \xi_if_i$. Since $\<f_i, \varphi_j\> = \delta_{ij}$,  we have  
$$\<f_0, \varphi_j\> =  \sum_{i=1}^n \xi_i \<f_i, \varphi_j\> = \xi_j,\quad j\in \{1, \ldots, n\}. $$
Hence, $\Phi(f_0) = \xi$. To see the uniqueness,  suppose  $f$ is  any arbitrary element in $\hbox{span}\{f_1, \ldots, f_n\}$ which  satisfies $\Phi(f) = \xi$.  Then $f$ has the representation $f=\sum_{i=1}^n \alpha_i f_i$ for some $(\alpha_1, \ldots, \alpha_n)\in {\mathbb{R}}^n$,  so that  
$\alpha_j = \<f, \varphi_j\>  = \xi_j$ for every $ j\in \{1, \ldots, n\}$. Hence,  we can conclude that $f = f_0$.

<!-- theorem-7: body_md -->
\label{projection} 
Let $Q: {\mathcal X}\to {\mathcal X}$  be defined as in (\ref{gen-proj}) and let ${\mathcal X}_0:= {\rm span}\{h_1, \ldots, h_k\}$. Then $Q$ is a projection operator with 
$$R(Q)={\mathcal X}_0,\quad N(Q)= N(\Phi),\quad\hbox{and}\quad R(\Phi) = \{\Phi(f): f\in {\mathcal X}_0\}.$$
<!-- end theorem-7 -->
<!-- proof-6: body_md -->
Since   $Q(h_j)=h_j$ for every $j\in \{1, \ldots, k\}$, we obtain $Q(f) = f$ for every $f\in {\mathcal X}_0$.  Also,  $f\in {\mathcal X}$,  we have 
\begin{eqnarray*} 
f\in N(Q)  &\iff&  \psi_i(f)=0\quad\forall\, i\in \{1, \ldots, k\} \\
&\iff & \varphi_i(f)=0\quad\forall\, i\in \{1, \ldots, n\}\\
&\iff& f\in N(\Phi).\end{eqnarray*}
Thus, $Q$ is a projection operator with 
$R(Q)={\mathcal X}_0$ and $N(Q)= N(\Phi).$

Next, for every $f\in {\mathcal X}$, if $g\in N(\Phi)$ and $h\in {\mathcal X}_0$ are such that $f=g+h$, then we have $\Phi(f) = \Phi(h)$ so that, it follows that $R(\Phi) = \{\Phi(f): f\in {\mathcal X}_0\}$.
<!-- end proof-6 -->
<!-- theorem-8: body_md -->
\label{LS-2}
Let $\xi\in {\mathbb{R}}^n$.  Then,  (\ref{op-1}) has a unique least-square solution in ${\mathcal X}_0$, that is, there  exists a unique    $ f^\dagger \in {\mathcal X}_0$  such that   
$$\Phi^*\Phi(f^\dagger) = \Phi^*(\xi).$$
Further, \w.r.t. $f^\dagger$ is the unique least-square solution  of (\ref{op-1})  such that 
\begin{equation}\label{mini-norm} \|f^\dagger \|_0 = \inf\{\|f\|_0: \Phi^*\Phi(f) = \Phi^*(\xi)\},\end{equation} 
where $\|\cdot\|_0$ is the norm on ${\mathcal X}$, defined by 
$$\|f\|_0 = \|g\|_{\mathcal X} + \|h\|_{\mathcal X}, f\in {\mathcal X},$$ 
with $(g, h)$  as the unique pair in $N(\Phi)\times {\mathcal X}_0$ such that $f=g+h$.
<!-- end theorem-8 -->
<!-- proof-7: body_md -->
Let   $f\in {\mathcal X}$ be any given least-square solution of  the equation  (\ref{op-1}), and let $f^\dagger = Q(f)$ be as defined in (\ref{gen-proj}), where $Q: {\mathcal X}\to {\mathcal X}$ is the projection operator defined as in (\ref{gen-proj}), that is,   
$$f^\dagger = \sum_{i=1}^k \psi_i(f)h_i, $$
where $\psi_1, \ldots, \psi_k$ are as in (\ref{span-op}). 
Clearly, $f^\dagger \in {\mathcal X}_0$. Since $\psi_i(f) = \psi_i(f^\dagger)$ for every $i\in \{1, \ldots,  k\}$, we obtain  $\Phi(f) = \Phi(f^\dagger)$, and hence 
$$\Phi^*\Phi(f^\dagger) = \Phi^*\Phi(f) = \Phi^*(\xi).$$
Now, suppose $\tilde f$ is any least square solution in ${\mathcal X}_0$. Then, we have   
$$\Phi^*\Phi(\tilde f) = \Phi^*(\xi) = \Phi^*\Phi(f^\dagger)$$ 
so that 
$\Phi(\tilde f-f^\dagger) \in N(\Phi^*).$
By Lemma \ref{lem-adj},  $N(\Phi^*) = R(\Phi)^\perp$. Hence, $\Phi(\tilde f-f^\dagger)=0$, that is,   $\tilde f-f^\dagger \in N(\Phi))$.  Since $\tilde f -f^\dagger\in {\mathcal X}_0$, the above equality implies that $\tilde f = f^\dagger$.  This finishes the first part of the theorem.  

For the second part, first  we note that  
$$\|f\|_0 = \|Q(f)\|_{\mathcal X}+\|f-Q(f\|_{\mathcal X},\quad f\in {\mathcal X}.$$
Then, for any least-square solution $f$ of (\ref{op-1}), we have $Q(f) = f^\dagger$ so that 
$$\|f^\dagger\|_0 = \|f^\dagger\|_{\mathcal X} \leq \|f\|_0.$$
Thus, $f^\dagger$ satisfies (\ref{mini-norm}). 
To see the uniqueness of $f^\dagger$ satisfying (\ref{mini-norm}), let $\tilde f$ be also a  least-square solution of (\ref{op-1})  satisfying (\ref{mini-norm}). Then we have 
$$\|f^\dagger\|_{\mathcal X} = \|f^\dagger\|_0 = \|\tilde f\|_0 = \|f^\dagger \|_{\mathcal X}+\|\tilde f-f^\dagger\|_{\mathcal X}.$$
This shows that $\tilde f = f^\dagger$, and the proof is complete.

<!-- theorem-9: body_md -->
\label{Th-matrix-pos-self} 
The  $k\times k$ matrix ${\bf A} =(a_{ij})$, where $a_{ij}$ is an in  (\ref{matrix-0}), is symmetric and positive definite \w.r.t. the standard inner product on ${\mathbb{R}}^k$. Further, $N({\bf A})=0.$
<!-- end theorem-9 -->
<!-- proof-8: body_md -->
Fro the expression for $a_{\ell j}$ as given in  (\ref{matrix-0}), we see that $a_{\ell\,j} = a_{j\ell}$. Thus,  ${\bf   A}$ is symmetric. Now, to see that it is positive definite, let    ${\bf u}\in {\mathbb{R}}^k$. Then we have 
\begin{eqnarray*} 
\<{\bf A}{\bf u}, {\bf u}\>_{{\mathbb{R}}^k} &=&     \sum_{\ell=1}^k {\bf  u}_\ell\sum_{j=1}^k   \Big(\sum_{i=1}^n w_i  \<h_j, \varphi_i\>  \<h_\ell, \varphi_i\>\Big)      {\bf   u}_j \\
& = & \sum_{i=1}^n  w_i    \Big(\sum_{\ell=1}^k  
\<h_\ell, \varphi_i\> {\bf  u}_\ell\Big)  \Big( \sum_{j=1}^k      \<h_j, \varphi_i\>     {\bf   u}_j \Big).
\end{eqnarray*} 
Thus, 
\begin{equation}\label{pos-def} \<{\bf A}{\bf u}, {\bf u}\>_{{\mathbb{R}}^k}  = \sum_{i=1}^n  w_i   \Big( \sum_{j=1}^k      \<h_j, \varphi_i\>     {\bf   u}_j \Big)^2 \geq 0\quad\forall\, {\bf u}\in {\mathbb{R}}^k,
\end{equation} 
so that   ${\bf A}$ is positive definite.  Also,  in view of  (\ref{pos-def}) and (\ref{span-op}), we have 
\begin{eqnarray*} 
\<{\bf A}{\bf u}, {\bf u}\>_{{\mathbb{R}}^k}  = 0  
&\iff&  \sum_{j=1}^k      \<h_j, \varphi_i\>     {\bf   u}_j  = 0 \quad\forall\, i=1, \ldots, n,\\
&\iff&  \sum_{j=1}^k      \<h_j, \psi_i\>     {\bf   u}_j  = 0 \quad\forall\, i=1, \ldots, k\\
&\iff& {\bf u}_i=0\quad\forall\, i=1, \ldots, k \\
&\iff& {\bf u}=0.
\end{eqnarray*}
In particular, $N({\bf A})=0$.

<!-- theorem-10: body_md -->
\label{Th-error-noise-free}
Let ${\bf u} ^\dagger = (\alpha_1, \ldots, \alpha_k)$ and ${\bf u}_\lambda = (\gamma_1, \ldots, \gamma_k)$ be the solutions of  (\ref{matrix-1}) and (\ref{matrix-2}), respectively,   and  let  $f^\dagger  = \sum_{j=1}^k \alpha_j h_j$ and $f_\lambda = \sum_{j=1}^k \gamma_j h_j$ be 
as   obtained  in Theorem  \ref{LS-2} and in (\ref{reg-sol}), respectively. 
Then    the inequalities 
\begin{equation}\label{error-1} \|{\bf u} ^\dagger -{\bf u}_\lambda\|_{{\mathbb{R}}^k} \leq \lambda \|{\bf w}\|_{{\mathbb{R}}^k},\quad \|f^\dagger -f_\lambda\|_{\mathcal X}  \leq  \Big( \sum_{j=1}^k\|h_j\|_{\mathcal X}^2\Big)^{\frac{1}{2}}\|{\bf u}^\dagger  -{\bf u}_\lambda\|_{{\mathbb{R}}^k}\end{equation} 
hold for every $\lambda>0$, where ${\bf w}$ is as in Corollary \ref{cor-matrix-pos-self}.
In particular,
\begin{equation}\label{error-2}\|{\bf u}^\dagger -{\bf u}_\lambda\|_{{\mathbb{R}}^k} =O(\lambda),   \quad   
\|f^\dagger -f_\lambda\|_{\mathcal X}  = O(\lambda)  \quad\hbox{as}\quad \lambda \to 0.\end{equation}
<!-- end theorem-10 -->
<!-- proof-10: body_md -->
Since  ${\bf u}^\dagger $ is the solution of  (\ref{matrix-1}), we have 
$({\bf A} +\lambda {\bf I}) {\bf u} ^\dagger = \lambda{\bf u} ^\dagger + {\bf v}.$
This combined with (\ref{matrix-2}) imply that 
$$({\bf A} +\lambda {\bf I}) ({\bf u}^\dagger  -{\bf u}_\lambda) = \lambda{\bf u}^\dagger $$
so that, by the invertibility of ${\bf A} +\lambda {\bf I}$, we obtain 
$${\bf u} ^\dagger -{\bf u}_\lambda = \lambda ({\bf A} +\lambda {\bf I})^{-1} {\bf u}^\dagger .$$
{By Corollary \ref{cor-matrix-pos-self},  there exists a unique ${\bf w}\in {\mathbb{R}}^k$ such that   ${\bf u}^\dagger  = {\bf A}{\bf w}$},  so that we obtain 
$$\|{\bf u}^\dagger  -{\bf u}_\lambda\|_{{\mathbb{R}}^k} = \lambda \|({\bf A} +\lambda {\bf I})^{-1} {\bf A}{\bf w}\|_{{\mathbb{R}}^k} \leq \lambda \|{\bf w}\|_{{\mathbb{R}}^k}.$$
Thus, first inequality in (\ref{error-1}) is proved. For getting the last inequality in the above,  we used the inequality $\|({\bf A} +\lambda {\bf I})^{-1} {\bf A}\|\leq 1$ (cf. \cite{Nair-linop}). Since 
$$ f^\dagger -f_\lambda  =    \sum_{j=1}^k (\alpha_j - \gamma_j)  h_j,\quad  \|{\bf u}^\dagger  - {\bf u}_\lambda\|_{{\mathbb{R}}^k}^2 = \sum_{j=1}^k |\alpha_j - \gamma_j|^2,$$ 
by Cauchy-Schwarz inequality, we obtain 
$$
\|f^\dagger -f_\lambda\|_{\mathcal X}  \leq   \sum_{j=1}^k |\alpha_j - \gamma_j|\,  \| h_j\|_{\mathcal X}  \leq  \Big( \sum_{j=1}^k  \| h_j\|_{\mathcal X}^2\Big)^{\frac{1}{2}} \|{\bf u} ^\dagger - {\bf u}_\lambda\|_{{\mathbb{R}}^k} .$$
Thus, the second inequality in (\ref{error-1}) holds.  Since $\|{\bf u} ^\dagger -{\bf u}_\lambda\|_{{\mathbb{R}}^k} \leq \lambda \|{\bf w}\|_{{\mathbb{R}}^k}$, we have 
$$
\|f^\dagger -f_\lambda\|_{\mathcal X}  \leq  \lambda \|{\bf w}\|_{{\mathbb{R}}^k} \Big( \sum_{j=1}^k  \| h_j\|_{\mathcal X}^2\Big)^{\frac{1}{2}} .$$
Thus, (\ref{error-2}) is also proved.

\begin{equation}\label{error-4} \|f^\dagger -\tilde f_\lambda\|_{\mathcal X}  \leq \Big(\sum_{j=1}^k \| h_j\|_{\mathcal X}^2\Big)^{\frac{1}{2}}    \|{\bf u}^\dagger -{\bf \tilde u}_\lambda\|_{{\mathbb{R}}^k}\end{equation}

where 
$ C_1 :=   \|{\bf w}\|_{{\mathbb{R}}^k}   +  1/2$ and  $C_2 :=  C_1   \Big(\sum_{j=1}^k \| h_j\|_{\mathcal X}^2\Big)^{\frac{1}{2}}.$

\rm

$$\Phi^*\Phi(f_\lambda) + \lambda  \sum_{j=1}^k \<f_\lambda, \psi_j\>\psi_j = \Phi^*(\xi),$$
