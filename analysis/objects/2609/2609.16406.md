<!-- definition-1: body_md -->
Let $\mathcal{H}$ be a Hilbert space of functions defined over set $X$.
We say that $\mathcal{H}$ is a {\bf reproducing kernel Hilbert space (RKHS)} if, for each $\mathbf{x}\in X$, the point evaluation is a bounded linear functional, i.e. there exists some constant $M_\mathbf{x}\geq0$ such that 
\begin{equation}
|f(\mathbf{x})| \leq M_\mathbf{x} \|f\|_\mathcal{H}, \quad \mbox{for all } f\in\mathcal{H}.
\end{equation}
<!-- end definition-1 -->
<!-- definition-2: body_md -->
The kernel $K$ is a positive (semi)definite kernel, in the sense that, for any $m\geq1$ and any $\mathbf{x}^{(1)},\dots,\mathbf{x}^{(m)}\in X$, the $m\times m$ matrix with entries $K(\mathbf{x}^{(i)}, \mathbf{x}^{(j)}), i,j\in[m]$, is positive (semi)definite.
<!-- end definition-2 -->
<!-- theorem-1: body_md -->
If $K: X\times X\to\mathbb{R}$ is a positive semidefinite kernel, then there exists a unique reproducing kernel Hilbert space $\mathcal{H}$ whose reproducing kernel coincides with $K$.
<!-- end theorem-1 -->
<!-- definition-3: body_md -->
A positive definite kernel $K:\mathbb{R}^d\times \mathbb{R}^d\to\mathbb{R}$ is {\bf translation-invariant} if there exists a function $\Tilde{K}:\mathbb{R}^d \to\mathbb{R}$ such that
\begin{equation*}
K(\mathbf{x},\mathbf{x}') = \Tilde{K}(\mathbf{x}-\mathbf{x}') \quad \mbox{ for all } \mathbf{x},\mathbf{x}'\in \mathbb{R}^d.
\end{equation*}
<!-- end definition-3 -->
<!-- theorem-2: body_md -->
A continuous translation-invariant kernel $K:X\times X\to\mathbb{R}$ satisfying $K(\mathbf{x},\mathbf{x}') = \Tilde{K}(\mathbf{x}-\mathbf{x}')$ is positive definite if and only if $\Tilde{K}(\boldsymbol\omega)$ is the Fourier transform of a non-negative measure.
<!-- end theorem-2 -->

<!-- theorem-3: body_md -->
Let $K\subset \mathbb{R}^d$ compact and $U \subset C(K)$ compact and consider a parametric family of random activation function $\{\varphi(\mathbf{x},\boldsymbol\omega):\mathbf{x}\in\mathbb{R}^d, \boldsymbol\omega\in \Omega \}$, where $\boldsymbol\omega\in\Omega$ is a vector of randomly chosen (hyper)parameters, and assume that $\phi$ are uniformly bounded in $\mathbb{R}^d\times \Omega$. Let $\rho$ be a probability distribution on $\Omega$. Given any $\epsilon$, there exists a $N\in\mathbb{N}$ and i.i.d samples $\{\boldsymbol\omega_k\}_{k\in[N]}$ from $\rho$, chosen independently of $f$, such that for every $f\in U$ the random approximation
\begin{equation*}
    f_\epsilon(\mathbf{x}) = \sum_{k=1}^N c_k[f]\varphi(\mathbf{x},\boldsymbol\omega_k),
\end{equation*}
approximates $f$ in the sense that with high probability 
\begin{equation*}
\|f - f_\epsilon\|_{L^2(\mu)} < \epsilon,
\end{equation*}
for a suitable probability measure $\mu$ over $K$. Moreover, if $\varphi(\mathbf{x},\boldsymbol\omega) = \psi(\mathbf{x}\cdot\boldsymbol\omega)$, for a L-Lipschitz function $\psi$, the above approximation is uniform (i.e. in the supremum norm).
<!-- end theorem-3 -->
<!-- proof-1: body_md -->
The proof in \cite{FABIANI2025RandONets} follows three steps: first, it applies universal approximation results of vanilla shallow neural networks with a continuous sigmoidal (non-polynomial) activation function; second, it uses radial basis function (RBF) networks to approximate the continuous sigmoidal activation function, and hence shows that RBF networks are universal approximators; third, it shows that randomized neural networks can approximate RBF networks, and then randomized neural networks are universal approximators of continuous functions.

Alternatively, we can apply universal kernels \cite{Micchelli2006Universal} to show that their corresponding RKHS is dense in $C(K)$, and then show that randomized neural networks (random features models) can approximate any functions in the RKHS. Therefore, randomized neural networks are universal approximators of continuous functions.
<!-- end proof-1 -->
<!-- theorem-4: body_md -->
\label{Thm:L2}
Let $f$ be a function from $\mathcal{F}(\rho)$. Suppose that the random feature map $\phi$ satisfies $|\varphi(\mathbf{x},\boldsymbol\omega)|\leq1$ for all $\mathbf{x}\in X$ and $\boldsymbol\omega\in\mathbb{R}^d$. Then for any $\delta\in(0,1)$, there exists $c^\sharp_1,\dots,c^\sharp_N$ so that the function
\begin{equation}
\label{RF_approximator}
f^\sharp(\mathbf{x}) = \sum_{k=1}^N c^\sharp_k\varphi(\mathbf{x},\boldsymbol\omega_k) 
\end{equation}
satisfies
\begin{equation*}
\left| f(\mathbf{x}) - f^\sharp(\mathbf{x})\right| \leq \frac{12\|f\|_{\mathcal{F}(\rho)}\log(2/\delta)}{\sqrt{N}}     
\end{equation*}
with probability at least $1-\delta$ over $\boldsymbol\omega_1,\dots,\boldsymbol\omega_N$ drawn i.i.d from $\rho(\boldsymbol\omega)$.
<!-- end theorem-4 -->
<!-- proof-2: body_md -->
We outline the main idea of the proof. The proof is constructive. We first construct a random feature approximation $f^\sharp$ associated with the target function $f$. Since the true function is generally unknown to us, this construction is used for analysis and is not intended to be implemented directly. We then apply concentration inequalities to obtain the desired results.
<!-- end proof-2 -->
<!-- theorem-5: body_md -->
\label{Thm:H1}
Let $f$ be a function from $\mathcal{F}(\rho)\cap\widetilde{\mathcal{F}}(\rho)$. Suppose that the random feature map $\phi$ satisfies $|\varphi(\mathbf{x},\boldsymbol\omega)|\leq1$ for all $\mathbf{x}\in X$ and $\boldsymbol\omega\in\mathbb{R}^d$. 
We define a set 
\begin{equation*}
\epsilon_N(\delta) = \Big\{ \max_{k\in [N]} \max_{i\in[d]} \sup_{\mathbf{x}\in X} \left| \frac{\partial \varphi(\mathbf{x}, \boldsymbol\omega_k)}{\partial x_i} \right| \leq B_N(\delta) \Big\},
\end{equation*}
where $B_N(\delta)>0$ depends on $N$ and $\delta$. We assume that $\mathbb{P}(\epsilon_N(\delta)) \geq 1-\delta/2$.
Then for any $\delta\in(0,1)$, there exists $c^\sharp_1,\dots,c^\sharp_N$ so that the function
\begin{equation}
                        
f^\sharp(\mathbf{x}) = \sum_{k=1}^N c^\sharp_k\varphi(\mathbf{x},\boldsymbol\omega_k) 
\end{equation}
satisfies
\begin{equation*}
\| f(\mathbf{x}) - f^\sharp(\mathbf{x})\|_{H^1(X)} \leq \frac{12\|f\|_{\mathcal{F}(\rho)}\log(2/\delta)\sqrt{|X|}}{\sqrt{N}} + \frac{12MB_N(\delta)\|f\|_\mathcal{F}(\rho)\log(2/\delta)\sqrt{|X|}}{\sqrt{N}}
\end{equation*}
with probability at least $1-\delta$ over $\boldsymbol\omega_1,\dots,\boldsymbol\omega_N$ drawn i.i.d from $\rho(\boldsymbol\omega)$ and over random event $\epsilon_N(\delta)$.
<!-- end theorem-5 -->
<!-- proof-3: body_md -->
We first introduce notation $\alpha_{\leq T}(\boldsymbol\omega) = \alpha(\boldsymbol\omega)\mathbbm{1}_{|\alpha(\boldsymbol\omega)|\leq T}$ and $\alpha_{>T} = \alpha(\boldsymbol\omega) - \alpha_{\leq T}(\boldsymbol\omega)$ for any $T>0$.
We draw random features $\{\boldsymbol\omega\}_{k=1}^N$ from $\rho(\boldsymbol\omega)$. We then define $c_k^\sharp = \alpha_{\leq T}(\boldsymbol\omega_k) / N$ for all $k\in[N]$ and a random feature approximation as
\begin{equation*}
f^\sharp(\mathbf{x}) = \frac{1}{N}\sum_{k=1}^N  \alpha_{\leq T}(\boldsymbol\omega_k) \varphi(\mathbf{x},\boldsymbol\omega).
\end{equation*}
For each component $x_i$ of $\mathbf{x}\in\mathbb{R}^d$, we decompose the error into two terms, i.e.
\begin{equation*}
\left| \frac{\partial(f-f^\sharp)}{\partial x_i}\right| \leq \underbrace{\left| \frac{\partial(f-g)}{\partial x_i}\right|}_{I_1} + \underbrace{\left| \frac{\partial(g-f^\sharp)}{\partial x_i}\right|}_{I_2},
\end{equation*}
where $g=\mathbf{E}_{\boldsymbol\omega} f^\sharp$. Moreover, we notice that $f-g = \mathbf{E}_{\boldsymbol\omega} \alpha_{>T}(\boldsymbol\omega)\varphi(\mathbf{x},\boldsymbol\omega)$.

We first bound term $I_1$, which can be written as
\begin{equation*}
I_1 = \left| \mathbf{E}_{\boldsymbol\omega} \alpha_{>T}(\boldsymbol\omega) \frac{\partial \varphi(\mathbf{x},\boldsymbol\omega)}{\partial x_i}\right| = \left|\int_{\mathbb{R}^d} \alpha_{>T}(\boldsymbol\omega) \frac{\partial \varphi(\mathbf{x},\boldsymbol\omega)}{\partial x_i} d\rho(\boldsymbol\omega) \right|.
\end{equation*}
Then, we apply Cauchy-Schwarz inequality to obtain 
\begin{equation*}
I_1 \leq \underbrace{\left[ \int_{\mathbb{R}^d} \left|\alpha(\boldsymbol\omega) \frac{\partial \varphi(\mathbf{x},\boldsymbol\omega)}{\partial x_i} \right|^2 d\rho(\boldsymbol\omega) \right]^{1/2}}_{M_i} \left[ \int_{\mathbb{R}^d} \mathbbm{1}_{|\alpha(\boldsymbol\omega)|\geq T}^2d\rho(\boldsymbol\omega) \right]^{1/2}.
\end{equation*}
Finally, applying Markov's inequality yields
\begin{equation*}
I_1 \leq M_i \frac{\mathbf{E}_{\boldsymbol\omega}|\alpha(\boldsymbol\omega)|^2}{T} = \frac{M_i \|f\|^2_{\mathcal{F}(\rho)}}{T}.
\end{equation*}

Next, we bound term $I_2$. By assumption, we have
\begin{equation*}
\mathbb{P}(\epsilon_N(\delta)) \geq 1-\delta/2.
\end{equation*}
For any $\mathbf{x}\in X$, we define random variable $Z(\boldsymbol\omega) = \alpha_{\geq T}(\boldsymbol\omega)\frac{\partial \varphi(\mathbf{x},\boldsymbol\omega)}{\partial x_i}$ and let $Z_1,\dots, Z_N$ be N i.i.d copies of $Z(\boldsymbol\omega)$ defined by $Z_k = Z(\boldsymbol\omega_k)$ for $k\in[N]$.
On the event $\epsilon_N(\delta)$, we have, with probability at least $1-\delta/2$,
\begin{equation*}
|Z_k| \leq T B_N(\delta).
\end{equation*}
The variance of $Z$ is bounded above as
\begin{equation*}
\mathbf{E}_{\boldsymbol\omega} |Z - \mathbf{E}_{\boldsymbol\omega} Z|^2 \leq \mathbf{E}_{\boldsymbol\omega} |Z|^2 \leq M_i^2.
\end{equation*}
By Lemma~\ref{lemma:bound} and Theorem~\ref{Thm:Bern}, it holds that, 
\begin{equation*}
I_2 = \left|\frac{1}{N}\sum_{k=1}^N Z_k - \mathbf{E}_{\boldsymbol\omega}Z\right|\leq \frac{4TB_N(\delta)\log(2/\delta)}{N} + \sqrt{\frac{2M_i^2\log(2/\delta)}{N}}.
\end{equation*}
Choosing $T=\sqrt{N}\|f\|_{\mathcal{F}(\rho)}$ and adding the bounds of $I_1$ and $I_2$ give
\begin{equation*}
\begin{aligned}
\left| \frac{\partial(f-f^\sharp)}{\partial x_i}\right| \leq &\frac{M_i\|f\|_{\mathcal{F}(\rho)}}{\sqrt{N}} + \frac{4M_i\|f\|_{\mathcal{F}(\rho)}B_N(\delta)\log(2/\delta)}{\sqrt{N}} + \frac{\sqrt{2\log(2/\delta)}M_i}{\sqrt{N}} \\
\leq& \frac{12M_iB_N(\delta)\|f\|_{\mathcal{F}(\rho)}\log(2/\delta)}{\sqrt{N}}.
\end{aligned}
\end{equation*}
Then we immediately obtain the following bound since $X$ has finite Lebesgue measure and we have the relation $M^2 = \sum_{i=1}^dM^2_i$ by the definitions of $M$ and $M_i$, i.e.
\begin{equation}
\label{grad_L2}
\|\nabla(f-f^\sharp)\|_{L^2(X)} = \sqrt{ \sum_{i=1}^d \left\| \frac{\partial (f-f^\sharp)}{\partial x_i} \right\|^2_{L^2(X)} } \leq \frac{12MB_N(\delta)\|f\|_\mathcal{F}(\rho)\log(2/\delta)\sqrt{|X|}}{\sqrt{N}}.
                         
\end{equation}
Combining with the $L^2$ error bound in Theorem \ref{Thm:L2} leads to the desired bound in $H^1$ norm.

<!-- remark-2: body_md -->
Consider the following 1D example where $f(x)$ is represented by its Fourier transform. Then, we have 
\begin{equation*}
\alpha(\omega) = \frac{\Hat{f}(\omega)}{\rho(\omega)},  \,\,\,\, \varphi(x,\omega)=\exp(ix\omega), \,\,\, \mbox{ and } M^2 = \int_{\mathbb{R}} \frac{|\hat{f}(\omega)|^2}{\rho(\omega)}d\omega.
\end{equation*}
Therefore, we show that the Fourier transform is controlled by density function of random feature. If we further take Cauchy distribution with density function $\rho(\omega) = \frac{1}{1+\omega^2}$, then we observe that $M$ is equivalent to $H^1$ norm.
The norm $M$ appearing in the definition of space $\widetilde{\mathcal{F}}(\rho)$ quantifies the regularity of functions and controls the approximation error. 
This approximation result has the same flavor as classical error estimates for finite element method (FEM): controlling the approximation error in $H^1$ norm requires a higher-order regularity assumption on the target function, typically the $H^2$ norm is finite.

<!-- remark-4: body_md -->
In the theorem statement, we define a good event $\epsilon_N(\delta)$ such that the partial derivative of random feature is bounded with probability at least $1-\delta/2$.  
Good event $\epsilon_N(\delta)$ and quantity $B_N(\delta)$ depend on the choice of random features. 
Here, we derive an explicit $B_N(\delta)$ for Gaussian distribution $\mathcal{N}(0,\sigma^2)$ because we mainly use Gaussian distribution in our numerical experiments. 
Suppose that $\omega_i$ follows Gaussian distribution $\mathcal{N}(0,\sigma^2)$, then we have the tail bound 
\begin{equation*}
\mathbb{P}(|\omega_i|\geq B) \leq 2\exp\left(-\frac{B^2}{2\sigma^2}\right).
\end{equation*}
Applying the union bound gives
\begin{equation*}
\mathbb{P}(\max_{k\in[N]} \max_{i\in[d]} |\omega_{k,i}|\leq B) \geq 1-2Nd\exp\left(-\frac{B^2}{2\sigma^2}\right).
\end{equation*}
Since we assume that the failure probability is at most $\delta/2$, then we have
\begin{equation*}
B_N(\delta) = \sigma\sqrt{2\log\left(\frac{4Nd}{\delta}\right)}.
\end{equation*}

<!-- theorem-6: body_md -->
\label{Thm:Bern}
Let $Z$ be a H-valued random variable, where $(H,\langle\cdot,\cdot\rangle,\|\cdot\|)$ is a separable Hilbert space. Suppose there exist positive numbers $b>0$ and $\sigma>0$ such that
\begin{equation}
\label{B_mom_cond}
\mathbf{E} \| Z - \mathbf{E} Z\|^p \leq \frac{1}{2}p!\sigma^2b^{p-2} \quad \mbox{ for all } p\geq 2.
\end{equation}
For any $\delta\in(0,1)$ and $N\in\mathbb{N}$, denoting by $\{Z_n\}_{n=1}^N$ a sequence of $N$ i.i.d copies of $Z$. it holds that
\begin{equation}
\mathbb{P}\left( \left\| \frac{1}{N}\sum_{n=1}^N Z_n - \mathbf{E} Z\right\| \leq \frac{2b\log(2/\delta)}{N} + \sqrt{\frac{2\sigma^2\log(2/\delta)}{N}}\right) \geq 1-\delta. 
\end{equation}

<!-- lemma-1: body_md -->
\label{lemma:bound}
Let $Z$ be a (potentially) uncentered random variable such that
\begin{equation*}
\|Z\| \leq c \mbox{ almost surely } \quad \mbox{ and } \mathbf{E}\|Z-\mathbf{E} Z\|^2 \leq v^2 
\end{equation*}
for some $c>0$ and $v>0$. Then $Z$ satisfies Bernstein's moment condition \eqref{B_mom_cond} with $b=2c$ and $\sigma=v$. If $\mathbf{E} Z=0$, then taking $b=c$ suffices.
