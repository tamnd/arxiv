\label{main 1:intro}
There are natural bijections 
\[
    \xymatrix{G(\mathcal{O})\backslash X^\theta(F)\ar[rr]\ar[dr]&&G\backslash\mathrm{Temp}(G,\theta_0)\ar[dl]\ar[ll]\\
&\mathrm{Bun}_G(\mathbb{P}^1)_{\eta}(\mathbb{R})\ar[ul]\ar[ur]&}
\]
among the following sets:
\begin{enumerate}
    \item $G(\mathcal{O})\backslash X^\theta(F)$,   the set of
$G(\mathcal{O})$-orbits on $X^\theta(F)$,
 \item $\mathrm{Bun}_G(\mathbb{P}^1)_{\eta}(\mathbb{R})$,  the set
 of isomorphism classes of 
 $G$-bundles on the twistor $\mathbb{P}^1$,
\item $G\backslash\mathrm{Temp}(G,\theta_0)$, the set of equivalence classes of tempiric Langlands parameters.
\end{enumerate}
Furthermore, suppose that
$\gamma\in X^\theta(F)$, $\phi\in\mathrm{Temp}(G,\theta_0)$, and $\mathcal{E}\in\mathrm{Bun}_G(\mathbb{P}^1)_{\eta}(\mathbb{R})$
correspond to one another under these bijections. Then there are natural isomorphisms
\[\pi_0(Z_{G(\mathcal{O})}(\gamma))\cong\pi_0(Z_G(\phi))\cong\pi_0(\mathrm{Aut}(\mathcal{E}))\]
between the component groups of the corresponding stabilizer and automorphism groups.

\label{enh}
(1) 
Two tempiric parameters  are called equivalent if they lie in the same $G$-orbit.
We denote by $G\backslash\operatorname{Temp}(G,\theta_0)$ the set of $G$-orbits, referred to as equivalence classes of tempiric parameters.

(2)  Elements in the set $\mathrm{Temp}(G,\theta_0)^{G,enh}=\{(\phi,\chi)|\phi\in\mathrm{Temp}(G,\theta_0), \chi\in\operatorname{Irr}(\pi_0(Z_G(\phi)))\}$
are called $G$-enhanced tempiric parameters.
The set of irreducible $G$-local systems
\[\operatorname{Loc}_G(\mathrm{Temp}(G,\theta_0))=G\backslash\mathrm{Temp}(G,\theta_0)^{G,enh}\]
is referred as equivalence classes of $G$-enhanced tempiric parameters.

(3)  Elements in the set $\mathrm{Temp}(G,\theta_0)^{G^{alg},enh}=\{(\phi,\tilde\chi)|\phi\in\mathrm{Temp}(G,\theta_0), \chi\in\operatorname{Irr}(\pi_0(Z_{G^{alg}}(\phi))\}$

\[\operatorname{Loc}_{G^{alg}}(\mathrm{Temp}(G,\theta_0))=G^{alg}\backslash\mathrm{Temp}(G,\theta_0)^{G^{alg},enh}\]
