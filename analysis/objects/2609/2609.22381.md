<!-- theorem-1: body_md -->
\label{thm:main}
For each $q = 2^m$, there is a box-free tripartite $3$-uniform hypergraph with $q^4$ vertices in each part and $q^{11}$ edges.
<!-- end theorem-1 -->
<!-- corollary-1: body_md -->
\label{cor:main}
As $n \to \infty$, we have $z(n) = \Theta(n^{11/4})$.
<!-- end corollary-1 -->
<!-- proof-1: body_md -->
Erd\H{o}s~\cite[Theorem~1]{erdos} proved the upper bound $z(n) = O(n^{11/4})$. For $n \geq 1$, let $m = \lfloor \log_{16} n \rfloor$ and $q = 2^m$, so that $q^4 = 16^m \leq n < 16 q^4$. Adding $n - q^4$ isolated vertices to each part of the hypergraph from Theorem~\ref{thm:main} then gives $z(n) \geq q^{11} > (n/16)^{11/4}$.
<!-- end proof-1 -->
<!-- theorem-2: body_md -->
\label{thm:fd_lines}
For each $s \in K$, let $c = \delta(s)$. Then \textup{(i)}~$c \neq 0$ and $\operatorname{Tr}(c) = \operatorname{N}(c)$; \textup{(ii)}~for $t \in K$, we have $\delta(t) = c$ if and only if $\tau(t) \in \tau(s) + c\,k$; and \textup{(iii)}~if $\delta(t) = \lambda c$ for some $t \in K$ and $\lambda \in k^\times$, then $\lambda = 1$. In particular, $\tau$ sends the fibers of $\delta$ to pairwise skew affine lines $\tau(s) + c\,k$ partitioning $K$: no affine plane contains two of them.
<!-- end theorem-2 -->
<!-- proof-2: body_md -->
Fix $s \in K$ and set $c = \delta(s)$. Since $\tau$ is injective, we have $c \neq 0$. By equation~\eqref{eq:tau_power}, each $t \in K$ satisfies $\tau(t+1)^{q+1} = (t+1)^2 = t^2 + 1 = \tau(t)^{q+1} + 1$. Because $\tau(t+1) = \tau(t) + \delta(t)$ and the map $s \mapsto s^{q+1}$ is injective, we have $\delta(t) = c$ if and only if $\bigl(\tau(t)+c\bigr)^{q+1} = \tau(t)^{q+1} + 1$. Dividing by $c^{q+1}$ and setting $v = \tau(t)/c$ gives $(v+1)^{q+1} = v^{q+1} + c^{-(q+1)}$, so $\delta(t) = c$ if and only if
\begin{equation}\label{eq:v_trace}
v^q + v = 1 + c^{-(q+1)}.
\end{equation}

Taking $t = s$ shows that $v = \tau(s)/c$ satisfies equation~\eqref{eq:v_trace}. Since $\operatorname{Tr}(v^q) = \operatorname{Tr}(v)$ and $\operatorname{Tr}(1) = 1$ in characteristic~$2$, and $c^{-(q+1)} = c^{q^2}/{\operatorname{N}(c)}$ with $\operatorname{N}(c) \in k^\times$, applying $\operatorname{Tr}$ to equation~\eqref{eq:v_trace} gives $0 = 1 + \operatorname{Tr}\bigl(c^{q^2}/{\operatorname{N}(c)}\bigr) = 1 + \operatorname{Tr}(c)/{\operatorname{N}(c)}$, so $\operatorname{Tr}(c) = \operatorname{N}(c)$, proving~\textup{(i)}.

Adding equation~\eqref{eq:v_trace} for $t$ and for $s$ shows that $\delta(t) = c$ if and only if $w = \bigl(\tau(t) + \tau(s)\bigr)/c$ satisfies $w^q = w$ and hence lies in $k$, so that $\tau(t) \in \tau(s) + c\,k$, proving~\textup{(ii)}.

For~\textup{(iii)}, if $\delta(t) = \lambda c$ for some $t \in K$ and $\lambda \in k^\times$, then~\textup{(i)} applied to $c = \delta(s)$ and to $\lambda c = \delta(t)$ gives
\[
\lambda \operatorname{N}(c) = \lambda \operatorname{Tr}(c) = \operatorname{Tr}(\lambda c) = \operatorname{N}(\lambda c) = \lambda^3 \operatorname{N}(c).
\]
Since $\lambda \operatorname{N}(c) \neq 0$, dividing by $\lambda \operatorname{N}(c)$ gives $\lambda^2 = 1$, so $\lambda = 1$. By~\textup{(ii)} and the bijectivity of $\tau$, distinct fibers of $\delta$ map onto disjoint lines $\tau(s) + c\,k$ partitioning $K$, and by~\textup{(iii)} no two such lines are parallel, so they are pairwise skew.
<!-- end proof-2 -->
<!-- remark-1: body_md -->
\label{rem:char2}
Characteristic~$2$ is essential to Theorem~\ref{thm:fd_lines}: the identity $(t+1)^2 = t^2 + 1$ cancels the quadratic term $t^2 = \tau(t)^{q+1}$, making equation~\eqref{eq:v_trace} linear in $v$, and $\lambda^2 = 1$ forces $\lambda = 1$, ruling out parallel lines.
<!-- end remark-1 -->
<!-- construction-1: body_md -->
\label{const:Hq}
Let $\mathcal{X}$, $\mathcal{Y}$, and $\mathcal{Z}$ be disjoint copies of $K \times k$, each of size $q^4$. Vertices $x = (W,\omega) \in \mathcal{X}$, $y = (Y,\eta) \in \mathcal{Y}$, and $z = (Z,\zeta) \in \mathcal{Z}$ form an edge of the tripartite $3$-uniform hypergraph $H_q$ if and only if
\begin{equation}\label{eq:edge_cond}
\operatorname{Tr}\bigl(\tau(Y+Z)\,W\bigr) + \omega = E(Y,Z) + \eta + \zeta.
\end{equation}
Each triple $(y, z, W) \in \mathcal{Y} \times \mathcal{Z} \times K$ determines a unique $\omega \in k$ satisfying equation~\eqref{eq:edge_cond}, so $H_q$ has $q^4 \cdot q^4 \cdot q^3 = q^{11}$ edges.
<!-- end construction-1 -->
<!-- lemma-1: body_md -->
\label{lem:coplanar}
Let $Y_0, Y_1, Z_0, Z_1 \in K$ satisfy $Y_0 \neq Y_1$ and $Z_0 \neq Z_1$, and set $A_{ij} = \tau(Y_i + Z_j)$ for $i, j \in \{0,1\}$. If the four points $A_{ij}$ lie in an affine plane in $K$, then
\[
\sum_{i,j \in \{0,1\}} A_{ij} = 0 \qquad\text{and}\qquad \sum_{i,j \in \{0,1\}} E(Y_i, Z_j) \neq 0.
\]
<!-- end lemma-1 -->
<!-- proof-3: body_md -->
Let $a = Y_0 + Y_1 \neq 0$, and set $s_j = (Y_0 + Z_j)/a$ for $j \in \{0,1\}$. Since $Y_i = Y_0 + ia$, we have $Y_i + Z_j = a\,(s_j + i)$ and $A_{ij} = a^d\,\tau(s_j + i)$ for $i,j \in \{0,1\}$.

For $j \in \{0,1\}$, let $c_j = \delta(s_j)$ and $L_j = \tau(s_j) + c_j\,k$, so that $A_{0j} + A_{1j} = a^d\,c_j \neq 0$ by Theorem~\ref{thm:fd_lines}\textup{(i)}. Since $\tau(s_j+1) = \tau(s_j) + c_j$, both $\tau(s_j)$ and $\tau(s_j+1)$ lie on $L_j$, so the distinct points $A_{0j}$ and $A_{1j}$ lie on the rescaled line $a^d\,L_j$. Every affine plane through all four points $A_{ij}$ therefore contains both $a^d\,L_0$ and $a^d\,L_1$. By Theorem~\ref{thm:fd_lines}\textup{(ii)}--\textup{(iii)}, the fiber lines $L_0$ and $L_1$ are skew when $c_0 \neq c_1$, so $c_0 = c_1$ and $\sum_{i,j \in \{0,1\}} A_{ij} = a^d\,(c_0 + c_1) = 0$.

Thus $A_{10} + A_{11} = A_{00} + A_{01} = a^d\,\bigl(\tau(s_0) + \tau(s_1)\bigr)$. Since $Z_0 \neq Z_1$, we have $s_0 \neq s_1$. Because $\delta(s_1) = \delta(s_0) = c_0$ and $\tau$ is injective, Theorem~\ref{thm:fd_lines}\textup{(ii)} gives $\tau(s_0) + \tau(s_1) = \lambda c_0$ for some $\lambda \in k^\times$, so $A_{00} + A_{01} = \lambda a^d\,c_0$. Using $Y_0^{2q} + Y_1^{2q} = a^{2q}$ and $a^{2q}\,a^d = \operatorname{N}(a)$ then gives
\[
\sum_{i,j \in \{0,1\}} Y_i^{2q}\,A_{ij} = (Y_0^{2q} + Y_1^{2q})\,(A_{00} + A_{01}) = \lambda \operatorname{N}(a)\,c_0.
\]
Since $\lambda \operatorname{N}(a) \in k^\times$ and $\operatorname{Tr}(c_0) = \operatorname{N}(c_0)$ by Theorem~\ref{thm:fd_lines}\textup{(i)}, taking traces yields
\[
\sum_{i,j \in \{0,1\}} E(Y_i, Z_j) = \lambda \operatorname{N}(a)\,\operatorname{Tr}(c_0) = \lambda \operatorname{N}(a)\,\operatorname{N}(c_0) \neq 0. \qedhere
\]

For $m = 0$, the statement is trivial, so assume that $m \geq 1$. Suppose that the hypergraph $H_q$ of Construction~\ref{const:Hq} contains a box on vertices $x_h = (W_h, \omega_h) \in \mathcal{X}$, $y_i = (Y_i, \eta_i) \in \mathcal{Y}$, and $z_j = (Z_j, \zeta_j) \in \mathcal{Z}$ with $h,i,j \in \{0,1\}$. Since equation~\eqref{eq:edge_cond} uniquely determines each of $\omega$, $\eta$, and $\zeta$ from the remaining coordinates, the inequalities $x_0 \neq x_1$, $y_0 \neq y_1$, and $z_0 \neq z_1$ force $W_0 \neq W_1$, $Y_0 \neq Y_1$, and $Z_0 \neq Z_1$.

For $i, j \in \{0,1\}$, set $A_{ij} = \tau(Y_i + Z_j)$. Adding the edge equations~\eqref{eq:edge_cond} for $(x_0, y_i, z_j)$ and $(x_1, y_i, z_j)$ cancels $E(Y_i, Z_j)$, $\eta_i$, and $\zeta_j$, leaving
\[
\operatorname{Tr}\bigl(A_{ij}\,(W_0 + W_1)\bigr) = \omega_0 + \omega_1.
\]
Since $W_0 \neq W_1$, the $k$-linear functional $s \mapsto \operatorname{Tr}\bigl(s\,(W_0+W_1)\bigr)$ on $K$ is nonzero, so the four points $A_{ij}$ lie in an affine plane in $K$. Lemma~\ref{lem:coplanar} therefore gives $\sum_{i,j \in \{0,1\}} A_{ij} = 0$ and $\sum_{i,j \in \{0,1\}} E(Y_i, Z_j) \neq 0$.

On the other hand, adding the four edge equations for $(x_0, y_i, z_j)$ over $i,j \in \{0,1\}$ cancels $\omega_0$ (which appears four times) and each $\eta_i$ and $\zeta_j$ (which appears twice), giving
\[
\sum_{i,j \in \{0,1\}} E(Y_i, Z_j) = \operatorname{Tr}\biggl(\Bigl(\sum_{i,j \in \{0,1\}} A_{ij}\Bigr)\,W_0\biggr) = 0,
\]
a contradiction.
