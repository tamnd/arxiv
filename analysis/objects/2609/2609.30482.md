~\cite[I,\S 1,Theorem 1]{KKMSD73} Let $M$ be a $\mathbb{Z}$-lattice of finite rank and let $T=\mathrm{Spec}(\Bbbk[M])$.
  The correspondence $S\to \mathrm{Spec}(\Bbbk[S])$ defines a bijection between the set of finitely generated semigroups $S\subseteq M$ which are saturated in $M$ and which generate $M$ as a group and the set of isomorphism classes of normal affine toric $T$-varieties.

~\cite[I,\S 1,Theorem 1']{KKMSD73}
  Let $T$ be a split $\Bbbk$-torus.
  
  The correspondence $\sigma\to \mathrm{Spec} (\Bbbk[\sigma^{\vee}\cap \widehat{T}])\equiv U_{\sigma}$ defines a bijection between the set of strongly convex rational polyhedral cones $\sigma\subseteq \widehat{T}^0_{R}$ and the set of isomorphism classes of normal affine toric $T$-varieties.

<!-- prop-1: body_md -->
\cite[1.3.12,1.3.20]{CLS11},\cite[I,\S 1,Theorem 4;p.19]{KKMSD73}
  
  For a strongly convex rational polyhedral cone $\sigma\subseteq N_{\mathbb{R}}$,   $U_{\sigma}$ is an orbifold
  if and only if $\sigma$ is simplicial. $U_{\sigma}$ is smooth if and only if $\sigma$ is smooth.

<!-- prop-2: body_md -->
~\cite[I,\S 1, Theorem 3]{KKMSD73},\cite[p.106-7]{CLS11}
  Let $\sigma$ be a strongly convex rational polyhedral cone and $\tau=\sigma\cap H_{\mathbf{m}}$ a face corresponding to $\mathbf{m}\in \sigma^{\vee}\cap M$, then $$U_{\tau}=\mathrm{Spec}(\Bbbk[\sigma^{\vee}\cap M]_{\chi^{\mathbf{m}}})=(U_{\sigma})_{\chi^{\mathbf{m}}}$$
  is a basic open subset of $U_{\sigma}$ determined by the character $\chi^{\mathbf{m}}$.
  This determines a unique $T$-equivariant embedding of $U_{\tau}$ into $U_{\sigma}$.

In particular, if $\sigma_1,\sigma_2$ are two strongly convex rational polyhedral cones in $N_{\mathbb{R}}$, then for $\tau=\sigma_1\cap \sigma_2$, there exists a common supporting hyperplane, that is, there exists $\mathbf{m}\in (\sigma_1^{\vee}\cap (-\sigma_2)^{\vee})\cap M$ such that
$\sigma_1\cap H_{\mathbf{m}}=\tau=\sigma_2\cap H_{\mathbf{m}}$.  This produces a gluing isomorphism
$g_{\sigma_2,\sigma_1}:(U_{\sigma_1})_{\chi^{\mathbf{m}}}\cong (U_{\sigma_2})_{\chi^{-\mathbf{m}}}$ which is the identity on $U_{\tau}$.
<!-- end prop-2 -->
<!-- defn-1: body_md -->
~\cite[3.1.2]{CLS11}
  
  A fan $\Sigma$ in $N_{\mathbb{R}}$ is a finite collection of cones $\sigma\subseteq N_{\mathbb{R}}$ such that:
  \begin{itemize}
  \item Every $\sigma\in \Sigma$ is a strongly convex rational polyhedral cone.
  \item For all $\sigma\in \Sigma$, each face of $\sigma$ is in $\Sigma$.
  \item For all $\sigma_1,\sigma_2\in \Sigma$, the intersection $\sigma_1\cap \sigma_2$ is a face of each and so is in $\Sigma$.
\end{itemize}

We first observe that
$$V^i_r\equiv \mathrm{Span}_{\mathbb{Z}}\{e_a-e_b:a\in [a_r,i],b\in [i+1,b_r]\}$$
is the $\mathbb{Z}$-span of the positive roots corresponding to the rectangular array $[a_r,i]\times [i+1,b_r]$.   In fact, $\{\alpha_t: t\in [a_r,b_r]\}$ is a $\mathbb{Z}$-basis for $V^i_r$ since $\mathbf{e}_a-\mathbf{e}_b=\sum_{t=a}^b\alpha_t$ if $a\in [a_r,i],b\in [i+1,b_r]$.  
In particular, $V^i_n=\mathbb{Z} A_n$.  We will set $V^i_0=\{\0\}$.

  We first claim that if $C_t=\{(a_r,b_r):i=1,\dots,t\}$ is the partial staircase path from  $(a_1,b_1)=(i,i+1)$ to $(a_t,b_t)$, then $\beta_{C_t}$ is a $\mathbb{Z}$-basis for $V^i_t$.
In particular, this observation reproves the fact (from the unimodular triangulation) that $\beta_C$ is a $\mathbb{Z}$-basis of $\mathbb{Z} A_n$.


We prove this claim by induction on $r$.
$\beta_{C_1}=\{\alpha_i\}$ and so is a basis for $V^i_1$.  Assume $\beta_{C_r}$ is a basis for $V^i_{r}$.

It is clear by construction that $\beta_{C_{r+1}}\subseteq \{\mathbf{e}_a-\mathbf{e}_b: a\in [a_{r+1},i],b\in [i+1,b_{r+1}]\}$ so that $\mathrm{Span}_{\mathbb{Z}}(\beta_{C_{r+1}})\subseteq V^i_{r+1}$.

To show the reverse inclusion, we need to show that $\alpha_t\in \mathrm{Span}_{\mathbb{Z}}(\beta_{C_{r+1}})$ for $t\in [a_{r+1},b_{r+1}]$ since $\{\alpha_t:t\in [a_{r+1},b_{r+1}]\}$ is a $\mathbb{Z}$-basis of $V^i_{r+1}$.
By the staircase condition, 
$(a_{r+1},b_{r+1})=(a_r-1,b_r)$ or $(a_{r+1},b_{r+1})=(a_r,b_r+1)$.
So for $t\in [a_r,b_r]$, $\alpha_t\in V^i_r=\mathrm{Span}_{\mathbb{Z}}(\beta_{C_r})\subseteq \mathrm{Span}_{\mathbb{Z}}(\beta_{C_{r+1}})$.

If $(a_{r+1},b_{r+1})=(a_r-1,b_r)$, then $\alpha_{a_{r+1}}=(\mathbf{e}_{a_{r+1}}-\mathbf{e}_{b_r})-(\mathbf{e}_{a_r}-\mathbf{e}_{b_r})\in \mathrm{Span}_{\mathbb{Z}}(\beta_{C_{r+1}})$.

If $(a_{r+1},b_{r+1})=(a_r,b_r+1)$, then $\alpha_{b_{r+1}}=(\mathbf{e}_{a_{r}}-\mathbf{e}_{b_{r+1}})-(\mathbf{e}_{a_r}-\mathbf{e}_{b_r})\in \mathrm{Span}_{\mathbb{Z}}(\beta_{C_{r+1}})$.

(Either way, the additional simple root is the difference of the last two vectors in $\beta_{C_{r+1}}$.)

So $\beta_{C_t}$ is a $\mathbb{Z}$-basis for $V^i_{t}$ for all $t=1,\dots,n$ and, in particular, $\beta_C$ is a basis for $V^i_{n}=\mathbb{Z} A_n$.
Note that for $s<t$, $\beta_{C_s}\subset \beta_{C_t}$ and $\gamma_{C_s}\subset \gamma_{C_t}$. We set $\beta_{C_0}=\emptyset$.
We will prove by induction on $n$ that for each $t=1,\dots,n$, $\gamma_{C_t}\subseteq V^i_{t}\setminus V^i_{t-1}$.

Observe that $\gcd(|I|,|J|)s_{I,J}=\sum_{a\in I,b\in J}\mathbf{e}_a-\mathbf{e}_b$.


Since $\gamma_{C_1}=\beta_{C_1}=\{\mathbf{e}_i-\mathbf{e}_{i+1}\}$, and $V^i_0=\{\0\}$,  the result is trivial for $t=1$.

Assume $t>1$ and that the result holds for $\gamma_{C_{t-1}}$.  So $\gamma_{C_{t-1}}\subseteq V^i_{t-1}\subset V^i_{t}$.
Now $\gamma_{C_t}=\gamma_{C_{t-1}}\cup \{s_{[a_t,i],[i+1,b_t]}\}$.
By the observation above,  a positive integer multiple of
$s_{[a_t,i],[i+1,b_t]}\in V^i_t$, but $s_{[a_t,i],[i+1,b_t]}$ is not in  $V^i_{t-1}$.  So $s_{[a_t,i],[i+1,b_t]}\in (\mathbb{Z} A_n\cap \mathbb{Q} V^i_t)\setminus V^i_{t-1}$. 
Since a $\mathbb{Z}$-basis of $V^i_t$ is $\{\alpha_j: j\in [a_t,b_t]\}$ and this $\mathbb{Z}$-basis can be extended to a $\mathbb{Z}$-basis of $\mathbb{Z} A_n$, then $\mathbb{Z} A_n\cap \mathbb{Q} V^i_t=V^i_t$.

So, by induction, for each $t=1,\dots,n$, $\mathrm{Span}_{\mathbb{Z}}(\gamma_{C_t})$ is a finite index sublattice of $V^i_t=\mathrm{Span}_{\mathbb{Z}}(\beta_{C_t})$ and $\mathrm{mult}(\mathrm{Cone}(\gamma_{C_t})=[\mathrm{Span}_{\mathbb{Z}}(\beta_{C_t}):\mathrm{Span}_{\mathbb{Z}}(\gamma_{C_t})]$.
In particular, $\mathrm{Span}_{\mathbb{Q}}(\gamma_{C_t})=\mathrm{Span}_{\mathbb{Q}}(\beta_{C_t})$ so that $\mathrm{Span}_{\mathbb{R}}(\gamma_{C_t})\cap \mathrm{Span}_{\mathbb{Z}}(\beta_{C_t})=\mathrm{Span}_{\mathbb{Z}}(\beta_{C_t})$.  So $\mathrm{mult}(\mathrm{Cone}(\gamma_{C_t}))=[\mathbb{Z}\beta_{C_t}:\mathbb{Z}\gamma_{C_t}]$ as required.

There is another relatively natural way to determine the simplicial $\mathrm{Aut}(A_n)$-invariant fan from the unimodular triangulation of $P(A_n)$.
  As already observed, the unimodular triangulation of $P(A_n)$ is determined by the natural isomorphism of each coordinate facet $F_i$ with a product of simplices, and then the staircase triangulation of the product of simplices.
Although the staircase triangulation of
$\Delta_{i-1}\times \Delta_{n-i}$ is not $S_{i}\times S_{n+1-i}$-invariant, it is possible to first decompose the product of simplices into a union of product of simplices indexed by the elements of $S_{i}\times S_{n+1-i}$.


Let $I=\{i_1,\dots,i_r\}$ be an ordered subset of $[1,n+1]$ and $I_s=\{i_1,\dots,i_s\}$ for all $1\le s\le r=|I|$.
Let $\Delta_I=\mathrm{Conv}(\mathbf{e}_i:i\in I)$ be a standard simplex.  Let $\mathbf{v}_J=\frac{1}{|J|}\sum_{j\in J}\mathbf{e}_j$ for each subset $J$ of $[1,n+1]$.
The barycentric subdivision of $\Delta_I$ can be viewed as a decomposition into $|I|!$-simplices in $\oplus_{i\in I}\mathbb{Q}\mathbf{e}_i$, one for each element of $S_{I}$:
$$\Delta_I=\cup_{\sigma\in S_I}\Delta_I(\sigma)=\cup_{\sigma\in S_I}\sigma(\Delta_I(\mathrm{id}))$$
where here $$\Delta_I(\sigma)=\mathrm{Conv}(\mathbf{v}_{\sigma(I_j)}:j=1,\dots,|I|)$$ 

In fact, as is well known, and can be easily checked:
$$\Delta_I(\sigma)=\left\{\sum_{j=1}^ra_j\mathbf{e}_{i_j}: a_{\sigma(1)}\ge a_{\sigma(2)}\ge \cdots\ge a_{\sigma(r)},0\le \sum_{j=1}^ra_j\le 1\right\}$$
Note that this description shows that the subgroup of $S_{I}$ which stabilizes $\Delta_I(\sigma)$ coincides with the subgroup of $S_{I}$ which stabilizes it pointwise.



One can then decompose $\Delta_I\times \Delta_J$ for disjoint subsets $I,J\subseteq [1,n+1]$ as
$$\Delta_I\times \Delta_J=\cup_{(\sigma,\tau)\in S_I\times S_J}(\sigma,\tau)(\Delta_I(\mathrm{id})\times \Delta(\mathrm{id}))$$

For disjoint subsets $I,J\subseteq [1,n+1]$, let
$$\delta_{I,J}:\oplus_{i\in I}\mathbb{R}\mathbf{e}_i\times \oplus_{j\in J}\mathbb{R}\mathbf{e}_j\to\oplus_{i\in I,j\in J}\mathbb{R}(\mathbf{e}_i-\mathbf{e}_j), (\mathbf{v},\mathbf{w})\to \mathbf{v}-\mathbf{w}$$
be the natural difference map.
Note that $\mathbf{v}_I-\mathbf{v}_J=\frac{1}{\mathrm{lcm}(|I|,|J|)}s_{I,J}$ if $I,J$ are disjoint sets and so $s_{I,J}$ is the primitive generator of $\mathrm{Cone}(\mathbf{v}_I-\mathbf{v}_J)$.

Note that $\delta_{[1,i],[i+1,n+1]}$ maps $\Delta_{[1,i]}\times \Delta_{[i+1,n+1]}$ isomorphically onto the $i$th coordinate facet.

One can then apply the map $\delta_{[1,i],[i+1,n+1]}$ to the decomposition of $\Delta_{[1,i]}\times \Delta_{[i+1,n+1]}$ to equivariantly subdivide $F_i$ with respect to the $S_{[1,i]}\times S_{[i+1,n+1]}$ action:

$$F_i=\cup_{\sigma\in S_{[1,i]},\tau\in S_{[i+1,n+1]}}F_i(\sigma,\tau)=
  \cup_{\sigma\in S_{[1,i]},\tau\in S_{[i+1,n+1]}}(\sigma,\tau)(F_i(\mathrm{id},\mathrm{id}))$$

    Ordering $[1,i]$ in decreasing order and $[i+1,n+1]$ in increasing order, we can apply the staircase  triangulation to $\Delta_{[1,i]}(\mathrm{id})\times \Delta{[i+1,n+1]}(\mathrm{id})$ and hence to its image $F_i(\mathrm{id},\mathrm{id})$ under the difference map.
    For each minimal staircase path $C=\{(r_i,s_i):i=1,\dots,n\}$ in $\mathrm{MP}(i)$,
    $$F_i(\mathrm{id},\mathrm{id})=\cup_{C\in \mathrm{MP}(i)}\mathrm{Conv}(\widehat{\beta}_C)$$
    where $\widehat{\beta}_C=\{\mathbf{v}_{[a_r,i]}-\mathbf{v}_{[i+1,b_r]}:r=1,\dots,n\}$.

   $\mathrm{Cone}(\widehat{\beta_C})=\mathrm{Cone}(\gamma_C)$
   since $\mathrm{Cone}(\mathbf{v}_I-\mathbf{v}_J)=\mathrm{Cone}(s_{I,J})$ for $I,J$ disjoint subsets of $[1,n+1]$.

This then recovers our simplicial $\mathrm{Aut}(A_n)$-invariant fan.

$Q_{mn}$ is a reflexive polytope for all $m,n\in \mathbb{N}$.

<!-- proof-4: body_md -->
The following argument uses ideas from the proof of Proposition 5 in ~\cite{KV84}.

Using the notation above, 
to show that $Q_{mn}$ is reflexive, we need to show that $Q_{mn}^0$ is a lattice polytope.  
The set of vertices of $Q_{mn}^0$  is precisely the set $\{\mathbf{u}_F:F \mbox{ facet of } Q_{mn}\}$ where $u_F=\sum_{i=1}^m\sum_{j=1}^na_{ij}\mathbf{e}_{ij}\in M_{\mathbb{R}}$ is the facet normal of the facet $F$.  Let $\mathbf{u}_F$, represented  by a $m\times n$ matrix $(a_{ij})$ with 0 row and column sums,  determine a supporting hyperplane for a facet $F$.
Then the set of vertices of $F$: $V_F=\{\pm \mathbf{e}_{ij}:a_{ij}=\mp 1\}$ must span $N_{\mathbb{R}}=(\Lambda(A_m)\otimes \Lambda(A_n))_{\mathbb{R}}$ which has dimension $(m-1)(n-1)$.  To show that $Q_{mn}$ is reflexive, we need to show that each such $\mathbf{u}_F$ has integral coefficients or equivalently that if $\mathbf{u}_F$ is represented by $(a_{ij})$ then $a_{ij}\in \mathbb{Z}$ for all $i,j$.

Suppose not.  Let $K_{mn}$ be a complete bipartite graph with disjoint vertex sets
$\{\overline{\mathbf{e}_i}:i=1,\dots,m\}$ and $\{\overline{f_j}:j=1,\dots,n\}$.  Recall that a subgraph $H$ of a graph $G$ has the same vertex set as $G$ but a subset of the edges, and the complement $\overline{H}$ of a subgraph $H$ of a graph $G$ has the same vertex set as $G$ but has edge set $E(\overline{H})=E(G)-E(H)$.

Note that any subgraph $G$ of $K_{mn}$ with edge set $E(G)$  defines a subset 
$$V[G]=\{\mathbf{e}_{ij}: (\overline{\mathbf{e}_i},\overline{\mathbf{f}_j})\in E(G)\}$$ of the generating set $\{\mathbf{e}_{ij}:1\le i\le m, 1\le j\le n\}$ of $N=\Lambda(A_{m-1})\otimes \Lambda(A_{n-1})$.
We define a subgraph $\Gamma$ of $K_{mn}$: $(\overline{\mathbf{e}_i},\overline{\mathbf{f}_j})$ is an edge of $\Gamma$ if and only if $a_{ij}\not\in \mathbb{Z}$.

Since each row and column of $(a_{ij})$ sums to 0, then any row or column with a non-integer entry must have at least 2 non-integer entries.  This shows that all vertices of $\Gamma$ have degree at least 2.  Then $\Gamma$ must contain a $2r$-cycle
$C=(\overline{\mathbf{e}_{a_1}},\overline{\mathbf{f}_{b_1}},\dots,\overline{\mathbf{e}_{a_r}},\overline{\mathbf{f}_{b_r}},\overline{\mathbf{e}_{a_1}})$ for some $r\ge 1$.
Let $\{a_1,\dots,a_m\}=\{1,\dots,m\}$ and $\{b_1,\dots,b_n\}=\{1,\dots,n\}$. 
Let $C'$ be the subgraph of $K_{mn}$ which contains all vertices of $K_{mn}$ and edge set that of $C$ plus additional edges $(\overline{\mathbf{e}_{a_1}},\overline{\mathbf{f}_{b_j}}):r+1\le j\le n$ and   $(\overline{\mathbf{e}_{a_i}},\overline{\mathbf{f}_{b_1}}):k+1\le i\le m$.  That is, the $\overline{\mathbf{e}_i}$ not in the cycle are connected to $\overline{\mathbf{f}_{b_1}}$ in the cycle and the $\overline{\mathbf{f}_j}$ not in the cycle are connected to $\overline{\mathbf{e}_{a_1}}$ in the cycle.
$C'$ has $2r+(m-r)+(n-r)=m+n$ edges.

Now let $F$ be a facet of $Q_{mn}$ with facet normal $\mathbf{u}_F$ represented by the $m\times n$ matrix $(a_{ij})$.
Note that $\pm \mathbf{e}_{ij}\in V_F$ if and only if $a_{ij}\in \{\pm 1\}$ and
so $\mathbf{e}_{ij}\in V_F$ implies that $a_{ij}\in \mathbb{Z}$.
Then $V_F\subseteq V[K_{mn}-\Gamma]\subseteq V[K_{mn}-C]$.
Since $C$ is a subgraph of $C'$, we also have $V[K_{mn}-C']\subseteq V[K_{mn}-C]$.
We want to show that $\mathrm{Span}_{\mathbb{Z}}(V[K_{mn}-C'])=\mathrm{Span}_{\mathbb{Z}}(V[K_{mn}-C])$.


Since $E(K_{mn})-E(C)=(E(K_{mn})-E(C'))\cup (E(C')-E(C))$, we only need to show that $\mathbf{e}_{ij}\in \mathrm{Span}_{\mathbb{Z}}(V[K_{mn}-C'])$ if $(\overline{\mathbf{e}_i},\overline{\mathbf{f}_j})$ is an edge of $C'$ which isn't an edge of $C$.

The new edges of $C'$ which aren't edges of $C$ take the form $(\overline{\mathbf{e}_{a_1}},\overline{\mathbf{f}_{b_j}})$ where $r+1\le j\le n$ or $(\overline{\mathbf{e}_{a_i}},\overline{\mathbf{f}_{b_1}})$ where $r+1\le i\le m$.

In the first case, $\mathbf{e}_{a_1,b_j}=-\sum_{a\ne a_1}\mathbf{e}_{a,b_j},j=r+1,\dots,n$
and in the second case, $\mathbf{e}_{a_i,b_1}=-\sum_{b\ne b_1}\mathbf{e}_{a_i,b},i=r+1,\dots,n$.
In either case, the result is contained in $\mathrm{Span}_{\mathbb{Z}}(V[K_{mn}-C'])$.
But note that the set $V[K_{mn}-C']$ has size $|E(K_{mn})-E(C')|=mn-m-n$
and so cannot span $N=\Lambda(A_m)\otimes \Lambda(A_n)$ of rank $(m-1)(n-1)$.
So $V_F$ also cannot span $N_{\mathbb{R}}$, and so $F$ cannot be a facet of $Q_{mn}$.

By contradiction, we must have $a_{ij}\in \mathbb{Z}$ for all $1\le i\le m,1\le j\le n$.

 (a)  We start with the facets of $Q_{33}$ to determine $G$-orbits of maximal cones of $\Sigma_{33}$.
  
Let $F$ be a facet and $\mathbf{u}_F=(a_{ij})$ its facet normal.
