A probability measure $ \mathbb{P} \in \mathcal{P}( \mathbb{X} ) $ is causal if $\mathbb{F}^{X} := \sigma( X ) $ is compatible with $\mathbb{F}^{X'} := \sigma( X' ) $, in the sense that for all bounded Borel-measurable $ f : S \times S \rightarrow \mathbb{R} $ and $ g : S \rightarrow \mathbb{R} $,
$$
\mathbb{E}^{\mathbb{P}} \big[ 
f ( X_1, X_2 ) g ( X'_1 ) \vert X_1 \big] 
=
\mathbb{E}^{\mathbb{P}} \big[ 
f ( X_1, X_2 ) \vert X_1 \big] 
\,
\mathbb{E}^{\mathbb{P}} \big[ 
g ( X'_1 ) \vert X_1 \big] 
.
$$

\int_S \delta_mg(\mu,x)(\mu'-\mu)(\mathrm{d}x),

<!-- proposition-1: body_md -->
\label{prop:Taylor expansion measure order n}
Let $ g : {\cal P}_p ( S ) \rightarrow \mathbb{R} $ be an $n-$times linearly differentiable map, such that $\delta_m^j g (\mu, \cdot) \in {\rm Pol}_p $, locally uniformly in $\mu$, and is measurable. Then, the following identity holds
\begin{equation*}
\begin{split}
 g(\mu')
=
 g(\mu)
&+
\sum_{k = 1}^{n-1} 
\frac{1}{k!}
\int_{ S^k} 
\delta^{k}_m g(\mu, x )(\mu'-\mu)^{\otimes k} (dx)
\\
&+
\int_0^1 \frac{ ( 1 - \lambda )^{n-1 }}{(n-2)!} 
\int_{S^{n}}
\delta^{n}_m g( \bar{\mu}_\lambda , x )(\mu'-\mu)^{ \otimes n} (dx)
\mathrm{d}\lambda
\end{split}
\end{equation*}
for all $
\mu,\mu'\in{\cal P}_p ( S )$, where $ \bar{\mu}_\lambda = ( 1 - \lambda ) \mu + \lambda \mu '$.

<!-- proposition-2: body_md -->
\label{prop:symm k-th lin deriv}

\end{equation*}

The proof follows the same structure. The only difference is that we need to be careful with bi-causal couplings and causal couplings.
