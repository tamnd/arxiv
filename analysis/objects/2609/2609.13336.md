<!-- theorem-1: body_md -->
\label{thm:char-normal-vis}
A network is normal if and only if it is shortcut-free and all its vertices are visible.
<!-- end theorem-1 -->
<!-- definition-1: body_md -->
\label{def:inclusion-visible}
	Let $\ensuremath{\mathfrak{C}_{}}$ be a set system and $C\in\ensuremath{\mathfrak{C}_{}}$. Then, $C$ is \emph{inclusion-visible (in
	$\ensuremath{\mathfrak{C}_{}}$)} if there exists some $x\in C$ such that for all $D\in\ensuremath{\mathfrak{C}_{}}$ with $x\in D$, we have
	$D\subseteq C$ or $C\subseteq D$. In this case, $x$ is an \emph{inclusion-visible witness} for $C$.
<!-- end definition-1 -->
<!-- lemma-1: body_md -->
\label{lem:visible-semiregular}
    Let $N$ be a network and let $v\in V(N)$. If $v$ is visible, then
    $\operatorname{\mathtt{C}}_N(v)$ is inclusion-visible in $\ensuremath{\mathfrak{C}_{N}}$. If $N$ is semi-regular, then $v$ is
    visible if and only if $\operatorname{\mathtt{C}}_N(v)$ is inclusion-visible in $\ensuremath{\mathfrak{C}_{N}}$.
<!-- end lemma-1 -->
<!-- proof-1: body_md -->
Let $N$ be a network with root $\rho$, let $v\in V(N)$ and put $C=\operatorname{\mathtt{C}}_N(v)$. First assume that
	$v$ is visible.
	Then, there exists some $x\in C$ such that every $\rho x$-path in $N$ contains $v$. Let
	$D\in\ensuremath{\mathfrak{C}_{N}}$ be any cluster with $x\in D$. Then, $D=\operatorname{\mathtt{C}}_N(w)$ for some $w\in V(N)$.
	Since $x\in D$, there is a
	directed path from $w$ to $x$, and hence a $\rho x$-path $P'$ containing $w$, obtained by
	concatenating any $\rho w$-path with any $wx$-path.
	Since every $\rho x$-path in $N$ contains $v$, it holds that $v$ is a vertex of $P'$, and
	hence, $v\preceq_N w$ or $w\preceq_N v$. In either case, we have that either $C\subseteq D$ or
	$D\subseteq C$. Hence, $C$ is inclusion-visible in $\ensuremath{\mathfrak{C}_{N}}$.
	
	Now, assume that $N$ is semi-regular. By the first part, it remains to prove the
	\emph{if-direction} of the second statement.
 	Hence, suppose that $\operatorname{\mathtt{C}}_N(v)$ is inclusion-visible in $\ensuremath{\mathfrak{C}_{N}}$. Then, there exists some
	inclusion-visible witness $x$ for $C$. Thus,
	for all $D\in\ensuremath{\mathfrak{C}_{N}}$ with $x\in D$, we have $D\subseteq C$ or $C\subseteq D$.
	Let $P=v_0v_1\ldots v_k$ be an arbitrary $\rho x$-path in $N$, where $v_0=\rho$ and $v_k=x$.
	Since $x\preceq_N v_i$, we have  $x\in \operatorname{\mathtt{C}}_N(v_i)$ for all $i\in\{0,\ldots,k\}$. 
	By the choice of $x$, it follows that $\operatorname{\mathtt{C}}_N(v_i)\subseteq \operatorname{\mathtt{C}}_N(v)$ or
	$\operatorname{\mathtt{C}}_N(v)\subseteq \operatorname{\mathtt{C}}_N(v_i)$ for all $i\in\{0,\ldots,k\}$. Since $N$ satisfies 
	(PCC), the vertices $v$ and $v_i$ are therefore $\preceq_N$-comparable for all
	$i\in\{0,\ldots,k\}$. The latter together with the fact that $x=v_k\preceq_N v\preceq_N v_0=\rho$
	implies that there is some $j\in\{0,\ldots,k-1\}$ such that $v_{j+1}\preceq_N v\preceq_N v_j$.
	Since $v_{j+1}$ and $v_j$ are adjacent in $N$ and $N$ has no shortcuts, we conclude that
	$v=v_{j+1}$ or $v=v_j$. In either case, $v$ is a vertex of $P$. Since $P$ was an
	arbitrary $\rho x$-path in $N$, we conclude that $v$ is a visible vertex.
<!-- end proof-1 -->
<!-- definition-2: body_md -->
Let $\ensuremath{\mathfrak{C}_{}}$ be a set system. Then, $C\in\ensuremath{\mathfrak{C}_{}}$  is \emph{not-overlap-covered (NOC)} if
		\[C\not\subseteq\bigcup_{\substack{D\in\ensuremath{\mathfrak{C}_{}}:\, D\between C}} D.\]
	An element $x\in C\setminus\bigcup_{D\in\ensuremath{\mathfrak{C}_{}},D\between C} D$ is a \emph{NOC witness} for $C$. 
	We say that $\ensuremath{\mathfrak{C}_{}}$ has the \emph{NOC property} if every $C\in\ensuremath{\mathfrak{C}_{}}$ is NOC.
<!-- end definition-2 -->
<!-- lemma-2: body_md -->
\label{lem:NOC-size}
	Let $\ensuremath{\mathfrak{C}_{}}$ be a set system on an $n$-element ground set $X$. If $\ensuremath{\mathfrak{C}_{}}$ has the NOC property, then
	\[|\ensuremath{\mathfrak{C}_{}}|\leq \frac{n(n+1)}{2}\] and this bound is sharp.
<!-- end lemma-2 -->
<!-- proof-2: body_md -->
Let $\ensuremath{\mathfrak{C}_{}}$ be a set system on an $n$-element ground set $X$
with the NOC property. For each $k\in\{1,\ldots,n\}$,
define $\ensuremath{\mathfrak{C}_{k}}=\{S\in\ensuremath{\mathfrak{C}_{}}\colon |S|=k\}$. We first show that $ |\ensuremath{\mathfrak{C}_{k}}|\leq n-k+1$. To this end,
suppose that $\ensuremath{\mathfrak{C}_{k}}=\{S_1,\ldots,S_m\}$. Since $\ensuremath{\mathfrak{C}_{}}$ has the NOC property, each $S_i$ has a
NOC witness; choose one and denote it by $x_i$. We claim that $x_i$ is contained in no other member
of $\ensuremath{\mathfrak{C}_{k}}$. Indeed, suppose that $ x_i\in S_j$ for some $j\neq i$. Then $S_i\cap
S_j\neq\emptyset$. Since $S_i$ and $S_j$ are distinct sets of the same cardinality, neither can
contain the other. Hence $S_i\between S_j$; contradicting the fact that $x_i$ is a NOC witness for
$S_i$. Thus, every member $S_i$ of $\ensuremath{\mathfrak{C}_{k}}$ has an element $x_i$ that occurs in no other member of
$\ensuremath{\mathfrak{C}_{k}}$. In particular, the witnesses $x_1,\ldots,x_m$ are pairwise distinct.

Now fix one set, say $S_1$. It consists of its witness $x_1$ together with $k-1$ further elements.
None of these $k-1$ elements can be one of the witnesses $x_2,\ldots,x_m$, since $x_i$ occurs only
in $S_i$ among the members of $\ensuremath{\mathfrak{C}_{k}}$. Consequently, the ground set $X$ contains at least the $m$
distinct witnesses $x_1,\ldots,x_m$ together with the $k-1$ remaining elements of $S_1$. Hence
$n\geq m+k-1$ and therefore $ |\ensuremath{\mathfrak{C}_{k}}|=m\leq n-k+1. $
Summing over all possible cardinalities gives $ |\ensuremath{\mathfrak{C}_{}}| = \sum_{k=1}^n |\ensuremath{\mathfrak{C}_{k}}| \leq
\sum_{k=1}^n(n-k+1) = n+(n-1)+\cdots+1 =\frac{n(n+1)}{2} $. 

To see that the bound is sharp, consider
$\ensuremath{\mathfrak{C}_{}}=\bigl\{\{1,\ldots,k-1\}\cup\{j\}:1\leq k\leq j\leq n\bigr\}$.
For each such set, $j$ is a NOC witness, and
$|\ensuremath{\mathfrak{C}_{}}|=\sum_{k=1}^n(n-k+1)=\frac{n(n+1)}{2}$.
<!-- end proof-2 -->
<!-- lemma-3: body_md -->
\label{lem:clusters-visible-noc}
	Let $\ensuremath{\mathfrak{C}_{}}$ be a set system and let $C\in\ensuremath{\mathfrak{C}_{}}$. Then, $C$ is inclusion-visible if and only if
	$C$ is NOC. In particular, $x$ is an inclusion-visible witness for $C$ if and only if $x$
	is a NOC witness for $C$.
<!-- end lemma-3 -->
<!-- proof-3: body_md -->
Let $\ensuremath{\mathfrak{C}_{}}$ be a set system and $C\in\ensuremath{\mathfrak{C}_{}}$. First assume that $C$ is inclusion-visible. Let
	$x\in C$ be such that for all $D\in\ensuremath{\mathfrak{C}_{}}$ with $x\in D$, we have $D\subseteq C$ or $C\subseteq D$.
	By contraposition, if $D\in\ensuremath{\mathfrak{C}_{}}$ satisfies $D\between C$, then $x\notin D$. Consequently, $C$ is NOC.

	Conversely, assume $C$ is NOC. Then, there exists some element 
	$x\in C\setminus (\cup_{D\between C} D)$. Thus, $x\notin D$ for all
	$D\in\ensuremath{\mathfrak{C}_{}}$ with $D\between C$. Consequently, every $D\in\ensuremath{\mathfrak{C}_{}}$ containing $x$ is comparable with
	$C$ under inclusion, that is, $D\subseteq C$ or $C\subseteq D$. Hence, $C$ is inclusion-visible.
	
	The arguments used here, in particular, imply the last statement of the lemma.
<!-- end proof-3 -->
<!-- theorem-2: body_md -->
\label{thm:normal-characterization}
Let $N$ be a network. Then, the following statements are equivalent:
\begin{enumerate}[(1)]
\item $N$ is normal.
\item $N$ is semi-regular and every cluster in $\ensuremath{\mathfrak{C}_{N}}$ is inclusion-visible.
\item $N$ is semi-regular and $\ensuremath{\mathfrak{C}_{N}}$ has the NOC property.
\end{enumerate}
<!-- end theorem-2 -->
<!-- proof-4: body_md -->
Let $N$ be a network. First assume that $N$ is normal. By Corollary~14 of \cite{Hellmuth:2023},
$N$ is semi-regular. Moreover, Theorem~\ref{thm:char-normal-vis} implies that every vertex in
$N$ is visible. Hence, by Lemma~\ref{lem:visible-semiregular}, every
cluster in $\ensuremath{\mathfrak{C}_{N}}$ is inclusion-visible. Thus, (1) implies (2).
Conversely, assume that (2) holds. By Lemma~\ref{lem:visible-semiregular},
every vertex in $N$ is visible. Since $N$ is semi-regular, it is
also shortcut-free. Therefore, Theorem~\ref{thm:char-normal-vis} implies that $N$ is normal.
Hence, (2) implies (1). Finally, Statements (2) and (3) are equivalent by
Lemma~\ref{lem:clusters-visible-noc}.
<!-- end proof-4 -->
<!-- corollary-1: body_md -->
\label{cor:NOC-char}
    Let $\ensuremath{\mathfrak{C}_{}}$ be a clustering system. Then, the following statements are equivalent: 
    \begin{enumerate}[(1)]
        \item Every cluster in $\ensuremath{\mathfrak{C}_{}}$ is inclusion-visible.
        \item $\ensuremath{\mathfrak{C}_{}}$ has the NOC property.
        \item There exists a normal network $N$ such that $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$.
        \item There exists a tree-child network $N$ such that $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$.
    \end{enumerate}
    In particular, if (1) or (2) holds, then 
   $N\coloneqq\ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{}})$ is a normal network with $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$.
<!-- end corollary-1 -->
<!-- proof-5: body_md -->
Let $\ensuremath{\mathfrak{C}_{}}$ be a clustering system. The equivalence of Statements (1) and (2) is given by
  Lemma~\ref{lem:clusters-visible-noc}. Assume that (1) holds. By Proposition~2 in 
  \cite{Hellmuth:2023}, there exists a unique regular network $N$ such that $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$. 
  In particular, as shown in the proof of Proposition~2 in \cite{Hellmuth:2023}, 
  this network is given by the Hasse diagram $N\coloneqq\ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{}})$. 
  Since every cluster in $\ensuremath{\mathfrak{C}_{}}$ is inclusion-visible, Lemma~\ref{lem:visible-semiregular} 
  implies that every vertex in $N$ is visible. Since $N$  is regular, it is in particular 
  semi-regular (cf.\ \cite[Thm.~2]{Hellmuth:2023}). The latter two conditions together with 
  Theorem~\ref{thm:normal-characterization} imply that $N$ is normal. Hence, (1) implies (3).
 
  Since every normal network is tree-child, Statement (3) immediately implies (4).
  Finally, assume that (4) holds, and let $N$ be a tree-child network with $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$. As observed
  in \cite[Lem.~2]{Cardona:2009}, every vertex of a tree-child network is visible.  Hence, by
  Lemma~\ref{lem:visible-semiregular}, every cluster in $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$ is inclusion-visible. Thus, (4)
  implies (1).
<!-- end proof-5 -->
<!-- corollary-2: body_md -->
Let $N$ be a tree-child or normal network on an $n$-element leaf set $X$. 
	Then $|\ensuremath{\mathfrak{C}_{N}}|\leq \frac{n(n+1)}{2}$. 
	If, in addition, $N$ is regular, then $|V(N)|\leq \frac{n(n+1)}{2}$.
	In both cases, the bound is sharp.
<!-- end corollary-2 -->
<!-- proof-6: body_md -->
By Corollary~\ref{cor:NOC-char}, $\ensuremath{\mathfrak{C}_{N}}$ has the NOC property. Hence,
Lemma~\ref{lem:NOC-size} gives
$|\ensuremath{\mathfrak{C}_{N}}|\leq \frac{n(n+1)}2$.
If $N$ is regular, we have $N\simeq \ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{N}})$ and it follows that the 
vertices of $N$ are in bijection with the clusters in $\ensuremath{\mathfrak{C}_{N}}$.
Therefore $|V(N)|=|\ensuremath{\mathfrak{C}_{N}}|$ and the second assertion follows.

In both cases, sharpness follows from Lemma~\ref{lem:NOC-size} together with
Corollary~\ref{cor:NOC-char}, since the extremal set system constructed in the proof of
Lemma~\ref{lem:NOC-size} is a clustering system and is realized by the regular normal network
$\ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{}})$.

<!-- corollary-3: body_md -->
\label{cor:noc-polytime}
Let $\ensuremath{\mathfrak{C}_{}}$ be a clustering system on an $n$-element ground set $X$. Then it can be decided in 
$ O(\min\{|\ensuremath{\mathfrak{C}_{}}|^2n,\; n^5\}) $
time whether $\ensuremath{\mathfrak{C}_{}}$ has the NOC property. Consequently, it can be decided in polynomial time
whether there exists a normal network $N$ such that $\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$. If such a network exists, a normal
network realizing $\ensuremath{\mathfrak{C}_{}}$ can be constructed in polynomial time.
<!-- end corollary-3 -->
<!-- proof-7: body_md -->
Let $m=|\ensuremath{\mathfrak{C}_{}}|$. We assume that the elements of $X$ are ordered and that every set $C\in\ensuremath{\mathfrak{C}_{}}$ is
represented by its characteristic vector in $\{0,1\}^n$. For each $C\in\ensuremath{\mathfrak{C}_{}}$, compute
$U_C=\bigcup_{{D\in\ensuremath{\mathfrak{C}_{}},D\between C}} D$. By definition, $C$ is NOC if and only if $C\setminus
U_C\neq\emptyset$. Thus, $\ensuremath{\mathfrak{C}_{}}$ has the NOC property if and only if this condition holds for every
$C\in\ensuremath{\mathfrak{C}_{}}$. For each ordered pair $(C,D)\in\ensuremath{\mathfrak{C}_{}}\times\ensuremath{\mathfrak{C}_{}}$, whether $C$ and $D$ overlap can be decided
in $O(n)$ time by a single scan through their characteristic vectors. 
At the same time, the sets $D$ overlapping $C$ can be
added to the union $U_C$. Hence, all sets $U_C$ and the corresponding tests $C\setminus
U_C\neq\emptyset$ can be computed in $O(m^2n)$ time. On the other hand, by
Lemma~\ref{lem:NOC-size}, every NOC set system on an $n$-element ground set contains at most $
\frac{n(n+1)}2 $ members. Hence, if $m>\frac{n(n+1)}2$, we may immediately conclude that $\ensuremath{\mathfrak{C}_{}}$ is
not NOC. Otherwise, $m=O(n^2)$, and the above algorithm runs in $O(n^5)$ time. Therefore, the NOC
property can be recognized in $ O(\min\{m^2n,n^5\}) = O(\min\{|\ensuremath{\mathfrak{C}_{}}|^2n,n^5\}) $ time.

By Corollary~\ref{cor:NOC-char}, $\ensuremath{\mathfrak{C}_{}}$ is the clustering system of a normal network
if and only if $\ensuremath{\mathfrak{C}_{}}$ has the NOC property. Moreover, whenever this is the case, the
Hasse diagram $\ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{}})$ is a normal network realizing $\ensuremath{\mathfrak{C}_{}}$. Since $\ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{}})$ is obtained by
testing, for each pair $A,B\in\ensuremath{\mathfrak{C}_{}}$, whether $B\subsetneq A$ and whether there exists some $C\in\ensuremath{\mathfrak{C}_{}}$
with $B\subsetneq C\subsetneq A$, it can be constructed in polynomial time.
<!-- end proof-7 -->
<!-- corollary-4: body_md -->
\label{cor:bijection-normal-noc}
Let $X$ be a finite set, and let
\[
\mathsf{NOC}(X) =
\{\ensuremath{\mathfrak{C}_{}} \mid \ensuremath{\mathfrak{C}_{}} \text{ is a clustering system on } X \text{ satisfying the NOC property}\}.
\]
Then, the map $ N\mapsto \ensuremath{\mathfrak{C}_{N}} $
induces a bijection from each of the following two classes, considered up to isomorphism, onto $\mathsf{NOC}(X)$:
\begin{enumerate}[(1)]
\item Strong-phylogenetic normal networks on $X$.
\item Phylogenetic  and separated normal networks on $X$.
\end{enumerate}
Consequently, there is a canonical bijection between the classes in (1) and (2): a network $N$ in
(1) is mapped to the unique network $N'$ in (2) satisfying $ \ensuremath{\mathfrak{C}_{N'}}=\ensuremath{\mathfrak{C}_{N}}$.
<!-- end corollary-4 -->
<!-- proof-8: body_md -->
By Theorem~\ref{thm:normal-characterization}, the clustering system of every normal network
satisfies the NOC property. Hence, for each of the classes in (1) and (2), the map $ N\mapsto
\ensuremath{\mathfrak{C}_{N}} $ indeed takes values in $\mathsf{NOC}(X)$.

We first consider the class in (1). Let $\ensuremath{\mathfrak{C}_{}}\in\mathsf{NOC}(X)$. By
Corollary~\ref{cor:NOC-char}, there is a normal network realizing $\ensuremath{\mathfrak{C}_{}}$, namely
$N\coloneqq\ensuremath{\mathcal{H}}(\ensuremath{\mathfrak{C}_{}})$. Clearly, $N$ is regular. For normal networks,
regularity is equivalent to being strong-phylogenetic \cite[Thm.~3.14]{HLM:26}, and therefore $N$ is
a strong-phylogenetic normal network. Thus, the map $N\mapsto\ensuremath{\mathfrak{C}_{N}}$ is surjective onto
$\mathsf{NOC}(X)$. Conversely, suppose that $N_1$ and $N_2$ are strong-phylogenetic normal networks
on $X$ with $\ensuremath{\mathfrak{C}_{N_1}}=\ensuremath{\mathfrak{C}_{N_2}}=\ensuremath{\mathfrak{C}_{}}$. Since both $N_1$ and $N_2$ are normal and strong-phylogenetic,
Theorem~3.14 of \cite{HLM:26} implies that both networks are regular.
Proposition~2 of \cite{Hellmuth:2023} states that a clustering system admits, up to isomorphism, a
unique regular realization. Since both $N_1$ and $N_2$ are regular realizations of the same
clustering system $\ensuremath{\mathfrak{C}_{}}$, they are isomorphic. Hence, the map $N\mapsto\ensuremath{\mathfrak{C}_{N}}$ is injective on the
class in (1).

We now consider the class in (2). By Theorem~6 of \cite{Hellmuth:2023}, every clustering system
$\ensuremath{\mathfrak{C}_{}}$ on $X$ is realized by a unique semi-regular, phylogenetic, and separated network. Let
$\ensuremath{\mathfrak{C}_{}}\in\mathsf{NOC}(X)$, and let $N$ denote this unique realization. Since $N$ is semi-regular and
$\ensuremath{\mathfrak{C}_{N}}=\ensuremath{\mathfrak{C}_{}}$ has the NOC property, Theorem~\ref{thm:normal-characterization} implies that $N$ is
normal. Consequently, $N$ is a phylogenetic and separated normal network, that is, a network in the
class in (2). Hence, the map $N\mapsto\ensuremath{\mathfrak{C}_{N}}$ is surjective onto $\mathsf{NOC}(X)$. Conversely,
suppose that $N_1$ and $N_2$ are phylogenetic and separated normal networks on $X$ with $
\ensuremath{\mathfrak{C}_{N_1}}=\ensuremath{\mathfrak{C}_{N_2}}=\ensuremath{\mathfrak{C}_{}}$. Proposition~8 of \cite{Hellmuth:2023} states that if a clustering system
admits a realization by a phylogenetic and separated normal network, then that normal network is
unique up to isomorphism. In other words, $N_1$ and $N_2$ are necessarily isomorphic. Hence, the map
$N\mapsto\ensuremath{\mathfrak{C}_{N}}$ is injective on the class in (2).

Thus, for each of the classes in (1) and (2), the map $N\mapsto\ensuremath{\mathfrak{C}_{N}}$ induces a bijection onto
$\mathsf{NOC}(X)$.

Let $\ensuremath{\mathfrak{C}_{}}$ be a set system on $X$ such that $\cup_{S\in\ensuremath{\mathfrak{C}_{}}}S=X$ and let
	$\ensuremath{\mathfrak{T}}\subseteq\ensuremath{\mathfrak{C}_{}}$. Suppose that $\ensuremath{\mathfrak{T}}$ is an inclusion-minimal set cover of $X$. Let
	$T\in\ensuremath{\mathfrak{T}}$. Since $\ensuremath{\mathfrak{T}}$ is inclusion-minimal as a set cover, the family $\ensuremath{\mathfrak{T}}\setminus \{T\}$
	does not cover $X$. Hence, there exists some element $x_T\in T$ such that $x_T\notin S$ for all
	$S\in\ensuremath{\mathfrak{T}}\setminus\{T\}$. In particular, $ x_T\notin S $ for every $S\in\ensuremath{\mathfrak{T}}$ with $S\between
	T$. Therefore, $ x_T\in T\setminus \bigcup_{S\in\ensuremath{\mathfrak{T}},S\between T}S, $ and hence
	$T$ is NOC. Since $T$ was arbitrary, $\ensuremath{\mathfrak{T}}$ has the NOC property.

    
    Suppose now that $\ensuremath{\mathfrak{C}_{}}$ has the NOC 
    property and that $\ensuremath{\mathfrak{T}}$ comprises the inclusion-maximal elements of $\ensuremath{\mathfrak{C}_{}}$. 
    First observe that $\ensuremath{\mathfrak{T}}$ is a set cover of $X$: every element of every member of
    $\ensuremath{\mathfrak{C}_{}}$ is contained in some inclusion-maximal member of $\ensuremath{\mathfrak{C}_{}}$. 
    Now consider any minimum set cover $\ensuremath{\mathfrak{T}}'\subseteq\ensuremath{\mathfrak{C}_{}}$ of $X$. We show that $|\ensuremath{\mathfrak{T}}|\leq|\ensuremath{\mathfrak{T}}'|$. 
	To that end, note that each $T\in\ensuremath{\mathfrak{T}}$ is NOC, so there exists some
    $x\in T$ such that, for every $S\in\ensuremath{\mathfrak{C}_{}}$ with $S\between T$, we have $x\notin S$. Since
    $\ensuremath{\mathfrak{T}}'$ is a set cover, there is some element of $\ensuremath{\mathfrak{T}}'$ containing $x$; choose one such set
    and denote it by $T_x$. 
    Since $T_x\in\ensuremath{\mathfrak{T}}'\subseteq\ensuremath{\mathfrak{C}_{}}$ and $x\in T_x$, the choice of $x$ implies that $T_x$ cannot overlap $T$.
    This together with
    $x\in T\cap T_x$ and inclusion-maximality of $T$ implies that $T_x\subseteq T$. Moreover, any
    $S\in\ensuremath{\mathfrak{T}}$ with $S\neq T$ either overlaps $T$ or is disjoint from $T$. In
    either case, $x\notin S$. The latter and $x\in T_x$ implies that $T$ is the only element of
    $\ensuremath{\mathfrak{T}}$ that contains $T_x$. Defining $\varphi(T)=T_x$ for each $T\in \ensuremath{\mathfrak{T}}$ therefore yields an
    injective map from $\ensuremath{\mathfrak{T}}$ to $\ensuremath{\mathfrak{T}}'$. Hence, $|\ensuremath{\mathfrak{T}}|\leq|\ensuremath{\mathfrak{T}}'|$. Since $\ensuremath{\mathfrak{T}}$ itself is a set cover, it follows
    that $\ensuremath{\mathfrak{T}}$ is a minimum-cardinality set cover of $X$.
