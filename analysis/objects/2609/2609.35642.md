<!-- remark-2: body_md -->
\label{rmk: pick maxl CM}
    Given two abelian varieties $A/K$ and $A'/K$ which are isogenous over $K$, then there is an equality of the torsion fields $K(A[\ell^\infty]) = K(A'[\ell^\infty])$. This, combined with the fact that two isogenous curves defined over the same field must have identical reduction information, implies that the property of being ``heavenly at $\ell$'' must be an isogeny invariant.

    Additionally, for any abelian variety $A/K$ with complex multiplication by an order in the field $L$ there must exist some $A'/K$ isogenous to $A$ with complex multiplication by the maximal order $\mathcal{O}_L \subset L$ \cite[Lem. 2.4]{Lom-HeavenlyCM}. Hence when deciding whether $A/K$ with complex multiplication is heavenly, we may always choose to work with the representative $A'/K$ instead.

<!-- proof-1: body_md -->
This upper bound was found by a computational search using {\tt SageMath\ } \cite{sagemath} following a strategy described in \cite{quadfields}. The code used is publicly available at \cite{OHara26}.

In order to conduct this search, we first suppose we have a fixed pair of Tate-Oort numbers $(j_1,j_2)$ with $j_1 < j_2$. We then determine a list of primes $\ell$ for which it would be possible to have an elliptic curve, $E/K$ over a cubic field which is heavenly at $\ell$ with Tate-Oort numbers $(j_1,j_2)$. Note that the $e$ is now determined, as $j_1 + j_2 = e$.

Without loss of generality, we may assume $\ell > 11$. Fix some prime $p \neq \ell$, and for each prime of $K$, $\mathfrak{p}$ above $p$, set $f = f_\mathfrak{p}$. Note then that $1 \leq f \leq 3$. We consider a choice of Frobenious element $\theta_\mathfrak{p}$. Let $q = p^f$. For a heavenly elliptic curve at $\ell$, the trace of our representation $\tau_1 = \alpha_1 + \alpha_2$ must have the following restraint from the Weil bound: $\vert \tau_1\vert \leq 2\sqrt{q}$.

Using the value of $\tau_1$, we determine the trace of $m$-th power of the chosen Frobenious element. For an abelian variety $A$, the action of $\theta_\mathfrak{p}^m \curvearrowright V_\ell A$ has characteristic polynomial $P_m(T) \in \mathbb{Z}[T]$. When factoring over $\mathbb{C}$, $P_m(T) = (T-\alpha_1^m)(T-\alpha_2^m)$, where $-\tau_m$ is the coefficient of $T$ in $P_m(T)$. See \cite[\S 4.2]{quadfields} The values of $\alpha_1$ and $\alpha_2$ are determined by the trace of $\tau_1$ above. Hence, the trace of some $\theta_\mathfrak{p}^m$ must be given by $\tau_m = \alpha_1^m + \alpha_2^m$. However, the $e$-th power gives us an extra congruence to consider. As $\tau_1$ must determine $\tau_e$, we still only consider about $4\sqrt{q}$ possible values for $\tau_e$ even as $e$ grows.
By \eqref{eq: ei =j}:
\begin{equation}\label{eq: te - q-q}
    \tau_e - q^{j_1} - q^{j_2} \equiv 0 \ (\mathrm{mod}\ \ell).
\end{equation}
In other words, for each $p$, if $\ell \neq p$, then $\ell\vert \left(\tau_e - p^{f\cdot j_1}-p^{f\cdot j_2}\right)$. There are only finitely many possible values for $\tau_e$ and $f$, and so only finitely many $\ell$ which satisfy \eqref{eq: te - q-q}. First screening against $p = 3$, we obtain a finite list of $\ell$ which can possibly admit a heavenly elliptic curve with Tate-Oort numbers $(j_1,j_2)$. We now repeat this screen for other $p \leq 11$, removing any $\ell$ which fails \eqref{eq: te - q-q} for every choice of $\tau_e$ and $f$.

For the next step of the computation, we consider possible options for the powers of $\chi$ that appear on the diagonal of the representation given in Proposition \ref{prop: heavenly upper triangular}. We now fix a prime $\ell$ from our reduced list of possible primes for our fixed Tate-Oort pair $(j_1, j_2)$. Recall that 
$$ ei_1 \equiv j_1 \ (\mathrm{mod}\ \ell-1)\: \eqref{eq: ei =j} \qquad \text{and} \qquad i_2 +i_1 \equiv 1 \ (\mathrm{mod}\ \ell-1) \: \eqref{eq: sum i-val}.$$

Once we solve for the values of $(i_1,i_2)$, it is possible to compute the trace of our representation $\rho_{E,\ell}$ with respect to a Frobenius element $\theta_\mathfrak{p}$. The pairs $(i_1, i_2)$ are determined only by the representation, so they must provide a valid trace for a Frobenius element at any prime $p$.

We consider each $(i_1, i_2)$ pair that meets these congruences. If $\mathfrak{p}$ is a prime of $K$ of norm $q = p^f$ then each Forbenius element $\theta_\mathfrak{p}$ must have $\chi^{i_1} (\theta_\mathfrak{p})+ \chi^{i_2}(\theta_\mathfrak{p}) \equiv \tau_1 \ (\mathrm{mod}\ \ell)$. In particular, for each pair of values $(i_1,i_2)$, we check if there exists an integer representative of $\pm \left(p^{f\cdot i_1} + p^{f\cdot i_2}\right) \ (\mathrm{mod}\ \ell)$ in the range $ \left[-\lfloor2\sqrt{p^f}\rfloor, \lfloor2\sqrt{p^f}\rfloor\right]$. If this condition fails for even a single $\mathfrak{p}$, then $(i_1,i_2)$ cannot be the powers of $\chi$ in the representation. In some cases, every possible $(i_1,i_2)$ pair can be eliminated, and so a curve heavenly at $\ell$ with Tate-Oort numbers $(j_1,j_2)$ cannot exist.

<!-- proposition-4: body_md -->
\label{prop: balanced at rational}
    Let $E/K$ be an elliptic curve and suppose $K/\mathbb{Q}$ is an extension of odd degree. Suppose $E$ is balanced at the odd rational prime $\ell$. Then $\ell \equiv 3 \ (\mathrm{mod}\ 4)$.
<!-- end proposition-4 -->
<!-- proof-2: body_md -->
If $\ell = 3$, the result immediately follows. So suppose $\ell > 3$ and $[K:\mathbb{Q}] = n$. 
    As $E$ is balanced at $\ell$, $E$ is balanced at all primes $\mathfrak{l}_i\vert\ell$. Suppose $\ell$ splits into $r$ primes. Then  $\sum_{i=1}^{r}f_{\mathfrak{l}_i}e_{\mathfrak{l}_i} = n$.

    It cannot be the case that every $e_{\mathfrak{l}_i}$ is even since $n$ is odd.
    So up to re-ordering, we may assume that $e_{\mathfrak{l}_1}$ is an odd integer.

    As $E$ is balanced at $\mathfrak{l}_1$, $4\vert e_E(\mathfrak{l}_1)$ and $\operatorname{\textnormal{\textsf{ord}}}_2(e_E(\mathfrak{l}_1)) > \operatorname{\textnormal{\textsf{ord}}}_2(\ell-1)$ by \cite[Lem. 4.1]{quadfields}. By Proposition \ref{prop: semistable options}, $e_E(\mathfrak{l}_1) \in \{e_{\mathfrak{l}_1}, 2e_{\mathfrak{l}_1}, 3e_{\mathfrak{l}_1}, 4e_{\mathfrak{l}_1}, 6e_{\mathfrak{l}_1}\}$. 
    Hence $e_E(\mathfrak{l}_1) = 4e_{\mathfrak{l}_1}$ is the only possible solution.
    Thus $\operatorname{\textnormal{\textsf{ord}}}_2(e_E(\mathfrak{l}_1)) = 2 > \operatorname{\textnormal{\textsf{ord}}}_2(\ell-1) = 1$. This is only possible if $\ell \equiv 3 \ (\mathrm{mod}\ 4)$.
<!-- end proof-2 -->

<!-- lemma-2: body_md -->
\label{lem: i1,i2 soln} Let $E/K$ be an elliptic curve heavenly at an odd prime $\ell$ and suppose $K/\mathbb{Q}$ is an extension of odd degree. Further, suppose either that $E$ is balanced at $\ell$, or $K/\mathbb{Q}$ is Galois and $E$ is balanced at some prime $\mathfrak{l}$ above prime $\ell$. The solutions to \eqref{eq: balanced 2ei = e} are:

\begin{enumerate}
    \item[(a)] If $\ell = 3$, then $\{i_1,i_2\} \equiv \{0,1\} \ (\mathrm{mod}\ 2)$.

    \item[(b)] If $\ell > 3$, let $s \in \mathbb{Z}$ such that $2es \equiv 0 \ (\mathrm{mod}\ \ell-1)$. Then $\{i_1,i_2\} \equiv \{\frac{\ell+1}{4} + s, \frac{3\ell-1}{4} - s\} \ (\mathrm{mod}\ \ell -1)$.
\end{enumerate}
<!-- end lemma-2 -->
<!-- proof-3: body_md -->
The solution for $(a)$ is clear, since $4\vert e$ \cite[Lem. 4.1]{quadfields}. In this case \eqref{eq: balanced 2ei = e} reduces to $0i_r \equiv 0 \ (\mathrm{mod}\ \ell-1)$.

    For part $(b)$, it is easy to check that $\{(\ell+1)/4, (3\ell-1)/4\} \ (\mathrm{mod}\ \ell -1)$ gives a valid set of solutions. Here $s$ can be thought of as a shift of this initial solution. Shifting in this way maintains the constraint from \eqref{eq: sum i-val}, which in the elliptic curve case simply says $i_1 + i_2 \equiv 1 \ (\mathrm{mod}\ \ell -1)$.

    Let $s \in \mathbb{Z}$ such that $2es \equiv 0 \ (\mathrm{mod}\ \ell -1)$. We will check that $((\ell+1)/4) +s$ provides a solution to \eqref{eq: balanced 2ei = e}. The case with $((3\ell-1)/4) -s$ works similarly.

    $$2e\left(\frac{\ell+1}{4} +s\right) \equiv 2e\left(\frac{\ell+1}{4}\right) + 2es
        \equiv e + 2es \equiv e \ (\mathrm{mod}\ \ell-1) $$
<!-- end proof-3 -->
<!-- remark-3: body_md -->
Suppose we have $2n$ solutions to \eqref{eq: balanced 2ei = e}, where $n$ is an odd divisor of $[K:\mathbb{Q}]$. This indicates there are $n$ pairs of solutions, one of which must be $((\ell+1)/4, (3\ell-1)/4)$. In which case we have $n-1$ shifted solutions, and hence $(n-1)/2$ unique shift values $s \ (\mathrm{mod}\ \ell -1)$ by the previous proposition.
<!-- end remark-3 -->
<!-- remark-4: body_md -->
For a given balanced curve $E/K$, if $\mathrm{gcd}(2e,\ell-1) = 2$, then $\{(\ell+1)/4, (3\ell -1)/4\}$ is the unique set of solutions $\ (\mathrm{mod}\ \ell -1)$ and $E$ must be totally balanced. First, $\mathrm{gcd}(2e,\ell-1) = 2$ clearly holds if $e_\mathfrak{l} = 1$. Next suppose $p$ is some prime dividing $e_\mathfrak{l}$. Then $p\vert (\ell -1) \iff \ell \equiv 1 \ (\mathrm{mod}\ p)$. So if it is the case that $\ell \not\equiv 1 \ (\mathrm{mod}\ p)$ for all $p\vert [K:\mathbb{Q}]$ then $\mathrm{gcd}(2e,\ell-1) = 2$.

<!-- proposition-5: body_md -->
\label{prop: new trace}
Suppose $K/\mathbb{Q}$ is an odd degree extension, and $E/K$ is heavenly at an odd prime $\ell$. Suppose either that $E$ is balanced at $\ell$, or $K/\mathbb{Q}$ is Galois and $E$ is balanced at some prime $\mathfrak{l}$ above $\ell$. Further suppose $\mathfrak{p}$ is a prime of $K$ above $p \neq \ell$, with residue degree $f \vcentcolon= f_\mathfrak{p}$ and norm $q = \textbf{N}\mathfrak{p}$. Then 

\begin{equation}
    a_\mathfrak{p}(E) \equiv q^{(\ell +1)/4}\left(q^s + q^{-s}\left(\frac{p}{\ell}\right)^f\right) \ (\mathrm{mod}\ \ell).
\end{equation}

In particular when E is totally balanced, we have

\begin{equation}\label{eq: totally balanced}
    a_\mathfrak{p}(E) \equiv q^{(\ell +1)/4}\left(1 +\left(\frac{p}{\ell}\right)^f\right) \ (\mathrm{mod}\ \ell).
\end{equation}
<!-- end proposition-5 -->
<!-- proof-4: body_md -->
Let $\theta_\mathfrak{p} \in G_K$ be a Frobenius element for $\mathfrak{p}$. Since $\chi(\theta_\mathfrak{p}) = q$, 

\begin{align*}
    a_\mathfrak{p}(E) \equiv \operatorname{\textnormal{\textsf{tr}}}(\rho_{E,\ell}(\theta_\mathfrak{p})) & \equiv q^{i_1} + q^{i_2}\\
    & \equiv q^{((\ell +1)/4) +s} + q^{((3\ell-1)/4) - s}\\
    & \equiv q^{(\ell + 1)/4}\left(q^s + q^{((\ell-1)/2) -s} \right)\\
    & \equiv q^{(\ell+1)/4}\left(q^s + q^{-s}\left(\frac{p}{\ell}\right)^f\right) \ (\mathrm{mod}\ \ell).
\end{align*}

We deduce the equation for totally balanced curves by simply setting $s = 0$.
<!-- end proof-4 -->
<!-- proposition-6: body_md -->
\label{Prop: balanced trace KL}
    Let $K/\mathbb{Q}$ be a Galois extension of odd degree and $E/K$ be an elliptic curve totally balanced at $\mathfrak{l}$, a prime of $K$ above an odd prime $\ell$. Let $\mathfrak{p}$ be a prime of $K$ above $p$, a prime distinct from $\ell$. Let $f: = f_{\mathfrak{p}}$, and $L = \mathbb{Q}(\sqrt{-\ell})$.
    \begin{enumerate}
        \item[(a)] If $\mathfrak{p}$ is inert in $KL$, $a_\mathfrak{p}(E) \equiv 0 \ (\mathrm{mod}\ \ell)$.

        \item[(b)] If $\mathfrak{p}$ splits in $KL$, $a_\mathfrak{p}(E)^2 \equiv 4p^f \ (\mathrm{mod}\ \ell)$.

    \end{enumerate}
<!-- end proposition-6 -->
<!-- proof-5: body_md -->
Let $\mathfrak{P}$ be a prime of $KL$ above $\mathfrak{p}$, and $\mathfrak{q} = \mathfrak{P}\cap \mathcal{O}_L$.
    By Corollary \ref{cor: balanced Galois} $\ell \equiv 3 \ (\mathrm{mod}\ 4)$, so we have $\left(\frac{-\ell}{p}\right) = \left(\frac{p}{\ell}\right)$. Thus $p$ splits in $L$, meaning $f_\mathfrak{q} = 1$, if and only if $\left(\frac{p}{\ell}\right) = 1$.

    As both $K$ and $L$ are Galois over $\mathbb{Q}$, the extensions $KL/\mathbb{Q}$, $KL/L$, and $KL/K$ are all be Galois as well \cite[\S 14.4 Prop. 21]{dummit2003abstract}.

    For $(a)$, suppose $\mathfrak{p}$ is inert in $KL$. Then $f_{\mathfrak{P}|\mathfrak{p}}$ = 2. Since $K/\mathbb{Q}$ is a Galois extension of odd degree, it must be that $f$ is some odd divisor of the degree of the extension. We can now compare inertial degrees using our two distinct multiplicative towers of fields.

    \[f_\mathfrak{P} = f_{\mathfrak{P}|\mathfrak{p}}\cdot f = 2f = f_{\mathfrak{P}|\mathfrak{q}}\cdot f_\mathfrak{q}.\]

    As $KL/L$ is Galois of odd degree, $f_{\mathfrak{P}|\mathfrak{q}}$ is odd. Hence $f_\mathfrak{q} = 2$ and $p$ is inert in $L$, so $\left(\frac{p}{\ell}\right) = (\frac{p}{\ell})^f = -1$.

    By Proposition \ref{prop: new trace}, $a_\mathfrak{p}(E) \equiv 0  \ (\mathrm{mod}\ \ell).$

    For $(b)$, suppose $\mathfrak{p}$ splits in $KL$. Then $f_{\mathfrak{P}|\mathfrak{p}} = 1$, $f_{\mathfrak{P}}$ is odd, and $f_\mathfrak{q} = 1$. Since $\ell \equiv 3 \ (\mathrm{mod}\ 4)$, $\ell$ is the only prime that ramifies in $L$. Thus $p$ splits in $L$, i.e. ,$(\frac{p}{\ell}) = 1$. Proposition \ref{prop: new trace} now implies 
    \[a_\mathfrak{p}(E)^2 \equiv 4\left(p^f\right)^{(\ell + 1)/2} \equiv 4\left(p^{(\ell + 1)/2}\right)^f \equiv 4\left(p\left(\frac{p}{\ell}\right)\right)^f \equiv 4p^f \left(\frac{p}{\ell}\right)^f \equiv 4p^f \ (\mathrm{mod}\ \ell).\qedhere \]
<!-- end proof-5 -->
<!-- proposition-7: body_md -->
\label{prop: heavenly not surj}
Let $K/\mathbb{Q}$ be a Galois extension of odd degree and suppose $E/K$ is an elliptic curve totally balanced at a prime $\mathfrak{l}$ above an odd prime $\ell$. Then 
\[\tr\left(\rho_{E,\ell}(G_K)\right) \subseteq \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}.\]
<!-- end proposition-7 -->
<!-- proof-6: body_md -->
In order to show the image of the trace is non-surjective, we first recall that $\ell \equiv 3\: (\text{mod } 4)$, and so $-1$ is not a square $(\text{mod } \ell)$. 
    Hence $\left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}$ contains exactly the square classes or non-square classes depending on the sign of $\left(\frac{2}{\ell}\right)$. By the Chebotarev Density Theorem and the finiteness of $\rho_{E,\ell}$ in every coset of $\ker(\rho_{E,\ell})$ is represented by a Frobenius element $\theta_\mathfrak{p}$ for some $\mathfrak{p}\nmid \ell$.
    So we must show that for all $a_\mathfrak{p} \in \tr\left(\rho_{E,\ell}(G_K)\right)$ it is the case that either $a_\mathfrak{p} \equiv 0 \ (\mathrm{mod}\ \ell)$ or $\left(\frac{a_\mathfrak{p}}{\ell}\right) = \left(\frac{2}{\ell}\right).$

    First set $f\vcentcolon= f_\mathfrak{p}$. Suppose that $\left(\frac{p}{\ell}\right) = 1$. Then \eqref{eq: totally balanced} implies $a_\mathfrak{p} \equiv 2\left(p^f\right)^{\frac{f(\ell + 1)}{4}}\: (\text{mod } \ell)$. 
    Now $\left(\frac{a_\mathfrak{p}}{\ell}\right) = \left(\frac{2p^{\frac{f(\ell+1)}{4}}}{\ell} \right) = \left(\frac{2}{\ell}\right) \left(\frac{p}{\ell}\right)^\frac{f(\ell+1)}{4} = \left(\frac{2}{\ell}\right)$ as desired.

    Now suppose $\left(\frac{p}{\ell}\right) = -1$. Then $a_\mathfrak{p} \equiv \left(p^f\right)^{\frac{\ell+1}{4}}(1 + (-1)^f)\: (\text{mod } \ell)$. 
    As $K/\mathbb{Q}$ is a Galois extension of odd degree, $f$ must be odd. 
    Thus $a_\mathfrak{p} \equiv 0\: (\text{mod } \ell)$.
<!-- end proof-6 -->
<!-- remark-5: body_md -->
In the quadratic case, \cite{quadfields}, the authors were able to show that $\tr\left(\rho_{E,\ell}(G_K)\right) = \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}$. It is a surprising result that the reverse containment was not immediate over cubic fields. We will attempt to classify a partial result where we can show the trace of $\rho_{E,\ell}$ is \textit{precisely} the squares or non-squares inside $\mathbb{F}_\ell^\times$.
<!-- end remark-5 -->
<!-- lemma-3: body_md -->
\label{lem: when KL cap Q = L}
    Let $K/\mathbb{Q}$ be Galois of odd degree, $\ell$ an odd prime, and $L = \mathbb{Q}(\sqrt{-\ell})$, $KL \cap \mathbb{Q}(\mathbf{\upmu}_\ell) = L$ if either of the following hold:
    \begin{enumerate}
        \item[(a)] $K$ is a real number field.
        \item[(b)] For $\mathfrak{l}$ a prime of $K$ above $\ell$ $\left(e_\mathfrak{l},(\ell-1)/2\right) = 1$.
    \end{enumerate}
<!-- end lemma-3 -->
<!-- proof-7: body_md -->
The proof for $(a)$ is immediate. We classify this result as if $E$ has complex multiplication then $K = \mathbb{Q}(j(E))$ is a real number field.

    For $(b)$ as $K/\mathbb{Q}$ is Galois of odd degree $e_\mathfrak{l}$ is odd. As $\ell$ must ramify in $L$, we know the ramification index of $\ell$ in $KL$ is $2\cdot e_\mathfrak{l}$. Let $L' := KL\cap\mathbb{Q}(\mathbf{\upmu}_\ell)$, we will calculate the degree of $[L':L]$.

    As $L'$ is a subfield of $KL$, we know the ramification index of a prime above $\ell$ in $L'/L$ must a divisor of $e_\mathfrak{l}$. $L'$ must also be a subfield of $\mathbb{Q}(\mathbf{\upmu}_\ell)$ so $[L':L]\Big\vert \displaystyle\frac{\ell-1}{2}$. In addition, such an extension must be completely ramified at $\ell$, meaning the ramification index is the degree of the extension. Hence we can conclude $[L':L] \Big\vert e_\mathfrak{l}$ as well. Therefore as $\left(e_\mathfrak{l}, (\ell-1)/2\right) = 1$ by assumption, we must have that $L' = L$.
<!-- end proof-7 -->
<!-- remark-6: body_md -->
\label{rmk: KL cap Q condition totally balanced}
Note that $(e_\mathfrak{l}, (\ell-1)/2) =1$ is equivalent to $(2e_\mathfrak{l}, \ell-1) = 2$. So if $E/K$ is an elliptic curve which is balanced at $\mathfrak{l}$ and condition $(b)$ holds, then $E/K$ is totally balanced at $\mathfrak{l}$.

<!-- lemma-4: body_md -->
\label{lemma: intersection square class}
     Let $K$ and $L$ as in Proposition \ref{Prop: balanced trace KL} and suppose $KL\cap \mathbb{Q}(\mathbf{\upmu}_\ell) = L$. For any fixed $b \in \mathbb{F}_\ell^\times$, there exists a prime $p$ that splits completely in $KL$ such that $p \equiv b^2 $ (mod $\ell$).
<!-- end lemma-4 -->
<!-- proof-8: body_md -->
We'll consider the following diagram of field extensions. 

    \begin{center}
\begin{tikzcd}
                      &                                                               & M \vcentcolon= KL(\mathbf{\upmu}_\ell)                                                                        &                                   \\
                      & KL \arrow[ru, no head]                                                 &                                                                                           & \mathbb{Q}(\mathbf{\upmu}_\ell) \arrow[lu, no head] \\
K \arrow[ru, no head] &                                                               & L = \mathbb{Q}(\sqrt{-\ell}) \arrow[lu, no head] \arrow[ru, "\frac{\ell-1}{2}"', no head] &                                   \\
                      & \mathbb{Q} \arrow[lu, "N", no head] \arrow[ru, "2"', no head] &                                                                                           &                                  
\end{tikzcd}
    \end{center}
    Let $b \in \mathbb{F}_\ell^\times$ be given. Our goal is to find a Frobenius element in $\operatorname{\textnormal{\textsf{Gal}}}(M/\mathbb{Q})$ corresponding to a rational prime that has the desired properties. For any number field, there are infinitely many primes that split completely, however our hope is to justify that there must always exist one that is congruent to $b^2$ for any fixed $b$. This will be done by first considering elements of $\operatorname{\textnormal{\textsf{Gal}}}(KL/\mathbb{Q}) \times \operatorname{\textnormal{\textsf{Gal}}}(\mathbb{Q}(\mathbf{\upmu}_\ell)/\mathbb{Q})$. We then apply the Chebortarev Denisty Theorem to lift to a suitable element in $G_\mathbb{Q}$. Note
     $$\operatorname{\textnormal{\textsf{Gal}}}(M/\mathbb{Q}) \cong \{(\sigma, \tau) : \sigma\vert_L = \tau\vert_L\} \leq \operatorname{\textnormal{\textsf{Gal}}}(KL/\mathbb{Q}) \times \operatorname{\textnormal{\textsf{Gal}}}(\mathbb{Q}(\mathbf{\upmu}_\ell)/\mathbb{Q}),$$ so we may fix a homomorphism $\phi:  \operatorname{\textnormal{\textsf{Gal}}}(KL/\mathbb{Q}) \times \operatorname{\textnormal{\textsf{Gal}}}(\mathbb{Q}(\mathbf{\upmu}_\ell)/\mathbb{Q}) \to \operatorname{\textnormal{\textsf{Gal}}}(M/\mathbb{Q}) $ \cite{dummit2003abstract}.

    First consider the criteria that $p$ slits completely in $KL$ and let $\theta_p \in G_\mathbb{Q}$ be a Frobenius element for $p$. By the proof of Proposition \ref{Prop: balanced trace KL}, $\left(\frac{p}{\ell}\right) = 1$. Now consider $\chi$, the $\ell$-adic cyclotomic character modulo $\ell$. 
   
    This map has the property that $\chi(\theta_p) \equiv p $ (mod $\ell$). The second criteria we ask is that $p$ is a square $\ (\mathrm{mod}\ \ell)$. For such a prime $p$ it must be that  $\chi(\theta_p) \in \operatorname{\textnormal{\textsf{Gal}}}(\mathbb{Q}(\mathbf{\upmu}_\ell)/L)$. So we conclude that any Frobenius corresponding to a prime that splits completely in $KL$ and is congruent to a square modulo $\ell$ must fix the subfield $L$.

    Hence we can now reduce our search to the following subgroup
    \[H \vcentcolon= \operatorname{\textnormal{\textsf{Gal}}}(KL/L) \times \operatorname{\textnormal{\textsf{Gal}}}(\mathbb{Q}(\mathbf{\upmu}_\ell)/L).\]

    As $KL \cap \mathbb{Q}(\mathbf{\upmu}_\ell) = L$ by assumption, $\operatorname{\textnormal{\textsf{Gal}}}(M/L) \cong H$. Hence the restriction of $\phi$ to $H$, $\phi_H : H \to \operatorname{\textnormal{\textsf{Gal}}}(M/L)$, is an isomorphism.

    Hence for any $\tau \in \operatorname{\textnormal{\textsf{Gal}}}(\mathbb{Q}(\mathbf{\upmu}_\ell)/L)$ representing a specific square modulo $\ell$, there exists $\sigma \in \operatorname{\textnormal{\textsf{Gal}}}(KL/L)$ such that $\phi(\sigma, \tau ) \in \operatorname{\textnormal{\textsf{Gal}}}(M/L) \leq \operatorname{\textnormal{\textsf{Gal}}}(M/\mathbb{Q})$ as desired.

<!-- corollary-2: body_md -->
\label{Cor: reverse containment}
    With $K,L, E$ as in Proposition \ref{prop: heavenly not surj} and Lemma \ref{lemma: intersection square class}, then
    \[\tr\left(\rho_{E,\ell}(G_K)\right) = \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}.\]
<!-- end corollary-2 -->
<!-- proof-9: body_md -->
It is only necessary to show the reverse of the containment established in Proposition \ref{prop: heavenly not surj}. 

    Let $a \in \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}$. We must demonstrate a prime $\mathfrak{p}$ such that $a_\mathfrak{p} \in \tr\left(\rho_{E,\ell}(G_K)\right)$ satisfies $a_\mathfrak{p} \equiv a \ (\mathrm{mod}\ \ell)$.

    If $a = 0$, pick any prime $p$ inert in $L$, and choose any prime $\mathfrak{p}$ of K above $p$. Then $\left(\frac{p}{\ell}\right) = -1$, and so $a_\mathfrak{p} \equiv 0$ as $f_\mathfrak{p}$ must always be odd.

    Now suppose $a \neq 0$, and set $b = \frac{a}{2} \in \mathbb{F}_\ell^\times$. By Lemma \ref{lemma: intersection square class}, there exists a prime $p$ that splits completely in $KL$ and has the property that $p \equiv b^2 \equiv \left(\frac{a}{2}\right)^2$.

  As $p$ splits completely in $KL$, it must also split completely in all sub-extensions. So for some prime $\mathfrak{p}$ of $K$  above $p$, it must be that $\mathfrak{p}$ splits in $KL$. By Proposition \ref{Prop: balanced trace KL}, $$a_\mathfrak{p}(E)^2 \equiv 4p^f \equiv (2b)^2 \equiv a^2\: (\text{mod } \ell).$$ So it must be that $a_\mathfrak{p}(E) \equiv \pm a \ (\mathrm{mod}\ \ell)$. We have already shown $a_\mathfrak{p} \in \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}$ by the first containment, and $a \in \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}$ by assumption.  So we must now simply show that $-a \not\in \left(\frac{2}{\ell}\right)\cdot\mathbb{F}_\ell^{\times2}\cup \{0\}$. However $\ell \equiv 3 \ (\mathrm{mod}\ 4)$ and so $-1 \not\in \mathbb{F}_\ell^{\times2}$. Thus $-a \notin \left(\frac{2}{\ell}\right)\mathbb{F}_\ell^{\times 2}$ also.

<!-- proposition-8: body_md -->
\label{prop: CM good red l 3}
    Suppose $E/K$ is an elliptic curve defined over $K = \mathbb{Q}(j(E))$, an odd degree extension of $\mathbb{Q}$.
    Suppose further that $E$ has complex multiplication by the maximal order of an imaginary quadratic field $L$. 
    If $E$ has good reduction away from an odd prime $\ell$, then $L = \mathbb{Q}(\sqrt{-\ell})$ and $\ell \equiv 3 \ (\mathrm{mod}\ 4)$.
<!-- end proposition-8 -->
<!-- proof-10: body_md -->
Set $n = [K:\mathbb{Q}]$, and consider the composite field $KL = L(j(E))$.
    This must be the Hilbert class field of $L$. \cite[Ch. II.4, Thm. 4.3]{advancedSilverman}
    Furthermore, since $n$ is be odd, we have $K \cap L = \mathbb{Q}$ and hence $[KL:L] = [K:\mathbb{Q}]$. We will denote the genus field of $L$ by $\Gamma(L)$, where $\Gamma(L) \subseteq KL$.
    
    By the classification of genus fields given in \cite[Thm. 6.1]{primesx+ny}, $\Gamma(L) = L(\sqrt{p_1^*}, \ldots , \sqrt{p_r^*})$ with each $p_i$ a factor of $\Delta_{L/\mathbb{Q}}$ and $p_i^* = (\frac{p_i}{4})\cdot p_i$.
    Hence the degree of the extension $\Gamma(L)/L$ must be a power of 2.
    As $KL/L$ has odd degree, $L = \Gamma(L)$. 
    Hence $\Delta_{L/\mathbb{Q}}$ must have only one prime factor, say $\Delta_{L/\mathbb{Q}} = p$. 
    For this to be true for an imaginary quadratic field, $L$ must have the form $\mathbb{Q}(\sqrt{-p})$ with $p \equiv 3\ (\mathrm{mod}\ 4)$.

    We now endeavor to show that $ p = \ell$.
    First, since $E/K$ has good reduction away from $\ell$, the extension $K(E[\ell])/K$ must be unramified away from $\ell$.
    By \cite[Lem. 3.15]{BCS17}, $L \subseteq K(E[\ell])$.
    So we have the following tower of field extensions on which we may compare discriminants.

    \begin{center}
                                                                                                                                                                                                                                                                                                                                  
\begin{tikzcd}
                      & {K(E[\ell])}                                       &                       \\
                      & KL \arrow[u, no head]                              &                       \\
K \arrow[ru, no head] &                                                    & L \arrow[lu, no head] \\
                      & \mathbb{Q} \arrow[ru, no head] \arrow[lu, no head] &                      
\end{tikzcd}
    \end{center}

We may compute the discriminant $\Delta_{KL/\mathbb{Q}}$ by comparing relative discriminants down either side of the tower. By \cite[Cor. 2.10]{algebraic_number_neukrich} we find a formula that relates absolute and relative field discriminants.  

\begin{equation}\label{eq: relative disc.}
    \Delta_{KL/\mathbb{Q}} = \Delta_{K/\mathbb{Q}}^{[KL:K]}\cdot N_{K/\mathbb{Q}}(\Delta_{KL/K}) = \Delta_{L/\mathbb{Q}}^{[KL:L]}\cdot N_{L/\mathbb{Q}}(\Delta_{KL/L}).
\end{equation}


 Further we know that a a prime $\mathfrak{p} \in K$ ramifies in $KL$ if and only if $\mathfrak{p}\big\vert\Delta_{KL/K}$. As $KL/K$ is an extension unramified away from $\ell$, it must be that the only factors of the discriminant $\Delta_{KL/K}$ are primes $\mathfrak{l}\big\vert \ell$. Hence, $N_{K/\mathbb{Q}}(\Delta_{KL/K}) = \ell ^r$ for some $r$. Similarly, $KL/L$ is a totally unramified extension, so its discriminant $\Delta_{KL/L}$ must be a unit in $\mathcal{O}_L$ and so $N_{L/\mathbb{Q}}(\Delta_{KL/L}) = \pm 1$. Finally $\Delta_{L/\mathbb{Q}} = -p$. Then \eqref{eq: relative disc.} simplifies to

 \[\Delta_{KL/\mathbb{Q}} = (\Delta_{K/\mathbb{Q}})^2\cdot \ell^r = \pm(-p)^n.\]

 It is clear that the right hand side of our equality has only one prime factor, and hence $p = \ell$.

<!-- remark-7: body_md -->
Under the hypothesis of Proposition \ref{prop: CM good red l 3}, we have $KL/\mathbb{Q}$, and hence $K/\mathbb{Q}$ unramified away from $\ell$. This greatly restricts the fields that can appear as the odd-degree field of definition of an elliptic curve with complex multiplication, and good reduction away from one rational prime.

Note that $\sharp\textit{Cl}(\mathcal{O}_L) = [KL:K]$ is a function of $n = [K:\mathbb{Q}]$ only. There are finitely many imaginary quadratic fields with a fixed class number, so for each $n$ only finitely many choices of $\mathcal{O}_L$ are possible. \cite{fixed-class-number}. This finite list of maximal orders may only produce examples of heavenly elliptic curves that meet the hypothesis of Proposition \ref{prop: CM good red l 3}.

<!-- theorem-1: body_md -->
\label{thm: CMheavenly iff not sur}
    Let $\ell$ be an odd prime, and $K$ an extension of $\mathbb{Q}$ of odd degree. Suppose $E/K$ is an elliptic curve that satisfies $K = \mathbb{Q}(j(E))$. Further, assume that $E/K$ has complex multiplication and has good reduction away from $\ell$.  Then $E/K$ is heavenly at $\ell$ if and only if $\operatorname{\textnormal{\textsf{tr}}}(\rho_{E,\ell}(G_K))$ is a proper subset of $\mathbb{F}_\ell$.
<!-- end theorem-1 -->
<!-- proof-14: body_md -->
As $E$ has good reduction away from $\ell$, we must only show that $[K(E[\ell]):K(\mu_\ell)]$ a power of $\ell$. 
    Let $L$ be the field of complex multiplication, and set $M\vcentcolon= KL$. 
    From Remark \ref{rmk: pick maxl CM}, we may assume $E$ has CM by the maximal order $\mathcal{O}_L$.
    By \cite{BCS17}, $L \subseteq K(E[\ell])$.
    Hence $M(E[\ell]) = K(E[\ell])$. 
    The $j$-invariant for any elliptic curve with complex multiplication must be real, hence $K$ is a real field, and $[K(\mu_\ell) : K] = \ell-1$. 
    By Theorem \ref{prop: CM good red l 3}, $L = \mathbb{Q}(\sqrt{-\ell})$ with $\ell \equiv 3 \ (\mathrm{mod}\ 4)$.
    It then must be true that $M = K(\sqrt{-\ell}) \subseteq K(\mu_\ell) = M(\mu_\ell)$ and $[M(\mu_\ell):M] = (\ell-1)/2$.

    Let $\rho = \rho_{E,\ell}$ be the $G_K$-representation on $E[\ell]$. 
    As $E$ has complex multiplication, $E[\ell]$ is a free rank one module over $\mathcal{O}_L/\ell\mathcal{O}_L$.
    Since $\ell$ ramifies in $L$, $\mathcal{O}_L/\ell\mathcal{O}_L \cong \mathbb{F}_\ell [T]/(T^2)$. 
    Then
    \[\rho(G_K) \leq \operatorname{\textnormal{\textsf{Aut}}}_{\mathcal{O}_L/\ell\mathcal{O}_L}\left(E[\ell]\right) \cong \left(\mathbb{F}_\ell[T]/\left(T^2\right)\right)^\times = \{bT + a : b \in \mathbb{F}_\ell, a \in \mathbb{F}_\ell^\times\}.\]

    By definition $\ker(\rho) = G_{K(E[\ell])}$.
    Since $E$ has good reduction away from $\ell$ and complex multiplication there is an injection
    \[\overline{\rho} : \operatorname{\textnormal{\textsf{Gal}}}(K(E[\ell])/M) \hookrightarrow \operatorname{\textnormal{\textsf{Aut}}}_{\mathcal{O}_L/\ell\mathcal{O}_L}(E[\ell]).\]

    As $K \subseteq M$, then $G_M \leq G_K$ and $\rho(G_M) \subseteq \rho(G_K)$. Hence we can conclude that the image of $G_{M}$ under $\rho$ must also sit inside of $\operatorname{\textnormal{\textsf{Aut}}}_{\mathcal{O}_L/\ell\mathcal{O}_L}(E[\ell])$. 
    We may then choose an ordered basis for $E[\ell]$ such that
    \[\rho(G_{M}) \leq \mathcal{C} := \left\{\begin{pmatrix}
        a & b\\ 0 & a
    \end{pmatrix} : b \in \mathbb{F}_\ell, a \in \mathbb{F}_\ell^\times \right\}.\]\cite[Thm. 1.1]{Lozano_Robledo_2022}
    Let $\mathcal{N}$ be the normalizer of $\mathcal{C}$ inside $\operatorname{\textnormal{\textsf{GL}}}_2(\mathbb{F}_\ell)$. 
    There exists a unique subgroup $\mathcal{N}'\leq \mathcal{N}$ with the property that $[\mathcal{N}':\mathcal{C}] = 2$.
    This subgroup has the form
    \[\mathcal{N}' : = \left\{\begin{pmatrix}
        \pm a & b\\ 0 & a
    \end{pmatrix} : b \in \mathbb{F}_\ell, a \in \mathbb{F}_\ell^\times \right\}.\]
    Further, by \cite[Lem. 6.2]{Lozano_Robledo_2022}, it must be that $\rho(G_K) \leq \mathcal{N}'$.
    Consequently, we can express $\rho$ using homomorphisms $\theta: G_K \to \mathbb{F}_\ell^\times$ and $\varepsilon : G_K \to \{\pm 1\}$ such that
    \[\rho = \begin{pmatrix}
        \varepsilon\theta & \star \\ & \theta \end{pmatrix}, \quad \rho\big\vert_{G_{M}} = \begin{pmatrix}
            \psi & \star\\ & \psi \end{pmatrix}, \ \text{where}\ \psi : = \theta\big\vert_{G_{M}}.\]
    Further, these must satisfy the condition $\varepsilon\theta^2 = \det\rho = \chi$.
    Notice now that $\varepsilon$ is a cokernel character for the projection $G_K \twoheadrightarrow G_K/G_M$ as for any $\sigma \in G_K$, we have 
    \[\operatorname{\textnormal{\textsf{tr}}}\rho(\sigma) = 0 \iff \varepsilon(\sigma) = -1 \iff \sigma \notin G_{M}.\]
    So $\operatorname{\textnormal{\textsf{tr}}}\left(\rho(G_K)\right) = \operatorname{\textnormal{\textsf{tr}}}\left(\rho(G_{M})\right)\cup \{0\}$.
    Then for any $\sigma \in G_{M}$, $\operatorname{\textnormal{\textsf{tr}}}\rho(\sigma) = 2\cdot\psi(\sigma)$.
    But as 2 is invertible in $\mathbb{F}_\ell$,
    \[\sharp(\operatorname{\textnormal{\textsf{tr}}}\rho(G_{M})) = \sharp(2\cdot\psi(G_{M})) = \sharp\psi(G_{M}).\]
    We now check if $\psi$ is surjective.
    Set $M^\psi \vcentcolon= \overline{M}^{\ker\psi}$. 
    The condition $\psi^2 = \chi\big\vert_{G_{M}}$ gives the following inclusion of Galois groups:
    \[G_{M^\psi} = \ker\psi \leq \ker\psi^2 = \ker\chi\big\vert_{G_{M}} = G_{M(\mu_\ell)}.\]
    Thus $M(\mu_\ell) \subseteq M^\psi$. The representation $\rho\big\vert_{M^{\psi}}$ is unit upper triangular. 
    So the image $\rho(M^\psi)$ can only have order $1$ or $\ell$.
    Pulling back through the representation shows $[M(E[\ell]): M^\psi]$ must divide $\ell$. 
    We also have
    \[[M^\psi : M(\mu_\ell)] = \frac{[M^\psi: M]}{[M(\mu_\ell): M]} = \frac{\sharp\psi(G_{M})}{(\ell-1)/2}.\]
    The curve $E/K$ is heavenly if and only if $[K(E[\ell]):K(\mu_\ell)] = \ell$, which will happen if and only if $[M^\psi : M(\mu_\ell)] = 1$.
    This happens exactly when $\sharp\psi(G_{M}) = (\ell-1)/2$, implying $\psi$ is not surjective.
<!-- end proof-14 -->
<!-- remark-9: body_md -->
It is worth noting here that Proposition \ref{prop: heavenly not surj} only shows $\operatorname{\textnormal{\textsf{tr}}}\left(\rho(G_K)\right) \subseteq \left(\frac{2}{\ell}\right)\cdot \mathbb{F}_\ell^{\times 2} \cup \{0\}$ for totally balanced curves.
    This does not imply that $\sharp\operatorname{\textnormal{\textsf{tr}}}\left(\rho(G_K)\right) = (\ell-1)/2$ exactly.
    However, under the assumptions of Theorem \ref{thm: CMheavenly iff not sur} $E$ has complex multiplication and we show that no other order is possible.
    If $\sharp\operatorname{\textnormal{\textsf{tr}}}\left(\rho(G_K)\right) = \sharp\psi(G_{M}) = (\ell-1)/n < (\ell-1)/2$, then
    \[\frac{[M^\psi: M]}{[M(\mu_\ell): M]} = \frac{(\ell-1)/n}{(\ell-1)/2} < 1\]
    which is impossible.
    Hence in the case where $E$ is heavenly at $\ell$ and has complex multiplication, $\operatorname{\textnormal{\textsf{tr}}}\left(\rho(G_K)\right) = \left(\frac{2}{\ell}\right)\cdot \mathbb{F}_\ell^{\times 2} \cup \{0\}$ exactly.

<!-- lemma-5: body_md -->
\label{lem: exectional j lifting}
    For $n$ odd and $B > 3$, there do not exist any $([E]_{\overline{\mathbb{Q}}},\ell) \in \overline{\mathcal{H}}^\circ(n,1)_B$ with $j := j(E) \in \{0,1728\}.$
<!-- end lemma-5 -->
<!-- proof-15: body_md -->
Suppose there did exist some $([E]_{\overline{\mathbb{Q}}},\ell) \in \overline{\mathcal{H}}^\circ(n,1)_B$ such that $j = 0$. Then there must exist some representative $E'/K$ in the $\overline{\mathbb{Q}}$ isomorphism class of $E$ where $K$ is a Galois field of degree $n$, and $E'$ has CM field $\mathbb{Q}(\mathbf{\upmu}_6)$. For ease of notation, we will simply let $E$ be the correct representative. Then by \cite[Lem. 3.15]{BCS17}, it must be that $K(\mathbf{\upmu}_6) \subseteq K(E[\ell])$. 


    Let $\rho_E$ be the $G_K$-representation on the $\ell$-torsion of $E$, and let $\Gamma \vcentcolon= \operatorname{\textnormal{\textsf{Gal}}}(K(E[\ell])/K)$. Since $E$ is heavenly at $\ell$ over $K$, we have that $\Gamma \cong \rho_E(G_K) \leq \mathcal{B}$ by Prop. \ref{prop: heavenly upper triangular}.

   Consider the subgroup $\Gamma_1 = \Gamma \cap\mathcal{U}$. It must be that $K(\mathbf{\upmu}_\ell) = K(E[\ell])^{\Gamma_1}$, as $\rho_E(G_{K(\mathbf{\upmu}_\ell)}) \leq \mathcal{U}$. Now,

   $$\sharp \Gamma_1 = [K(E[\ell]):K(\mathbf{\upmu}_\ell)] = [K(E[\ell]):K(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell)][K(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell):K(\mathbf{\upmu}_\ell)]$$

   Note that $[K(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell):K(\mathbf{\upmu}_\ell)] \leq [\mathbb{Q}(\mathbf{\upmu}_6): \mathbb{Q}] = 2$. In addition, $\sharp\mathcal{U} = \ell$, so $\sharp\Gamma_1 = [K(E[\ell]):K(\mathbf{\upmu}_\ell)]$ must be odd. This lets us conclude that $[K(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell):K(\mathbf{\upmu}_\ell)] = 1$ and hence $K(\mathbf{\upmu}_6) \subseteq K(\mathbf{\upmu}_\ell)$. We will show this conclusion leads to a contradiction. 

   As $\ell \geq B > 3$ then $\mathbf{\upmu}_6 \not\subseteq \mathbf{\upmu}_\ell$ and it must be that $[\mathbb{Q}(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)] = 2$.

   Let $M = \mathbb{Q}(\mathbf{\upmu}_\ell) \cap K$, and let $r = [M:\mathbb{Q}]$. Then,

   \begin{align*}
       [K(\mathbf{\upmu}_\ell):\mathbb{Q}] & = \frac{[K:\mathbb{Q}][\mathbb{Q}(\mathbf{\upmu}_\ell):\mathbb{Q}]}{[M:\mathbb{Q}]}\\
       & = \frac{n(\ell-1)}{r}\\
       & = [K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)][\mathbb{Q}(\mathbf{\upmu}_\ell):\mathbb{Q}]
   \end{align*}

   So $[K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)] = \frac{n}{r}$ which must be odd.

   However, $[K(\mathbf{\upmu}_\ell) : \mathbb{Q}(\mathbf{\upmu}_\ell)] = [K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell)][\mathbb{Q}(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)] = 2[K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_6,\mathbf{\upmu}_\ell)]$, a contradiction.

We will now proceed with a similar proof for the case $j = 1728$. Suppose $([E]_{\overline{\mathbb{Q}}}, \ell) \in \overline{\mathcal{H}}^\circ(n,1)_B$ with $j = 1728$. Again, for ease of notation we will let $E/K$ be the representative from the $\overline{\mathbb{Q}}$ isomorphism class with CM field $\mathbb{Q}(\mathbf{\upmu}_4)$ and $K/\mathbb{Q}$ a Galois extension of degree $n$. As $\ell \geq B > 3$, \cite[Lem. 3.15]{BCS17} shows $K(\mathbf{\upmu}_4) \subseteq K(E[\ell])$.

As above let $\rho_E$ be the $G_K$-representation on the $\ell$-torsion of $E$, and let $\Gamma \vcentcolon= \operatorname{\textnormal{\textsf{Gal}}}(K(E[\ell])/K)$. As $E/K$ is heavenly at $\ell$, Proposition \ref{prop: heavenly upper triangular} shows $\Gamma \cong \rho_E(G_K) \leq \mathcal{B}$. Consider $\Gamma_1 = \Gamma\cap \mathcal{U}$. As $\rho_E(G_{K(\mathbf{\upmu}_\ell)}) \leq \mathcal{U}$, it must be that $K(\mu_\ell) = K(E[\ell])^{\Gamma_1}$. So,

\[\sharp\Gamma_1 = [K(E[\ell]):K(\mathbf{\upmu}_\ell)] = [K(E[\ell]): K(\mathbf{\upmu}_4, \mathbf{\upmu}_\ell)][K(\mathbf{\upmu}_4, \mathbf{\upmu}_\ell):K(\mathbf{\upmu}_\ell)]\]

As $[K(\mathbf{\upmu}_4, \mathbf{\upmu}_\ell):K(\mathbf{\upmu}_\ell)] \leq [\mathbb{Q}(\mathbf{\upmu}_4):\mathbb{Q}] =2$ and $\sharp\Gamma_1 = [K(E[\ell]):K(\mathbf{\upmu}_\ell)]$ is odd, then $[K(\mathbf{\upmu}_4, \mathbf{\upmu}_\ell):K(\mathbf{\upmu}_\ell)] =1$ and $K(\mathbf{\upmu}_4) \subseteq K(\mathbf{\upmu}_\ell)$. 

Note that as $\ell > 3$ $\mathbf{\upmu}_4 \not\subseteq \mathbf{\upmu}_\ell$ and hence $[\mathbb{Q}(\mathbf{\upmu}_4, \mathbf{\upmu}_\ell): \mathbb{Q}(\mathbf{\upmu}_\ell)] =2$. Set $M \vcentcolon= \mathbb{Q}(\mu_\ell)\cap K$ and let $r = [M:\mathbb{Q}]$. Then,

\begin{align*}
       [K(\mathbf{\upmu}_\ell):\mathbb{Q}] & = \frac{[K:\mathbb{Q}][\mathbb{Q}(\mathbf{\upmu}_\ell):\mathbb{Q}]}{[M:\mathbb{Q}]}\\
       & = \frac{n(\ell-1)}{r}\\
       & = [K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)][\mathbb{Q}(\mathbf{\upmu}_\ell):\mathbb{Q}]
   \end{align*}

   So $[K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)] = \frac{n}{r}$ which must be odd.

   However, $[K(\mathbf{\upmu}_\ell) : \mathbb{Q}(\mathbf{\upmu}_\ell)] = [K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_4,\mathbf{\upmu}_\ell)][\mathbb{Q}(\mathbf{\upmu}_4,\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_\ell)] = 2[K(\mathbf{\upmu}_\ell):\mathbb{Q}(\mathbf{\upmu}_4,\mathbf{\upmu}_\ell)]$, a contradiction.

\label{prop: finite fibers heavenly ex}
    Suppose $\overline{E}/\overline{\mathbb{Q}}$ is an elliptic curve, $([\overline{E}]_{\overline{\mathbb{Q}}},\ell) \in \overline{\mathcal{H}}^\circ(p,1)_B$ for $p$ prime. Suppose $B > p$, and $j:= j(E) \notin \{0,1728\}.$ Let $X$ be the fiber of $\alpha$ over $([\overline{E}]_{\overline{\mathbb{Q}}},\ell)$.

    \begin{enumerate}
        \item[(a)] Suppose $K',K''$ are distinct fields of degree $p$ and $A'/K'$, $A''/K''$ are elliptic curves satisfying $([A']_{K'},\ell),([A'']_{K''},\ell) \in X$. Then $j(\overline{E}) \in \mathbb{Q}$.
        \item[(b)] Let $A_0/\mathbb{Q}$ be any elliptic curve with $j(\overline{E}) = j(A_0)$. for every $([A]_K,\ell)\in X$, it holds that $K \subseteq \mathbb{Q}(A_0[\ell])$.
    \end{enumerate}
    In particular, the set $X$ must be finite.

<!-- proof-16: body_md -->
First we will argue that $(a)$ and $(b)$ are sufficient to show the finiteness of the fiber $X$. For the sake of contradiction, suppose $(a)$ and $(b)$ hold, but $X$ is infinite. Each fixed field $K$ may only contribute finitely many pairs of the form $([A]_K,\ell) \in X$, as the Shafarevich Conjecture ensures that there are finitely many $K$-isomorphism classes of elliptic curves with good reduction away from $\ell$. So if $X$ is infinite, it is because infinitely many distinct fields of degree $p$ are contributing elements of $X$. By $(a)$ it must be that $j \in \mathbb{Q}$, hence there does exist some model $A_0/\mathbb{Q}$ with $j(A_0) = j$. However part $(b)$ implies that $K \subset \mathbb{Q}(A_0[\ell])$. It cannot be true that a finite extension of $\mathbb{Q}$ contains infinitely many distinct subfields, and hence it must be that $\sharp X < \infty$.

    To prove part $(a)$, we will note that $A'$ and $A''$ both living in the fiber of $([\overline{E}]_{\overline{\mathbb{Q}}},\ell)$ means $j(A') = j = j(A'')$. Hence $j \in K'\cap K'' = \mathbb{Q}$. It is exactly in this step where the reduction to prime degree fields in necessary.

    We now prove $(b)$. We may only assume that there exists some $A_0/\mathbb{Q}$ with $j(A_0) = j$ if $j \in \mathbb{Q}$. By $(a)$, this must hold any time there are two distinct fields of order $p$ who produce an element of the fiber. Clearly by the Shafarevich Conjecture, if all of the pairs $([A]_K, \ell) \in X$ have the same field $K$, then it must be that $X$ is finite.

    So we may take $A_0/\mathbb{Q}$ with $j(A_0) = j$. Let $([A]_K, \ell) \in X$ and suppose by way of contradiction that $K \not\subseteq \mathbb{Q}(A_0[\ell])$. It must then be that $A_0\times_\mathbb{Q} K$ and $A$ are quadratic twists of each other, as they are curves with the same $j$-invariant both defined over the same field $K$. So we have some quadratic character $\lambda: G_K \to \{\pm1\}$ such that $(A_0\times_\mathbb{Q} K)^\lambda \cong_K A$. The goal of this proof is to extend this to a quadratic character on $G_\mathbb{Q}$ so that we generate a heavenly elliptic curve $E_0/\mathbb{Q}$ which must also be in the fiber $X$.

    We have not assumed $A_0$ is heavenly at $\ell$, but $A$ is. We can then use the fact that $A_0$ is a twist of $A$ to deduce 

    $$\rho_{A_0,\ell}\big\vert_{G_K} = \rho_{A,\ell}^\lambda = \begin{pmatrix}
        \lambda\chi^{i_1} & \star\\ 0 & \lambda\chi^{i_2}
    \end{pmatrix}$$

    Let $G_0 \vcentcolon= \operatorname{\textnormal{\textsf{Gal}}} (\mathbb{Q}(A_0[\ell])/\mathbb{Q})$. $K$ and $\mathbb{Q} (A_0[\ell])$ are linearly disjoint by assumption, so $G_0 \cong \operatorname{\textnormal{\textsf{Gal}}} (K(A_0[\ell])/K)$. So, $\rho_{A_0}(G_\mathbb{Q}) \cong \rho_{A_0}(G_K)$. In addition, by the above observation, $\rho_{A_0}(G_K) = \rho_A^\lambda(G_K) \leq \mathcal{B}$ up to conjugacy. We can then conclude that $\rho_{A_0}(G_\mathbb{Q}) \leq \mathcal{B}$. Hence there must exist maps $\phi_i:G_\mathbb{Q} \to \mathbb{F}_\ell^\times$ such that 

    $$\rho_{A_0} \sim \begin{pmatrix}
        \phi_1 & \star \\ 0 & \phi_2
    \end{pmatrix}$$

    These characters must also have the property that for $m = 1,2$ $\phi_m\big\vert_{G_K} = \lambda\chi^{i_m}$, so we will set $\varepsilon_m \vcentcolon= \phi_m\chi^{-i_m}$. Note that $\varepsilon_m\big\vert_{G_K} = \lambda$. We can then study the following commutative diagram:

                                                                                                                                                                                                                                                                                                                                     
\[\begin{tikzcd}
	{G_K} & {G_0} & {G_\mathbb{Q}} \\
	& {\mathbb{F}_\ell^\times}
	\arrow[two heads, from=1-1, to=1-2]
	\arrow["\lambda"', from=1-1, to=2-2]
	\arrow[from=1-2, to=2-2]
	\arrow[two heads, from=1-3, to=1-2]
	\arrow["{\varepsilon_m}", from=1-3, to=2-2]
\end{tikzcd}\]

We now want to show that $\varepsilon_1 = \varepsilon_2$. Let $\sigma \in G_\mathbb{Q}$ be an arbitrary element, and denote the image under the natural projection as $\overline{\sigma} \in G_0$. Then let $\tilde{\sigma} \in G_K$ any element which maps to $\overline{\sigma}$. But then $\varepsilon_1(\sigma) = \lambda(\tilde{\sigma}) = \varepsilon_2(\sigma)$. As this is true for an arbitrary element of $G_\mathbb{Q}$, we can conclude $\varepsilon_1 = \varepsilon_2$. So we can remove the indexing and refer to this map as $\varepsilon$. This must be a quadratic character as $\varepsilon(G_\mathbb{Q}) \subseteq \lambda(G_K) = \{\pm 1\}$. So for $m = 1,2$, $\phi_m = \varepsilon\chi^{i_m}$, and we may construct $E_0 \vcentcolon= A_0^\varepsilon$, a quadratic twist. This gives us the following description of $\ell$-torsion representations.

$$\rho_{A_0} = \begin{pmatrix} \phi_1 & \star \\ 0 & \phi_2 \end{pmatrix} = \begin{pmatrix} \varepsilon\chi^{i_1} & \star \\ 0 & \varepsilon\chi^{i_2} \end{pmatrix}, \qquad \rho_{E_0} = \begin{pmatrix} \chi^{i_1} & \star \\ 0 & \chi^{i_2} \end{pmatrix}.$$

However, we have also constructed $\varepsilon$ such that $\varepsilon\big\vert_{G_K} = \lambda$, so $(A_0\times_\mathbb{Q} K)^\lambda \cong_K (A_0^\epsilon \times_\mathbb{Q} K) = E_0 \times_\mathbb{Q} K$. Hence we can conclude that $E_0 \times_\mathbb{Q} \overline{\mathbb{Q}} \cong_{\overline{\mathbb{Q}}} \overline{E}$ and $K(A[\ell^\infty]) = K\cdot\mathbb{Q}(E_0[\ell^\infty])$.

We now wish to argue that $E_0$ is heavenly at the prime $\ell$. By Lemma \ref{lem:heavenly equiv def}, we must show that $[\mathbb{Q}(E_0[\ell]):\mathbb{Q}(\mathbf{\upmu}_\ell)]$ is $\ell$-power degree, and $E_0$ has good reduction away from $\ell$.

When we restrict $\rho_{E_0}$ to $G_{\mathbb{Q}(\mathbf{\upmu}_\ell)}$ it is unit upper triangular, so $[\mathbb{Q}(E_0[\ell]):\mathbb{Q}(\mathbf{\upmu}_\ell)]\big\vert\ell$. Now let $p \neq \ell$ be a distinct prime. We will argue that $E_0$ must have good reduction at $p$, using the criteria of N\'{e}ron-Ogg-Sharafevich \cite{Serre-Tate}, we will argue that $p$ is unramified in $\mathbb{Q}(E_0[\ell^\infty])\mathbb{Q}$. 

Arguing that $p$ is unramified for some arbitrary $\ell^n$ division field, will be sufficient to show $p$ is unramified in the composite $\mathbb{Q}(E_0[\ell^\infty])$. So let $n > 1$ be an integer; set $F = \mathbb{Q}(E_0[\ell^n])$ and $\mathfrak{p}$ a prime of $F$ above $p$. Clearly $KF \subseteq K(A[\ell^\infty])$. As $A$ is heavenly at $\ell$, $KF/K$ must be unramified away from $\ell$. Hence any ramification of the prime $p$ is controlled by $K$. So $e_{\mathfrak{p}\vert p} \leq [K:\mathbb{Q}] = p$. In addition, $\mathbb{Q}(\mathbf{\upmu}_\ell)/\mathbb{Q}$ is unramified at $p$ so $e_{\mathfrak{p}\vert p}$ must divide $[F:\mathbb{Q}(\mathbf{\upmu}_\ell)]$, an $\ell$ extension.

However, we have assumed at the start of this proof that $\ell \geq B > p$. Hence the only way for $e_{\mathfrak{p}\vert p}$ to be a power of $\ell$ \textit{and} less than or equal to $p$ is if $e_{\mathfrak{p}\vert p} = 1$ as desired. This is sufficient to show $([E_0]_\mathbb{Q},\ell) \in \mathcal{H}(\mathbb{Q},1)$. This would then tell us that $([\overline{E}]_{\overline{\mathbb{Q}}},\ell) \in \overline{\mathcal{H}}(\mathbb{Q},1)$, which contradicts the assumption that $([\overline{E}]_{\overline{\mathbb{Q}}},\ell) \in \overline{\mathcal{H}}^\circ(p,1)_B$.
